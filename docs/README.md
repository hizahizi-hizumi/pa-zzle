# 文書

pa-zzle の文書は目的ごとに分けて管理する。

- [`画面/`](画面/): 画面種別ごとの目的、情報構造、共通とゲーム固有の境界の正本。
- [`パズル/`](パズル/): パズル候補の調査、成立性・導入判断、難易度検証など、MVP前後を問わず継続するパズル固有の調査・検証資料。現在仕様の正本ではない。
- [`立ち上げ/`](立ち上げ/): アプリ立ち上げ期に固有のPoC・仮説・正本化の経緯。立ち上げ時の根拠を確認するときの参照先で、長期的な正本ではない。
- [`adr/`](adr/): 重要な意思決定の背景・比較・理由。ADRだけを現在仕様の正本として扱わない。
- [`メモ/`](メモ/): 開発上の参考資料。現在仕様の正本として扱わない。

現在の事実を確認するときは、対象コード・設定と、その作業に対応する現行文書を合わせて確認する。
