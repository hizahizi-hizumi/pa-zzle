# 文書

pa-zzle の文書は目的ごとに分けて管理する。

- [`プロダクト/`](プロダクト/): 利用者要求、システム要件、ユーザーストーリー、仕様、画面、受入条件からなる現在のプロダクト定義の正本。
- [`パズル/`](パズル/): パズル候補の調査、成立性・導入判断、難易度検証などの調査・検証資料。現在仕様の正本ではない。
- [`立ち上げ/`](立ち上げ/): アプリ立ち上げ期に固有のPoC・仮説・正本化の経緯。長期的な正本ではない。
- [`adr/`](adr/): 重要な意思決定の背景・比較・理由。現在仕様そのものはプロダクト文書へ置く。
- [`棚上げ/`](棚上げ/): 要求・要件候補やパズル候補と、その検討状況を整理する。現在仕様の正本でも作業バックログでもない。
- [`メモ/`](メモ/): 開発上の参考資料。現在仕様の正本として扱わない。

文書体系と現在のプロダクト定義を確認するときは `プロダクト/` を起点とし、調査根拠や判断理由が必要な場合だけ対応する資料へ遡る。
