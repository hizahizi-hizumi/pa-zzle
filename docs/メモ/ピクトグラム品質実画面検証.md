# ゲーム選択画面の「顔」：デザイン体系の比較検証と不採用判断

## 目的と結論

2026-11-07 時点の最新 `main`（`add7b90d4d6889973f92ca8af84d2251c3366a17`）にある10ゲームを対象に、現行ピクトグラムと異なる2体系のSVGを試作し、ゲーム選択画面で比較した。

**比較結果：現行の方が明確に良い。新規の A / Carved diagram と B / Soft emblem はともに不採用。** どちらも現行が備えるアイコニックさ、シリーズとしての統一感、pa-zzle の静かなUIとの調和を上回れなかった。

当初、この検証では「Bを第一候補」と推奨していたが、**その判断は撤回する**。着色した面が大きく、ヒーローで目立つことを「アプリの顔として強い」と誤認し、重要な3条件を十分に評価していなかった。実画面でエラーがないこともデザイン品質の証明にはならない。

この検証は品質基準を校正するための資料であり、製品版のSVG・制作Skill・`DESIGN.md`・ADRを変更するものではない。

## なぜ現行の方が優れていたか

### アイコニックさ

現行は、意味を持つ少数の輪郭・線・面の関係によってゲームを象徴する。例として、ウォーターソートは2本の試験管と液層、パーキングジャムは開口のある外周と車、リフレクションは盤の外形・光路・鏡・吸収点が記号の核となっている。

試作Bは形を太く、色面を増やしたことで、かえって**ゲーム固有の造形を持つ記号**から**ゲーム部品を並べた小さなイラスト**へ近づいた。多数の色が付いていること、丸く収まっていること、画面内で大きく見えることは、シルエットの固有性や象徴としての強さではない。

### シリーズの統一感

現行は同じ画法で全ゲームを均一化するのではなく、ゲームごとに異なる外形を持ちながら、線の主従・補助情報の濃淡・情報密度に共通言語がある。

試作A/Bは配色や角丸を共有していても、題材の切り取り方、面と線の比率、画面内の重量がゲームごとにばらついた。**「同じ装飾を使った複数の絵」≠「一つの視覚言語による記号群」**である。

### アプリとの調和

現行の一覧は中立色が基調で、選択中のゲームだけに色と動きを与える。共通UIは静かに保ち、ゲームの特徴を主役にできる。これが現行の完成度の一部になっている。

A/Bは通常時にもゲーム固有色や多色の小部品を導入し、一覧全体の刺激と情報量を増やした。ヒーローが単体で華やかになっても、画面内の視覚的な役割分担は弱くなった。**「単体で目立つ」ことは「アプリの顔として馴染む」ことと別**であり、むしろ競合し得る。

## 比較対象と不採用理由

| 対象 | 造形上の意図 | 検証後の判断 |
|---|---|---|
| 現行 | 濃淡2色、ゲーム固有の形、選択中の色・動き | **維持。現時点の比較で最良** |
| A / Carved diagram | 関係を線階層で描き、一部に色を付ける | **不採用。** 現行と近い題材に色を追加したにとどまり、造形品質・統一感の明確な改善がない |
| B / Soft emblem | 太い形・負の空間・色面でシンボル性を強める | **不採用。** 造形の象徴性より装飾性が先行し、ゲーム間の共通言語とアプリ適合性が低下 |

これを理由に、線画・濃淡2色以外のデザイン体系を永久に排除するわけではない。ただし、現行の視覚言語を捨てる根拠を今回の試作から得たとは言えない。

## ゲーム単位で観測されたトレードオフ

| ゲーム | 現行が保っているもの | 試作から分かった失敗 |
|---|---|---|
| ウォーターソート | 2本の試験管と液層の明快な対比 | 色層・矢印・容器を増やすと、記号より説明的なイラストになる |
| ナンプレ | 格子と数字の一体感 | 色付きタイルや余計な丸みを足しても、数字・格子のアイコニックさは増さない |
| マインスイーパー | 格子・数字・旗・地雷の盤面語彙 | マスを圧縮し、色面を増やしても、視覚情報の主従は自動で改善しない |
| パーキングジャム | 車と開口のある外周の、少数要素による関係 | 車種・車窓・色分け・矢印を増やすほど、駐車場の挿絵に近づく |
| スライドパズル | 数字タイルと空きマスの関係 | 大胆な省略だけでは、タイルを動かすゲームとしての手掛かりを失う |
| バイナリパズル | 二種類の図形による固有の記号 | 色面に依存せず成立する図形を多色化しても、本質的な改善がない |
| リフレクション | 光路と鏡、盤・吸収点の関係 | 発色を強めるだけでは、静的図形としての整理・統一は向上しない |
| 一筆パズル | 始点からの一本の道と未通過部の関係 | 面の強調が強すぎると、道としての読みやすさを損なう |
| アイスフロア迷路 | 軌跡と止まる条件に関わる要素 | 色による説明を加えても、ゲーム固有のルール理解は別途必要 |
| 詰将棋 | 将棋駒と盤面の構造 | 駒を大きな色面に還元すると、文字・向き・駒同士の意味が薄れる |

これらは**実物を比較して得たデザイン上の所見**であり、利用者実験で測定した識別率や記憶率ではない。元の図案の完成度を保証するものでもなく、より優れた案が存在しないという意味でもない。

## 品質基準の校正：今回の不採用から得たもの

今後は以下を**独立した前提条件**として扱い、いずれかが不足する案を「現行より優れた新体系」とは認めない。

1. **アイコニックさ**：装飾や色を外しても、ゲーム固有の外形と関係が記号として成立する。名前を知った後に素早く区別できる。
2. **造形体系の統一**：色や角丸の共通化ではなく、どこを省略するか、形をどう作るか、主従をどう置くかという設計判断がセット全体で整合する。
3. **アプリ内での成立**：現行のゲーム選択画面に置いたとき、静かな共通UIを壊さず、選択中のゲームが適切に主役となる。
4. **造形の完成度**：輪郭、プロポーション、接続、光学バランス、負の空間が単体でも完成している。
5. **発見の価値**：単に現行を改変しただけではなく、新案を採用する明確な理由がある。現行に劣る場合は不採用とする。

「目立つ」「色が多い」「立体的」「要素数が少ない」「既存のSVG静的検査に合格」は、いずれも単独で品質の根拠にならない。

### 探索・比較・完成判定を分ける

- **探索**：現行を含め、着眼点と造形体系が根本的に異なる仮説を残す。初期段階では実装制約で可能性を狭めない。
- **比較**：造形完成度を揃えた後、まず無彩色のシルエット／小サイズの記号性、次にシリーズ全体、最後に本来のアプリ画面に置いた状態を確認する。単体の華やかさのみで選ばない。
- **完成判断**：現行が基準点であり、新案は上記の複数条件で現行と同等以上、かつ採用する実質的な利点が必要。未達なら現行維持。現行の欠点は別途評価し、無理に新案へ置換しない。

この手順は**今回の失敗から導いた検証仮説**であり、ユーザー実験等による有効性の証明はまだない。これを新しい正式規約として確定したものではない。
