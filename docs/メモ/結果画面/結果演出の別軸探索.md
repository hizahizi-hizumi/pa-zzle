# Issue #690 ピクトグラムを前提にしない演出の発散

この資料は9案を同じ方向へ絞るためではなく、何を主役にするかを変えて実際に見える形で探索したもの。前回の12案は全案でピクトグラムを共通の主表現に置き、画面の構図を変えなかったことが問題だった。今回の9案では**ピクトグラムは一度も使わない**。ただしピクトグラムを禁止する意図ではなく、前回の12案に不足していた別軸を加えるために意図的に外す。

[動く比較HTML](./結果演出の別軸探索.html)（JavaScriptなし。9方向×ウォーターソート/ナンプレ）

| ID | 主役 | 動きによって起こすこと |
|---|---|---|
| 01 | 盤面 | 盤面全体を主役にする：盤面から波及する完成の連鎖。小さなアイコンではなく、解答対象を大きく残す。 |
| 02 | 文字 | 評価を一瞬の舞台にする：図形や盤面を使わず、文字・数字の勢い、余白、静止の対比だけで成立させる。 |
| 03 | 画面遷移 | 画面そのものが入れ替わる：遊んでいた画面の一部がそのまま次の情報面を開き、切り替えが達成になる。 |
| 04 | 物理感 | 手で確定させた手触り：評価が紙・プレート・印章のように一度だけ着地する。盤面やアイコンは描かない。 |
| 05 | 記録比較 | 過去の自分を追い越す：記録の二本のラインが競り合い、今回は過去より前へ到達する。 |
| 06 | 環境 | 空間全体に色を返す：面の色、光、陰影だけが完成のあと一度変わる。記号は一切増やさない。 |
| 07 | 祝祭 | 解放の祝祭：得点のそばから数種類の光片が広がり、評価が残る。強い対比を試す。 |
| 08 | 余韻 | 何も足さず、止める：動いていた盤面・数字がぴたりと止まり、静止した結果だけが残る。 |
| 09 | 導線 | 次の一問へ橋を架ける：達成のエネルギーを次の問題ボタンへ渡す。称賛より継続の勢いを重視する。 |


- 盤面を使う場合は、ゲーム側の実盤面や終了直前の操作を使う想定であり、別のピクトグラムを新造するという意味ではない。
- 文字・記録・色・光・画面遷移・静けさだけでも成立する演出があり、必ずしも盤面も必要ではない。
- 演出の設計は、現状の実装制約・ブランドとの適合・費用をいったん外して発散する。後で検証して判断する。
- 試作に載せるスコア94点や記録の数値は固定の比較値。盤面は概念を示す図であり、実問題の正しい解答を示すものではない。
- CSS-onlyの動きのため実音は鳴らない。音を主役にする設計は今回の映像案とは別軸で追加探索できる。

**現状に対する改善は未評価。** トンマナ統一の成果を残しながら、結果画面の体験強化の可能性を広く具体化する段階。
