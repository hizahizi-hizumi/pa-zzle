# ゲーム難易度調査

## 文書の位置付け

この文書は、ゲームにおける難易度・挑戦・面白さ・難易度調整について、学術研究、研究レビュー、家庭用ゲーム・アプリの公式資料、アクセシビリティ指針から確認できた事実を整理する調査資料である。

pa-zzle の現在仕様や設計判断を定める正本ではない。調査結果から何を採用するか、難易度をどのように定義・実装・運用するかは別途正本で判断する。

調査日は 2026-09-20。主な資料を次の4種類に分けて扱う。

- 査読付き実証研究: 被験者実験、尺度開発、商用ゲームのプレイデータ分析など。
- 研究レビュー・理論研究: 既存研究の整理、概念定義、理論的説明。
- 製品・開発元の一次資料: ゲーム公式サイト、開発元FAQ、開発者発表。
- 業界・アクセシビリティ指針: 実務上の推奨。実験的に普遍性が証明された基準とは区別する。

## 1. 難易度と挑戦の概念

### 1.1 用語は研究分野でも完全には統一されていない

2024年の Oxford Research Encyclopedia のレビューは、ゲーム難易度を「ゲーム内の課題を完了する妨げに対するプレイヤーの知覚」として整理し、設計された特徴、意図しない障壁、プレイヤー技能の双方を反映する知覚変数として扱っている。一方、`challenge` や `task` はゲーム側の設計特徴を表す語として区別できるとしている。同レビューは、difficulty、challenge、demand、flow、competence が既存研究で必ずしも一貫して区別されてこなかったことも指摘している。[A1]

2025年の Subjective Game Difficulty Scale（SGDS）研究も、ゲーム難易度をプレイヤーとゲーム課題の相互作用として扱う。研究内では、客観的難易度を「ゲーム課題がプレイヤー技能へ課す客観的要求水準」、主観的難易度を「ゲーム課題、プレイ過程、自身の状態を評価して生じる主観的な難しさ」と定義している。[A2]

### 1.2 主観的な難しさは単一の量としてしか現れないわけではない

Denisova らの CORGIS 研究は、ゲーム中に知覚される挑戦を測る30項目の尺度を開発し、認知的、遂行的、感情的、意思決定的という4種類の挑戦を抽出した。尺度開発・検証は3研究、合計1,390人を対象に行われた。[A3]

2025年の SGDS 研究は、関連文献を整理したうえで主観的ゲーム難易度を6次元に分け、25項目の尺度を開発した。最終検証には米国、中国、日本の参加者326人が用いられた。6次元はゲームの複雑さ、ゲーム完了の難しさ、プレイ遂行の難しさ、プレイヤーの有能感、プレイヤーの圧力、プレイヤーの努力である。[A2]

### 1.3 パズルの挑戦はアクションゲームと同じ指標で扱えるとは限らない

Pusey、Wong、Rappa は2021年の Puzzle Challenge Analysis Tool 研究で、ビデオゲーム内パズルの挑戦度を測定・比較すること自体が難しいとし、パズルにおける認知的挑戦を分析するための道具を提案した。The Witness と Untitled Goose Game を基に開発し、Baba Is You でも一般化を検討している。[A4]

同研究は、単純なアクションゲーム等で用いられてきた成績・速度等の方法が、そのままパズルの認知的挑戦を説明するとは限らないという問題設定を置いている。[A4]

## 2. 難易度・挑戦と面白さに関する研究

### 2.1 挑戦は古くから内発的な面白さの構成要素として扱われている

Malone の1981年の研究は、動機づけの高いコンピューターゲームの分析を背景に、内発的動機づけを challenge、fantasy、curiosity の3カテゴリーで整理した。challenge については、結果が不確実な目標と関係するという仮説を提示し、結果を不確実にする方法として可変難易度、複数レベルの目標、隠された情報、ランダム性等を挙げた。[A5]

これは後年のゲーム難易度の因果効果を検証した実験ではなく、理論形成を目的とした古典的研究である。

### 2.2 有能感・自律性とゲームの楽しさには関連が報告されている

Ryan、Rigby、Przybylski の2006年の研究は Self-Determination Theory をゲームへ適用した4研究を報告している。研究1〜3では、ゲーム内で知覚された自律性と有能感が、楽しさ、選好、プレイ前後のwell-beingの変化と関連していた。オンラインマルチプレイヤーを扱う研究4では、自律性、有能感、関係性が楽しさや将来プレイする意向と独立に関連した。[A6]

この研究が直接検証しているのは心理的欲求の充足とプレイヤー体験の関係であり、「難しいほど楽しい」という単調な関係ではない。[A6]

### 2.3 挑戦と楽しさの関係は活動や条件によって異なる

Abuhamdeh と Csikszentmihalyi の2012年の研究は、Internet Chess を用いた研究で、知覚された挑戦が楽しさを強く予測し、自分より強い相手との対局は弱い相手との対局より楽しまれ、接戦は一方的な対局より楽しまれる傾向を報告した。一方、論文自体が、それ以前の幅広い活動を対象とする研究では「最適な高めの挑戦」が常に支持されていたわけではないことを前提としている。[A7]

Larche と Dixon の2020年の Candy Crush 研究では、60人の経験者が現在の進行度付近、簡単すぎる問題、難しすぎる問題をプレイした。現在の進行度付近で主観的な skill-challenge balance が最も高かった。簡単な問題では flow が最も低かったが、通常条件と難しい条件の flow は同程度で、難しい条件では挑戦と frustration が大きかった。[A8]

この結果は、「簡単すぎると flow が下がる」という結果を示す一方、「難しすぎれば必ず flow が下がる」という単純な逆U字型をこの実験では完全には再現していない。[A8]

### 2.4 flow と最適難易度を一つの普遍則として扱うには研究上の留保がある

2024年の Oxford のレビューは、difficulty と challenge が flow、competence、learning、enjoyment 等に関係する研究を整理しつつ、どの難易度が最適かについて証拠は混在しているとしている。[A1]

Candy Crush の研究でも、主観的な skill-challenge balance、flow、frustration は同じ方向へ単純には動かなかった。[A8]

## 3. 失敗と frustration

### 3.1 ゲーム内の挑戦による frustration と、ゲーム外要因による frustration は異なる反応を生み得る

Miller と Mandryk の2016年の実験は42人を対象に、難しい障害物による `in-game frustration` と、入力遅延等の不具合による `at-game frustration` を比較した。両者は主観的な frustration の大きさが近くても、in-game frustration の方が楽しいと評価され、原因を自分側へ帰属する傾向が強かった。at-game frustration はゲーム側へ原因を帰属する傾向が強かった。[A9]

この研究では、同じ「frustration」という自己報告でも、その原因がゲーム上の挑戦か、操作・システム上の障害かによって体験が異なることが観測されている。[A9]

### 3.2 失敗をゲームの意味の一部として扱うゲーム研究もある

Jesper Juul の *The Art of Failure* は、ゲームがプレイヤーへ失敗を経験させ、その失敗が再挑戦や学習、克服と結びつくというゲーム固有の構造を論じている。[T1]

これは被験者実験による効果量の検証ではなく、ゲーム研究上の理論的論考である。

## 4. 動的難易度調整とプレイヤーの自己決定

### 4.1 DDA はプレイヤー状態に応じてゲーム側を動的に変える研究領域として確立している

Zohaib の2018年レビューでは、Dynamic Difficulty Adjustment（DDA）を、プレイヤー技能に応じてゲームの特徴、振る舞い、シナリオ等をリアルタイムに自動変更する方法として整理している。レビュー内では、簡単すぎると退屈、難しすぎると frustration が生じるという問題設定のもと、プレイヤー能力を追跡し、変化へ追従し、調整が体験上不自然にならないこと等が既存研究の要件として紹介されている。[R1]

DDA は一つの標準アルゴリズムではなく、多様なプレイヤーモデル、ヒューリスティクス、適応対象を含む研究領域である。[R1]

### 4.2 自動調整と手動選択はプレイヤー体験上同じではない

Smeddinck らの CHI 2016 研究は、プレイヤー自身が選ぶ難易度変更と自動難易度変更の提示方法を2つの研究で比較した。第1研究は40人を対象とした。結果として調整方法は知覚された自律性に影響し、多くの参加者が手動での難易度選択を好んだ。一方、その他の総合的なプレイヤー体験指標は、自動調整によって期待されたほど大きくは変化しなかった。[A10]

Constant と Levieux の CHI 2019 研究は、論理・運動・感覚に関する3ゲームを用い、難易度をランダムに変える条件とDDAで適応する条件を比較した。ゲーム内の賭けによって自己効力感を測定したところ、DDA が成功確率を実際より高く見積もる overconfidence を生じさせ得ることを報告した。[A11]

### 4.3 プレイヤー状態へ反応する仕組みが必ずしも「難易度」を変更しているとは限らない

Valve の *The AI Systems of Left 4 Dead* では、AI Director の Adaptive Dramatic Pacing が Survivor チームの状態へ反応し、強度のピークと谷を生成すると説明されている。一方、開発者資料はこの処理について明確に「pacing を調整し、difficulty は調整しない」とし、難易度の振幅ではなく発生頻度を変えるものと説明している。[P1]

この事例では、プレイヤー状態への動的反応と難易度調整が別概念として実装・説明されている。[P1]

## 5. 商用パズルゲームにおける難易度の計測・運用

### 5.1 実プレイ統計による難易度の運用が行われている

Kristensen と Burelli の2024年研究は、商用モバイルパズル *Lily's Garden* をケーススタディとして難易度予測を検証している。同論文は、パズルゲームでは平均クリア試行回数や、その逆に相当する通過率を難易度の運用指標として用いることが一般的であると整理している。[A12]

研究で用いた *Lily's Garden* のデータでは、難易度を「クリア1回あたりの平均試行回数」として扱った。対象は最初の500レベルで、当時ゲーム全体には6,000以上のレベルが存在した。最初の約100レベルにはチュートリアルと易しい導入レベルが多く、その後は平均約3.2試行/クリア付近で推移した。易しいレベルは典型的に1試行、難しいレベルは平均7試行以上を必要としていた。[A12]

研究に用いたプレイヤーデータは2021-06-01から2021-12-01までの実プレイから取得された。[A12]

### 5.2 プレイヤー集団や個人差を考慮したモデルが研究されている

同研究は、難易度をコンテンツだけから固定的に決めるのではなく、プレイヤーまたはプレイヤー集団との関係を予測対象に含めている。既存レベルの履歴、プレイヤー情報、レベル特徴、プレイテストエージェントのデータを組み合わせて比較した結果、コホート統計とシミュレーションデータを組み合わせたモデルが、研究で設定した各予測条件で最も高い精度を示した。[A12]

この研究は「全ゲームで個人最適化が必要」と結論しているものではなく、商用パズルで個人別・コホート別・新規コンテンツの難易度予測を行う方法を比較したものである。[A12]

### 5.3 Chess.com はパズルとプレイヤーの双方をrating化し、相対的な難易度設定を提供している

Chess.com は2025年にパズルratingシステムを更新し、約170億回の過去のパズル試行を再処理して、プレイヤーとパズルを再ratingしたと公表している。新システムは通常対局と同様の Glicko 系の考え方を利用している。[P2]

現在の Chess.com の Puzzle Difficulty は `Standard`、`Hard`、`Extra Hard` の3設定で、各設定はプレイヤー自身の Puzzle rating に対して相対的な難しさとして問題を供給する。パズルrating自体も、そのパズルを誰が解けたかを基に初期決定され、一定期間後に固定される。[P2][P3]

## 6. 家庭用ゲーム・PCゲームで確認できる難易度設計の実例

### 6.1 固定的な一つの Easy / Normal / Hard 以外の仕組みも広く使われている

#### Hades

Supergiant Games は公式FAQで、挑戦はプレイヤーごとに相対的であると説明し、複数の難易度関連機構を提供している。[P4]

- `God Mode`: 被ダメージへの耐性を上げ、死亡するたびにさらに少し耐性が上がる。
- `Hell Mode`: より高い挑戦を望むプレイヤー向けのモード。
- `Pact of Punishment`: 後半でゲームへの制約・強化条件を加えて挑戦を増やす仕組み。
- 永続的な成長システムも通常進行の一部として存在する。

同一ゲーム内で、救済的な適応、高難易度モード、任意の高難度化が併存している。[P4]

#### Super Mario Odyssey

Nintendo の公式製品ページでは、通常モードと `Assist Mode` をいつでも切り替えられる。Assist Mode では被ダメージへの耐性、落下時の復帰、静止時の体力回復、次の目的地への誘導等が追加される。[P5]

同じ製品内には、通常進行とは別に、隠された Power Moon、各種ミニゲームの記録、クリア後の Balloon World 等、追加的な挑戦も存在する。[P5]

#### Mario Kart 8 Deluxe

Nintendo は `ハンドルアシスト` と `オートアクセル` を個別の補助機能として提供している。ハンドルアシストはコースアウトしそうな際に減速・操舵を補助する。一方、ハンドルアシスト使用中はウルトラミニターボを利用できない。オートアクセルは加速操作を自動化し、ドリフト等の別技能へ集中できるようにする。[P6]

また、グランプリには 50cc、100cc 等のクラスがあり、数字が大きいほど最高速度が上がる。[P6]

#### Celeste

Celeste の公式 changelog からは、`Assist Mode` をオン・オフでき、ゲーム速度を変えるオプションや Dash Assist が存在することが確認できる。後の更新では `Variant Mode` も追加されている。[P7]

この一次資料は機能の存在・変更履歴を示すもので、各機能がプレイヤー体験へ与えた因果効果を検証する研究ではない。[P7]

### 6.2 難易度の高さだけでなく、挑戦の構成要素を個別に変更する製品設計が存在する

Mario Kart 8 Deluxe の補助機能は操舵と加速を別々に切り替えられる。[P6]

Celeste の Assist Mode はゲーム速度等を個別に調整する。[P7]

Hades は耐久性を上げる God Mode と、逆に制約を加える Hell Mode / Pact of Punishment を別機構として持つ。[P4]

これらは製品で実際に採用された設計事例であり、どの方式が他ジャンルでも最適かを比較した実験結果ではない。

## 7. アクセシビリティと難易度

### 7.1 アクセシビリティ上の障壁から生じる難しさを扱う研究がある

Martinez、Froehlich、Fogarty の CHI 2024 研究は、障害のあるゲーマー13人へのインタビューを基に、ゲームが想定した能力とプレイヤー能力の不一致から生じる `access difficulty` を扱った。研究は、障害のあるプレイヤーがゲームを発見し、評価し、自分に合わせて適応する過程と、その中で生じる障壁を分析している。[A13]

この研究では、一部のアクセシビリティ上の困難を克服することに満足を感じる事例もあった一方、望んでいるゲーム上の挑戦へ到達する前に、アクセス上の障壁が退屈・frustration・不可能性を生む事例も報告されている。[A13]

### 7.2 業界ガイドラインは複数難易度と個別調整を推奨している

2026年時点の Microsoft Xbox Accessibility Guideline 108 は、難易度を主観的な構成概念とし、同じゲーム上の障壁でもプレイヤー能力によって体験される難しさが異なると説明している。[G1]

同ガイドラインは、幅広いプレイヤーが望む挑戦を選べるよう、難易度presetを「理想的には4段階以上」用意することを推奨している。また、Easy / Normal / Hard のような大分類だけでなく、戦闘、パズル、時間依存操作等の個々のゲーム要素を個別に調整できることも推奨している。[G1]

これは Microsoft のアクセシビリティ実装指針であり、「4段階以上がゲーム一般の楽しさを最大化する」という実証研究結果ではない。

Game Accessibility Guidelines も、単純な難易度選択を幅広い能力へ対応するための「粗いが有用な第一歩」とし、個々の難易度要素をさらに細かく調整する方法、プレイ中の難易度変更、assist mode、ゲーム速度変更等を推奨している。[G2][G3]

## 8. 資料横断で確認できた事実

今回確認した資料の範囲では、次の事実を確認できた。

- `difficulty` と `challenge` の定義・境界には研究上も複数の立場があり、完全に統一された語彙はない。[A1][A2][A4]
- プレイヤーが知覚する難しさは、ゲーム課題の特徴だけでなく、プレイヤー技能・状態・文脈との相互作用として扱う研究が複数存在する。[A1][A2][A12]
- 挑戦や主観的難易度を複数次元に分けて測定する実証研究が存在する。[A2][A3]
- 挑戦と楽しさには関連が報告されているが、「難しいほど楽しい」「技能と難易度が一致すれば常に最も楽しい」という単純な普遍則は、確認した実証研究全体からは支持できない。[A7][A8]
- 同程度の frustration でも、ゲーム上の挑戦に由来する場合と、遅延・操作不良等に由来する場合で、楽しさや原因帰属が異なる実験結果がある。[A9]
- 自動難易度調整は研究・実装されているが、手動選択との違いとして自律性感覚や自己評価への影響も報告されている。[A10][A11][R1]
- 商用パズルでは、平均試行回数、通過率、プレイヤー履歴、コホート統計、シミュレーション等を使って難易度を推定・校正する研究と実運用が存在する。[A12][P2][P3]
- 家庭用ゲームでは、固定難易度presetだけでなく、assist、ゲーム速度、個別操作補助、死亡に応じた救済、任意の高難度modifier、プレイヤーrating相対の問題供給等、異なる方式が実際に用いられている。[P2]〜[P7]
- アクセシビリティ指針では、単一presetより広い難易度範囲や要素別調整を推奨する資料がある。[G1]〜[G3]

## 9. 今回の調査だけでは確定できないこと

次の事項について、普遍的に確定できる根拠は今回確認した資料からは得られなかった。

- ゲーム一般に最適な難易度段階数。3段階、4段階、5段階等のうち一つが普遍的に最適であることを示す実証結果は確認していない。Microsoft の「理想的には4段階以上」はアクセシビリティガイドライン上の推奨である。[G1]
- ジャンルを越えて比較できる単一の絶対難易度尺度。[A1][A2][A3]
- すべてのゲームでプレイヤー個人ごとの難易度モデルを持つ必要性。個人化・コホート化・DDAの研究は存在するが、全ゲームへの必須性を示すものではない。[A12][R1]
- flow を最大化する一つの固定的な skill-challenge 比率。[A1][A8]
- 家庭用ゲームの特定の難易度機能が、他方式より因果的に優れていること。公式製品資料は採用された仕組みを確認する一次資料であり、比較実験ではない。[P4]〜[P7]
- アクセシビリティ上の難易度preset数が、一般的なゲームの面白さに対しても同じ最適値になること。[G1][G2]
