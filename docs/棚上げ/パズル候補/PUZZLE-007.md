# PUZZLE-007 バイナリパズル / タクズ

## 問題供給成立性

通過。一意解で、1本の行・列を読む推論だけで解ける 8×8 の問題を、各難易度 500問の問題集として事前生成し、全問を検証した。

- [タクズ導入前提調査](../../パズル/導入調査/タクズ/タクズ導入前提調査.md)
- [タクズ難易度](../../パズル/導入調査/タクズ/タクズ難易度.md)

## 難易度運用成立性

確認中。人間向け解法器による分析、5段階の分類、各難易度の問題集の供給は済んだ。代表・境界問題の試遊と人間の実プレイとの照合が人間レビュー待ちで残る。特に難易度3と4の差（重複の回避が、残り1個の置き場所を読むより深く感じられるか）を確かめる。

- [タクズ難易度](../../パズル/導入調査/タクズ/タクズ難易度.md)

## スマホプレイ成立性

通過。実ブラウザで、スマートフォン幅の盤面の大きさとタップ巡回の操作を確認した。タイル・違反の印の見やすさと誤タップの頻度は、人間の実プレイで確かめる。

- [タクズ導入前提調査](../../パズル/導入調査/タクズ/タクズ導入前提調査.md)

## 導入判断

条件付き保留。成立性調査は3段階の難易度を前提に「実装候補」としたが、現在の採用条件である5段階の難易度運用が人間レビュー待ちで残るため、実装候補にも正式採用にもしない。試遊に使える形まで実装して現在仕様へ反映しており、試遊と人間による通しレビューを経て正式採用を判断する。
