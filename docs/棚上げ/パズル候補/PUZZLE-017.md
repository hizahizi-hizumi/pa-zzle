# PUZZLE-017 ノノグラム / イラストロジック

## 問題供給成立性

通過。

本実装の着手時に、完成図を生成した図柄に、盤面を幅10列まで（ズームなし）に、問題を仮置きなしで解けるものに限る想定（人間未確認）へ変えた。その想定のもとで、5段階それぞれの問題を継続して作れることを確かめ直した。
