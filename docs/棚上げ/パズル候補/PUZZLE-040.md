# PUZZLE-040 箱入り娘

## 問題供給成立性

通過。

4×5 の盤で駒の組ごとに、出口に着いた状態から全状態を BFS でたどり、どの状態からも最短手数を求められる（空き2〜5の全組で、1組あたり最大83万状態）。手は全部1手で戻せるので、プレイの途中で解けなくならない。

## 難易度運用成立性

確認中。

4×5 の盤だけで5段階に分ける案と、各レベルの問題集を用意する。代表・境界問題をラベルを伏せて遊び、レベルの順と差が人の難しさと大きく矛盾しないことの確認が、人間レビューで残る。

## スマホプレイ成立性

確認中。

駒をなぞって空きへすべらせ、角も曲がれる操作を主にする。スマホ縦画面での盤面と操作の収まり、なぞる途中に画面が動かないこと（特に iPhone）を、実ブラウザと実機で確かめるまで確認中とする。
