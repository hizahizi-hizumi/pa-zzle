# PUZZLE-040 箱入り娘

## 問題供給成立性

通過。

4×5 の盤で駒の組ごとに、出口に着いた状態から全状態を BFS でたどり、どの状態からも最短手数を求められる。手は全部1手で戻せるので、プレイの途中で解けなくならない。

82 の駒の組の全局面（684万状態）から、似た問題を除いて問題集（L1〜L4 各500問、L5 300問、計2,300問）を作った。生成スクリプトの `--verify` で、全問のレベル・最短手数・準備の長さと、似た問題が無いことを確かめている。

## 難易度運用成立性

確認中。

4×5 の盤だけで、準備の長さ（娘を進められないあいだに読む手の数）・娘の遠回り・空きの数で5段階に分けた。
- 合意の易しい例はレベル1、横刀立馬はレベル5 に入る。
- 隣のレベルの分布は逆転しない。
- 素朴な解き方では、L5 を最短の3倍以内に解けない。

準備の長さは、独立の確かめで見つかった抜け道（少し長い解、娘の往復、一時的な前進、1手の滑りの途中）で下がらない数え方にした。

人の体感（レベルの差、L5 の最短手数が短めの問題が L5 に感じられるか）を人の試遊で確かめるまで、確認中とする。
