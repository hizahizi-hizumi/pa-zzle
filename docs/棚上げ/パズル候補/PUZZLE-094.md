# PUZZLE-094 氷の床迷路

## 問題供給成立性

通過。

氷と岩だけのランダム配置から、1盤面のBFSで全停止点への最短手数が求まり、最短3手以上を選べる盤面は8×8で94.2%。同型重複は0件。詰みは構成上避けられないため、待った・盤面を戻す・リセットを必須とする。初期実装は氷と岩だけにし、レベルごとの問題集を事前生成して同梱する。

確認中。

人間の先読みの深さ（計画深さ）で5段階へ分ける分析PoCと、8×8固定での5段階の供給見込みは確認済み。代表・境界問題をラベルを伏せて遊び、人間の挑戦と大きく矛盾しないことの確認が残る。
