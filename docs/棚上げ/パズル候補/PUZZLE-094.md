# PUZZLE-094 氷の床迷路

## 問題供給成立性

通過。

氷と岩だけのランダム配置から、1盤面のBFSで全停止点への最短手数が求まり、最短3手以上を選べる盤面は8×8で94.2%。同型重複は0件。詰みは構成上避けられないため、待った・盤面を戻す・リセットを必須とする。初期版は氷と岩だけの各レベル500問の問題集を製品コードで作って同梱した。

作り直しで、もろい岩・薄い氷を含む問題集（L1・L2 各500問、L3〜L5 各300問、計1,900問）に置き換えた。テストで全問のレベルの形・要素・最少手数、最短解の一意性、駒が通らないマスを盤面に描かないこと、同型が無いことを確かめ、全問の分析と分類を生成スクリプトで確かめた。生成は4並列で約52分。

## 難易度運用成立性

確認中。

初期版（氷と岩だけ、計画深さを主軸にした5段階）は、試遊でレベル5でも簡単だった。駒1つ・静的な盤面は慣れた人には「見れば分かる」ので、盤面の状態が変わる要素を試遊し、もろい岩と薄い氷で十分な難しさが出た。要素の種類と数・生成の条件で段を作る5段階（L1〜2 氷と岩だけ、L3 もろい岩か薄い氷、L4 薄い氷を多くか両方、L5 両方を多く）へ作り直し、現在仕様（SPEC-019）へ反映した。作り直した問題集を試遊して、レベルの順と差、各レベルの手数と要素の数の範囲を決める。

## スマホプレイ成立性

通過。

320〜390pxで実ブラウザ操作し、盤面スワイプを主操作にする方式が成立した。初期版は方向ボタンを代わりの操作にしたが、作り直しで外し、スワイプと矢印キーだけにした。盤面は 320×568 で1マス24px程度を下限に、縦長を含めて最大12×14 とする（仮決定）。作り直した問題集の盤面は最大 10×12 で、320×568 の 10×12（1マス約27.5px）でも氷・薄い氷・水面・岩・もろい岩を見分けられ、スワイプだけでクリアまで遊べることを実ブラウザで確かめた。実機での画面端の戻るジェスチャーとの競合などは未確認で残る。

## 導入判断

条件付き保留。

初期版を試遊に使える形まで実装した（ゲーム ID `ice-floor-maze`）が、難易度が易しすぎたため、もろい岩・薄い氷を足して作り直した。作り直しを実装し、現在仕様（SPEC-019）へ反映した。`実装候補` にはしない。作り直した問題集の試遊と人間による通しレビューを経て正式採用を判断する。ゲーム ID は変えない。

表示名 `氷の床迷路` は作業名として扱い、公開名の第一候補でもある。公開名は J-PlatPat での商標の確認後に決める。
