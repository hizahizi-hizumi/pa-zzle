# PUZZLE-094 氷の床迷路

## 問題供給成立性

通過。

氷と岩だけのランダム配置から、1盤面のBFSで全停止点への最短手数が求まり、最短3手以上を選べる盤面は8×8で94.2%。同型重複は0件。詰みは構成上避けられないため、待った・盤面を戻す・リセットを必須とする。本実装では 8×8〜12×14 の盤面から各レベル500問の問題集を製品コードで作って同梱し、全問を identity から復号して、分類・最少手数・盤面の形・無関係な岩が無いこと・同型が無いことを確かめた。

## 難易度運用成立性

確認中。

人間の先読みの深さ（計画深さ）を主軸に、盤面の形（8×8〜12×14 の正方形・縦長）を上のレベルほど広い盤面まで許す範囲として組み合わせる5段階分類と、各レベルの問題集は用意した。盤面の形の組み合わせは仮決定。代表・境界問題をラベルを伏せて遊び、人間の挑戦と大きく矛盾しないこと（特に 12×14 のレベル4と5を区別できること）の確認が人間レビュー待ちで残る。

## スマホプレイ成立性

通過。

320〜390pxで実ブラウザ操作し、盤面スワイプを主操作、方向ボタンを代わりの操作とする方式が成立した。盤面は 320×568 で1マス24px程度を下限に、縦長を含めて最大12×14とし、上のレベルほど広い盤面まで許す（仮決定）。本実装でも 320 / 360 / 390px で、スワイプ・方向ボタン・矢印キーでクリアまで遊べ、320×568 の 12×14（1マス23.7px）でも盤面を読めることを確かめた。実機での画面端の戻るジェスチャーとの競合などは未確認で残る。

## 導入判断

条件付き保留。

難易度運用の代表・境界問題の試遊が人間レビュー待ちで残るため、`実装候補` にはしない。試遊に使える形まで実装して現在仕様へ反映しており（ゲーム ID `ice-floor-maze`）、試遊と人間による通しレビューを経て正式採用を判断する。評価の配点と係数、盤面の形、閉じ込めの知らせの線引き、ピクトグラム、ゲーム ID は仮決定のまま、そのレビューで確かめる。

表示名 `氷の床迷路` は作業名として扱い、公開名の第一候補でもある。公開名は J-PlatPat での商標の確認後に決める。
