# PUZZLE-094 氷の床迷路

## 問題供給成立性

通過。

氷と岩だけのランダム配置から、1盤面のBFSで全停止点への最短手数が求まり、最短3手以上を選べる盤面は8×8で94.2%。同型重複は0件。詰みは構成上避けられないため、待った・盤面を戻す・リセットを必須とする。本実装では 8×8〜12×14 の盤面から各レベル500問の問題集を製品コードで作って同梱し、全問を identity から復号して、分類・最少手数・盤面の形・無関係な岩が無いこと・同型が無いことを確かめた。

作り直しでは、もろい岩・薄い氷を含む問題集を製品コードで作り直す。要素つきの問題が採用条件を満たせることは Python の生成で確かめた。

## 難易度運用成立性

確認中（作り直し中）。

初期版（氷と岩だけ、計画深さを主軸にした5段階）は、試遊でレベル5でも簡単だった。駒1つ・静的な盤面は慣れた人には「見れば分かる」ので、盤面の状態が変わる要素を試遊し、もろい岩と薄い氷で十分な難しさが出た。L1〜2 氷と岩だけ、L3 もろい岩か薄い氷、L4〜5 両方の構成で作り直し、作り直した問題集を試遊して各レベルの手数と要素の数の範囲を決める。

## スマホプレイ成立性

通過。

320〜390pxで実ブラウザ操作し、盤面スワイプを主操作、方向ボタンを代わりの操作とする方式が成立した。作り直しで方向ボタンを外し、スワイプと矢印キーだけにする。盤面は 320×568 で1マス24px程度を下限に、縦長を含めて最大12×14とし、上のレベルほど広い盤面まで許す（仮決定）。本実装でも 320 / 360 / 390px で、スワイプ・方向ボタン・矢印キーでクリアまで遊べ、320×568 の 12×14（1マス23.7px）でも盤面を読めることを確かめた。実機での画面端の戻るジェスチャーとの競合などは未確認で残る。

## 導入判断

条件付き保留。

初期版を試遊に使える形まで実装して現在仕様へ反映した（ゲーム ID `ice-floor-maze`）が、難易度が易しすぎたため、もろい岩・薄い氷を足して作り直している。`実装候補` にはしない。作り直しの後、作り直した問題集の試遊と人間による通しレビューを経て正式採用を判断する。ゲーム ID は変えない。

表示名 `氷の床迷路` は作業名として扱い、公開名の第一候補でもある。公開名は J-PlatPat での商標の確認後に決める。
