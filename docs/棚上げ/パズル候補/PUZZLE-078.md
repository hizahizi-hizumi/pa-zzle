# PUZZLE-078 詰将棋

## 問題供給成立性

確認中。

逆算法による1 / 3 / 5手の自前生成は成立し、5手詰だけでも難易度5帯へ各10問の小規模プールを作れた。各帯の10問は解答木fingerprintも10 / 10ユニークだった。

一方、製品用のstrict validatorと独立oracleの一致、大規模問題プールでの供給率・重複率・生成性能は未確認。玉方の駒打ちを作意に含む問題も現PoCのsupported subsetでは供給できていないため、問題供給はまだ `通過` としない。

## 難易度運用成立性

確認中。

手数を難易度にせず、初手王手候補、もっともらしい誤王手、反証の深さと本数、玉方分岐、手筋の組み合わせで5段階を作る見込みを確認した。同じ5手詰だけでL1〜L5各10問のミニプールを作れている。

導入調査で最終閾値を固定せず、製品実装時に代表・境界・異常問題を人間の実プレイと照合して分類を完成させる。

通過。

## 導入判断

条件付き保留。

技術的には有力な候補。問題供給・難易度とも導入成立の見込みは立ったが、製品用validator / oracle、大規模供給、人間の難易度照合が残るため `実装候補` にはしない。

初期実装は、説明可能かつ厳密に検証できる1 / 3 / 5手中心のsupported subsetを第一候補とし、玉方合駒を含む作品は後続拡張として扱う。
