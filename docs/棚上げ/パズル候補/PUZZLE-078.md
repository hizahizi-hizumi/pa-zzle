# PUZZLE-078 詰将棋

## 問題供給成立性

通過。

製品コードの逆算 generator と strict validator（品質の状態を項目ごとに判定）で 3手・5手詰を生成し、レベル1〜3 各300問・レベル4・5 各200問の計1,300問の問題集を同梱した。全問を identity から作り直し・分析し直して、成立性・分類・作業の量の一致と、局面・作意の重複と手筋の偏りの上限を守ることを確かめた。分類できた候補 3,810局面を独立oracle（shtsume）とローカルで照合し、説明できない不一致と解釈の割れる変化の局面（1.2%）は問題集に採らなかった。oracle は製品・CIに入れない。

玉方の合駒が作意に現れる問題と、無駄合・2手変長の解釈で答えが変わる問題は supported subset の外として提供しない。

## 難易度運用成立性

確認中。

手数ではなく、初手の王手の数・もっともらしい誤王手・深い紛れ（反証が数手先まで見えない誤王手）の本数・正しい手順の比べどころの組み合わせによる5段階分類と、各レベルの問題集は用意した。代表・境界・異常な問題を問題集の中から選んであり、ラベルを伏せて実プレイし、人間の挑戦と大きく矛盾しないことの確認が人間レビュー待ちで残る。

## スマホプレイ成立性

通過。

320〜390pxで9×9盤、持駒、成 / 不成を含む基本操作を確認した。本実装でも 320〜390px で、駒と持駒を押して行き先を押すだけで最後まで遊べ、横スクロールが無いことを実ブラウザで確かめた。1升は 320px で約34pxのため、誤タップの有無を人間の実機プレイで確かめ、必要な場合だけ盤面領域ズームを検討する。

## 導入判断

条件付き保留。

難易度運用の代表・境界問題の試遊が人間レビュー待ちで残るため、`実装候補` にはしない。試遊に使える形まで実装して現在仕様へ反映しており、試遊と人間による通しレビューを経て正式採用を判断する。

初期提供は、3手・5手詰で、攻方毎手王手・玉方最長抵抗・駒箱・早詰と余詰と駒余りなし・作意に合駒なしの supported subset に限る。玉方合駒を含む作品と7手以上は後続拡張として扱う。
