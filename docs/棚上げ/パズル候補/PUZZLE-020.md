# PUZZLE-020 橋をかけろ

## 問題供給成立性

通過。

島を木で育てて橋を架ける完成グラフ先行の生成で 6×6〜10×10 の問題を製品コードで作り、各レベル500問の問題集を同梱した。全2,500問を作り直して、一意解・推理だけで解けること・分類の一致・同型の重複が無いことを確かめた。

- [橋をかけろ供給実験](../../パズル/導入調査/橋をかけろ/橋をかけろ供給実験.md)
- [橋をかけろ難易度](../../パズル/導入調査/橋をかけろ/橋をかけろ難易度.md)

## 難易度運用成立性

確認中。

盤面の大きさ・島の数・入口の広さ・「少なくとも1本」の読みとつながりの読みの回数・数字だけでは決まらない範囲の組み合わせによる5段階分類と、各レベルの問題集は用意した。代表・境界問題をラベルを伏せて実プレイし、レベル3〜5 の手応えの差と、1手の先読みを推理と感じるかを判断することが人間レビュー待ちで残る。

通過。
