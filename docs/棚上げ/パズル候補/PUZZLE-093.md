# PUZZLE-093 リフレクション / Reflection

## 問題供給成立性

通過。

一意解・全ピース使用・全ピース有効を満たす 5×5〜10×10 の問題を製品コードで生成し、レベル1〜3 は各500問、レベル4・5 は各300問の問題集を同梱した。全問を identity から作り直して、一意解・分類の一致・同型の重複が無いことを確かめた。

## 難易度運用成立性

確認中。

人間向け解法器の推論レベル（L1〜L5）、盤面サイズ・ピース数の範囲、一致表示つきの試し置きで押し切れる度合いの組み合わせによる5段階分類と、各レベルの問題集は用意した。代表・境界問題をラベルを伏せて実プレイし、人間の挑戦と大きく矛盾しないことの確認が人間レビュー待ちで残る。

## スマホプレイ成立性

通過。

320〜390pxで7×7 / 8×8を実ブラウザ操作し、配置・外周ヒント・光路表示が成立した。提供する盤面は最大10×10とする（SPEC-013）。本実装でも 320〜390px で、ストック選択と盤面タップだけで最後まで遊べることを確かめた。7×7 のマスは 390px で約42pxと44pxに届かない点は、人間の実プレイで誤タップの有無を確かめる。
