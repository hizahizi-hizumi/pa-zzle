# PUZZLE-093 リフレクション / Reflection

## 問題供給成立性

通過。

一意解・全ピース使用・全ピース有効を満たす 5×5〜7×7 の問題を製品コードで生成し、各レベル 500問の問題集を同梱した。全問を identity から作り直して、一意解・分類の一致・同型の重複が無いことを確かめた。

## 難易度運用成立性

確認中。

人間向け解法器の推論レベル（L1〜L5）と盤面サイズ・ピース数の範囲の組み合わせによる5段階分類と、各レベルの問題集は用意した。代表・境界問題をラベルを伏せて実プレイし、人間の挑戦と大きく矛盾しないことの確認が人間レビュー待ちで残る。

## スマホプレイ成立性

通過。

320〜390pxで7×7 / 8×8を実ブラウザ操作し、配置・外周ヒント・光路表示が成立した。初期提供の通常上限は7×7とする。本実装でも 320〜390px で、ストック選択と盤面タップだけで最後まで遊べることを確かめた。7×7 のマスは 390px で約42pxと44pxに届かない点は、人間の実プレイで誤タップの有無を確かめる。

## 導入判断

条件付き保留。

難易度運用の代表・境界問題の試遊が人間レビュー待ちで残るため、`実装候補` にはしない。試遊に使える形まで実装して現在仕様へ反映しており、試遊と人間による通しレビューを経て正式採用を判断する。

表示名 `リフレクション` は作業名として扱い、公開用の正式名は商標の最終確認後に決める。
