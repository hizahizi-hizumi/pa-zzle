# PUZZLE-056 ハミルトン路問題

## 問題供給成立性

通過。

穴だけで一意にする 6×6〜8×8 の問題を製品コードで生成し、各レベル500問の問題集を同梱した。全2,500問を分析し直して、一意解・分類の一致・同型の重複が無いことを確かめた。

## 難易度運用成立性

確認中。

局所の推論・先読みの重さ・盤面サイズの範囲の組み合わせによる5段階分類と、各レベルの問題集は用意した。遊ぶ側レビューではレベル4 と 5 の体感がほぼ重なった。代表・境界問題をラベルを伏せて実プレイし、判断することが人間レビュー待ちで残る。
