# 棚上げ

新しいパズルを知り、比較するための資料を置く。資料であり、採用・開発状態の正本ではない（ADR-0003）。候補を載せることは着手を意味しない。

## 閲覧

- [パズル候補.csv](パズル候補.csv)：候補92件の一覧、概要、過去の調査範囲、一次評価。
- [候補カタログ](パズル候補/カタログ.md)：全候補の目標、操作、面白さの核、盤面模式図。模式図は解ける問題や完成した実装を示すものではない。
- `パズル候補/PUZZLE-xxx.md`：必要な候補に限り、導入調査・検証資料への索引を置く。既存の導入判断は調査当時の結論であって、現在の採用状態ではない。

## 記録と更新

- 台帳はその時点の候補の概要と評価を保存した資料である。新規発見、調査、比較評価の際に更新するが、常に最新に同期する仕組みにはしない。
- `問題供給`、`難易度運用`、`スマホプレイ` は過去の成立性調査で確認した範囲を示す。`未確認`、`確認中`、`通過` などの短い状態を使用し、今の実装品質を保証するものとはみなさない。
- **採用済み・実装済み・開発中などの現在状態は管理しない。** 現在の実装の有無はコード、進行中の作業はIssue・PRで確認する。実装・マージに合わせた台帳の同期を要求しない。
- 実装順や着手予定も管理しない。類似・派生候補を削除するかは、その関係を比較してから判断する。

## 一次比較評価（2026-11-08）

`比較優先度(仮)`、`比較順(仮)`、`面白さ(仮)`、`追加価値(仮)`、`評価理由(仮)` はパズルの構造と既存ゲームとの差分からの**仮説**。全候補を試遊して検証した点数ではない。採用や実装順を確定しない。

- `P`：優先して比較する5候補。5件の比較順は `比較順(仮)` に残す。
- `A`：有望な次点候補。
- `B`：後続の比較候補。
- `C`：現時点では低優先の候補。
- 優先度空欄：未採点、または候補間の関係を整理する段階。**不採用ではない。**
- `整理課題`：類似・派生、ルール未確定などの関係を優先度と分離して示す。
- `面白さ(仮)` は推理・発見・試行錯誤・繰り返す魅力、`追加価値(仮)` は既存ゲームと異なる体験を増やす価値を、それぞれ5点満点で見たもの。

評価点を付けたのは92件中80件。そのうち62件をP/A/B/Cに分類し、18件は整理課題の確認を先とした。ほか12件は今回未採点としている。評価日以降の再評価が必要なら、その時点で比較根拠を確認する。
