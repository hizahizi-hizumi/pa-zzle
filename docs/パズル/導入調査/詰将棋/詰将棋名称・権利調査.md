# 詰将棋 名称・権利調査

調査日: 2026-09-30〜2026-10-02

## 結論

公開名称としては、日本語の一般名称である **「詰将棋」** を第一候補とする。

問題データは第三者サイト・書籍・アプリから転載せず、**pa-zzleで独立生成した問題を使う**のが安全である。

## 名称

「詰将棋」は一般名称として広く用いられており、pa-zzle内の作業名・題材名として自然である。公開前の商標最終確認は別途行う。

一方、調査対象にした個別サービス名・アプリ名・OSS名は公開名称へ流用しない。

## 問題データ

個々の詰将棋作品の著作権について、すべての問題に一律で同じ結論を置かない。

第三者作成問題を大量収録する方式は、少なくとも次を個別確認する必要がある。

- 問題データ自体の利用条件
- 問題文・解説文・図面の著作物性と利用条件
- サイト / 書籍 / アプリの利用規約
- 再配布の可否

そのため、pa-zzleの本番供給では自前generatorで独立生成し、generator version / seed / fingerprint等のprovenanceを保持する方針を採る。

## OSS

調査では主に次を参照した。

- `tokuhirom/tanuki-tsume-shogi`: 自動生成・solver・Web UIの比較対象
- `hkijin/shtsume`: solver / 作意推定 / 余詰・駒余り・無駄合の研究用oracle候補
- `komori-n/KomoringHeights`: 高性能詰将棋solverの参考
- `yaneurao/YaneuraOu`: 将棋 / 詰将棋solver・大規模局面集合の参考

第三者OSSのコードを製品へ取り込む場合は、その時点でライセンスを改めて確認する。特にGPL系solverは、研究用外部oracleとして使う場合と製品へリンク / 配布する場合を分ける。

## 日本将棋連盟等の公開資料

日本将棋連盟のルール説明等はルール理解の一次資料として参照するが、文章・図・問題をpa-zzleへ転載しない。

## 実装時の方針

- generator、validator、詰み探索、難易度分析器は独立実装する
- ルールエンジンは自作せず、MITライセンスの `tsshogi`（sunfish-shogi/tsshogi）を製品依存として使う（[詰将棋実装前提調査](詰将棋実装前提調査.md) §10）
- GPL系を含む外部solver（`hkijin/shtsume` 等）は独立oracleとしてローカルの照合にだけ使い、製品・CIへリンク / 配布しない
- 第三者の問題データを本番問題プールへ流用しない
- 既存アプリの画像・駒素材・UI素材を流用しない
- OSSを製品依存へ追加する場合はライセンス確認を別途行う
