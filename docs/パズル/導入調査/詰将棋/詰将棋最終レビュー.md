# 詰将棋最終レビュー

本実装（[詰将棋実装前提調査](詰将棋実装前提調査.md) §11 の段01〜段14 と段15）を終えた詰将棋を、人間がレビューするための資料。人間に判断してほしいのは次の4つだけで、ほかの論点は規約（`AGENTS.md`・`APP.md`・`GAME.md`・`DESIGN.md`）と既存ゲームの前例に照らして AI が決めた（実装前提調査 §10.7。段15で変えたものは §10「成・不成の選択（段15で更新）」「誤王手の数え方（段15）」「レベル1 の起点（段15）」）。

1. ピクトグラム: P1〜P4 のどれにするか（玉の字を含む）
2. 難易度プレビュー: 伝わるか
3. ゲーム体験: 通しで1回遊んだ所感
4. 伏せ問題10問: 体感レベルとスコアの納得感

現在の契約は [SPEC-015 詰将棋](../../../プロダクト/仕様/パズル/SPEC-015.md) を正とする。レビューで変えると決めたものは、記入欄に書いてもらえれば AI が実装と SPEC-015・関連文書を直す。

この文書は導入調査の資料で、現在仕様の正本ではない。

---

## 0. 準備

```sh
bun run --cwd frontend dev
```

開発サーバーでは内部診断が有効になり、URL で問題を指定して開ける（本番ビルドでは使えない）。指定した問題は難易度を「問題指定」と伏せ、記録しない。問題集の問題ならスコアは出る。

| 画面 | URL |
| --- | --- |
| ゲーム選択 | `/` |
| 難易度選択 | `/puzzles/tsume-shogi` |
| プレイ（難易度を選んで1問） | `/puzzles/tsume-shogi/play/<1〜5>` |
| 記録 | `/records` |

見る順の目安:

1. 初めて遊ぶ状態（ブラウザのサイトデータを消すか、プライベートウィンドウ）で、ゲーム選択 → 難易度選択 → レベル1 を1問遊ぶ（§1・§2・§3）。
2. §4 の伏せ問題を、ラベルを伏せたまま順に遊ぶ。

できればスマートフォン（幅 320〜390px）で遊ぶ。

## 1. ピクトグラム

ゲーム選択（`/`）の一覧で、ほかのゲームと並べて見る（ライト / ダーク）。今は P1 が入っている。

| 案 | 形 | 長所 | 弱点 |
| --- | --- | --- | --- |
| **P1 盤の右上隅の詰め上がり**（今の案） | 盤の上辺と右辺の枠、2×2 の升、隅の玉と、その頭の攻め駒 | 詰め上がりと図面に見える。一覧の中で一段軽く、ほかと見分けやすい | 考える過程（候補の比較）は描かない |
| P2 閉じた枠の詰め上がり | P1 の枠を四方で閉じる | 一覧の重さがそろう | バイナリパズルに構成が近い。駒が小さい |
| P3 玉と攻め駒の対峙 | 盤なし。大きな玉に攻め駒の尖りが向かう | 駒が最も大きく読め、将棋の駒だとすぐ分かる | 盤が無く、詰将棋より将棋に見える |
| P4 王手の候補の比較 | 大きな玉の下に、選んだ王手と退けた候補2つ | 「候補を比べて1つ選ぶ」過程を示す | 46px で候補の輪郭が弱い |

玉の字は「王」（今の案。回しても崩れない）・「玉」（プレイ画面と同じ。プレイ画面の玉方の玉は 180° 回した「玉」で、小さい表示では「王」に見えるという指摘がある）・文字なし（玉だと分からない）から選ぶ。

代替案の SVG は [ピクトグラム検討/](ピクトグラム検討/)、見比べ方と選び替え方は [詰将棋ピクトグラム検討](詰将棋ピクトグラム検討.md) §6。部分採用（例: P1 の隅に P3 の大きな駒を置く）もできる。

## 2. 難易度プレビュー

難易度選択（`/puzzles/tsume-shogi`）の各選択肢の図を、320〜390px と PC で見る。

図は盤の右上隅を切り出し、どのレベルでも同じ玉方の駒に向けて、攻方の駒と持駒をレベルが上がるほど足したもの。初手の王手の候補は 3・5・7・10・13 で、レベル4 から成駒（馬）を置く。どの図も詰まない答えの無い模式図で、問題そのものではない。伝えたいのは「上のレベルほど読み比べる王手の候補が増える」こと。

| 伝わるか（伝わる / 伝わらない） | 所感（「駒が多い局面が出る」とだけ受け取らないか、図を解こうとして戸惑わないか、駒が読めるか など） |

## 3. ゲーム体験

レベル1 を初めて遊ぶ状態から通しで1回遊び、次の4点の所感を書く。遊び方は初回に自動で開き、以後はメニューと難易度選択画面から開ける。

意図的に試すとよい操作: 王手にならない手を押す / 成・不成を選ぶ / 誤王手を指して玉方の反証（ローズ色）を見て、「戻る」で判断地点へ戻る / 「待った」で1手戻す。

| 観点 | 所感 |
| --- | --- |
| 遊び方を読んで遊び始められるか | |
| 誤王手の反証（「で逃れる」「この筋では詰みません」）と「戻る」が分かるか | |
| テンポ（玉方の応手の間 0.6秒・駒の動き・詰んだ後の約1.5秒） | |
| スマホで駒が読めて押せるか（320px で1升 約34px） | |
