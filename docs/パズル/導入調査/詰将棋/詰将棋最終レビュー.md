# 詰将棋最終レビュー

本実装（[詰将棋実装前提調査](詰将棋実装前提調査.md) §11 の段01〜段13）を終えた詰将棋を、人間がレビューするための資料。人間に判断してほしいのは次の4つだけで、ほかの論点は規約（`AGENTS.md`・`APP.md`・`GAME.md`・`DESIGN.md`）と既存ゲームの前例に照らして AI が決めた（実装前提調査 §10.5）。

1. ピクトグラム: P1〜P4 のどれにするか（玉の字を含む）
2. 難易度プレビュー: 伝わるか
3. ゲーム体験: 通しで1回遊んだ所感
4. 伏せ問題10問: 体感レベルとスコアの納得感

現在の契約は [SPEC-015 詰将棋](../../../プロダクト/仕様/パズル/SPEC-015.md) を正とする。レビューで変えると決めたものは、記入欄に書いてもらえれば AI が実装と SPEC-015・関連文書を直す。

この文書は導入調査の資料で、現在仕様の正本ではない。

---

## 0. 準備

```sh
bun run --cwd frontend dev
```

プレイ画面の URL には遊んでいる問題の問題ID（`?problem=<問題ID>`）が付き、同じ URL で同じ問題を開ける（ほかのゲームと同じ）。問題IDは問題を作る情報から求めた短い文字列で、手数・生成条件・seed は読めない。問題IDで開いたプレイも通常のプレイとして記録する。

| 画面 | URL |
| --- | --- |
| ゲーム選択 | `/` |
| 難易度選択 | `/puzzles/tsume-shogi` |
| プレイ（難易度を選んで1問） | `/puzzles/tsume-shogi/play/<1〜5>` |
| プレイ（問題IDの問題） | `/puzzles/tsume-shogi/play/<その問題のレベル>?problem=<問題ID>` |
| 結果（クリアすると移る） | `/puzzles/tsume-shogi/result/<記録ID>` |
| 記録 | `/records` |

見る順の目安:

1. 初めて遊ぶ状態（ブラウザのサイトデータを消すか、プライベートウィンドウ）で、ゲーム選択 → 難易度選択 → レベル1 を1問遊ぶ（§1・§2・§3）。
2. §4 の伏せ問題を、レベルを見ないで順に遊ぶ。

できればスマートフォン（幅 320〜390px）で遊ぶ。

## 1. ピクトグラム

ゲーム選択（`/`）の一覧で、ほかのゲームと並べて見る（ライト / ダーク）。今は P1 が入っている。

| 案 | 形 | 長所 | 弱点 |
| --- | --- | --- | --- |
| **P1 盤の右上隅の詰め上がり**（今の案） | 盤の上辺と右辺の枠、2×2 の升、隅の玉と、その頭の攻め駒 | 詰め上がりと図面に見える。一覧の中で一段軽く、ほかと見分けやすい | 考える過程（候補の比較）は描かない |
| P2 閉じた枠の詰め上がり | P1 の枠を四方で閉じる | 一覧の重さがそろう | バイナリパズルに構成が近い。駒が小さい |
| P3 玉と攻め駒の対峙 | 盤なし。大きな玉に攻め駒の尖りが向かう | 駒が最も大きく読め、将棋の駒だとすぐ分かる | 盤が無く、詰将棋より将棋に見える |
| P4 王手の候補の比較 | 大きな玉の下に、選んだ王手と退けた候補2つ | 「候補を比べて1つ選ぶ」過程を示す | 46px で候補の輪郭が弱い |

玉の字は「王」（今の案。回しても崩れない）・「玉」（プレイ画面と同じ。プレイ画面の玉方の玉は 180° 回した「玉」で、小さい表示では「王」に見えることがある）・文字なし（玉だと分からない）から選ぶ。

代替案の SVG は [ピクトグラム検討/](ピクトグラム検討/)、見比べ方と選び替え方は [詰将棋ピクトグラム検討](詰将棋ピクトグラム検討.md) §6。部分採用（例: P1 の隅に P3 の大きな駒を置く）もできる。

## 2. 難易度プレビュー

難易度選択（`/puzzles/tsume-shogi`）の各選択肢の図を、320〜390px と PC で見る。

図は盤の右上隅を切り出し、隅の玉の守り駒をレベルが上がるほど足して穴熊の囲いに近づけたもの。攻方の駒（龍）と持駒（金・桂）はどのレベルでも同じ。どの図も詰まない答えの無い模式図で、問題そのものではない。伝えたいのは、将棋を知る人がひと目で「上のレベルほど難しそう」と感じること。難易度の特徴量との厳密な対応より見た目を優先した（[詰将棋難易度](詰将棋難易度.md) §15）。

| 伝わるか（伝わる / 伝わらない） | 所感（上のレベルほど難しそうに見えるか、遊んだ後に各レベルの難しさとして納得できるか、図を解こうとして戸惑わないか、駒が読めるか など） |

| | |

## 3. ゲーム体験

レベル1 を初めて遊ぶ状態から通しで1回遊び、次の4点の所感を書く。遊び方はほかのゲームと同じく自動では開かず、プレイ中のメニューと難易度選択画面の「遊び方」から開く。クリアすると記録の結果画面へ移り、「同じ問題」で同じ問題をもう一度遊べる。記録画面の各行の「同じ問題をプレイ」からも同じ問題を開ける。

意図的に試すとよい操作: 王手にならない手を押す / 成・不成を選ぶ / 誤王手を指して玉方の反証（ローズ色）を見て、「待った」で判断地点へ戻る / 作意の筋で「待った」を押して1手戻す。

| 観点 | 所感 |
| --- | --- |
| 遊び方に気づいて開き、読んで遊び始められるか | |
| 誤王手の反証（「で逃れる」「3手では詰みません」）と、「待った」で判断地点まで戻ることが分かるか | |
| テンポ（玉方の応手の間 0.6秒・駒の動き・詰んだ後の約1.5秒） | |
| スマホで駒が読めて押せるか（320px で1升 約34px） | |

## 4. 伏せ問題10問

レベルを伏せた10問を A から順に遊び、遊び終えるたびに記入する。各問は下の表の「開く」のリンク（問題IDの URL）で、通常のプレイ画面として開く。

- 問題IDからは手数・王手の候補の数・生成条件は読めない。ただし URL のパスにはその問題のレベルの数字が入り（問題IDは開いた難易度の問題集から引くため）、結果画面にもレベルが出る。アドレスバーのパスと結果画面のレベルの表示を見ないで遊び、詰ませたら結果画面のレベルを読む前に体感レベルを決めてから、スコアを見て記入する。
- 遊び終えるまでメニューの「検証情報」は開かない（レベルが出る）。
- 問題IDで開いたプレイも記録に残る。記録画面の自己ベストに伏せ問題のプレイが入るのを避けたいときは、プライベートウィンドウで遊ぶ。
