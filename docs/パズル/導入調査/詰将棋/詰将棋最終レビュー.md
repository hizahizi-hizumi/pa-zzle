# 詰将棋最終レビュー

本実装（[詰将棋実装前提調査](詰将棋実装前提調査.md) §11 の段01〜段14）を終えた詰将棋を、人間が通しでレビューするための資料。観点（ピクトグラム / 難易度プレビュー / ゲーム体験 / 難易度 / スコア）ごとに、見る場所、判断してほしい論点、記入欄をまとめる。

各論点は、本実装で人間の判断を待たずに AI が仮決定したもの。仮決定の理由と比べた案は、各行の「詳細」の節にある。現在の契約は [SPEC-014 詰将棋](../../../プロダクト/仕様/パズル/SPEC-014.md) を正とする。レビューで変えると決めたものは、記入欄に書いたうえで、詳細の節と SPEC-014 を直す。

この文書は導入調査の資料で、現在仕様の正本ではない。

---

## 0. 準備

### 0.1 開き方

```sh
bun run --cwd frontend dev
```

開発サーバーでは内部診断が有効になり、次が使える。本番ビルドでは使えない。

- プレイ中のメニューと結果画面の「検証情報」: identity・問題集の版と番号・局面（SFEN）と作意（USI）・分析し直した特徴（判断地点ごとの内訳を含む）・分類。5手詰では開くのに数秒かかることがある。
- URL での問題の指定（`/puzzles/tsume-shogi/play/<レベル>?…`）。指定した問題は難易度を「問題指定」と伏せ、記録しない。問題集の問題ならスコアは出る。
  - 問題集の番号で: `?pool=2&problem=<レベル>-<番号>`（問題集の版 2 の番号。番号の先頭がレベルなので、ラベルを伏せたいときは次の形を使う）
  - identity で: `?seed=<seed>&plies=<手数>&checks=<下限>-<上限>`（`checks` は seed の `c<下限>-<上限>`。問題集にある identity なら問題集の問題を開く）

| 画面 | URL |
| --- | --- |
| ゲーム選択 | `/` |
| 難易度選択 | `/puzzles/tsume-shogi` |
| プレイ（問題集から seed で1問） | `/puzzles/tsume-shogi/play/<1〜5>` |
| 記録 | `/records` |

### 0.2 見る順の目安

1. 初めて遊ぶ状態（ブラウザのサイトデータを消すか、プライベートウィンドウ）で、ゲーム選択 → 難易度選択 → レベル1 を遊ぶ。遊び方が最初に開く（§3）。
2. §4.1 の問題をラベルを伏せて遊ぶ（難易度）。
3. 同じプレイの結果画面と記録画面でスコアを見る（§5）。
4. ピクトグラムと難易度プレビューを見比べる（§1・§2）。

できればスマートフォン（幅 320〜390px）でも §3 の操作を一通り試す。

## 2. 難易度プレビュー

- 難易度選択（`/puzzles/tsume-shogi`）の各選択肢の図。320〜390px と PC、ライト / ダーク。
- 判断の詳細: [詰将棋難易度](詰将棋難易度.md) §15、実装前提調査 §10「難易度プレビュー（段10）」。

## 3. ゲーム体験

### 見る場所

- プレイ画面（`/puzzles/tsume-shogi/play/1` など）。遊び方（初回は自動、以後はメニューと難易度選択画面から）、駒の選択と着手、成・不成の選択、指せない手を押したときの表示、誤王手を指したときの反証と「戻る」「待った」、メニューの「盤面を戻す」「リセット」「別の問題」、詰んだときの演出。
- 意図的に試すとよい操作: 王手にならない手・二歩・行き所のない駒を押す / 成・不成の両方が王手になる手 / 誤王手を指して、その筋で王手を続け「この筋では詰みません」まで進める / 「戻る」と「待った」の違い。
- 判断の詳細: SPEC-014「プレイ」、実装前提調査 §10 の段05・段06 の行と §10.4。

### 判断してほしい論点

| # | 論点 | 仮決定 | 代わりの案 / 詳細 |
| ---: | --- | --- | --- |
| 3-1 | 遊び方だけで、将棋を知らない利用者が遊び始められるか | 既存ゲームと同じ形の遊び方に、駒の動き（10種）・成り・持駒・二歩 / 打歩詰・毎手王手・最長抵抗・駒箱・誤王手と「戻る」を載せる。1手詰のチュートリアルは持たない | 1手詰のチュートリアルを別に持つ（§10「遊び方」） |
| 3-2 | 選んだ駒の行き先を示さないことで、駒の動きに迷わないか | 行き先・王手になる手を示さない（どの手が王手かを読むことが考えどころ）。指せない手を押すと理由を示す | 行き先を点で示す、補助として切り替えられるようにする（§10「選択と移動先の表示」） |

| 3-5 | 「戻る」（判断地点へ）と「待った」（1手戻す）を分けたことが分かりにくくないか | 誤王手の筋にいる間だけ「戻る」を待ったの隣に出す | 待ったで兼ねる（§10「戻る操作」） |

| 3-7 | 320px（1升 約34px）で誤タップしないか | ズームを入れない | 盤面領域のズーム（§10「盤の大きさ」） |
| 3-8 | 駒の文字が小さい画面で読めるか。玉方の玉が「玉」と読めるか（段06 のスクリーンショットでは玉方の玉が「王」のように見えた。今の盤は 180° 回した「玉」。段14 のレビューでも、小さい表示では回した「玉」が「王」に見えるという指摘があった。ピクトグラムの 1-3 と合わせて判断する） | 駒は自前の SVG の五角形と1文字、玉方は 180° 回す、成駒の文字は赤 | 玉方の駒を色で見分ける（§10「盤と駒の見せ方」） |

## 4. 難易度

### 見る場所

- 下の §4.1 の問題を、ラベルを伏せて遊ぶ。遊び終えるまで検証情報は開かない（分類が出る）。
- 判断の詳細: [詰将棋難易度](詰将棋難易度.md) §3（挑戦）、§8（5段階の分類）、§10（代表・境界・異常）、§11（確かめること）、SPEC-014「難易度」。

5段階は手数ではなく、初手の王手の数・もっともらしい誤王手（利用者向けには「効いていそうな誤王手」）・深い紛れ（「数手先まで続く紛れ」）の本数と、レベル4・5 の正しい手順の比べどころ（手筋2種以上か変化2以上）で分ける。深い紛れはレベル1・2 で0、レベル3〜5 で 1〜2 / 3〜5 / 6以上。

## 5. スコア

### 見る場所

- §4.1 で遊んだ問題の結果画面（問題指定でもスコアは出る）。スコアの内訳（読みの確かさ・速さ・反証を見た・待った・盤面戻し・基準時間・手数・初手の王手・効いていそうな誤王手・数手先まで続く紛れ）と採点基準。
- 難易度を選んで遊んだプレイの結果画面の自己ベスト更新と、記録画面（`/records`）の自己ベストと履歴（スコア・時間差・誤王手）。記録からの再プレイ。
- 判断の詳細: [詰将棋成績評価](詰将棋成績評価.md) §4（評価式）・§5（基準時間）・§6（案の比較と総当たり）・§8（記録と自己ベスト）・§9（確認点）、SPEC-014「成績評価」。

評価: 読みの確かさ20点（誤王手1回 −5点、0点まで）+ 速さ80点（基準時間以内で満点、基準時間の3倍で0点）。基準時間 = 8秒 + 4秒 × 攻方の手の数 + 2秒 × 初手の王手 + 4秒 × min(もっともらしい誤王手, 20) + 6秒 × min(深い紛れ, 10)。係数はすべて実プレイ前の仮置き。

### 判断してほしい論点

| # | 論点 | 仮決定 | 代わりの案 |
| ---: | --- | --- | --- |
| 5-1 | 基準時間の水準。迷わず読み切れたプレイが `perfect`・`great` に届き、手間取ったプレイが `perfect` にならないか | 上の式（中央値: レベル1〜5 で 0:24 / 0:36 / 1:00 / 1:28 / 2:32） | 係数を直す（全体に遅いなら盤面を見る・攻方の1手、上のレベルだけずれるなら誤王手・深い紛れ） |
| 5-2 | 同じ腕前で、レベルによって速さの点が偏らないか | 作業の量だけで基準時間を決め、レベルそのものは使わない | 係数と上限を直す。変化の幅を足す |
| 5-3 | 誤王手1回 −5点（4回まで）の重さ。反証を見て考え直したことが罰に感じないか | 確かさ20点・1回 −5点 | 速さだけ100点、確かさ40点（1回 −10点）、誤王手があれば95点まで |
| 5-4 | 総当たり（読まずに王手を順に試す）が `good`（80点）に残り、ゆっくり読み切ったプレイ（基準時間の1.5倍）と同じ段階になることが気にならないか | 総当たりは `good` の下端で止まる | 確かさの満点・減点の上限を直す |
| 5-5 | 0点になる倍率（3倍）の傾き。基準の2割増しで92点、4割増しで84点が厳しすぎ・甘すぎないか | 3倍 | 倍率を直す |
| 5-6 | レベル1 の短い基準時間（18〜28秒）で、数秒の迷いで段階が動くことが気にならないか | そのまま | 盤面を見る時間・攻方の1手の係数を上げる |
| 5-7 | 結果の主要成績（時間と基準時間との差、誤王手）と内訳・採点基準が、自分のプレイの説明として納得できるか。「効いていそうな誤王手」「数手先まで続く紛れ」の言い換えが伝わるか | 誤王手は主要成績、反証を見た回数などは内訳。プレイ中は誤王手の回数を見せない | 誤王手を内訳へ、反証を見た回数を主要成績へ |
| 5-8 | 自己ベストの指標（評価点・基準時間との差・誤王手）と、記録に問題集の版と番号を残すこと | 難易度ごとに3指標。問題集の番号は再プレイには使わず記録に残す | 誤王手を自己ベストから外す、問題集の番号を残さない |
| 5-9 | 誤王手を指してから「待った」で戻し、同じ誤王手を指し直すと、誤王手をもう1回数える。反証を確かめ直すための指し直しも減点されることが気になるか | 判断地点から誤王手を指すたびに数える（「待った」「戻る」で戻した手を覚えない） | 同じ判断地点で同じ誤王手は1回だけ数える |
