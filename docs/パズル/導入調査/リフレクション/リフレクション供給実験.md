# リフレクション供給実験

調査日: 2026-09-28

## 目的

リフレクションについて、次の品質条件を要求しても継続的に問題を供給できるか確認する。

- 与えられたピースをすべて使う
- 完成配置の各ピースが少なくとも1つの外周ヒントへ影響する
- 外周ヒントを満たす解が一意である
- 回転・反転で同型の問題を問題集内で重複させない

実験コードは [`scripts/research/reflection_supply_experiment.py`](../../../../scripts/research/reflection_supply_experiment.py) に置く。BGA版コードは使用せず、公開ルールからレーザー遷移と一意解検証を独立実装している。

## 再現方法

Python標準ライブラリだけを使用する。

```sh
python3 scripts/research/reflection_supply_experiment.py supply --samples 20 --seed 20260928 --timeout 5
python3 scripts/research/reflection_supply_experiment.py variants --samples 30 --seed 20260928 --timeout 5
python3 scripts/research/reflection_supply_experiment.py diversity --samples 200 --seed 20260928 --timeout 5
```

実行時間は環境性能に依存する。問題の一意 / 複数解の判定、採用数、重複数を主要な結果として扱い、時間は実装方式を選ぶための目安とする。

## 解法器の検証

4×4の小盤面では全配置列挙による解集合と突き合わせ、実験用の制約解法器が同じ解集合を返すことを確認した。

一意性判定では2解目を見つけた時点で探索を打ち切る。したがって「複数解」の正確な総数は数えず、一意解ではないことだけを判定する。

## 供給・性能

`全ピースが外周ヒントへ影響する` 条件を満たす候補を各条件20問集め、一意性を確認した。

| 盤面 / ピース数 | 有効20問を得るまでの候補数 | 一意解 | 複数解 | 5秒上限 | 一意性判定中央値 | p90 | 最大 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 5×5 / 6 | 30 | 20 | 0 | 0 | 2.2 ms | 2.9 ms | 3.8 ms |
| 5×5 / 8 | 23 | 20 | 0 | 0 | 2.2 ms | 6.7 ms | 9.0 ms |
| 6×6 / 8 | 23 | 20 | 0 | 0 | 6.1 ms | 15.9 ms | 34.5 ms |
| 6×6 / 10 | 23 | 17 | 3 | 0 | 12.2 ms | 43.9 ms | 72.1 ms |
| 7×7 / 8 | 23 | 20 | 0 | 0 | 20.5 ms | 76.5 ms | 361.6 ms |
| 7×7 / 10 | 25 | 20 | 0 | 0 | 40.6 ms | 108.0 ms | 124.3 ms |
| 7×7 / 12 | 31 | 19 | 1 | 0 | 67.2 ms | 250.8 ms | 541.7 ms |
| 8×8 / 8 | 26 | 20 | 0 | 0 | 53.7 ms | 194.6 ms | 334.8 ms |
| 8×8 / 10 | 21 | 18 | 2 | 0 | 136.2 ms | 399.6 ms | 1.72 s |

追加の各10問では、8×8 / 12が一意9・複数解1、8×8 / 15が一意7・複数解3だった。9×9 / 12では一意8、5秒上限到達2となった。

### 判断

7×7 / 10程度では、一意解を品質条件にしても供給率と検証時間に問題は見られない。8×8以上・ピース数増加では探索時間の裾が伸びるため、利用者のブラウザで毎回生成・一意性検証する方式より、事前生成問題集が適する。

## ピース構成

7×7 / 10ピースで、各構成について有効問題を30問集めた。

| 構成 | 有効30問 / 生候補 | 一意 / 複数解 | 生候補に対する一意問題率 | 判定中央値 |
| --- | ---: | ---: | ---: | ---: |
| 斜め鏡 + 二重鏡 | 30 / 35 | 26 / 4 | 74.3% | 35.8 ms |
| + 全方向反射体 | 30 / 38 | 26 / 4 | 68.4% | 106.1 ms |
| + ブラックホール | 30 / 37 | 29 / 1 | 78.4% | 54.3 ms |
| + 全方向反射体 + ブラックホール | 30 / 46 | 30 / 0 | 65.2% | 67.0 ms |

全方向反射体とブラックホールを含めても供給が破綻する兆候はない。ブラックホールは吸収、全方向反射体は反射という異なる外周制約を増やすため、基本ピースとして残す候補とする。

## 多様性

7×7 / 10ピースで、一意解かつ全ピース有効な200問を生成した。

- 採用までの生候補: 261
- 外周ヒント完全一致の重複: 0
- 正解配置を回転・反転まで正規化した同型重複: 0
- 一意性判定中央値: 約27.9 ms
- p90: 約144.4 ms

この規模では問題空間の不足は見られない。本番問題集でも回転・反転を正規化したキーで重複を除外する。

## この実験で判断しないこと

- 人間の体感難易度
- 難易度1〜5の境界
- 最適な盤面サイズ
- スマートフォンでの操作成立性
- 完成UI

機械探索が速い / 遅いことを、そのまま人間の難易度とはみなさない。難易度は別途、人間の解法過程に対応する分析で検証する。
