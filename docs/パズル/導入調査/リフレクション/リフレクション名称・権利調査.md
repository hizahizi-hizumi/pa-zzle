# リフレクション名称・権利調査

調査日: 2026-09-28

## 結論

パズルのルール・仕組みそのものを、BGA版のコード・文章・画像・音・ロゴを流用せず独自実装することについて、現時点で導入を止める権利上の要因は確認できていない。

一方、**`Reflection` / `リフレクション` は公開時の表示名として確定しない。候補名としてのみ扱う。**

理由は次の通り。

- ゲームのルールや着想と、具体的な表現物・ソースコード・素材は分けて扱う必要がある。
- BGA版の公開コードはBGA Studio向けの利用条件であり、pa-zzleへ流用しない。
- `リフレクション` の完全一致文字商標には日本で第41類を含む過去の登録例がある。
- `リフレクション` という称呼はゲームに関係する第9類・第28類・第41類でも複数の複合商標に使われており、名称空間が混雑している。
- `BLUE REFLECTION` など現在もゲームIPとして使われている近接名称がある。
- 今回の調査ではJ-PlatPat上の各権利の最新の存続状態・指定商品役務・類似群まで公式画面で最終確認できていない。

したがって、実装研究中は `リフレクション` を作業名として使用してよいが、一般公開用の正式表示名を決める直前にJ-PlatPatで最終クリアランスを行う。商用展開や商標登録を行う段階では、必要に応じて弁理士等による確認を行う。

## 1. 調査対象

- Board Game Arena: `Reflection` / `リフレクション`
  - https://ja.boardgamearena.com/gamepanel?game=laserreflection
- 原型: Jean-François Mainguet, `Reflection's matter` / `Matière à réflexion`
  - https://games.mainguet.org/ppcjfm/reflexion.htm
- BGA版公開実装
  - https://github.com/cdelaforge/reflection

## 2. 著作権とゲームルール

今回採用したいのは、次のようなゲーム上の仕組みである。

- 外周からレーザーを入射する
- 盤面内の鏡・吸収体等で経路が変わる
- 外周に示された距離・退出・反射・吸収の観測結果から内部配置を推理する

これらはゲームのアイデア・ルール・機能として扱い、BGA版や原型の具体的な表現を複製しない。

pa-zzleでは次を独自に作成する。

- ルール説明文
- UI・盤面レイアウト
- ピースの視覚表現
- アイコン・アニメーション・効果音
- 問題生成器・解法器・難易度分析
- 実装コード

## 3. BGA公開コードの扱い

`cdelaforge/reflection` の `bga/LICENCE_BGA` は、BGA Studio上のゲーム実装としての利用・改変・再利用について定めている。また、ゲームのアイデアとグラフィックの権利はそれぞれの権利者に残る旨が書かれている。

このため、公開実装は次の用途だけに使う。

- 現在BGAで提供されているルール・設定・解答判定の挙動確認
- 生成方式等の比較対象

コード、CSS、画像、音、文章をpa-zzleへコピーしない。

参考:

- https://github.com/cdelaforge/reflection/blob/master/bga/LICENCE_BGA

## 4. 原型との関係

原作者Jean-François Mainguetの公開ページでは、基本アイデアは雑誌 `La Recherche` で見たものを基にし、本人が全反射・吸収・ライトワープ等を追加したと説明されている。

したがって、BGA版だけを唯一のルール出典とはみなさない。初期実装では、推理の核に必要な一般化可能な光学ルールだけを独立実装し、BGA固有の素材や表現を持ち込まない。

参考:

- https://games.mainguet.org/ppcjfm/reflexion.htm

## 5. 特許の予備調査

次の観点で公開検索を行った。

- `Reflection's matter` / `Reflection` + puzzle / mirror / laser
- Jean-François Mainguet名義の特許
- ゲームの外周レーザー観測・鏡配置推理に直接対応する技術

今回の検索では、このパズルルールまたはpa-zzleで予定する一般的な独自実装を直接拘束する特許は確認できなかった。

ただし、これは正式なFTO（Freedom to Operate）調査ではない。将来、特殊な技術実装や商用展開で特許リスクを厳密に評価する必要が生じた場合は別途確認する。

## 6. 日本の完全一致文字商標

特許庁発行公報を集約するBrand Terraceで、完全一致の文字列を確認した。

### `リフレクション`

完全一致文字商標として5件の登録公報が確認できる。ゲームとの関連で注意が必要なのは次の登録である。

- 登録4844394
  - 出願: 2004-07-09
  - 登録: 2005-03-11
  - 権利者: 株式会社ラーニングデザインセンター
  - 区分: 第35類、第41類

他の完全一致例は第10類、第14類、第19類、第21類で、ゲームとは離れた商品分野である。

参考:

- https://patent-i.com/tm/mark/リフレクション/

### `REFLECTION`

完全一致英字については6件の公報が確認できる。2025年登録の完全一致例は第42類であり、今回確認できた完全一致一覧ではゲームソフト・玩具・オンラインゲームに直接対応する第9類・第28類・第41類の登録は見つからなかった。

参考:

- https://patent-i.com/tm/mark/0056096/

ただし、この一覧は「完全一致文字列」だけの確認である。商標の類否判断では称呼・外観・観念、指定商品役務、類似群等も見る必要があるため、これだけで安全とは判断しない。

## 7. 称呼・近接名称

`リフレクション` という称呼では、完全一致以外にも多数の登録・出願が存在し、第9類・第28類・第41類を含む。

ゲーム分野では特に次を確認した。

- コーエーテクモゲームスの `BLUE REFLECTION` IP
  - 2026年7月にも `BLUE REFLECTION Quartet` が発売され、現役IPとして利用されている。
  - https://www.koeitecmo.co.jp/business/entertainment/
- `Summer Pockets REFLECTION BLUE`
  - ゲームとして継続利用されている名称で、第9類・第28類・第41類を含む商標例も存在する。

これらは `Reflection` 単独の使用を直ちに妨げるという意味ではない。しかし、**ゲーム分野で「リフレクション」という語が空いている・識別力が高いとは言えない**根拠になる。

## 8. 米国の参考調査

米国ではThe Upper Deck Companyが `REFLECTION` をデジタルトレーディングカード・カードゲーム等について出願していたが、2026-01-26に `ABANDONED - NO STATEMENT OF USE FILED` となっていることを確認した。

- Serial 97917465
- https://furm.com/trademarks/reflection-97917465

米国でも `REFLECTION` は多分野で使われる一般的な語であり、完全一致だけでなく商品役務を含む個別確認が必要である。

## 9. 名称判断

### 現時点

| 項目 | 判定 |
| --- | --- |
| `Reflection` を調査用の呼称として使う | 可 |
| `リフレクション` を調査用の呼称として使う | 可 |
| 一般公開用の正式表示名として確定する | 未確定 |
| BGAのロゴ・画像・説明文を使う | 不採用 |
| BGAコードを流用する | 不採用 |
| パズルルールを独自実装する | 導入を止める権利要因は現時点で未確認 |

### 公開前の最終確認

正式名を決める直前に、少なくともJ-PlatPatで次を確認する。

1. `REFLECTION`
2. `リフレクション`
3. 称呼 `リフレクション`
4. 第9類: ダウンロード可能なゲームソフト等
5. 第28類: ゲーム・玩具等
6. 第41類: オンラインゲーム・娯楽サービス等
7. 類似群を含む近接商標の存続状態と指定商品役務

正式名称候補を別名へ変更する場合も、その候補について同じ検索を行う。

## 10. 実装への申し送り

- 当面の内部ID・ディレクトリ名に `reflection` を使うことと、利用者向け表示名を同一にすることは分離する。
- ピースの図形は機能を表す独自の単純図形として設計し、BGA素材をトレースしない。
- ルール文章は一次ルールを理解したうえでpa-zzle向けに書き直す。
- `Reflection` の名称を正式採用する判断は、パズル本体の実装判断と切り離す。
