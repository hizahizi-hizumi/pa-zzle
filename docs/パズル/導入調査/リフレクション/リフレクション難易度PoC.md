# リフレクション難易度PoC

調査日: 2026-09-28

## 目的

リフレクションで、盤面サイズやピース数をそのまま難易度にせず、人間が行う推理の深さを再現可能に分析できるかを確認する。

この文書は導入成立性のPoC記録であり、現在仕様の正本ではない。

## 前提

対象問題は次を満たすものに限る。

- 全ピース使用
- 全外周ヒント一致
- 一意解
- 全ピースが少なくとも1つの外周ヒントへ影響

問題成立性の完全解法器と難易度分析器は分離する。完全解法器の探索時間・探索量は人間難易度へ使わない。

## 人間向け推論モデル

PoCでは、プレイヤーの推論を次の5段階としてモデル化した。

| レベル | 推論 | 意味 |
| --- | --- | --- |
| L1 | 単一ヒントの直接確定 | 1本の外周ヒントだけで、必ず通るセルのピース種または配置を確定できる |
| L2 | 候補の直接整合性 | あるセル/ピース候補を全外周ヒントへ直接照合すると、その候補だけで矛盾するため除外できる |
| L3 | 制約伝播 | 1つの確定・除外によって別ヒントの候補が減り、その結果を再び伝播して確定する |
| L4 | ピース在庫 | 使用数・残数と候補セル数を使わないと確定できず、在庫制約と光路制約を行き来する |
| L5 | 仮定と矛盾 | 候補を仮置きし、その後の制約伝播・在庫制約の先で初めて矛盾が生じるため候補を除外できる |

L5は「候補を正解と仮定してみる」こと自体ではなく、直接整合性では除外できず、その仮定から別の推論を進めた先で矛盾を得る場合だけに限定する。

PoC途中では、この区別が弱く、単純な候補照合まで深い仮定として数える過大評価があった。現在の分析器では、直接照合をL2、反復伝播をL3、在庫をL4、仮定後の追加伝播を必要とするものだけをL5へ分離している。

## 分析方式

各外周レーザーを、`(位置, 方向, 経過距離, 結果種別)` の有限状態制約として扱う。

1. 各ヒント単独で成立し得る状態とピース候補を前向き・後ろ向きに絞る。
2. 必ず通るセルについて、単一ヒントで一意になる候補をL1として確定する。
3. セル/ピース候補を固定したとき、全ヒントが直接成立可能かを確認してL2の候補除外を行う。
4. L2の更新を反復し、更新によって別セルが決まるものをL3とする。
5. ピース在庫の上限・下限・残候補数を適用し、光路制約と反復して決まるものをL4とする。
6. なお未確定なら候補を1つ仮定し、1〜5相当の伝播後に矛盾する候補を除外する。これを必要とする問題をL5とする。

同じ問題から同じ分析結果を得る決定的な分析で、探索順によるランダムなtie-breakは使わない。

## 正しさの確認

問題生成時の完全解法器で一意解を確認したうえで、難易度分析の各候補削減後に既知の一意解が全セルの候補集合へ残っていることを検査する。

2026-09-28の再確認では、次の40問で全段階の検査を通過した。

- 5×5 / 2ピース: 20 / 20
- 5×5 / 10ピース: 20 / 20
- `unsupported`: 0
- 正解候補を誤って除外した問題: 0

これは完全性の証明ではないが、PoC分析器の候補削減が既知の正解と矛盾していないことを確認する回帰検査として使う。

## 固定5×5での分布

盤面サイズを5×5へ固定し、ピース数1〜8について各条件で一意問題を生成した200問を分析した。

| レベル | 問題数 |
| --- | ---: |
| L1 | 42 |
| L2 | 19 |
| L3 | 97 |
| L4 | 32 |
| L5 | 10 |

全200問を分析でき、`unsupported` は0だった。

ピース数と最高推論レベルのSpearman順位相関は約 `0.668` だった。ピース数が増えるほど深い推論は現れやすいが、同じピース数の中でも複数レベルが混在するため、ピース数をそのまま難易度へ割り当てるモデルではない。

例:

- 5×5 / 2ピース: L1・L2・L3が混在
- 5×5 / 4ピース: L1・L2・L3・L4が混在
- 5×5 / 7ピース: L1〜L5が混在したバッチあり
- 5×5 / 8ピース: L3〜L5が混在

## レベル別供給の見込み

目的レベルが出やすい生成条件へ候補生成を寄せても、最終レベルは生成条件ではなく分析結果で決める。

### 低〜中難度候補

5×5 / 2ピースの一意問題100問:

| レベル | 問題数 | 採用率 |
| --- | ---: | ---: |
| L1 | 43 | 43% |
| L2 | 18 | 18% |
| L3 | 38 | 38% |
| L4 | 1 | 1% |
| L5 | 0 | 0% |

難易度分析時間の中央値は約 `5.9 ms`。

### 高難度候補

5×5 / 10ピースの一意問題30問:

| レベル | 問題数 | 採用率 |
| --- | ---: | ---: |
| L1 | 0 | 0% |
| L2 | 0 | 0% |
| L3 | 4 | 13.3% |
| L4 | 20 | 66.7% |
| L5 | 6 | 20% |

難易度分析時間の中央値は約 `0.64 s`。

別seedの5×5 / 9〜10ピース50問でもL5は11問だった。

### 判定

各レベルを候補生成後の棄却選別で得られる見込みがある。

特に供給上のボトルネックになりやすいL2とL5でも、今回の候補領域ではそれぞれ18%、20%程度の採用率を観測している。プレイ開始時に生成する必要はなく、事前生成問題集を前提にすれば供給量の確保は現実的である。

一方、これらの数値はPython PoCとChatGPT実行環境での値であり、本番実装の性能目標にはしない。

## 代表問題

人間レビュー用に、同じ5×5で各レベルの代表seedを固定する。

| レベル | ピース数 | seed | 主な分析結果 |
| --- | ---: | ---: | --- |
| L1 | 2 | `631086562` | L1で2ピースとも直接確定 |
| L2 | 2 | `755896441` | L1で1個、直接整合性で残り1個を確定 |
| L3 | 2 | `783625993` | 1段目の確定後、再伝播して残りを確定 |
| L4 | 10 | `1712183813` | L1で3個、在庫制約を含む伝播で残り7個を確定 |
| L5 | 10 | `708978181` | L1/L3で4個、仮定と矛盾を2回使って残り6個を確定 |

これらは分類を確定するための正解例ではなく、ラベルを伏せた実プレイ比較へ渡す固定fixtureである。

## 難易度ゲートの判断

機械側では次を確認できた。

- 人間の推論過程として説明できる5段階の分析モデルを再現可能に実装できる。
- 盤面サイズを固定しても全5段階が現れる。
- ピース数と難易度は関係するが同値ではない。
- `unsupported` を難易度5へ押し込まず、今回の測定範囲では0件だった。
- 各レベルを事前生成で継続供給できる採用率を確認した。

残る必須確認は、人間のプレイ体験との対応である。

上記代表問題と境界問題をラベルを伏せて遊び、少なくとも次を確認する。

- L1→L5で推理の深さが概ね増えること。
- L4/L5が単にピース数の多さ・盤面の忙しさとして難しく感じるだけではないこと。
- L2/L3の差が人間にとって意味のある差として観測できること。
- 機械判定と体感が大きく逆転する問題に共通する未観測要因がないこと。

このため、候補台帳の `難易度運用` はまだ `確認中` とする。機械側の成立性PoCは完了し、人間レビューが残件である。

## 再現方法

分析コード:

```text
scripts/research/reflection_difficulty_experiment.py
```

例:

```sh
python3 scripts/research/reflection_difficulty_experiment.py \
  --condition 5x2 \
  --condition 5x10 \
  --samples 20 \
  --inventory-mode random \
  --timeout 2 \
  --seed 202609291 \
  --quiet
```

問題成立性・一意性検証には [リフレクション供給実験](リフレクション供給実験.md) の解法器を利用するが、難易度ラベルには完全解法器の探索時間・探索量を利用しない。
