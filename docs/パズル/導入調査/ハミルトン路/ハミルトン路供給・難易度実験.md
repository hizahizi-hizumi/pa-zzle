# ハミルトン路の問題供給・難易度実験

調査日: 2026-10-31

Issue #514 のうち、PUZZLE-056「ハミルトン路（全マス一筆書き）」のゲート1（問題供給成立性）とゲート2（難易度運用成立性）を実験で確かめた結果。総合判断は [ハミルトン路導入成立性調査](./ハミルトン路導入成立性調査.md) を参照。

実験コードは [`scripts/research/hamiltonian_path_experiment.py`](../../../../scripts/research/hamiltonian_path_experiment.py)（標準ライブラリのみ）。数値はすべてこのスクリプトを seed `20261031` で実行した実測値で、実行環境は4並列の Python 3.13 の研究用コード。製品コードの性能を表すものではない。

## 結論

- **ゲート1 問題供給成立性: 条件付き通過。** 完成解先行なら可解性は構成上保証でき、一意性確認（2解目で停止）も枝刈りで実用域に入る。ただし**マス壁だけで一意解を作る方式は 8×8 前後で破綻**する（10×10 の始点のみ指定では、山登りで 0/100 試行、無作為生成で 0/300 盤面）。隣接マス間の**仕切り（細い壁）**を許して別解を潰す方式なら 5×5〜10×10 で一意解を供給できた（10×10 は成功率 34〜78%、成功1問あたり 1.5〜12秒のため事前生成前提）。
- **ゲート2 難易度運用成立性: 条件付き通過。** 仕切りありの一意解問題では、人間向け解法器の「仮置き（この方向へ進むと破綻するかを数手先まで試す）」の回数と長さで帯1〜5を作り分けられ、8×8〜10×10 では5帯すべてが 6〜47% の出現率で継続供給できた。同じ盤面サイズでも帯が広く分布し、壁率で分布を動かせた。一方、**マス壁だけの一意解問題は 94%（512問中482問）が局所的な強制だけで解ける帯1に偏り**、**一意性を問わない問題は解き進める道筋によって帯が大きく変わる**（約半数で帯差2以上）ため、どちらも単独では5段階の根拠にならない。
- **推奨基礎仕様候補: 始点のみ指定・終点自由、一意解、マス壁と仕切りを使う。** クリア判定は保存解との一致ではなく「全有効マスをちょうど1回ずつ、4近傍・仕切りを越えずに通る」という規則で行う（一意解なので結果は同じ）。帯4〜5は 7×7 以上でしか実質的に出ないため、5段階は盤面サイズの混在（小盤面は低帯、8×8 以上で高帯）を前提にする。

主な条件・懸念:

1. 帯の中身は「仮置きの回数・長さ」に強く寄り、分断・パリティ推論が必要になる問題はほぼ生成されなかった（帯2〜4で 2〜5%）。高帯が人間にとって「面白い先読み」か「単調な試行錯誤」かは実プレイで確かめる必要がある。
2. 仕切りの数は 10×10 で中央値 12〜26 本に達する。視認性と、仕切りという要素をルールに足すことの是非はゲート3・4で判断する。
3. 一意解問題でも、始点から引き進める描画視点の分析では誤り手の多くが短い先読みで退けられ（描画分岐の段階は大半が段階2）、全体を論理で解く視点の帯とずれる。どちらの視点で帯を決めるかは未確定。

## ゲート1: 問題供給成立性

### 盤面とルール変種

盤面は長方形の正方形格子。各マスは有効マスか壁マスで、有効マス同士は上下左右で隣接する。プレイヤーは有効マスをすべてちょうど1回ずつ通る1本の道を引く。以下、有効マス数を `N` とする。

比較したルール変種:

| 記号 | 指定 | 判定 |
|---|---|---|
| a | 始点のみ指定、終点自由 | 「一意解を要求」または「正しい道ならどれでもクリア」 |
| b | 始点と終点を指定 | 同上 |
| c | 指定なし（どこから始めてもよい） | 同上 |
| a+仕切り | aに加え、隣接マス間に通れない仕切り（細い壁）を置く | 一意解を要求 |

#### パリティ（二部グラフ）による制約

4近傍格子はマスを市松模様に塗ると二部グラフになり、道は必ず色を交互にたどる。有効マス中の黒マス数を `B`、白マス数を `W` とすると、

- `|B - W| >= 2` なら解は存在しない。
- `B = W + 1` なら両端とも黒（多い色）。始点は多い色でなければならない。
- `B = W` なら両端は異なる色。

したがって変種aでは始点を決めた時点で終点の色が決まり、終点候補は約半分に絞られる。変種bでは始点・終点の色の組合せが上の条件を満たさなければ不可解。変種cでは `B ≠ W` のとき多い色のマスしか始点にできない。

この制約は生成器では完成解先行で自動的に満たされる。解法器では「全体の色数から終点の色を決める」「関節マスで切れた各領域の色数が交互塗りと整合する」という推論として使い、人間向け解法器では段階4（パリティ）として独立に計測した。

### 生成方式

すべて完成解先行で、生成した道が少なくとも1つの解であることは構成上保証される。

| 方式 | 内容 | 壁 | 用途 |
|---|---|---|---|
| 全面 backbite | 蛇行するハミルトン路から、端点を道の途中の隣マスへつなぎ替える backbite 変形を `30×盤面マス数` 回 | なし | 壁なし盤 |
| SAW（backbite + reptation） | 長さ `N` の自己回避路を蛇行路の一部から作り、backbite と reptation（片端を1マス伸ばし反対端を1マス縮める）を `30×盤面マス数` 回。通らないマスを壁にする | 壁率を固定して無作為 | 主方式 |
| walk | Warnsdorff 寄りの重み（先のマスの残り隣接数 `k` に `1/(1+k)^2`）でランダム歩行し、行き詰まったら終了。通らないマスを壁にする | 壁数は成り行き | 比較 |
| 始点選び直し | SAW の盤で、無作為な有効マスから解が存在するものを始点にする | SAW と同じ | 始点位置の操作 |
| climb（一意化） | SAW から出発し、backbite / reptation を1〜3回加えた候補の解数（上限6、探索2万ノード）が増えなければ採用する山登り。最大300回 | 壁配置も動く | 一意解・マス壁のみ |
| thin（一意化） | SAW の盤で、別解が使い元の道が使わない辺へ仕切りを1本ずつ足し、一意になったら不要な仕切りを無作為順に外す | SAW と同じ＋仕切り | 一意解・仕切りあり |

### 解法器

#### 全解探索（一意性確認）

始点から道を伸ばす深さ優先探索で、解を指定数（一意性確認では2）見つけたら停止する。各手で次を検査して枝刈りする。

- 孤立マス: 未訪問マスで、未訪問の隣接と先頭マスとの隣接を合わせて0になったもの
- 行き止まりマス: 同じく1になったマス。終点自由なら1つまで、終点指定なら終点以外は0
- パリティ: 残りマスの色数が先頭からの交互塗りと一致するか、終点指定なら終点の色が合うか
- 連結性: 未訪問マスと先頭が連結か（ビット演算の塗りつぶし）
- 関節点: 未訪問マス＋先頭のグラフで、先頭が関節点でないこと、先頭側以外へ切り離される成分が高々1つでそこに終点が入ること、その成分の色数が整合すること

関節点の枝刈りは1ノードあたりの時間を増やすが、開発中の一時計測（10×10・壁率0.2、始点指定・終点指定各30盤面、別seed）では平均ノード数が10,702から904へ、平均時間が72.2msから27.4msへ減り、20万ノード打ち切りが1件から0件になった。この比較はスクリプトのサブコマンドには含めていない。

全面 4×4・5×5・6×6 の角始点ハミルトン路数は 52・824・22,144 で、既知値と一致した（`selfcheck`）。

#### 人間向け解法器

「各隣接辺を使う／使わない」を確定していく辺ベースの解法器。推論を次の段階に分け、易しい段階が使える限り易しい段階を使う。

| 段階 | 名前 | 内容 |
|---|---|---|
| 1 | 局所次数 | 端点以外は使う辺がちょうど2本、端点は1本。残り候補がちょうど必要数なら全部使う、必要数に達したら残りは使わない。終点自由のとき、候補辺が1本しかないマスは終点になる |
| 2 | 閉路・端点連結禁止 | 同じ道片の両端を結ぶ辺は使わない。始点側の道片と終点側の道片を全マス被覆前に結ぶ辺は使わない |
| 3 | 分断・到達 | 使える辺のグラフが分断されたら矛盾。橋（そこを通らないと届かない辺）は使う。関節マスで3つ以上に割れる、端点が関節になる、端点を含まない領域が切り離されるのは矛盾。関節マスは終点になれない |
| 4 | パリティ | 全体の色数から終点の色を決め、色の合わない終点候補を外す。関節マスで2つに割れたとき、各領域の色数が交互塗りと整合しなければ矛盾 |
| 5 | 1段仮置き | 未確定の辺を1本「使う／使わない」と仮定して段階1〜4を進め、矛盾すれば逆を確定する。矛盾までの推論手数が少ない仮定を優先する |
| 6 | 2段仮置き | 仮定の中でさらに1段仮置きを行う。候補辺を24本に制限 |

段階6でも進まなければ「評価不能（未解決）」とする。この解法器は「人間がこの順で考える」ことを主張するものではなく、必要な推論の種類と量を比較可能にするための代理である。

健全性は次で確認した。

- `selfcheck --samples 150`: 5×5〜7×7 の150盤面で、全解探索で完成可能と分かっている手 5,788件を仮定しても、段階1〜5のどれも誤って矛盾を出さなかった。
- `unique` で生成した一意解 1,039問はすべて段階5までで解き切れた（評価不能0問、2段仮置きの使用0問）。各推論が健全で解が一意なので、解き切った結果は正解と一致する。

#### 描画視点の分岐分析

プレイヤーは始点から道を伸ばしていく前提で、解の道をたどりながら各地点を調べる。

- **分岐**: 盤面を見てすぐ分かる破綻（孤立マス、行き止まりマスの過多、目に見える分断）を起こさない手が2つ以上ある地点
- **致命手**: そのうち完成できない手（全解探索で確認）
- **分岐の推論段階**: 致命手を退けるのに必要な最小の推論段階。現在の道を確定させた状態から段階2まで、3まで、4まで、仮置き（段階5）で矛盾が出るかを順に調べ、出なければ6とする。その地点の致命手のうち最も見抜きにくいものの段階を、その分岐の段階とする
- **最大誤進入**: 致命手に入ったあと、すぐ分かる破綻だけを見ながら進める最大の深さ（3,000ノードで打ち切り、打ち切りは99と記録）

一意性を問わない問題では解の道が複数あるため、生成時の道と、乱択探索で拾った別の道（合計最大5本）でそれぞれ分析し、帯の中央値を採った。道ごとに帯が変わった割合も記録した。

### 結果1: ルール変種と一意解の出やすさ

SAW 盤（壁率固定）を各条件100盤面生成し、生成時の道の始点・終点を使って解の数を数えた（a・b は64解で打ち切り、c は2解で打ち切りかつ 6×6 以下のみ）。

| 盤面 | 壁率 | 一意率 a | 一意率 b | 一意率 c | 解数中央値 a | 解数中央値 b | 64解以上 a | 確認p95 ms a/b |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 5×5 | 0.00 | 0% | 0% | 0% | 64 | 58 | 100% | 11.8/25.5 |
| 5×5 | 0.15 | 2% | 17% | 0% | 22 | 4 | 8% | 9.2/4.5 |
| 5×5 | 0.30 | 6% | 52% | 1% | 6 | 1 | 0% | 5.5/1.1 |
| 6×6 | 0.15 | 1% | 4% | 0% | 64 | 10 | 61% | 25.3/20.5 |
| 6×6 | 0.30 | 8% | 37% | 3% | 9 | 2 | 2% | 9.2/5.1 |
| 7×7 | 0.30 | 7% | 18% | - | 17.5 | 3 | 12% | 21.7/9.2 |
| 8×8 | 0.30 | 2% | 11% | - | 36 | 7.5 | 39% | 50.6/46.3 |
| 9×9 | 0.30 | 0% | 0% | - | 64 | 16 | 59% | 107.2/78.8 |
| 10×10 | 0.15 | 0% | 0% | - | 64 | 64 | 97% | 4852.9/728.6 |
| 10×10 | 0.30 | 0% | 1% | - | 64 | 64 | 85% | 164.0/197.2 |

全面盤（壁率0）は全サイズで一意解が0%、6×6〜10×10 の壁率0.15も b の 6×6（4%）・7×7（1%）以外は0%だった（表から一部の行を省略。全行は `variants` の出力）。20万ノード打ち切りは 10×10・壁率0.15 で a 3件・b 1件のみ。

読み取り:

- 一意解の出やすさは常に b > a > c。終点指定は強い制約で、一意化しやすい代わりに終点という大きな手掛かりを与える。
- c（指定なし）は 6×6 以下でも最大3%で、始点探しという別の作業も加わるため、基礎仕様候補から外す。
- 一意性を問わない場合、生成は完成解先行の SAW だけで済み（10×10 でも生成 p50 約5ms）、判定は規則検査だけで済む。

### 結果2: 一意化方式の比較

`unique` を各条件50試行。climb は最大300回の山登り、thin は仕切り追加。数値は「成功率」「成功1問あたりの総生成秒（失敗試行の時間を含む）」「一意性の最終確認時間」。

| 盤面 | climb 壁0.25 a | climb 壁0.25 b | climb 壁0.15 b | thin 壁0 a | thin 壁0.15 a |
|---|---|---|---|---|---|
| 5×5 | 98% / 0.03s | 100% / 0.00s | 98% / 0.03s | 100% / 0.02s | 100% / 0.01s |
| 6×6 | 80% / 0.24s | 98% / 0.03s | 94% / 0.27s | 100% / 0.05s | 100% / 0.02s |
| 7×7 | 46% / 1.17s | 100% / 0.21s | 52% / 1.89s | 98% / 0.29s | 100% / 0.05s |
| 8×8 | 18% / 6.11s | 84% / 0.82s | 16% / 14.08s | 86% / 1.29s | 100% / 0.09s |
| 9×9 | 2% / 104.25s | 30% / 5.49s | 0% | 62% / 3.56s | 96% / 0.38s |
| 10×10 | 0% | 14% / 21.88s | 0% | 34% / 11.99s | 78% / 1.50s |

- climb の a・壁率0.15（表外）は 5×5 で80%、6×6 で14%、7×7 以上は 0/50。
- 一意性確認（2解探索）の p95 は climb で 23.6ms 以下、thin で 10×10・壁率0 の 1,463.9ms が最大。
- thin の仕切り数中央値は、壁率0で 5（5×5）→ 11（7×7）→ 26（10×10）、壁率0.15 で 2.5 → 5 → 12。
- 解数評価のノード打ち切り率は最大 5.6%（climb 10×10 壁率0.15 a）で、打ち切りは「一意でない」扱いで棄却した。

マス壁だけで一意解を得るには、壁で細い通路を作って局所的に道を固定する必要がある。盤面が大きくなるほど「どこか1か所でも付け替えの余地が残る」確率が上がるため、ランダム生成・山登りとも成功率が急落したと考える（原因は推測。より賢い壁配置探索で改善する余地はある）。仕切りは別解が使う辺だけを狙って切れるため、元の道を壊さずに一意化できる。

### 結果3: 一意性を問わない場合の供給

`anypath` を各条件120問、5条件で計600問/サイズ。生成は全サイズで p50 6ms 以下（始点選び直しの 10×10 のみ 28.9ms）。ボトルネックは難易度分析で、10×10 の全面盤では1問あたり p50 8.3秒・p95 19.2秒、壁率0.30 では p50 0.15秒・p95 1.29秒だった。

### 多様性

| 対象 | 問題数 | 完全一致重複 | 回転・反転込み重複 |
|---|---:|---:|---:|
| 一意性不問 6×6 全面盤 | 1000 | 964 | 994 |
| 一意性不問 6×6 壁率0.15 | 1000 | 4 | 20 |
| 一意性不問 8×8 / 10×10 壁率0.15・0.30 | 各1000 | 0 | 0 |
| 一意性不問 10×10 全面盤 | 1000 | 900 | 985 |
| 一意解 climb（全サイズ） | 512 | 1 | 2 |
| 一意解 thin（全サイズ） | 527 | 0 | 0 |

- 全面盤は問題が始点だけで決まるため、ほぼ全問が重複する。壁も仕切りもない全面盤は問題として供給しない。
- 全面盤の角始点は蛇行するだけで必ず解ける自明問題で、1,000問中 45〜107問あった。
- 蛇行・単調さの目安として、長さ4以上の直進区間に含まれるマスの割合（直進率）を記録した。0.6以上は一意性不問の壁率0.15以上で 3.6〜12.8%、一意解 thin で 80/527問（うち48問が帯1）。
- 抑制方法: 回転・反転を正規化した盤面（壁・仕切り・始点）のハッシュで重複を除く。全面盤を除外し、帯0（誤り手がない）を提供範囲外とする。直進率の高い帯1を一定割合以下に抑える。

### ゲート1の判定

| 項目 | 判定 | 条件 |
|---|---|---|
| 完成解生成 | 通過 | SAW（backbite + reptation）。10×10 でも数ms |
| 一意性確認 | 通過 | 2解目で停止＋孤立・行き止まり・パリティ・連結・関節点の枝刈り |
| 一意解（マス壁のみ） | 7×7 まで条件付き | a は 7×7 で成功率46%、8×8 で18%。b なら 8×8 まで84% |
| 一意解（仕切りあり） | 通過 | 5×5〜8×8 は成功1問あたり 1.3秒以下。9×9〜10×10 は事前生成 |
| 一意性不問 | 通過 | 生成・判定とも自明。分析時間だけが 10×10 で数秒〜数十秒 |
| 多様性 | 通過 | 全面盤を除けば重複はほぼない |

**ゲート1は条件付き通過。** どのルール変種でも問題は供給できる。ただし一意解を要求するなら、8×8 以上は仕切りを使う必要があり、9×9 以上は事前生成を前提にする。

## ゲート2: 難易度運用成立性

### パズル固有の挑戦

ルールは「全マスを1回ずつ通る」だけで、数字などのヒントはない。挑戦は**盤面の形（壁・仕切り・始点）から、取り残されるマスを出さない道筋を先に見通すこと**にある。具体的には次の判断から成る。

- 局所の強制: 角・通路・袋小路のように通り方が1通りに決まるマスを見つけ、連鎖的に道を確定する。袋小路は終点になる。
- 閉路・端点の制約: 道片の両端を結んで輪にしない。
- 分断と到達: この方向へ進むと、まだ通っていない領域が切り離されないか。
- パリティ: 市松模様の色数から終点の色や領域の通り抜け可否を判断する。
- 先読み: 上の推論だけで決まらないとき、「ここをこう通ると数手先で破綻する」を確かめて別の手を選ぶ。

基準とするプレイ条件は、ヒント・やり直し支援を使わず、始点から道を引き進めるプレイとする（入力方式はゲート3で決める）。

### 解法器から取った特徴量

一意解問題には全体解法（人間向け解法器）、一意性不問の問題には描画視点の分岐分析を使った。

| 特徴量 | 意味 |
|---|---|
| 停滞回数 | 段階1〜2だけでは進めなくなった回数 |
| 初停滞時の確定辺率 | 最初に段階1〜2で止まった時点で確定していた辺の割合（強制の連鎖でどこまで進むか） |
| 段階3〜4の発火 | 分断・パリティ推論が必要になったか |
| 仮置き回数 | 段階1〜4で止まり、1段仮置きで進めた回数 |
| 矛盾までの手数 | 仮置きから矛盾が出るまでの推論手数（先読みの長さ） |
| 2段仮置き・未解決 | 1段仮置きでも進めない局面の有無 |
| 分岐数・致命分岐数 | 描画視点で、すぐ見える破綻のない手が複数ある地点と、そのうち完成できない手を含む地点の数 |
| 分岐の推論段階 | 致命手を退けるのに必要な段階 |
| 最大誤進入 | 致命手に入ってから、すぐ見える破綻だけを見て進める最大の深さ |

探索ノード数や探索時間は特徴量に使っていない。

### 判定

| 確認事項 | 結果 |
|---|---|
| 挑戦を言語化できるか | 通過。局所強制・閉路禁止・分断・パリティ・先読みに分けて解法器で計測できた |
| 生成条件で分布を動かせるか | 通過（仕切りあり一意解）。壁率で帯4〜5の比率が 8×8 で 18/43 ↔ 0/50 と動いた |
| サイズだけで決まらないか | 通過。同一サイズで帯1〜5が出る。ただしサイズとの相関は強い |
| 5帯の継続供給 | 条件付き通過。8×8〜10×10 で5帯すべて6%以上。5×5〜6×6 は帯1に偏る |
| 判定の再現性 | 一意解なら道筋に依らず再現できる。一意性不問では約半数が道筋で帯差2以上 |
| マス壁だけの一意解 | 不通過。94%が帯1 |

**ゲート2は条件付き通過。** 条件は次の3点。

1. 一意解・仕切りありを基礎仕様にする（マス壁だけ、または一意性不問では5段階の根拠が得られなかった）。
2. 5段階は盤面サイズの混在を前提にする。帯4〜5は 7×7 以上、実質 8×8 以上からしか供給できない。
3. 難しさの中身は先読みの回数と長さに偏る。高帯が人間にとって意味のある挑戦かを、実プレイで確かめてから閾値を校正する。

## 未確定事項

- 帯の閾値。仮置き回数・矛盾までの手数を実プレイの所要時間・やり直し回数と照合して校正する。
- 全体解法の帯と描画視点の分析のどちらで判定するか。一意解の仕切りあり問題でも、描画視点の分岐段階は大半が段階2で、全体解法の帯と一致しない。始点から引き進めるプレイで、仮置きがどの程度「分岐で迷う」体験として現れるかは未検証。
- 分断・パリティ推論を要する問題を意図的に作る生成方法。今回の一意解生成ではほとんど出ず、一意性不問では多く出た。
- 一意性不問の問題で、道筋の分布に対する期待難易度のような道筋に依らない評価が作れるか。作れれば、市販アプリに近い「どの正しい道でもクリア」の問題群も候補に戻せる。
- 仕切り数（10×10 で中央値12〜26本）の視認性と、仕切りをルールに加えることの是非（ゲート3・4）。仕切りと終点指定の組合せ、仕切り本数の最小化は未試行。
- マス壁だけの一意化で成功率が急落する理由。今回は推測にとどまり、より賢い壁配置探索で改善するかは試していない。
- 製品実装での生成・一意性確認・解法器の性能。今回の秒数は研究用 Python の参考値。
