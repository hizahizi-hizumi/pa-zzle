# ハミルトン路の導入成立性調査

調査日: 2026-10-31

Issue #514 の調査結果。PUZZLE-056「ハミルトン路問題」を、盤面の全有効マスを上下左右の隣接だけでちょうど1回ずつ通る1本の道を引くパズル（以下「ハミルトン路」。製品名は別途決める）として、pa-zzle の実装候補に採用するかを判断する。

詳細は次の資料に分けた。

- [ハミルトン路の問題供給・難易度実験](./ハミルトン路供給・難易度実験.md): ゲート1・2
- [ハミルトン路のスマホ操作PoC](./ハミルトン路スマホ操作PoC.md): ゲート3
- [ハミルトン路実装前提調査](./ハミルトン路実装前提調査.md): 本実装の前提と仮決定、実装スタック

## 結論

**条件付き保留。** 問題供給・スマホ操作は成立し、難易度帯も生成側で作り分けられた。ただし、生成できる難しさが「先読みの回数と長さ」の1軸に偏っており、高い帯が人間にとって意味のある挑戦になっているかを確かめていない。また、経路接続（PUZZLE-019）と独立したゲームにするかを決めていない。この2点を解消すれば実装候補に採用できる見込みである。

| ゲート | 判定 | 根拠の要約 |
|---|---|---|
| 1. 問題供給成立性 | 条件付き通過 | 完成解先行で可解性を保証できる。一意解はマス壁だけだと 8×8 前後で生成が破綻するが、隣接マス間の仕切りで別解を潰せば 5×5〜10×10 で供給できる。9×9 以上は事前生成 |
| 2. 難易度運用成立性 | 条件付き通過 | 仕切りありの一意解問題は、人間向け解法器の仮置き回数で帯1〜5に広がり、8×8 で5帯すべてを供給できた。壁率で分布を動かせる。帯が人間の体感と合うかは未確認 |
| 3. スマホプレイ成立性 | 通過（盤面上限つき） | 補間つきドラッグ＋タップ代替が 5×5〜8×8 で成立。仕切りは暗色の短い棒で描けば見分けられ、越える移動を全入力で防げた。10×10 は実機確認後の上位候補 |
| 4. 導入判断 | **条件付き保留** | 市場の裏付けは強いが、上の2点が未解消 |

## 基礎仕様候補

- 長方形の正方形格子。各マスは有効マスか壁マス。隣接マスの間に仕切り（通れない辺）を置ける。
- 上下左右に隣接し、仕切りのないマスへだけ進める。
- 指定された始点から、全有効マスをちょうど1回ずつ通る1本の道を引く。終点は指定しない。
- 解は一意。ただしクリア判定は保存解との一致ではなく、上の規則を満たすかで行う。
- 盤面は 5×5〜8×8 を初期対象とし、7×7〜8×8 を中心にする。5×5・6×6 は低い帯の入門用。

比較した他の候補と、採らない理由は次のとおり。

| 候補 | 採らない理由 |
|---|---|
| 始点のみ・一意解・マス壁のみ | 7×7 を超えると一意解の生成が破綻し、できた問題の94%が局所的な強制だけで解ける帯1に偏る |
| 始点と終点・一意解・マス壁のみ | 8×8 まで供給できるが帯1に偏る。終点が強い手掛かりになる。易しい帯の補助候補として残す |
| 指定なし | 一意解がほぼ作れず、始点探しという別の作業も加わる |
| 始点のみ・一意性不問 | 市販アプリに近く生成も容易だが、プレイヤーの選ぶ道筋で帯が大きく変わり（約半数で帯差2以上）、難易度を再現可能に決められない |

## ゲート1: 問題供給成立性

- 生成は完成解先行（自己回避路を backbite / reptation で変形し、通らないマスを壁にする）。可解性は構成上保証され、10×10 でも数ms。
- 一意性確認は2解目で停止する全解探索に、孤立マス・行き止まり・パリティ・連結性・関節点の枝刈りを入れて実用域に入った（仕切りあり 10×10・壁率0 で p95 約1.5秒、研究用 Python）。
- 一意化は「別解だけが使う辺に仕切りを足し、不要な仕切りを外す」方式（thin）。成功1問あたりの生成時間は 5×5〜8×8 で1.3秒以下、10×10 で1.5〜12秒。
- 多様性: 全面盤（壁も仕切りもない盤）は始点だけで問題が決まりほぼ全問が重複するため供給しない。壁・仕切りがあれば回転・反転込みの重複はほぼない。回転・反転を正規化したハッシュで重複を除ける。

**判定: 条件付き通過。** 一意解を採る限り、仕切りをルールに含めることが条件になる。

## ゲート2: 難易度運用成立性

### パズル固有の挑戦

ヒントは盤面の形（壁・仕切り・始点）だけで、挑戦は**取り残されるマスを出さない道筋を先に見通すこと**にある。次の推論から成る。

- 局所の強制: 角・通路・袋小路のように通り方が1通りに決まるマスを見つけ、連鎖的に道を確定する。袋小路は終点になる。
- 閉路・端点の制約: 道片の両端を結んで輪にしない。
- 分断と到達: その方向へ進むと未通過の領域が切り離されないか。
- パリティ: 市松模様の色数から終点の色や領域の通り抜け可否を判断する。
- 先読み: 上の推論で決まらないとき、数手先の破綻を確かめて手を選ぶ。

### 観測と作り分け

- 人間向け解法器が推論を段階的に適用し、局所推論だけで解けるか、仮置き（数手先までの試行）が何回・何手要るかを記録する。探索ノード数や時間は特徴量にしない。
- 仮説の帯: 帯1 = 局所推論だけ、帯2 = 仮置き1回、帯3 = 2〜3回、帯4 = 4〜6回、帯5 = 7回以上。帯が上がると仮置きから矛盾までの最長手数（中央値）も 6 → 16 と伸びた。
- 同じ 8×8 で帯1〜5がすべて出る。壁率で分布が動き、8×8 の帯4〜5は壁率0 で 43問中18問、壁率0.15 で 50問中0問。
- 帯ごとの供給: 8×8 で各帯の出現率は 9〜47%、1問あたり 1.3〜6.7秒。最も出にくい 10×10 の帯2・帯5でも約44秒で、事前生成なら継続供給できる。
- 生成した一意解 1,039問はすべて解法器で解き切れ、評価不能は0問。

### 残る問題

1. 難しさの中身が「先読みの回数と長さ」に偏る。分断・パリティ推論が必要な問題は帯2〜4でも 2〜5% しか生成されなかった。
2. 始点から引き進めるプレイの視点で分析すると、分岐の大半は短い先読みで退けられ、全体を論理で解く視点の帯と一致しない。どちらの視点で帯を決めるかは未確定。
3. 帯4〜5は実質 7×7 以上でしか出ないため、5段階は盤面サイズの混在が前提になる。
4. 帯4以上の問題を人が最後まで解いて所要時間を測っていない。

**判定: 条件付き通過。** 狙った帯の問題を作り分けて継続供給する方法はある。帯が人の体感と合うかは未確認で、結論の保留理由の1つになる。

## ゲート3: スマホプレイ成立性

- 主操作は先端からのドラッグ。指の通過したマスを1/6マス刻みで補間し、マス縁に幅15%の不感帯を置く。ドラッグ中の巻き戻しは直前マスへの戻りだけに限り、道の途中から引き直すときはそのマスを押して始める。
- ドラッグの代替として、先端に隣接するマスのタップで延長、道の途中のマスのタップで巻き戻し、矢印キーを用意する（WCAG 2.2 の 2.5.7）。全盤面をタップだけで解けた。
- 盤面のドラッグはページをスクロールさせず、盤面外のスワイプではスクロールする。
- 仕切りは暗色（`#22201c`）の短い棒で、角を空けて描く。マス境界線・道・塗りと区別でき、隣り合う仕切りがつながって迷路の壁に見えることもない。仕切りを越える移動はドラッグ・補間・タップ・キーのすべてで防げた。
- 1マスの幅は 390px 幅で 8×8 が44px、320px 幅でも35px。10×10（35px、320px 幅で28.5px）は自動操作では成立したが、指隠れと手ぶれの余裕が小さく、仕切りが多いと隠れる情報が増える。12×12 以上はスマホの対象外。
- 実機（iOS Safari / Android Chrome）での端ジェスチャー・長押し・ドラッグ直後のタップは未確認。

**判定: 通過（盤面上限つき）。** 初期対象は 5×5〜8×8。10×10 は実機確認を条件とする。

### 名称・権利

- 日本語の「一筆書き」は辺を1回ずつ通る型（PUZZLE-054・055）を指すことが多く、本候補をそう呼ぶと混同する。内部の仕様名は「ハミルトン路」とする。
- 製品名で避ける名称: Fill、One Line / 1LINE、Zip、Flow、ナンバーリンク、Hidato、Numbrix。J-PlatPat での日本の登録状況は製品名を決める段階で確認する。

### 実装量・保守

- 既存ゲームと同じ `frontend/src/games/<game>/` の構成に載る。盤面・ルール・判定・道の状態遷移・描画は軽い。
- 固有の中心は連続ドラッグ入力（補間・不感帯・ポインターキャプチャー・タップ代替）で、既存ゲームには無い。経路接続と共通化できる。タッチ直後の `click` の扱いは `frontend/src/games/reflection/ui/touch-tap.ts` と同じ方針で扱える。
- 生成・一意性確認・難易度分析は計算量が大きいため、事前生成で本番から切り離す。

### 他候補との差異とリスク

| 観点 | ハミルトン路 | 経路接続 | 迷路 | Hidato |
|---|---|---|---|---|
| 何を考えるか | 1本の道で全マスを回る順序を計画し、取り残しを作らない | 複数ペアの経路の割り振りと全マス被覆 | 分岐から正しい通路を探す | 数字の連続性から各数字の位置を推論する |
| 盤面の手がかり | 壁マス・仕切り・始点 | 色つき端点の組 | 通路の壁・入口と出口 | 数字 |
| 見た目 | 1色の道と塗られていくマス | 複数色の太線 | 細い通路と壁 | 数字が並ぶ格子 |

- **経路接続との近さ（大）**: どちらも格子を線で埋めるドラッグ操作で、端点1組の経路接続は始点・終点指定のハミルトン路と同じになる。
- **迷路との近さ（中）**: 仕切りを辺いっぱいの線で描くと迷路の壁の断片に見える。仕切りの密度は内部辺の6〜16%で、完全迷路（32〜45%）の約1/3以下。短い棒で描き、迷路側は連続線で描き分ける。ピクトグラムには仕切りを入れない。
- **Hidato との近さ（中）**: 数字や順序付き通過点を足すと Numbrix・Zip に近づくため、数字は入れない。
- PUZZLE-051「完全クリア迷路」は定義がなく、全マスを訪れる迷路なら本候補と重なる。

### 判断

**条件付き保留。** 次の2点が解消すれば実装候補に採用する。

1. **高い帯が人間にとって意味のある挑戦か。** 帯は解法器の仮置き回数で作り分けられたが、中身は先読みの回数と長さに偏り、引き進める視点の分析とも一致しない。高い帯が「面白い先読み」ではなく「単調な試行錯誤」なら、5段階の意味が成り立たない。
   - 確認方法: [`scripts/research/hamiltonian_path_play.html`](../../../../scripts/research/hamiltonian_path_play.html)（仕切りあり一意解 6×6〜10×10 の帯1〜5、計20問。帯は解き終わるまで隠せる）を人が遊び、帯の順序と体感・所要時間・戻りの量を照合する。
   - 通過条件: 帯の順序と体感が系統的に逆転せず、帯4〜5が先読みを要する挑戦として成り立っている。成り立たない場合は、分断・パリティ推論を要する問題の生成や、引き進める視点での帯の決め方を検討する。
2. **経路接続と独立したゲームにするか。** 独立させれば、ペアの割り振りが無いぶん「計画と取り残し回避」に絞った短時間の経路パズルになる。経路接続の1本モードにすれば、入力・描画・判定を共有でき一覧上の重複も避けられる。経路接続の扱いと合わせて決める。

保留のまま本実装スタックを進め、上の2点は全段の実装後に人間が実プレイで確かめる。2 は独立したゲームとして仮決定した（[ハミルトン路実装前提調査](./ハミルトン路実装前提調査.md) §1・§4・§20）。

次は実装前に確かめればよく、保留の理由にはしない。

- 市場実績の一次表示
- 実機（iOS Safari / Android Chrome）での操作
- 10×10 と縦長盤（例: 8列×10行）の扱い
- PUZZLE-051 の定義
