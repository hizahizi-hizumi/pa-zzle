# 魔方陣導入判断調査

調査日: 2026-11-22。調べた版: 作業ブランチ `magic-square/work` の worktree。計測は `docs/パズル/導入調査/魔方陣/調査コード/magic_square_adoption.py`（seed 1、`all` で約3分半）。外部の確認は、ニコリの商標一覧だけ原本を開いた（2026-11-22）。OEIS・USPTO はこの環境から届かず、J-PlatPat は画面の操作が要るので引けなかった。文献の数と外部の事柄は、記憶にもとづく [外部知見・記憶] として書く。

## 結論

- 近い既存ゲーム・候補との違い: 成り立つ。合意どおり別ゲームとして作る。実装済みの11ゲームに、「列の合計」を目標に数を置くゲームは無い。近い候補はどれも数の使い方か条件の形が違い、統合先にならない。カックロ（PUZZLE-003）は列ごとに別の合計を与え、1〜9 を盤の中で何度も使う。KenKen（PUZZLE-004）はラテン方陣と区画の演算、Hidato（PUZZLE-009）は 1〜N を1回ずつ使う点だけが同じで、条件は隣り合う連番、数式穴埋め（PUZZLE-012）は独立した式を解く。魔方陣だけの特徴は2つ。1〜n² を盤全体で1回ずつ使うので、残っている数が全部の列で共有される。2n+2 本の列の目標がどれも同じ合計になる。
- 表示名「魔方陣」: 条件つきで成り立つ。数学の一般名で（[外部知見・記憶]）、ニコリの登録商標の一覧に無い（[事実]）。前例の詰将棋と同じく、伝統的な一般名をそのまま使う形になる。条件は2つある。(1) 公開前に J-PlatPat で「魔方陣」「マホウジン」「MAGIC SQUARE」を第9・28・41類で確かめる（この環境ではできない）。(2) 同じ読みの「魔法陣」（依頼の文面もこちらだった）と取り違えられうる。ピクトグラムで数の盤と分かるかを最終レビューで見てもらう。
- 台帳 PUZZLE-011 の値: 条件つきで成り立つ。各成立性の最終の値は、問題供給・難易度・スマホ操作の観点と実装後の検証で決まる。値の案と条件は下の「台帳の値」に書いた。今の評価理由「繰返しの解き味と高難度の多様性が弱い可能性」には、測った結果で次のように答える。
  - 答えの種類の少なさは供給を縛らない（計測）。4×4 の魔方陣は 7,040 通り（回転・裏返しで 880）、5×5 は文献で約22億通り（回転・裏返しで 275,305,224、[外部知見・記憶]）。4×4 だけでも、粗い解法器で解ける問題は、構造の同じものをまとめて少なくとも約2.2万（与える数4個）〜約30万（5個）ある（見積もり）。
  - 繰返しの解き味の懸念は残る（計測と推測）。与える数を減らし切った問題でも、置く数の約7割（中央値 0.67〜0.73）は「1マスだけ空いた列」の引き算で決まる。推理の種類は「列の残りに合う組を、残っている数から絞る」に集まる。ナンプレのように多くの手筋が順に開けていく形にはならない見込み（推測）。試遊で確かめる。
  - 高難度の多様性は、深さの面では成り立ち、種類の面では弱い見込み（計測と推測）。5×5・6×6 でも、最初に1マスだけ空いた列が無く、組の絞り込みを何度も行き来する問題は作れる。組を絞る回数は 2〜19 回と問題ごとに分かれた。一方で、縦・横・斜め以外に合計の決まるマスの組（隠れた列）は 4×4 にだけ4組あり、5×5・6×6 には無い（計測）。この解法器で見る限り、盤を大きくしても組が長くなるだけで、別の種類の推理は増えない。範囲の推理など、解法器に無い種類が効くかは測っていない。

段階の定義（スクリプトの冒頭に書いた。導入判断の目安で、難易度の観点の分類とは揃えていない）は次のとおり。段階1は1マスだけ空いた列、段階2は空き2マスの列の組を残っている数から絞り交わる列と突き合わせる、段階3は空き3マスの組、段階4は隠れた列を列として使う、段階5は空き4マスの組。どの推理も健全なので、解き切れた問題の答えは1つと言える。

限界: 範囲（最小・最大の和）の推理と仮置きを持たない。盤が大きいほど与える数が多めに残る。乱択の魔方陣は一様な乱択ではない。reduce の問題は「指定の段階で解ける」範囲での最小で、答えが1つになる最小の与える数ではない。

### 評価理由への答え

- [事実・計測] 盤面の大きさごとの数: 3×3 は1通りしかないので出さない（合意）。4×4 は 880通り、列の構造を保つ並べ替えと補数でまとめると 166通り（`count`）。5×5 は 275,305,224通り（回転・裏返しで同じとみなした数。Schroeppel 1973、OEIS A006052）、6×6 は正確な数が知られておらず、モンテカルロ法で約 1.8×10¹⁹ と見積もられている（Pinn と Wieczerkowski 1998）。5×5 と 6×6 は [外部知見・記憶] で、OEIS へは届かなかった。
- [推測] 4×4 の答えは 166 通りの構造に限られる。4×4 のレベルで500問を出せば、同じ構造の答えが平均3回ほど出る。並べ替えと補数で見た目が変わり、与える数の位置も違うので、遊ぶ人が「同じ問題」と気づくことはまず無いと考える。問題の数（下限の見積もりで約2.2万〜73万）は500問に十分足りる。
- [事実・計測] 解き味: 与える数を減らし切った問題でも、置く数の約7割は引き算で決まる（`reduce`、3つの大きさで中央値 0.67〜0.73）。推理が要る場面（組を絞る回数）は1問に 2〜23 回。
- [推測] 引き算の多さは、補助と状態の知らせの観点で比べる「あといくつ」の表示と関わる。表示すれば約7割の手が「読んで置くだけ」になり、遊びは組を絞る場面に集まる。表示しなければ、4〜6個の数（6×6 では36まで、合計111）の暗算が手の大半を占める。どちらを選んでも「同じ作業の繰り返し」に感じられる恐れがあり、試遊で確かめる論点になる。
- [事実・計測] 高難度: 隠れた列は 4×4 にしか無く（`structure`）、4×4 では減らし切った問題の 55%（164/300）で要った（`reduce --max-stage 4`）。5×5・6×6 には隠れた列が無いので、この解法器で解けた問題どうしの違いは、組の大きさ（2→3→4）と絞る回数だけになった。範囲の推理や、端の数（1 や n²）がどこに入るかの読みなど、解法器に無い種類が人の解き方で効くかは測っていない。
- [推測] 高難度の幅は、盤の大きさより「どの種類の推理が要るか」の組み合わせで作る方が出る。4×4 の隠れた列（四隅・中央の合計も34）を見つける「ひらめき」と、5×5・6×6 で組を何度も行き来する「長い読み」は違う手応えになる。レベルを「盤が大きいほど上」とだけ並べると、上のレベルは同じ推理が長くなるだけになりやすい（確かめるのは難易度の観点）。
- [事実・計測] 1マスだけ空いた列をたどるだけで解ける問題は、4×4 で与える数が8個以上（盤の半分）、5×5 で14個以上（56%）のときにしか作れない（`structure`。数の値によらず、与える数の位置だけで決まる）。
- [推測] 認識合わせの L1（4×4 で1マスだけ空いた列をたどれば解ける）は、盤の半分以上が埋まった状態から始まる。易しいレベルの手応えの薄さも、繰返しの解き味の懸念に入る。
- [事実・計測] 健全な解法器で解き切れた問題の答えは1つなので、解の数え上げを省ける。5×5 の1問は平均約0.14秒でできた（`reduce`）。メインの先の計測（数え上げで1問約60秒）より大幅に軽い。
