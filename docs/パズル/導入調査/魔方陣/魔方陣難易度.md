# 魔方陣難易度

魔方陣（ゲーム ID `magic-square`）の `レベル 1`〜`レベル 5` を、`/add-puzzle` の調査で [難易度開発手順.md](../../難易度開発手順.md) の工程2〜8 に沿って組み立てた検討記録の下書き。研究用の Python（`docs/パズル/導入調査/魔方陣/調査コード/magic_square_difficulty.py` と補助の集計 `magic_square_difficulty_extra.py`）で使い捨ての小さな生成（4×4〜7×7）を作り、つまみの案を比べて1つに決めた。製品のコードはまだ無い。

この文書は正本ではない。採用する契約は PZL-014 の難易度の節（§12 の案を spec の項目で移す）、つまみ・境目・候補空間の値はゲームのコード（difficulty の項目で作る）を正とする。ここに写した値は調査時点のもの。

根拠は次の見出し語で区別する。

- **事実（実測）**: 上の調査コードで測った結果。どのサブコマンドかを添える。再現の仕方は付録 A。
- **導出**: 定義から論理的に導けること。
- **推測**: 遊んで確かめていない判断。

**人も AI もまだ遊んでいない。** 各レベルの体験差は仮説として扱い、§7 の問題で試遊する（§10）。特徴の定義の反例探し（検査 A4）は6回行い、どれも反例が出たので作り直した。今の定義を版 8 と呼ぶ。1回目にかけた定義が版 2、2回目が版 3、3回目が版 4、4回目が版 5、5回目が版 6、6回目が版 7（§5.3・§13）。版 8 には反例探しをかけていない。PO の判断で6回で打ち切り、版 6〜8 を同じ物差しで比べて版 8 を採った（§5.3・§9）。

## 2. 挑戦と基準とするプレイ条件

### 2.1 挑戦

> 列ごとの残り（合計の定数 − 今の合計）と、まだ使っていない数から「足してちょうどになる数の組」を思い浮かべ、交わる列の組と突き合わせてマスの数を決めること。突き合わせだけでは決まらない所では、絞った候補（メモ）で組を作り直したり、3マス空いた列の組を読んだりして、交わる列と行き来しながら決めていくこと。

レベルは、最初の盤面ですぐ決まるマスがあるか（入口）、要る読みの種類（段）、深い所（3マスの組を読む所か、2マスの組を作り直す所）があるか、最初の1マスが深い所かで分ける。挑戦にしないもの:

- 引き算・足し算そのもの。列の残りは表示された今の合計から引き算で出す。読みに数えない。
- 空きの数と置く回数（作業量）。分類の特徴に使わず、盤面の範囲で許す。
- 試し置きして戻す回数（プレイ成績）。
- 4×4 の四隅の合計も34になる、といった魔方陣の性質の知識（§2.4）。

1巡の中で、交わる列どうしの候補を頭の中で重ねることは、挑戦に含める（メモに書ける数を超えても重ねる。§2.7 の前提 P3）。L4・L5 の多くは、メモ4つだけで頭で重ねずに読むと試し置きが要る（§5.3）。

### 2.2 基準の読むモデル

読むモデル（`read_solve`。設定は `DEFAULT_READ`）は、置いた数・列の残り・候補のメモだけから空きマスの候補を絞る。

**読む単位**。どれも「その単位の空きマスに、メモの候補の数を互いに違うように入れて、単位の列の合計を全部満たす入れ方」を全部考える。

| 単位 | 段 | 中身 |
| --- | --- | --- |
| 列 | 空きの数 | 空きが e マスの列（段 e）。e = 1 なら、そのマスに残りの数が入る |
| 鎖 | 2 | 1つのマスの数を t と置くと、ほかの全部のマスが t の式で順に書けるまとまり。空きが2マスの列が同じマスでつながったもの（2本以上）から始め、空きのうち1マスを除く全部がまとまりの中にある列（空きが3マス以上でもよい）を足して、その列の残る1マスもまとまりに入れる。足した先のマスからも空き2の列をたどり、足せる列が無くなるまで続ける（全部のマスがまとまりの中にある列は確かめの式として足す。`tchain_units`、版 7）。入れ方は、まとまりの全部の列を同時に満たすもの |

段は、単位の空きマスの数 − 式の数 + 1（その単位で仮に置く数に1を足したもの）。空き e の列は e−1 個を仮に置けば残る1マスが決まるので段 e、鎖は1つの数 t を置けば全部が決まるので段2。式は、残りが1マスになった列から単位のマスを1つずつ決めていくのに使うものだけを数え、全部のマスが決まった後にも当たる列は確かめに使うだけで数えない（閉じた鎖も段2）。空き3の列を含み、どの1マスを置いても順に決まらない組は3以上になる。**段は単位で付け、入れ方の数では付け替えない**。空き2マスの列は、残っている数の中で足してちょうどの組が1通りしか無くても段2（組を思い浮かべて1通りと分かる読みで、L2 から上の挑戦そのもの）、組が少ない空き3の列も段3。組が少ない単位を低い段で読む近道を持つ人（§2.3 の `pair1`・`short3_*`・`jointk2_s*`）は、近道なしで置けない所でだけ近道を使うとみなし、近道で初めて置けた所は、近道を使った段の1つ上（空き3の列を含む単位なら段3、空き2の列なら段2）と数える（`read_solve` の `try_tier`）。その所の巡は、近道を使った巡と、1つ上の段を近道なしで読んだときの巡（それで置けるとき）の少ない方にする（近道は読みを軽くするだけで、深くしない。§4.4）。要る読みの種類は近道で変わらない。**段はその所に要る段で、近道を要らない所で使っても数えない**。近道なしで置ける所で近道も一緒に読み、見つけたマスを置く人はいるが、その所に要る段は近道なしの段のままで、近道で見つけたマスを別の段の所として数えることもしない（読むモデルは近道を要る所でだけ使う）。

**単位を読んだ結果**。どちらも、組を全部考えたときに同時に分かることで、読んだ巡の結果に入る。

| 結果 | 内容 |
| --- | --- |
| 台 | 単位の各マスのメモを、どれかの入れ方で入る数に絞る |
| 組の数を他で使わない | どの入れ方でも単位の中で使う数を、その巡に読んだ単位のマス（メモのあるマス）のうち単位の外のマスのメモから消す。段2以上の単位で使う |

**巡**。段 t の1巡は、段 t 以下の単位を全部、巡の始めのメモ（同じ写し）から読み、結果を全部重ねること。重ねるのは頭の中で、1巡の中ではメモに書ける数（4つ）を超える候補どうしも同じマスで重ねる（メモの上限は巡と巡の間にだけ当てる。§2.7 の P3）。重ねたメモで、候補が1つになったマスと、入る所が1マスだけになった数（この数はここだけ）を、その巡で決まったマスとする。k 巡目は k−1 巡目の結果だけを使うので、巡の数は読みの依存の段数の最小になり、読む順に依らない（導出）。

**段と所**。

- 段1 = 空き1マスの列・メモで候補が1つのマス・この数はここだけ。段1で置けなくなった盤面を「行き詰まり」と呼ぶ。
- 行き詰まりでは、段2・段3・段4の順に、どの段も行き詰まりの始めのメモから巡を重ね、決まったマスが出たら止める。決まったマスが出た最も低い段を使い、その段とそこまでの巡の数を、その「所」の値にする。
- 決まったマスは全部置き、段1に戻る。メモは残す（置いた数は全部のメモから消す）。
- **深い所** = 段3の所か、段2で3巡以上の所（3マスの組を読むか、絞った候補で2マスの組を2回以上作り直して初めて決まる所。版 8。版 7 までは段2で2巡以上）。

基準のモデルはメモの数に上限を置かない（候補が5つ以上のマスの絞り込みも頭で覚える）。巡と巡の間にゲームのメモに書ける分だけを覚える人は、次の §2.3 の部品 `memo4` として一致を求める。1巡の中で重ねる量にも限りがある人は、モデルの外として測る（§2.7 の P3）。

### 2.3 読み方の部品と、一致の決まり

基準の読むモデルのほかに、人が使いうる読み方・数え方を「部品」（`AGREE`）として 34 持つ。基準と、部品の1つ・2つ・3つの組み合わせ（`AGREE_COMBOS`。2つの組 525 通り、3つの組 4,948 通り。版 5 から3つまで）のどれで測っても同じレベルになる問題だけにレベルを付ける。1つでも違うレベル（範囲外を含む）になる問題は `reading-dependent` として出さない。これがレベルの帯の間の空きの1つ目になる。2つ目は、基準のモデルで境目から上下に1段離れた問題だけを作る決まり（§4.2 の「作るときの帯」。版 8 で上向きの余裕も取った）で、一致はこの帯を求めずにレベルだけで比べる。読み方で段2の巡が1つずれても、隣のレベルには移らない。

- 組み合わせの設定の重ね方: 「K 通りまで」「K 本まで」（`short3_sets`・`short_joint_sets`・`jointk`）は大きい方、「段 t から」（`mrange`）は低い方を採る（`MERGE_MAX`・`MERGE_MIN`）。ほかの切り替えに違う値が入る組（たとえば `range1` と `viol2`）と、前に出た組と設定が同じ組（`strong`・`weak` に含まれる組など）は除く。
- 4つの組み合わせは一致を求めず、無作為に選んで測る（§5.3）。
- 比べるレベルには巡の上限を当てない。巡の上限・L1 の段1での極小・作るときの帯は、基準のモデルで測る作り方の決まり（§4.4）。
- 4×4 は、どの読み方でも、その読み方に仮想の列（§2.4）を足して読むとレベルが下がる問題を除いた上で比べる。

| 群 | 部品 | 中身 |

| 置き方・段の選び方 | `one` | 1巡で決まったマスを1つずつ置く |

### 2.4 表現できない読み・モデルの外の読み

- **4×4 の仮想の列**。どの 4×4 魔方陣でも、四隅・中央の 2×2・上下の辺の中央2マスずつ・左右の辺の中央2マスずつの合計が 34 になる（事実（実測）、`enum4` で全 7,040 通りに成り立つ）。知っている人には1マス空きの列が増える。4×4 は、仮想の列を足して読むとレベルが下がる問題を除く（§4.1）。5×5 には6マス以下、6×6 には5マス以下の仮想の列は無い（事実（実測）、`identities`）。
- **一致を求めないで測るだけの読み方**（範囲内の問題でレベルが変わる割合は §5.3）:
  - 単位を決まった順に読み、結果をすぐ次の単位に使う数え方（走査の回数）。1回の走査で依存の連なりを何段か進めるので、読む順で値が変わる。巡は盤面だけで決まる依存の段数で、別の量として扱う。
  - 4本の列の ±1 の式、列の式の一次結合（多くの列を足し引きして1マスを出す）。人の読みとして扱わない（推測）。
  - 組の数を他で使わないを全く使わない・組が1通りの単位からしか使わない人、鎖を読まない人。読むモデルの核の読みを使わない・減らす人で、モデルの外とする。
  - メモを候補3つ以下のマスにしか書かない人、空き2の列のマスにしか書かない人。ゲームは4つまでどのマスにも書けるので、自分で書く所を減らす人として外に置いた。
  - 段の付け方の別案のうち、3本以上の鎖や全部の鎖を段3に数える案。段は単位の空きマスの数 − 式の数 + 1（§2.2）で付ける。空き3の列と交わる列を一緒に読むのを段2に数える案（`jk2t2`）と、3本の列の組を入れ方が1〜2通りなら段2で読む案（`jointk3_s1`・`jointk3_s2`）は、§2.2 の近道と同じく、それで初めて置けた所を段3と数えて測った。
  - 段1の読みとして不自然とした読み: 組が1通りかをメモで見て段1で読む（`pair1_memo`）、メモの上下限を空き2の列にも段1から繰り返し当てる（`mrange1e2`）。段2の読みを段1と呼び直すのに近い。
  - A4 の4回目の向きの一段先（組5〜8通りの空き3の列、交わる2本の入れ方3〜4通り、3本の列の組、メモの上下限を空き2の列にも段2から、鎖を遅れてつなぎ2本ずつ読む、残っている数8個以下のときだけ `pair1`）。測って、動く割合を §5.3 に置いた。

## 4. 状態と分類

### 4.1 状態

| 状態 | 条件 |
| --- | --- |
| 成立しない（`invalid`） | 解が無いか2つ以上、または完全な解法器の上限に達した |
| 提供範囲外 `requires-trial` | 基準の読むモデルの段4でも止まる（試し置きが要る） |
| 提供範囲外 `long-line` | 段4（空きが4マス以上の列を読む）が要る |

| 提供範囲外 `not-minimal` | 段1だけで解けるが、与える数が基準の段1で極小でない（作り方の決まり） |

| 提供範囲外 `size-not-allowed` | 読みのレベルはあるが、その盤面を許していない（5×5・6×6 の L1、6×6 の L2、4×4 の L3〜L5） |

| 提供範囲外 `near-boundary` | 基準の読むモデルで L2〜L5 に当たるが、作るときの帯（§4.2）に入らない（作り方の決まり） |

### 4.2 レベルごとの基準表（案 C2・版 8。比較実験の条件で、調査時点の値。正はコード）

「深い所」は、段3の所か、段2で3巡以上の所（梯子 W3。版 8）。上から当て、最初に当たったレベルにする。太字はそのレベルで新しく要るもの。どのレベルも、§2.3 の部品の1〜3つの組み合わせで同じレベルになる問題だけを採る。「作るときの帯」は基準の読むモデルだけで測る作り方の決まりで、一致を比べるときには求めない。帯は、段2の巡で上下に1つずつ余裕を取る: 深くない所は段2で1巡（2巡で深くならない）、深い所は段3か段2で4巡（3巡でも深い）。段2で2巡・3巡の所は、どのレベルでも境目に乗るので作らない。

| レベル | 盤面 | 条件 | 作るときの帯 |
| ---: | --- | --- | --- |
| 1 | 4×4 | 段1だけで解ける | 与える数を段1で極小にする |
| 2 | 4×4・5×5 | 入口がある。段2（**組の突き合わせ・鎖**）まで要り、深い所は無い | 段2の所が全部1巡 |
| 3 | 5×5・6×6 | **入口が無い**。段2まで、深い所は無い | 段2の所が全部1巡 |
| 4 | 5×5・6×6 | 入口が無い。**深い所**があり、最初の所は深くない | 最初の所が段2・1巡で、段3の所か、段2で4巡以上の所がある |
| 5 | 5×5・6×6 | 入口が無い。**最初の所が深い** | 最初の所が段3で2巡以上か、段2で4巡以上 |

どのレベルも、段4・試し置きは要らず、巡の間のメモが4つまでの人でも試し置きなしで解ける（1巡の中では、交わる列の候補を頭で重ねる前提。§2.7 の P3）。1か所の巡は基準の数え方で4まで。入口があって深い所もある問題はどのレベルにも入れない（§4.4）。4×4 は、仮想の列（§2.4）を足して読んでもレベルが下がらない問題だけにする。

## 6. 供給

### 6.1 生成の仕方（調査コード）

1. 魔方陣を1つ作る。4×4 は全 7,040 通りから一様に選ぶ（乱択の深さ優先探索は 3,000 回で 880 種のうち 814 種、最多の種が 21 回と偏った。事実（実測））。5×5 以上は乱択の深さ優先探索（候補の最も少ないマスを分け、列の残りの上下限で枝を切る）。
2. 極小化: マスを無作為な順に1つずつ空け、読むモデル（段 T まで）で解けなくなるマスは戻す。読むモデルの推論はどれも健全なので、解き切れれば解は1つ（導出）。完全な解法器で全候補が一意解と確かめた（事実（実測））。T = 1 で戻さない（k = 0）候補は、段1で極小になる（導出）。
3. k = 0〜2: 空けたマスから k マスを戻す（易しめの候補）。k = 12・13: 戻さずに200回、与える数の入れ替え（1つ外して別のマスを与える）・外す・足すを試し、点を下げない向きに磨く（`polish_givens`）。k = 12 は L5 向けの点（`polish_score`: 入口0・最初の1マスの巡・巡3まで・3マスの列・作り直し）、k = 13 は L4 向けの点（`polish_score4`: 入口0・最初の所が段2・1巡・段3の所か段2で4巡以上の所（版 7 までは3巡以上）。最初の所が深いと引く）。版 8 の L5 向けの点は、帯に合わせて最初の所が段3のときだけ最初の所の巡を点にした。どちらも、7つの読み方（`POLISH_KEY_VARIANTS`: `strong+jointk2_s2`・`memo4+chain_late`・`strong+mrange1`・`lock_eph+weak`・`memo4+diag_nochain`・`lock_eph+memo4`・`tchain_none`）で梯子（版 8 は W3）のレベル（巡の上限を当てない）が基準と違うごとに15を引く。基準で巡が4を超える盤面と段4が要る盤面には進まない。初めの6つは、版 5 の候補で帯に入る L4・L5 のうち版 6 の一致で外れる 87 問を、読み方で貪欲に被覆したもの（版 6）。6つの内訳は `strong+jointk2_s2` 40、`memo4+chain_late` 19、`strong+mrange1` 18、`lock_eph+weak` 6、`memo4+diag_nochain` 2、`lock_eph+memo4` 1 で 86 問（残る1問だけを捕まえる `range1+pair1` は、磨く時間を増やすだけなので入れなかった。事実（実測）、`magic_square_difficulty_extra.py designs`）。版 7 は、基準の鎖を延ばしたので、延ばさない人（`tchain_none`）を7つ目に足した。
4. 分類し（帯を確かめ、部品の1〜3つの組み合わせを当てる）、当たったレベルに採る。生成条件 (n, T, k) を巡回する。

## 8. 素朴な解き方

`naive_solve`。どの表示でも、空きが1マスの列はその数を入れる（引き算は読みではないとみなす）。入れた数が使用済みか範囲外ならその場で矛盾に気づく。

- **無作為の試し置き**: 空きの最も少ない列（2マス以上）のマスを無作為に選び、残っている数を無作為な順に試す。違反が出たら戻し、試す数が尽きたら1つ前の試し置きまで戻す。
- **慣れた試し置き**: 上と同じだが、そのマスの列の空きが2マスなら、相手のマスに入る数（残り − 試す数）が残っている数だけを試す。
- 表示は、今の合計を出して違反を知らせる（決めた表示）、埋まった列の合否だけ、何も出さない（全部埋めてクリアにならなければ最後の試し置きから戻す）の3通り。
- 1問3回。上限は空きの数の20倍の手（置く回数）。取り消しは試し置きとそれに続いた1マス空きの列の埋めをまとめて1回と数える。

## 12. パズル仕様の難易度の節の案

spec の項目で PZL-014 に移す。値（巡の上限・作るときの帯の幅・盤面の割り当て・一致を求める部品の一覧と組み合わせの数・メモの上限）はコードに置き、ここには書かない。

- 挑戦: 列ごとの残りと残っている数から「足してちょうどになる組」を思い浮かべ、交わる列の組と突き合わせてマスの数を決める。決まらない所では、絞った候補で組を作り直したり、3マス空いた列の組を読んだりして、交わる列と行き来して決める。
- 基準とするプレイ: 盤面に見えるのは、置いた数・列の今の合計と合計の定数・候補のメモ（1マスに書ける数に上限がある）。違反は知らせ、行き詰まりは知らせない。列の残りを出す引き算は挑戦に数えない。試し置きをしなくても推理だけで解ける問題だけを出し、メモを上限までしか書かない人にも試し置きが要らない。
- 読みの数え方の意図: 読む単位は列と鎖。鎖は、1マスの数を仮に置くとほかの全部のマスが列の残りから順に決まるまとまり（空き2マスの列のつながりと、それで1マスを除いて埋まる列でたどれる所まで）。段は単位の空きマスの数 − 式の数 + 1（仮に置く数に1を足したもの）で、入れ方の数に依らない（空き2マスの列は組が1通りでも段2、組が少ない3マスの列も段3。組が少ない単位を低い段で読む人の近道は、読みを軽くするだけで、所の段を変えず、所を深くもしない。段はその所に要る段で、近道を要らない所で使っても数えない）。1巡は全部の単位を同じメモから読んで結果を重ねることで（1巡の中では頭の中で重ね、メモの上限は巡の間にだけ当てる）、巡で読みの依存の段数を数える（読む順・置き方に依らない）。レベルは「入口があるか」「段」「深い所（3マスの組を読む所か、2マスの組を2回以上作り直す所）があるか」「最初の所が深いか」で決め、回数と段3の所の巡では分けない。人が使いうる読み方・数え方（段を上げた所の数え方、メモの書き方と書ける数、上下限・組の少ない列などの安い読み、段の付け方・鎖のつなぎ方、読みを減らす人）を部品とし、その3つまでの組み合わせのどれでも同じレベルになる問題だけを出す。そのうえで、基準の読み方で境目から上下に1段離れた問題（深くない所は作り直しの無いもの、深い所は1段深いもの）だけを作り、読み方で作り直しの回数が1つずれても隣のレベルに移らないようにする。読むモデルが置いている前提（1巡の中の重ね方など）は書き出し、前提をはずす人のうちモデルの外とした人は測るだけにする。巡の上限・L1 の与える数の減らし方・この帯は、基準の読み方で測る作り方の決まり。

- 規模: 上ほど広い盤面を許し、隣のレベルと盤面を重ねる。同じ盤面の隣のレベルは読みで分ける。4×4 は上のレベルの問題がほとんど作れず、四隅などの合計の近道もあるので、下のレベルだけにし、その近道でレベルが下がる問題は出さない。

### A.3 限界

- 候補は使い捨ての小さな生成（1条件 40〜120 候補）で、全生成ではない。レベルごとの件数は 69〜315。
- 5×5 以上の魔方陣は乱択の深さ優先探索で作り、一様ではない（偏りは測っていない。対称・汎魔方陣は0だった）。
- 素朴な解き方は1問3回で、戻しは乱数で揺れる。
- 部品は、人が使いうると考えた読み方・数え方の一覧で、全部ではない。モデルの前提（§2.7）のうち測っていないものがある。組み合わせは3つまで全部、4つは無作為に選んだ組だけ確かめた（§5.3）。反例探しは6回で打ち切った（PO の判断）。
- 読むモデルが表す読みが人の読みと合うか（鎖を一度に読むか・組の数を他で使わない・巡の上限・3マスの組の重さ・メモ4つまでで足りるか・近道で読む所を重く感じるか）は、人で確かめていない。
