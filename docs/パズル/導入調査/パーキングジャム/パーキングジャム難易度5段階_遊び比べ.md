# パーキングジャム難易度5段階 遊び比べ問題（ラベル伏せ）

> **調査用の問題リスト**: [パーキングジャム難易度5段階調査](パーキングジャム難易度5段階調査.md) の工程9（人間の実プレイ）に使う。現在仕様ではない。どの問題がどのレベル案・どのレバーの対に当たるかは、遊び終えるまで調査文書の「答え合わせ表」（第2版）を見ない。

## 使い方

- 31問を P01 から順に遊ぶ。順番は答えと無関係に並べ替えてある。
- 問題の多くは2問1組の「対」になっている。対は、依存の深さ・読み違いを誘う開口や方向・読む範囲（盤面の広さと車の数）のうち、1つのレバーだけが違うように選んだ。どれとどれが対かは答え合わせ表で分かる。
- 各問題について、完答時間、最初の操作までの時間、不成立操作（出せない方向を選んだ回数）、待った・盤面を戻した回数と、「どこで何を考えたか・どこで読み違えたか」を一言残す。
- 可能なら、続けて遊んだ2問のどちらが難しかったかも残す（ペア比較）。
- 製品の画面には、特定の問題を指定して開く手段が現在ない。盤面図で遊ぶか、調査文書「遊ぶ手段」の案を参照する。

## 盤面図の読み方

- 外周の `=` は道路への開口、`#` は縁石（出られない）。四隅の `+` は角。
- `X` は固定物（植栽島など。通れない）。`.` は空き。
- 英字1字が1台の車。小文字は横向き（左右へ出る）、大文字は縦向き（上下へ出る）。同じ文字のマスが1台の車の範囲。
- 車は自分の向きの前後どちらかへ、進路上に車・固定物がなく、その車線の外周が開口 `=` のときだけ出庫できる。出庫した車は盤面から消える。
- identity は本番の `restoreParkingJamProblem` で同じ盤面を復元できる問題識別情報（generator version 2）。「開口変換」と書いた問題は、その identity の盤面の道路開口だけを、書かれた開口に置き換えた盤面である（本番の生成器では作れない）。
