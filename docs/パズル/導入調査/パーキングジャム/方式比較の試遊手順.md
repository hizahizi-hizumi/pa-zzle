# パーキングジャムの方式比較：試遊の手順（#727）

[方式横断の判断材料.md](方式横断の判断材料.md)の「試遊で確かめること」を、実際に遊んで確かめるための手順。比較試作画面は検証用で、プレイの記録を保存しない。気づいたことは遊びながら書き留める。

## 開き方

- 比較試作画面は `/puzzles/parking-jam/lab`。検証用のブランチのプレビューで開く。main には無い。
- スマホで遊ぶ。問題を選ぶと、指令（または乗客の列）・待機枠・状況・盤面・「1手戻す」が1画面に収まる位置へ移る。
- 画面上部で方式を選び、「問題」のプルダウンで問題を選ぶ。ルールの説明は「ルール」を開くと読める。
- 「分岐の答えを表示」は、遊び終えるまで使わない。

## 遊ぶ順

全部で約30分。A だけなら約15分。画面の問題名には機械的な Lv が出ている。先入観を減らすため、Lv の順ではなく下の順に遊ぶ。

| 3 | Lv2 代表1 | 同上 |
| 4 | Lv4 代表2 | すぐ出せる同色車を後に残す判断。納得できる罠か |

## 書き留めること

問題ごとに次を書く。

- 詰んだ回数と、戻した手数のおおよそ
- 難しさ（1〜5）
- どこで何を考えたか。考えずに押しただけなら、そう書く
- 理不尽に感じた瞬間、気持ちよかった瞬間

遊び終えたら次を書く。

- A の8問を、難しかった順に並べる
- A の5問目以降で、同色2台の使い分けに気づいた後も考える必要があったか
- A と B を、同じゲームの別の遊び方として両方遊びたいか
- スマホで、指令・待機枠・盤面を読みながら遊べたか。押し間違えた場面

## 結果と次の判断

| 遊んだ結果 | 次の判断 |
| --- | --- |
| A の難しさの順が Lv とおおむね合い、型を覚えた後も考え、B と別々に遊びたい | 出庫指令型を遊び方として足す方向で、同じゲームに足すか別のゲームにするかを決める |
| A は面白いが、Lv の順が合わない、または型を覚えると作業になる | 出庫指令型は保留のまま、判断の型を増やす作りと基準の直しを先に行う |
| A の詰みが理不尽、または B の方が良い | 出庫指令型は見送り、クラシックを維持する |
| C の11問目が A に無い面白さを持つ | 乗客列型を、出庫指令型の判断の型を増やす材料として検討する |

1人の試遊で分かるのは、その人の体感までである。難易度の校正には、複数人の記録が要る。
