# 出庫指令型：難易度と良問供給の検証（#738）

## 目的・前提

#727 の子Issue #738で、車の遮断関係と次の出庫指令、有限の待機枠を読んで出庫順を計画するゲーム性を検証する。現行の4方式の比較と操作可能な試作は[ゲーム性再設計.md](ゲーム性再設計.md)およびPR #730を参照する。正式なルール・難易度・問題集・記録は変更しない。

**可解な問題の生成、選択に正誤があること、5段階の難易度、面白い問題の継続供給は別の要件。** 成功率や計算量を人間の体感難易度の代わりにしない。

## 1. 指令を引き直す方法の限界（最初の試作）

`scripts/research/parking_jam_dispatch_supply_probe.py`（seed 20261109、8台と12台の各8盤面に5指令列）を使い、車両配置と色を固定して可解な出庫順から指令を生成した。最初に出せない色を指令の先頭に置く候補も混ぜた。四辺開口・固定障害物なしで、正式なLv1〜Lv5を代表しない。

| 方式と待機枠 | 仮条件への適合／40列 | 1列だけ試して成功した盤面／8 | 5列を試して成功した盤面／8 |
| --- | ---: | ---: | ---: |
| 8台・2枠 | 0 | 0 | 0 |
| 8台・3枠 | 3 | 1 | 3 |
| 8台・4枠 | 2 | 0 | 2 |
| 8台・5枠 | 0 | 0 | 0 |
| 12台・2〜4枠 | 0 | 0 | 0 |
| 12台・5枠 | 1 | 1 | 1 |

**仮の選抜条件：**（a）毎手合法な出庫を等確率に選ぶ場合の全クリア確率が5〜50%、かつ（b）最初の3手までに到達できる可解局面で、合法な悪手の後も2手以上は続けられ、その悪手が**車の遮断をなくせば正解に変わる**。条件は研究上の探索指標であり、「良問」の認定ではない。単純に5倍の指令候補を探索すれば成功例が増え得るが、生成改善と同一視できない。最初に出せない色を先頭に置く方法は、少数標本で適合を確認できなかった。

## 2. 駐車場の遮断から指令を構築する方法

`scripts/research/parking_jam_dispatch_structured.py` を追加。無作為な指令列の引き直しと比較するため、同じ車両配置を使って、次の4方法を実装した。

| 方法 | 色と指令の作り方 | 狙い |
| --- | --- | --- |
| random | 色ペアと可解な指令列を無作為に構築 | 対照群 |
| geometry-colors-only | 初期に塞がれた2台に同じ色を割り当てる。指令は無作為 | 色の配置だけの効果を分離 |
| single-target | 上記の色付けに加え、塞がれた車を次の指令とし、その車を出せるようになる最少の先行出庫を後続指令へ置く | 遮断を解く局面を1つ構築 |
| double-target | 車を解放する上記の構造を、盤面の状態を更新しながら2回作る | 異なる遮断局面の連続を構築 |

各方法に**同一の盤面あたり5回の指令提案**を許す。構造が見つからない提案、同じ指令の重複は評価候補にならないため、評価した問題の数は異なる。randomと構造型は色の割当ても異なる一方、geometry-colors-onlyとsingle/double-targetは**同一盤面・同一の構造依存色付け**を使う。

`single/double-target`は既存の試作生成器で得た盤面に合わせて**色と指令列を作る**方法である。まだ車両配置そのものを手筋から逆算して生成する方式ではない。また、最少で塞ぎを取り除く操作列を一つ選んでおり、人間にとってその解き方が自然かまでは判断していない。

### 出庫指令型の状態圧縮

現在の出庫指令型では、車が出庫した時点で盤面から消え、各車は要求色が一致すると1度だけ乗り場から離れる。したがって、**同じ車の集合が盤面から取り除かれているなら、どの順で取り除いたかにかかわらず、消化済み指令の最大接頭辞と待機枠の使用数は等しい**。

- 除去済み車の色別台数から、色別に要求を満たせる指令の最長接頭辞を求められる。
- 使用枠数は `除去済み車の台数 − 消化済み指令数`。
- 盤面の合法出庫は残っている車の集合だけで決まる。

この不変条件を使った全探索では、**状態を車両の残存ビット集合だけ**で表せる。最大状態数の上限は車両数 `n` に対して `2^n` であり、同じ盤面内での待機車の並び順を別状態として数えない。これは**出庫指令型に限る**。乗客ごとに車の容量を満たす方式にはそのまま転用できない。`test_parking_jam_dispatch_structured.py` で旧探索器・独立した全探索実装と、解法列数および無作為手での成功確率を照合した。

## 3. 同じ生成予算で比較した結果

同じ生成器の盤面を各条件で使用。seed **738** は各条件60盤面、seed **20261110** は各条件20盤面、合計**各条件80盤面×各方法5提案＝400提案**を比較。8台7×7・12台8×8、四辺開口、固定障害物なし。各方法の提案に同じ選抜条件を適用し、独立した2乱数種で結果の方向を確認した。`parking_jam_dispatch_structured.expected.json` に両乱数種の結果と問題例を保存。

| 規模・枠数 | random 適合／400提案 | single-target 適合／400提案 | double-target 適合／400提案 | double-target の異なる判断局面（参考） |
| --- | ---: | ---: | ---: | ---: |
| 8台・3枠 | 17 | 1 | 5 | 2 |
| 8台・4枠 | 9 | 3 | 14 | 7 |
| 12台・4枠 | 10 | 0 | 1 | 1 |
| **12台・5枠** | **8** | **4** | **33** | **19** |

同じ条件で `geometry-colors-only` の適合数は、順に **7、6、7、4件／400提案**。**単に塞がれた2台を同色にするだけでは改善しなかった**。`double-target` の成功率向上は一律でなく、**12台・5枠では顕著だが12台・4枠では悪化**した。8台・4枠では14件あるが、成功を含む盤面は7/80で、randomの9/80を超えていない。

`double-target` は400回提案しても、実際に異なる可解な指令列として評価できた件数が8台・3枠153、8台・4枠188、12台・4枠308、12台・5枠298だった。**適合／評価できた指令数**のみを見ると、構造が作れなかった盤面を除外して過大評価するため、上表は全提案400回を分母にした。

**供給性の見積りにあたっての重複：** 12台・5枠の33適合候補は、実際には16/80盤面で発生し、最初に発見した「正しい経路で到達した局面＋悪手」の組合せで重複を折りたたむと19件。出庫指令の後半だけ変えた候補がある。これは問題の視覚的同型・戦略的同型を完全に除いた件数ではなく、**良問19問の保証ではない**。

### 固定した具体例（機械的に検証済み）

`parking_jam_dispatch_structured.expected.json` に盤面の全車両位置、色、指令列、枠数、出庫列を固定し、独立の全探索で追試した。以下はユーザーに正解を知らせるUIではなく、研究用の事例。

| 例 | 正しい途中経路 | その後の悪手／代替の正しい手 | 悪手後に残る最大操作回数 | 何が変わるか |
| --- | --- | --- | ---: | --- |
| 8台・4枠・構造2回（盤面22） | 車3→2→7 | 車8／車1 | 2 | 出庫で塞ぎが解かれる順と待機枠の競合 |
| 12台・5枠・構造2回（盤面0） | 車7→2→8 | 車11／車3 | 3 | 出庫指令が未消化のまま保留車が増える |
| 12台・5枠・構造2回（盤面12） | 車1→6→9 | 車10／車4 | 3 | 別の遮断経路を選ぶ意味が生まれる |

車番号は`v0`を「車1」とした値。すべての例で、途中経路は合法かつその後もクリア可能、悪手後は不可能、代替の手なら可能。悪手後に最大2〜3手は操作できる。車の遮断を取り除く反実仮想では悪手からでも完走できることを確認した。ただし、**プレイヤーが失敗を事前に予見でき、面白いと感じるかは未検証**。

## 4. 難易度5段階と継続供給の判断

出庫指令型の挑戦の核は「先の指令に必要な車を解放するため、何台をどの順で待機させ、どこで枠を空けるかを計画すること」である。次の段階は分類モデルではなく**問題制作時に検証する解き味の仮説**とする。

| 仮の段階 | プレイヤーに求めたい判断 | 必要な代表問題・反例 |
| --- | --- | --- |
| Lv1 | 次の指令車の見える遮断を解消する | 色照合だけでは解けず、単一遮断を読める例 |
| Lv2 | 必要な車の前に1台を待機させる | 待機の順序を間違える意味がある例 |
| Lv3 | 複数の指令・遮断と、枠が空く時点を併せて読む | 最初の一手だけでは結果が決まらない例 |
| Lv4 | 複数の開放候補から後の指令に有利な車を選ぶ | 見かけの分岐が実際には同等でない例 |
| Lv5 | 競合する複数の遮断系列と枠の空きを計画する | 長いだけ・台数が多いだけの問題との比較例 |

今回の比較で具体的に確認できたのは**遅延する悪手を含む一部の問題例と、構造起点での候補出現率の変化**まで。Lv1〜Lv5に意味のある順序を保証する解法モデル、手筋ごとの境界、安定した供給量、盲検の人間校正は未完了。12台・5枠だけの適合率をLv5供給の成立とはみなさない。

次は**車両配置も含めた構造生成**（遮断の依存の連鎖、開口の位置、同じ色の別車の解放経路、枠の予約が競合する局面を意図的に埋め込む方式）を試し、無作為盤面を後から選抜する方式と生成予算・計算時間・同型除去後の手筋の種類で比較する。特に8台・3枠、12台・4枠の供給改善はまだ確認できていない。
