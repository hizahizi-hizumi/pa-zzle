# 乗客列型：駐車場を読むパズルとして成立するかの検証（#739）

#727 の子 Issue #739 の検証資料。乗客列型が、駐車場の遮断を読むパズルとして成立するかを調べた。4方式の比較は[ゲーム性再設計.md](ゲーム性再設計.md)、同じ物差しで測った出庫指令型は[出庫指令型の供給検証.md](出庫指令型の供給検証.md)にある。用語（判断局面、距離、理由 A・B、最小枠数、余裕、自然な計画）は出庫指令型の資料と同じ意味で使う。正式なルール・難易度・問題集・記録は変更していない。

## 結論

- 乗客列型の判断の約半分は、駐車場を見なくても乗客の列と定員だけで決まる。判断局面のうち、車の遮断が勝ち負けを決めるものは 47%、列だけで決まるものは 52% だった。出庫指令型では、判断はすべて遮断から生じる。
- 乗客列型にしかない判断は、定員の違う同色車のどちらを使うかである。この判断の 80% は列だけで決まる。
- 遮断が勝ち負けを決める問題だけに絞ると、判断のほとんどは同じ定員の同色車の使い分けになり、出庫指令型と同じ型になる。
- #727 への提案は「乗客列型は不採用」。駐車場を読む判断に絞ると出庫指令型と変わらず、固有の要素を残すと列を読むゲームになる。

## ルールと計算

- 車の出庫は出庫指令型と同じ。出庫した車は待機枠に入る。乗客の列の先頭の色と一致する待機車に1人が乗り、車は長さと同じ人数（2人か3人）が乗ると出発する。待機車が枠数に達すると次の出庫ができない。
- 待機車に何人乗っているかが状態に加わるので、出庫指令型のように車の残存集合だけでは状態が決まらない。残っている車の集合と、色ごとの待機車の長さを到着順に並べたもので状態を表す。
- この計算は、待機列を順序つきで持つ別実装の全探索と照合してテストにしている。比較試作画面のルールとも、無作為な40問の解の数と初手の勝ち負け、問題例4問の解の数が一致した。

## 判断の出どころ

読み手は、乗客の列の先頭を1人以上進める出庫の集合から、自然な計画を1つ選ぶ。勝ち筋の上で、自然な計画の中に負けるものがある局面を判断局面とする。負ける計画を次のように分ける。

| 分類 | 決め方 |
| --- | --- |
| 遮断が決める | 負ける計画を選んだ後の局面を、全車がいつでも出せる盤面に置き換えると解ける |
| 列だけで決まる | 同じ置き換えをしても解けない |

2つの乱数種で 2000問ずつ、余裕0の問題を測った。遮断が決める判断の割合は 49% と 46% で、乱数種を変えても同程度だった。

| 条件 | 遮断が決める判断の割合 |
| --- | --- |
| 長さ2の車だけ | 93% |
| 長さ3の車だけ | 82% |
| 長さ2と3が半々 | 28% |
| 開口が隣り合う2辺 / 1辺 | 80% / 72% |
| 開口が4辺 | 36% |
| 開口が上下の2辺 | 10% |
| 列を可解な出庫順から作る | 28% |
| 列を無作為に作る | 74% |
| 2枠 / 3枠 / 4枠 | 26% / 69% / 78% |
| 8台 / 10台 / 12台 | 57% / 52% / 45% |

- 定員をそろえると、判断はほぼ遮断で決まる。このとき乗客列型は、1台に複数の指令が要る出庫指令型と同じ構造になる。
- 遮断を無くしても最小枠数が変わらない問題が 94% ある。枠がいくつ要るかは、列の並びでほぼ決まる。出庫指令型では、遮断を無くすと全問が待機なしで解ける。
- 自然な計画が1つしか無い局面（先頭の色の車を出すだけ）は、経路上の局面の 43% だった。

## 判断の種類

- 判断の 97% は、同色の別の車を使う選択である。掘る側の選択は 1.3%。同色の待機車にどちらが先に乗るかの判断は0件だった。
- 同色車の使い分けのうち、同じ定員どうしのものは 98% が遮断で決まる。定員が違うものは 80% が列だけで決まる（3502/4347）。
- 遮断が決める判断だけを持つ問題 587問では、判断の 94% が同色車の使い分けで、その 77% が同じ定員どうしだった。遮断を無くしても判断が残る問題は 5.6%。
- 理由 B（待機枠の圧迫）は、ほぼすべての負け筋に付く。出庫指令型で Lv3 と Lv4 を分けた「理由 B の有無」は使えない。

この分類は、遮断が選択肢を作っても「列だけで決まる」に数えることがある。掘る側の選択で、どちらの遮断車を待機させるかが列で決まる場合である（問題例の反例。全体の 1.2%）。

## 5段階と供給

遮断が決める判断だけを持つ問題を対象に、判断局面の数と距離で仮の5段階を置いた。基準としては成立しないと判断した。

- 判断の型が1種類で、理由 A・B でも分けられない。段階の差は、同じ判断の数と距離だけになる。
- 8台で最上位に当たる問題は 1/1271 で、上位の段階は台数に寄る。
- 埋まった同色車を掘る計画も選択肢に残す数え方に変えると、段階が変わる問題が 15〜44% ある。出庫指令型の 14〜28% より大きい。
- 余裕0の問題の 15〜21% は列だけで決まる判断を含み、対象から外れる。

供給そのものは詰まらない。遮断が決める判断を持つ問題は、列を無作為に作る生成で CPU 1分あたり 212〜228問（命中率 24%）出た。可解な出庫順から列を作る生成は、列だけで決まる判断を増やすので劣る。

## 読む量

負ける選択の帰結が、乗客の列の何人先に出るかを測った。

- 中央値は6人先、上位10%は11〜12人先。同じ色が続く区間を1つと数えると、中央値は4区間、上位10%は8区間。
- 8台・10台・12台（列は20・25・30人）で値は変わらない。遮断が決める判断と列だけで決まる判断でも同じ。
- 1つの判断に要る先読みは、区間で数えれば出庫指令型の指令数と同程度である。違いは、その先読みの約半分が駐車場を見ない列の読解であること。

## 問題例

`scripts/research/parking_jam_passenger_examples.json` に4問を置き、比較試作画面（`/puzzles/parking-jam/lab` の「乗客列＋待機枠」）に載せた。最初の判断局面は4問とも手で追った。

| 問題 | 内容 |
| --- | --- |
| 遮断が本質の判断 | 同色2台のうち定員3の車を使うと、残った定員2の車が別の色の車の出口を塞ぎ、12人目で詰む |
| 列だけで決まる判断 | 同色2台はどちらもすぐ出せる。定員3の車を使うと席が余って待機が続き、8人目で枠が溢れる。駐車場は関係しない |
| 両方を含む境界 | 1つ目の判断は遮断が決め、2つ目は列だけで決まる |
| 掘る側の選択が列で決まる反例 | 遮断が選択肢を作るが、勝ち負けは列で決まる |

## 確かめていないこと

- 人による試遊をしていない。列を目で追う負担、失敗の納得感、スマホ幅での読みやすさは分からない。
- 読み手は人の解き方のモデルである。判断の定義そのものが人の迷い方に合うかは確かめていない。
- 乗客の公開範囲を絞る、乗客を操作するなど、ルールを変えた案は試していない。
