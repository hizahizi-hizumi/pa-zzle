# 乗客列型：駐車場を読むパズルとして成立するかの検証（#739）

#727 の子 Issue #739 の検証資料。乗客列型が、駐車場の遮断を読むパズルとして成立するかを調べた。4方式の比較は[ゲーム性再設計.md](ゲーム性再設計.md)、同じ物差しで測った出庫指令型は[出庫指令型の供給検証.md](出庫指令型の供給検証.md)にある。用語（判断局面、理由 A・B、最小枠数、余裕、掘る、埋まった車）は出庫指令型の資料と同じ意味で使う。開口は、盤の辺のうち車が出られる辺を指す。正式なルール・難易度・問題集・記録は変更していない。

## 結論

- 乗客列型が駐車場を読むパズルになるかは、問題の作り方で決まる。条件を混ぜた無作為な問題では、判断局面の約半分が、駐車場を見なくても乗客の列と定員だけで決まる。定員2と3の車を混ぜ、列を無作為に作り、開口を隣り合う2辺か1辺に絞ると、判断局面の 83〜87% が車の遮断で決まる。
- その条件では、出庫指令型に無い判断がある。定員の違う同色車のどちらを使うかを、定員と遮断の両方から読む判断である。負ける選択肢の 24〜26% がこの型で、出庫指令型と同じ型（同じ定員の同色車の使い分け）は 35〜38% だった。
- この判断を、解く人が必ず通る問題は少ない。判断がすべて遮断で決まる問題（判断の無い問題を含む）のうち、どの勝ち筋でも通る問題は 5〜8% である。
- 5段階の基準は置けなかった。試した基準は、数え方を変えると多くの問題の段階が変わる。
- #727 への提案は「乗客列型は保留。出庫指令型の後に回す」。出庫指令型の弱点である判断の型の少なさを補う要素を持つが、段階の基準も試遊も無く、検証は出庫指令型より手前にある。

## ルールと計算

- 車の出庫は出庫指令型と同じ。出庫した車は待機枠に入る。乗客の列の先頭の色と一致する待機車に1人が乗り、車は長さと同じ人数（定員。2人か3人）が乗ると出発する。出庫後の待機車が枠数に達すると次の出庫ができない。
- 待機車に何人乗っているかが状態に加わる。残っている車の集合と、色ごとの待機車の長さを到着順に並べたもので状態を表す。
- 計算は、待機列を順序つきで持つ別実装の全探索と照合してテストにしている。経緯を知らない検証者が一から書いた実装でも、可解性・解の数・最小枠数・判断の集計に不一致は無かった（この実装はリポジトリに置いていない）。比較試作画面のルールとは、無作為な20問と問題例8問で、解の数と初手ごとの勝ち負けが一致する（`dispatch-levels.test.ts`）。

## 判断の出どころ

読み手は、乗客の列の先頭を1人以上進める出庫の集合（余計な車を含まないもの）から、自然な計画を1つ選ぶ。自然な計画は、出庫指令型と同じ2つ（同じ車をより少ない出庫で出せる計画がある、同色の車がすぐ出せるのに埋まった方を掘る）を除いたものである。勝ち筋の上で、自然な計画の中に負けるものがある局面を判断局面とする。負ける選択肢を次のように分ける。

| 分類 | 決め方 |
| --- | --- |
| 遮断が決める | 負ける計画を選んだ後の局面を、全車がいつでも出せる盤面に置き換えると解ける |
| 列だけで決まる | 同じ置き換えをしても解けない |

この決め方を別の5通り（置き換えを判断局面の前から行う、遮断を1台分だけ外す、など）に変えても、遮断が決める割合の変化は数ポイントだった。

問題の作り方ごとの結果（乱数種2つ、各400問、余裕0）:

| 問題の作り方 | 遮断が決める判断局面 | 判断局面の数（1問あたり） | 判断があり、すべて遮断で決まる問題 |
| --- | ---: | ---: | ---: |
| 条件を混ぜた無作為な問題 | 56%（乱数種で 48% と 68%） | 1.59 | 20% |
| 定員混在・無作為な列・隣り合う2辺 | 87% | 2.46 | 49% |
| 定員混在・無作為な列・1辺 | 83% | 2.98 | 45% |
| 定員混在・無作為な列・4辺 | 40% | 1.88 | 16% |
| 定員混在・可解な出庫順から作る列・4辺 | 11% | 3.65 | 4.3% |

- 条件を混ぜた問題の割合は、判断局面が極端に多い少数の問題に左右されて安定しない。2000問ずつの別の標本では 49% と 46% だった。
- 列を可解な出庫順から作ると、列だけで決まる判断が増える。開口が4辺や上下の2辺だと、遮断が少なく、列だけで決まる判断が増える。
- 以下、「定員混在・無作為な列・開口が隣り合う2辺か1辺」を有利な条件と呼ぶ。有利な条件でも、列だけで決まる選択肢が1割強残る。

## 判断の種類

有利な条件での、負ける選択肢の内訳（乱数種2つの合計）:

| 種類 | 隣り合う2辺 | 1辺 |
| --- | ---: | ---: |
| 同じ定員の同色車の使い分け（出庫指令型と同じ型） | 38% | 35% |
| 定員の違う同色車の使い分けで、定員と遮断の両方が効く | 24% | 26% |
| 定員の違う同色車の使い分けで、位置だけで決まる | 21% | 21% |
| 定員の違う同色車の使い分けで、列だけで決まる | 11% | 15% |
| 勝つ自然な計画が無い局面の選択肢 | 7% | 3% |

「定員と遮断の両方が効く」は、2台の定員だけを入れ替えた問題で、どちらかの選択の勝ち負けが変わるものとした。入れ替えても変わらないものが「位置だけで決まる」である。同じ定員の使い分けの行には、列だけで決まるものも含まれる。列だけで決まる選択肢の合計は、表の 11〜15% より多い。

- 定員と遮断の両方が効く選択肢 953件で定員を入れ替えると、どちらを選んでも勝てるようになるものが 62%、勝ち負けが逆転するものが 30%、どちらも負けるものが 8% だった。定員は、正解を入れ替えるより、罠を作る働きが多い。
- 掘る側の選択は0件、同色の待機車にどちらが先に乗るかの判断は1件だった。
- 理由 B（待機枠の圧迫）は、負ける選択肢の 98% に付く。出庫指令型で Lv3 と Lv4 を分けた「理由 B の有無」は使えない。

## 5段階と供給

有利な条件で、列だけで決まる判断を含まない問題（判断の無い問題を含む。1117問）を対象に、仮の5段階を置いた。判断局面を勝ち筋すべての合計で数えると、同等の筋が多い問題ほど増える。そこで、判断が最も少ない勝ち筋で通る判断の数を軸にした。台数は軸にしていない。

| 段階 | 条件 | 問題数 |
| --- | --- | ---: |
| 1 | 通る判断が0 | 852 |
| 2 | 1 | 143 |
| 3 | 2以上で、定員と遮断の両方が効く判断が無い | 47 |
| 4 | 定員と遮断の両方が効く判断が1つ | 63 |
| 5 | 定員と遮断の両方が効く判断が2つ以上、または1つで判断が3以上 | 12 |

この基準は成立しなかった。

- 埋まった同色車を掘る計画も選択肢に残す数え方に変えると、段階が変わる問題が段階1で 22%、段階2〜5で 46〜74% ある。判断が最も多い勝ち筋で数える変え方でも、段階1の 39%、段階2〜4の 13〜28% が変わる。
- 段階1の 73% は、先頭色の車が出せるなら出す解き方で負けることがある。運よく避けられる罠が、この軸に表れない。
- 定員と遮断の両方が効く判断を、どの勝ち筋でも通る問題は、8台で 8.4%、10台で 6.1%、12台で 5.0%。通る筋がある問題は 14%、24%、37%。

供給は、有利な条件で列を無作為に作る生成で測った（乱数種2つ。先頭色優先で必ず勝てる問題は除く。盤の対称と色の付け替え、遮断関係で同じになる問題は無かった）。

| 採用する問題 | CPU 1分あたり |
| --- | ---: |
| 判断があり、すべて遮断で決まる | 379 / 391 |
| そのうち、定員と遮断の両方が効く判断を持つ | 171 / 221 |
| 仮の段階4以上 | 52 / 45 |
| 仮の段階5 | 7.4 / 7.4 |

段階の基準が成立していないので、上位の段階が足りるかは分からない。

## 読む量

負ける選択の帰結が、乗客の列の何人先に出るかを有利な条件で測った。同じ色が続く区間を1つと数えた値も出した。

- 選択肢ごとに見ると、中央値は6人先（4〜5区間）、下位10%は2〜3人先、上位10%は12人先（9区間）。定員と遮断の両方が効く判断は、中央値が7人先（5〜6区間）。
- 問題ごとの最大で見ると、判断があり、すべて遮断で決まる問題の中央値は6人・4区間（隣り合う2辺の開口）。出庫指令型の採用問題では、問題ごとの距離の最大の中央値が Lv3 で3指令、Lv4 で4指令、Lv5 で5指令である。区間で数えれば同じ程度、人数で数えれば約1.5倍になる。区間と指令は同じ単位ではないので、大まかな比較である。

## #727 への提案

乗客列型は保留とし、出庫指令型の後に回す。

- 残す理由: 有利な条件では判断の大半が遮断で決まり、定員と遮断の両方を読む判断という、出庫指令型に無い型がある。遮断で決まる判断を持つ問題は多く作れる。
- 採用を提案しない理由:
  - 段階を作る物差しが無い。試した基準は数え方で段階が変わる。
  - 固有の判断を必ず通る問題は 5〜8%（判断のある問題に限ると約13%）で、多くの問題では運よく避けられる。
  - 有利な条件でも、列だけで決まる選択肢が1割強残る。これを含む問題を除く選抜が要る。
  - 人による試遊をしていない。乗客の列（8台で約20人、12台で約30人）を目で追う負担と、スマホ幅での読みやすさは分からない。
- 続けるなら要ること: 定員と遮断の両方を読む判断を必ず通る問題だけを作る生成、数え方を変えても動かない段階の軸、人による試遊。

## 確かめていないこと

- 読み手は人の解き方のモデルである。定員の入れ替えで分けた「定員と遮断の両方が効く」が、人の感じる「定員を読む」に合うかは確かめていない。
- 2台の定員を同じにする反実仮想は、色ごとの乗客数が変わるので試していない。
- 乗客の公開範囲を絞る、乗客を操作するなど、ルールを変えた案は試していない。

- `supply` は CPU 時間で区切るので、試行数は機械の速さで変わる。
