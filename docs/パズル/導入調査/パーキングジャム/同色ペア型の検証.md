# 同色ペア型：構造的な限界の検証（#740）

#727 の子 Issue #740 の検証資料。同色ペア型が「出せるペアを探す反復」を超えて、駐車場を読む判断を作れるかを調べた。4方式の比較は[ゲーム性再設計.md](ゲーム性再設計.md)、同じ物差しで測った出庫指令型は[出庫指令型の供給検証.md](出庫指令型の供給検証.md)にある。用語（理由 A・B、最小枠数、余裕、掘る）は出庫指令型の資料と同じ意味で使う。判断局面と距離の数え方は「計測」に書く。正式なルール・難易度・問題集・記録は変更していない。

## 結論

- 2枠の同色ペア型には判断が無い。ルールから導け、探索でも0件だった。
- 3枠・4枠が要る問題は無作為な問題の16%で、その中でも判断のある問題は数%〜1割である。判断は「どの色を先にそろえるか」だけで、負けの帰結は多くが1色の出発した直後に出る。
- 探索で登れば、判断局面が2〜3つある問題は作れる。ただし供給は出庫指令型の探索による生成の約10分の1で、判断の多くは同じ読みの繰り返しだった。
- ルールを変えた「同色4台のうち2台がそろうと出発」の案では、判断のある問題が増える。判断は出庫指令型と同じ「同色のどの車を使うか」になる。この案の探索と供給は測っていない。
- #727 への提案は「同色ペア型の基本ルールは不採用」。出庫指令型に対して、判断の量でも供給でも上回る点が見つからなかった。同色4台の案は、判断の型が出庫指令型と重なるので優先しない。Issue の方針に従い、生成器と5段階は作り込んでいない。

## ルールと計算

- 車の出庫は出庫指令型と同じ。各色ちょうど2台。出庫した車は待機枠に入り、同色の2台がそろうと2台とも出発する。出庫後の待機車が枠数に達すると次の出庫ができない。指令も乗客の列も無い。
- 待機しているのは、片方だけ出た色の車である。待機数と失敗は、残っている車の集合だけで決まる。
- 検証した盤面は、どの局面からも出庫できる車がある。詰みはすべて待機枠の溢れによる。
- この計算は、待機列を順序つきで持つ別実装の全探索と照合してテストにしている。比較試作画面のルールとも、無作為な40問で解の数と初手の勝ち負けが一致した（この照合はリポジトリに置いていない）。問題例4問の解の数の一致は `dispatch-levels.test.ts` で確かめている。

## なぜ判断が生じにくいか

ほかの色を待たせずに1色を片付ける手（以下、安全な手）は、負けにならない。待機中の色の相方を出す手と、枠に空きがあるときに2台を続けて出せる色を出す手がこれに当たる。勝つ手順の先頭へ移しても、手順は合法のままで待機数が増えないためである。

- 安全な手がある局面では、それを選べば判断を避けられる。判断を避けられないのは、安全な手が1つも無く、相方が埋まっている色に手を付けるしかない局面である。
- 2枠では、1台が待機している間は相方しか出せない。出せるのは続けて出せるペアだけで、どの順に出しても勝ち負けは変わらない。
- 遮断を無くした盤面では、溢れていない局面はすべて解ける。判断はすべて遮断から生じる。

## 計測

8台・10台・12台、開口4通り、各300問の 3600問（乱数種 740）。

- 最小枠数は、2が 83.6%、3が 15.8%、4が 0.6%。上下の2辺が開く盤面は全問が2で、4辺が開く盤面は3以上が 1.2% だった。3以上はほぼ隣り合う2辺と1辺の開口に限られる。
- 読み手は、1色の出発を1つの区切りとし、距離も出発した色の数で数える。各色を最少の出庫でそろえる計画を自然な計画とする。判断局面は、自然な計画の中に負けるものがあり、かつ安全な手が無い局面を数える。安全な手は常に負けないと遊ぶ人が分かっている、という前提を置いている。出庫指令型と同じく安全な手がある局面も数えると、3枠・余裕0で判断局面がある問題は 5.8% のまま、2つ以上ある問題は1問から16問（2.8%）に増える。

| 枠 / 余裕 | 判断局面がある問題 |
| --- | --- |
| 2 / 0 | 0%（3010問） |
| 3 / 0 | 5.8%（567問中33問。判断局面2つは1問） |
| 3 / 1 | 0% |
| 4 / 0 | 0%（23問） |
| 4 / 1 | 0.2% |

- 8台・余裕0の問題全体では、判断局面がある問題は 0.4%。出庫指令型は 20.2%。この標本には、判断が出ないと分かっている上下の2辺と4辺の開口が含まれる。3枠・余裕0に限ると、隣り合う2辺の開口で 8.2%、12台で 9.7% である。
- 負ける計画は、1色が出発した後に詰むものが 89%、2色の後が 11%。台数を14台まで増やし開口を絞った標本では、1色の後が 76% に下がる。
- 3枠・余裕0の判断はすべて待機0台の局面で起き、種類は全件が「どの色を先にそろえるか」だった。同色2台の使い分けは起こらない。2台とも出す必要があるためである。
- 負けた局面は全件、枠を1つ増やすと勝てる（理由 B）。遮断を無くせば必ず解けるので、理由 A は定義から全件に当たる。理由で段階を分けられない。
- 手の単位で見ると、選ぶと負ける手は多くの問題にある（3枠・余裕0で 92%）。その 85% は出した瞬間に詰む。残りの多くは、どの色をそろえる最少の計画にも入らない車を先に出す手で、自然な計画を選ぶ読み手は選ばない（残りの内訳はリポジトリに置いていない）。

## 深さの上限

探索で、判断局面の数と距離が大きくなる方へ登った。2通りの探索を試した。

| 探索 | 判断局面3つ以上に届いた試行 | CPU 1分あたり |
| --- | ---: | ---: |
| 無作為な問題から150歩登る（8〜12台と開口4通りに CPU を均等に配分、480秒、689回） | 1 | 0.125 |
| 判断局面のある問題を種にし、色と配置を同時に変える変異と悪化の受け入れを加える（360秒、24本） | 8 | 約1.3 |

- 1つ目の探索は、上下の2辺と4辺の開口にも CPU を割いている。この2つの開口では判断局面1にも届かず、数値を下げている。届いた問題はすべて12台・隣り合う2辺の開口だった。
- 1つ目の探索で、判断局面2以上かつ負けまでの出庫が3回以上に届いた試行は、CPU 1分あたり 1.75本だった。
- 2つ目の探索は検証者が試したもので、リポジトリに置いていない。
- 出庫指令型の探索による生成（G3）は、Lv4 で CPU 1分あたり 16〜21問、Lv5 で 11〜14問を出す。同色ペア型は約10分の1である。出庫指令型のレベルには待機枠の圧迫や素朴な解き方の条件があり、距離も指令の数で数えるので、厳密に同じ尺度ではない。
- 判断局面が3つある問題の多くは、負ける色が1色で、同じ読みを3回繰り返す。負ける色が3種類ある問題も少数あった。
- 判断は、色どうしの依存（ある色の車の進路を別の色の車が塞ぐ）に循環があり、連鎖が3色以上の問題にだけ出た。判断のある問題の割合は、連鎖3で 8.7%、4で 14.3%、5で 6.3% だった。
- 色の割り当てだけを変えても深くならない。10台の12盤面で色の割り当てを全通り試すと、最善でも判断局面は1つだった。

判断の型が1種類であることは、出庫指令型も同じである。同色ペア型が劣るのは、判断のある問題の少なさと供給である。

## ルールを変える案

| 案 | 結果 |
| --- | --- |
| 同色3台がそろうと出発 | 最小枠数は上がるが、判断局面がある問題は4枠・余裕0で 3.2%、判断はすべて1つ。判断は増えない |
| 同色4台のうち2台がそろうと出発 | 2枠・余裕0で 24.6% の問題に判断がある（8台 17.6%、12台 33%）。判断局面が4つある問題もある。負ける計画の 97% は、同じ色の別の2台を使う選択 |

試したのはこの2案だけである。2つ目の案は、判断のある問題の割合では出庫指令型に並ぶ。判断の型は出庫指令型の「同色2台の使い分け」と同じである。探索と供給は測っていない。この案では、安全な手が負けにならないことを証明しておらず、判断局面は近似で数えた。

出庫指令型は、同色ペア型から「どの色を先にそろえるか」の自由を指令で奪ったものに近い。同色ペア型では、安全な手があるかぎり判断を避けられる。

## 問題例

`scripts/research/parking_jam_pair_examples.json` に4問を置き、比較試作画面（`/puzzles/parking-jam/lab` の「同色ペア＋待機枠」）に載せた。説明は4問とも手で追って確かめた。

| 問題 | 内容 |
| --- | --- |
| 2枠：判断が無い | 出せるペアを順に出すだけで解ける。負ける手は出した瞬間に詰む |
| 3枠：負ける手は理由の無い保留だけ | 負ける手は、すぐ出せる車を早く出す1種類。自然な計画には判断が無い |
| 3枠：判断1つ（典型） | 初手で C を先にそろえると A の車が枠に残り、A の相方を掘る枠が足りない。D を先にすれば勝つ |
| 最も深い問題 | 12台・4枠。判断局面3つがどれも「D を先にそろえるか」 |

## 確かめていないこと

- 人による試遊をしていない。
- 計測は乱数種1つである。検証者が別の乱数種と条件で測った値は、この資料に書いた範囲で傾向が合った。
- 14台以上で多様性を保つ探索を作り込めば、供給が出庫指令型に近づく可能性は残る。遮断関係で見て異なる問題がどれだけ出るかは測っていない。
- 生成器の作り込みと5段階の基準は、見込みが薄いので作っていない。
