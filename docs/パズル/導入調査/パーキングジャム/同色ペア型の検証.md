# 同色ペア型：構造的な限界の検証（#740）

#727 の子 Issue #740 の検証資料。同色ペア型が「出せるペアを探す反復」を超えて、駐車場を読む判断を作れるかを調べた。4方式の比較は[ゲーム性再設計.md](ゲーム性再設計.md)、同じ物差しで測った出庫指令型は[出庫指令型の供給検証.md](出庫指令型の供給検証.md)にある。用語（判断局面、距離、理由 A・B、最小枠数、余裕、自然な計画、掘る）は出庫指令型の資料と同じ意味で使う。正式なルール・難易度・問題集・記録は変更していない。

## 結論

- 2枠の同色ペア型には判断が無い。ルールから導け、探索でも0件だった。
- 3枠・4枠でも、判断のある問題は無作為な問題のごく一部で、判断の型は「どの色を先にそろえるか」の1種類だけである。負けの帰結は、ほぼ1色が出発した直後に出る。
- 探索で登っても、出庫指令型の上位レベルに当たる複雑さにはほとんど届かない。判断局面が3つの問題は 689回の試行で1問で、その3つは同じ読みの繰り返しだった。
- 判断を増やす最小のルール差（同色4台のうち2台がそろうと出発）では、判断が出庫指令型と同じ「同色のどの車を使うか」になる。
- #727 への提案は「同色ペア型は不採用」。Issue の方針に従い、生成器と5段階は作り込んでいない。

## ルールと計算

- 車の出庫は出庫指令型と同じ。各色ちょうど2台。出庫した車は待機枠に入り、同色の2台がそろうと2台とも出発する。出庫後の待機車が枠数に達すると次の出庫ができない。指令も乗客の列も無い。
- 待機しているのは、片方だけ出た色の車である。待機数と失敗は、残っている車の集合だけで決まる。
- 検証した盤面は、どの局面からも出庫できる車がある。詰みはすべて待機枠の溢れによる。
- この計算は、待機列を順序つきで持つ別実装の全探索と照合してテストにしている。比較試作画面のルールとも、無作為な40問と問題例4問で、解の数と初手の勝ち負けが一致した（40問の照合はリポジトリに置いていない）。

## なぜ判断が生じにくいか

ほかの色を待たせずに1色を片付ける手は、負けにならない。待機中の色の相方を出す手と、2台を続けて出せる色を出す手がこれに当たる。勝つ手順の先頭へ移しても、手順は合法のままで待機数が増えないためである。

- 判断が生じうるのは、そうした手が1つも無く、相方が埋まっている色に手を付けるしかない局面だけになる。
- 2枠では、1台が待機している間は相方しか出せない。出せるのは続けて出せるペアだけで、どの順に出しても勝ち負けは変わらない。
- 遮断を無くした盤面では、溢れていない局面はすべて解ける。判断はすべて遮断から生じる。

## 計測

8台・10台・12台、開口4通り、各300問の 3600問（乱数種 740）。

- 最小枠数は、2が 83.6%、3が 15.9%、4が 0.6%。上下の2辺が開く盤面は全問が2で、4辺が開く盤面は3以上が 1.2% だった。3以上はほぼ隣り合う2辺と1辺の開口に限られる。
- 読み手は、1色の出発を1つの区切りとし、各色を最少の出庫でそろえる計画を自然な計画とする。

| 枠 / 余裕 | 判断局面がある問題 |
| --- | --- |
| 2 / 0 | 0%（3010問） |
| 3 / 0 | 5.8%（567問中33問。判断局面2つは1問） |
| 3 / 1 | 0% |
| 4 / 0 | 0%（23問） |
| 4 / 1 | 0.2% |

- 8台・余裕0の問題全体では、判断局面がある問題は 0.4%。出庫指令型は 20.2%。
- 負ける計画は、1色が出発した後に詰むものが 89%、2色の後が 11%。
- 判断はすべて待機0台の局面で起き、種類は全件が「どの色を先にそろえるか」だった。同色2台の使い分けは起こらない。2台とも出す必要があるためである。
- 負けた局面は全件、枠を1つ増やすと勝てる。全件が理由 A と B の両方に当たり、理由で段階を分けられない。
- 手の単位で見ると、選ぶと負ける手は多くの問題にある（3枠・余裕0で 92%）。その 85% は出した瞬間に詰み、残りは出す理由の無い車を先に出して枠を埋める手である。自然な計画を選ぶ読み手は選ばない。

## 深さの上限

色の入れ替えと車の置き直しで、判断局面の数と距離が大きくなる方へ登った（最小枠数3〜4、余裕0、CPU 480秒、689回）。

| 到達した水準 | 件数 | CPU 1分あたり |
| --- | ---: | ---: |
| 判断局面1以上 | 328 | 41 |
| 判断局面2以上で、負けが出庫3手以上後に出る | 14 | 1.75 |
| 判断局面3以上 | 1 | 0.125 |

- 下の2行はすべて12台・隣り合う2辺の開口だった。上下の2辺と4辺の開口では、判断局面1にも届かなかった。
- 出庫指令型の探索による生成は、Lv4 で CPU 1分あたり 16〜21問、Lv5 で 11〜14問を出す。
- 判断局面が3つの1問は、3つとも「D を先にそろえない」という同じ読みだった。
- 判断は、色どうしの依存（ある色の車の進路を別の色の車が塞ぐ）に循環があり、連鎖が3色以上の問題にだけ出た。

## ルールを変える案

| 案 | 結果 |
| --- | --- |
| 同色3台がそろうと出発 | 最小枠数は上がるが、判断局面がある問題は4枠・余裕0で 3.2%、判断はすべて1つ。判断は増えない |
| 同色4台のうち2台がそろうと出発 | 2枠・余裕0で 24.6% の問題に判断がある。負ける計画の 97% は、同じ色の別の2台を使う選択 |

2つ目の案の判断は、出庫指令型の「同色2台の使い分け」と同じ型である。この案では、ほかの色を待たせない手が負けにならないことを証明しておらず、判断局面は近似で数えた。

出庫指令型は、同色ペア型から「どの色を先にそろえるか」の自由を指令で奪ったものに近い。同色ペア型では、ほかの色を待たせない手が常に安全なので、自由があるかぎり判断が生じない。

## 問題例

`scripts/research/parking_jam_pair_examples.json` に4問を置き、比較試作画面（`/puzzles/parking-jam/lab` の「同色ペア＋待機枠」）に載せた。説明は4問とも手で追って確かめた。

| 問題 | 内容 |
| --- | --- |
| 2枠：判断が無い | 出せるペアを順に出すだけで解ける。負ける手は出した瞬間に詰む |
| 3枠：負ける手は理由の無い保留だけ | 負ける手は、すぐ出せる車を早く出す1種類。自然な計画には判断が無い |
| 3枠：判断1つ（典型） | 初手で C を先にそろえると A の車が枠に残り、A の相方を掘る枠が足りない。D を先にすれば勝つ |
| 最も深い問題 | 12台・4枠。判断局面3つがどれも「D を先にそろえるか」 |

## 確かめていないこと

- 人による試遊をしていない。
- 計測は乱数種1つである。
- 生成器の作り込みと5段階の基準は、見込みが薄いので作っていない。
