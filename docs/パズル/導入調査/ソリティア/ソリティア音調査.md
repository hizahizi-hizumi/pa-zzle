# ソリティア 調査: 音

## 結論

合意した前提（札をタップで選んで置き先をタップ・山札は裏向きで1枚ずつ何周でも・待ったと盤面を戻す・詰んだら知らせる）のもとで、音の決まりはどれも当てはめられる。成り立たない前提は無い。

- **どの操作の瞬間に何を返すか: 成り立つ。** `DESIGN.md`「音」の決まりだけで、どの操作に鳴らし、どれに鳴らさないかが決まる。鳴らすのは、列へ置く・組札へ運ぶ・山札をめくる・山札を戻す（捨て札を山札へ返す）・置けない・クリアの6つ。鳴らさないのは、札を選ぶ・選び直す・選ぶのをやめる、待った、盤面を戻す、詰んだ知らせ。鳴らす瞬間は、札や束が動き終えて着いた時を基本にし、めくるだけは札が返り始めた時にする（下の表）。
- **題材のどの素材から作るか: 条件つきで成り立つ。** 素材は札（板紙）と卓の2つに絞り、6つの音をそれぞれ札の動き（置く・揃える・返す・束ねる・戻る）から作れる。ただ、紙の擦れと当たりを合成して本物らしく聞こえるかは確かめていない。詰将棋では、合成した駒音に本物らしさが足りず、CC0 の録音へ切り替えた前例がある。札の CC0 の録音が手に入るかも、この環境の外へ出られず確かめられなかった。録音にするか合成にするかは、sound の項目で聞き比べて決める。
- **既存ゲームの効果音の本数と合計の大きさ: 測った。** 11ゲームの本数は3〜14本（中央9本）、合計の大きさは17.7〜148.9KB（中央21.9KB）。アプリの共通の音7本（135.9KB）を合わせると、タイトルで読み込む FLAC は106本・631.3KB。このうち98.4KB は音の入っていない PADDING のブロックで、ブリッジの10本と氷の床迷路の2本に付いている。
- **このゲームの目安: 条件つきで成り立つ。** 目安は、12本以下、PADDING 無しで合計40KB以下。足しても全体は約+6%で、4秒で全部を読み込むのに要る下りの帯域は1263kbps から約1343kbps になる（算術の試算）。ただし、クリア演出の形が決まらないとクリアの本数は決まらない。紙の音はほかの音より圧縮が効きにくいことも見込んでいる。
- **置く・めくる・組札へ運ぶ・置けない・山札を戻す・クリアのどれに付けるか: 6つ全部に付ける。** 置けないの音には条件が2つある。置けなかったことを動きで見せること（今の見本は文で知らせている）。採点の観点が置けないをミスに数えないこと。ミスに数えるなら、置けないの音は不成立より一段重い音にする。

## 事実と推測

- [事実] アプリは、`./**/*.flac` を `import.meta.glob` で集めた効果音を、タイトルですべて読み込む。読み込みは4000ms で打ち切り、間に合わなかった音はその後も鳴らさない: `frontend/src/frontend.tsx`、`frontend/src/lib/app-launch.ts`、`docs/プロダクト/仕様/SPEC-005-アプリの入口.md`、ADR-0011
- [事実] FLAC は小さくても JS に埋め込まず、1本ずつ別のファイルとして取りに行く: `frontend/vite.config.ts`（`assetsInlineLimit`）
- [事実] ゲームの効果音は題材から作り、FLAC で `assets/` に置き、`playSound` で鳴らす。音の中身を実行時に合成しない。回数の多い操作の音には `REPEATED_SOUND_VARIATION`（±30セント・±12%）を渡す。盤面操作の音は `useOperationSound`、クリア音は `useClearSound` で鳴らす。報酬の音・選ぶ音・始める音・BGM はアプリが鳴らす。動きを減らす設定では、動きが無く画面が変わらない操作の音を鳴らさない: `.claude/rules/game-structure.md`「効果音」、`frontend/src/games/play-sound-effects.ts`、`frontend/src/lib/audio/sound-effects.ts`
- [事実] 書き出しのスクリプトは `scripts/assets/<ゲーム ID>_sounds.ts` に置く。音は Chromium の `OfflineAudioContext` で描き、ffmpeg で FLAC にする。録音を素材にするときは出典とライセンスを書き出し先に残す: `.claude/skills/add-puzzle/references/build-order.md`（sound の行）
- [事実] 詰将棋は、合成した駒音に重厚感と本物らしさが出なかったため、CC0 1.0 の録音（VCSL）を加工した音に切り替えた: `docs/パズル/導入調査/詰将棋/詰将棋名称・権利調査.md` 53行、`frontend/src/games/tsume-shogi/assets/sounds/VCSL.CC0.txt`。ほかの10ゲームの `assets/sounds/` には出典のファイルが無い。ブリッジと氷の床迷路のスクリプトは録音を使わないと書いており（`scripts/assets/`）、一筆パズルは `OfflineAudioContext` で合成した（ハミルトン路実装前提調査 825行）
- [事実] 同じ1回の操作で多く動いて見えるほど音を厚くする前例がある。マインスイーパーは、一度に開いたマスの数（1・2・6・16以上）で音の粒を1〜4個重ねる: `frontend/src/games/minesweeper/ui/use-minesweeper-sound-effects.ts`。1本の音を `playbackRate` で高さを変えて鳴らす前例もある: `frontend/src/app/game-home/GameHomeScreen/zukan-stamp-sound.ts`、氷の床迷路
- [事実] 道の長さで音の高さを上げる案は、進み具合を音で知らせることになり、長い道で機械的に上がり続けるので採らなかった。行き止まり・取り残しには別の音を付けなかった: `docs/パズル/導入調査/ハミルトン路/ハミルトン路実装前提調査.md` 653行
- [事実] 同じ音を録り直した複数のテイクから、直前と違う1本を選んで鳴らす仕組みは、詰将棋のゲームの中にだけある（`frontend/src/games/tsume-shogi/ui/sound-takes.ts`）。別のゲームの実装は import しない（`game-structure.md`「依存方向」）
- [事実] 認識合わせの見本では、選んでいる札があるときに置けない所を押すと、選ぶのをやめて「そこには置けません。」と文で出す。別の札を押すと選び直し、同じ札を押すと選ぶのをやめる。山札も捨て札も無いときに山札を押すと、選ぶのをやめるだけ: 認識合わせのページ（https://claude.ai/artifact/DcWR4AFeZdEHRBFXCFooCf 、Version 2）のスクリプト
- [事実] PADDING のブロックを外す処理は、詰将棋のスクリプトにはある（`without_padding`）。ブリッジのスクリプトには無い。氷の床迷路の `ice_floor_maze_glide_sounds.py` は「PADDING なし」と書いているが外していない（ffmpeg の `-map_metadata -1 -bitexact` だけ）: `scripts/assets/`
- [推測] 紙の擦れと当たりは、PADDING を除いて1秒あたり約28〜31KB になる（雑音のように圧縮が効きにくい音）。氷の床迷路の `slid`（約27KB/秒）・`snow-pushed`（約31KB/秒）、詰将棋の録音の駒音（約28KB/秒）から割り出した。音の高さがはっきりした音は約15〜23KB/秒（タクズ・ナンプレ）。書き出した音で確かめられる
- [推測] 目安の見積もり: 操作の音を各0.06〜0.08秒・不成立と山札を戻すを0.12〜0.18秒にすると、操作の音7本で約23KB。クリアを2本（組札が順に照る音1本を `playbackRate` で4回、仕上げ0.7秒）にすると約18KB。合わせて約41KB・9〜10本。クリアを組札ごとに4本書き出すと13本・50KB 台になる
- [推測] 素朴な解き方は L1 の解き方に近い。人が解くと、山札をめくる回数（確かめるために回る）と、待ったの後の手で、回数はこれより増える。めくるが速く続く操作の速さ（間隔）は測っていない
- [推測] 終盤の「組札へ運ぶだけが続く」手（中央19手）は、遊ぶ人にとって考えることの無い連打になりうる。自動で運ぶ演出を置くかは play-ui と採点で決めること。置くなら DESIGN.md 199行の「まとめて見せる演出」として、1回ずつではなく重さに応じて強めて鳴らし、飛ばせるようにする（186行）

## 仮決定の候補

- **鳴らす操作**: [推奨] 列へ置く・組札へ運ぶ・山札をめくる・山札を戻す・置けない・クリアの6つに鳴らし、選ぶ操作・待った・盤面を戻す・詰んだ知らせには鳴らさない / [理由] DESIGN.md「効果音を鳴らすとき」をそのまま当てはめた結果。めくると山札を戻すは山札を使う中心の操作の成立で、前進に当たる。詰んだ知らせは表示され続ける状態で、知らせのために音を変えると先の展開を音で伝えることになる / [比べた案] 山札を戻すを鳴らさない（画面は変わるのに手応えが無い）。詰んだ知らせに柔らかい音を付ける（一筆パズルで採らなかった。音を聞いてから盤面を見直す癖を作る） / [覆したときに作り直す範囲] 鳴らす音の振り分け（効果音のフック）と、書き出す本数
- **列へ置く音と組札へ運ぶ音を分けるか**: [推奨] 分ける。列へ置くは重なった列に軽く置く柔らかい「ぱさっ」。組札へ運ぶは揃った札の山にぴたりと載る、立ち上がりの鋭い明るい「ぱちっ」。組札から列へ戻す手は、置いた先で決めて列へ置く音にする / [理由] 置き先が見て分かるほど違う。組札はクリアへの前進で、手応えを分けられる。同じ瞬間の見た目と同じ意味の範囲に収まる / [比べた案] 1つの置く音にまとめる（本数は1本減るが、1局の4割を占める組札へ運ぶ手応えが列の並べ替えと同じになる）。組札の音の高さを札の数字で上げる（進み具合を音で知らせることになり、終盤に最長45回続けて機械的に上がる。一筆パズルで採らなかった案と同じ） / [覆したときに作り直す範囲] 音の定義の2本と振り分け
- **2枚以上をまとめて動かしたとき**: [推奨] 1枚と2枚以上の2段にする。2枚以上のときは、列へ置く音の前に、束がずれて擦れる小さな層（1本）を重ねる / [理由] 束が動くのは見て分かり、見た目と同じ意味の範囲で厚くできる（マインスイーパーの前例）。1局で中央9回と少なく、層は1本で済む / [比べた案] 枚数によらず同じ音（いちばん簡単。12枚の束も1枚と同じ手応えになる）。枚数に比例して層を増やす（本数が増え、長い束で機械的に聞こえる） / [覆したときに作り直す範囲] 層の1本と振り分け
- **繰り返しの扱い**: [推奨] どの操作の音も1本と `REPEATED_SOUND_VARIATION` を基本にし、組札へ運ぶ音だけテイクを2本にする。テイクを選ぶ仕組みはソリティアの `ui/` に置く（詰将棋から import しない）。録音を素材にするなら、めくるも2本にする / [理由] スライドパズル・ナンプレ・タクズは、回数の多い操作の音を1本と揺らぎで鳴らしている。組札へ運ぶ音だけは、終盤に中央22回・最長45回続けて鳴る（計測） / [比べた案] 全部の操作の音を2〜3テイクにする（本数が13〜15本になり、目安を超える）。テイクを選ぶ仕組みを共通の `lib/audio` へ移す（アプリの変更になるので、2つ目のゲームが要るときに決める） / [覆したときに作り直す範囲] テイクの本数と選ぶ仕組み
- **置けないの扱い**: [推奨] 不成立として、責めない短い音を鳴らす。札が置き先に当たって元の場所へ戻る動き（play-ui で作る）に合わせ、高い音を落とした鈍い小さな当たりを2回鳴らす。動きを減らす設定で動きが無ければ鳴らさない / [理由] 置けない所を押すのは読み違いではなく操作の誤りで、ルールが受け付けないだけ。前例は一筆パズル・氷の床迷路の「責めない鈍い2回」とウォーターソートの `invalid` / [比べた案] 採点で置けないをミスに数えるなら、不成立より一段重い音にする（DESIGN.md 211行）。鳴らさない（文で出しても、ほかの不成立と手応えが揃わない） / [覆したときに作り直す範囲] 1本の定義。決めるのは採点の観点

## 確かめていないこと

- 音を聞いていない: この調査では音を作らず、聞いてもいない。紙の音が本物らしく聞こえるか、めくるが続いてうるさくないか、組札へ運ぶ音が続いて機械的に聞こえないかは、sound の項目と試遊で聞いて確かめる。
- 札の CC0 の録音が手に入るか: この環境からは、VCSL のファイル一覧（GitHub API が403）も、ほかの素材の配布ページ（プロキシが403）も見られなかった。VCSL は楽器の録音集なので札の音は無いだろうと推測している（未確認）。
- 読み込みにかかる実際の時間: 帯域の値は算術の試算で、往復の時間・同時に取りに行く本数・ブラウザでのデコードの時間は測っていない。106本を1本ずつ取りに行くので、大きさだけでなく本数も効く可能性がある。
- 人が遊んだときの操作の回数と速さ: 素朴な解き方と DFS で数えた値で、人のプレイ記録ではない。めくるが速く続くときの間隔も測っていない。
- ドラッグで動かすか: 見本はタップで選んで、タップで置く。ドラッグも受け付けるなら、持ち上げるのは選ぶ操作として鳴らさず、離して着いた時に置く音、戻った時に置けないの音を鳴らす（推測。play-ui で決める）。
- 自動で組札へ運ぶか、完成演出の形、置けないときの動き: play-ui と採点で決まる。クリアの本数と、置けないの音を鳴らすかはこれに従う。
- 範囲外の気づき: ブリッジの10本と氷の床迷路の2本に付いている PADDING（98.4KB、タイトルで読み込む全体の15.6%）は、外しても音は変わらない。ソリティアで足す分より大きい。ソリティアの作業の範囲外なので、この調査では扱わない。
