# 箱入り娘 調査: 難易度

## 結論

- **合意した前提は成り立つ。** 4×5 の盤だけで、駒の組（空き2〜6）を変えて5段階を分けられ、合意の易しい例（最短13手）はレベル1、横刀立馬（最短81手）はレベル5 に入る。
- **挑戦の定義: 成り立つ。** 「娘を出口へ通す道を空けるために、娘を動かせないあいだに、ほかの駒をどこへどの順でよけるか（ときに娘自身をいったん出口から遠ざけるか）を先に読む」。最短手数（作業の量）は分類に使わず、短すぎ（7手以下）・長すぎ（91手以上）を切る下限と上限にだけ使う。
- **つまみの案を広げて比べ、案 E に決めた: 成り立つ。** 準備の長さ（最短解のうち、娘を動かさずに続ける手の最長）の帯でレベルを決め、娘の遠回り（娘を出口から遠ざける手の数）と空きの数は、レベルごとに許す範囲として確かめる。上限（L5 の最短手数の中央値 79、横刀立馬を含む）、隣のレベルの分かれ方（3系統とも 10/50/90 パーセンタイルの逆転なし。最短手数をそろえた層の中でもレベルが分かれる）、素朴な解き方（L5 は 1000 手以内に解けたのが 0.8〜1.7%）、数え方の変種（道筋の選び方で変わるのは 0.9%）、収率で、5案のうち最もよかった。2番手は C（準備の長さだけ）で、L5 に短い問題が混ざり、素朴な解き方で 19% 解けた点で負けた。
- **各レベルを利用者向けの一言で言えるか: 成り立つ。** 1「数手よけるだけで道が開く」、2「娘を一度わきへよけてから通す」、3「娘を動かせない手が続き、1〜2回よけながら入れ替えを読む」、4「娘を何度も遠回りさせ、長い入れ替えを組む」、5「横刀立馬のように長い入れ替えを読み切る」。
- **図鑑の数百問: 条件つきで成り立つ。** L1〜L4 は近い問題を除いても 2,700 問以上（下限）。L5 は近い問題を除くと約 380 問が上限で、その 6 割強が1つの駒の組（縦3・横2・小4）から来る。L5 を数百問にするなら、駒の組の偏りを受け入れることになる。

## 事実と推測

- [事実] 盤は 4×5 固定、1手は同じ駒の連続移動、正しい手・残り手数は出さない、待っても手数は減らない、天井は横刀立馬くらい: `導入調査 Issue #600 の合意節`
- [事実] 手数・盤面サイズなどの作業量・複雑さはそれ自体では難易度ではない: `docs/パズル/難易度.md`「挑戦ではない負担を難易度にしない」
- [事実] 状態名は `classified`・`out-of-range`・`unsupported`・`invalid`、範囲外の理由は `unlisted-combination`: `.claude/rules/game-structure.md`「難易度」
- [事実] 先例のブロック脱出の調査は最短手数を主軸にし、準備の手数などを補助に記録する方式を挙げている: `docs/パズル/導入調査/ブロック脱出/ブロック脱出調査.md`。スライドパズルは最短手数でなく遠回り手数を主軸にした: `docs/パズル/導入調査/スライドパズル/スライドパズル難易度.md`
- [事実・導出] 隣り合う2つの局面の最短手数の差は1以下なので、誘いに乗った1手の損は、戻せば2手で済む。誘いの局面の数（案 D）が読みの量を表す根拠は弱い。
- [事実・導出] 全局面を BFS で数え切れるので、評価不能（`unsupported`）は起こらない。
- [事実（計測）] 最短40手以上の局面は、駒の組ごとに1〜2個の連結成分にしか現れない。L5 は同じ成分の中の別の開始局面を採ることになり、近い問題を除く規則が要る。
- [推測] 準備の長さは「盤面に進み具合が見えないまま頭の中でつなぐ区間」で、人の先読みの長さに対応する。人の試遊で確かめる。
- [推測] 上ほど1手の候補が少ない（初手の合法手の中央値 L1 8 → L5 3）。「選べる手が少ないので易しい」と感じられる恐れがある。人の試遊で確かめる。
- [推測] 誘いの局面が空きの多い盤ほど多いのは、娘を動かせる手が多いから。

## 仮決定の候補

- つまみ: **案 E（準備の長さの帯 × 娘の遠回りの範囲 × 空きの範囲）** / 横刀立馬を L5 に含み、L5 の帯がそろい、素朴な解き方でほぼ解けず、最短手数を使わずに分かれる / 比べた案: A 最短手数、B 遠回り、C 準備の長さだけ（2番手）、D 誘いの局面 / 覆したら作り直すのは `problem/difficulty-analysis.ts`・`difficulty.ts`・問題集・採点の基準時間・図鑑の枠。
- 基準表の暫定値: 準備 0〜4 / 5〜7 / 8〜11 / 12〜16 / 17以上、遠回り 0〜1 / 1 / 1〜2 / 2〜3 / 3以上、空き 4〜6 / 3〜6 / 2〜4 / 2〜3 / 2 / L2 の遠回りを「ちょうど1」にすると L1 と L2 の違いが「娘を一度よける」になる（0〜1 を許すと、遠回りの中央値も空きも同じになった） / 比べた値: L2 の遠回り 0〜1（E0） / 覆したら作り直すのは基準表と問題集。
- 特徴の定義: 遠回りは娘の左上と (3,1) のマンハッタン距離が増える手、準備の長さは娘のどの向きの手でも区切る。どちらも最短解の中の最小 / 定義の選び方でレベルが3〜6割変わるので、SPEC に定義を書いて固定する。上へ戻る手だけを数えると横刀立馬の遠回りが0回になる / 比べた案: 上へ戻る手だけ、近づく手だけで区切る / 覆したら作り直すのは分析と問題集。
- 提供範囲: 最短 8〜90 手 / 90 は合意の天井（横刀立馬81）の少し上で、91〜138 手を切る / 比べた値: 下限10、上限なし / 覆したら作り直すのは L1 と L5 の問題集。
- 候補空間: 66 の駒の組（空き2〜6、長い駒4〜6本、小駒0〜6。実装で 82 組に広げた）の置き方の全数を数え、左右反転を除き、近い問題（4手以内、最短解の祖先・子孫）を除いて採る / 全数でも Python 4並列で1〜2分 / 比べた案: 無作為な置き方 / 覆したら作り直すのは生成スクリプトと問題集。
- L5 の供給: 約 380 問を上限として、駒の組の偏り（6 割強が縦3・横2・小4）を受け入れる / 均等に巡回すると数十問になる / 比べた案: L5 の遠回りを2以上に緩める（近い問題を除いて 1,637 問、一時スクリプトで計測。ただし L4 と遠回りの範囲が重なる）、L5 の空きを2〜3にする（399 問でほぼ増えない） / 覆したら作り直すのは L5 の基準表と図鑑の枠。図鑑の件数は図鑑の観点で決める。

## 確かめていないこと

- 人と AI の試遊: していない。境界の対（難易度の資料の下書き §7）で、遠回り1回の差・準備の長さの差が手応えの差になるかを確かめる必要がある。
- 人の手筋（定石）: 攻略記事・文献から集める調べをしていない（Web を調べていない）。分析が表現しない手筋で、上のレベルが浅く解けないかは分からない（F1）。
- 1手の数え方の変種（まっすぐな移動だけを1手にする等）: 合意で決まっているので測っていない。
- 候補空間の外の駒の組（長い駒3本以下、小駒7以上、長い駒7本）: 数えていない。L5 の供給が増えるかは分からない。
- 問題集の大きさと TS での生成時間（E4）: 問題集を作っていないので測っていない。
- 誘いの深さ（近づく手を続けて深くはまる罠）: 1手の誘いだけを測り、複数手の罠は測っていない。
- 80手前後をスマホで最後まで遊べるか: スマホの観点に任せた。
