# 箱入り娘成績評価

箱入り娘の1プレイを100点満点で評価し、評価段階（`perfect` / `great` / `good` / `clear`）と自己ベストの比較へつなげるための検討記録。

この文書は資料で、正本ではない。
- 評価規則（称えるもの・配点・基準時間に使う量・待ったと盤面を戻すの扱い）は、[SPEC-028](../../../プロダクト/仕様/パズル/SPEC-028.md) の「評価」へ移した。
- 係数は SPEC に書かず、コード（`frontend/src/games/hakoiri-musume/score.ts`）を正とする。代表の値は `score.test.ts` で固定する。

根拠の見出し語: **計測（問題集）**（問題集 2,200 問の特徴から計算した。一時スクリプト）、**導出**、**推測**（係数・参照モデル・プレイヤー像はすべてここ）。**実プレイでは何も確かめていない。**

## 1. 前提として守ること

| 出どころ | 内容 |
|---|---|
| 合意 | 点数は手数の少なさが中心で、速さも見る。最短の手数は解いた後に見せる。「1手戻す」「最初から」で手数は減らさない |
| `SPEC-006` | 難易度は問題の性質、成績は起きた事実、評価は事実の意味として分ける。100点で `perfect`、90以上 `great`、80以上 `good` |
| 失敗パターン集（スコア・結果） | 事実の表から始める。二重減点にしない。基準時間はレベルではなく問題の作業の量から。評価値は保存しない |

## 2. 良いプレイ

> よける駒と順を先に読み、最短の手数で娘を出口へ運ぶこと。速く読めればなお良い。

- 1手は「どの駒をどこへよけるか」の判断で、読まずに動かした手（試し）はそのまま手数に表れる。
- 待ったで戻しても、取り消した手は手数に残る。待ったを使った総当たりでは手数の点が上がらない。

## 3. 事実の表

| 事実 | 意味 | 扱い | 理由 |
|---|---|---|---|
| 指した手の数 `moveCount` | 同じ駒の連続移動を1手。待ったで取り消した手と盤面を戻す前の手も含む | **使う**（効率） | 読みの確かさが最も直接に出る |
| 経過時間 `elapsedMs` | 開始からクリアまで。盤面を戻しても引き継ぐ | **使う**（速さ） | 合意の「速さも見る」 |
| 待った `undoCount` | 待ったの回数 | 記録だけ（内訳に出す） | 取り消した手は手数に、かかった時間は経過時間に入っている。別に減点すると二重減点 |
| 盤面を戻す `restartCount` | 始めの盤面に戻した回数 | 記録だけ | 同上 |
| 最短手数 `optimalMoveCount`（問題の量） | 問題集が持つ | **使う**（効率の基準・基準時間） | 作業の量 |
| 準備の長さ `preparationLength`（問題の量） | 問題集が持つ（難易度の分析と同じ量） | **使う**（基準時間） | 娘を進められないあいだに読む量。最短手数が同じでも、読む時間が違う |
| 娘の遠回り・空き・初手の数 | 難易度の分析の量 | 使わない | 読む時間への効き方を測れていない。準備の長さと強く相関する（順位相関 0.87） |
| 駒を動かした回数（1マスごと）・なぞりの長さ | 操作の量 | 使わない | 1手の中の動きは操作の手間で、読みの出来ではない |

## 4. 評価式

| 観点 | 満点 | 規則 |
|---|---:|---|
| 効率 | 70 | 手数が最短以下で満点。それより多ければ `70 × (最短 + 5) ÷ (手数 + 5)`。最短の2倍に5手足した手数で35点 |
| 速さ | 30 | 基準時間以内で満点。超過に応じて線形に減らし、基準時間の3倍で0点（2倍で半分残る。§5.4） |

```
基準時間 = 10秒 + 2.5秒 × 最短手数 + 2.5秒 × 準備の長さ（1秒未満は切り上げる）
```

- 切り上げるのは、係数の 2.5 秒で基準時間に 0.5 秒の端数が出て、結果画面の基準時間が読みにくいため。切り上げで遊ぶ人が不利になることはない。
- 採点の内訳では、準備の長さを「よける順を読む」手数と呼び、「自分の手順の数ではなく問題の値で、この問題を解くのに、娘を出口へ近づけられない手が最低でも続く長さ」と1文で添える。自分が指した手順から数えた手数と読み違えないため（自分の手順で数えると合わない）。

この式から言えること（導出。`score.test.ts` で固定）:
- `perfect` は、最短手数で基準時間以内にクリアしたときだけ。
- 待った・盤面を戻すを使っても、同じ手数と時間なら同じ点。
- 素朴な解き方（試して進む）は、最短の3倍以内に解けることがほぼ無く（難易度の資料 §8）、3倍の手数での効率は 70 × (最短+5) ÷ (3 × 最短 + 5) で 30点前後。`clear` を超えない。

## 5. 基準時間

### 5.1 案の比較（計測（問題集）、一時スクリプト）

1問ずつ所要時間を見積もる参照モデルを置いた（推測）: 盤面を見る 8秒 + 1.5秒 × 最短手数（操作）+ 3秒 × 準備の長さ（娘を進められないあいだの読み）。見たいのは絶対値ではなく、同じ腕前の人がどのレベルでも同じくらいの速さの点を取れるか。

| 案 | 式（秒） | 基準時間 ÷ 参照モデル（中央値、L1〜L5） | 参照モデルの1.3倍で解く人の速さの点（中央値） |
|---|---|---|---|
| T1（前の版） | 15 + 4 × 最短 | 1.62 / 1.34 / 1.26 / 1.17 / 1.15 | 30 / 30 / 29.0 / 26.8 / 26.1 |
| T3 | 10 + 2 × 最短 + 3 × 準備 | 1.21 / 1.17 / 1.16 / 1.15 / 1.14 | 27.6 / 26.7 / 26.3 / 26.0 / 25.9 |
| **T6（採用）** | **10 + 2.5 × 最短 + 2.5 × 準備** | 1.29 / 1.24 / 1.21 / 1.19 / 1.18 | 29.8 / 28.4 / 27.9 / 27.3 / 27.1 |
| T5 | 10 + 3 × 最短 + 1 × 準備 | 1.28 / 1.15 / 1.10 / 1.05 / 1.04 | 29.4 / 26.0 / 24.6 / 23.0 / 22.5 |

参照モデルの係数を1つずつ変えた4通り（操作 1秒・2秒（読み 3秒）、読み 2秒・4秒（操作 1.5秒））でも比べた。レベルごとの中央値の比の幅は次のとおりで、T3・T6 は 1.0 を大きく下回るレベルが無い。
- T3: 0.97〜1.41
- T6: 1.00〜1.52
- T1: 0.97〜1.88

- T1 を採らない: L4・L5 で基準時間が参照モデルを下回り、同じ腕前の人の速さの点が L5 で 19 点に下がる。「高いレベルを選んだだけで点が下がる」規則になる。
- T6 を採る（T3 と僅差）:
  - T3 は準備の長さの項が基準時間の過半を占める（L4・L5 の中央値で 47〜49%）。準備の長さは解法器が数えた量で、1つの項に寄せすぎると、その量の誤差がそのまま点に出る（失敗パターン「解法器の回数をそのまま時間にする」）。
  - T6 では準備の項は 17〜44%（各レベルの 10〜90 パーセンタイル）。
  - 同じ腕前の人の速さの点は L2〜L5 で 26〜28 点にそろう。L1 は 30 点近くで甘いが、短い問題は効率（1手の超過が大きく響く）で差がつく。
- 注意: 参照モデルは「準備の長さが長いほど読みに時間がかかる」と仮定しており、T6 がよく合うのはその仮定のもとでの確かめにすぎない。

### 5.2 レベルごとの基準時間（計測（問題集）。最小 / 10 / 50 / 90 / 最大、秒）

| L1 | L2 | L3 | L4 | L5 |
|---|---|---|---|---|
| 35 / 38 / 48 / 63 / 75 | 65 / 70 / 88 / 115 / 145 | 100 / 108 / 130 / 160 / 190 | 135 / 143 / 163 / 193 / 215 | 173 / 183 / 255 / 330 / 423 |

- L5 の基準時間は L4 の長い問題とほぼ同じか長い。L5 の10パーセンタイル（183秒）は L4 の90パーセンタイル（193秒）とほぼ同じで、中央値（255秒）は L4 の最大（215秒）より長い。問題集の採り方で L4 の最短手数を L5 の中央値未満に絞った（`箱入り娘難易度.md` §13「問題の質と選び方」）。
- T1 では L5 の10パーセンタイル（167秒）が L4 の中央値（159秒）とほぼ同じで、L4 の長い問題（90パーセンタイル 207秒）より短い。

### 5.3 ほかのゲームとの厳しさの比べ（導出。各ゲームの `score.ts` の式から計算した。人の記録では確かめていない）

初見の L3〜L5 を、最短の 1.3 倍・2 倍の手数と、基準時間の 1.3 倍・2 倍の時間で解いたときの点。手数で評価する近いゲームと比べた。

| ゲーム（配点 効率 / 速さ、手数のゆとり） | 1.3 倍で解いた点 | 2 倍で解いた点 |
|---|---|---|
| 箱入り娘（70 / 30、5手。L3 の中央値 最短30手） | 56 + 21 = 77 | 38 + 0 = 38 |
| 箱入り娘（同。L5 の中央値 最短60手） | 55 + 21 = 76 | 36 + 0 = 36 |
| スライドパズル（60 / 40、ゆとり無し） | 46 + 28 = 74 | 30 + 0 = 30 |
| 氷の床迷路（60 / 40、10手。最短15手） | 51 + 28 = 79 | 38 + 0 = 38 |

- 速さが0点になる倍率（基準時間の2倍）は4つとも同じ（この比べの後、箱入り娘は3倍に変えた。§5.4）。効率の比の形も同じ系統（最短 ÷ 手数に、ゆとりを足すかどうか）。
- 箱入り娘だけが厳しいということはない（1.3 倍で 74〜79 点、2 倍で 30〜38 点の中にある）。係数と手数のゆとりは変えない。
- 残る点: 「初見で最短の 1.3 倍・基準の 1.3 倍」が箱入り娘の初見として妥当かは、人の記録が無いので分からない（推測）。人の記録での校正は人間に残す（§9 の 2）。

### 5.4 速さが0点になる倍率（決めたこと。導出。人の記録では確かめていない）

基準時間の2倍で0点にしていたが、L4・L5 の速さの点が実質とれなかった（L5 の基準時間の中央値 250秒に対し、通しで遊んだ人の最長は 6分20秒）。
同じ理由（先を読む時間が読みの当たり外れでぶれる）で3倍にしているゲームと、手を動かす量で時間が決まり2倍にしているゲームに分かれている。

| ゲーム | 0点の倍率 | 時間を決めるもの | 基準の 1.3 倍で残る速さ | 2 倍で残る速さ |
|---|---|---|---|---|
| 詰将棋・一筆書き・リフレクション | 3倍 | 先を読む・試す時間（読みの当たり外れでぶれる） | 85% | 50% |
| スライドパズル・氷の床迷路・パーキングジャム・ウォーターソート・バイナリパズル・マインスイーパー | 2倍 | 手を動かす量 | 70% | 0% |
| 箱入り娘（変えた後） | 3倍 | 準備の長さ（よける順を先に読む時間）と最短手数 | 85% | 50% |

- 箱入り娘の挑戦は「よける駒と順を先に読む」ことで（SPEC-028）、先を読むゲームの組に入る。準備の長い問題ほど読みの当たり外れで時間がぶれる。
- L4・L5 だけを3倍にする案は採らない。難易度そのものを基準時間の理由にしない（SPEC-028）ためで、ぶれの大きさは準備の長さで基準時間にすでに表れている。
  レベルによらず3倍にすると、L1 で時間をかけた初めての人の点も残る（L1 の8手を1分13秒で解いて 67点だったのが約 80点になる。導出）。
- 3倍にした後の §5.3 の比べ: 箱入り娘の初見（1.3 倍の手数・時間）は L3 56 + 26 = 82点・L5 55 + 26 = 81点、2倍は L3 38 + 15 = 53点・L5 36 + 15 = 51点。
  効率の配点が70点あるので、2倍の時間でも速さが評価を逆転させることはない。
- 人の記録での校正は人間に残す（推測。§9 の 2）。

## 6. 遊び直し（覚えた解をなぞる2回目）

計算（推測。1回目は基準時間の1.1倍の時間で、最短の3割増しの手数。2回目は覚えた最短解を1手1.5秒＋5秒でなぞる。速さは基準時間の3倍で0点）:

| 問題 | 1回目 | 2回目 |
|---|---|---|
| L3 の代表 `8qh42n6jd5`（29 / 17、基準 125秒） | 38手・138秒 → 効率 55 + 速さ 28 = 83（`good`） | 29手・49秒 → 100（`perfect`） |
| L5 の代表 `aa81cuoiqc`（56 / 35、基準 238秒） | 73手・262秒 → 効率 55 + 速さ 28 = 83（`good`） | 56手・89秒 → 100（`perfect`） |

扱い（仮決定）: 2回目の `perfect` をそのまま認める。
- このゲームの挑戦は「よける順を読むこと」で、読み切った解をなぞれることも、その問題を解き切った結果と見る。
- 記録だけからは「覚えてなぞった」と「初めて読み切った」を分けられない。
- 図鑑の出来は最高の記録で見せるので、遊び直すと出来が上がる。

最終レビューの遊び直しのカードで、人がこれを納得するかを確かめる。別案は次のとおり。
- 同じ問題の2回目以降を自己ベストに入れない。
- 2回目以降の速さを0点にする。

どちらも共通の記録の仕組みに手を入れる。

## 7. 記録と自己ベスト

- 記録には事実だけを保存する。保存するのは、経過時間・手数・待った・盤面を戻すの回数と、問題の作業の量（最短手数・準備の長さ）。評価値・基準時間・基準との差は保存せず、今の規則で導く（`play-record.ts`）。
- 準備の長さも記録に残すので、問題集から外れた記録でも基準時間を求め直せる。
- 自己ベストはレベルごと（SPEC-002 の比較単位）に、点・基準時間との差・最短との手数の差で比べる。
- 結果画面と記録画面の比べる値（点・基準時間との差・手数の差）は、`createHakoiriMusumeResult` と `play-record.ts` の指標が同じ `score.ts` の関数から求める。

## 8. 抜け道（確かめたこと）

- 待った・盤面を戻す: 手数も時間も減らない（導出、`session.test.ts`）。
- 「…」メニューのリセット: 手数と時間が0に戻る。試してからリセットすると、減点の事実が消える（山場2の AI の試遊）。共通のプレイ画面の決まりで、最終レビューで人間に聞く（作業カード 05 の「直さないもの」）。
