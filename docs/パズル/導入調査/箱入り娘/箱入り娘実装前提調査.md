## 根拠の書き分け

- 事実: リポジトリの決まり・コード・前例から読めること。
- 計測: 上の調査コードで測ったこと。どれも標準ライブラリだけ・seed 固定で、採った案の結果は同名の `.expected.json` にある（音・導入判断は案を採る測定が無いので無い）。
- 推測: 計測や前例から推したこと。人や実機で確かめていない。
- AI判断（仮決定）: 合意した意図の範囲で AI が決めたこと。「仮決定一覧」に理由・比べた案・覆したときに作り直す範囲を書く。

## 認識合わせの合意

認識合わせのページ（https://claude.ai/artifact/EZZjQ3TAhTubk5yRu9HQyo）を人間が見て「OK。イメージどおり。」と返した。全文は Issue #600 の合意節。

- 4×5 の盤。駒は娘（2×2）・縦長（縦2マス）・横長（横2マス）・小駒（1マス）。出口は下辺の真ん中2マス。
- 駒をなぞって空きマスへすべらせる。なぞったまま角を曲がってよく、同じ駒の連続した移動は何マス・何回曲がっても1手。
- 娘が出口の前（娘の左上が下から2段目・左から2列目）に着けばクリア。どの道順でもよい。
- 核: 娘を通す道を作るために、どの駒をどこへどの順でよけるかを先に読む。
- 5段階。どのレベルも 4×5。易しいほど駒が少なく空きが多く、上ほど詰まって長い。最上位は横刀立馬（最短81手）くらいまで。
- 正しい手・残り手数は出さない。待った（1手戻す）と盤面を戻す（最初から）があり、戻しても手数は減らさない。点数は手数の少なさが中心で速さも見る。最短手数は解いた後に見せる。
- スライドパズル・パーキングジャム・ブロック脱出（候補）とは別のゲーム。表示名は「箱入り娘」で、使ってよいかは最終レビューで人間が確かめる。

## 成立性

| 観点 | 判定 | 要点 |
|---|---|---|
| 問題供給 | 成り立つ | 駒の組ごとに、出口に着いた状態を含む連結成分を BFS で全部たどれる（空き2〜5の全組で最大83万状態・62秒。計測）。1つの問題集を Python 1プロセスで約5分。2,300問で JSON 64 KB（gzip 15 KB）。手はどれも1手で戻せるので、遊んでいる途中で解けなくならない（計測: 全状態で確認） |
| 難易度 | 成り立つ | 5案を全数（61組・4,087,078状態）で比べ、案 E（準備の長さで分け、娘の遠回りと空きをレベルごとの範囲で確かめる）に決めた。合意の易しい例は L1、横刀立馬は L5。L5 は素朴な解き方で1000手以内に 0.8〜1.7% しか解けない。最短手数をそろえた層の中でもレベルが分かれる（計測） |
| 図鑑と問題の特徴 | 条件つきで成り立つ | 横長の数・小駒の数・娘の下の段数の3つ。レベルの中で値が分かれ、互いに重ならず（\|ρ\| ≤ 0.53）、最短手数の写しにならない（\|ρ\| ≤ 0.37）。計測は仮のレベル分けで、案 E のレベルで測り直していない |
| 音 | 成り立つ | 駒がマスを移るたびの短いすべり音と、クリア音。不成立音は置かない。6〜9本・合計 30 KB 以下（既存ゲームの中央値 8.5本・21.0 KB。計測） |
| スマホ操作 | 条件つきで成り立つ | 幅320pxで1マス 67〜74px（計算）。盤面と全操作は既存の `GamePlayFrame` に収まる（事実）。なぞりの競合はハミルトン路と同じ止め方で避ける。iPhone 実機は未確認 |
| 導入判断 | 成り立つ | 近いゲームとルールが違う（横刀立馬は、数え方で 81 / 90（一直線を1手）/ 116（1マスを1手）手と変わり、曲がる手が効く。計測）。表示名「箱入り娘」は商標を確かめていないので、公開前に人間が J-PlatPat で確かめる条件つき |

台帳の値: 問題供給 通過、難易度運用 確認中、スマホプレイ 確認中、導入判断 条件付き保留（正式採用は spec の層のマージで決まる）。

## 確かめていないこと

- 人と AI の試遊。レベルごとの体験差、80手前後をスマホで遊び切ってもらえるか、L5 の問題（6割強が1つの駒の組から来る）が人に同じ問題に見えないか、上のレベルほど1手の候補が少ない（初手の合法手の中央値 L1 8 → L5 3）ことが易しく感じられないか。
- iPhone 実機でのなぞりとスクロール・端のジェスチャー・長押し。ブラウザで描いたマスの実寸。
- 図鑑の特徴を案 E のレベル分けで測り直すこと（difficulty・problem-pool の後、問題集で確かめる）。
- レベルをまたいだ近さ（下のレベルの問題が上のレベルの問題の解く途中の盤面になっている組）。
- 商標の登録（「箱入り娘」「はこいり娘」「Klotski」「華容道」）。
- 素材に使える CC0 の木のこすれ・すべりの録音があるか。実機で1マスごとの音がうるさくないか。LUFS での大きさ。
- TypeScript での生成時間。
