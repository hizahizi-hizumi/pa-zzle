根拠の見出し語:

- **計測（問題集）**: 問題集の生成スクリプト `bun run --cwd frontend generate:hakoiri-musume-pool`（seed `20261104`）の統計の出力と、`-- --verify` で測った結果。

## 2. 挑戦と基準とするプレイ条件

- **挑戦の1文**: 娘を出口へ通す道を空けるために、娘を動かせないあいだに、ほかの駒をどこへどの順でよけるか（ときに娘自身をいったん出口から遠ざけるか）を先に読む。
- **基準とするプレイ条件**: ルールとなぞる操作を知っている。正しい手・残りの手数は見えない。待ったと最初からは使えるが、手数は減らない。時間制限は無い。速さは難易度に入れない（採点の責務）。
- **分析が表現する解法過程の範囲**: 最短解が要求する「先読みの区間の長さ」（準備の長さ）と「見た目の進み具合に逆らう判断の回数」（娘の遠回り）だけ。人が使う定石（小駒2つを横長の代わりに回す、娘の回り込みの型など）は分析に入れていない。外部の攻略・文献から手筋を集める調べはしていない（§13・確かめていないこと）。
- **挑戦に入れないもの**: 手数そのもの（作業の量）。最短手数は軽すぎ・長すぎを切る下限と上限にだけ使い、レベルの分類には使わない。
- 人は最短解で解かない。特徴は「最短で解こうとしたときに避けられない読み」で、人が実際に踏む手の数ではない。

## 3. 特徴

どれも、ゴールから全状態への多始点 BFS で最短手数を求め、最短解の DAG の上で「最短解の中の最小」をとる（最短解の選び方・探索順に依らない）。

| 特徴 | 意味 | 人の挑戦がなぜ変わるか | 扱い |
|---|---|---|---|
| 準備の長さ（`prep`） | 最短解の中で、娘を動かさずに続ける手の連続の最長 | 娘が動けないあいだは盤面に進み具合が見えず、その区間を頭の中でつなぐ読みが要る。長いほど見えない先を長く読む | **分類に使う（主）** |
| 娘の遠回り（`bmin`） | 最短解の中で、娘の左上と出口の位置のマンハッタン距離が増える手の数 | 娘を出口から遠ざけるのは見た目の進み具合に逆らう判断で、先の局面を読まないと選べない。回数が増えるほど計画を組み直す | **分類に使う（範囲）** |
| 空き（`e`） | 空きマスの数（= 16 − 2×(縦長+横長) − 小駒） | 空きが少ないほど、1つの駒を動かすために先に動かす駒の連鎖が長くなる | 分類に使う（規模として許す範囲） |
| 最短手数（`opt`） | 1手の定義での最短手数 | 作業の量。それ自体は挑戦ではない | 下限8・上限90 だけに使う |
| 誘いの局面（`lmin`） | 娘を出口へ近づける手があるのに、それが最短を縮めない局面の数 | 近づく手に誘われる回数。ただし誤った1手は戻せば2手の損で済む（隣り合う状態の最短手数の差は1以下。導出） | 記録だけ |
| 初手の合法手（`branch`）・最短の初手（`nopt`） | 1か所の重さ・入口の狭さ | 候補が多いほど1手ごとに比べる手が多い | 記録だけ |
| 娘の手の数（`dmv`） | 最短解で娘を動かす手の数（最小） | 区切りの数 | 記録だけ |

### レベルごとの基準表（暫定値）

準備の長さの帯で1つのレベルに決まり、空きと娘の遠回りはそのレベルで許す範囲として確かめる。

| レベル | 準備の長さ | 娘の遠回り | 空き | 利用者向けの一言 |
|---|---|---|---|---|
| 1 | 0〜4 | 0〜1 | 4〜6 | 空きが多く、娘はほぼまっすぐ出口へ向かう。数手よけるだけで道が開く |
| 2 | 5〜7 | 1 | 3〜6 | 娘を一度わきへよけてから通す。どの駒を先によけるかを数手先まで読む |
| 3 | 8〜11 | 1〜2 | 2〜4 | 空きが減り、娘を動かせない手が続く。娘を1〜2回よけながら、駒の入れ替えを先に読む |
| 4 | 12〜16 | 2〜3 | 2〜3 | 空きは2〜3マス。娘を何度も遠回りさせ、長い入れ替えを組んでから娘を動かす |
| 5 | 17 以上 | 3 以上 | 2 | 横刀立馬のように、空き2マスで娘を3回以上遠回りさせ、娘を動かせない長い入れ替えを読み切る |

組み方の理由:

- 上のレベルは、準備の長さ・娘の遠回り・空きのどの系統でも下げない（範囲の下限・上限が単調）。
- 空きの範囲は隣のレベルと重ね、同じ空きでも準備の長さと遠回りでレベルが分かれるようにした（§5 の同じ空きでの分かれ方）。
- レベル2 の遠回りを「ちょうど1回」にしたのは、レベル1 と2 を分けるため。0〜1 回を許す閾値（E0）では、レベル1 と2 の遠回りの中央値がどちらも0、最短手数の中央値も 10 と 14 で、空きも同じ 4 になり、違いが準備の長さ1〜3手だけになった（計測）。「娘を一度よける」をレベル2 の一言にできる。
- 横刀立馬（準備25・遠回り3・空き2・最短81）はレベル5、合意の易しい例（準備4・遠回り1・空き4・最短13）はレベル1 に入る（計測。期待値の `fixtures`）。

## 8. 素朴な解き方（D1）

- 解き方（`naive_play`）: 見えるのは盤面だけ。待ったは使わない。
  - `random`: 合法手を無作為に選ぶ。
  - `greedy`: まだ行っていない局面への手のうち、娘を出口へ近づける手があればそれを、無ければまだ行っていない局面への手を、それも無ければ合法手を無作為に選ぶ。
  - `explore`: まだ行っていない局面への手を無作為に、無ければ合法手を無作為に選ぶ（試して戻る代わり）。
- 打ち切り: 1000 手。1問 3 回ずつ。標本は駒の組・レベルごとに最大 8 問。

| レベル | 問題数 | 最短の3倍以内に解けた（random / greedy / explore） | 1000手以内に解けた（同） | 解けたときの手数 ÷ 最短の中央値（greedy） |
|---|---|---|---|---|
| 1 | 232 | 0.1% / 1.4% / 0.1% | 30.5% / 75.7% / 49.0% | 23 |
| 2 | 256 | 0% / 0.1% / 0.1% | 14.2% / 53.9% / 31.2% | 26 |
| 3 | 247 | 0% / 0.4% / 0% | 2.4% / 24.2% / 13.8% | 19 |
| 4 | 150 | 0% / 0% / 0% | 0.2% / 13.1% / 6.4% | 14 |
| 5 | 40 | 0% / 0% / 0% | 0% / 0.8% / 1.7% | 8 |

- 読み方: どのレベルも、素朴な解き方で最短の3倍以内に解けることはほぼ無い。1000手まで粘ると、L1 は greedy で 3/4 が解けるが、L5 は 1〜2% しか解けない。上のレベルほど解ける割合が下がる。
- 限界: 止める向きにだけ使う。解けないことは人に難しいことの根拠ではない。待ったを使う試し方（戻して別の手を試す）は `explore` で近似しただけ。
- 戻した回数: このゲームの「戻す」は逆向きの1手で、`explore` が行ったことのある局面へ戻るのがそれに当たる（数は出していない）。

## 12. SPEC の難易度の節の案

```markdown
## 難易度

- 基準とするプレイは、正しい手と残りの手数が見えない盤面で、待ったと最初からを使えるプレイとする。手数と速さは難易度に含めない。
- 挑戦は、娘を出口へ通す道を空けるために、娘を動かせないあいだに、ほかの駒をどこへどの順でよけるか（ときに娘をいったん出口から遠ざけるか）を先に読むこととする。
- 難易度は、準備の長さ（最短解のうち、娘を動かさずに続ける手の最長）、娘の遠回り（最短解のうち、娘を出口から遠ざける手の数）、規模（空きマスの数）の組で決める。どちらの量も、最短解が複数あるときは最も少ない解で数える。
- 最短手数は難易度に使わず、短すぎる問題と長すぎる問題を提供範囲から外すためにだけ使う。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 空きが多く、娘はほぼまっすぐ出口へ向かう。数手よけるだけで道が開く |
| 2 | 娘を一度わきへよけてから通す。どの駒を先によけるかを数手先まで読む |
| 3 | 空きが減り、娘を動かせない手が続く。娘を1〜2回よけながら駒の入れ替えを先に読む |
| 4 | 空きは2〜3マス。娘を何度も遠回りさせ、長い入れ替えを組んでから娘を動かす |
| 5 | 空きは2マス。横刀立馬のように、娘を何度も遠回りさせる長い入れ替えを読み切る（§4 の一言と、spec の項目で1つにそろえる） |

- 上の難易度は、どの観点でも下の難易度より弱くならない。
- 規模は各難易度で許す範囲として組み合わせ、規模だけで難易度は決めない。
- 盤面が小さく全局面を数え切れるので、評価できない問題は無い。娘が出口に着けない問題は成立しない問題とする。
```

- A を採らない: 最短手数だけで、作業の量で難しくする形（合意の補足と `難易度.md`）。L5 に遠回り0回・準備8手の問題が入る。
- B を採らない: 遠回りの回数の幅が 0〜5 しか無く、L5 が 1,481 候補・5 成分と細い。横刀立馬（遠回り3）が L4 になり、合意の天井と合わない。
- D を採らない: 誘いは空きが多い盤ほど多く、合意の易しい例（誘い4）がどのレベルにも入らない。1手の誤りは戻せば2手の損で済むので、誘いの数が読みの量を表す根拠が弱い。
- E0（E の閾値違い）を採らない: レベル1 と 2 の違いが準備の長さ1〜3手だけになる（§4）。

### 数え方の変種（A3、採った案 E、計測）

| 変種 | 変わった割合 | 2段以上の跳び | 範囲外へ |
|---|---|---|---|
| 遠回りを最短解の中の最大で数える | 0.9% | 0 | 0.9% |
| 遠回りを「娘が上へ戻る手」だけで数える | 30.4% | 0 | 30.4% |
| 準備の長さを「娘を出口へ近づける手」で区切る | 58.3% | 2.1% | 33.6% |
| 左右反転 | 0（特徴の不一致0） | — | — |

- 道筋の選び方への依存は小さい。
- 定義の選び方で大きく変わるので、SPEC に定義を書いて固定する。遠回りを「上へ戻る」だけにすると横刀立馬が遠回り0回になり（横へのよけを数えない）、挑戦の定義と合わない。準備の長さは娘の手ならどの向きでも区切る: 娘が動くこと自体が盤面に見える区切りで、近づく手だけで区切ると娘の横への動きが準備に混ざり遠回りと二重に数えるため。
