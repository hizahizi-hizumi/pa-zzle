根拠は次の見出し語で分ける。

- **計測**: [調査コード/shuttle-parking_difficulty.py](調査コード/shuttle-parking_difficulty.py) で測った値。乱数は文字列の seed で固定し、同じ入力で同じ結果になることを確かめた（§6）。
- **導出**: 定義から論理的に言えること。
- **推測**: 計測で確かめていない判断。

**人はまだ遊んでいない。** AI の試遊もしていない。各レベルの体験差は、読み手のモデルと「1手戻す人」の模擬で測った仮説である。§10 の試遊が済むまで、そう扱う。

## 2. 挑戦と基準とするプレイ条件

**挑戦の1文**: 乗客の列を先まで読み、いま出す車が何人先で待機枠をふさぐか（座席が余る・必要な車が出られなくなる）を見抜いて、出す車とその順番を決める。

挑戦に入れないもの:

- 列の長さ・車の台数・手数（作業量）。台数は8に固定し、レベルを分ける特徴に入れない（§5 で、レベルと列の長さに相関が無いことを確かめた）。
- 戻して試し直す量（罰と作業量）。「1手戻す」があれば、どの問題も試し置きで押し切れる（§8）。押し切りの扱いは採点の観点で決める。

基準とするプレイ条件: 列も盤面も全部見えていて、負けの知らせは無い。戻しは使わずに先を読んで解く人を基準にする（合意の「称えたい解き方の仮説」）。

分析が表現する解き方。2種類の読み手を置き、どちらも「h 人先まで見て、その範囲で詰みが見える手は避ける人」とする。

| 読み手 | 候補にする車 | 候補の中からの選び方 |
|---|---|---|
| 先頭に合わせる人 | 列の先頭の色の車がすぐ出せればそれ。出せなければ、先頭の色の車とそれを（間接的にも）塞ぐ車 | 固定した4つの規則のどれか1つ（下の表）。問題ごとに、最も浅い読みで済む規則の値を取る |
| 先回りする人 | 見えている h 人のうち、先頭から h' 人（h' は h 以下で自由に選べる）に出てくる色の車と、それを塞ぐ車 | 一様。h' の選び方は、勝率が最も高くなるもの |

どちらの読み手も、候補の中に勝てる手が無い局面では出せる車すべてに広げる。

**素朴な規則の組**（測る前に決めて固定した。後から都合のよい規則を足さない）。先頭の色の車がすぐ出せるとき、その中のどれを選ぶか:

| 規則 | 選び方 |
|---|---|
| どれでも | 先頭の色の車から無作為 |
| 定員の小さい順 | 定員2を先に |
| 定員の大きい順 | 定員3を先に |
| 塞ぎを解く | いま出られない車の進路の上にいる車（出すと他の車が開く見込みがある車）を先に、並べば定員の小さい車 |

先頭の色の車がすぐ出せなければ、どの規則も、塞ぎの最も少ない先頭色の車を掘る。待機枠がすぐ埋まる手は避ける。この規則だけで（先読みせずに）出す人の勝率を「規則の勝率」と呼ぶ。

言葉の定義（計測のコードと同じ）:

- **罠**: 読み手の候補のうち、そのあとどう続けても全員を送り出せない手。
- **罠の深さ**: 2つの取り方を持つ。
  - 最善の続き: 罠の手のあと、最善を尽くして乗れる人数（その時点の先頭から）。先を読める人が「ここまでは何とかなる」と見える範囲。
  - 気づかずに続けた場合: 罠の手のあと、先頭に合わせて出し続ける人（どれでもの規則）が詰むまでに乗せる人数の期待値。罠に気づかずに遊んだ人が、何人先で詰みに出会うか。
- **勝率の曲線 p(h)**: h 人先まで見える読み手が、深さが h 未満の罠を避け、残りの候補から上の選び方で選んだときの勝率。h について単調に増える（導出）。
- **h90 / h50**: p(h) が 0.9 / 0.5 に届く最小の h（何人先まで読めば、9割 / 半分勝てるか）。
- **深さの帯**: h90 が 0 / 1〜4 / 5〜7 / 8以上。
- **重なり**: h50 が 5 以上（5人先まで読んでも半分も勝てない）。

表現できない解き方: 数手まとめた計画を立ててから比べる読み方、同じ色の車のどちらを使うかを列の残りの人数から逆算する読み方などは、h 人先の詰みの見え方に置き換えて近似している。4つの規則に無い手がかり（盤面の形など）を使う人も表していない。これらがレベルの順を崩すかは、反例探し（A4）と人の試遊で確かめる。

## 3. 特徴

| 特徴 | 意味 | 扱い |
|---|---|---|
| 先頭に合わせる人の h90・h50（4つの規則のうち最小） | 規則の手がかりを使って先頭の客に合わせる人が、9割・半分勝つのに何人先まで読む必要があるか | 分類に使う |
| 先回りする人の h90・h50 | 先の客のために前もって車を出す人が、同じく何人先まで読む必要があるか | 分類に使う |
| 上の2つを、気づかずに続けた場合の深さで測り直したもの | 深さの取り方に依らないかを見る | 分類に使う（4つのレベルが一致すること） |
| 最も深い罠の帯 | その読み手が p(h)=1 になる最小の h の帯。h90 の帯より深ければ、まれな深い罠だけを持つ | 分類に使う（範囲外の判定） |
| 規則の勝率（4つ） | 読まずに規則で出す人が勝つ割合 | 分類に使う（Lv3 以上は4つとも 0.8 未満。Lv1・Lv2 は4つのどれかが 0 より大きい） |
| 待機枠を1つ増やした問題のレベル | 同じ盤面と列で枠を増やすと易しくなるはず | 分類に使う（増やした問題のレベルが元より高ければ、増やした問題を範囲外） |
| 列だけで決まる罠の有無 | 全部の車がいつでも出せる盤面に置き換えても負ける罠 | 記録だけ（§13.3） |
| 1手戻す人の戻し回数 | 先頭の色を優先して試す人と、無作為に試す人 | 記録だけ（レベルの順の確かめに使う。§8） |
| 待機枠の数・余裕、色の数、列の長さ、開口、盤面の大きさ | 生成条件 | 記録だけ |

## 4. 状態と分類

状態（`game-structure.md` の状態名に合わせる）:

- `invalid`: 全部の車を出せない、または待機枠が2〜4の範囲で解けない。
- `out-of-range`: 次のどれか。
  - 2人の読み手 × 深さの2つの取り方の4つのレベルが一致しない（`unlisted-combination`）。
  - どれかで、最も深い罠の帯が h90 の帯より深い（まれな深い罠）。
  - Lv3 以上で、規則の勝率のどれかが 0.8 以上。
  - Lv1・Lv2 で、規則の勝率が4つとも 0（先頭に合わせる遊び方では必ず詰む）。
  - 同じ盤面と列で待機枠を1つ少なくした問題より、高いレベルになる。
- `unsupported`: 使わない（全部見える完全情報の1人ゲームで、厳密探索がいつも終わる。8台では1候補 p95 0.036 秒）。
- `classified`: 下の基準表に当たる。

**レベルごとの基準表（検討時点の暫定値）**: 4つのそれぞれで下の表からレベルを出し、すべて同じときだけそのレベルにする。

| レベル | 深さの帯（h90） | 重なり（h50 ≥ 5） | 規則の勝率 |
|---|---|---|---|
| 1 | 0 | — | — |
| 2 | 1〜4 | — | 4つのどれかが 0 より大きい |
| 3 | 5〜7 | なし | 4つとも 0.8 未満 |
| 4 | 5〜7 | あり | 4つとも 0.8 未満 |
| 4 | 8 以上 | なし | 4つとも 0.8 未満 |
| 5 | 8 以上 | あり | 4つとも 0.8 未満 |

利用者向けの一言:

| レベル | 一言 | 合意で見せた一言からの変更 |
|---|---|---|
| 1 | 列の先頭に合う車を出していけば解ける | なし |
| 2 | 罠があり、結果は1〜4人先に出る。すぐ先を見れば避けられる | なし |
| 3 | 罠の結果が5〜7人先に出る。数台分先まで列を読む | なし |
| 4 | 罠の結果が8人以上先に出るか、5〜7人先の罠が重なる | 「8人以上先」だけだったものに「5〜7人先の罠が重なる」を足した |
| 5 | 深い罠が重なる。5人先まで読んでも半分も勝てない | なし |

組み方の理由:

- 境目の 1・5・8 と h50 の 5 は、合意で見せた一言から置いた（分位点ではない）。
- Lv4 の一言を変えた理由: 深さだけで Lv3 と Lv4 を分けると、規則の組を入れた後でも、1手戻す人の戻し回数で Lv3 の方が多くなる（無作為に取った Lv4 が Lv3 より多く戻す確率 0.45。案E では反例探しの役の計測で、Lv3 の方が多く戻す確率が 0.48〜0.60）。戻し回数は罠の深さより、罠に出会う回数（重なり）で増える（§13.1）。そこで、5〜7人先でも罠が重なる問題を Lv4 に上げた。上のレベルが深さも重なりも下げないように、8人以上先で重ならない問題は Lv4 に置いた（Lv3 に下げると、Lv3 の深さの90パーセンタイルが Lv4 を超える）。
- 2人の読み手と2つの深さの取り方が一致する問題だけを採るのは、遊び方（先頭に合わせる・前もって出す）と、罠に気づいた後の続け方（最善・素直に続ける）に依らないレベルにするため。
- 規則の組を前もって固定し、どれか1つで読む深さが浅く済むならその値を取るのは、盤面に見える手がかり（他の車を塞いでいる方を先に、など）を使えば読まずに避けられる罠を、深い罠に数えないため。
- Lv1 は罠が無いだけの手続きではない: 無作為に試す人は中央値で2回戻す（10〜90%: 0〜9回）。どの車を掘るかと、先頭に合わせるという判断は要る。

## 12. パズル仕様の難易度の節の案

- 挑戦: 乗客の列を先まで読み、いま出す車が何人先で待機枠をふさぐかを見抜いて、出す車と順番を決めること。
- 基準とするプレイ: 列と盤面が全部見え、負けの知らせは無い。戻さずに先を読む人を基準にする。
- 難易度に含めないもの: 列の長さ・台数・盤面の広さ・戻して試し直す量。
- 挑戦を強めるもの: 罠の結果が何人先に出るか（深さ）と、罠がいくつ重なるか。盤面に見える手がかりで読まずに避けられる罠は数えない。先頭に合わせて出す遊び方と前もって出す遊び方、罠に気づいた後の続け方のどれでも、同じレベルになる問題だけを提供する。
- 1〜5 の違い: §4 の一言。
- 提供範囲: 遊び方や続け方でレベルが食い違う問題、まれな深い罠だけを持つ問題、読まずに8割勝てる上位の問題、先頭に合わせる遊び方では必ず詰む低いレベルの問題、待機枠を増やすと上がる問題は提供しない。

特徴の計算・境目・分類条件はコードに置き、ここには書かない。

### 13.3 列だけで決まる罠

盤面に関係なく列と定員だけで決まる罠は、案F の Lv2〜Lv5 の 12〜40% の問題に含まれる。合意した核は「乗客の列の先を読む」ことで、列だけで決まる罠もその読みの一部なので、除かずに記録する（仮決定）。盤面を読む割合を増やしたいと人が判断したら、除く条件をレベルの基準表に足す。
