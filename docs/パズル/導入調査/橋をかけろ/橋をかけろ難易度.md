## 2. 挑戦と基準とするプレイ条件

### 2.1 挑戦

> 島の数字と、橋を架けられる行き先の数から「必ず架かる・架からない」を決めていき、数字だけでは決まらない所では、橋の組が閉じて孤立しないこと・全島が1つにつながることまで読んで決めること。

挑戦にしないもの: 盤面の広さ・島の数だけによる架ける回数の増加（単独ではレベルを決めない）、短いすき間の押しにくさ（スマホ操作の観点）、架け直し・戻すの回数と所要時間（プレイ成績）。

### 2.2 分析が表現できる解法過程

人間向け解法器（`problem/generation/human-solver.ts`）は、辺ごとの本数の範囲を数字と盤面だけから狭める。低い段から使い切り、止まった所（手詰まり）で次の段を使い、その段で言えることを盤面全体へ同時に当てる（適用の順に依らない。導出）。

| 段 | 名前 | 内容 |
| --- | --- | --- |
| A1 | ちょうど | 足りた島の残りの行き先は0本。相手の島の残りより多くは架けない。行き先ごとの上限の合計が数字と同じなら全部上限 |
| A2 | 少なくとも・多くとも | 他の行き先を上限まで使っても足りない分は、この行き先に要る |
| C1p | 2島で閉じない | 1と1をつながない、2と2を2本にしない |
| C1g | 3島以上の組で閉じない | 架けると全島ではない組の本数が全部足りて閉じるなら、その本数は架けない |
| C3 | 唯一の通り道 | この行き先が無いと、架けられる橋だけでは全島がつながらないなら1本は要る |
| D | 1手の先読み | 1手だけ仮に決め、両端の島が埋まった結果どこかが閉じる・孤立するなら、その手は無い |
| T | 試し置き | 1手を仮に決めて A1〜D で進めると矛盾する。推理の外として、提供しない問題を見分けるためにだけ使う |

- 交差は段ではなく、架かると決まった橋と交わる行き先を0本にする規則として常に当てる（合意 6 で盤面からも見える）。研究用の解法器にあった段 B（交差）は、最初に要る手詰まりが一度も無く（付録 A.2、導入調査 §4.3 の導出）、製品コードでは段にしていない。研究用の100盤面で段と回数が一致したので、外しても経過は変わらない（事実（実測）。下の移植の確かめ）。
- D は推理の範囲に含める（D-07）。人にとって推理か試し置きかは試遊で確かめる（§10）。

### 2.3 移植の確かめ（F2）

`scripts/research/bridges_parity_cases.py` が研究用の生成器で作った100盤面（6×6〜10×10、一意解46・解の無い盤面や複数ある盤面を含む。段 A1〜D・T をすべて含む）を、研究用の解法器で解いた答えとともに `problem/generation/research-solver-cases.json` に置き、製品コードと次が一致することをテストで固定した（事実（実測）、`exact-solver.test.ts`・`human-solver.test.ts`）。

- 完全解法器: 解の数（2まで）・探索した局面の数・打ち切りの有無。つながりを無視したときの解の数（20まで）と局面の数
- 人間向け解法器: 状態、手詰まりごとの段と狭めた辺の数、数字の読みだけで決まる割合、入口の辺の数

局面の数まで一致させたのは、打ち切りの上限（一意性 20万局面、つながりを無視 10万局面）が問題の採否を変えないことを保つため。上限は計算を止めるためのもので、人の能力ではない。研究用の240盤面でも一時スクリプトで不一致 0（事実（実測））。素朴な解き方は乱数列が研究用 Python と違うので値は一致しない。分布は §8 で研究用の値と並べた。

## 4. 状態と分類

### 4.1 状態

| 状態 | 条件 |
| --- | --- |
| 成立しない（`invalid`） | 解が無い、2つ以上ある、一意性の探索が上限に達した |
| 評価不能（`unsupported`） | 一意解だが、試し置きまで使っても決まらない |
| 提供範囲外（`out-of-range`）`requires-trial` | 推理（A1〜D）では決まらず試し置きが要る（合意 3） |
| 提供範囲外 `unlisted-combination` | 特徴と盤面の組み合わせがどのレベルにも当たらない（10×10 で数字だけで解ける、6×6 で A2 が要るなど） |
| 分類済み（`classified`） | いずれかのレベルの組み合わせに当たる。2つに当たれば高い方 |

### 4.2 レベルごとの基準表（検討時点の値。正はコード）

| レベル | 盤面 | A2 の手詰まり | つながりの手詰まり | 数字だけでは決まらない割合 | N2 戻し | 利用者向けの一言（案） |
| ---: | --- | --- | --- | --- | --- | --- |
| 1 | 6〜7 | 0 | 0 | 0 | 問わない | 数字と行き先の数を見るだけで、次々に決まる |
| 2 | 7〜8 | 1以上 | 0 | 0 | 問わない | 「少なくとも1本はここへ」と読む所がある |
| 3 | 8〜9 | 問わない | ちょうど1 | 0.5以下 | 問わない | 一か所、「つなぐと閉じて孤立する」読みが要る |
| 4 | 9〜10 | 問わない | 1以上 | 0.5より大 | 1以上 | 数字だけでは半分も決まらず、早くからつながりを読む |
| 5 | 10 | 問わない | 2以上 | 0.6より大 | 3以上 | 何度もつながりを読む。試しに架けて直す進め方では何度もやり直しになる |

組み方の理由:

- 導入調査の案 R（付録 A.4）をそのまま移した。「数字だけで決まる割合」の上限（L4 0.5 未満・L5 0.4 未満）を、上のレベルほど大きくなる「数字だけでは決まらない割合」の下限に言い換えた（同じ境界。`NumericRange` は下限だけを開区間にできるため）。
- 上のレベルは、盤面・つながり・数字だけでは決まらない割合・N2 戻しのどの下限も下げない（`difficulty.test.ts` で固定）。A2 の手詰まり回数はつながりを読まないレベル1・2 を分けるためだけに使う。L3 以上は上の段（つながり）が要る。
- 隣のレベルは盤面を1つ共有し（1/2 は 7、2/3 は 8、3/4 は 9、4/5 は 10）、共有する盤面では推論の特徴でだけ分かれる（§5 の B2）。
- 境界の値は分布の切れ目と一言から置いた暫定値で、人の試遊で確かめていない。

### 5.3 系統どうしの相関（B4、事実（実測）、`analyze:bridges`）

推理で解ける一意解の候補 6,300問で、盤面と島の数 0.92、盤面とつながり 0.28、盤面と決まらない割合 0.17、盤面と N2 戻し 0.29。推論の系統の中では、つながりと決まらない割合 0.88、つながりと N2 戻し 0.81、決まらない割合と N2 戻し 0.78。10×10 だけ（1,142問）では島の数とつながり 0.03。規模の系統と推論の系統はほぼ独立で、推論の系統の中の3つは強く関わる（研究用 Python §A.2.2 と同じ読み）。

## 6. 供給

### 6.1 生成の仕方

- 完成グラフ先行（D-02）: 島を1つ置き、既存の島から縦横に伸ばした先の空きマスへ島を足して橋を架けることを繰り返し、木を作る。島は既存の島の上下左右に置かない（D-04）。次に、まだ橋の無い島の組のうち既存の橋と交わらない組に輪の橋を足す。数字は出ている橋の本数（`problem/generation/island-tree.ts`）。研究用の `bridges_difficulty.py` の `generate` と同じ手順で、乱数列は製品の `createProblemSeededRandom` を使う。
- 生成条件（D-08）: 盤面の一辺 6〜10 × 島の密度 {0.24, 0.30} × 2本の割合 {0.1, 0.2, 0.3} × 輪の割合 {0, 0.15}。どれもレベルの判定には使わない。
- 採り方: レベルごとに、レベルの盤面の範囲に入る全生成条件（L1〜L4 は24条件、L5 は12条件）を巡回し、各条件で候補番号の順に次に当たる候補を1問ずつ採る。回転・反転（8通り）の正規化キーでレベルをまたいで重複を除く。

生成条件の値を選んだ理由（研究用の条件と比べた結果）:

- 2本の割合は研究用の main（0.3・0.5）と l5（0.1〜0.3）のうち 0.1〜0.3 にした。0.5 は 10×10 の L5 の収率が 0.2%（付録 A.4.4）で、L5 に入らない。0.1〜0.3 を巡回すると、各レベルの2本の割合の内訳が 168 / 166 / 166 にそろい、L5 が 0.1 に張り付かない（事実（実測）、`generate:bridges-pool`）。
- 島の密度は研究用の 0.18 を外した。島の数は伸ばせる所が尽きると目標に届かず（密度 0.30 では目標に対する島の数の中央値が 6×6 0.82・8×8 0.79・10×10 0.77 倍。一時スクリプト）、0.18 は L1 の盤面を疎にするだけになる（推測）。0.36 は 0.30 とほぼ同じ島の数になる（導入調査の l5）。
- 輪の割合は研究用の 0・0.15・0.3 のうち 0・0.15 にした。L5 の収率はどちらでも同じ桁（10×10・2本 0.1 で、密度 0.3 なら 30.0% / 18.0%、0.24 なら 18.0% / 23.3%。事実（実測）、`analyze:bridges`）で、輪のある盤面と無い盤面を混ぜるために両方を巡回する。0.3 は比べていない。

## 8. 素朴な解き方

`problem/generation/naive-solver.ts` の `tryBridgesNaively`。

- 解き方 N2: 数字の読み（A1・A2）で進め、止まったら未決の行き先を無作為に選んで本数を無作為に仮に決める。本数が破れたら戻す。全島がちょうどなのにつながっていなければ（盤面は全島が灰色なのにクリアにならない）戻す。交差する所には架けない（合意 6）。1問5回、1回2万局面で打ち切り。乱数は盤面の記法から決まり、同じ盤面では同じ結果になる。
- 慣れた試し置き: N2 のうち、未決の行き先が最も少ない島のまわりから試すもの（`most-constrained`）。分析スクリプトだけで測る。
- 補助: 合意どおり、島ごとの本数の知らせだけ。つながりの知らせは無い。

| レベル | N2 戻しの中央値（10 / 50 / 90） | 1度も戻さず解けた試行の割合（中央値） | 全島ちょうどで非連結（中央値） |
| --- | --- | --- | --- |
| 1・2 | 0 / 0 / 0 | 100% | 0 |
| 3 | 0 / 1 / 1 | 40% | 0 |
| 4 | 1 / 2 / 5 | 20% | 1 |
| 5 | 3 / 5 / 12 | 0% | 4 |

（事実（実測）、`analyze:bridges`。研究用 Python の §A.4.3 では L5 3 / 5 / 12、1回目で解けた割合 5%。）

読み方と限界: L4・L5 は戻し1回・3回以上を下限にしたので、試しに架けて直す進め方では押し切れない（定義から導出）。L1〜L3 は試しても解ける帯。N2 の戻しは人の手間（どこから直すかを探す、架け直す）を数えない。解けないことや戻しが多いことは、熟練者に難しいことの根拠にならない。5回の中央値なので、境界（L4 と L5 の 3）の近くでは乱数でレベルが動きうる（§7 の 10×10 の境界の対）。

## 12. SPEC の難易度の節の案

- 挑戦: 島の数字と行き先の数から「必ず架かる・架からない」を決め、数字だけでは決まらない所では、橋の組が閉じて孤立しないこと・全島が1つにつながることまで読んで決める。
- 基準とするプレイ: 島ごとの本数の知らせ（足りない・ちょうど・多すぎ）を見ながら、読んで決めてから架ける。橋の正誤とつながりは知らせない。待った・盤面を戻すの回数・架け直しは難易度に含めない。
- 分析が表現する推論: ちょうど・少なくとも（数字の読み）、2島・3島以上の組が閉じない、唯一の通り道、1手の先読み（つながりの読み）。試し置きは推理に含めない。
- 問題成立性: 一意解。交差しない。同じ2島の間は2本まで。全島が1つにつながる。島は上下左右に隣り合わない。
- つまみ: 盤面の広さ（上ほど広い盤面を許し、隣のレベルと1つ共有）、数字の読みで止まってつながりを読む回数、数字だけでは決まらない範囲の広さ、試しに架けて直す進め方での戻しの多さ（L4・L5 の下限）。
- レベルごとの一言: §4.2。
- 評価不能・提供範囲外: 試し置きが要る問題、どのレベルの組み合わせにも当たらない問題は出さない。
- 供給: 事前生成した問題集から出す。生成条件（島の密度・2本の割合・輪の割合）はレベルの判定に使わず、分析・分類した結果でレベルを決める。

## 14. 限界と未確定事項

- **L1 と L2 の差が小さい**: L2 の A2 の手詰まりは中央値1回で、違いは「少なくとも1本」を1回使うことと入口の広さ（中央値 0.67 → 0.43）。人には同じ手応えに見えうる（推測。B3 の懸念）。入口 ÷ 行き先の上限を L2 に足す案がある。試遊で確かめる。
- **L4 と L5 の境は N2 戻しの乱数に左右される**: 10×10 で推論の特徴がほぼ同じ問題が、N2 戻し（5回の中央値）の 2 と 5 で分かれる（§7 の境界の対）。戻しの中央値は試行の乱数で動くので、同じ盤面の同型どうしでもレベルが変わりうる（推測。A3 は回転・反転で測っていない）。
- **上位の天井**: L5 の中央値は、数字だけでは 83% が決まらず、つながりの手詰まり2回、N2 戻し5回。試し置きが要る問題を除いても 10×10 の候補の 1.2% ほどしか失わない（`analyze:bridges` の生成条件ごとの割合から、10×10 の候補 1,800 のうち約22）。天井を決めているのは 10×10 の上限と島の数（中央値 24）である（推測）。熟練者に足りるかは試遊でしか分からない。
- **つながりの知らせを足すと前提が変わる**: 全島ちょうどで非連結のときに知らせると、N2 の行き詰まりが早く見え、L4・L5 の押し切りにくさの下限を測り直す必要がある（ripple 段 1）。
- **解法器の独立した確かめ（F1）**: 作った本人以外による手追いをしていない。
- **縦長の盤面**: 比べていない（D-05 で入れない）。
- **島の配置の規則（D3）**: 生成器は対称などの規則を使わないので、規則の近道は無い（導出）。

### A.3 素朴な解き方

- **N1 局所の本数推論だけ**: A1・A2 だけで止まるまで進める。「数字だけで決まる割合」がその到達度。
- **N2 局所の本数推論＋試し置き**: A1・A2 で進め、止まったら未決の行き先を無作為に選んで本数を無作為に仮に決める。本数が破れたら戻す。全島がちょうどになってもつながっていなければ（盤面は全島が灰色なのにクリアにならない）戻す。1問5回、上限2万手。
- **慣れた試し置き**: N2 のうち、残りの行き先が最も少ない島のまわりから試すもの。

N2 は盤面の本数の知らせのもとで打てる手だけを使い、交差する手は打たない（合意 6）。限界: 止める向きにだけ使う。解けないことや戻しが多いことは、熟練者に難しいことの根拠にならない。

| 5 | 10×10 | つながりの手詰まり2回以上 | 40% 未満 | 3回以上 | 何度もつながりを読む。試しに架けて直す進め方では、何度もやり直しになる |

- 隣り合うレベルは同じ盤面を共有し（1/2 は 7×7、2/3 は 8×8、3/4 は 9×9、4/5 は 10×10）、共有する盤面では推論の特徴でだけ分かれる。
- 評価不能（試し置きが要る）・組み合わせ外（10×10 の数字だけで解ける問題、6×6 の A2 など）は提供しない。

### A.5 供給と偏り

- **収率**: 推奨 L5 は 10×10 候補の 8%（p2 を 0.1〜0.3 で回した集合）。数百問なら数分で作れる（推測。1候補 15ms からの計算）。
- **生成条件の偏り（E2）**: 推奨 L5 の 626問の内訳は p2=0.1 が 375、0.2 が 166、0.3 が 82。L5 の2本橋の割合は中央値 0.09 で、L1 の 0.50 より低い。L5 の盤面は「1 と 2 が多い」見た目になりやすい。p2 を巡回して採り、レベルごとの2本橋の割合の分布を問題集の検証に入れる。
- **重複（E3）**: 回転・反転で正規化したキーで、同じレベルの重複が 25組（ほぼ 6×6）。問題集を作るときに除く。
- **時間**: 人間向け解法器は1問 0.03秒以下（最大 0.026秒）。
