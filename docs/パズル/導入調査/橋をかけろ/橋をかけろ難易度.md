## 2. 挑戦と基準とするプレイ条件

### 2.1 挑戦

> 島の数字と、橋を架けられる行き先の数から「必ず架かる・架からない」と「2本と1本の配分」を決めていき、数字だけでは決まらない所では、橋の組が閉じて孤立しないこと・全島が1つにつながることを一か所ずつ見抜き、それでも決まらない所は1手だけ仮に決めて先を確かめて決めること。

レベルは作業の量ではなく、要る読みの種類と深さで分ける（判定の版 5）。挑戦にしないもの: 盤面の広さ・島の数だけによる架ける回数の増加（単独ではレベルを決めない）、短いすき間の押しにくさ（スマホ操作の観点）、架け直し・戻すの回数と所要時間（プレイ成績）。

### 2.2 分析が表現できる解法過程

人間向け解法器（`problem/generation/human-solver.ts`）は、辺ごとの本数の範囲を数字と盤面だけから狭める。低い段から使い切り、止まった所（手詰まり）で次の段を使い、その段で言えることを盤面全体へ同時に当てる（適用の順に依らない。導出）。C1p で進める手詰まりでは、同じ「閉じない」読みの C1g も同じ局面で見て、C1p を当てて数字の読み（A1・A2）で止まるまで進めても届かない狭め方が C1g にあるときだけ、両方を当てて C1g と記録する（判定の版 6。届くなら C1p だけを当てる）。

| 段 | 名前 | 内容 |
| --- | --- | --- |
| A1 | ちょうど | 足りた島の残りの行き先は0本。相手の島の残りより多くは架けない。行き先ごとの上限の合計が数字と同じなら全部上限 |
| A2 | 少なくとも・多くとも | 他の行き先を上限まで使っても足りない分は、この行き先に要る |
| C1p | 2島で閉じない | 1と1をつながない、2と2を2本にしない |
| C1g | 3島以上の組で閉じない | 架けると全島ではない組の本数が全部足りて閉じるなら、その本数は架けない |
| C3 | 唯一の通り道 | この行き先が無いと、架けられる橋だけでは全島がつながらないなら1本は要る |
| D | 1手の先読み | 1手だけ仮に決め、交差と両端の島だけを1段進めた結果、本数が破れる・見渡せる組（7島までか、外に残る島が5島まで）が閉じる・4島までのまとまりが孤立するなら、その手は無い |
| T | 試し置き | 1手を仮に決めて A1〜D で進めると矛盾する。推理の外として、提供しない問題を見分けるためにだけ使う |

- 交差は段ではなく、架かると決まった橋と交わる行き先を0本にする規則として常に当てる（合意 6 で盤面からも見える）。研究用の解法器にあった段 B（交差）は、最初に要る手詰まりが一度も無く（付録 A.2、導入調査 §4.3 の導出）、製品コードでは段にしていない。研究用の100盤面で段と回数が一致したので、外しても経過は変わらない（事実（実測）。下の移植の確かめ）。
- D は推理の範囲に含める（D-07）。人にとって推理か試し置きかは試遊で確かめる（§10）。
- D の「1段進める」の中身（判定の版 6）: 仮に決めた辺の両端の島が埋まる所だけを進める。足りた島（決まった本数の合計が数字と同じ）の他の行き先は0本、行き先ごとの上限の合計が数字と同じ島は全部上限にする。数字の読み（A1・A2）を盤面に広げたり、3手目以降を追ったりはしない。架かると決まった辺と交わる辺は0本にする。
- D で見る破れ（判定の版 6）: 本数の破れは、仮に決めた辺と1段で変わった辺の両端の島、交差で0本になった辺の両端の島で見る（版 5 は両端の島を進める前にだけ見ていて、進めた後に隣の島の本数が足りなくなる手を見逃し、D を多く数えた。独立した確かめ F1、§4.7）。孤立は、架けられる橋だけでは残りとつながらなくなるまとまりが4島以下（`BRIDGES_LOOKAHEAD_ISOLATION_LIMIT`）のときだけ見る。孤立は知らせに出ず、大きなまとまりの孤立を確かめるのは盤面全体をたどる探索になり、SPEC-024 の「盤面の一部を見て矛盾が分かる」から外れるため（§4.7）。
- D で見る閉じた組（判定の版 7）: 閉じた組は、組が7島以下（`BRIDGES_LOOKAHEAD_CLOSED_GROUP_LIMIT`）か、組の外に残る島が5島以下（`BRIDGES_LOOKAHEAD_REMAINING_LIMIT`）のときだけ見る。組の島が全部足りたことは島の知らせで見えるが、それが全島ではないと確かめるには、組か外の島を数え切る。数え切れるのはどちらかが数島の所で、組も外も広い所は盤面全体をたどる探索になる。判定の版 6 は大きさを問わず、L4・L5 の先読みで 8島以上の組が閉じ、外に6島以上残る手が L4 147問・L5 304問にあった（評価役の `bigclose.ts`）。作り手が手で解いても、その所は場合分けになり、L4 で10〜15分、L5 で20分以上かかった（版 897989f2 の §7）。上限を超える組でしか退けられない手は、D では退けず、それでしか進めない問題は試し置き（T）が要る問題として出さない。
- 先読みの種類（判定の版 7）: D の手詰まりで決まった各辺について、決まった範囲のすぐ外の手（下限を上げたなら1本少ない手、上限を下げたなら1本多い手）を退けた理由を見て、本数の破れを見たものを「本数を見る先読み」、3島以上の組が閉じるか数島が孤立するのを見たものを「組を見る先読み」（うち孤立を見たものを「孤立を見る先読み」）、1本多い手を退けて上限を下げたものを「上限を下げる先読み」と数える。1回の手詰まりは複数の種類に入りうる。
- 組を見る先読み（判定の版 6）: 仮に決めた手の両端を埋め、組を端までたどって閉じるのを確かめる読みで、遊ぶ評価者が L5 で「2段の仮定」と感じた所（§4.7）。本数を見る先読みは、両端を埋めた後に隣の島の本数が足りなくなるか多すぎるのを見る読みで、組をたどらずに数字だけで分かる。
- 続けて要る先読み（判定の版 6）: 前の D の手詰まりから、ほかの読みで狭めた組が3以下（`BRIDGES_LOOKAHEAD_CHAIN_GAP`）のうちに次の D が要るなら、その D を「続けて要る先読み」と数える。先読みの結果から数組だけ進めてまた先読みが要る、1つの局面で先読みを重ねる所。
- 交差で塞がる行き先（判定の版 6）: 架かると決まった橋と交わって0本になった辺のうち、両端の島がまだ足りなかった辺の数。数字の読みでは塞がらない行き先を交差が塞ぎ、数字の読みが進む所（交差の背理法の入口）。交差は手詰まりごとの読みを当てた直後に盤面全体へ当て、そのときの島の足りる・足りないで数える。A1 の1回の当ては、まず各行き先の上限を両端の島の残りで下げ、下げた上限の合計が数字と同じ島を全部その上限にする（1回の当てで決まる所が変わると、交差を当てる時点の島の足りる・足りないが変わるので、ここまで決めておく。独立した確かめ F1）。
- C1p と C1g を同じ局面で見るのは、どちらも「架けると組が閉じる」という同じ読みで、組の大きさが違うだけだから。段ごとに分けたままだと、C1p で止まった手詰まりで C1g の読みが次の手詰まりへ回り、つながりの手詰まりの回数が「手詰まりごとに最も低い段だけを当てる」規則に左右される（独立した確かめ F1。§4.4）。一方、C1p と数字の読みで同じ所まで決まるのに C1g と記録すると、3島以上の組の読みが要らない問題を上のレベルに入れる（版 5 の L3 の 17/500。F1、§4.7）。D は1手の先読みでより深い読みなので、段として分けたまま数える。
- 一か所の気づきと掃く作業を分ける（判定の版 5）: つながりの読みの手詰まりで決まる組が1〜2なら一か所の気づき、3以上なら同じ規則で盤面を掃く作業とみなし、レベルを分ける閉じない読み（C1p・C1g）の回数には一か所の気づきだけを数える（`BRIDGES_SHARP_ROUND_EDGE_LIMIT`）。版 4 では、1つの手詰まりで C1g が十数か所まとめて決まる（盤面を同じ規則で掃く）問題も1回と数え、解き進みの6割より後の後始末の読みが「つながりを読む」回数に入っていた（評価役の計測）。
- 1手の先読みの回数: 下の段で決まる所を全部決め切った盤面（下の段は単調に範囲を狭めるだけなので、どの順に当てても同じ盤面になる。導出）で、D でしか進めない手詰まりを数える。各手詰まりで D の結論を盤面全体へ同時に当てるので、どの順に解いても、D で止まる回数はこの数より少なくならない（導出）。

### 2.3 移植の確かめ（F2）

`scripts/research/bridges_parity_cases.py` が研究用の生成器で作った100盤面（6×6〜10×10、一意解46・解の無い盤面や複数ある盤面を含む。段 A1〜D・T をすべて含む）を、研究用の解法器で解いた答えとともに `problem/generation/research-solver-cases.json` に置き、製品コードと次が一致することをテストで固定した（事実（実測）、`exact-solver.test.ts`・`human-solver.test.ts`）。

- 完全解法器: 解の数（2まで）・探索した局面の数・打ち切りの有無。つながりを無視したときの解の数（20まで）と局面の数
- 人間向け解法器: 状態、手詰まりごとの段と狭めた辺の数（最初に D か T が要る手詰まりより前まで。判定の版 6 で D の破れの見方を研究用の解法器から変えたため）、数字の読みだけで決まる割合、入口の辺の数（研究用の解法器は C1p と C1g を別の手詰まりで当てるので、突き合わせでは一緒に当てない設定で解く）

局面の数まで一致させたのは、打ち切りの上限（一意性 20万局面、つながりを無視 10万局面）が問題の採否を変えないことを保つため。上限は計算を止めるためのもので、人の能力ではない。研究用の240盤面でも一時スクリプトで不一致 0（事実（実測））。素朴な解き方は乱数列が研究用 Python と違うので値は一致しない。分布は §8 で研究用の値と並べた。

組み方の理由:

- レベルを、規模と作業量ではなく要る手筋の種類と深さで分け、上のレベルへ1つずつ新しい読みを足す: L1 は決め打ちと行き先が1つの島（入口）、L2 は配分の読みと2島を閉じない読み、L3 は3島以上の組を含むつながりの読みと交差、L4 は1手の先読み（本数を見るものと組を見るもの）と読みの手詰まり6回以上、L5 は続けて要る先読み。評価役の3巡目の採点（§4.8）で、レベルの段差が 58点と最も低かったため。判定の版 6 は、L1 と L2 で閉じない読みが出る問題と出ない問題が混ざり、L4 と L5 は先読みの回数で分けていた。
- 上のレベルは、盤面・島の数・A2・つながり・閉じない読み・1手の先読み・組を見る先読み・交差・5以上と6以上の数字・輪の下限を下げず、入口の上限を上げない（`difficulty.test.ts` で固定）。L4 と L5 は、本数を見る先読みと続けて要る先読みで分かれ、本数を見る先読みは L5 では問わない（続けて要る先読みに置き換える）。
- 上限を下げる先読みと孤立を見る先読みは札にした。どちらも先読みが要る候補の 15% 前後にしか出ず（一時スクリプト、L4 62・L5 70 候補）、全問に求めると候補が尽きる。L5 に上限を下げる先読みを全問に求めること（評価役の案）は §13。
- 島の割合の下限は、そのレベルの盤面の大きさから島の数の下限を決めるために置いた。同じレベルで 9×9 と 10×10 が混ざっても、マスに対する込み具合がそろう。L4 の 22% は 10×10 で22島（評価役の案）、L5 の 26% は 10×10 で26島（10×10 に広げた盤面の上の方。§6.1）。L1〜L3 の 24% は判定の版 6 と同じ。
- 閉じない読みは一か所の気づきだけを数え、まとめて決まる手詰まり（掃く作業）は数えない（§2.2）。
- 架ける行き先の割合の上限 0.85 は、どの行き先にも架ける盤面（評価役の計測で、L1 の 70問が全部の行き先に架けていた）を除くため。行き先を数えれば決まり、どこへ架けないかを読む所が無い。
- 数字の質の値は、評価役の案（数字2 0.30、最も多い数字 0.35、平均 2.8）から少し緩めた。10×10 で磨いた候補の多くが数字2 31〜33%・平均 2.75〜2.8 に集まり、案のままでは L5 の各500問を作るのに数時間かかる（一時スクリプト）。L1 は島が10前後で1島が割合を1割近く動かすので1段緩めた。
- 境界の値は分布と一言から置いた暫定値で、人の試遊で確かめていない。

### 6.1 生成の仕方

- 島を広げながら橋を張る（`problem/generation/island-spread.ts`）: 島を1つ置き、既にある島へ縦横にまっすぐ、架けた橋を横切らずに架けられる空きマスを盤面全体から1つ選んで島を置き、その間に橋を架けることを、置ける所が尽きるまで繰り返す（生成器の版 6。版 5 は島の密度を目標の数として、届いたら止めた）。マスは、架けられる橋の間のマスの数の平方根と、架けられる向きの数に比べた重みで選び、外周のマスは重みを 0.35 倍、島の多い偶奇の組（行と列の偶奇が同じマス）のマスは 0.5 倍にする（生成器の版 6。間が1マスの橋で島が1マスおきの格子に並ぶのを減らし、間が偶数マスの橋も混ぜる）。選んだマスからどの島へ架けるかは、間のマスの数に比べた重みで選び、長い橋を優先する。島を置いたとき、別の向きの島にも `extraBridgeRate` の確率で橋を足して輪を作る。島を置く代わりに `splitRate` の確率で架けた橋の途中に島を差して2本に分ける。橋は `doubleBridgeRate` の確率で2本。島の数が島の割合の下限（`islandDensity` × マスの数）に届かない盤面と、外周の各行・列に島が1つ以上ない盤面は、磨く前に捨てて作り直す（生成器の版 6。磨いてから島の数で外れる候補に時間を使わない）。
- 磨く（`problem/generation/refinement.ts`）: `refinementSteps` が 0 でなければ、島の位置を変えずに、辺1つの本数を1段変えた解を作り、全島がつながったまま推理だけで解ける（推理の段はどれも盤面から必ず言えることだけを決めるので、推理で解き切れれば一意解。導出）盤面を、焼きなましで点の高い方へ寄せ、途中で最も点の高かった盤面を返す。最も高い点が 700回上がらなければ打ち切る（生成器の版 6）。点は磨く向き（`refinementGoal`）で変える。入口（`entry`、生成器の版 6）は最初の配分の読みを足し、2つ目からの配分の読みとつながりの読み・先読みを引く。配分（`count`）は A2 と2島を閉じない読みを足し、ほかのつながりの読みと先読みを引く。つながり（`closure`）は閉じない読み・通り道を足し、先読みを引く。先読み（`lookahead`）は先読み8点、組を見る先読み +4点、本数を見る先読み +3点（最初の1回は +12点）、上限を下げる先読み +4点、続けて要る先読み +6点（最初の1回は +15点）を足す。レベルが1つ以上を求める読みの最初の1回を重くするのは、同じ点では多い読みを1種類だけ増やす変形が選ばれ、求める読みの揃わない盤面が残るため（生成器の版 6。§4.8）。どの向きも、交差で塞がる行き先を1つ1点（上限あり）、解の輪を1つ2点（島6つに1つまで。最初の2つはさらに3点）、長い橋（盤面の一辺の半分以上）を1本 0.5点（4本まで）、6以上・7以上の数字をそれぞれ2点足し、数字の平均・2本の組・数字2・最も多い数字・外周に沿う橋・短い橋（間が1マス）5割・架ける行き先 85% を外れた分を 60 倍して引く。
- 生成条件（D-08）: 盤面の一辺 6〜10 × 島の割合の下限 {0.22, 0.24, 0.26} × 2本の割合 {0.5, 0.65} × 輪の割合 {0.25, 0.45} × 分割 {0.2, 0.45} × 磨く回数 {0, 150, 500, 1500, 2000} × 磨く向き。島の割合・磨く回数・向きはレベルに当たりやすい値に絞る（L1 は 0.24、150・500 回、入口。L2 は 0.24、500・1500 回、配分。L3 は 0.24、500・1500 回、つながり。L4 は 0.22・0.24、1500 回、先読み。L5 は 0.26、2000 回、先読み）。島の割合の下限はレベルの島の割合の下限と同じにして、届かない盤面を早く捨てる。どれもレベルの判定には使わない。生成器の版は 6。

## 14. 限界と未確定事項

- **手応えの差は人で確かめていない**: 上のレベルへ1つずつ新しい読みを足したが、それが人の手応えの差になるかは推測。L4 と L5 の差は続けて要る先読みと島の数で、先読みを早く使う人には差が小さく感じられるおそれがある。
- **L5 の天井**: 先読み3回以上・上限を下げる先読み・輪3つ以上は L5 の一部（札）で、全問には求めていない。求めると L5 の生成が2〜3倍かかる（§13）。
- **見渡せる大きさの線は推測**: 孤立は4島以下、閉じる組は7島以下か外に5島以下なら見渡せるという線は、作り手と評価役が手で解いた所見から置き、人で確かめていない。人が線より大きい組を見て先読みを使うことはあり、そのときは解法器より早く進む（解法器は人より遅く進む側に数える）。
- **外周と短い橋の偏り**（§5.3）: 外周のマスの重みを下げ、長い橋を優先し、磨く点に長い橋を足したが、長い橋の割合は増えなかった。6×6・7×7 は外周のマスが盤面の半分を超え、外周に沿う橋の上限も L1 だけ緩めた。
- **場合分けで解ける所**: 作り手が L4・L5 を手で解くと、場合分けの片方で解き切れて、もう片方を退けずに答えにした所があった（§7）。一意解を前提にした近道で、解法器の推理の範囲の外にある。人がこの近道を使うと、先読みの要る所でも試し置きのように速く解け、基準時間と比べた速さに表れる。
- **唯一の通り道（C3）は札で入れている**: 自然に出る割合は数%で、分類には使っていない。1手の先読みが要る L4・L5 では、通り道も要る候補がさらに少なく、下限を 3% にした。
- **全生成の時間**: 4プロセスで約4時間（L2 と L4 が大半。§6.2）。子プロセスを揃えて動かせば約2時間10分の見込みで、目標の1〜2時間に収めるには、L2 と L4 の当たる候補を増やす磨き方が要る。`--verify` は4プロセスで約5分。
- **つながりの知らせを足すと前提が変わる**（ripple 段 1）。
- **島の配置の規則（D3）**: 生成器は対称などの規則を使わないので、規則の近道は無い（導出）。

### A.3 素朴な解き方

- **N1 局所の本数推論だけ**: A1・A2 だけで止まるまで進める。「数字だけで決まる割合」がその到達度。
- **N2 局所の本数推論＋試し置き**: A1・A2 で進め、止まったら未決の行き先を無作為に選んで本数を無作為に仮に決める。本数が破れたら戻す。全島がちょうどになってもつながっていなければ（盤面は全島が灰色なのにクリアにならない）戻す。1問5回、上限2万手。
- **慣れた試し置き**: N2 のうち、残りの行き先が最も少ない島のまわりから試すもの。

N2 は盤面の本数の知らせのもとで打てる手だけを使い、交差する手は打たない（合意 6）。限界: 止める向きにだけ使う。解けないことや戻しが多いことは、熟練者に難しいことの根拠にならない。

### A.5 供給と偏り

- **収率**: 推奨 L5 は 10×10 候補の 8%（p2 を 0.1〜0.3 で回した集合）。数百問なら数分で作れる（推測。1候補 15ms からの計算）。
- **生成条件の偏り（E2）**: 推奨 L5 の 626問の内訳は p2=0.1 が 375、0.2 が 166、0.3 が 82。L5 の2本橋の割合は中央値 0.09 で、L1 の 0.50 より低い。L5 の盤面は「1 と 2 が多い」見た目になりやすい。p2 を巡回して採り、レベルごとの2本橋の割合の分布を問題集の検証に入れる。
- **重複（E3）**: 回転・反転で正規化したキーで、同じレベルの重複が 25組（ほぼ 6×6）。問題集を作るときに除く。
- **時間**: 人間向け解法器は1問 0.03秒以下（最大 0.026秒）。
