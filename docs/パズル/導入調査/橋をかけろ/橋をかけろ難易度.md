## 2. 挑戦と基準とするプレイ条件

### 2.1 挑戦

> 島の数字と、橋を架けられる行き先の数から「必ず架かる・架からない」を決めていき、数字だけでは決まらない所では、橋の組が閉じて孤立しないこと・全島が1つにつながることまで読んで決めること。

挑戦にしないもの: 盤面の広さ・島の数だけによる架ける回数の増加（単独ではレベルを決めない）、短いすき間の押しにくさ（スマホ操作の観点）、架け直し・戻すの回数と所要時間（プレイ成績）。

### 2.2 分析が表現できる解法過程

人間向け解法器（`problem/generation/human-solver.ts`）は、辺ごとの本数の範囲を数字と盤面だけから狭める。低い段から使い切り、止まった所（手詰まり）で次の段を使い、その段で言えることを盤面全体へ同時に当てる（適用の順に依らない。導出）。C1p で進める手詰まりでは、同じ「閉じない」読みの C1g も一緒に当てる（版 3。§4.4）。

| 段 | 名前 | 内容 |
| --- | --- | --- |
| A1 | ちょうど | 足りた島の残りの行き先は0本。相手の島の残りより多くは架けない。行き先ごとの上限の合計が数字と同じなら全部上限 |
| A2 | 少なくとも・多くとも | 他の行き先を上限まで使っても足りない分は、この行き先に要る |
| C1p | 2島で閉じない | 1と1をつながない、2と2を2本にしない |
| C1g | 3島以上の組で閉じない | 架けると全島ではない組の本数が全部足りて閉じるなら、その本数は架けない |
| C3 | 唯一の通り道 | この行き先が無いと、架けられる橋だけでは全島がつながらないなら1本は要る |
| D | 1手の先読み | 1手だけ仮に決め、交差と両端の島だけを1段進めた結果、本数が破れる・どこかが閉じる・孤立するなら、その手は無い |
| T | 試し置き | 1手を仮に決めて A1〜D で進めると矛盾する。推理の外として、提供しない問題を見分けるためにだけ使う |

- 交差は段ではなく、架かると決まった橋と交わる行き先を0本にする規則として常に当てる（合意 6 で盤面からも見える）。研究用の解法器にあった段 B（交差）は、最初に要る手詰まりが一度も無く（付録 A.2、導入調査 §4.3 の導出）、製品コードでは段にしていない。研究用の100盤面で段と回数が一致したので、外しても経過は変わらない（事実（実測）。下の移植の確かめ）。
- D は推理の範囲に含める（D-07）。人にとって推理か試し置きかは試遊で確かめる（§10）。
- C1p と C1g を一緒に当てるのは、どちらも「架けると組が閉じる」という同じ読みで、組の大きさが違うだけだから。段ごとに分けたままだと、C1p で止まった手詰まりで C1g の読みが次の手詰まりへ回り、つながりの手詰まりの回数が「手詰まりごとに最も低い段だけを当てる」規則に左右される（独立した確かめ F1。§4.4）。D は1手の先読みでより深い読みなので、段として分けたまま数える。

### 2.3 移植の確かめ（F2）

`scripts/research/bridges_parity_cases.py` が研究用の生成器で作った100盤面（6×6〜10×10、一意解46・解の無い盤面や複数ある盤面を含む。段 A1〜D・T をすべて含む）を、研究用の解法器で解いた答えとともに `problem/generation/research-solver-cases.json` に置き、製品コードと次が一致することをテストで固定した（事実（実測）、`exact-solver.test.ts`・`human-solver.test.ts`）。

- 完全解法器: 解の数（2まで）・探索した局面の数・打ち切りの有無。つながりを無視したときの解の数（20まで）と局面の数
- 人間向け解法器: 状態、手詰まりごとの段と狭めた辺の数、数字の読みだけで決まる割合、入口の辺の数（研究用の解法器は C1p と C1g を別の手詰まりで当てるので、突き合わせでは一緒に当てない設定で解く）

局面の数まで一致させたのは、打ち切りの上限（一意性 20万局面、つながりを無視 10万局面）が問題の採否を変えないことを保つため。上限は計算を止めるためのもので、人の能力ではない。研究用の240盤面でも一時スクリプトで不一致 0（事実（実測））。素朴な解き方は乱数列が研究用 Python と違うので値は一致しない。分布は §8 で研究用の値と並べた。

## 4. 状態と分類

### 4.1 状態

| 状態 | 条件 |
| --- | --- |
| 成立しない（`invalid`） | 解が無い、2つ以上ある、一意性の探索が上限に達した |
| 評価不能（`unsupported`） | 一意解だが、試し置きまで使っても決まらない |
| 提供範囲外（`out-of-range`）`requires-trial` | 推理（A1〜D）では決まらず試し置きが要る（合意 3） |
| 提供範囲外 `unlisted-combination` | 特徴と盤面の組み合わせがどのレベルにも当たらない（10×10 で数字だけで解ける、6×6 で A2 が要るなど） |
| 分類済み（`classified`） | いずれかのレベルの組み合わせに当たる。レベルの組み合わせは重ならないので、当たるのは多くても1つ |

### 4.2 レベルごとの基準表（判定の版 4。検討時点の値。正はコード）

| レベル | 盤面 | 島の数 | 入口 ÷ 行き先 | A2 の手詰まり | つながりの手詰まり | 数字だけでは決まらない割合 | 利用者向けの一言（案） |
| ---: | --- | --- | --- | --- | --- | --- | --- |
| 1 | 6〜7 | 7以上 | 0.5〜0.95 | 0 | 0 | 0 | 数字と行き先の数を見るだけで、次々に決まる |
| 2 | 7〜8 | 9以上 | 0.2〜0.45 | 2以上 | 0 | 0 | 見ただけでは決まらず、「少なくとも1本はここへ」と何か所かで読む |
| 3 | 8〜9 | 12以上 | 0.45以下 | 2以上 | 1 | 0.5以下 | 「少なくとも1本」の読みに加えて、一か所、「つなぐと閉じて孤立する」読みが要る |
| 4 | 9〜10 | 15以上 | 0.45以下 | 2以上 | 2 | 0.5より大 | 数字だけでは半分も決まらず、つながりを二か所で読む |
| 5 | 10 | 18以上 | 0.45以下 | 2以上 | 3〜6 | 0.6より大 | 何度もつながりを読む。3島以上の組が閉じない読みがほぼどの問題にも要る |

組み方の理由:

- レベル3〜5 は、つながりの読みが要る手詰まりの回数（1・2・3以上）で分ける。どのレベルの組み合わせも重ならない。版 1 では L4・L5 を素朴な解き方の戻した回数（乱数）で分けていた（§4.3）。
- 上のレベルは、盤面・島の数・A2 の手詰まり・つながりの手詰まり・数字だけでは決まらない割合の下限を下げず、入口の上限を上げない（`difficulty.test.ts` で固定）。L3〜L5 も A2 を2回以上にし、上のレベルが下のレベルの読み（「少なくとも1本」を何か所かで読む）を含むようにする（§4.5）。
- L1 と L2 は、A2 の回数（L1 は0、L2 は2以上）と入口の広さ（L1 は 0.5 以上、L2 は 0.2〜0.45）で分ける。L2 の入口の下限 0.2 は、つながりを読まない L2 が L3 より解き始めにくくならないようにするため（§4.5）。A2 が1回だけの問題は、1か所で抜けると後は見るだけで決まり、L1 と手応えが同じになる（§4.4）。L1 の入口の上限 0.95 は、入口が全部（解き始めに全行き先が狭まる）の自明な問題を除くため。
- 島の数の下限は、そのレベルの最も小さい盤面のマスの 18%（切り上げ。6×6 で7、7×7 で9、8×8 で12、9×9 で15、10×10 で18）。島がそれより疎だと、島どうしが離れて1つの島の行き先が少なくなり、盤面が広くても見渡すだけで橋が決まって、広さが挑戦にならない、という見込み（推測）。測ると、生成器が作る候補で下限を下回るものは盤面ごとに 1% 未満（6×6〜10×10 で 2〜19件 / 約2,300〜3,400件）と少なく、数字のちょうどの読みだけで解ける割合は下回る候補の方が高い盤面が多い（9×9 で 21% 対 11%、10×10 で 11% 対 6%）が、件数が少なく差は確かではない（事実（実測）、一時スクリプト、全生成条件 × 200候補）。上のレベルほど盤面が広いので下限も上がる（合意の「上ほど島が多い」）。値は版 2 の下限（7・9・12・15・18）と同じ。
- L5 のつながりの手詰まりの上限 6 は、帯の中で突出して重い問題を除くため（問題集の 90 パーセンタイルは 4）。
- 隣のレベルは盤面を1つ共有し（1/2 は 7、2/3 は 8、3/4 は 9、4/5 は 10）、共有する盤面では推論の特徴でだけ分かれる。
- 境界の値は分布の切れ目と一言から置いた暫定値で、人の試遊で確かめていない。

### 4.3 作り直した理由（版 1 → 版 2）

山場2の確かめ（AI の試遊・独立した確かめ・自己点検、版 02a6b878）の所見と、その原因（`難易度開発手順.md` 工程10 の順）:

1. **L3〜L5 の手応えの差がほとんど無い（AI の試遊）**。原因は判定方法（工程10 の4）: 版 1 の L4 と L5 は推論の特徴の範囲が重なり（L4 はつながり1回以上、L5 は2回以上）、10×10 で推論の特徴がほぼ同じ問題が素朴な解き方の戻した回数（乱数）だけで分かれた。L4 代表 `9342dhdm1r`（つながり2回・C1g あり・決まらない割合 0.64）は L5 の推論側の基準をすべて満たしていた（独立した確かめ）。→ つながりの手詰まりの回数で重ならないように分け、N2 を分類から外した。
2. **L4 に上限が無い**（つながり5回・N2 戻し47の9×9 が L4）。→ L4 はつながり2回ちょうどにした。L5 にも上限 6 を置いた。
3. **L1 と L2 の差が A2 の1回と入口だけで、境界の対が同じ島の数で A2 の0回か1回かだけで分かれる**。→ 入口の広さの帯を分けた（L1 0.5 以上、L2 0.45 以下）。
4. **L1 に自明さの下限が無い**（島4つ、入口が全部 19/500）。→ 島7つ以上、入口 0.95 以下。
5. **L5 の天井**: 島の数の上限を上げるため、生成器に分割（既にある橋の途中に島を差す。導入調査の供給実験）を足した（生成器の版 2、§6.1）。10×10 で島の数の 10/50/90 が 18/23/26（分割なし）→ 24/24/30（分割 0.2）、つながり3回以上の候補が 6.8% → 13.8%（事実（実測）、一時スクリプト、10×10 各2,400候補）。

### 4.4 作り直した理由（版 2 → 版 3）

作り込みの1巡目の確かめ（AI の試遊・体験レビュー・自己点検・独立した確かめ、版 b6a1b2dc）の所見と、その原因:

1. **つながりの手詰まりの回数が数え方の規則に左右される（独立した確かめ F1）**。版 2 の L5 代表 `5mj7u0kf1h` は、最初の手詰まりで C1p と同じ深さの C1g（(3,0)-(6,0) は1本まで）も使えば、つながりの手詰まり2回で解け、L4 の基準に入った。原因は判定方法（工程10 の4）: 手詰まりごとに最も低い段だけを当てるので、同じ「閉じない」読みが2つの手詰まりに分かれた。→ C1p で進める手詰まりでは C1g も一緒に当てて1回と数える（§2.2）。研究用の100盤面で、一緒に当てるとつながりの手詰まりの回数が増える盤面は無い（`human-solver.test.ts`）。同じ確かめで、L4 代表 `hm4ab7mh0s` は D を使えば2回 → 1回、L5 `9suc0p7hq7` は3回 → 2回になると指摘された。D は1手の先読みでより深い読みなので、低い段で進められる所で D を先に使う解き方は数えない（§2.2）。
2. **L1 と L2 の手応えが同じになりそう（自己点検）**。版 2 の L2 は A2 の中央値1回で、差は主に入口の帯だった。→ L2 を A2 2回以上にした。L2 の収率は 4.6% → 0.9% に下がった（調べた候補 10,981 → 54,874、事実（実測）、`generate:bridges-pool`）。問題集は全体で 113.5秒で作れる（§6.2）。比べた別案（L1 を 6×6 だけにして規模の差を足す）は、差を規模で作ることになり NFR-008 に寄らないので採らなかった（測っていない）。
3. **盤面の外周に島の無い行・列が残る（体験レビュー）**。→ 生成器で、外周の各行・列に島が1つ以上ない盤面を作らない（生成器の版 3、§6.1）。表示では削らない。
4. **島の数の下限の理由が分位点（自己点検）**。→ 盤面のマスに対する割合とその意味で書き直した（§4.2）。値は変わらない。

### 4.5 作り直した理由（版 3 → 判定の版 4）

作り込みの2巡目の自己点検（版 1c8b0f0f）で、版 3 で L2 を A2 2回以上にした結果、L3 の方が A2 は少なく（中央値1 対 2）、入口は広い（10 / 50 / 90 のすべて）と分かった。入口は上のレベルで広げてはいけない量（B1）で、試遊でも「L2 と L3 は推論の種類が同じで、L3 は盤面が広く交差が増えた分の差」と所見が出た。

比べた案（事実（実測）、一時スクリプト、全生成条件 × 200候補 = 24,000候補での収率と、入口・A2 の 10 / 50 / 90 の逆転の有無）:

| 案 | L2 収率 | L3 収率 | 残る逆転 |
| --- | ---: | ---: | --- |

## 6. 供給（生成器の版 3・判定の版 4）

### 6.1 生成の仕方

- 完成グラフ先行（D-02）: 島を1つ置き、既存の島から縦横に伸ばした先の空きマスへ島を足して橋を架けることを繰り返し、木を作る。島は既存の島の上下左右に置かない（D-04）。育てる途中で、`splitRate` の確率で既にある橋の途中（両端の島から2マス以上）に島を差して橋を同じ本数の2本に分ける（分割、版 2 で追加）。次に、まだ橋の無い島の組のうち既存の橋と交わらない組に輪の橋を足す。数字は出ている橋の本数。盤面の外周の各行・列に島が1つ以上ない盤面は作らない（版 3。外周に島の無い行・列があると、盤面がその分だけ小さい問題と同じになり、盤面の広さが見かけだけになる）（`problem/generation/island-tree.ts`）。1つの identity で作れるまで最大200回作り直す（`problem/generator.ts`。外周の条件を足した後、全生成で要った回数は最大23回、事実（実測）、一時スクリプト）。
- 生成条件（D-08）: 盤面の一辺 6〜10 × 島の密度 {0.24, 0.30} × 2本の割合 {0.1, 0.2, 0.3} × 輪の割合 {0, 0.15} × 分割 {0, 0.2}。どれもレベルの判定には使わない。生成器の版は 3（版 2 で分割を足して identity の生成条件が変わり、版 3 で外周の条件を足して同じ identity から作る盤面が変わったため）。

## 8. 素朴な解き方

## 12. SPEC の難易度の節の案

- 挑戦: 島の数字と行き先の数から「必ず架かる・架からない」を決め、数字だけでは決まらない所では、橋の組が閉じて孤立しないこと・全島が1つにつながることまで読んで決める。
- 基準とするプレイ: 島ごとの本数の知らせ（足りない・ちょうど・多すぎ）を見ながら、読んで決めてから架ける。橋の正誤とつながりは知らせない。待った・盤面を戻すの回数・架け直しは難易度に含めない。
- 分析が表現する推論: ちょうど・少なくとも（数字の読み）、2島・3島以上の組が閉じない、唯一の通り道、1手の先読み（つながりの読み）。試し置きは推理に含めない。
- 問題成立性: 一意解。交差しない。同じ2島の間は2本まで。全島が1つにつながる。島は上下左右に隣り合わない。
- つまみ: 盤面の広さと島の数（上ほど広い盤面と多い島を許し、隣のレベルと盤面を1つ共有）、解き始めの入口の広さ、数字の読みで止まって「少なくとも1本」を読む回数とつながりを読む回数、数字だけでは決まらない範囲の広さ。
- レベルごとの一言: §4.2。
- 評価不能・提供範囲外: 試し置きが要る問題、どのレベルの組み合わせにも当たらない問題は出さない。
- 供給: 事前生成した問題集から出す。生成条件（島の密度・2本の割合・輪の割合・分割）はレベルの判定に使わず、分析・分類した結果でレベルを決める。盤面の外周のどの行・列にも島がある。

## 14. 限界と未確定事項

- **手応えの差は人で確かめていない**: 版 2 からつながりの読みの回数でレベル3〜5 を分けている。回数の差が人の手応えの差になるかは推測で、AI の試遊（版 1）では「解き筋の型が同じ」と感じられた。型（使う推論の種類）は L4・L5 で同じ（C1p・C1g）で、違いは回数と 1手の先読みの出現（判定の版 4 で L4 7%・L5 23%）。
- **L1 と L2 の差**: 版 3 で L2 を A2 2回以上にした。2か所の「少なくとも1本」の読みが L1 との差に感じられるかは試遊で確かめる。L2 の収率は 0.8% で、L2 の条件をさらに強めると全生成の時間が延びる。
- **L2 と L3 の差**: 判定の版 4 で、L3 は L2 の読みに加えてつながりを1か所読む問題になった。同梱の問題集の入口の 90 パーセンタイルは L2 0.40・L3 0.41 で、0.01 だけ逆が残る（§4.5）。
- **D を先に使う読み方**: D を C1p・C1g・C3 と一緒に当てると、L4 の 38.6%・L5 の 61.0% の問題でレベルが変わる（§5.2）。判定は低い段から読むプレイを基準にしたまま。D を早く使う人には L4・L5 の差が小さく感じられるおそれがある。
- **近い問題**: 島の配置が同じで数字の違う問題の対が 25 あり、ほぼ全部が L1 の 6×6 どうし（§5.2）。続けて遊んで同じ盤面に見えるかは試遊で確かめる。除く条件は足していない。
- **上位の天井**: L5 の中央値は、島24・数字だけでは 84% が決まらない・つながり3回。熟練者に足りるかは試遊でしか分からない。分割で島の数の上限は 30 まで上がった。
- **つながりの知らせを足すと前提が変わる**: 全島ちょうどで非連結のときに知らせると、N2 の行き詰まりが早く見える（ripple 段 1）。
- **解法器の独立した確かめ（F1）**: 版 1 の代表問題で L4 代表が L5 の推論側の基準を満たすこと（§4.3）、版 2 の L5 代表がつながり2回で解けること（§4.4）の指摘を受けた。判定の版 4 の代表問題の手追いはまだ。
- **縦長の盤面**: 比べていない（D-05 で入れない）。
- **島の配置の規則（D3）**: 生成器は対称などの規則を使わないので、規則の近道は無い（導出）。

### A.3 素朴な解き方

- **N1 局所の本数推論だけ**: A1・A2 だけで止まるまで進める。「数字だけで決まる割合」がその到達度。
- **N2 局所の本数推論＋試し置き**: A1・A2 で進め、止まったら未決の行き先を無作為に選んで本数を無作為に仮に決める。本数が破れたら戻す。全島がちょうどになってもつながっていなければ（盤面は全島が灰色なのにクリアにならない）戻す。1問5回、上限2万手。
- **慣れた試し置き**: N2 のうち、残りの行き先が最も少ない島のまわりから試すもの。

N2 は盤面の本数の知らせのもとで打てる手だけを使い、交差する手は打たない（合意 6）。限界: 止める向きにだけ使う。解けないことや戻しが多いことは、熟練者に難しいことの根拠にならない。

| 2本橋の割合 | 0.20 / 0.50 / 0.75 | 0.12 / 0.36 / 0.54 | 0.17 / 0.33 / 0.50 | 0.04 / 0.14 / 0.29 | 0.00 / 0.09 / 0.20 |

- 上のレベルが下げてはいけない特徴（島の数・つながりの手詰まり・N2 戻し）と、上げてはいけない特徴（数字だけで決まる割合・入口 ÷ 行き先）で、隣り合うレベルの 10 / 50 / 90 は逆転しない（B1）。
- 推論の種類の出現: L1 は A1 だけ、L2 は A2 100%、L3 は C1p 43%・C1g 52%・D 4%、L4 は C1p 92%・C1g 55%・D 8%、L5 は C1p 98%・C1g 98%・D 11%（B5）。
- レベルの中で盤面ごとの中央値（C2）: 広い盤面ほど易しくはなっていない（L4 は 9×9 で N2 戻し 1、10×10 で 2。L3 は 8×8・9×9 で数字だけで決まる割合 0.70・0.74）。
- 共有する盤面での件数（B2）: 7×7 は L1 1,032・L2 269、8×8 は L2 301・L3 196、9×9 は L3 229・L4 177、10×10 は L4 1,116・L5 626。
- レベル案 R に入った問題の中では、レベルと盤面の順位相関 0.93、N2 戻し 0.91、数字だけで決まる割合 -0.87 で、どれもレベルとともに動く。規模と推論はもとの集合ではほぼ独立（§A.2.2）なので、レベルの範囲をそう組んだ結果（導出）。

#### A.4.4 L5 を「つながりの読みが要る」問題にそろえられるか（事実（実測））

10×10 の 7,800 候補で、絞り方ごとの件数（候補に対する割合）:

| 絞り方 | 件数 | 割合 | 数字だけで決まる割合（中央値） | N2 戻し（中央値） | N2 が1回目で解けた割合 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A〜D で解ける一意解 | 4,680 | 60.0% | 0.65 | 1 | 52% |
| つながり1回以上 | 2,944 | 37.7% | 0.38 | 1 | 24% |

生成条件 p2 ごとの推奨 L5 の収率（候補に対して）: p2=0.1 で 20.8%、0.2 で 9.2%、0.3 で 2.7%、0.5 で 0.2%。1候補は1スレッドで約15ms（10×10、素朴な解き方の5回×2種を含む）。

結論: L5 をつながりの読みが2回以上要る問題にそろえられる（成り立つ）。ただし、絞ると 2本橋の少ない問題に偏る（§A.5）。

### A.5 供給と偏り

- **収率**: 推奨 L5 は 10×10 候補の 8%（p2 を 0.1〜0.3 で回した集合）。数百問なら数分で作れる（推測。1候補 15ms からの計算）。
- **生成条件の偏り（E2）**: 推奨 L5 の 626問の内訳は p2=0.1 が 375、0.2 が 166、0.3 が 82。L5 の2本橋の割合は中央値 0.09 で、L1 の 0.50 より低い。L5 の盤面は「1 と 2 が多い」見た目になりやすい。p2 を巡回して採り、レベルごとの2本橋の割合の分布を問題集の検証に入れる。
- **重複（E3）**: 回転・反転で正規化したキーで、同じレベルの重複が 25組（ほぼ 6×6）。問題集を作るときに除く。
- **時間**: 人間向け解法器は1問 0.03秒以下（最大 0.026秒）。
