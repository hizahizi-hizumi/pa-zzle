採用ゲートが求める「パズル固有の面白さを保った5段階の体験差を定義でき、各レベルの問題を意図的かつ継続的に供給できる見込み」を、調査用の Python（`scripts/research/bridges_difficulty.py`）で確かめる。製品コードはまだ無い。ここで出す組み合わせの値は比較実験の条件で、製品の値は difficulty の項目で製品コードを使って決め直す。

## 2. 前提として引き継ぐ条件

導入調査 Issue #576 の合意から引き継ぐ。

| 条件 | 内容 |
| --- | --- |
| 盤面 | 正方形 6×6〜10×10 で比較した。上限 10×10 は合意（スマホで1マス約36px）。縦長の盤面は問題供給の観点で比べる |
| 問題成立性 | 一意解。交差しない。同じ2島の間は2本まで。全島が1つにつながる。島は縦横に隣り合わない（間に1マス以上空ける）。生成器が保証し、一意性は完全な解法器で確かめる |
| 推測の要否 | 推理だけで解ける問題だけを出す。試し置きをしないと決まらない問題は出さない（合意 3） |
| 基準とするプレイ条件 | 島ごとの本数の知らせ（足りない・ちょうど・多すぎ）が見える。橋の正誤とつながりの知らせは出さない（合意 5）。交差する所には架けられない（合意 6）。ひとつ戻すがある（合意 7）。読んで決めてから架けるプレイを基準にし、架けて直す試行錯誤の量は難易度ではなくプレイ成績（時間）に表す（合意 8） |
| 規模 | 上ほど盤面が広く島が多い。L1 は小さく数字だけで次々に決まる。L5 は 10×10 で、孤立を避ける読みが要る所がある（合意のレベルの説明） |

## 3. 橋をかけろ固有の挑戦

### 3.1 挑戦の定義（案）

> 島の数字と、橋を架けられる行き先の数から「必ず架かる・架からない」を決めていき、数字だけでは決まらない所では、橋の組が閉じて孤立しないこと・全島が1つにつながることまで読んで決めること。

### 3.2 挑戦を強くするもの（仮説）

1. 「ちょうど」（行き先を全部使わないと足りない、もう足りた）だけでは止まり、「少なくとも1本はここへ」の読みが要る。
2. 数字の読みでは止まり、つながりの読み（2島で閉じない、3島以上の組で閉じない、1手先で孤立する）が要る。
3. その手詰まりが盤面の早い段階で来る（数字だけで決まる範囲が狭い）、何度も来る。
4. 試しに架けて直す進め方では、全島が「ちょうど」になってもつながっていない配置に何度も行き着く。

### 3.3 挑戦にしないもの

- 盤面の広さ・島の数だけによる作業量（架ける回数）の増加。単独ではレベルを決めない
- 橋の押し分けにくさ・短いすき間のタップ（スマホ操作の観点で扱う）
- 架け直し・戻すの回数、所要時間そのもの（プレイ成績）

## 4. 分析モデル（人間向け解法器）

`bridges_difficulty.py` の `human_solve` が、島の数字と盤面だけから（解を見ずに）各行き先の本数の範囲（下限〜上限）を狭める。

### 4.1 推論の段

| 段 | 名前 | 内容 |
| --- | --- | --- |
| A1 | ちょうど | 足りた島の残りの行き先は0本。相手の島の残りより多くは架けない。行き先ごとの上限の合計が数字と同じなら全部上限 |
| A2 | 少なくとも・多くとも | 他の行き先を上限まで使っても足りない分は、この行き先に要る（例: 行き先2つの3は各1本以上） |
| B | 交差 | ここに架けると交差で消える行き先のせいで、その島の数字が満たせない |
| C1p | 2島で閉じない | 1と1をつながない、2と2を2本にしない |
| C1g | 3島以上の組で閉じない | 架けると、全島ではない組の本数が全部足りて閉じるなら、その本数は架けない |
| C3 | 唯一の通り道 | この行き先が無いと、架けられる橋だけでは全島がつながらないなら1本は要る |
| D | 1手の先読み | 仮に架け（外し）、両端の島が埋まった結果どこかが孤立・閉鎖するなら、その手は無い |
| T | 試し置き | 仮に決めて A〜D で進めると矛盾する。提供範囲外の判定にだけ使う |

- 低い段から使い切り、止まったら次の段を使う。1回の手詰まりでは、その段で言えることを盤面全体で同時に適用する。適用の順に依らない（導出）。
- 交差は規則として常に当てる（架かった橋と交差する行き先は0本）。合意 6 で交差する橋は置けないので、盤面からも見える。

### 4.2 健全性（事実（実測））

- 5×5 の小さな盤面 300問で、総当たりと完全な解法器の解の数が一致（不一致 0/300）。`selfcheck`
- main と l5 の一意解 11,156問すべてで、人間向け解法器（T まで）が解き切り、答えは生成時の答えと一致した（不一致 0）。
- 盤面を回転・反転しても、段と各段の回数が変わる問題 0/400（A3）。`selfcheck`

### 4.3 交差の段（B）は独立して現れない

全問題集合で、B が最初に要る手詰まりは 0 回（事実（実測））。理由は導出できる: 交差で消える行き先 f のせいで島 k が満たせなくなるなら、k の A2 がすでに f に1本以上を要求し、規則で e は0本になる。1つの島から出る行き先のうち、同じ橋と交差できるのは1本だけ（上下の行き先は同じ列にあり、橋はその列の片側だけを横切る）なので、複数の行き先を同時に失う形も無い。

したがって、交差は推論の段ではなく、数字の読み（A）が使う盤面の制約として働く。観点カードの「交差の推論」の系統は、このモデルでは段にならない。交差で消える行き先の数は記録だけの特徴にする（レベルとともに増える。§7.1）。

### 4.4 評価できる範囲

| 状態 | 条件 | 割合（10×10 の一意解） |
| --- | --- | ---: |
| 評価できる | A〜D で解き切る | 98.3% |
| 試し置きが要る | T を使わないと決まらない | 1.7%（79/4,759） |

試し置きが要る問題は合意 3 により出さない（提供範囲外）。レベル5 へ押し込まない。

## 7. 分析結果（事実（実測））

### 7.1 盤面ごとの最高段（main、一意解のみ）

| 盤面 | 一意解の割合 | A だけで解ける | つながりが要る | 試し置きが要る |
| --- | ---: | ---: | ---: | ---: |
| 6×6 | 74% | 85% | 15% | 0.1% |
| 7×7 | 68% | 80% | 20% | 0.2% |
| 8×8 | 65% | 73% | 26% | 0.6% |
| 9×9 | 60% | 67% | 32% | 0.9% |
| 10×10 | 54% | 65% | 33% | 1.5% |

- 盤面が広いほどつながりの読みが要る割合は上がるが、10×10 でも 65% は数字の読みだけで解ける。盤面だけではレベルは決まらない。
- つながりの読みが要るかは生成条件 p2 に強く依存する（10×10、候補に対する割合）: つながり1回以上 p2=0.1 で 57〜71%、0.3 で 20〜32%、0.5 で 7.5〜14%。2本橋が少ないほど 1・2 の島が多く、閉じる組ができやすい（推測）。

### 7.2 系統どうしの順位相関（main、A〜D で解ける一意解 7,644問）

| | 盤面 | 島の数 | 最高段 | つながりの手詰まり | 数字だけで決まる割合 | N2 戻し | 入口 ÷ 行き先 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 盤面 | 1 | 0.90 | 0.24 | 0.18 | -0.14 | 0.16 | -0.40 |
| 最高段 | | | 1 | 0.83 | -0.82 | 0.67 | -0.66 |
| つながりの手詰まり | | | | 1 | -0.99 | 0.81 | -0.56 |
| 数字だけで決まる割合 | | | | | 1 | -0.81 | 0.57 |
| N2 戻し | | | | | | 1 | -0.49 |

10×10 だけ（4,680問）では、島の数と最高段 0.15、島の数とつながりの手詰まり 0.14、つながりの手詰まりと N2 戻し 0.83、入口 ÷ 行き先と A2 回数 -0.70。

読み方:

- **規模の系統**（盤面・島の数）と **推論の系統**（最高段・つながりの手詰まり・数字だけで決まる割合）はほぼ独立（絶対値 0.13〜0.24）。
- 推論の系統の中の3つは同じ量を測っている（0.82〜0.99）。別の系統として数えない。
- **試し置きでの押し切りにくさ**（N2 戻し）は推論の系統と 0.67〜0.81 で、独立した系統ではないが同じでもない。L5 の下限に使う（§8）。
- 観点カードの「交差の推論」の系統は段にならない（§4.3）。

### 7.3 推論の種類の出現（盤面ごと、A〜D で解ける一意解）

| 盤面 | A2 | C1p | C1g | C3 | D |
| --- | ---: | ---: | ---: | ---: | ---: |
| 6×6 | 27% | 12% | 5% | 0% | 0% |
| 8×8 | 45% | 16% | 14% | 0% | 2% |
| 10×10 | 59% | 21% | 20% | 0% | 3% |

C3（唯一の通り道）は先に C1 が使えるため、最初に要る手詰まりがほぼ無い（全体で1問）。D（1手の先読み）は 10×10 の 3%。

## 8. 素朴な解き方（D1）

- **N1 局所の本数推論だけ**: A1・A2 だけで止まるまで進める。「数字だけで決まる割合」がその到達度。
- **N2 局所の本数推論＋試し置き**: A1・A2 で進め、止まったら未決の行き先を無作為に選んで本数を無作為に仮に決める。本数が破れたら戻す。全島がちょうどになってもつながっていなければ（盤面は全島が灰色なのにクリアにならない）戻す。1問5回、上限2万手。
- **慣れた試し置き**: N2 のうち、残りの行き先が最も少ない島のまわりから試すもの。

N2 は盤面の本数の知らせのもとで打てる手だけを使い、交差する手は打たない（合意 6）。限界: 止める向きにだけ使う。解けないことや戻しが多いことは、熟練者に難しいことの根拠にならない。

## 9. 5段階の分類

### 9.1 案と比較

| 案 | 内容 | 判断 |
| --- | --- | --- |
| P | 盤面 × 最高段（A1 / A2 / 2島の閉路 / それ以上） | 不採用。A1 の判定を相手の島の残りまで含めて直すと L2 がほとんど出ない |
| Q | 盤面 × 推論の種類（L3 は 2島の閉路だけ、L4 は 3島以上の組）＋ L5 に N2 戻しの下限 | 不採用。L3 と L4 で「数字だけで決まる割合」が逆転する（L3 0.53 → L4 0.73、中央値）。L3 と L4 の N2 戻しも同じ（1）。3島以上の組で閉じる読みは、数字の読みがほぼ終わった最後に1回だけ要ることが多い |
| R | 盤面 × 推論の種類 × 数字だけで決まる割合 ＋ L5 に N2 戻しの下限 | **推奨** |

### 9.2 推奨する組み合わせ（案 R。比較実験の条件）

上から順に当て、最初に当たったレベルにする。

| レベル | 盤面 | 推論 | 数字だけで決まる割合 | 試し置きの戻し（N2 中央値） | 利用者向けの一言（案） |
| ---: | --- | --- | --- | --- | --- |
| 1 | 6×6〜7×7 | A1 だけ | 100% | 問わない | 数字と行き先の数を見るだけで、次々に決まる |
| 2 | 7×7〜8×8 | A2 が要る（つながりは要らない） | 100% | 問わない | 「少なくとも1本はここへ」と読む所がある |
| 3 | 8×8〜9×9 | つながりの手詰まりちょうど1回 | 50% 以上 | 問わない | 一か所、「つなぐと閉じて孤立する」読みが要る |
| 4 | 9×9〜10×10 | つながりが要る | 50% 未満 | 1回以上 | 数字だけでは3割ほどしか進まず、早くからつながりを読む |
| 5 | 10×10 | つながりの手詰まり2回以上 | 40% 未満 | 3回以上 | 何度もつながりを読む。試しに架けて直す進め方では、何度もやり直しになる |

- 隣り合うレベルは同じ盤面を共有し（1/2 は 7×7、2/3 は 8×8、3/4 は 9×9、4/5 は 10×10）、共有する盤面では推論の特徴でだけ分かれる。
- 評価不能（試し置きが要る）・組み合わせ外（10×10 の数字だけで解ける問題、6×6 の A2 など）は提供しない。

- 上のレベルが下げてはいけない特徴（島の数・つながりの手詰まり・N2 戻し）と、上げてはいけない特徴（数字だけで決まる割合・入口 ÷ 行き先）で、隣り合うレベルの 10 / 50 / 90 は逆転しない（B1）。

### 9.4 L5 を「つながりの読みが要る」問題にそろえられるか（事実（実測））

| 絞り方 | 件数 | 割合 | 数字だけで決まる割合（中央値） | N2 戻し（中央値） | N2 が1回目で解けた割合 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A〜D で解ける一意解 | 4,680 | 60.0% | 0.65 | 1 | 52% |
| つながり1回以上 | 2,944 | 37.7% | 0.38 | 1 | 24% |
| つながり2回以上 | 1,550 | 19.9% | 0.28 | 2 | 14% |
| つながり3回以上 | 433 | 5.6% | 0.21 | 4 | 8% |
| つながり2回以上 かつ N2 戻し3以上 | 729 | 9.3% | 0.19 | 5 | 5% |
| 推奨 L5（上に加え数字だけで決まる割合 0.4 未満） | 626 | 8.0% | 0.15 | 5 | 5% |

生成条件 p2 ごとの推奨 L5 の収率（候補に対して）: p2=0.1 で 20.8%、0.2 で 9.2%、0.3 で 2.7%、0.5 で 0.2%。1候補は1スレッドで約15ms（10×10、素朴な解き方の5回×2種を含む）。

結論: L5 をつながりの読みが2回以上要る問題にそろえられる（成り立つ）。ただし、絞ると 2本橋の少ない問題に偏る（§10）。

## 10. 供給と偏り

- **収率**: 推奨 L5 は 10×10 候補の 8%（p2 を 0.1〜0.3 で回した集合）。数百問なら数分で作れる（推測。1候補 15ms からの計算）。
- **生成条件の偏り（E2）**: 推奨 L5 の 626問の内訳は p2=0.1 が 375、0.2 が 166、0.3 が 82。L5 の2本橋の割合は中央値 0.09 で、L1 の 0.50 より低い。L5 の盤面は「1 と 2 が多い」見た目になりやすい。p2 を巡回して採り、レベルごとの2本橋の割合の分布を問題集の検証に入れる。
- **重複（E3）**: 回転・反転で正規化したキーで、同じレベルの重複が 25組（ほぼ 6×6）。問題集を作るときに除く。
- **時間**: 人間向け解法器は1問 0.03秒以下（最大 0.026秒）。

## 11. 限界と未確定事項

- **L1 と L2 の差が小さい**: L2 の A2 の手詰まりは中央値1回。違いは「少なくとも1本」を1回使うことと、入口の広さ（0.80 → 0.57）。人には同じ手応えに見えうる（B3 の懸念。推測）。入口 ÷ 行き先の上限（例: L2 は 0.7 以下）を足す案がある。試遊で確かめる。
- **上位の天井**: L5 の中央値は、数字だけで 15% まで進み、つながりの手詰まり2回、N2 戻し5回。試し置きが要る問題を除いても 10×10 の 1.7% しか失わないので、「推測を要する問題を出さない」は天井をほとんど下げない（事実）。天井を決めているのは 10×10 の上限と島の数（中央値 23）である（推測）。熟練者に足りるかは試遊でしか分からない。
- **試し置きでの押し切り**: L3・L4 は N2 戻しが中央値1〜2回で、試しに架けて直す進め方でも解ける。リフレクションと同じく、下位〜中位は「読めば速い、試しても解ける」帯として扱う（推測）。L5 は戻し3回以上を下限にした。
- **N2 は人の試し置きの手間を表さない**: 戻し1回の人の手間（どこから直すかを探す、架け直す）は数えていない。全島がちょうどなのにつながらない状態に何回行き着くかを並べたのは、その代わり（推測）。
- **つながりの知らせを足すと前提が変わる**: 合意 5 でつながりは知らせない。全島ちょうどで非連結のときに知らせる（例: 分かれた組を色で示す）と、N2 の行き詰まりが早く見え、L5 の押し切りにくさの下限を測り直す必要がある。
- **解法器の確かめ（F1）**: 作った本人の手追い以外で、各レベルの代表問題を浅い読みで解けないかを確かめていない。D の段（1手の先読み）が人にとって「試し置き」に当たるかも、人の判断が要る。
- **縦長の盤面**: 比べていない（問題供給の観点）。
- **島の配置の規則（D3）**: 生成器は対称などの規則を使わないので、規則の近道は無い（導出）。
