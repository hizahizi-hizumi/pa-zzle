## 仮決定の候補

- 別ゲームとして作るか: 推奨は独立ゲーム `bridges` / 理由: 実装済みの8ゲームにも未実装の候補にも統合先が無い。挑戦の中身（数字の算術と連結の読み）が一筆パズル・マインスイーパーのどちらとも違う。合意も別ゲーム / 比べた案: 経路接続の一変種にする（経路接続が未実装で、マスを埋めない点でルールが合わない） / 覆したときに作り直す範囲: 統合するなら `frontend/src/games/bridges/` 全体とカタログ・ルート
