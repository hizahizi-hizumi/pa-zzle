# 氷の床迷路 先行事例調査

氷すべり系パズルで、追加の要素がどう難しさを生むか、難しい問題をどう作るかを、既存の作品・設計の知見・研究から集めた。氷の床迷路の難易度の作り直しで、ゼロから考える前に先行事例を確かめるために行った。

調査日: 2026-11-01

## 調べた理由

生成 v2（[難易度再設計PoC](氷の床迷路難易度再設計PoC.md) §11）で作った手筋入りの20問を、パズルに強いユーザーが試遊した。21〜28手の問題も、最短手数ちょうど・待ったなし・20〜50秒で解けた。最初の数秒〜十数秒で読み切り、あとは機械的に入力していた。ゴール通過の誘いや詰みの誘い手は一度も効かなかった。駒1つ・氷と岩だけ・盤面がすべて見える形では、慣れた人には「見れば分かる」パズルにしかならない、と見立てた。

## 調べ方と限界

Web 検索の結果の要約（抜粋）で確かめた。この環境からは `arxiv.org` などの本文を取得できなかったため、論文・記事の本文は読んでいない。数値や主張は、抄録・紹介文・ストアの説明の水準の確度である。「推測」と書いたものは出典のない判断である。

## 2. 難しさの源泉についての知見

- 駒1つ・静的な盤面では、状態は止まれる場所だけで、マス数以下になる（推測）。氷の床迷路の実測でも、到達できる停止点は50〜70程度だった。
- 人の難しさは状態空間の構造で決まり、状態数や解の長さのような静的な尺度では捉えにくい。人の探索をまねた計算モデルが有効だった（Jarušek & Pelánek, FLAIRS 2011、[AAAI PDF](https://cdn.aaai.org/ocs/2518/2518-11200-1-PB.pdf)）。
- 規則が既知で作業量が課題になるパズルだけを並べると単調になる（[The Codex「Aha! vs Process」](https://thecodex.ca/puzzles-aha-vs-process/)）。
- 深くする定石:
  - 止め役を動かせるもの・消えるものにする。Ricochet Robots では他のロボットを止め役に使う。
  - 新しい部品は少なく、組み合わせで掘る（A Monster's Expedition、[Thinky Games](https://thinkygames.com/games/a-monsters-expedition)）。
  - おとりは、確かめるのにコストがかかるときに効く（推測）。全部見えて状態が小さい盤面では、上級者は確かめてから動くので罠が効かない。試遊で誘いが効かなかったことと合う。
  - 同じ構造でも見た目で難しさが大きく変わる（ハノイの塔の同型問題で最大16倍。Kotovsky, Hayes & Simon 1985）。
  - 小さな変更が難しさを大きく変えるので、計算機での全探索が設計を支える（Sturtevant ら AIIDE 2020、[AAAI](https://ojs.aaai.org/index.php/AIIDE/article/view/7421)）。

## 3. 計算量と自動生成の研究

- 駒1つ・固定の岩・ゴール到達は、停止点のグラフ上の BFS で多項式時間（推測、自明な論証）。
- Lunar Lockout は NP 困難、固定ブロック付きの一般化は PSPACE 完全。Ricochet Robots はロボット数を限らなければ PSPACE 完全（[HAL](https://hal.archives-ouvertes.fr/hal-02191102)）。ice sliding games の整理は Dorbec ら（[arXiv 1507.00559](https://arxiv.org/pdf/1507.00559)、本文未確認）。
- 押したブロックが障害物まで滑る PushPush-k は PSPACE 完全（[Demaine ら](https://erikdemaine.org/papers/PushPush1_PSPACE_FUN2004/)）。
- 難しさを跳ね上げるのは「動く・消える・増える」状態。静的な床（止まる床・向き変更・ワープ）は状態数を増やさない。
- 自動生成: 解の経路を先に引いて残りに障害物を置く逆向きの構成（[blubberquark](https://www.tumblr.com/blubberquark/154241474475/procedural-generation-pattern-inverse-puzzle)、[abagames](https://abagames.github.io/joys-of-small-game-development-en/procedural/puzzle_level.html)）。最短手数が変わらなければ岩を氷に戻す方式（[attention verglas](https://delca.itch.io/attention-verglas)）。
- 人の難易度との相関: 特徴量を組み合わせた難易度関数の学習（van Kreveld ら [CIG 2015](https://ics-websites.science.uu.nl/docs/vakken/mscip/assignments/CIG2015-AutomatedPuzzleDifficultyEstimation.pdf)）、ソルバーのループ回数と主観的な難しさの相関（Shyne ら [AIIDE 2024](https://ojs.aaai.org/index.php/AIIDE/article/view/31873)）。

## 4. 氷の床迷路への示唆

「見れば分かる」を壊すには、初期盤面と解いている途中の盤面が違うこと、つまり止め役が動く・消える・現れる要素が要る（推測）。静的な床の追加では足りない。

試遊で試す価値が高い順:

1. 相棒の駒（2駒・互いが止め役）: 状態数が停止点の2乗程度になり、必要な止め役が初期盤面に無いので逆読みが効かない。仕組みは Ricochet Robots・Lunar Lockout と同系統なので、ロボット・宇宙・色付き目標チップの見た目は避ける（[名称・権利調査](氷の床迷路名称・権利調査.md)）。
2. もろい岩（一度止めると崩れる）: 止め役を使う順序が問われる。
3. 切り替わる岩（スイッチで出る・消える）: 頭の中で2枚の盤面を保つ必要がある。
4. 割れる氷: 1回通ると岩になる型は、自分の通過で止め役を作るので深さに効く見込み。2回で割れて落ちる型は罰型で、単独では勧めない。
5. 雪の床（1回止まると氷になる）: 素のふつうの床は目印になるので推さない。1回きりにすれば、使う順序が問われる資源になる。

試遊では、上級者が最初の数秒で読み切ったか、最短手数どおりに解けた割合、解くのにかかった時間を指標にする。状態が変わる要素では詰みが構造的に増えるので、待ったの扱いを先に決める。
