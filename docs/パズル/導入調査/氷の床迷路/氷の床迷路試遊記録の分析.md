# 氷の床迷路試遊記録の分析

氷の床迷路の試遊記録（1人・38件）と問題の特徴量を突き合わせ、人が手こずる問題を分ける特徴量を探した記録。作り直した問題集の第3版（[氷の床迷路難易度](氷の床迷路難易度.md) §18〜§20）は、ここで見つけた「自作依存の点」でレベル3〜5 を分ける。

根拠は [氷の床迷路実装前提調査](氷の床迷路実装前提調査.md) と同じ見出し語で区別する。**事実（実測）** は記録と一時スクリプト（`/tmp/difficulty-analysis/`。コミットしていない）で測った値、**推測** は確かめていない判断。

## 1. データ（事実（実測））

| 組 | 件数 | 内容 |
| --- | ---: | --- |
| v2 | 20 | 氷と岩だけ、手筋入り（[再設計PoC](氷の床迷路難易度再設計PoC.md) §11） |
| v3 | 9 | 要素1種類ずつ（薄い氷・もろい岩・相棒の駒・雪の床。再設計PoC §12） |

すべて同じユーザー（パズルに強い）。問題ごとの手こずり方は、総手数と最短手数の比（`ratio`）と1手あたりの時間（`tpm`）の順位の平均（`t_comp`。ギブアップは最も手こずったとする）で表した。`t_within` は組の中での順位（組ごとの慣れの差を除く）。特徴量は問題集の分析（`problem/generation/element-features.ts`）と同じ規則を Python で測り直し、第2版の問題集の L3〜L5 の900問で TypeScript の値と一致することを確かめた。

## 2. 結論

- **人の難しさを生むのは、初期盤面に無い地形を自分の手で作り、それに何手も後で頼ること。** 特に (1) 2手以上前に作った止め役（割れてできた水面）で止まる回数（`varied_stop`）と、(2) ゴールで止まる最後の手の止め役が自作であること（`goal_stop_self`）。ギブアップか総手数が最短の2倍を超えた4問（v3 の v01（薄い氷）・相棒の駒2問、v4 の w02（薄い氷））はどれもこの2つを満たし、「簡単」と言われた問題集 L5 の7問はどれも満たさない。
- **効かないもの**: 要素の数・種類、変わるマスの数・散らばり、割ってすぐ戻る手（単独では弱い）、順序の依存・おとり・誘い（0か負の相関）、試し手の取り返しのつかなさ、状態の数・状態の読み深さ、第2版の難しさの点（もろい岩・薄い氷の13件で順位相関 −0.46）。
- **見た目どおりの読みは「解なし」が効く**（要素のある18件の組の中の順位で +0.83）。「誤る」（見た目どおりの解が通らない）は弱い。

## 3. 自作依存の点

```text
自作依存の点 = 2 × varied_stop + 1 × (varied_use − varied_stop) + 0.5 × quick_return + 2 × goal_stop_self
```

- `varied_use`: 前の自分の手が作った地形（割れてできた水面・崩れて空いたマス）を、割ってすぐ戻る手筋でなく使う回数。`varied_stop` はそのうち2手以上前に作った水面で止まる回数。
- `quick_return`: 薄い氷を割った直後の手で、その水面へ戻って止まる回数。
- `goal_stop_self`: ゴールで止まる最後の手が、自分で作った水面で止まる。
- 最短解が複数あれば、点の最も低い解で測る。

重みと帯は記録を見た後に決めた。要素のある18件で `t_comp` との順位相関 +0.79、組の中の順位で +0.82（事実（実測））。

第3版の問題集は、レベル3〜5 を自作依存の点の帯で分けた（[氷の床迷路難易度](氷の床迷路難易度.md) §18）。

| レベル | 帯（AI判断（仮決定）） |
| --- | --- |
| 3 | 3以下（入門。要素2〜3個） |
| 4 | 3.5〜5.5 |
| 5 | 6以上、かつ varied_stop 2以上 |

## 6. 限界

- **1人・38件。** 要素のある問題は18件、もろい岩・薄い氷だけなら13件しかない。
- **重みと帯は記録を見た後に決めた。** 同じ記録で測った相関は高く出る（過学習の恐れ）。作り直した問題集での再試遊で確かめる。
- 組ごとに問題の作り方と遊んだ時期が違い、慣れの差が混ざる（組の中の順位 `t_within` で一部を除いた）。
- 相棒の駒と雪の床は問題集に入れない要素で、自作依存の点の高い側（相棒）と低い側（雪）の例として使っただけ。
