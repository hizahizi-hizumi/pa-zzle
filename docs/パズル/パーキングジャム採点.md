# パーキングジャム採点

> **再設計中**: `play-quality-v1` は現行8×8・14台問題と旧UIに対する暫定モデルへ戻す。盤面モデル・難易度・操作UIの再設計後に基準時間と減点の意味を再校正する。背景は [パーキングジャム再設計PoC](パーキングジャム再設計PoC.md) を参照する。

## 目的

パーキングジャムの評価点は、問題そのものの難しさではなく、その問題をどのように解いたかを評価する。

今回のルールでは、合法に出庫した車は盤面から消え、合法な車を選んだことで後から手詰まりになることはない。また、クリアに必要な成功出庫回数は車両数で固定される。したがって成功手数や最短手数との差はプレイ品質を表さない。

初版 `play-quality-v1` では次の3点を評価する。

- **正確さ 40点**: 盤面を読み、出せない方向を選ばずに判断できたか
- **速さ 40点**: 難易度に見合う時間で盤面を読み続けられたか
- **安定性 20点**: 出庫済みの車を戻したり、最初からやり直したりせずに進められたか

配点を40 / 40 / 20とするのは、判断の正確さと判断速度を同じ主評価とし、待った・やり直しはプレイを支える補助操作なので副評価とするためである。

## 採点基準

### 正確さ

40点から開始し、出せない方向を1回選ぶごとに5点減点する。0点未満にはしない。

不成立操作は単なる操作回数ではなく、その時点の盤面について「この車はこの方向へ出せる」と判断した結果なので、正確さとして扱う。

### 速さ

難易度ごとに次を満点基準時間とする。

| 難易度 | 満点基準時間 |
| --- | ---: |
| easy | 60秒 |
| normal | 90秒 |
| hard | 120秒 |

基準時間以内は40点。基準を超えた分だけ線形に減点し、基準時間の2倍で0点とする。

例として normal は90秒まで40点、112.5秒で30点、135秒で20点、180秒以上で0点になる。

現在の問題供給は8×8・14台を共通にし、難易度の中央値が依存深さ2 / 3 / 4へ分離している。初期基準時間はこの1段階の負荷差へ30秒ずつ余裕を追加した60 / 90 / 120秒とする。盤面規模を変更する場合、この値をそのまま使わず再校正する。

同じ「基準時間に対する倍率」なら難易度が違っても同じ速さ点になる。これにより、hardだから点を取りにくいという状態を避ける。

### 安定性

20点から開始し、次を減点する。

- 待った1回: -2点
- やり直し1回: -5点

合法な出庫は将来の手詰まりを生まないため、待ったは必須の探索手段ではなく、既に成立した判断を戻した事実として扱う。やり直しはそれより大きくプレイを巻き戻すため、減点も大きくする。

時間は待った・やり直し中も継続する。これは二重罰ではなく、判断に要した実時間と、補助操作へ頼った度合いを別の評価軸として扱うためである。

## 評価段階

既存ゲームと同じ結果段階の意味へ接続する。

| 評価点 | 段階 |
| --- | --- |
| 100 | perfect |
| 90〜99 | great |
| 80〜89 | good |
| 0〜79 | clear |

クリア自体と高評価は分離する。80点未満でもパズルを解いた事実は `clear` として成立する。

## 初期校正シナリオ

難易度ごとの基準時間を `T` としたとき、同じプレイ品質なら難易度によらず次の点数になる。

| プレイ例 | 時間 | 不成立 | 待った | やり直し | 点数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 迷いなく解く | `1.00T` 以下 | 0 | 0 | 0 | 100 |
| 正確だが少し慎重 | `1.25T` | 0 | 0 | 0 | 90 |
| 正確だがゆっくり | `1.50T` | 0 | 0 | 0 | 80 |
| 小さな読み違いから復帰 | `1.00T` | 1 | 1 | 0 | 93 |
| 読み違いが複数ある | `1.00T` | 2 | 1 | 0 | 88 |
| 一度やり直して慎重に完了 | `1.25T` | 0 | 0 | 1 | 85 |
| 読み違いと時間超過が重なる | `1.50T` | 3 | 1 | 0 | 63 |

この表は点数の分布を作るための目標値ではなく、「明らかに良いプレイほど高い」という順序が式から崩れていないかを確認するための固定例である。

## 保存と再計算

評価点自体をプレイ事実の正本にしない。後から再計算するために必要なのは次の事実である。

- 難易度
- 経過時間
- 不成立操作数
- 待った回数
- やり直し回数

セッションでは総操作数と成功出庫数も取得しているが、初版の採点には使用しない。成功出庫数はクリア時に車両数へ一致し、総操作数は成功出庫数と不成立操作数から説明できるためである。

## 再校正

`play-quality-v1` の数値は現在の8×8・14台問題に対する初期値である。実プレイで次を確認し、違和感があれば軸の意味を保ったまま数値を調整する。

- easy / normal / hard で、100 / 90台 / 80台 / それ未満の体感が不自然にずれないか
- 不成立1回の5点が大きすぎないか、小さすぎないか
- 待ったとやり直しの差が実際のプレイ感に合うか
- 基準時間の1.25倍・1.5倍・2倍の評価が体感に合うか
- 同じ難易度内で問題差によって時間評価が極端に有利・不利にならないか

採点軸の意味を変える場合はモデル版を更新する。係数だけを変更する場合も、この文書の固定シナリオと代表問題で再確認する。
