# PUZZLE-040 箱入り娘

## 問題供給成立性

通過。

基準の 4×5 の盤と、それを一部として含む広げた盤の作り（4×4・角の壁・横の出口・L字の駒・1マスの出口・娘2人・4×6・5×5・5×6）で、盤の作りと駒の組ごとに、目標の駒がどれも行き先に着いた状態から全状態をたどり、どの状態からも最短手数を求められる。手は全部1手で戻せるので、プレイの途中で解けなくならない。

盤の作りのまとまり（族）ごとに採った問題を、難易度ごとに決めた割合で混ぜて、各難易度 500 問・計 2,500 問の問題集を作った。生成スクリプトの `--verify` で、全問のレベル・最短手数・準備の長さ・正規形の確かめと、問題の重なりが無いことを確かめている。

## 難易度運用成立性

確認中。

準備の長さ（娘を進められないあいだに読む手の数）・娘の遠回り・空きの数で5段階に分けた。目標が2人の盤では、2人の距離の和を1本の進み具合として数える。
- 易しい例はレベル1、横刀立馬はレベル5 に入る。
- 隣のレベルの分布は逆転しない。
- 素朴な解き方では、L5 を最短の3倍以内に解けない。

準備の長さは、独立の確かめで見つかった抜け道（少し長い解、娘の往復、一時的な前進、1手の滑りの途中）で下がらない数え方にした。

人の体感（レベルの差、L5 の最短手数が短めの問題が L5 に感じられるか）を人の試遊で確かめるまで、確認中とする。
