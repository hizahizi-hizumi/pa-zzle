# PUZZLE-073 ソリティア / クロンダイク

## 問題供給成立性

確認中。

列の札を全部表向きに配り、山札を1枚ずつ何周でもめくれる形にすると、解けるかどうかは山札の順に依らず、見えている札だけで探索できる。小さな生成（400配り）では、解き筋を見つけて1手ずつ合法と確かめ直せた配り方が 91%、打ち切りが 2.5% だった。打ち切りは出さない。各レベル500問には候補が約2万要り、TypeScript・4並列で約3〜10時間と見込む（Python の計測からの推測）。問題集の件数と生成時間は実装で確かめる。

## 難易度運用成立性

確認中。

どのレベルも52枚・7列のまま、素朴な解き方（置ける所に置き、無ければめくる）の道筋がどれも勝つか・勝つ道筋も詰む道筋もあるか・どれも詰むかの段と、詰む手を打ってから行き詰まるまでに組札が何枚進むかの段を組み合わせて、5段階に分ける案に決めた。L1 は置く順をどう選んでも解け、L4・L5 は置ける手をどの順で打っても詰む。組札の枚数は、詰む手から数えても、その前の本当の選びから数えても同じ段になる問題だけを使う。人の試遊でレベルの差を確かめるまで確認中とする。

## スマホプレイ成立性

確認中。

320px で7列の札は 40×56px になる（計算）。重ねた札の帯は狭いので、置き元の山と置き先の山を押す形にし、長い列だけずらし幅を詰めて盤面をスクロールさせない。実ブラウザでは確かめていない。
