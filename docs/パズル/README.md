# パズル

パズル候補の比較、パズル横断の難易度設計、個別パズルの導入調査を管理する。

## 難易度

難易度に関する文書は、本質から具体化へ向かう依存方向で分ける。

| 文書 | 役割 | 実現したい状態 |
| --- | --- | --- |
| [難易度.md](難易度.md) | 難易度の意味・目的・原則・用語 | 実装や工程が変わっても、何を難易度と呼ぶかが揺れない |
| [難易度提供.md](難易度提供.md) | 難易度を利用者へどのような意味の選択肢として提供するか | 多数のパズルで、利用者が望む挑戦強度を一貫した読み方で選べる |
| [難易度判定.md](難易度判定.md) | パズル固有の挑戦を再現可能に分析・分類する原則 | 共通式を強制せず、各パズルで人間の挑戦を機械的に扱える |
| [難易度開発手順.md](難易度開発手順.md) | 難易度を導入・変更するときの調査、実装、検証、正本化の工程 | 場当たり的な判定や根拠のない閾値調整を避け、検証可能な形で難易度を成立させる |

依存方向は次の通り。

```text
難易度.md
├─ 難易度提供.md ─┐
└─ 難易度判定.md ─┴→ 難易度開発手順.md
```

横断的な難易度の設計判断はこの配下の難易度文書に置く。パズル固有の挑戦と難易度を分ける意図は[パズル仕様](../プロダクト/パズル/)に、特徴量の計算・閾値・分類条件はコードとテストに置く。

## パズル候補

[候補/](候補/) には、新しいパズルを知り比較するための台帳と候補カタログを置く。採用・開発状態の正本ではない。

## 導入調査

[導入調査/](導入調査/) には、パズル候補の成立性、導入判断、難易度制御などの調査・検証資料を置く。今の決まりの正本ではない。調査に使ったコードや再現データも、対応するパズルの `調査コード/` にまとめる。

採用済みパズルの今の決まりは [../プロダクト/パズル/](../プロダクト/パズル/) を正とする。
