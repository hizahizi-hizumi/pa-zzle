# 選んでいるゲームの姿で、空いた面に色を敷くことと、白黒版を直さずに解けた瞬間を見せる周の組み方を認める

## 要約

- **決定**: 選んでいるゲームの色付きの姿で、濃淡2色の姿の線に囲まれて空いている盤の地などの面に、ゲーム固有色を敷くのは色の変化に含める。濃淡2色の姿が解いている途中の盤を描くゲームでは、濃淡2色の姿を直さずに、ヒーローの周の途中で解けた瞬間を見せ、1 コマで濃淡2色の姿の盤へ戻って周を終える組み方（`rest-cut`）を認める。
- **主な選択肢**: 面は塗らず線の色だけを変える / 空いた面に色を敷く。途中の盤のゲームでは濃淡2色の姿を解けた盤に直す / 直さず今の盤で止める（解けた瞬間を見せない）/ 直さず周の途中で解けた瞬間を見せる。
- **背景**: ADR-0016 の「違うのは色だけ」の下で、盤の地を持つゲームは盤が線だけの色の無い姿になり、途中の盤を描くゲームは解けた瞬間を見せるには濃淡2色の姿を直すしかなかった。
- **要約**: 選んでいるゲームの姿で、濃淡2色の姿の線に囲まれて空いた盤の地などにゲーム固有色を敷くことと、途中の盤を描くゲームで濃淡2色の姿を直さずに周の途中で解けた瞬間を見せる rest-cut を認める。面を塗らない案、濃淡2色の姿を解けた盤に直す案、今の盤で止める案と比べた。形を変えずにゲームらしい姿と解けた瞬間を見せ、濃淡2色の姿を周の組み方の都合で変えないことを重視した。

## 背景と問題

ADR-0016 で、ホームで選んでいるゲームのピクトグラムを、濃淡2色の姿と同じ形のままゲーム固有色と動きで見せると決めた。形をそろえるため、色付きの SVG を作るスキルの契約は、静止状態では濃淡2色の姿の図形をそのまま使い、変えるのは塗りと線の色だけにすると定め、ヒーローの周は止まった姿（見せ場の後の姿）で終わる `cut` と、継ぎ目で途切れず回る `seam` に限っていた。

この決まりの下で、二つの問題が出た。

一つ目は、盤の地を持つゲームである。氷の床迷路の氷や詰将棋の盤の木は、濃淡2色の姿では線に囲まれた空の面として描かれている。字句どおりに「要素は変えない」と読むと、色付きの姿でも盤が線だけになり、詰将棋では「盤が白黒なのはなぜ」と受け取られた。空いた面に色を敷くのは輪郭を変えないが、要素を 1 枚足すことになる。

二つ目は、濃淡2色の姿が解いている途中の盤を描くゲームである。止まった姿を解けた盤にするには、濃淡2色の姿を解けた盤に直す必要があった。濃淡2色の姿を直さずに今の盤で止める案は、解けた瞬間を見せられない。一筆パズルでは、人が「白黒の方を直さないといけないのか」と問い、濃淡2色の姿を直さない案を選んで「規則の側が間違っている」とした。

## 判断基準

- 選んだ瞬間に変わるのが色だけであること（ADR-0016）。
- 解けた・揃った瞬間を、ヒーローで見せられること（RQ-001・RQ-002）。
- 濃淡2色の姿を、色付きの姿の周の組み方の都合だけで変えないこと。濃淡2色の姿は一覧・結果・記録など多くの場所で使われる。
- 選んだゲームの色付きの姿が、そのゲームを解く場面の姿に近いこと。
- アプリの再生の受け口（周の終わりの静止区間から再生を始める）を変えずに済むこと。

## 検討した選択肢

1. **面は塗らず、線の色だけを変える**
2. **濃淡2色の姿の線に囲まれて空いた面に、ゲーム固有色を敷く**
3. **途中の盤を描くゲームでは、濃淡2色の姿を解けた盤に直す**
4. **途中の盤を描くゲームでは、濃淡2色の姿を直さず、今の盤で止める**
5. **途中の盤を描くゲームでは、濃淡2色の姿を直さず、周の途中で解けた瞬間を見せてから今の盤へ戻る（`rest-cut`）**

1・2 は盤の地の扱い、3〜5 は途中の盤を描くゲームの扱いの選択肢である。

## 採用した選択肢と理由

採用: **濃淡2色の姿の線に囲まれて空いた面に、ゲーム固有色を敷く** と、**途中の盤を描くゲームでは、濃淡2色の姿を直さず、周の途中で解けた瞬間を見せてから今の盤へ戻る（`rest-cut`）**。理由: 空いた面に色を敷いても輪郭は変わらず、選んだ瞬間には面に色が入るだけで形は跳ばない。盤が解く場面の色になり、そのゲームの姿として読める。`rest-cut` は、周の頭と終わりを濃淡2色の姿と同じ静止状態にするので、アプリは今の受け口のまま静止状態から再生を始め、選んだ瞬間は色だけが変わる。解けた姿から静止状態への 1 コマの切り替えは、`cut` の周の境界と同じ種類の頭出しとして見え、巻き戻しには見えなかった。

途中の盤を描くゲームの扱いは、`rest-cut` だけに絞らない。濃淡2色の姿を解けた盤に直す案（選択肢 3）は残し、`rest-cut` の案と並べて人が選ぶ。直した方が濃淡2色の姿としても良いゲームや、一覧の選択中と動きを減らす設定でも解けた姿を見せたいゲームがあるためである。今の盤で止める案（選択肢 4）は、`rest-cut` で見せ場が周期の目安に収まらないなど、成り立たないときだけ使う。

### 帰結

- Good: 盤の地を持つゲームが、選んだときに解く場面の盤の色で見える。
- Good: 途中の盤を描くゲームで、濃淡2色の姿を変えずに、ヒーローで解けた瞬間を見せられる。
- Good: アプリの再生の受け口を変えずに済む。
- Bad: 面を敷くと一覧の選択中が重くなる。詰将棋では他のゲームの中央値の約 2.3 倍になり、人が見て受け入れた。重さはゲームごとに人に問う。
- Bad: `rest-cut` のゲームは、一覧の選択中と動きを減らす設定では途中の盤を見せ、解けた姿はヒーローの動きの中でだけ見える。
- Bad: 再生の形式が 3 つになり、スキルの契約・検査（`check_animation.py`・`observe_animation.cjs`）・自己チェックで扱う形が増える。

## 各選択肢の良し悪し

### 面は塗らず、線の色だけを変える

- Good: 要素を足さず、契約の字句どおりに済む。
- Bad: 盤が線だけになり、解く場面の姿から遠い。「盤が白黒なのはなぜ」と受け取られた。

### 濃淡2色の姿の線に囲まれて空いた面に、ゲーム固有色を敷く

- Good: 輪郭を変えずに、盤が解く場面の色になる。
- Bad: 一覧の選択中が重くなりやすい。

### 途中の盤を描くゲームでは、濃淡2色の姿を解けた盤に直す

- Good: 一覧の選択中も動きを減らす設定も、解けた姿を見せられる。
- Bad: 濃淡2色の姿を周の組み方の都合で変えることになり、未踏のマスなど途中の盤ならではの手がかりや、濃淡2段階の線を失うことがある。

### 途中の盤を描くゲームでは、濃淡2色の姿を直さず、今の盤で止める

- Good: 濃淡2色の姿も周の組み方も変えずに済む。
- Bad: 解けた瞬間を見せられない。

### 途中の盤を描くゲームでは、濃淡2色の姿を直さず、周の途中で解けた瞬間を見せてから今の盤へ戻る（`rest-cut`）

- Good: 濃淡2色の姿を変えずに、解けた瞬間を見せられる。選んだ瞬間は色だけが変わる。
- Bad: 一覧の選択中と動きを減らす設定では途中の盤になる。再生の形式と検査が増える。

## 補足

- 関連: ADR-0016、SCR-001（ホーム）。この ADR は ADR-0016 を補い、置き換えない。ADR-0016 の「周の終わりにある静止した姿から再生を始めてから、動きの始まりの姿へ切り替える」は、`rest-cut` では動きの始まりの姿が静止した姿そのものになるので、そのまま成り立つ。
- 空いた面に色を敷く決まりは `DESIGN.md` の「ゲームピクトグラム」を、`rest-cut` の定義と検査はスキル（`.claude/skills/design-game-pictogram-showcase/`）の契約と scripts を正とする。
