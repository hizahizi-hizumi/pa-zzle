# ブリッジパズルの評価を速さだけにし、架け直しを減点しない

## 要約

- **決定**: ブリッジパズルの評価は、問題ごとの基準時間と比べた速さだけの100点満点にする。架け直し・待った・盤面を戻す・交わる橋に阻まれた回数は記録だけにし、点に入れない。
- **主な選択肢**: 速さ 80点と架け直しの少なさ 20点 / 速さ 60点と正確さ 40点（一筆パズルの形）/ 速さだけ。
- **背景**: 認識合わせで「点数は速さが中心。橋の架け直しや戻すは減点しない（時間にだけ表れる）」と合意した。架けて本数の知らせを見ながら直すことが、このゲームの中心の操作である。
- **要約**: ブリッジパズル（橋をかけろ）の評価を、島の数・橋の本数・読みの量から求める基準時間と比べた速さだけの100点満点にし、架け直し・待った・盤面を戻す回数は減点しない。架け直しの少なさや正確さに配点する案と比べた。合意と、遊び方の中心の操作を罰さないことを重視した。

## 背景と問題

既存のゲームには、速さだけで採点するもの（リフレクション）と、速さと正確さ・効率を組み合わせるもの（一筆パズルの引き直し、バイナリパズルの置き直し）がある。ブリッジパズルでは、島ごとの本数の知らせを見ながら架けて直すことが遊び方の中心で、架け直しは押し間違いも含めて頻繁に起きる。合意は「点数は速さが中心。架け直しや戻すは減点しない」である。

## 判断基準

- 合意と食い違わないこと。
- 遊び方の中心の操作を罰さないこと。
- 二重減点（時間と回数の両方で同じ事実を数える）を作らないこと。

## 検討した選択肢

1. **速さ 80点と架け直しの少なさ 20点**
2. **速さ 60点と正確さ 40点（一筆パズルの形）**
3. **速さだけ**

## 採用した選択肢と理由

採用: **速さだけ**。理由: 合意どおりで、架け直しは時間にだけ表れるので二重に減点しない。架け直しの少なさに配点すると、本数の知らせを見ながら直す遊び方そのものを罰する。

### 帰結

- Good: 架け直し・待った・盤面を戻すを気にせず、知らせを見ながら直して遊べる。
- Good: 記録には事実と作業量だけを残すので、配点を変えても記録を移さずに済む。
- Bad: 読まずに試して直すプレイも、読むプレイと同じ時間で終われば同じ点になる。素朴な試し置きの模型（やり直し1回の時間を置いた推測）では、レベル4・5 の問題の一部が満点の速さに収まった（割合は[成績評価の資料](../パズル/導入調査/橋をかけろ/橋をかけろ成績評価.md)の素朴な解き方で取る評価の段階）。人の実測で校正するまで、この偏りは残る。

## 各選択肢の良し悪し

### 速さ 80点と架け直しの少なさ 20点

- Good: 読んで迷わず架けるプレイを、速さとは別に称えられる。試し置きのプレイと差が付く。
- Bad: 合意と食い違う。押し間違いの直しも減点し、知らせを見ながら直す遊び方を罰する。

### 速さ 60点と正確さ 40点

- Good: 一筆パズルと同じ形で、読みの正確さを称えられる。
- Bad: このゲームには一筆パズルの引き直しに当たる「読みを変えた」事実が無く、架け直しの回数は押し間違いと区別できない。
