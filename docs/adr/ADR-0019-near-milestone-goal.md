# 集めた量を全問の数ではなく次の節目までの残りで示し、節目に届いたら強く返す

## 要約

- **決定**: 図鑑の解いた問題の数を、全問の数と並べず、10・25・50・100・250・500・1000 問と刻んだ次の節目（最後は全問の数）までの残りと進みで示す。図鑑の前回からの変化を見せる演出で、解いた数を節目に届かせた問題を、ほかの変化より強く返す。記録のコレクションの塔も同じ節目を上端の目盛りにする。
- **主な選択肢**: 全問の数と並べ、割合・進み具合・称賛を付けない今の形を保つ / 全問に対する割合や進みを示す / 次の節目までの残りを示し、節目に届いたときだけ強く返す。
- **背景**: 試遊レビューで、「2/1000」「解いた問題 0 / 5000」のような遠い分母では、解いても進んだ手応えが無いと分かった。プロダクトオーナーは、リポジトリの決まりとゲーム制作の原則がぶつかるときは、原則の「面白さ」（目標は目の前に吊るす、褒める）を優先する方針を示した。
- **要約**: 解いた数を全問の数と並べる代わりに、すぐ手の届く次の節目までの残りと進みで示し、節目に届いたときは図鑑の変化の演出で強く返す。今の形を保つ案と、全問に対する割合を示す案と比べた。遠い分母では積み上がりが見えないことと、全問に対する割合は埋め切るノルマになることから、目の前の目標だけを見せることを選んだ。

> この ADR は ADR-0004 の一部（解いた問題の数を全問の数と並べて示すこと、割合・進み具合の演出や称賛を付けないこと）を置き換える。

## 背景と問題

ADR-0004 は、解いた問題の数を全問の数と並べ、割合・進み具合・称賛を付けないと決めた。埋めることがノルマにならないようにするためである。一方、問題集は1レベル数百〜千問、1ゲーム数千問あり、全問の数と並べると、何問解いても数字がほとんど動かない。試遊レビューでは、これが「やっても進まない」手応えとして受け取られた。

## 判断基準

- 解くたびに、目標へ近づいたことが見えること。
- 全部を埋めることや続けることを、ノルマや義務にしないこと。
- 節目に届いた瞬間を、もう1問遊びたくなる報酬として返すこと。

## 検討した選択肢

- 今の形を保つ: 全問の数と並べ、割合・進み・称賛を付けない。ノルマにはならないが、積み上がりが見えない。
- 全問に対する割合や進みを示す: 進んだことは見えるが、全問を埋めることが目標に見え、ノルマになる。
- 次の節目までの残りと進みを示し、節目に届いたら強く返す: 目標は常に近く、届いたら次の節目へ移るので、全問を埋めることを目標として見せない。

## 採用した選択肢と理由

次の節目までの残りと進みを示し、節目に届いたら強く返す案を採る。節目は桁ごとに刻み、問題が増えるほど間隔が広がるので、最初の数問から手応えがあり、長く遊んでも目標が遠すぎない。全問に対する割合は示さない。称賛は結果の場面に集める決まりは保ち、選ぶ場面で強く返すのは、集めた量が節目に届いたときだけとする。

## 帰結

- ゲームのホームの見出しとレベルのカードは、解いた数と次の節目までの残りを示す。全問の数は、状態ごとの数の合計で分かる。
- 図鑑の変化の演出に、節目に届いたマスの強い押し方が加わる。
- 記録のコレクションの塔の上端は、最も多いゲームの数以上で最も小さい節目にする。
