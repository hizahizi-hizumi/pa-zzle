# 線で描く盤の境界と地を揃え、題材の質感は個別に磨く

## 要約

- **決定**: 格子と面で描く盤の地・罫線・外周を揃える。題材に由来する質感はゲームごとに磨く。
- **主な選択肢**: 現状を保つ / 全ゲームの立体感を揃える / 全ゲームを平面にする / 線で描く盤の境界と地だけを揃える。
- **背景**: #626 で、質感を揃えること自体に価値があるかを、実際の10ゲームと6案の比較画面（#650）で検討した。
- **要約**: 線で描く盤の地・罫線・外周を共通の描画言語にし、題材の質感はゲームごとに磨く。現状の維持、物の立体感の統一、全面的な平面化と比べた。個別に磨く方針の下で、盤面の境界と格子の強弱は共通に扱えることを重視した。

## 背景と問題

10ゲームの盤面には、木目、車のイラスト、岩の厚み、平面の格子などが混在していた。線で描く盤同士でも外周の太さと色が異なり、マインスイーパーは開いたマスが画面の余白と同じ地になっていた。

プロダクトオーナーは、統一を前提にせず実際に比較することを求めた。6案を作った後、「個別に磨いていく」方向を選び、揃える対象として線で描く盤の外周・罫線・地を試すことにした。

## 判断基準

- 題材らしさと、ゲームを遊びたいと思える姿を残す。
- 同じ役割を持つ盤面の地・境界・格子は、ゲーム間で共通の強弱で読める。
- 盤の形や、ルールを表す区画・穴を変えない。

## 検討した選択肢

1. 現状を保つ。
2. 盤面に載る物、または動く物の立体感を全ゲームで揃える。
3. 全ゲームを平面にする。
4. 線で描く盤の境界と地だけを揃え、題材の質感は個別に磨く。

## 採用した選択肢と理由

採用: 選択肢4。プロダクトオーナーが選んだ個別に磨く方針を保ち、共通に扱う範囲を線で描く盤の地・罫線・外周に絞る。

### 帰結

- Good: 盤面の境界と、外周・区画・通常罫線の関係が揃う。
- Good: 木目、氷、車など題材の質感を、全ゲーム共通の立体感へ置き換えずに磨ける。
- Bad: 質感の幅は残るので、10ゲームの見た目が一律になるわけではなく、個別の調整は引き続き要る。

## 補足

- 対象はナンプレ、バイナリパズル、リフレクション、一筆パズル、マインスイーパー。
