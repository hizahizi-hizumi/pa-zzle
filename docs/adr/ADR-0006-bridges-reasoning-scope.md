# ブリッジパズルは試し置きを要する問題を出さず、1手の先読みは推理に含める

## 要約

- **決定**: ブリッジパズルは、人間向け解法器が数字の読みとつながりの読み（1手の先読みまで）で解き切れる問題だけを出す。1手の先読みより先まで試さないと決まらない問題（試し置き）は出さない。
- **主な選択肢**: 試し置きを要する問題も最上位に出す / 1手の先読みも範囲外にする / 1手の先読みまでを推理に含め、試し置きは出さない。
- **背景**: 認識合わせで「当てずっぽうではなく推理で解ける」ことを合意した。一方で、1手の先読みは「試しに1本架けてみる」読みにも見え、範囲の線をどこに引くかを決める必要があった。
- **要約**: ブリッジパズル（橋をかけろ）では、人間向け解法器が数字の読みとつながりの読み（閉じる組・唯一の通り道・1手の先読み）で解き切れる問題だけを出し、試し置きを要する問題は出さない。試し置きの問題も最上位に出す案、1手の先読みも範囲外にする案と比べた。合意の「推理だけで解ける」を守りつつ、最上位の問題数と歯ごたえを残すことを重視した。

## 背景と問題

認識合わせで、解き方は「当てずっぽうではなく、数字と行き先の数から必ず橋がある所を決めていく推理」と合意した（導入調査 Issue #576）。人間向け解法器は、数字の読み（A1 ちょうど・A2 少なくとも）、つながりの読み（C1p・C1g 組が閉じない、C3 唯一の通り道、D 1手の先読み）、試し置き（T）を段として持つ。

D は、1つの辺を仮に決め、その両端の島だけを1段進めて、本数が破れる・閉じる・孤立するなら退ける読みである。盤面の局所を見て矛盾が見える範囲に限られるが、「試しに1本架けてみる」と同じ形をしているので、推理と試し置きの線を D の前に引くか後に引くかを決める必要があった。T（仮に決めて推理を進め、矛盾が出るまで追う）を要する問題を出すかも同じ論点である。

## 判断基準

- 合意の「推理だけで解ける」を守ること。
- 最上位（レベル5）に十分な数と歯ごたえの問題を供給できること。
- 人間向け解法器で、出す問題と出さない問題を再現可能に分けられること。

## 検討した選択肢

1. **試し置きを要する問題も最上位に出す**
2. **1手の先読み（D）も範囲外にし、C3 までで解ける問題だけを出す**
3. **D までを推理として含め、試し置き（T）を要する問題は出さない**

## 採用した選択肢と理由

採用: **D までを推理として含め、試し置き（T）を要する問題は出さない**。理由: D は両端の島だけを見て矛盾が見える局所の読みで、矛盾を探して深く追う T とは手応えが違う。D を範囲外にすると、レベル5 の候補が約1割減り、つながりを何度も読む問題が減る（導入調査の計測）。T を要する問題は合意に反するので出さない。

### 帰結

- Good: 合意の「推理だけで解ける」を守り、問題集は人間向け解法器で T を使わずに解き切れたものだけになる。
- Good: レベル5 の候補を減らさずに済む。分類された候補では、レベル5 の約2割、レベル4 の約5% に D が現れる。
- Bad: D を人が推理と感じるか、試し置きと感じるかは人の試遊で確かめていない。試し置きと感じられたら、D を要する問題を外し、レベル5 の供給を見直す。
- Bad: 試し置きで解くプレイを評価で区別しない（速さだけの評価）ので、試して直すプレイが読むプレイと同じ時間で終われば同じ点になる。

## 各選択肢の良し悪し

### 試し置きを要する問題も最上位に出す

- Good: 最上位の候補が増え、最も重い問題を出せる。
- Bad: 合意の「推理だけで解ける」に反する。

### D も範囲外にする

- Good: 「試しに架ける」読みを一切求めず、線が明快になる。
- Bad: レベル5 の候補が約1割減り、つながりを何度も読む問題が減る。
