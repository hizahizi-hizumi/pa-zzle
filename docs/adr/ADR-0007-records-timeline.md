# 記録を遊んだ時間の流れに絞り、自己ベストと推移をゲームのホームへ移す

## 要約

- **決定**: 記録画面は、全ゲームのクリアと離脱を遊んだ時刻の順に並べ、直近の日ごとに遊んだ量を示す「いつ・何を遊んだか」の画面にする。自己ベスト・推移・記録のコピーは、ゲームのホームの見出しの並びから開く「成績」へ移し、開いている難易度の分だけを示す。
- **主な選択肢**: 記録画面でゲームと難易度を選んで成績を見る（今まで） / 記録画面に時間の流れを足し、成績も残す / 記録を時間の流れに絞り、成績をゲームのホームへ移す / 成績を結果画面だけにする。
- **背景**: 図鑑がゲームのホームに入り、ゲームと難易度ごとに「何を解いたか・どこまで集めたか」を担うようになった。記録画面のゲームと難易度ごとの視点はこれと重なり、ゲームをまたいだ視点は無かった。
- **要約**: 記録画面を、全ゲームのクリアと離脱を遊んだ時刻の順に並べる画面に絞り、自己ベスト・推移・記録のコピーをゲームのホームで開いている難易度の「成績」へ移す。記録画面で選ぶ今までの形、記録に時間の流れと成績を同居させる案、成績を結果画面だけに置く案と比べた。比較単位（ゲームと難易度）を既に選んでいる場所で成績を見せ、同じ選択を二度させないことと、図鑑と役割を重ねないことを重視した。

## 背景と問題

自己ベストの比較単位は、同じゲームの同じ難易度である（SPEC-002）。記録画面は、この比較単位をゲームと難易度の2つの選択で選び、自己ベスト・推移・履歴の表を見せていた。

ゲームのホームは、難易度を選んで始めることと図鑑を1画面にし（SPEC-004・SPEC-021）、開いている難易度を常に持つ。図鑑は、ゲームと難易度ごとに、どの問題を解いたかと問題ごとの最も良い出来を示す。記録画面でゲームと難易度を選び直すことは、ゲームのホームで選んでいるものの繰り返しになり、記録画面の履歴の表は、図鑑の問題ごとの出来と同じ単位の別の見え方になっていた。

一方、ゲームをまたいで、いつ・何を遊んだかを示す画面は無かった。ゲームのホームと図鑑はゲームごとに置き、ゲームをまたいだ合計や比較を示さない（SPEC-021）ので、ゲームをまたぐ視点は記録にしか置けない。

## 判断基準

- 成績の比較は、比較単位を選んでいる場所で、選び直しなしに見られること。
- 画面どうしで同じ単位の同じ情報を重ねないこと。
- 過去の自分と比べられること（FR-010）、推移を確かめられること（FR-021）、記録から同じ問題を遊び直せること（FR-020）を保ち続けること。
- 記録が数千件あっても、記録画面を開く時間を延ばさないこと。

## 検討した選択肢

1. **記録画面でゲームと難易度を選んで成績を見る**（今まで）
2. **記録画面に時間の流れを足し、成績も残す**
3. **記録を時間の流れに絞り、成績をゲームのホームへ移す**
4. **成績を結果画面だけにする**

## 採用した選択肢と理由

採用: **記録を時間の流れに絞り、成績をゲームのホームへ移す**。理由: ゲームのホームは開いている難易度を持つので、成績を比較単位の選択なしに出せる。記録画面は、図鑑が持たないゲームをまたいだ視点だけを担い、図鑑と役割が重ならない。

- 記録画面の行からは、そのプレイの結果を開く。1プレイの評価と指標、自己ベストとの差、同じ問題の遊び直しは結果画面が持つので、記録画面の行に重ねない。結果を開き直せない履歴と離脱したプレイは、その問題を選んだゲームのホームを開き、そこから遊び直せる。
- 日ごとに遊んだ量は、数・連続日数・称賛を付けずに濃さだけで示す。図鑑を能力の認定にも条件にも使わない（SPEC-021）のと同じく、遊んだ量を続けさせるための数や義務にしない。

### 帰結

- Good: 自己ベストと推移を、遊ぶ難易度を選んでいるその場で、選び直しなしに確かめられる。
- Good: 記録画面で、ゲームをまたいだ遊び方の流れを見られる。
- Good: 記録画面は記録の数に比例して描かないので、記録が多くても速く開ける。
- Bad: 廃止した難易度区分の比較単位は、ゲームのホームにその難易度が無いので、成績として見られない。その履歴は記録画面と結果画面には残る。
- Bad: 記録画面から同じ問題を遊び直すには、結果画面かゲームのホームを経るので1手増える。
- Bad: ゲームをまたいで成績を見比べる場所は無い。

## 各選択肢の良し悪し

### 記録画面でゲームと難易度を選んで成績を見る（今まで）

- Good: 成績が1か所にまとまる。
- Bad: ゲームのホームで選んでいるゲームと難易度を、記録画面で選び直させる。履歴の表が図鑑と同じ単位で重なる。ゲームをまたいだ視点が無い。

### 記録画面に時間の流れを足し、成績も残す

- Good: 今の成績の見方を変えずに、時間の流れを足せる。
- Bad: 1つの画面に、ゲームをまたぐ視点と比較単位ごとの視点が同居し、ゲームと難易度の選択が時間の流れには効かないまま残る。図鑑との重なりも残る。

### 成績を結果画面だけにする

- Good: 画面を増やさない。
- Bad: 推移を確かめる場所が無くなり、FR-021 を満たせない。
