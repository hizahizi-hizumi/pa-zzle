# 一筆パズルの難易度分析に2辺カットの推論を足し、仮置きを止まった局面で数える

## 要約

- **決定**: 一筆パズルの人間向け解法器の段階3に2辺カットの推論を足し、1段仮置きを止まった局面ごとに1回と数え、その数と長い先読みから「先読みの重さ」を求めてレベルを決める。研究用 Python の解法器との一致は捨て、製品の解法器を正とする。
- **主な選択肢**: 推論も数え方も今のまま閾値だけ動かす / 2辺カットだけ足す / 2辺カットと局面ごとの数え方を足す / さらに組の禁止や人間の読み方のモデルまで足す。
- **背景**: 試遊で、終点から逆にたどるとほぼ一本道の問題が仮置き4回のレベル4に分類され、レベル2〜4の差より問題ごとの差が大きかった。仮置きの回数は辺を1本ずつ決めるので候補を試す順の副産物になり、150問中101問で盤面の向きによって変わっていた。
- **要約**: 一筆パズル（ハミルトン路）の難易度分析で、人間向け解法器に2辺カット（2本の辺だけで残りとつながる領域を端の数から通り抜けるか決める）の推論を足し、1段仮置きを止まった局面ごとに数える方式に変え、局面の数と長い先読みの段から先読みの重さを求めてレベルを決める。閾値だけ動かす案、2辺カットだけ足す案、組の禁止や人間の読み方のモデルまで足す案と比べた。試遊で一本道に見えた問題を仮置き無しにでき、向きによるばらつきも減り、研究用 Python との一致より人間の手応えに合うことを重視した。

## 背景と問題

一筆パズルのレベルは、人間向け解法器（段階1〜6）が始点と盤面だけから道を決めるときに、局所・分断・パリティの推論で止まって1段仮置き（数手先の破綻を読む）を要した回数で決めていた。解法器は研究用 Python の `HumanSolver` と同じ推論・同じ数え方で、問題集の盤面で経過が一致することをテストしていた。

穴のルールの問題集（各レベル30問）を、論理パズルに慣れたプレイヤーが画面だけで遊んだところ、次の食い違いが出た。

- レベル4 の1問は、終点から逆にたどるとほぼ一本道でレベル1 並みだった。解法器は仮置き4回・先読み34手としていた。
- レベル2〜4 は、レベルの差より問題ごとの差の方が大きかった。レベル5 は確かに難しかった。

調べると原因は2つあった。

- 段階3（分断）が橋と関節点しか見ない。穴の盤面では、2本の辺だけで残りとつながる領域（2辺カット）を「端が無ければ入って出る」「終点があれば片方だけ使う」と読む場面が多いが、解法器はそれを仮置きで代わりに読んでいた。橋・関節点が仮置きの外で働いた問題は150問中1問で、2辺カットを足すと44問で働く。
- 仮置きは止まるたびに辺を1本だけ決めて数える。同じ局面で矛盾する仮置きが複数あっても1本ずつ数えるので、回数が候補を試す順の副産物になり、150問中101問で盤面の向きによって回数が変わった。人は止まった局面で見えた矛盾をまとめて使うので、辺の数ではなく局面の数が読む回数に近い。

## 判断基準

- 試遊の手応え（一本道に見える問題が易しく、レベル5 が難しい）に合うこと。
- 盤面の向きで難易度が変わりにくいこと。
- 推論が健全であること（解と食い違う辺を決めない）。
- 各レベルを継続して生成できること（採用率と1問あたりの時間）。

## 検討した選択肢

1. **推論も数え方も今のまま、閾値だけ動かす**
2. **2辺カットの推論だけ足す**
3. **2辺カットの推論を足し、仮置きを局面で数える**
4. **3に加えて、組の禁止や人間の読み方のモデルを足す**

## 採用した選択肢と理由

採用: **2辺カットの推論を足し、仮置きを局面で数える**。理由: 2辺カットで試遊の「一本道」の問題が仮置き無しになり、局面で数えると向きで回数が変わる問題が150問中101問から27問に減って、レベル2〜4 の差が手応えに近づいた。どちらも問題集150問×8向きと無作為盤面517面で、解と食い違う辺・矛盾・解の途中の反証が0だった。

レベルは、局面の数に、最も長い先読みが短い先読み（8手以内）に収まらずに手数の上限を広げた段の数を足した「先読みの重さ」で決める。局面で数えると回数が小さくまとまり（多くの問題で0〜3）、回数だけではレベル4・5 を分けられない。長い先読みが1回要ることを短い先読みの局面1つと同じ重さに数えると、1つの値でレベルを並べられる。

研究用 Python の解法器との一致は捨て、製品の解法器を正とする。2辺カットと局面の数え方を Python に移して一致を保つ手間に見合う使い道が無い。研究用 Python は段13 までの解法器として残す。全解探索（一意性の確認）は推論の変更と関係なく、Python との一致を残す。

### 帰結

- Good: 一本道に見える問題を易しく、向きによるばらつきを小さく分類できる。
- Good: 2辺カットは通れる辺の全域木で一度に見つけられるので、推論1回あたりの計算は橋・関節点と同じ程度で済む。
- Good: 推論ごとの小さな盤面テストと、製品の解法器で取り直した経過の回帰テストで振る舞いを守れる。
- Bad: 局面ごとに全ての候補を試すので、1局面あたりの計算が増える。
- Bad: 研究用 Python で製品の分析結果を再現できなくなる。分析を変えたときの照合は製品のテストだけになる。
- Bad: 生成器の版を上げたので、前の版の記録は遊び直せない。問題 ID も変わる。

## 各選択肢の良し悪し

### 推論も数え方も今のまま、閾値だけ動かす

- Good: 生成器の版を上げずに済む。
- Bad: 一本道の問題が仮置き4回と数えられる原因が残り、閾値ではレベル2〜4 の逆転を直せない。

### 2辺カットの推論だけ足す

- Good: 一本道の問題は直る。
- Bad: 回数が候補を試す順の副産物であることは残り、向きによるばらつきが大きいまま。

### 組の禁止や人間の読み方のモデルを足す

- Good: 組の禁止（使う辺が0本のマスで、輪や端の早すぎる連結になる2本の組を除く）は人が使う推論に近い。始点・終点の先端だけを仮置きする読み方のモデルは、レベル2 の「2段の場合分け」を再現する。
- Bad: 組の禁止はレベル2 の半数をレベル1 相当にし、それが手応えに合う証拠が無い。読み方のモデルはレベル2・4 の順序を再現しない。研究に残す。
