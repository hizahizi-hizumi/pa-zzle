# 選んでいるゲームのピクトグラムを、濃淡2色の姿と同じ形のままゲーム固有色と動きで見せる

## 要約

- **決定**: ホーム（SCR-001）の同格の候補の中で選んでいるゲームのピクトグラムを、ゲーム固有色で見せ、大きく見せるヒーローでは動きも付ける。その姿は濃淡2色の姿と同じ形にし、選んだ瞬間に変わるのは色だけにする。ヒーローの動きは止まった姿から始める。合わないゲームは、色付きの姿か濃淡2色の姿を描き直してそろえる。選んでいない候補と、ほかの画面のピクトグラムは濃淡2色の静止画のままにする。
- **主な選択肢**: 濃淡2色の静止画のままヒーローの構図で補う / すべてのピクトグラムを色付きにする / 選んでいるものだけアプリ共通の色で強調する / 選んでいるものだけゲーム固有色と動きで、形が違ってもよいとする / 選んでいるものだけゲーム固有色と動きで、形を濃淡2色の姿とそろえる。
- **背景**: ホームのヒーローが濃淡2色の静止画だけで寂しく、何をする遊びかも遊びたくなる期待も伝えにくかった。色付きの姿を試すと、濃淡2色の姿と形が違うゲームでは、選んだ瞬間に形が跳んでがたつきに見えた。
- **要約**: ホームで選んでいるゲームのピクトグラムを、ゲーム固有色で、ヒーローでは動きも付けて見せ、その姿は濃淡2色の姿と同じ形にして選んだ瞬間には色だけが変わるようにする。濃淡2色のまま構図で補う案、すべてを色付きにする案、アプリ共通色で強調する案、形の違いを許す案と比べた。何をする遊びかの区別（FR-001）と遊びたくなる期待（RQ-002）を見せつつ、一覧の統一感と選んだ瞬間のつながりを保てることを重視した。

## 背景と問題

ホームは、上部のヒーローに選んでいるゲームのピクトグラムを大きく出し、下部に候補を並べる。ピクトグラムは、並べたときに共通の描画言語を持つよう、濃淡2色の静止画で描いていた。

ヒーローは画面の大きな面積を占めるのに、濃淡2色の静止画1つだけで寂しかった。FR-001 は、遊ぶ人がそれぞれのゲームで何を考え何をする遊びかを見分けて選べることを求め、RQ-002 はこれからのプレイへの期待を高めたいとする。濃淡2色の静止画では、盤の形は分かっても、そのゲームで何をするのか、解けた・揃った瞬間がどう気持ちよいのかまでは見せにくい。

選んでいるゲームをゲーム固有色の姿と動きで見せる試作では、濃淡2色の姿と同じパズルに見える範囲で、解けた盤を描く、動きの余地のために縮めるといった違いを許していた。選んだ瞬間に濃淡2色から色付きへ変わる様子を試すと、その違いがどの切り替え方でも跳びや二重像として見え、がたつきが目立った。ヒーローも動きの始まりの姿から再生していたため、一覧の選択中とも違う絵から始まっていた。

## 判断基準

- 選んだゲームで何を考え何をする遊びかが、動きで分かること（FR-001）。
- 解けた・揃った瞬間の気持ちよさが見え、遊びたくなること（RQ-001・RQ-002）。
- 選んだ手応えは上の2つを満たせば生まれるものとし、それだけのための演出を足さないこと。
- 選んだ瞬間に形が跳ばず、濃淡2色の一覧・選択中・ヒーローが一つの絵としてつながること。
- 一覧の統一感と画面の落ち着きを、不必要に損なわないこと。
- 動きを減らす設定でも、ゲームの姿を欠かさず見せられること。

## 検討した選択肢

1. **濃淡2色の静止画のまま、ヒーローの構図や大きさで補う**
2. **すべてのピクトグラムを色付きにする**
3. **選んでいるものだけアプリ共通の色（ブランド色やアクセント色）で強調する**
4. **選んでいるものだけゲーム固有色と動きで見せ、濃淡2色の姿と形が違ってもよいとする**
5. **選んでいるものだけゲーム固有色と動きで見せ、形を濃淡2色の姿とそろえる**

## 採用した選択肢と理由

採用: **選んでいるものだけゲーム固有色と動きで見せ、形を濃淡2色の姿とそろえる**。理由: 何をする遊びかと解けた瞬間の気持ちよさは、盤の形だけでなく、色の分かれ方や揃い方、操作で何が動くかに表れる。選んでいる1つに限れば、色と動きで見せても一覧全体の統一感は崩れない。形が同じであれば、選んだ瞬間には色が入るだけになり、どんな切り替え方でもがたつきが生まれない。

色はアプリ共通の色ではなく、そのゲームを解く場面の色にする。これから遊ぶものの本当の姿を見せ、選んだあとのプレイと見た目をつなげるためである。

一覧の選択中の色付きの静止した姿と、ヒーローの動く姿は、ゲームごとに1つの SVG で兼ねる。静止した姿は動きを付けない状態そのものとし、ヒーローの動きは周の終わりにある静止した姿から再生を始めてから、動きの始まりの姿へ切り替える。動きを減らす設定では、ヒーローもこの静止した姿を見せる。

濃淡2色の姿のままでは解けた瞬間を止まりにできない、動きの余地が無いといったゲームは、色付きの姿を濃淡2色の姿に寄せるか、濃淡2色の姿を描き直してそろえる。どちらにするかは、ゲームごとに人が見て決める。

### 帰結

- Good: ヒーローで、選んだゲームの遊び方と解けた瞬間を、文章に頼らず見せられる。
- Good: 選んだ瞬間に形が跳ばず、濃淡2色の一覧から選択中、ヒーローまでが一つの絵としてつながる。
- Good: 色と動きを持つのが選んでいる1つだけなので、一覧の統一感と画面の落ち着きを保てる。
- Bad: ゲームごとに、濃淡2色のピクトグラムに加えて色と動きを持つ SVG を作り、両者の形をそろえて保つ手間が増える。
- Bad: 静止した姿の描き方が濃淡2色の姿に縛られ、ゲームによっては濃淡2色の姿の描き直しが要る。
- Bad: 色付きの SVG を持たないゲームは濃淡2色のまま出るため、ゲームによって選んだときの見え方に差が出る。

## 各選択肢の良し悪し

### 濃淡2色の静止画のまま、ヒーローの構図や大きさで補う

- Good: ピクトグラムを作り足さずに済み、一覧の描画言語を一つに保てる。
- Bad: 何をする遊びかと解けた瞬間の気持ちよさは、構図や大きさでは見せられない。

### すべてのピクトグラムを色付きにする

- Good: 選択中と未選択で絵を切り替えずに済む。
- Bad: 一覧がゲームごとの色で騒がしくなり、統一感と落ち着きを損なう。結果画面で外から与える色ともぶつかる。

### 選んでいるものだけアプリ共通の色で強調する

- Good: どのゲームでも同じ作り方で済み、選んだことははっきりする。
- Bad: 選んだことを示すだけで、何をする遊びかも期待も増えない。解く場面と違う色になり、これから遊ぶものの姿を見せられない。

### 選んでいるものだけゲーム固有色と動きで見せ、形が違ってもよいとする

- Good: 解けた盤や動きの余地を、濃淡2色の姿に縛られずに描ける。
- Bad: 試作したどの切り替え方でも、形の違いが選んだ瞬間の跳びや二重像として見え、隠しきれなかった。

### 選んでいるものだけゲーム固有色と動きで見せ、形を濃淡2色の姿とそろえる

- Good: 判断基準をすべて満たせる。
- Bad: ゲームごとの SVG 制作と形をそろえる手間、一部ゲームの濃淡2色の姿の描き直しが要る。

## 補足

- 関連: FR-001（遊ぶゲームを見分けて選べる）、RQ-001、RQ-002、SCR-001（ホーム）。
- 見せ方の決まりは `DESIGN.md` の「ゲームピクトグラム」と SCR-001 を正とする。SVG の置き場所・色の渡し方・動きの再生の受け口と、濃淡2色の姿とそろえる作り方は、コードと色付きの SVG を作るスキル（`.claude/skills/design-game-pictogram-showcase/`）を正とする。
- 選んだ瞬間に濃淡2色から色付きへどう色が入るか（切り替えの見せ方）は、この ADR では決めない。
