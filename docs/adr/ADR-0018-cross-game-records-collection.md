# 記録にゲーム横断のコレクションを加え、プレイ履歴と役割を分ける

## 要約

- **決定**: 記録画面でゲーム横断のコレクションとプレイ履歴を切り替え、集めた問題と月別変化をゲーム間で比較できるようにする。ゲーム単位の自己ベストはゲームのホームに残す。
- **主な選択肢**: 従来の履歴専用画面を維持 / コレクションを別画面に新設 / 記録画面の中でコレクションと履歴を分ける。
- **背景**: 記録をゲーム横断で振り返るとき、遊んだ日時だけでなく、問題を集めてきた量と評価の違いも見たいという要望があった。
- **要約**: 記録画面にゲーム横断のコレクションとプレイ履歴を併設し、問題ごとの最高評価と月別変化を見られるようにする。履歴専用画面の維持や別画面の新設と比較した。既存の記録への導線を活かし、図鑑のゲーム別視点と役割を分けながら、遊んできた違いを一覧で見渡せることを優先した。

## 背景と問題

ADR-0012 は記録画面を「いつ・何を遊んだか」に絞り、ゲーム・難易度ごとの自己ベストをゲームのホームへ移した。一方、各ゲームの図鑑では1ゲームの問題を集めた姿は分かるが、複数ゲーム間の積み上がり方や時期の違いは比べられない。ゲーム横断のコレクションを見たいという要望を満たすには、記録画面を履歴専用とする範囲を見直す必要がある。

## 判断基準

- さまざまなゲームの集めた問題数と評価構成を、一度に見比べられること。
- 既存のプレイ履歴と、ゲームのホーム・図鑑の責務を維持すること。
- 記録を別に保存せず、既存の履歴と同じ問題集・評価規則から集計すること。

## 検討した選択肢

1. **履歴専用の記録画面を維持する**
2. **コレクションを独立した別画面として追加する**
3. **記録画面でコレクションとプレイ履歴を切り替える**

## 採用した選択肢と理由

採用: **記録画面でコレクションとプレイ履歴を切り替える**。理由: ゲームをまたいだ記録にアクセスする導線をまとめつつ、二つの見方を同じ場所で行き来できるため。コレクションは解いた問題ごとの最高評価の積み上げと月別変化に限定し、ゲーム・難易度単位の自己ベストは引き続きゲームのホームが持つ。

### 帰結

- Good: 遊んだゲームの違いと、どの時期に問題が増えたかをゲーム横断で振り返れる。
- Good: プレイ履歴や図鑑の機能を重複させず、既存の記録を利用できる。
- Bad: 記録画面に二つの視点が入り、切り替え操作が必要になる。
- Bad: 問題集から外れた過去の問題はコレクションに表示されないが、履歴には残る。

## 補足

- ADR-0012 の「記録画面は遊んだ時間の流れに絞る」という範囲のみを置き換える。自己ベストの扱いは変更しない。
- 関連: SPEC-001、SPEC-027、SCR-005、PR #712。
