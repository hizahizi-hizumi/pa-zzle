# 難易度選択と図鑑を、ゲームのホームの1画面にする

## 要約

- **決定**: ゲームごとの難易度選択と図鑑を、レベルのカード・「ランダムに遊ぶ」・図鑑の台紙を並べたゲームのホーム（`/puzzles/<game>`）の1画面にする。ゲームのホームは最後に遊んだ難易度を開き、遊んだことが無ければ最も低い難易度を開く。結果やプレイから戻ると、その問題を選んだ状態で開く。
- **主な選択肢**: 難易度選択と図鑑を別の画面のまま、結果から図鑑へ直接移る操作を足す / 難易度選択と図鑑をゲームのホームの1画面にする。
- **背景**: 図鑑（ADR-0004）は難易度選択から開く別の画面で、難易度選択と同じ5つのレベルを選ぶ操作を持ち、結果から見るには難易度選択を経る必要があった。
- **要約**: ゲームごとの難易度選択と図鑑を、レベルのカード・ランダムに遊ぶ・図鑑の台紙を並べたゲームのホームの1画面にし、結果画面からは解いた問題を選んだ状態で開く。別の画面のまま結果から図鑑へ直接移る操作を足す案と比べた。同じ5つのレベルを選ぶ操作が2つの画面に分かれていたことと、解いた1問が台紙のどこに加わったかを結果からすぐ確かめられることを重視した。

## 背景と問題

これまで、ゲーム一覧で選んだゲームは難易度選択の画面（`/puzzles/<game>`）を開き、難易度の選択肢を1つ押すとその難易度でプレイが始まった。図鑑は難易度選択の見出しから開く別の画面（`/puzzles/<game>/zukan`）で、難易度ごとの台紙をレベルの切り替えで1枚ずつ見せていた（ADR-0004）。結果画面の次の行動は、「次の問題」を主に、同じ問題・記録を確認・難易度変更・ホームを並べていた。

この形には次の問題があった。

- 難易度選択と図鑑が、同じ5つのレベルを選ぶ操作をそれぞれ持っていた。難易度選択では遊ぶ条件として、図鑑では見る台紙として、同じゲームの同じレベルを2つの画面で選び直していた。
- ADR-0004 は、図鑑を開くのは1問解いた直後にその1問が台紙のどこに置かれたかを見たいときや、次に遊ぶ問題を自分で選びたいときだとした。しかし結果から図鑑へは、難易度変更で難易度選択へ戻り、さらに図鑑を開く2段階が要った。
- 難易度を選んで始める流れの中に図鑑が無く、空き枠や挑戦中の問題が、もう1問遊ぶ理由（ADR-0004 の楽しさ2）として目に入るのは、図鑑をわざわざ開いたときだけだった。

## 判断基準

- 選んで始めるまでに、選択に関係しない手間を足さないこと（NFR-006）。
- 製品が特定の難易度を推奨として強調せず、ほかの難易度を選ぶ自由を失わせないこと（SPEC-004、`docs/パズル/難易度提供.md`）。
- 解いた1問が台紙のどこに加わったかを、結果からすぐ確かめられること。
- 続けて遊ぶ流れを、図鑑の変化の演出で妨げないこと（ADR-0004 の、解くたびには見せない決定）。
- 1プレイの区切り、開始条件、評価、図鑑の中身の意味を変えないこと。

## 検討した選択肢

1. **別の画面のまま、結果から図鑑へ直接移る操作を足す**
2. **難易度選択と図鑑を、ゲームのホームの1画面にする**（レベルのカードで台紙を切り替え、選んでいるレベルで「ランダムに遊ぶ」）

## 採用した選択肢と理由

採用: **難易度選択と図鑑を、ゲームのホームの1画面にする**。理由: 遊ぶレベルと見る台紙を1つのレベルのカードで選べ、レベルを選ぶ操作が1つになる。難易度を選んで始めるたびに台紙が目に入り、空き枠や挑戦中の問題から遊ぶ問題を自分で選ぶこと（ADR-0004 の楽しさ2・4）が、始める流れの中で起きる。別の画面のまま結果から図鑑へ移る操作を足す案は、結果の次の行動を増やし、レベルを選ぶ操作が2つある形を残す。

あわせて次を決めた。

- **開くレベル**: ゲームのホームは、そのゲームで最後にクリアまたは離脱したプレイの難易度を開く。これは利用者が前に選んだ難易度を引き継ぐもので、製品が特定の難易度を推奨することには当たらない。
- **初めてのゲームで開くレベル**: そのゲームを遊んだことが無ければ、最も低いレベルを開く。ゲームのホームは開いているレベルの台紙を見せる画面なので、開いているレベルが要る。どのレベルも開かない特別扱いは、初めてのゲームだけ台紙の無い別の画面の形を作り、カードを選んでから「ランダムに遊ぶ」を押す2タップを初回にだけ求める。最も低いレベルは並びの先頭にあるレベルで、カードに印やラベルを足して強調しないので、推奨にはならない。ほかのレベルはカードを1タップで選べるので、`docs/パズル/難易度提供.md` の、初期選択を定めても他の難易度を選ぶ自由を失わせないことを保つ。
- **始めるまでの手間**: 遊んだことの無いゲームでも、最も低いレベルなら「ランダムに遊ぶ」の1タップで始められ、2回目からは最後に遊んだレベルで1タップで始められる。開いているのと別のレベルで始めるときは、カードを選んでから「ランダムに遊ぶ」を押す2タップになる。これまでの難易度選択は選択肢を押すとすぐ始まる1タップだったので、増えたのは「ランダムに遊ぶ」を押す1回である。レベルのカードはそのレベルの台紙を開く操作も兼ねるので、選ぶだけでプレイを始めることはできない。「ランダムに遊ぶ」は始めることそのものの操作で、選んだ内容を確かめさせる確認ではなく、NFR-006 が求めない選択に関係しない入力・確認には当たらない。
- **結果のあと**: 次の行動は「次の問題」を主とし、「ゲームのホームへ」と「もう一度」（同じ問題）を従とする。「ゲームのホームへ」は解いた問題のマスを選んだ状態で開き、その1問が台紙のどこに加わったかをすぐ見せる。これまでの「難易度変更」は「ゲームのホームへ」に含まれる。結果の「記録を確認」はなくし、記録はアプリのホームから開く。ホームへはブランドの帯から戻る。プレイ中にゲームのホームへ戻るときも、今の問題を選んだ状態で開く。
- **変化を見せる時機**: 前回からの変化は、ゲームのホームを開いたときに見せる。解いてからゲームのホームへ戻れば、そのたびに変化の演出が出る。ADR-0004 が退けたのは、解くたびに結果画面などで見せることだった。ゲームのホームへ戻るのは利用者が選んだときだけで、主の「次の問題」で続けて遊ぶ間は演出を挟まず、何問か遊んだ分の変化を戻ったときにまとめて受け取る。ADR-0004 の、解くたびには見せない決定と食い違わない。
- **URL**: ゲームのホームは、これまでの難易度選択と同じ `/puzzles/<game>` に、ゲームごとの静的なルートと専用の View で置く。全ゲームを1つの動的なルートにすると、静的な `/puzzles/<game>/play/` を持つゲームでは静的な枝が優先され、ゲームのホームが開けなくなる。これまでの `/puzzles/<game>/zukan` は、ブックマークや履歴から開いても迷わないよう、そのゲームのホームへ置き換えて移す。

### 帰結

- Good: 結果から1タップで、解いた1問が加わった台紙を見られる。
- Good: レベルを選ぶ操作が1つになり、始めるたびに台紙の空き枠と挑戦中の問題が目に入る。
- Good: 初めてのゲームでは最も低いレベルで、2回目からは最後に遊んだレベルで、1タップで始められる。画面の形は遊んだことの有無によらず1つになる。
- Bad: 開いているのと別のレベルで始めるときは、カードを選んでから始める2タップになる。
- Bad: 初めてのゲームでは、利用者が選ぶ前から最も低いレベルが開いている。
- Bad: 1画面に見出し・カード・主操作・台紙を収めるので、スマートフォンでは台紙の高さが減り、カードを横に送らないと全レベルを見られない。
- Bad: 結果の次の行動から記録へ移れなくなる。
- Bad: 解いたあとに別のレベルを選ぶためにゲームのホームへ戻っても、変化の演出が出る。

## 各選択肢の良し悪し

### 別の画面のまま、結果から図鑑へ直接移る操作を足す

- Good: 選択肢を押せばすぐ始まる難易度選択と、図鑑の画面をそのまま保てる。
- Bad: 結果の次の行動が増える。
- Bad: 同じレベルを選ぶ操作が2つの画面に残り、始める流れの中で台紙が目に入らない。

### 難易度選択と図鑑を、ゲームのホームの1画面にする

- Good: 遊ぶレベルと見る台紙を1つの操作で選べる。
- Good: 結果から、解いた1問を選んだ台紙へ1タップで移れる。
- Bad: レベルを変えて始めるときに1タップ増える。
- Bad: 1画面に置く情報が増える。

### 初めてのゲームで、どのレベルも開かない（退けた案）

- Good: 利用者が選ぶまで、製品がどのレベルも開いておかない。
- Bad: 開いているレベルが無いので台紙を見せられず、初めてのゲームだけ台紙の無い別の画面の形が要る。
- Bad: 初めてのゲームだけ、カードを選んでから「ランダムに遊ぶ」を押す2タップになる。

### 初めてのゲームで、最も低いレベルを開く（採用）

- Good: 画面の形が1つになり、初めてのゲームでも「ランダムに遊ぶ」の1タップで始められる。
- Good: 最も低いレベルは並びの先頭で、強調しないので推奨にならず、ほかのレベルもカードを1タップで選べる。
- Bad: 利用者が選ぶ前から、最も低いレベルが開いている。

## 補足

- 現在の決まりは、開くレベルを SPEC-004、図鑑を SPEC-021、画面を `DESIGN.md` の「ゲームのホーム」「結果」を正とする。
- 関連: ADR-0004（図鑑。入口と、変化を見せる「図鑑を開いたとき」をこの ADR で変えた）。
- 未確定: スマートフォンでカードを横に送ること、結果の「記録を確認」をなくすこと、プレイ中の戻るでも今の問題を選んで開くことは、オーナーの確認を待っている。
