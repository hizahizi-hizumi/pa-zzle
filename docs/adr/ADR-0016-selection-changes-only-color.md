# 選んだ瞬間に変わるのはピクトグラムの色だけにする

## 要約

- **決定**: パズル選択で選んだ瞬間、ピクトグラムは白黒の姿から色だけが変わるようにする。色付きの静止した姿は白黒の姿と同じ形で色だけが違うものとし、ヒーローの動きはその静止した姿から始める。合わないゲームは、色付きの姿か白黒の姿を描き直してそろえる。
- **主な選択肢**: 姿が違ってよいまま切り替え演出で隠す / 白黒と色付きの間を形ごと変形させる / 静止した姿を白黒の姿にそろえ、色だけを変える。
- **背景**: 白黒から色付きへ切り替わる瞬間の試作で、白黒の姿と色付きの姿の形や状態の違いが、切り替えのたびにがたつきとして見えた。
- **要約**: パズル選択で選んだ瞬間、ピクトグラムは形を変えずに色だけが変わるようにし、色付きの静止した姿を白黒の姿と同じ絵にそろえ、ヒーローの動きもその姿から始める。切り替え演出で違いを隠す案、形ごと変形させる案と比べた。選んだ瞬間のがたつきを無くすことと、どのゲームでも同じ決まりで作れることを重視した。

## 背景と問題

ADR-0015 で、パズル選択の選択中のピクトグラムを、一覧ではプレイ画面の色の静止した姿、ヒーローではその色と動きで見せることにした。色付きの静止した姿は、白黒の姿と「同じパズルに見える」範囲で、盤の中身や配置を変えてよいとしていた。そのため、解けた状態を描く、動きの余地のために縮める、といった違いがゲームごとに生まれた。

選んだ瞬間に白黒から色付きへ変わる様子を試作したところ、どの切り替え方でも、形・位置・中身の違いが跳びや二重像として見え、がたつきが目立った。ヒーローは動きの始まりの姿から再生していたため、白黒の姿とも一覧の静止した姿とも違う絵から始まっていた。

## 判断基準

- 選んだ瞬間に形が跳ばず、がたつかないこと。
- 白黒の一覧、選択中の静止した姿、ヒーローの動きが、一つの絵としてつながって見えること。
- どのゲームでも同じ決まりで作れ、検査で確かめられること。
- 動きで何をする遊びかと解けた瞬間の気持ちよさを見せる、ADR-0015 の狙いを損なわないこと。

## 検討した選択肢

1. **姿が違ってよいまま、切り替え演出で違いを隠す**
2. **白黒の姿と色付きの姿の間を、形ごと変形させる**
3. **静止した姿を白黒の姿にそろえ、選んだ瞬間は色だけを変える**

## 採用した選択肢と理由

採用: **静止した姿を白黒の姿にそろえ、選んだ瞬間は色だけを変える**。理由: 形が同じであれば、どんな切り替え方でも色が入るだけになり、がたつきが原理的に生まれない。白黒と色付きの対応を絵の決まりとして持てば、ゲームごとの切り替え演出の調整も要らない。

ヒーローの動きは、周の終わりにある静止した姿から再生を始め、少し見せてから動きの始まりの姿へ切り替える。選んだ直後のヒーローは、一覧の選択中と同じ絵になる。

白黒の姿のままでは解けた瞬間を止まりにできない、動きの余地が無いといったゲームは、色付きの姿を白黒の姿に寄せるか、白黒の姿を描き直してそろえる。どちらにするかは、ゲームごとに人が見て決める。

### 帰結

- Good: 選んだ瞬間に形が跳ばず、白黒から色付きへのつながりが自然になる。
- Good: 白黒の一覧・選択中・ヒーローが一つの絵として読める。
- Good: 白黒と色付きを片方の図形からもう片方を写して作れば、形は作り方の段階で一致する。
- Bad: 既存の色付きの姿のうち、白黒の姿と違うものは作り直しになり、白黒の姿を描き直すゲームも出る。
- Bad: 静止した姿の描き方が白黒の姿に縛られ、見せ場の後の姿を止まりにする自由が減る。

## 各選択肢の良し悪し

### 姿が違ってよいまま、切り替え演出で違いを隠す

- Good: 既存の色付きの姿をそのまま使える。
- Bad: 試作したどの切り替え方でも違いが跳びや二重像として見え、隠しきれなかった。

### 白黒の姿と色付きの姿の間を、形ごと変形させる

- Good: 違う絵どうしでもつながりを見せられる。
- Bad: ゲームごとに変形を作る手間が大きく、変形そのものが選んだ手応えのためだけの演出になる。

### 静止した姿を白黒の姿にそろえ、選んだ瞬間は色だけを変える

- Good: 判断基準をすべて満たせる。
- Bad: 既存の色付きの姿の作り直しと、一部ゲームの白黒の姿の描き直しが要る。

## 補足

- 関連: ADR-0015（選択中のピクトグラムをプレイ画面の色と動きで見せる）。ADR-0015 の決定は保ち、色付きの静止した姿の描き方と、ヒーローの再生の始め方をこの ADR で定める。
- 見せ方の決まりは `DESIGN.md` の「ゲームピクトグラム」を正とする。白黒と色付きの作り方は、色付きの SVG を作るスキル（`.claude/skills/design-game-pictogram-showcase/`）を正とする。
- 選んだ瞬間に白黒から色付きへ変わる見せ方そのもの（どう色が入るか）は、この ADR では決めない。
