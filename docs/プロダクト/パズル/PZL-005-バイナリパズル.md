# PZL-005 バイナリパズル

## 遊びの核

- 盤面の局所的な並びから確定できる場所を探し、行・列全体の制約へ読みを広げる。
- 仮置きで試すのではなく、ルールから確実な配置を見つける。

## 出題方針

- 推測や後戻りを必要としない問題を出す。
  - 一つの行・列を読む推論だけで最後まで解ける範囲を守る。
- 単純に盤面を何度か見るだけで終わる問題は避ける。
  - 次に確定できる場所を探す挑戦を残す。
- 空きマス数だけで難易度を見分けられないようにする。
  - 空きの多さではなく、必要な推論で難しさを分ける。

## プレイ体験

- ルール違反は控えめに知らせ、考えている盤面を騒がしくしない。
  - 入力途中に一瞬だけ発生する違反は強調しない。
- 連続するタイルの違反と、行・列全体の違反を見分けられるようにする。
  - 直す必要のないタイルまで誤りに見せない。

## チュートリアル

- 同じルールを行と列に当てはめ、見方を順に増やしていく。
  - 前に教えた見方だけでは決まらない手を使って、次の見方を覚えさせる。
- 途中で切り替わるタイルを、置き間違いとして即座に責めない。
  - 選び終わってから必要な違反を知らせる。
- 自分で解く段階でも、完成解と一致するかは直接知らせない。
  - 学んだルールを当てはめて決める体験を守る。

## 難易度

### 基準とするプレイ

- 違反の知らせに頼らず、確定したタイルだけを置くプレイを基準とする。
- 入力回数や所要時間そのものを難しさに含めない。

### 挑戦

- 隣り合うタイルや個数から確定し、次に行・列全体の候補を比較する。
- 推測をせず、盤面の中から次の確定手を発見する。

### 段階設計

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 三つ並びを避ける局所的な形を見つけて進める。 |
| 2 | 行・列のタイル数を数えて残りを決める。 |
| 3 | 残り一つのタイルをどこへ置くか読む。 |
| 4 | 完成済みの行・列と重複しない置き方を読む。 |
| 5 | 重複の回避を何度も使い、候補が多い行・列を見比べる。 |

- 推論の深さと、それを必要とする局面の多さで段階を分ける。
- 二本以上の行・列を組み合わせる高度な推論は、現在の提供範囲に含めない。

## 評価

### 称えたいプレイ

盤面を読んで確定したタイルだけを置き、置き直しを抑えて解き切ることを最も称える。

### 採点項目

- **正確性**：置き直し、盤面を戻すこと、待ったを評価する。
- **速さ**：問題の作業量に応じた基準時間と比べる。
- 入力回数や違反の発生自体は評価しない。

### 配点

- 正確性を速さより重視する。
  - 推測なしで解ける問題を出すため、確実に読んで置くことを称える。
- 盤面を戻すことは、待ったや少数の置き直しより重く扱う。
  - 試し置きの跡をまとめて消せるため。
- 単純な押し間違いの修正と、試し置きを繰り返す行動は区別する。

### 自己ベスト

- 問題集から外れた問題の記録も、比較対象に残す。
- 過去の作業量に基づいた記録を、問題集の更新で失わせない。
