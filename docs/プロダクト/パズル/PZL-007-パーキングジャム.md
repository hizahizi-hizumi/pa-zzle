# PZL-007 パーキングジャム

## 遊びの核

- 車が通れる道と塞いでいる車を読み、出庫できる順序を見つける。
- 出られそうに見えて出られない車や方向を見抜く。

## 出題方針

- どの順序で出庫しても、成立した操作で手詰まりにならない問題を提供する。
  - 見えている進路と塞がり方を読むことに挑戦を絞る。
- 出庫の順序を考える場面がほとんどない問題は避ける。
  - 一目で全車を出せる盤面を増やさない。
- 未検証の極端に深い依存関係は無理に出さない。
  - 作れたことではなく、遊んで確かめられた挑戦を提供する。

## プレイ体験

- 出せない操作は、車がどの方向で何に阻まれたか分かるように返す。
  - 動きを減らす設定でも、操作が届いたことが分かるようにする。

## チュートリアル

- 先に塞いでいる車を出す体験をさせる。
  - 手順の後にも塞がれた車を残し、自分で順序を考えて出させる。
- 出せない操作への説明は、一般的なルールではなく、今選んだ方向と障害物を伝える。
  - 見えない動きがあっても、操作と結果を結び付けられるようにする。

## 難易度

### 基準とするプレイ

- 車と出口を見て、試さずに出せる方向と順序を決めるプレイを基準とする。
- 出庫した手数は難しさに含めない。

### 挑戦

- 塞いでいる車をさかのぼって、何を先に出せば進路が開くかを読む。
- 開口の位置や車線を見誤らず、試さずに正しい方向を選ぶ。

### 段階設計

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 浅い塞がり方を見て、すぐ出せる車から出す。 |
| 2 | 浅い塞がりに、出られそうに見える方向の紛らわしさが加わる。 |
| 3 | 複数の車の依存を二段ほどさかのぼる。 |
| 4 | 依存の読みと、多数の紛らわしい進路を見比べる。 |
| 5 | さらに深い依存や枝分かれを、広い盤面の紛らわしさと合わせて読む。 |

- 依存関係の深さ・広さと、読み違いの誘われやすさを組み合わせて段階を分ける。
- 規模は補助的な要因とし、車の台数だけで難易度を決めない。

## 評価

### 称えたいプレイ

出せない方向を選ばず、盤面を読んで出庫判断を続けるプレイを最も称える。

### 採点項目

- **正確さ**：出られない方向を試したことを評価する。
- **速さ**：車の数や塞がり方による作業量を反映した時間で評価する。
- **安定性**：成立した出庫判断を待ったや盤面を戻すことで取り消したことを評価する。
- 手数そのものは評価しない。

### 配点

- 正確さと速さを同程度に重視する。
- やり直しは、成立した判断を戻した事実として軽く扱う。

### 自己ベスト

個別の設計判断なし。
