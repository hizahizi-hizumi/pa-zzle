# PZL-002 ウォーターソート

## 遊びの核

- 限られた空きを使い、どの色を先に出して、よけて、まとめるかを考える。
- 目先で注げるだけではなく、後の注ぎ先を残す順序を見つける。

## 出題方針

- 初めから単色で完成しているボトルを置かない。
  - 色をまとめていく手応えを最初から残す。
- 自然な注ぎを繰り返すだけで解ける問題と、先読みしないと詰む問題を段階的に揃える。
  - 色数や総手数の違いだけでは難易度を作らない。

## プレイ体験

- 手詰まりは、実際に進める手がなくなったところで知らせる。
  - 先の失敗を予告して、注ぐ順番を考える楽しさを奪わない。
- 注ぎ先を選べないことは盤面の反応で伝える。

## チュートリアル

- 注ぐ先の条件を順番に体験させる。
  - 満杯のボトルが使えないことを教える前に、見かけ上注げそうな満杯のボトルを置かない。
- 完成したボトルはもう注げないことを、初めて色を揃えたときに伝える。
  - 試して止められる前に、完成の意味を理解できるようにする。
- 手を離した後は、順当に色を揃えれば詰まらない盤面で解かせる。

## 難易度

### 基準とするプレイ

- 盤面を読んで注ぐ順序を決め、待ったや盤面を戻すことに頼らないプレイを基準とする。
- 色数や最短手数そのものを難しさにしない。

### 挑戦

- 必要な色を後から取り出せる状態を残すよう、空きボトルの使い方を先読みする。
- 自然な手がそのまま正解になるとは限らないことを見抜く。

### 段階設計

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 同じ色をまとめていけば解ける。 |
| 2 | 自然に進めると、ときどき手詰まりになる。 |
| 3 | 空きボトルの使い方を考えないと手詰まりになる。 |
| 4 | 何手か先の色の移動を考える必要がある。 |
| 5 | 先を読まないと、ほぼ確実に手詰まりになる。 |

- 難易度は、自然に注ぐプレイがどれだけ詰みやすいかを中心に分ける。
- 最短解の探索量や経路の複雑さだけでは難易度を決めない。

## 評価

### 称えたいプレイ

少ない手数で、手戻りを抑え、速く色を揃えるプレイを称える。

### 採点項目

- **効率**：実際の手数を最短手数と比べる。
- **速さ**：問題の作業量を考慮した基準時間と比べる。
- **正確性**：取り消した手や盤面を戻す前の手を評価する。

### 配点

- 効率と速さを同程度に重視し、手戻りは補助的に評価する。
- 待ったや盤面を戻した回数そのものは追加で減点しない。

### 自己ベスト

個別の設計判断なし。
