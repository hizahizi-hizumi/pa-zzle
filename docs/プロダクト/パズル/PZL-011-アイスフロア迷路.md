# PZL-011 アイスフロア迷路

## 遊びの核

- 止まれない氷の上で、止まる場所を先まで読んでゴールへ進む。
- 自分の滑りで変わった地形を、何手も後に利用する道筋を組み立てる。

## 出題方針

- 出題する地形は、進路の判断に関わるものだけにする。
  - 使わない飾りの地形が、解く手掛かりの見え方を曖昧にしないようにする。
- 正解の道筋にある地形だけを置かない。
  - もっともらしい別の選択で働くおとりも用意し、置かれた要素自体を答えの印にしない。
- 同じ向きの連打や一本道が続く問題を避ける。
  - 思考せず操作を繰り返す時間を減らす。
- 初期盤面と変化後の盤面を同じように読んでも解ける問題は避ける。
  - 地形を変えてから使うことを、解法の中心にする。

## プレイ体験

- 滑りの途中でゴールを通過しても、止まれるかどうかを考える体験を守る。
  - ゴールで止まるまでの道筋を読ませる。
- 滑りの跡や地形の変化を、盤面で追えるようにする。
  - 先の動きを確かめて、変化した後の盤面を考えられるようにする。
- 詰みに入っても、すぐには知らせない。
  - 気づいて考え直す余地を残し、同じ状態を繰り返している場合には知らせる。
- 詰みを知らせるときは、動けないとは言わない。
  - 動けてもゴールで止まれない場合があるため。

## チュートリアル

- 盤面は、難易度1と同じ氷・岩・床だけにし、もろい岩・薄い氷・雪・滑る氷の塊は置かない。
- 岩で止まる・床で止まる・ゴールを通り過ぎる・止めたいマスの先の岩に向けて滑らせる、を1つずつ使わせる。最後の手順で使わせる読みは、止めたいマスの先の岩に向けて滑らせる読みとし、手を離した後は、ゴールの先の止め石へ向かう道筋を自分で組み立てさせる。
- 手を引く間は、駒と印のマスと、印のマスで駒を止める物だけを覆いから抜き、これから滑る通り道や道筋は見せない。
  - これから滑る通り道や道筋、ほかの手順での向きを見せると、止めたいマスへの向きを自分で読まずに済むため。
- 完成形から開始盤面へ戻す導入で、正解の移動経路を見せない。
  - 逆再生が答えのヒントになってしまうため。

## 難易度

### 基準とするプレイ

- 止まる位置と、滑った後の地形を読んで進むプレイを基準とする。
- 試し滑りに頼らず、後の道筋を組み立てることを基準にする。
- 最短手数や盤面の広さそのものを難易度に含めない。

### 挑戦

- 壁や床を使って止まる場所をつなぎ、ゴールで止まる経路を作る。
- 地形を変える滑りを先に使い、何手も後でその地形を利用する。

### 段階設計

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 氷と岩を中心に、ゴールの先の止め石を使う。 |
| 2 | 止め石への回り込みや、ゴールを通り過ぎて戻る経路を長く読む。 |
| 3 | 変化する地形の入門として、少ない変化から一つの気づきを得る。 |
| 4 | 変化させた地形を、後の手で何度も利用する。 |
| 5 | 何手も前に作った地形を繰り返し利用し、止め役も自分で作る。 |

- 地形の種類や数より、自分で作った地形に頼る読みの深さで段階を分ける。
- 床が有るかどうかだけでは難易度を変えない。
- 読み切れないほど深い問題は出さない。
  - 複雑さの上限を設け、難しくても最後まで遊べるようにする。

## 評価

### 称えたいプレイ

止まる場所と地形の変化を読んで、少ない滑りでゴールへ進むプレイを称える。

### 採点項目

- **効率**：総滑り手数を最短手数と比べる。
- **速さ**：盤面の規模、最短手数、変化する地形の作業量を考慮した時間で評価する。
- 待ったや盤面を戻した回数は追加で減点しない。

### 配点

- 効率を速さより重視する。
  - 短い問題で一度試しただけで大きく減点されないようにする。
- 総手数にはやり直す前の滑りも含め、読み直しの量を効率に表す。

### 自己ベスト

- 問題集から外れた問題も、元の盤面と最短手数を基に評価して比較に残す。
