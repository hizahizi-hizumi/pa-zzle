# PZL-015 送迎パーキング

## 遊びの核

- 乗客の列を先まで読み、どの車をいつ待機枠へ出すかを計画して、全員を送り出す。
- 列の先頭に合う車を出すだけでは何人か先で詰む局面で、その結果を読んで出す車と順番を選ぶ。
  - 同じ駐車場を使うパーキングジャム（PZL-007）は、どの順で出しても詰まない。送迎パーキングは、出せる車を出したことが後の詰みを生む読みのゲームとして別に置く。

## 出題方針

- 推測なしに、読みだけで全員を送り出せる問題を出す。解は複数あってよい。
- 待機枠は、その問題を解ける最小の数にする。
  - 余った枠で読まずに済む問題にしない。待機枠だけが違う同じ問題を、別の難易度に置かない。
- どう出しても必ず全員を送り出せる問題は出さない。
  - 読む所が無いため。
- どの難易度も、同じくらいの規模の盤面で遊べるようにする。
- 列だけで乗客を車へ割り当てる計画を立てれば解ける問題も、難しい問題から外さない。
  - 列を先まで読んで計画することが、このゲームの挑戦そのものであるため。

## プレイ体験

- 罠（全員を送り出せる盤面から、送り出せなくなる車を出すこと）に入っても、プレイ中は知らせない。
  - 「この手は負け」と伝えると、この先の詰みを教える補助になるため。
- 詰んだときは、出せる車が無いことだけを知らせ、どの手が原因かは示さない。
  - 原因は何台か前の出し方にあることが多く、それを探すこと自体を遊びに残す。
- 詰みの知らせで駐車場を隠さない。
  - 詰んだ後に原因を探すとき、駐車場の車を見て考えるため。
- 待った・盤面を戻す・リセットをすべて提供する。
  - 詰んでから戻して原因を探すことを、遊びに残すため。

## チュートリアル

- 先頭に合う車を出す、前を塞ぐ車があると出られない、待機枠が埋まると出せない、の3つの決まりを順に体験させる。
- 塞がれた車は、前の車を出すと出られるようになる流れで体験させ、塞がれた車を押させる手順は足さない。
  - 盤面1枚の手順を増やさず、本番の難易度1を進めるのに要る決まりと読みだけを手順で使わせるため（GAME-010）。
- 同じ色の車が2台待っていれば先に入った車から乗る決まりは、手順を足さず、解き終えたときの振り返りで示す。
  - 本番の難易度1を進めるのには要らない決まりで、盤面1枚の手順を増やさないため（GAME-010）。

## 難易度

### 基準とするプレイ

- 列と駐車場が全部見え、負けの知らせが無い中で、罠に入らずに先を読んで解くプレイを基準とする。
- 列の長さ・車の台数・手数・盤面の広さ・塞ぐ車を掘る台数・戻して試し直す量は、難しさに含めない。

### 挑戦

- 列を先まで読み、いま出す車が何人先で待機枠をふさぐか（座席が余る、必要な車が出られなくなる）を見抜いて、出す車と順番を決める。

### 段階設計

利用者に見せる一言は、この表を正とする。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 列の先頭に合う車を出していけば解ける。 |
| 2 | 先頭に合う車の中に罠があり、その結果はすぐ先（数人先まで）に出る。 |
| 3 | どう進めても避けて通れない罠の結果が、数人より先に出る。 |
| 4 | その罠の結果が、さらに先に出る。 |
| 5 | その罠の結果が、列の半分ほど先に出る。 |

- どう進めても避けて通れない罠の結果が、何人先に出るかで段階を分ける。
  - 罠に出会う回数（判断の重なり）は、どの遊び方の模擬でも難易度の順に並ばなかったため、段階には使わない。
- 進め方や遊び方で出会う罠が変わり、1つの難易度に定まらない問題は出さない。
- 難易度3以上では、先頭に合わせる以外の進め方で重い罠を避けて通れる問題、読まずに決まった選び方で解ける問題、その段階より浅い読みで解ける問題を出さない。
  - 「どう進めても避けて通れない罠を読む」という段階の意味が崩れるため。
  - 盤面の位置や運の癖でたまたま当たる問題は、問題をまたいで使える解き方ではないので残す。

## 評価

### 称えたいプレイ

列の先を読み切り、罠の車を出さずに全員を送り出すプレイを主に、その読みの速さを従に称える。

### 採点項目

- **正確さ**：罠に入った回数を、罠の結果が何人先に出るかによらず1回ずつ数える。
  - 推測の要らない問題なので、罠に入る1回はどれも読みの失敗と言える。
  - 待った・盤面を戻すで戻して、同じ盤面から同じ車をもう一度出しても数え直さない。詰んだ後に出した車は数えない。
    - 詰んでから原因を確かめ直す試行錯誤を、読みの失敗として重ねて数えないため。
- **速さ**：盤面の規模と、罠を避けるために読む人数を考えた時間で評価する。
  - 車の台数と列の人数はどの難易度もほぼ同じなので、読む量を含めないと、上の難易度ほど速さが下がるため。
  - 読む人数の項は、最も重い問題でも基準時間の半分を超えないようにする。
    - 速さが読む人数の見積もりだけで決まらないようにするため。
- 待った・盤面を戻すの回数、戻した車の数、出られない車を押した回数は採点に使わない。
  - 待ったには押し間違いの取り消し・詰んでからの原因探し・試し出しが混ざり、回数では分けられない。
  - 戻した車の数は深い罠ほど多くなり、同じ1回の失敗を上の難易度ほど重く数える。
  - 出られない車を押すのは駐車場の読み違いで、このゲームの挑戦（列の先読み）ではない。
- 手数は評価しない。
  - 全員を送り出すまでに出す車の数は、台数で決まるため。

### 配点

- 正確さを速さより重視する。
  - 罠に1回入ったプレイは、速く解いても great 以上の評価段階に届かず、great 以上は罠に入らずに読み切ったプレイに残す。
- 罠の回数を、問題ごとの罠の多さや深さで均さない。
  - 自己ベストは難易度ごとに比べるため。

### 自己ベスト

- 問題集が変わっても、記録に写した問題の事実（盤面の規模と、罠を避けるために読む人数）で評価して比較に残す。
