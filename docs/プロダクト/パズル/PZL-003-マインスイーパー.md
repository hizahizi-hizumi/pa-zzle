# PZL-003 マインスイーパー

## 遊びの核

- 開いたマスの数字と残りの地雷数から、安全な場所を論理的に確定する。
- 確率に賭けず、地雷を避けて解き切る判断を楽しむ。

## 出題方針

- 数字と総地雷数だけで推測せずに解き切れる問題を提供する。
  - 運任せの正解を、プレイヤーの上達と混同しない。
- 推論の薄い問題と、過度に重い問題を避ける。
  - 確定できる場所を探し続ける挑戦を保つ。

## プレイ体験

- 最初から開いているマスを手掛かりにして考え始められるようにする。
  - 最初のクリックの運不運を挑戦にしない。
- 旗を正解の提出ではなく、自分で考えるためのメモとして扱う。
  - 旗の正誤を先回りして知らせない。
- 地雷を踏んでもプレイを終わらせず、解き続けられるようにする。
  - 正確さは採点で評価し、失敗した問題を途中で奪わない。

## チュートリアル

- 使わせる読みは、数字1つで決まる2つの読み（周りの閉じたマスが数字と同じ数なら全部地雷、地雷が全部見つかった数字の周りの残りのマスは地雷ではない）とし、1つずつ使わせる。
- 読みを使わせる手順では、決め手の数字とその周りの閉じたマスだけを覆いから抜き、押す所と操作をプレイヤーに選ばせる。
  - 周りのほかの数字は抜かず、どの数字の話かを迷わせない。
- 旗を置かせる手順で地雷のマスを開いたときは、1回目だけ本番と同じく地雷を踏ませ、考えずに押すと何が起きるかを見せる。
- 手を離した後は、地雷を踏んでも本番と同じく続けられるようにする。

## 難易度

### 基準とするプレイ

- 確率判断を使わず、確定できるマスだけを開くプレイを基準とする。
- 旗の使用や解く速さでは難しさを決めない。

### 挑戦

- 確定できるマスを探し、数字と総地雷数を組み合わせて地雷の位置を論理的に絞る。

### 段階設計

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 数字一つを見れば分かる手で解ける。 |
| 2 | 隣り合う数字の差を使って決める。 |
| 3 | 数字の範囲の部分的な重なりを読む。 |
| 4 | 重なりの読みを繰り返し、盤面全体の地雷数も使う。 |
| 5 | 三つ以上の数字を同時に組み合わせる。 |

- 必要な推論の種類に加え、探す範囲の広さや地雷密度も段階的に強める。
- 盤面の広さや地雷数だけでレベルを決めない。

## 評価

### 称えたいプレイ

地雷を踏まず、確定したマスだけを開いて解き切ることを最も称える。

### 採点項目

- **正確性**：踏んだ地雷を評価する。
- **速さ**：作業量に応じた基準時間と比べる。

### 配点

- 正確性を速さより重視する。
  - 地雷を踏まずに解き切ったプレイを上位の評価へつなげる。
- 地雷を踏んでも、最後まで解き切る価値は残す。

### 自己ベスト

個別の設計判断なし。
