# PZL-010 ブリッジパズル

## 遊びの核

- 島の数字とつながりを読み、どこへ橋を架けるべきかを絞り込む。
- 数字だけでは決まらない場所で、島の組が孤立しない道筋を発見する。

## 出題方針

- 当てずっぽうや深い試し置きではなく、数字とつながりの推理で解き切れる問題を出す。
  - 局所的に矛盾が見える一手の先読みは、上位の挑戦として残す。
- スマートフォンで橋を押し分けられないほど島を密集させない。
  - 見た目の難しさと操作の難しさを混ぜない。
- 単調な配置や、同じ読みから始まる問題を重ねない。
  - 短い橋や外周の島ばかりに偏らず、盤面ごとに違う読みを楽しめるようにする。
- 最低条件を満たした問題を先着順に採らない。
  - 読みの豊かさ、山場の位置、盤面の美しさまで選び比べる。

## プレイ体験

- つながりが成立しているかは、島の数字をすべて満たすまで先回りして知らせない。
  - 島の組が閉じるかどうかを読むこと自体が挑戦だから。
- 数字が揃ってもクリアできない理由には気づけるようにする。
  - 全部の島がつながっていないことは知らせるが、どの組が孤立したかは解かない。
- 操作対象が曖昧なときは、勝手にどちらかの橋を選ばない。
  - 意図しない橋が架かる方が、何も起きないより直しにくい。
- 橋を架ける前に、狙った辺を確認して取り消せるようにする。
  - 小さい盤面でも狙った橋を操作できることを優先する。
- 島の間を押すだけでも、すべての問題を解けるようにする。
  - なぞる操作を使わなければ解けない場所は作らない。
- クリアした瞬間は、橋のつながりを島から島へ伝わる光で見せる。
  - 全島が一つにつながった達成を盤面で伝える。

## チュートリアル

- 島の数字を読むことと、島の組がつながることの両方を体験させる。

- つながりのルールを教えた後は、孤立する島の組を作ったことを早めに知らせる。
  - 本番とは異なり、習得したばかりのルールにその手が反することを理解させる。
- 自分で解く段階では、置いた橋が正解かを直接示さない。
  - 学んだルールで次の橋を判断させる。

## 難易度

### 基準とするプレイ

- 島の本数の知らせを見ながら、読んで決めた橋を架けるプレイを基準とする。
- 試し置きや、架けてから直す手間を難易度の中心にしない。

### 挑戦

- 数字の読みで橋の本数を絞り、次につながりの読みへ進む。
- 局所の矛盾を読む一手の先読みを、最上位の挑戦として扱う。

### 段階設計

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 数字から本数を見通せる島を足場に、橋が次々に決まる。 |
| 2 | 橋の配分に加え、二島だけで閉じない読みを使う。 |
| 3 | 配分と、組の孤立や交差で行き先が消えることを読む。 |
| 4 | 一か所で一手の先読みを使い、数字とつながりの読みを行き来する。 |
| 5 | 複数の場所で先読みが必要になり、終盤までつながりを読み続ける。 |

- 難易度は必要な読みの種類と深さで分ける。
  - 島の数や橋を架ける作業量だけでは決めない。
- 数字の読みとつながりの読みを、操作回数ではなく気づきのまとまりとして数える。
  - 解く順序や機械的な反復で難易度が変わらないようにする。
- 高い難易度では、読みの山場を解き始めだけに集中させない。
  - 後半が単純な決め打ちの作業にならないようにする。
- 問題の規模は挑戦を支える範囲で大きくする。

## 評価

### 称えたいプレイ

数字とつながりを読み、迷わず速く全部の島をつなぐプレイを称える。

### 採点項目

- **速さ**：島の数、橋の操作量、数字とつながりの読みを考慮した基準時間と比べる。
- 架け直しや待ったは追加で減点しない。
  - 押し間違いと読み直しを区別できず、かかった時間にも表れるため。

### 配点

- 速さだけを採点する。
  - つながりの読みと一手の先読みは、数字の読みより重く見積もる。
- 読みの多い問題ほど、時間による評価の下がり方に余裕を持たせる。
  - 読みにかかる時間には個人差が大きいため。

### 自己ベスト

- 問題集から外れた問題の記録も、比較対象に残す。
