# PZL-004 スライドパズル

## 遊びの核

- タイルをそろえるために、一度完成位置から遠ざける判断を楽しむ。
- タイルが互いの通り道を塞ぐ中で、退避と送り込みの順序を組み立てる。

## 出題方針

- 近づける手を選ぶだけで簡単に完成する問題は避ける。
  - 完成位置から遠ざける判断が必要な問題を提供する。

## プレイ体験

- 同じ行・列のタイルをまとめて動かせる操作を活用する。
  - 操作の手数ではなく、実際に動いたタイルの量で効率を捉える。

## チュートリアル

- まとめて動くルールを伝える前は、同じ行・列でないタイルへの入力を強く否定しない。
  - 未習得のルールで誤りを指摘しない。
- ルールを伝えた後は、誘導中でも本番と同じ不成立の反応を示す。

## 難易度

### 基準とするプレイ

- タイルをそろえる順序を考えてから動かすプレイを基準とする。
- 最短手数そのものを難しさにしない。

### 挑戦

- いったんタイルを退避させ、整列済みの部分を崩さずに目標位置へ送り込む。

### 段階設計

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 小さな盤面で、遠回りをほとんど必要としない。 |
| 2 | 盤面が広がり、少し遠回りする必要がある。 |
| 3 | 同じ規模でも、退避と送り込みをより深く考える。 |
| 4 | さらに広い盤面で、遠回りの順序を読む。 |
| 5 | 広い盤面で、退避と送り込みを何度も組み合わせる。 |

- 盤面の大きさと、避けられない遠回りの多さを組み合わせて段階を分ける。
- 盤面を広くするのは、見渡す範囲と整列済みの部分を守る負荷を強めるため。

## 評価

### 称えたいプレイ

少ないタイル移動で、速く盤面を完成させるプレイを称える。

### 採点項目

- **効率**：実際に動かしたタイルの総手数を、最短手数と比べる。
- **速さ**：盤面の規模と最短手数を考慮した時間で評価する。

### 配点

- 効率を速さより重視する。
  - 最短手数からの超過を比率で評価し、最短の数倍かかったプレイ間の上達差も残す。
- 盤面を戻した回数は別に減点しない。

### 自己ベスト

個別の設計判断なし。
