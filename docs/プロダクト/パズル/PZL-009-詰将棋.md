# PZL-009 詰将棋

## 遊びの核

- 王手の候補を比べ、玉方の応手を先まで読んで詰み筋を見つける。
- 誤王手も、玉方の反証から読み違いに気づき、考え直す体験にする。

## 出題方針

- 解釈によって正解が変わる問題は出さない。
  - ルールの曖昧さではなく、王手と応手の読みを楽しめるようにする。
- 同じ詰み筋の問題を重ねない。
  - 左右反転や平行移動だけの問題も避ける。
- 同じ難易度でも、さまざまな詰み筋や手筋に出会えるようにする。
  - 初手の捨駒や最終手の駒打ちなど、特定の形に偏らせない。

## プレイ体験

- 誤王手を指しても、すぐに不正解として戻さない。
  - 玉方に反証の手を指させ、盤面の変化から読み違いに気づけるようにする。
- 攻方の手と玉方の手を分けて見せる。
  - 玉方がどう逃れたかを見落とさないようにする。
- 誤王手の筋では、指定の手数で詰まないことだけを伝える。
  - より多い手数でも詰まないとは断定しない。
- 反証を見た後は、誤王手を選んだところまで戻って考え直せるようにする。
- 成・不成の選択肢は、位置が予測できることを優先する。
  - 周囲の駒を避けるために表示位置を変えない。

## チュートリアル

- 王手をかけることと、玉を詰ませることの違いを体験させる。
- 詰まない王手と詰ませる王手を、同じ升への着手で比べる。
  - 駒の違いで玉の逃げ道が変わることを見せる。
- 誤王手から詰みまでの流れを一通り体験させる。
  - 誤王手を指し、玉方の反証を見て、待ったで戻り、正しい手で詰ませる。
- 本番では説明しない理由も、チュートリアルでは必要に応じて伝える。
  - 着手できない理由や、玉方に逃げられた理由を説明する。

## 難易度

### 基準とするプレイ

- 将棋の基本ルールと最長抵抗を理解し、指す前に読んで正しい王手を選ぶプレイを基準とする。
- ルールや操作の習得に関わる負担を、難易度に含めない。
  - 駒を見分ける負担と、玉方の応手を待つ時間も含めない。
- 手数や駒数、単純な探索量の多さだけでは難易度を決めない。

### 挑戦

- 王手の候補を挙げ、玉方の応手を読み比べる。
- 正しそうに見えて詰まない王手を見抜く。
  - 特に、数手先で崩れる紛れを読み切ることを重視する。
- 正しい手順でも、玉方の異なる応手に対応できることを読み切る。

### 段階設計

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 王手の候補が少なく、誤王手はすぐに見抜ける。 |
| 2 | 正しそうな誤王手があるが、直後の応手で見抜ける。 |
| 3 | 数手先まで続く紛れがあり、候補の読み比べが必要になる。 |
| 4 | 複数の紛れがあり、正しい手順でも応手や手筋を読み比べる。 |
| 5 | 深い紛れが重なり、遠い利きや複数の手筋も読み切る。 |

- 上の難易度ほど、紛れの深さと数、必要な読みの幅を増やす。
- 玉方の応手では、逃げ方や王手した駒の取り方を中心に考える。
  - 合駒の候補数だけで難しさを作らない。
- 各レベルの特徴に合わない問題を、近いレベルへ無理に割り当てない。

## 評価

### 称えたいプレイ

王手の候補と玉方の応手を読み比べ、誤王手を抑えながら速く詰ませるプレイを称える。

一方、反証を見て考え直すことも大切な体験として扱う。

### 採点項目

- **正確さ**：誤王手を指した回数を評価する。
  - 同じ誤王手の指し直しや、詰まない筋の継続は追加で減点しない。
- **速さ**：経過時間を問題ごとの基準時間と比べる。
  - 王手の候補や紛れを読む負荷を、基準時間に反映する。
  - 難易度のラベルだけで基準時間を決めない。
- 反証を見たり、やり直したりすることは追加で減点しない。
  - 考え直す時間は速さに反映される。

### 配点

- 速さを主に、正確さを補助的に評価する。
- 誤王手による減点には上限を設ける。
  - 反証を見て考え直す体験を、過度に罰しない。
- 基準時間に、すべての王手候補を読む時間を足し込まない。
  - 正解が見つかれば、残りの候補をすべて読む必要はない。

### 自己ベスト

- 問題集から外れた問題も、自己ベストの比較対象に残す。
- 問題集の更新で過去のプレイの積み重ねを失わせない。
