# PZL-001 ナンプレ

## 遊びの核

- 行・列・ブロックの制約を読み、数字が入る場所を見つけていく。
- 一目で決まらないときは候補を絞り、次に決まる場所を自分で作り出す。

## 出題方針

- 推測や後戻りをしなくても、論理的な手筋で解き切れる問題を出す。
  - 当てずっぽうではなく、盤面を読むことを挑戦にする。
- 最後の空きマスを埋めるだけで終わる問題は避ける。
  - 数字の置き場所を探す場面を残す。
- 初期数字の数だけで難易度を見分けられない問題集にする。
  - 初期数字の多さではなく、必要な読みで難しさを変える。

## プレイ体験

- 完成解を照らし合わせる補助を使えるようにする。
  - 誤りの早期発見やメモの整理は助けつつ、次に数字を置く場所は教えない。
- 間違った数字を置くこと自体は止めず、盤面から考え直せるようにする。

## チュートリアル

- 行・列・ブロックそれぞれの見方を、実際に数字を埋めて覚えられるようにする。
  - 同じルールでも対象が違うことを順に体験させる。
- 最後の手順で使わせる読みは、ブロックの中で数字が入るマスを探す読みとし、そのマスに印を付けずに自分で探させる。
- 誤りを説明するときは、影響を受けた行・列・ブロックを一致させる。
  - 盤面で示した違反と説明が食い違わないようにする。
- どこにも重ならないのに答えと違う数字を入れたときも一言を返し、本番ではミスに数えられることを伝える。
  - 重ならない誤りは、盤面ではミスの色だけで示されて理由が読めないため。

## 難易度

### 基準とするプレイ

- 誤りの表示に頼らず、盤面を読んで確定した数字を置くプレイを基準とする。
- 必要に応じてメモを使うが、仮置きと後戻りは前提にしない。

### 挑戦

- 確定できるマスを見つけ、候補を絞る手筋へ進む。
- 難しくなるほど、離れた候補の関係まで読む。

### 段階設計

| 難易度 | 挑戦 |
| --- | --- |
| 1 | ブロック内で数字の置き場所を探せば進められる。 |
| 2 | 行・列や、一つのマスの候補まで読む。 |
| 3 | ブロックと行・列の重なりから候補を絞る。 |
| 4 | 一つの行・列・ブロック内の数字や場所の組を読む。 |
| 5 | 複数の行・列や離れたマスをまたぐ候補の関係を読む。 |

- 問題の難しさは、解くために避けられない手筋の深さで分ける。
- 盤面を埋める量や初期数字の少なさだけではレベルを上げない。

## 評価

### 称えたいプレイ

行・列・ブロックの制約から数字を論理的に確定し、正しく置いて完成させるプレイを称える。候補をメモして絞り込む過程も大切にする。そのうえで速く解き切ることを称える。

### 採点項目

- **正確さ**：完成解と異なる数字を入力した回数で評価する。
- **速さ**：完成までの経過時間で評価する。
- **安定性**：数字を戻す待ったと盤面を戻す操作の回数で評価する。

候補メモだけを戻す待ったは減点しない。数字を変更した待ったと盤面を戻す操作は、確定した判断をやり直した回数として安定性で評価する。誤タップと推論の訂正は区別できないが、他のパズルと同様に観測可能な操作を指標とする。

### 配点

- 正確さ：40点
- 速さ：40点
- 安定性：20点

正確さと速さに加え、数字の確定をやり直さずに完成させる安定性を評価する。候補メモの試行錯誤は安定性の減点対象から外す。

### 自己ベスト

評価点は高いほど、経過時間とミス数は少ないほど良い値として比べる。
