# PZL-008 一筆パズル

## 遊びの核

- 盤面の穴と始点から通り方の制約を読み、一つにつながる道筋を見つける。
- 局所の確定から、残りを取り残さないための先読みへ思考を広げる。

## 出題方針

- 穴の片寄りや通路ばかりで、道が自明になる問題は避ける。
  - 盤面の形から道筋を読む場面を残す。
- 始点から迷わず一本道をなぞるだけの問題は出さない。
  - どちらへ進むかを考える分岐を残す。
- 終点を読めないようにする人工的な仕掛けは入れない。
  - 盤面から終点を推理できるのも、このパズルの一部だから。

## プレイ体験

- 離れたマスを選んで道を自動補完しない。
  - 自分で道筋を決めて引く体験を保つ。
- 引けなかった理由は、指で隠れやすい先端だけでなく、操作した先でも分かるようにする。


## チュートリアル

- 最後の手順で使わせる読みは、通れる隣が少ないマスで道が決まる読みとする。通れる隣が2つしかないマス（角・通路）はその2つの間を通り、1つしかないマス（袋小路）は道の終わりになる。
- 穴をよけることを伝える手順では、穴を決め手として覆いから抜かない。
  - 穴を覆いから抜くと、通れるマスと紛れるため。
- 習得したルールに反する手は、手を引く間も本番と同じく阻まれたと知らせる。
- 伝えたルールで全部のマスを通れなくなったと盤面から分かる道筋は、ルールに合わない手として返し、道が解から外れる前のマスまで戻させる。
  - 手詰まりから抜けられず終わらないようにする。
  - 本番は途中で道の正誤を示さないので、解と違うだけの道は違反にしない。

## 難易度

### 基準とするプレイ

- 盤面を読んで道筋を決めてから引くプレイを基準とする。
- 行き止まりの知らせは使えてよい。
- 実際に引いて戻す試行錯誤の多さは、難易度でなく評価に表す。

### 挑戦

- 角・通路・袋小路の確定から始め、数手先の取り残しや分断を読んで道を選ぶ。

### 段階設計

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 局所の角や通路から、次の道筋が決まる。 |
| 2 | 局所の読みで止まる所を、領域の出入口や短い先読みで抜ける。 |
| 3 | 複数の場所で取り残しを読むか、一か所で長く先を読む。 |
| 4 | 開けた領域で、先読みを重ねて道筋を決める。 |
| 5 | 広い開けた盤面で、長い先読みを何度も重ねる。 |

- 局所推論で足りるか、先読みがどれだけ必要かを段階の中心にする。
- 道の長さやマス数だけで難易度を決めない。
- 上手に読めば不要な先読みは、難しさに数えない。

## 評価

### 称えたいプレイ

先を読んで道筋を決め、引き直しを抑えながら速く引き切ることを称える。

### 採点項目

- **速さ**：道の長さと必要な読みを考慮した基準時間と比べる。
- **正確さ**：別の道筋へ引き直したことを評価する。
- 待ったや盤面を戻した回数そのものは追加で減点しない。

### 配点

- 速さを主に、引き直しを補助的に評価する。
  - 先読みを要する問題で試しに引くことまで重く罰しない。
- 軽い押し間違いの修正で、評価段階が大きく落ちないようにする。

### 自己ベスト

- 問題集から外れた問題の記録も、比較対象に残す。
