# PZL-006 リフレクション

## 遊びの核

- 外周ヒントだけを頼りに、見えないピースの位置と種類を復元する。
- 光を通して配置を確かめ、別のヒントとの整合性から次の置き方を見つける。

## 出題方針

- すべてのピースが少なくとも一つの外周ヒントに影響する問題を出す。
  - どの手掛かりにも現れないピースは、推理で位置を決められないため。
- 複数の外周ヒントを照合する手応えと、ピースの種類の違いが生きる問題を揃える。
  - 単純に規模が大きいだけの問題にはしない。

## プレイ体験

- 外周ヒントの一致と光路は、今の配置から確かめられる情報として見せる。
  - 置いて確かめる行動そのものをこのゲームの一部にする。
- すべて置いても揃わないときは、どのヒントが違うかを盤面から分かるようにする。
  - 文章だけで誤りを指摘しない。
- 光路はプレイヤーが確かめたいときに表示する。
  - 確認の機会を残しつつ、次に置くべきピースまでは示さない。

## チュートリアル

- 外周ヒントの意味とピースの働きを、実際に配置して覚えられるようにする。
  - 同じ働きの向き違いは、手を離した後に自分で当てはめさせる。
- 光が出た先の外周ヒントも、推理の手掛かりになることを体験させる。

- 誘導中に印のない場所を押しても、ルール違反と誤解させない。
  - 解に合っているかと操作の誘導を混同させない。

## 難易度

### 基準とするプレイ

- 外周ヒントの一致を見ながら置き、必要に応じて光路を確かめるプレイを基準とする。
- 盤面の広さやピース数だけの作業量を難易度に含めない。
- 光路を頭だけで追う負担を、難しさにしない。

### 挑戦

- ヒントから置く場所と種類を確定し、必要に応じて複数の光路を照らし合わせる。
- 手持ちの残りや仮定した先の矛盾も使い、正しい配置へ絞る。

### 段階設計

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 一つの外周ヒントで置く場所と種類が決まる。 |
| 2 | 別の外周ヒントとの直接的な整合性を確かめる。 |
| 3 | 一つの確定が別の候補を減らし、連鎖して決まる。 |
| 4 | 手持ちの残り数も読み、複数の光路を行き来する。 |
| 5 | 仮定した配置から矛盾を見つけ、候補を除く。 |

- 推論の深さを主軸にし、規模は各段階で許す範囲として使う。
- 外周ヒントを一つずつ試すだけでは押し切れない問題を、上位の難易度に残す。
- 大きい盤面の方が簡単に見える逆転を避けるため、規模とピース数の釣り合いも取る。

## 評価

### 称えたいプレイ

外周ヒントを確かめながら、迷わず速く配置を復元するプレイを称える。

### 採点項目

- **速さ**：問題の作業量に応じた基準時間と比べる。
- 置き直し、盤面を戻すこと、光路を確かめることは追加で減点しない。

### 配点

- 速さだけを採点する。
  - 配置して確かめ、動かして直す行動はこのゲームの中心だから。

### 自己ベスト

- 置き直しや光路の確認回数を比較対象にしない。
- 問題集から外れた問題の記録も、比較対象に残す。
