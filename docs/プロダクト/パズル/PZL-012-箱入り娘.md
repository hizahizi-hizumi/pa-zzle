# PZL-012 箱入り娘

## 遊びの核

- 娘を出口へ通す道を空けるために、ほかの駒をどこへどの順でよけるかを先に読む。
- 娘を進められないあいだの長い入れ替えや、娘をいったん出口から遠ざける手を見つけ出す。

## 出題方針

- 娘を出口へ運べ、最短手数が分かっている問題だけを出す。
  - 解いた後の表示と評価の基準に、最短手数を使うため。
- よける順を読む前に解けてしまう問題と、最上位の横刀立馬を大きく超える問題は出さない。
- 同じ問題を解き直させない。
  - 少し動かせば行き来できる問題、解き筋の大半が重なる問題、上の難易度の問題の途中の盤面を、別の問題として重ねない。左右を反転した盤面も同じ問題として扱う。
  - 終わり方の似た問題や、同じ駒の組・同じ盤面の集まりから採った問題を続けない。
- 作られた初期配置に見える盤面を出す。
  - 取り除いても最短手数が縮まない駒（手を増やしていない余計な駒）がある盤面は出さない。遊ぶ人が駒の置かれた理由を読めないため。
  - 上の難易度では、娘を出口から遠い所から始める。
- 基準の 4×5 の盤を一部として含む広さまで盤の作りを広げ、壁・横や上の出口・L字の駒・2人の娘・大きい盤を混ぜる。
  - 新しい要素は、ルールを変えないものから先に出す。基準の盤は、どの難易度にも残す。
- 図鑑の並びは、慣れた要素の短い問題から始める。

## プレイ体験

- 駒は指でなぞって動かし、なぞったまま角を曲がれる。同じ駒の続けての移動は1手と数える。
  - 指を離しても、同じ駒を続けてなぞれば同じ1手とし、手数を細かい操作に引きずられないようにする。
  - 1手の中で駒を元の位置へ戻したら、その手は指さなかったことにする。最短手数と数え方をそろえるため。
- 速く弾いて離した駒は、弾いた向きへ1マス動かす。
  - ほかのゲームの短いスワイプに慣れた人が、動かないと受け取らないため。
- 動けない向きへの操作は、駒が動かないことだけで知らせる。文章も音も出さない。
- つかんだ駒は持ち上げ、置ける向きにだけ指へ寄せて見せる。
  - 寄せは見た目だけで、駒の位置と手数は変えない。寄せの向きを替えるときに、ちらつきや跳びを出さない。
- 娘が行き先に着いたら、出口から箱の外へ抜けていく姿と音でクリアを返す。
  - 娘が2人なら、1人ずつ抜けさせる。
- 正しい手・残りの手数・最短手数はプレイ中に出さない。
  - 出口はルールの一部として縁の切れ目で見せるが、出口の前のマスは塗らない。行き先を示しすぎないため。

## チュートリアル

- 同じ駒を続けて動かすと1手と数えることを、駒を続けて動かす手順の一言で伝える。
  - 手を決めるルールではなく手数の数え方なので、ルールの並びには置かない。
- ほかの駒を通り抜けられないことは、ふさがれた駒を動かそうとさせて体で知らせる。
  - ふさがれた手は本番と同じく、盤面では何も起きない。
- 娘をどかす向きを誤ったときは、なぜその向きでは道が開かないかを言う。
- チュートリアルでは手数を出さない。

## 難易度

### 基準とするプレイ

- 正しい手と残りの手数が見えない盤面で、待ったと盤面を戻すを使えるプレイを基準とする。
- 最短手数と速さは難易度に含めない。最短手数は、短すぎる問題と長すぎる問題を外すためにだけ使う。

### 挑戦

- 娘を出口へ進められないあいだに、よける駒と順をつないで読む（準備の長さ）。
- 見た目の進み具合に逆らって、娘をいったん出口から遠ざける判断をする（娘の遠回り）。
- 空きが少ないほど、1つの駒を動かすために先に動かす駒の連鎖が長くなる（規模）。

### 段階設計

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 空きが多く、数手よけるだけで道が開く。娘をわきへよけるのは多くて1回。 |
| 2 | 娘を進める前に十手ほどよけ方を読む。娘を一度わきへよけることもある。 |
| 3 | 空きが減り、娘を進められない手が続く。娘を1〜2回遠ざけながら、駒の入れ替えを先に読む。 |
| 4 | 空きは少なく、娘を進める前に長い入れ替えを組む。 |
| 5 | 横刀立馬のように、娘を2回以上遠ざけ、長い入れ替えを読み切る。 |

- 準備の長さ・娘の遠回り・規模の組で段階を分け、規模だけでは難易度を決めない。
- 上の難易度は、どの観点でも下の難易度より弱くならない。最上位は横刀立馬くらいまでとする。
- 準備の長さと遠回りは、実在する1つの解き方の姿を指すように数える。
  - 回り道、娘の往復、一時的に前へ出して戻す手、関係の無い手をはさんで区切りを作る解で、値が下がらないようにする。
- 最短で解いても娘を進められる区切りがほとんど無い問題は、準備の長さが手数そのものになるので、上の難易度に出さない。
  - 難易度が作業の量で決まらないようにするため。

## 評価

### 称えたいプレイ

よける駒と順を先に読み、最短の手数で娘を出口へ運ぶプレイを称え、その上で速さを称える。

### 採点項目

- **効率**：手数を最短手数と比べる。短い問題でも、試しに動かした1手の減点を小さく保つ。
- **速さ**：最短手数と準備の長さから決める基準時間と比べる。
- 待ったと盤面を戻すは別に減点しない。取り消した手は手数として効率に、かかった時間は速さに表れる。

### 配点

- 効率を速さより重視する。
- よける順を先に読む時間は読みの当たり外れでぶれるので、速さの許容は、先を読むほかのゲームとそろえる。
  - 難易度そのものを基準時間の理由にしない。

### 自己ベスト

- 問題集から引けなくなった記録も、記録した問題の作業量から評価し、比べられるようにする。
- 結果の内訳には、最短手数と並べて、完成した盤面までの手の数を出す。
  - 待ったで取り消した手と盤面を戻す前の手を除き、最短とどれだけ離れたかを読めるようにする。
