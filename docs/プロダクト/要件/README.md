# システム要件

pa-zzle が製品として保証する能力・性質を定義する。

機能要件は `FR-nnn`、非機能要件は `NFR-nnn` の一意な識別子を持つ。機能要件は製品が提供する振る舞い・能力を、非機能要件はその能力や製品全体に要求する品質・制約を扱う。

一つの要件は、実装や画面構成が変わっても独立して満たす・満たさないを判断できる粒度とする。画面上の配置、保存方式、関数・型などの実現方法は含めない。

要件に根拠となる上位正本がある場合は `upstream` から参照し、直接参照する上位正本を持たない場合は `upstream: []` とする。利用者要求への参照は、要件として成立するための必須条件としない。

要件文は一つの意味へ絞り、曖昧な形容や複数の独立した保証を一文へまとめることを避ける。
