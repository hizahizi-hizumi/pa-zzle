# SPEC-004 開始条件

開始条件は、プレイを始める前に利用者が選ぶ条件である。今の開始条件は難易度（SPEC-005）だけで、すべてのゲームが持つ。

難易度選択では、そのゲームのすべての難易度を、いつでも選べる状態で並べる。

プレイ中の「別の問題」とリセット（SPEC-007）では、選んでいる難易度を保つ。別の難易度を選び直すと、前のプレイを引き継がず、その難易度で新しいプレイを始める。

選べない難易度を指定してプレイを開いたとき（廃止した難易度区分のURLなど）は、その難易度を選べないことを示し、難易度選択へ戻れるようにする。

選んだ難易度で問題を用意できないときは、そのことを示し、難易度を選び直せるようにする。
