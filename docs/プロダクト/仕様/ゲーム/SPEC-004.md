# SPEC-004 開始条件

開始条件は、プレイを始める前に利用者が選ぶ条件である。現在の開始条件は難易度だけで、すべてのゲームが持つ。

利用者は、そのゲームの難易度（SPEC-005）のどれでも、ほかの難易度のプレイ実績と関係なく選んで始められる。

選んだ難易度は、そのとき始まるプレイの問題と進行に反映する。プレイ中の「別の問題」やリセットでは選んでいる難易度を保つ。別の難易度を選び直したときは、前のプレイを引き継がず、選び直した難易度で新しいプレイを始める。

選べない難易度を指定してプレイを開いたとき（廃止した難易度区分のURLなど）は、その難易度を選べないことを示し、難易度選択へ戻れるようにする。

選んだ難易度で問題を用意できないときは、そのことを示し、難易度を選び直せるようにする。
