# SPEC-004 開始条件

プレイを始める前に利用者が選ぶ条件の決まり。

## 難易度と問題

- すべてのゲームで難易度（SPEC-005）を選べる。製品が特定の難易度を推奨・標準として強調しない。
- 図鑑や記録から問題ID（SPEC-014）を指定して始めるプレイには、ランダム出題の条件を適用しない。
- 結果とプレイからゲームのホームへ移るときは、その問題を指定して開く。
- ゲームのホームを問題を指定して開いたときは、その問題の難易度を開き、その問題を選んだ状態にする。それ以外のときは、図鑑（SPEC-026）に使える履歴のうち、そのゲームで最後にクリアまたは離脱した（SPEC-015）プレイの難易度を開き、そのようなプレイが無ければ、最も低い難易度を開く。
- ゲームのホームは、開いている難易度に、これから遊ぶ1問をいつも1つ示す。
  - 問題を指定して開いたときのその難易度では、指定した問題を示す。それ以外の難易度では、ランダム出題で選んだ問題を示す。
  - 示している1問は、図鑑（SPEC-026）で選んだ問題と、ランダム出題で選び直した別の問題に替えられる。
  - 難易度を行き来しても、難易度ごとの1問は替えない。

## ランダム出題

- ランダム出題では、難易度に加え、出題対象となる問題の状態を設定できる。未挑戦・挑戦中と、クリア済みの clear・good・great・perfect（SPEC-006）の6種類をそれぞれ選べる。複数を組み合わせ、少なくとも1種類は選ぶ。
- クリア済みの状態はその問題の過去最高の評価点で決める。図鑑と同じ問題・履歴・状態判定（SPEC-026）を使う。
- 出題条件は全ゲーム共通を基本とし、必要なゲームだけ独立した条件で上書きできる。個別設定を解除すると現在の共通設定に戻る。初期状態は全状態を対象とする。
- 出題条件の変更は、効果音・BGMと同じ設定の入口にまとめる。設定は端末に保存し、次のプレイでも引き継ぐ。
- 選んだ難易度で、出題対象の状態に当たる問題を均等に抽選する。別の問題を始めるときと、ゲームのホームでこれから遊ぶ1問を別の問題に替えるときは、直前の問題を候補から除く。候補がない場合は条件に合う問題がないことを知らせ、条件を変えるか、その一回だけ全状態の問題から出題するかを選べるようにする。設定を勝手に変更したり、無断で対象を広げたりしない。
- 同じ難易度の「別の問題」と、結果からの「次の問題」にも同じ出題条件を適用する。問題IDを指定した再挑戦と、同じ問題のリセットには適用しない。
