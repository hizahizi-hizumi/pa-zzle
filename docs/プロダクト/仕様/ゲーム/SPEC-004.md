# SPEC-004 開始条件

プレイを始める前に利用者が選ぶ条件の決まり。

- 今の開始条件は難易度（SPEC-005）だけで、すべてのゲームが持つ。
- 製品が特定の難易度を推奨・標準として強調しない。
- 結果とプレイからゲームのホームへ移るときは、その問題を指定して開く。
- ゲームのホームを問題を指定して開いたときは、その問題の難易度を開き、その問題を選んだ状態にする。それ以外のときは、図鑑（SPEC-021）に使える履歴のうち、そのゲームで最後にクリアまたは離脱した（SPEC-015）プレイの難易度を開き、そのようなプレイが無ければ、最も低い難易度を開く。
