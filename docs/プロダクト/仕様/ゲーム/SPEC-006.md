# SPEC-006 プレイ成績と評価

難易度は問題側の性質、プレイ成績は一回のプレイで起きた事実、評価はその事実に対してゲームが与える意味として区別する。

## プレイ事実

各ゲームは、そのゲームで上手さに結びつく観点を定め、評価・振り返り・自己ベスト比較に必要な事実をプレイの進行から計測する。単に取得できる値を評価材料へ加えず、「何を良いプレイとして称えるか」から観点を決める。

経過時間を計るゲームでは、経過時間はプレイの開始からクリアまでの時間とし、画面が見えていない間や遊び方を開いている間も含める。同じプレイの続きとなる操作（SPEC-007）では経過時間とそれまでの計数を引き継ぎ、新しいプレイでは数え直す。

待った・盤面を戻すなどの操作を使ったプレイも、クリアすれば通常どおり評価・記録する。それらの回数を評価に使うかどうかはゲームごとに決める。

## 評価

評価はクリアしたプレイだけに与える。すべてのゲームで評価を100点満点の評価点で表し、評価段階は評価点から共通に、100点を `perfect`、90点以上を `great`、80点以上を `good`、それ未満を `clear` とする。評価段階はクリアの成立とは別に、プレイの出来に応じた称賛の強さを表す。

点数の付け方（観点、配点、基準）はゲームごとに決め、パズル仕様に書く。異なるゲームで同じ点数だから同程度の成績である、という比較は契約に含めない。

結果では、評価点がどのプレイ事実からどの基準で導かれたかの内訳を、内部の診断値を知らなくても読める形で確認できるようにする。

## 導出と一致

評価点と評価段階は、保存したプレイ事実から今の評価規則で導き、導いた値を記録へ保存しない。同じプレイについて、結果・記録・自己ベスト比較で示す評価と指標は、同じ定義から導いた同じ値とする。

評価規則を変えたとき、古い記録を当時の規則で計算し直す処理は設けない。今の規則で評価できない記録の扱いは SPEC-001 による。
