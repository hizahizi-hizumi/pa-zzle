# SPEC-006 プレイ成績と評価

難易度は問題側の性質、プレイ成績は一回のプレイで起きた事実、評価はその事実に対してゲームが与える意味として区別する。

各ゲームは、利用者が今回のプレイの出来を理解できるよう、そのゲームで上手さに結びつく複数の観点を定め、計測したプレイ事実から評価を導出する。単に取得できる値を評価材料へ加えず、「何を良いプレイとして称えるか」から評価観点を決める。

現在のゲームは評価を100点満点で表し、100点を `perfect`、90点以上を `great`、80点以上を `good`、それ未満のクリアを `clear` とする。この段階はクリア成立とは別であり、プレイの出来に応じた称賛の強さを表す。

評価式はゲーム固有とする。異なるゲームで同じ点数だから同程度の能力・成績である、という比較は現在の契約に含めない。

評価は保存したプレイ事実から再計算できるものとし、履歴へ導出値だけを事実として固定しない。
