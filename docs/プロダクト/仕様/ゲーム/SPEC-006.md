# SPEC-006 プレイ成績と評価

難易度は問題側の性質、プレイ成績は1回のプレイで起きた事実、評価はその事実にゲームが与える意味として区別する。

## プレイ事実

各ゲームは、何を良いプレイとして称えるかから観点を決め、評価・振り返り・自己ベストの比較に必要な事実をプレイの進行から計測する。取得できるというだけの値は評価に加えない。

経過時間は、プレイの開始からクリアまでの時間とする。画面が見えていない間や遊び方を開いている間も含める。

待った・盤面を戻す（SPEC-007）を使ったプレイも、クリアすれば通常どおり評価し、記録する。

## 評価

評価はクリアしたプレイだけに与える。評価は100点満点の評価点で表す。評価段階は全ゲーム共通で、評価点が100点なら `perfect`、90点以上なら `great`、80点以上なら `good`、それ未満なら `clear` とする。評価段階は、クリアの成立とは別に、プレイの出来に応じた称賛の強さを表す。

点数の付け方（観点、配点、基準）はパズル仕様に書く。異なるゲームの同じ点数が同程度の成績であることは表さない。

結果では、評価点がどのプレイ事実からどの基準で導かれたかの内訳を、内部の診断値を知らなくても読める形で示す。

## 導出と一致

評価点と評価段階は、記録したプレイ事実から今の評価規則で導く。同じプレイについて、結果・記録・自己ベストの比較で示す評価と指標は、同じ定義から導いた同じ値とする。
