# SPEC-006 プレイ成績と評価

1回のプレイで起きた事実と、その事実にゲームが与える評価の決まり。難易度は問題側の性質で、評価とは区別する。

- 各ゲームは、何を良いプレイとして称えるかから観点を決め、そのために要る事実をプレイの進行から計測する。取得できるというだけの値は評価に加えない。
- 経過時間は、プレイの開始からクリアまでの時間とする。画面が見えていない間や遊び方を開いている間も含める。
- 評価はクリアしたプレイだけに与え、100点満点の評価点で表す。
- 評価段階は全ゲーム共通で、評価点が100点なら `perfect`、90点以上なら `great`、80点以上なら `good`、それ未満なら `clear` とする。
- 異なるゲームの同じ点数が同程度の成績であることは表さない。
- 評価点と評価段階は保存せず、記録したプレイ事実から今の評価規則で導く。
