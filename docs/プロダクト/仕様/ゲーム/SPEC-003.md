# SPEC-003 ゲームを構成する概念

pa-zzle では次の概念を区別する。

- **パズル**: ナンプレ、ウォーターソートなど、何を考え何を完成させるかを定めるルール体系。
- **ゲーム**: 一つのパズルを、問題の供給、開始条件、操作、評価、演出、結果まで含めて pa-zzle 上で遊べる体験にしたもの。
- **問題**: パズルのルールに従って遊ぶ個々の一問。再現に必要な内部識別情報を持ってよい。
- **プレイセッション**: 一つの問題に対する一回のプレイ状態と進行。盤面を初期状態へ戻す操作（ゲームが提供する場合）は同じプレイセッションの続きとし、離脱としない。同じ問題のやり直し（画面の「リセット」）と新しい問題の開始は新しいプレイセッションとして始め、解き終える前だった前のプレイセッションは離脱として確定する。完了するとプレイ履歴の元になる事実が確定する。

利用者向けの「プレイ」は遊ぶ行為を指す通常語として用いる。実装上の都合で `game` や `session` を別の意味へ広げず、文書・実装の命名はこの概念境界を保つ。
