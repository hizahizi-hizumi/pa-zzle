# SPEC-003 ゲームを構成する概念

pa-zzle では次の概念を区別する。

- **パズル**: ナンプレ、ウォーターソートなど、何を考え何を完成させるかを定めるルール体系。
- **ゲーム**: 一つのパズルを、問題の供給、開始条件、操作、評価、演出、結果まで含めて pa-zzle 上で遊べる体験にしたもの。
- **問題**: パズルのルールに従って遊ぶ個々の一問。問題IDで指す（SPEC-014）。
- **問題集**: 難易度ごとに用意した問題の集まり。新しい問題は、選んだ難易度の問題集から選ぶ。
- **プレイ**: 一つの問題を初期状態から遊び始めてから、クリアするか離れるまでの1回分。どの操作で同じプレイが続き、どの操作で新しいプレイになるかは SPEC-007 で定める。クリアしたプレイは履歴（SPEC-001）、クリアせずに離れたプレイは離脱の記録（SPEC-015）の元になる。

利用者に向けては、遊ぶ対象を「パズル」、一問を「問題」、1回分を「プレイ」と呼ぶ。文書・実装の命名はこの概念境界を保ち、`game` や `session` などの名前を別の意味へ広げない。
