# SPEC-003 ゲームを構成する概念

pa-zzle で使う概念の境界と呼び名の決まり。

- **パズル**: ナンプレ、ウォーターソートなど、何を考え何を完成させるかを定めるルール体系。
- **ゲーム**: 一つのパズルを、問題の供給、開始条件、操作、評価、結果まで含めて pa-zzle 上で遊べる体験にしたもの。
- **問題**: パズルのルールに従って遊ぶ個々の一問。問題IDで指す（SPEC-014）。
- **問題集**: 難易度ごとに用意した問題の集まり。
- **プレイ**: 一つの問題を遊ぶ1回分（SPEC-007）。クリアしたプレイは履歴（SPEC-001）、クリアせずに離れたプレイは離脱の記録（SPEC-015）になる。

利用者に向けては、遊ぶ対象を「パズル」、一問を「問題」、1回分を「プレイ」と呼ぶ。文書と実装の命名はこの境界を保ち、`game` や `session` などの名前を別の意味へ広げない。
