# SPEC-007 1プレイの区切りとやり直しの操作

1回のプレイがどこで始まりどこで終わるかと、プレイ中のやり直しの操作の決まり。この区切りを、計測・評価・記録・自己ベストの比較のすべてで同じに扱う。

1回のプレイは、一つの問題を初期状態から始めた時点で始まり、クリアしたとき、離れたとき、新しいプレイに置き換わったときに終わる。

## やり直しの操作

プレイ中に盤面や問題をやり直す操作は次の4つとし、呼び名とプレイの区切りに対する意味を固定する。

| 操作 | すること | プレイ |
| --- | --- | --- |
| 待った | 直前の盤面操作を取り消す | 同じプレイの続き |
| 盤面を戻す | 盤面を初期状態へ戻す | 同じプレイの続き |
| リセット | 同じ問題を初期状態から始める | 新しいプレイ |
| 別の問題 | 同じ難易度で別の問題を始める | 新しいプレイ |

- 同じプレイの続きでは、経過時間とそれまでの計数を引き継ぐ。待った・盤面を戻すを使った回数は、そのプレイの事実として数え、示すときは操作と同じ呼び名を使う。
- 新しいプレイでは、経過時間と計数を数え直す。置き換えられた前のプレイがクリア前だったときは離脱とする（SPEC-015）。
- 「別の問題」はすべてのゲームが提供する。待った・盤面を戻す・リセットのどれを提供するかはパズル仕様で定める。

## そのほかの区切り

- クリアしたら、最後の操作で盤面がどうなったかを利用者が見て取れる状態を経てから結果へ進む。
- クリア後の結果で同じ問題を始める操作はリセットと、次の問題を始める操作は「別の問題」と同じ意味を持つ。
- プレイ中に再読み込みすると、同じ問題の新しいプレイとして始まる。
- 難易度選択やホームへ移る、ブラウザの戻る・進むで移動すると、プレイを離れる。
- 遊び方（SPEC-016）を開いて閉じても、同じプレイの続きとする。
- 「別の問題」と結果からの次の問題では、直前に遊んでいた1問を避けて選ぶ。
