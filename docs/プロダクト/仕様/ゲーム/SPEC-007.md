# SPEC-007 1プレイの区切りとやり直しの操作

1回のプレイは、一つの問題を初期状態から始めた時点で始まり、クリアしたとき、離れたとき、新しいプレイに置き換わったときに終わる。この区切りは、計測・評価・記録・自己ベスト比較のすべてで同じに扱う。

## プレイ中の操作

プレイ中に盤面や問題をやり直す操作は次の4つとし、利用者向けの呼び名とプレイの区切りに対する意味を固定する。

| 操作 | すること | プレイ |
| --- | --- | --- |
| 待った | 直前の盤面操作を取り消す | 同じプレイの続き |
| 盤面を戻す | 盤面を初期状態へ戻す | 同じプレイの続き |
| リセット | 同じ問題を初期状態から始める | 新しいプレイ |
| 別の問題 | 同じ難易度で別の問題を始める | 新しいプレイ |

同じプレイの続きでは、経過時間とそれまでの計数を引き継ぐ。待った・盤面を戻すを使った回数は、そのプレイの事実として数える。結果や記録でこの回数を示すときは、操作と同じ呼び名を使う。

新しいプレイでは、経過時間と計数を数え直す。置き換えられた前のプレイがクリア前だった場合は離脱とする（SPEC-015）。

「別の問題」はすべてのゲームが提供する。待った・盤面を戻す・リセットのどれを提供するかはパズル仕様で定める。提供しない操作の意味をほかの操作へ混ぜない。

## そのほかの区切り

- クリア後の結果から同じ問題を始める操作はリセットと、次の問題を始める操作は「別の問題」と同じ意味を持つ。
- 記録から同じ問題を遊び直すと、新しいプレイとして始まる（SPEC-014）。
- プレイ中に再読み込みすると、同じ問題の新しいプレイとして始まる。
- 難易度選択やホームへ戻る、ブラウザの戻る・進むで移動すると、プレイを離れる（SPEC-015）。
- 遊び方を開いても、同じプレイの続きとする。

## 新しい問題の選び方

新しい問題は、プレイを始めるときに seed を定め、その seed で選んだ難易度の問題集から1問を選ぶ。同じ seed と同じ問題集からは同じ問題を選ぶ。難易度を選び直したときも、新しい seed で問題を選ぶ。

新しい問題を始めるとき（プレイ中の「別の問題」、結果からの次の問題）は、同じ難易度の問題集から、直前に遊んでいた問題を避けて選ぶ。避けるのは直前の1問だけとする。問題集の大きさなどにより避けきれない場合は、同じ問題になることがある。
