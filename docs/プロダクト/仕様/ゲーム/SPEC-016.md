# SPEC-016 遊び方

各ゲームは、そのパズルのルールと操作方法を示す遊び方を持つ。遊び方は、盤面と同じ見た目の小さな図と短い文で示す。図と文で何を示すかはゲームごとに決める。

遊び方は、難易度選択とプレイ中のどちらでも、利用者が開いたときに確認できる。初めて遊ぶときも含め、自動では開かない。

プレイ中に遊び方を開いても、同じプレイの続きとして扱う。閉じると同じ盤面へ戻る。遊び方を開いている間の経過時間の扱いは SPEC-006 による。

遊び方を開いたことは記録せず、評価にも使わない。
