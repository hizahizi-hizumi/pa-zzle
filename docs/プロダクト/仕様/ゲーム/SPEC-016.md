# SPEC-016 遊び方

各ゲームがルール・操作・採点を示す遊び方の決まり。

- 遊び方は、そのパズルを知らない利用者がこれだけを読んで遊び始められ、遊んでいる途中で迷ったときに開けば答えが見つかるものにする。
- 遊び方は、チュートリアルと同じく、全画面に盤面を大きく見せ、文は人が横で盤面を指しながら教える話し言葉にする。
  - 遊び方とチュートリアルは、どちらも同じ利用者にパズルを教えるものであるため。
- 何のパズルで何を目指すかを、ルールや操作より先に示す。ゴールの盤面は、始まりの盤面から埋まっていき、本番のクリア演出で終わる形で見せる。
- 遊び方は、ルール・操作・採点に分け、迷った所へすぐ行けるようにする。
- チュートリアルがあるゲームでは、遊び方からチュートリアルを始められるようにする。チュートリアルの入口は遊び方の中だけに置く。
- 例は本番と同じ見た目で描き、本番と同じ判定と遷移で触って確かめられるようにする。触る前は静止させる。
- 遊び方で、本番に無い状態の知らせや補助（SPEC-017）を、本番にあるものとして見せない。例を読ませるために、判定の言葉や数、見比べる所の印を添えるのはよい。
- 遊び方は利用者が開いたときだけ示し、初めて遊ぶときも自動では開かない。
- 遊び方を開いたことは記録せず、評価にも使わない。
