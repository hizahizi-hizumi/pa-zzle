# SPEC-029 チュートリアル

各ゲームが持つチュートリアルの決まり。ゲームごとの盤面・手順と、この決まりの中での振る舞いは、各パズルの仕様の「チュートリアル」に書く。

## 進め方

- 1つの盤面を、ルールを1つずつ示しながら、プレイヤーと一緒に解く。
- 最初は手順ごとに一言と、操作するところかその手を決める物を示して手を引き、すべての手順を終えたら手を離して、残りをプレイヤーに解かせる。
- ルールは、それを示す手順に入ったときから示したものとする。まだ示していないルールの違反は見せない。
- ルールに合わないところができたときの一言は、どのルールに当たったかを、今の盤面から具体的に言う。ルールに合わない手や、手順から外れた手の後は、直す所や押す所に印を付けてよい。
- 手がかり（次の手を示すもの）は、次のときだけ見せる。
  - 手を引いている間は、押す所をプレイヤーに探させる手順（押す所に印を付けない手順や、印を付けた複数の所のどれにどう打つかを選ばせる手順）に限り、手が止まったら次に押す所を示してよい。
  - 手を離した後は、プレイヤーが「ヒント」で求めたときだけ見せる。手が止まっても、手がかりを出して割り込まない。

## 導入

- 開いたときは、操作より先に、ゲーム名と何をするパズルかを、解き終えた盤面と一緒に見せる。
  - 何を目指すかを、始めの盤面より先に見せるため。
- 解き終えた盤面は、自動では先へ進めず、プレイヤーの「はじめる」でだけ始めの盤面へ替え、そのまま最初の手順に入る。
- 解き終えた盤面を見せている間と、始めの盤面へ替える間は、盤面を押せない。

## 開いた場所と終え方

- チュートリアルは、ゲームのホームとプレイ中のメニューから開く。
- 解き終えたときの一言は、本番へどうつながるかを、開いた場所ごとに言う。
- 解き終えたら、覚えたルールを振り返ってから、本番へつなぐ操作を出す。
- ゲームのホームから開いたときは、終えて遊び始める操作で、ゲームのホームで開いていた難易度を始める（SPEC-004）。
- プレイ中のメニューから開いたときは、終えたらプレイに戻る。
- チュートリアルを終えたかどうかは残さない。開くたびに、導入から始まる。
- 解き終えた後の「もう一度」では、導入を見せず、最初の手順から始める。
