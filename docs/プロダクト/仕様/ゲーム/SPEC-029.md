# SPEC-029 チュートリアル

各ゲームが持つチュートリアルの決まり。

## 進め方

- 1つの盤面を、ルールを1つずつ示しながら、利用者と一緒に解く。
- 最初は手順ごとに一言と操作するところを示して手を引き、すべての手順を終えたら手を離して、残りを利用者に解かせる。
- ルールは、それを示す手順を始めたときに手に入る。
- まだ示していないルールの違反は見せない。
- ルールに合わないところができたときの一言は、どのルールに当たったかを、今の盤面から具体的に言う。

## 導入

- 開いたときは、操作より先に、ゲーム名と何をするパズルか、解き終えた盤面、始めの盤面の順に見せる。
  - 何を目指すかを、始めの盤面より先に見せるため。
- 解き終えた盤面と始めの盤面は、自動では先へ進めず、利用者の「次へ」でだけ進める。
  - 盤面を見る速さは人によって違うので、自分のペースで進められるようにする。2つの盤面を見ないまま、ルールを身につける手順に入らないようにする。
- 導入の間に「次へ」のほかの所やキーを押したときは、先へは進めず、今見せている動きを終えて、その終わりの姿を見せる。

## 開いた場所と終え方

- チュートリアルは、ゲームのホームとプレイ中のメニューから開く。
- そのゲームの問題を1問もクリアしたことがない人が、ゲームのホームでプレイを始める操作（ランダムに遊ぶ・図鑑の問題を遊ぶ）をしたときは、プレイの前にチュートリアルを開く。クリアしたことがあるかは、履歴（SPEC-001）から求める。
  - ルールを知らないまま本番の盤面に入って迷わないよう、最初の1問はチュートリアルから入る。
- ゲームのホームから開いたときは、導入の最初の画面から、1回の操作でチュートリアルを飛ばして本番を始められるようにする。
  - ルールを知っている人を、チュートリアルで待たせない。
- 解き終えたときの一言は、本番へどうつながるかを、開いた場所ごとに言う。
- ゲームのホームから開いたときは、終えて遊び始める操作と飛ばす操作で、プレイを始める操作をしたときに始めるはずだった問題を始める。メニューから開いたときは、ゲームのホームで開いていた難易度を始める（SPEC-004）。
- プレイ中のメニューから開いたときは、終えたらプレイに戻る。
- チュートリアルを終えたかどうかは残さない。開くたびに、導入から始まる。
