# SPEC-021 図鑑

ゲームの問題集の問題を1問ずつ枠として並べ、解いた問題を集めて見返す図鑑の決まり。

## 載せる問題

- 図鑑には、そのゲームの今の問題集の全問を1問につき1つの枠として載せる。
- クリアした問題は、クリアした問題として示す。同じ問題を何度クリアしても1つとする。まだクリアしていない問題は空き枠として示し、離脱したプレイ（SPEC-015）があった問題は挑戦中、無い問題は未挑戦と分かるようにする。
- 載せる問題と問題ごとの出来は専用の保存値を持たず、問題集と履歴（SPEC-001）から導く。今の問題集から同じ難易度で引けない履歴（SPEC-014）は図鑑に使わない。
- 解いた問題の数は、問題集の全問の数と並べて示す。
- 難易度ごとに、問題の数を、解いた問題は最高スコアの評価段階ごとに、まだクリアしていない問題は挑戦中と未挑戦に分けて示す。割合は示さない。
- 図鑑はゲームごとに置き、ゲームをまたいだ合計や比較を示さない。
- 図鑑を、能力の認定にも、何かを使えるようにする条件にも使わない。

## 番号

- 番号は、問題集の並び順（難易度の昇順、各難易度の中は問題集の並び）で、そのゲームの中を通して1から付ける。
- 番号は図鑑の表示にだけ使い、問題を指すのには使わない。問題は問題ID（SPEC-014）で指す。

## 問題の特徴

- 問題には、クリアしたかどうかによらず、始めたときの盤面で分かる特徴を示す。解かないと分からないこと（最短手数、要る手筋など）は特徴として示さない。

## 問題ごとの出来

- クリアした問題には、その問題をクリアしたプレイの中で最も良い値を、項目ごとに別のプレイからでも選んで示す。
  - 評価点（SPEC-006）の最も高いものと、その評価段階。
  - 最も短いクリアまでの経過時間。
  - 手数を評価に使うパズルでは、最も少ない完成までの手数と、その問題の最短手数。
  - ミスを数えるパズルでは、最も少ないミスの数。
- 問題ごとの出来には、基準時間や最短手数との差を示さない。

## 前回からの変化

- ゲームのホームを開いたとき、そのゲームの図鑑を前回見たときから新しくクリアした問題と、最高スコアの評価段階が上がった問題を示す。
- 変化はゲームのホームを開いたときにまとめて示し、問題をクリアしたときには示さない。示し終えた変化は次に開いたときには示さない。難易度ごとに示し、ゲームのホームを開いても示し終えていない難易度の変化は、次に開いたときにも示す。
- 前回見たときの状態（解いた問題の評価段階と、挑戦中の問題）は、変化を示すためだけにその端末にゲームごとに残し、難易度ごとに、その難易度の変化を示し終えたときに更新する。前回の状態が無いとき・読めないときは変化を示さない。読めない難易度や問題があれば、その分だけを無いものとする。

## 絞り込み

- 図鑑の問題は、状態（クリアした問題は最高スコアの評価段階、まだクリアしていない問題は挑戦中・未挑戦）、問題の特徴、成績で絞り込める。
- 成績は、問題ごとの出来の値で、ミスを数えるパズルではミスが無いか、手数を評価に使うパズルでは最短手数で完成させたかを分ける。ミスと手数は別の成績として扱う。成績の条件には、クリアした問題だけが当たる。
- 問題の特徴の条件は、開いている難易度の問題集にある値から選ぶ。値の種類が多い特徴は、パズルごとに決めた幅の範囲にまとめる。
- 状態は選んだ中のどれかに、問題の特徴は特徴ごとに、成績は成績ごとに選んだ値のどれかに当たり、それらをすべて満たす問題を条件に当たる問題とする。
- 絞り込んでも、図鑑に載せる問題・番号・解いた問題の数・状態ごとの数は変えない。条件に当たる問題の数は別に示す。
- 各選択肢には、ほかの種類（問題の特徴ではほかの特徴、成績ではほかの成績を含む）の条件をかけた上で、その選択肢に当たる問題の数を示す。数が0の選択肢は選べない。選んでいる選択肢は、数が0になっても外せる。
- 条件は保存しない。ゲームのホームを開いたときは条件なしで始め、難易度を切り替えると条件を外す。条件は、かけた難易度にだけかける。

## 図鑑から遊ぶ

- 図鑑の問題は、空き枠も含めて、記録からの遊び直し（SPEC-014）と同じく、その問題を新しいプレイとして始められる。
