# SPEC-014 問題ID

問題を指す識別子と、それを使ったプレイ画面と遊び直しの決まり。

- 各ゲームの問題は問題IDで指す。問題IDは、その問題を作るのに必要な情報全体から求める短い文字列とし、同じ問題からは常に同じ問題IDを得る。問題IDから難易度・生成条件・問題の中身を読み取れないようにする。
- 遊んでいる問題の問題IDをプレイ画面のURLに載せ、再読み込みしても同じ問題を遊べるようにする。
- 記録から同じ問題を遊び直すときは、記録と同じ難易度のプレイ画面をその問題IDで開き、通常のプレイとして始める。
- 記録した問題を今の問題集から同じ難易度で引けない記録（廃止した難易度区分の記録、生成器の版が今と違う記録など）は遊び直せない。遊び直せない記録も残す。結果と記録画面で、その問題を始める操作は今は遊べないことが分かる押せない状態で示し、遊べない理由は書き分けない。
