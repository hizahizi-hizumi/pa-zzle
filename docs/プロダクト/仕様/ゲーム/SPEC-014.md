# SPEC-014 問題ID

各ゲームの問題は、問題IDで指す。問題IDは、生成器の版、生成条件、seed、生成試行など、その問題を作るのに必要な情報全体から一方向に求めた短い文字列とし、同じ問題からは常に同じ問題IDを得る。問題IDの文字には難易度・生成条件・seed などの意味を持たせず、問題IDから問題の中身や作り方を読み取れないようにする。問題IDから問題へは、今の問題集から引く。

プレイ画面は、問題IDを指定されるとその問題から始め、指定がなければ新しい問題を選んで始める。遊んでいる問題の問題IDをプレイ画面のURLへ反映し、プレイ中に再読み込みしても別の問題へ変わらず、同じ問題を遊べるようにする。指定された問題IDを、開いた難易度の今の問題集から引けない場合は、そのことを通知せず新しい問題を選んで始める。

記録から同じ問題を遊び直すときは、記録した問題を再現するための情報から問題IDを求め、記録と同じ難易度のプレイ画面をその問題IDで開く。遊び直しは専用のプレイを設けず通常のプレイとして始め、完了すれば通常どおり記録する。記録した問題を今の問題集から同じ難易度で引けない記録（廃止した難易度区分の記録、生成器の版が今と違う記録、問題集から外れた問題の記録など）は、遊び直せない記録とする。遊び直せない理由は記録ごとに区別しない。
