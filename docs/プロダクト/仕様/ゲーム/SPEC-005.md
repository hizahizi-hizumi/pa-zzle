# SPEC-005 問題の成立性と難易度

問題がルール上成立して解けることと、その問題を人間が解くときの難しさを別の契約として扱う。

各パズルは、生成または採用する問題についてルール上必要な成立条件を保証する。その確認方法はパズル固有でよく、一意解が必要かどうかもパズルのルールによる。

難易度は、盤面規模や生成パラメータをラベルへ直接対応させるのではなく、そのパズル固有の挑戦を分析し、同じ問題を再現可能に評価できる形で判定する。

新しいパズルを pa-zzle に採用するには、[難易度の横断原則](../../../パズル/難易度.md)、[難易度提供](../../../パズル/難易度提供.md)、[難易度判定](../../../パズル/難易度判定.md) に従い、パズル固有の面白さを保った `難易度 1`〜`難易度 5` の5段階について意味のある挑戦差を成立させ、それぞれの問題を意図的かつ継続的に供給できなければならない。

採用時には、「問題が成立する条件」「パズル固有の挑戦」「難易度分析で前提とする解法知識・解法の範囲」「挑戦をどの観点から観測するか」「5段階をどう区別するかという意味上の契約」「5段階を継続供給できること」を確認する。

既存ゲームの特徴量や閾値を流用すること自体を共通契約とはしない。調査・分析・生成方法を見直しても5段階の意味ある挑戦差と継続供給を成立させられないパズルは採用しない。
