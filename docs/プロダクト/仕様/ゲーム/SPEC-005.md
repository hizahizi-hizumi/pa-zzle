# SPEC-005 問題の成立性と難易度

問題がルール上成立して解けることと、その問題を人間が解くときの難しさを、別の契約として扱う。

## 成立性

問題として成立する条件（一意解が必要かどうかなど）と、その確かめ方はパズル仕様に書く。成立性の確認と難易度の判定は別に行い、成立する問題でも難易度の判定で提供範囲から外れることがある。

## 難易度の段階

難易度は、すべてのゲームで共通の5段階とし、表示名は `レベル 1`〜`レベル 5` とする。`レベル 1` がそのゲームで挑戦の最も軽い帯、`レベル 5` が最も強い帯である。

各レベルで何がどう難しくなるか、何を見て判定するか、盤面の規模を難易度の要因にするかはパズル仕様に書く。
