# SPEC-005 問題の成立性と難易度

関連: FR-003, FR-004

問題がルール上成立して解けることと、その問題を人間が解くときの難しさを別の契約として扱う。

各パズルは、生成または採用する問題についてルール上必要な成立条件を保証する。その確認方法はパズル固有でよく、一意解が必要かどうかもパズルのルールによる。

難易度を提供するゲームでは、盤面規模や生成パラメータをラベルへ直接対応させるのではなく、プレイヤーが解く過程で必要になる判断・先読み・推論などの負荷を表す特徴を定める。特徴は同じ入力から同じ判定を再現できる形で計測し、問題集合と実プレイによって利用者の体感との対応を校正する。

新しいパズルを追加するときは、「問題が成立する条件」「人間の難しさを生む要因」「それを計測する方法」をそのパズルの仕様として定義する。既存ゲームの特徴量や閾値を流用すること自体を共通契約とはしない。
