# SPEC-005 問題の成立性と難易度

問題がルール上成立して解けることと、その問題を人間が解くときの難しさを別の契約として扱う。

## 成立性

各ゲームは、提供する問題がルール上成立し、解き切れることを保証する。必要な成立条件（一意解が必要かどうかなど）と、その確かめ方はパズルのルールによって決まり、パズル仕様に書く。

## 難易度の段階

難易度は、すべてのゲームで共通の5段階とし、表示名は `レベル 1`〜`レベル 5` とする。

各レベルは、そのゲームが提供する問題の範囲の中での相対的な位置を表す。`レベル 1` が挑戦の最も軽い帯、`レベル 5` が最も強い帯である。異なるゲームの同じレベルが同じ難しさであることは表さない。

問題の難易度は、盤面規模や生成条件をレベルへ直接対応させるのではなく、そのパズル固有の挑戦の強さから判定する。各レベルで何がどう難しくなるか、何を見て判定するかはパズル仕様に書く。
