# SPEC-017 状態の知らせと補助

プレイ中に示す情報は、そのパズルでプレイヤーが行う判断との関係によって、状態の知らせと補助に分ける。

## 状態の知らせ

操作や配置の成立状況を伝え、プレイヤーが盤面で起きたことを理解できるようにする情報を、状態の知らせとする。

- 今の盤面にあるルール違反
- 今の配置とルールの適合状況
- 今の盤面からもう進められないこと
- 操作が成立したか、成立しなかったか
- クリアしたこと

状態の知らせは、プレイヤーが求めなくても示してよい。示す内容は今の盤面とルールから分かる状態の範囲とする。

プレイヤーが操作して確かめる状態の知らせは、確認回数をプレイの事実として結果に示してよい。

## 補助

プレイヤーがパズルを解くために行う推論や判断を助ける情報を、補助とする。現在の配置から読み解く内容を詳しく示す表示、正解（完成した解や正しい置き場所など）、この先の展開（次に打てる手、候補、将来の手詰まりなど）を含む。
