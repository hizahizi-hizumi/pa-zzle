# SPEC-017 状態の知らせと補助

プレイ中にゲームが盤面について利用者へ示す情報を、状態の知らせと補助に分ける決まり。

## 状態の知らせ

今の盤面とルールだけから分かることを示すものを、状態の知らせとする。

- 今の盤面にあるルール違反
- 今の配置がルールの上でどう働いているか（今の配置での光の進み方など）
- 今の盤面からもう進められないこと
- 操作が成立したか、成立しなかったか
- クリアしたこと

状態の知らせは、利用者が求めなくても示してよい。ただし、今の盤面から分かる範囲を超えて、正解や先の展開をほのめかす形では示さない。

利用者が操作して確かめる状態の知らせ（盤面の一部を押して表示するものなど）は、確かめた回数をプレイの事実として結果に示してよい。示すか、評価に使うかはパズル仕様で定める。

## 補助

正解（完成した解や正しい置き場所など）や、この先の展開（次に打てる手、候補、この先の手詰まりなど）を使って伝えるものを、補助とする。

- 補助を出すゲームは、何を補助とし、どの場面で出すかをパズル仕様で定める。
- パズル仕様に補助として書いていない情報を、正解や先の展開から導いて示さない。
- 補助を使った回数を評価に使うかはパズル仕様で定める。
