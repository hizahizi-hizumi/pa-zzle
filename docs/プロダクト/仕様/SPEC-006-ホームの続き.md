# SPEC-006 ホームの続き

ゲームを選ぶホームで、選んでおくゲームと、選んでいるゲームの続きの決まり。

- ホームを開いたときは、表示するゲームの中から、図鑑（GAME-009）に使える履歴のうち最後にクリアまたは離脱した（SPEC-003）プレイのゲームを選んでおき、そのようなプレイが無ければ並びの先頭のゲームを選んでおく。
- 選んでいるゲームの続きとして、問題を指定せずにそのゲームのホームを開いたときに開く難易度（GAME-002）と、その難易度の挑戦中（GAME-009）の問題の数を示す。挑戦中の問題が無ければ難易度だけを示し、図鑑に使える履歴が無いゲームでは続きを示さない。
