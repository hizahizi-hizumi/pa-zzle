# SPEC-006 ホームの続き

ゲームを選ぶホームで、選んでおくゲームと、選んでいるゲームの続きの決まり。

- ホームを、あるゲームの画面（ゲームのホームと、そのゲームのプレイ・結果など）から開いたときは、ブラウザの戻る・進むで開いたときも含めて、そのゲームを選んでおく。
- それ以外のとき（アプリを開いた直後や、ゲームによらない画面から開いたとき）は、図鑑（GAME-009）に使える履歴のうち最後にクリアまたは離脱した（SPEC-003）プレイのゲームを選んでおき、そのようなプレイが無ければ並びの先頭のゲームを選んでおく。
- 選んでいるゲームの続きとして、問題を指定せずにそのゲームのホームを開いたときに開く難易度（GAME-002）と、その難易度の挑戦中（GAME-009）の問題の数を示す。挑戦中の問題が無ければ難易度だけを示し、図鑑に使える履歴が無いゲームでは続きを示さない。
