# アプリ仕様

個々のゲームのルールを知らなくても成立する、pa-zzle 全体の現在仕様を置く。書く基準は [.claude/rules/documents.md](../../../.claude/rules/documents.md) に従う。

プレイ記録、ゲーム識別、アプリ設定など、複数ゲームを横断して同じ意味を持つ契約を扱う。ゲーム固有の評価規則や画面固有の情報配置はここへ置かない。

仕様には、値そのものがプロダクトの判断であるものを書く。調整用の係数や上限は書かない。

一つの仕様は、一つの変更理由でまとまって変わる決まりを単位とし、`SPEC-nnn` の識別子を持つ。

ゲーム共通の決まりは [`../ゲーム/`](../ゲーム/)、パズル固有の決まりは [`../パズル/`](../パズル/) に置く。
