# 仕様

要件を満たすための今の決まりを置く。書く基準は [.claude/rules/documents.md](../../../.claude/rules/documents.md) に従う。

documents.md は値を書かないとするが、その例外として、仕様には値そのものがプロダクトの判断であるもの（評価段階の境目、難易度を分ける範囲など）を書く。調整用の係数や上限は例外に含めず、書かない。

一つの仕様は、一つの変更理由でまとまって変わる決まりを単位とし、`SPEC-nnn` の識別子を持つ。

配置は責務の最も狭い場所を選ぶ。

- [`アプリ/`](アプリ/): 個々のゲームを知らなくても成立する、アプリ全体の決まり。
- [`ゲーム/`](ゲーム/): パズルの種類によらず、すべてのゲームが同じ意味で従う決まり。
- [`パズル/`](パズル/): そのパズルだけの決まり。

複数のパズルで実装が似ていることだけを理由に、ゲーム共通の決まりへ上げない。
