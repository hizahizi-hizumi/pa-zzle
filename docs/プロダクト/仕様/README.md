# 仕様

要件を満たすためのアプリ・ゲーム共通の今の決まりを置く。書く基準は [.claude/rules/documents.md](../../../.claude/rules/documents.md) に従う。

仕様には、値そのものがプロダクトの判断であるものを書く。調整用の係数や上限は書かない。

一つの仕様は、一つの変更理由でまとまって変わる決まりを単位とし、`SPEC-nnn` の識別子を持つ。

- このディレクトリ: 個々のゲームのルールを知らなくても成立する、アプリ全体の決まり。プレイ記録、ゲーム識別、アプリ設定などの契約を扱う。
- [`ゲーム/`](ゲーム/): パズルの種類によらず、すべてのゲームが同じ意味で従う決まり。
- [`../パズル/`](../パズル/): パズル固有の決まり。

複数のパズルで実装が似ていることだけを理由に、ゲーム共通の決まりへ上げない。
