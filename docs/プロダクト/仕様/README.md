# 仕様

システム要件を現在の pa-zzle で実現するための、**具体的な振る舞い・意味上の契約**を定義する。

利用者・ゲーム・プロダクトとして意味のある契約を文書化し、型、関数API、Tailwind値など実装から機械的に導ける事実はコード・設定を正本とする。

一つの仕様は、一つの変更理由でまとまって変わる契約を基本単位とし、`SPEC-nnn` の一意な識別子を持つ。必要に応じて関連する `FR-nnn` / `NFR-nnn` を参照する。

配置は責務の最も狭い場所を選ぶ。

- [`アプリ/`](アプリ/): 個々のゲームを知らなくても成立するアプリ共通の契約。
- [`ゲーム/`](ゲーム/): パズルの種類によらず、pa-zzle のゲームとして共通の意味を持つ契約。
- [`パズル/`](パズル/): 特定のパズルでのみ成立する契約。

複数パズルで実装が似ていることだけを理由に、ゲーム共通仕様へ昇格させない。
