# SPEC-013 リフレクション

正方形の盤面の外周から入れた光の結果（外周ヒント）だけを手がかりに、手持ちのピースをすべて盤面へ置き、見えない光学系の配置を復元するパズル。画面に表示する名称は「リフレクション」とする。

## ルールと問題

- 盤面は 5×5 から 10×10 のいずれかで、難易度ごとに許す範囲の中から問題によって決まる。
- ピースは、光の向きを90度変える2種類の斜め鏡（`/`、`\`）、一方の軸に沿う光を通しそれと直交する光を来た方向へはね返す2種類の両面鏡（縦・横）、どの向きの光も来た方向へはね返す反射体、光を吸収するブラックホールの6種類とする。全難易度で6種類を使う。ピースは回転させず、盤面に初めから置かれた固定のピースは持たない。
- 外周ヒントは盤面の四辺のすべての位置に置き、その位置から入れた光が、別の位置から出る（退出）、入った位置へ戻る（反射）、吸収される（吸収）のいずれになるかと、盤面の中で通ったマスの数を示す。
- 問題は、手持ちのピースをすべて使い、全外周ヒントを満たす配置がただ1つであり、どのピースも少なくとも1本の外周ヒントの結果を変えるものに限る。
- 手持ちのピースをすべて置き、全外周ヒントが一致した時点でクリアとする。
- 一度盤面に置いたピースを、移す・入れ替える・ストックへ戻す・別の種類で置き換える回数を、置き直しとして数える。盤面を戻して回収したピースは置き直しに数えない。

## 見た目と操作

- 盤面と四辺の外周ヒントを画面の主役にし、手持ちのピースは盤面の下にストックとしてまとめ、種類ごとの残り数を示す。
- 外周ヒントの結果は、形も色も違う記号で示す。ピースは形で見分けられるようにしたうえで、そのピースが生む結果と同じ色を付ける。斜め鏡は退出、両面鏡と反射体は反射、ブラックホールは吸収の色とする。
- ピースは、ストックの種類を選んでから空きマスを押して置く。盤面のピースを押すとそのピースを選び、空きマスを押せば移し、別のピースを押せば入れ替え、ストックの同じ種類を押せば戻し、ストックの別の種類を押せばその種類に置き換える。ストックの種類を選んだまま配置済みのマスを押したときは、置き換えずにそのピースを選ぶ。ドラッグと回転の操作は持たない。
- 盤面のピースを選んでいる間は、同じ種類のストックに戻し先の印を付ける。
- プレイ中に示す成績は経過時間だけとする。
- プレイ中に説明の文を出さない。全ピースを置いても揃わないときも、揃っていないことや一致していない外周ヒントの本数を文で示さない。

## 状態の知らせ

外周ヒントの一致と光路は、今の配置で光がどう進むかを示す状態の知らせ（SPEC-017）とし、通常の操作として遊び方で説明する。

- 盤面が変わるたびに、各外周ヒントについて、今の配置でその位置から入れた光の結果と通るマスの数が外周ヒントと一致しているかを求める。退出では、光が出た先の外周ヒントも同じマスの数の退出であることを一致の条件に加える。全ピースを置く前でも、その時点の光で判定する。
- 一致している外周ヒントは控えめな緑の地で示し、切り替えで大きさ・位置・枠を変えない。一致しない外周ヒントは通常の見た目のままとし、誤りとして強調しない。マスごとやピースごとの正誤は示さない。
- 外周ヒントを押すと、その位置から入れた光が今の盤面でどう進むかを光路の線として描く。光が出た位置・通ったマスの数・結果は文で示さない。光路を表示している外周ヒントが一致していないときだけ、今の光が通るマスの数を添える。
- 盤面が変わると光路を閉じ、確かめ直すには外周ヒントを押し直す。光路を表示した回数を、光路を確かめた回数として数え、結果で示す。

## やり直し

盤面を戻す、リセット、別の問題を提供する。待ったは提供しない。盤面を戻すと全ピースをストックへ戻す。

## 難易度

- 基準とするプレイは、外周ヒントごとの一致を見ながら遊び、光路の表示は置いたピースの確認に使い、盤面を戻すを使わないプレイとする。盤面の大きさとピース数だけによる作業量、光路を頭の中で追い続ける負担、入力回数や時間そのものは難易度に含めない。
- 挑戦は、外周ヒントの結果から見えないピースの位置と種類を確定させ、1本の光路で決まらないときは、複数の光路、手持ちの残り数、仮に置いた先の矛盾まで読んで確定させることとする。複数の外周ヒントが同じピースを取り合い、1本を合わせると別の1本が崩れることも、読みを要する挑戦とする。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 1本の外周ヒントを見れば、置く場所と種類が決まる |
| 2 | 候補を他の外周ヒントと照らし合わせて絞る |
| 3 | 1つ決まると別の外周ヒントの候補が減り、連鎖して決まる |
| 4 | 手持ちの残り数も手がかりにして決める。1本ずつ合わせていくと別の外周ヒントが崩れる |
| 5 | 広い盤面で、仮に置いた先の矛盾まで読まないと決まらない。1本ずつの試し置きでは押し切れない |

- 難易度は推論の深さを主軸にし、盤面の大きさとピース数を各難易度で許す範囲とし、外周ヒントを1本ずつ試し置きで合わせて押し切れる度合いを難易度4・5 の条件として組み合わせる。規模だけで難易度が上がる・下がることはない。
- 上の難易度ほど許す規模の範囲を下げない。難易度4・5 では外周ヒント1本あたりのピース数を難易度ごとの範囲に揃え、見た目に大きい盤面が小さい盤面より易しくなることを避ける。
- 難易度の選択肢の図は、盤面の一部の帯を1本の光が斜め鏡で折れながら横切る図とし、上の難易度ほど折れる回数を増やす。色は光路とピースの2色にとどめ、外周ヒントの数字や結果の形は描かない。

## 評価

迷わず速く配置を復元することを称える。外周ヒントごとの一致を見ながら置いて確かめ、動かして直すことは罰しない。

- 速さ 100点: 経過時間を、問題の作業量から決める基準時間と比べる。難易度そのものを基準時間の理由にしない。
- 置き直し回数、盤面を戻した回数、光路を確かめた回数、入力回数は評価に使わない。置き直し回数は、評価に使わないプレイの事実として結果に示す。
- 問題集から引けなくなった記録も、記録した問題の作業量から評価し、自己ベストの比較に使う。

自己ベストでは、評価点は高いほど、基準時間との差は少ないほど良い値として比べる。置き直し回数と光路を確かめた回数は比べない。
