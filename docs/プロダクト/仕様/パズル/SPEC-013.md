# SPEC-013 リフレクション

リフレクションは、正方形の盤面の外周から入れたレーザーの結果（外周ヒント）だけを手がかりに、手持ちのピースをすべて盤面へ置き、見えない光学系の配置を復元するゲームとして提供する。盤面の大きさは 5×5 から 10×10 のいずれかで、難易度ごとに許す範囲の中から問題によって決まる。盤面の大きさを難易度とは別の開始条件として選ばせない。

ピースは、光の向きを90度変える2種類の斜め鏡（`/`、`\`）、一方の軸に沿う光を通し、それと直交する光を来た方向へはね返す2種類の両面鏡（縦・横）、どの向きの光も来た方向へはね返す反射体、光を吸収するブラックホールの6種類とする。ピースは回転させず、向きの違う鏡は別の種類として扱う。盤面に初めから置かれた固定のピースは持たない。

画面に表示する名称は「リフレクション」とする。

## 問題

外周ヒントは盤面の四辺のすべての位置（一辺 n の盤面で 4n 本）に置く。外周ヒントは、その位置から入れた光が、別の位置から出る（退出）、入った位置へ戻る（反射）、ブラックホールに吸収される（吸収）のいずれになるかと、その光が盤面の中で通ったマスの数を示す。

問題は、手持ちのピースをすべて使い、全外周ヒントを満たす配置がただ1つであり、どのピースも少なくとも1本の外周ヒントの結果を変えるものに限る。

## プレイ

盤面と四辺の外周ヒントを画面の主役にし、手持ちのピースは盤面の下にストックとしてまとめ、種類ごとの残り数を示す。

ピースは形で見分けられるようにし、斜め鏡は向きの違う1本線、両面鏡は光を通す向きに沿う2本線、反射体は四角の輪郭、ブラックホールは塗りの円として表す。そのうえで、ピースにはそのピースが生む外周ヒントの結果と同じ色を付ける。光を直角に曲げて外へ導く斜め鏡は退出、正面から当たった光をはね返す両面鏡と反射体は反射、ブラックホールは吸収の色とする。外周ヒントは、通ったマスの数と、結果ごとに形も色も違う記号で示し、色だけで結果を区別しない。

ピースは、ストックの種類を選んでから空きマスを押して置く。盤面のピースを押すとそのピースを選び、空きマスを押せばそこへ移し、別のピースを押せば入れ替え、ストックの同じ種類を押せばストックへ戻し、ストックの別の種類（残りのあるもの）を押せばその種類に置き換える（選んでいたピースはストックへ戻る）。盤面のピースを選んでいる間は、同じ種類のストックに戻し先の印を付ける。ストックの種類を選んだまま配置済みのマスを押すと、置き換えずにそのマスのピースを選ぶ。ドラッグと回転の操作は持たない。PC ではキーボードで盤面と外周ヒントを移動して押し、数字キーでストックの種類を選べる。

手持ちのピースをすべて置き、全外周ヒントが一致した時点でクリアとする。問題は一意解を持つため、これは完成解との一致と同じ意味になる。全ピースを置いても一致しないときも外周ヒントごとの一致の表示のままとし、一致していない外周ヒントの本数や揃っていないことを文では示さない。失敗して終わる条件は無い。

クリアした瞬間に入力を止め、全外周ヒントの光路を入口から伸ばしていく演出で揃ったことを返し、揃った全光路をしばらく見せてから結果へ進む。動きを減らす設定では、光路を伸ばさずに全光路を示し、同じ時間見せてから結果へ進む。

一度盤面に置いたピースを、別のマスへ移す、入れ替える、ストックへ戻す、別の種類で置き換える回数を、置き直しとして数える。入れ替えは動いた2個を1回と数える。盤面を戻して回収したピースは置き直しに数えない。完成解との照合は置き直しの判定に使わない。

プレイ中は経過時間だけを示す。置き直し回数、盤面を戻した回数、光路を確かめた回数は評価に使わないため、プレイ中に示さない。

### 状態の知らせ

外周ヒントの一致と光路は、どちらも今の配置で光がどう進むかを示す状態の知らせ（SPEC-017）である。どちらも通常の操作として遊び方で説明する。

盤面が変わるたびに、各外周ヒントについて、今の配置でその位置から入れた光の結果と通るマスの数が外周ヒントと一致しているかを求める。

- 退出では、光が出た先の外周ヒントも同じマスの数の退出であることを一致の条件に加える。光路は逆にたどれるので、完成の配置では、ある位置から入った光が別の位置から n マスで出るなら、出た先の外周ヒントも n マスの退出になるためである。
- 反射と吸収は、結果と通るマスの数で判定する。
- 全ピースを置く前でも、その時点の光で判定する。

一致している外周ヒントは、一致の色で示す。一致しない外周ヒントは通常の見た目のままとし、誤りとして強調しない。完成解とマスごとに比べた結果や、ピースごとの正誤は示さない。

外周ヒントを押すと、その位置から入れた光が今の盤面でどう進むかを、光路の線として盤面に描く。入口と光が出た位置には向きの印を置く。光が出た位置・通ったマスの数・結果は文で示さない。光路を表示している外周ヒントが一致していないときだけ、そのそばに今の光が通るマスの数を添える（数が外周ヒントと同じでも、出た先が違えば添える）。盤面が変わると光路を閉じ、確かめ直すには外周ヒントを押し直す。

外周ヒントを押して光路を表示した回数を、光路を確かめた回数として数え、結果で示す。評価には使わない。

### やり直し

プレイ中は、盤面を戻す、リセット、別の問題を提供する。置いたピースは直接選んで、別のマスへ移す、入れ替える、ストックへ戻すことができ、1手戻す役割がこの操作と重なるため、待ったは提供しない。

- 盤面を戻す: 全ピースをストックへ戻す。

## 難易度

問題難易度は、ルール・6種類のピース・外周ヒントの意味を理解し、外周ヒントごとの一致を見ながら遊び、光路の表示は置いたピースの確認に使い、盤面を戻す操作を使わないプレイを基準にする。盤面の大きさとピース数だけによる作業量、光路を頭の中で追い続ける負担、解くまでの入力回数や時間そのものは問題難易度に含めない。

リフレクションの挑戦は、外周ヒントの結果から見えないピースの位置と種類を1つずつ確定させ、1本の光路で決まらないときは、複数の光路、手持ちの残り数、仮に置いた先の矛盾まで読んで確定させることとする。外周ヒントごとの一致が見えるため、外周ヒント同士が同じピースを取り合わない問題は、1本ずつ試し置きで合わせていくだけでも解ける。複数の外周ヒントが同じピースを取り合い、1本を合わせると別の1本が崩れることも、読みを要する挑戦として扱う。各難易度で利用者が出会う挑戦は次のとおりとし、上の難易度ほど必要な推論が深くなる。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 1本の外周ヒントを見れば、置く場所と種類が決まる |
| 2 | 候補を他の外周ヒントと照らし合わせて絞る |
| 3 | 1つ決まると別の外周ヒントの候補が減り、連鎖して決まる |
| 4 | 手持ちの残り数も手がかりにして決める。1本ずつ合わせていくと別の外周ヒントが崩れる |
| 5 | 広い盤面で、仮に置いた先の矛盾まで読まないと決まらない。1本ずつの試し置きでは押し切れない |

難易度は推論の深さを主軸にし、盤面の大きさとピース数を各難易度で許す範囲として、外周ヒントを1本ずつ試し置きで合わせる進め方で押し切れる度合いを難易度4・5 の条件として組み合わせる。上の難易度ほど許す範囲と条件を下げず、隣り合う難易度は同じ規模を共有する。同じ規模の問題は推論の深さと試し置きで押し切れる度合いで難易度が分かれ、規模だけで難易度が上がる・下がることはない。難易度4・5 では、外周ヒント1本あたりのピース数も難易度ごとの範囲に揃え、大きい盤面ほどピースを多くする。同じピース数なら盤面が小さいほど外周ヒント同士が同じピースを取り合って難しくなるため、見た目に大きい盤面が小さい盤面より易しくなることを避ける。

難易度の選択肢には、その難易度で遊ぶ盤面の幅とピース数の範囲に収まる模式図として、盤面の一部の帯を1本の光が斜め鏡で折れながら横切る図を示す。光の折れる回数（たどる光路の長さ）は上の難易度ほど増え、推論の深さを表す。色は光路とピースの2色にとどめ、外周ヒントの数字や結果の形は描かない。上の難易度の図は、下の難易度の図の鏡をすべて同じ位置に含み、光路はその続きになる。

### 判定

難易度は、手持ちと外周ヒントだけから人間向けの推論で各マスの候補を絞る過程を分析して判定する。推論は浅い段階から順に、1本の外周ヒントからの直接の確定、候補を全外周ヒントに照らした除去、その除去の繰り返しによる連鎖、手持ちの残り数の利用、候補を仮に置いた先の矛盾による除去を区別し、全ピースの置き場所を決め切るまでに使った最も深い段階を観測する。光路は、同じマスを2回通るなら同じピースとみなし、手持ちの残り数を超えるピースを使う光路を考えない。

あわせて、推論をせずに、一致していない外周ヒントを1本ずつ狙い、その光路の上にピースを置いたり入れ替えたりして一致させていく決まった手順の試し置きで、解き切れるか、一致していた外周ヒントを崩したり置き方を変えたりした手が何回要るかを観測する。

分析結果は、次の状態を区別して扱う。

- 成立しない: 解が無い、2つ以上ある、または一意性を確かめられない。提供しない。
- 評価不能: 一意解だが、最も深い段階まで使っても決め切れない、または仮に置いて確かめる回数が上限に達する。高難易度と推定せず、提供しない。
- 提供範囲外: 分析できるが、推論の深さ・規模・試し置きの組がどの難易度の範囲にも当たらない。近い難易度へ寄せず、提供しない。
- 難易度1〜5: 推論の深さ・規模・試し置きの組がその難易度の範囲に入る。

正確な推論と試し置きの手順、探索と仮定の上限、各難易度の盤面の大きさ・ピース数・試し置きの条件はコードを正とする。

### 供給

各難易度の問題は、判定済みの問題を事前に生成した問題集から供給する。回転・反転で一致する問題は同じ問題として扱い、問題集に重複させない。各難易度の問題集は、その難易度で許す盤面の大きさとピース数の組からほぼ均等に採る。プレイ時には問題の生成・解探索・難易度分析を行わない。

## 成績評価

推測なしで解ける問題だけを提供し、外周ヒントごとの一致を見ながら置いて確かめ、動かして直すことをこのゲームの中心の操作とするため、迷わず速く配置を復元することを称える。

- 速さ 100点: 問題ごとの基準時間を満点基準とし、超過に応じて線形に減点する。基準時間の3倍で0点とする。点は1点単位に四捨五入し、0点から100点の範囲とする。

基準時間は、読んで解く時間と、読んで解く時間と試し置きで解く時間の短い方との中間とする。試し置きで解き切れない問題は、読んで解く時間を基準時間とする。

- 読んで解く時間: 外周ヒント1本あたり0.5秒、ピース1個あたり3.5秒、照らし直す局面1つあたり1.25秒、仮に置いて確かめる回数1回あたり3.5秒（10回を上限とする）の合計。
- 試し置きで解く時間: 外周ヒント1本あたり0.5秒と、試し置きの1手あたり5秒の合計。

基準時間の1.2倍以内で `great`、1.4倍以内で `good` に残る。

照らし直す局面の数は、判定と同じ人間向けの推論でその問題を解き切るまでに、全外周ヒントへ照らし直して候補が変わった回数とする。仮に置いて確かめる回数は、そのうち候補を仮に置いて確かめた回数とする。試し置きの手数は、判定と同じ試し置きの手順で解き切るまでの手数とする。いずれも問題ごとに定まる。基準時間は問題の作業量だけから決め、難易度そのものを加点や基準時間の理由にしない。

置き直し回数、盤面を戻した回数、光路を確かめた回数、入力回数は評価に使わない。置き直しを減点すると、一致を見ながら置き直す遊び方や押し間違いの修正を罰することになるためである。盤面を戻しても経過時間は続き、戻すまでに使った時間は速さに表れる。

### 記録と自己ベスト

記録するプレイ事実は、問題の作業量（ピース数、外周ヒントの本数、照らし直す局面の数、仮に置いて確かめる回数、試し置きの手数）、経過時間、置き直し回数、盤面を戻した回数、光路を確かめた回数、入力回数とする。問題の作業量を記録に持つので、生成器が変わって記録の問題を今の問題集から引けなくなっても、その記録は評価できる。

自己ベストでは、評価点は高いほど、基準時間との差は少ないほど良い値として比べる。置き直し回数と光路を確かめた回数は、評価に使わず、少ないほど良いとは言えないため比べない。

### 結果

結果では、評価点と評価段階に続けて、経過時間と基準時間との差、置き直し回数を主な成績として示す。置き直し回数は、評価に使わないプレイの事実として示す。評価の内訳、基準時間の根拠、盤面を戻した回数、光路を確かめた回数は、主な成績と分けて確認できるようにする。
