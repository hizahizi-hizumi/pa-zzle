# SPEC-013 リフレクション

リフレクションは、正方形の盤面の外周から入れたレーザーの結果（外周ヒント）だけを手掛かりに、手持ちのピースをすべて盤面へ置き、見えない光学系の配置を復元するゲームとして提供する。盤面の大きさは 5×5 から 11×11 のいずれかで、難易度ごとに許す範囲の中から問題によって決まる。難易度以外の開始条件として盤面の大きさを選ばせない。

ピースは、光の向きを90度変える2種類の斜め鏡（`/`、`\`）、一方の軸に沿う光を通し、それと直交する光を来た方向へはね返す2種類の両面鏡（縦・横）、どの向きの光も来た方向へはね返す反射体、光を吸収するブラックホールの6種類とする。ピースは回転させず、向きの違う鏡は別の種類として扱う。盤面に初めから置かれた固定のピースは持たない。

画面に表示する名称は作業名の「リフレクション」とする。正式な表示名は、商標の最終確認を経て公開前に決める仮決定とする。

## 問題

外周ヒントは盤面の四辺のすべての位置（一辺 n の盤面で 4n 本）に置き、その位置から入れた光が、別の位置から出る（退出）、入った位置へ戻る（反射）、ブラックホールに吸収される（吸収）のいずれになるかと、その光が盤面の中で通ったマスの数を示す。

問題は、手持ちのピースをすべて使い、全外周ヒントを満たす配置がただ1つであり、どのピースも少なくとも1本の外周ヒントの結果を変えるものに限る。問題の成立性の確認と、利用者向け難易度の判定は別の責務として扱う。

## プレイ

盤面と四辺の外周ヒントを画面の主役にし、手持ちのピースは盤面の下にストックとしてまとめ、種類ごとの残り数を示す。ピースは形で見分けられるようにし、斜め鏡は向きの違う1本線、両面鏡は光を通す向きに沿う2本線、反射体は四角の輪郭、ブラックホールは塗りの円として表す。そのうえでピースにゲーム固有の色を付け、そのピースが生む外周ヒントの結果と同じ色にする。光を直角に曲げて外へ導く斜め鏡は退出、正面から当たった光をはね返す両面鏡と反射体は反射、ブラックホールは吸収の色とする。選んでいる盤面のピースはマスの四隅の鉤形、選んでいるストックの種類はアイコンの下の短い線で、どちらもそのピースの色で示し、マスやストックの地や枠は変えない。外周ヒントは、通ったマスの数と、結果ごとに形も色も違う記号で示し、色だけで結果を区別しない。

ピースはストックの種類を選んでから空きマスを押して置く。盤面のピースを押すとそのピースを選び、空きマスを押せばそこへ移し、別のピースを押せば入れ替え、ストックの同じ種類を押せばストックへ戻し、ストックの別の種類（残りのあるもの）を押せばその種類に置き換える（選んでいたピースはストックへ戻る）。盤面のピースを選んでいる間は、同じ種類のストックに選択の線を薄くした印を付けて戻し先を示し、文字や帯は出さない。ストックの種類を選んだまま配置済みのマスを押すと、置き換えずにそのマスのピースを選ぶ。ドラッグと回転の操作は持たない。PC ではキーボードで盤面と外周ヒントを移動して押し、数字キーでストックの種類を押せる。

盤面が変わるたびに、各外周ヒントについて、今の配置でその位置から入れた光の結果と通るマスの数が外周ヒントと一致しているかを求める。退出では、光が出た先の外周ヒントも同じマスの数の退出であることを一致の条件に加える。光路は逆にたどれるので、完成の配置ではある位置から入った光が別の位置から n マスで出るなら、出た先の外周ヒントも n マスの退出になり、出た先の外周ヒントが違うのに数と結果だけが同じ光は完成の配置の光路ではないため。反射と吸収は結果と通るマスの数で判定する。一致している外周ヒントは、数字の地と数字を一致の色（控えめな緑）で示す。一致の地は数字と記号を内側に余白を持って収め、隣り合う一致の地が帯としてつながらないようにする。一致の切り替えでは色だけを瞬時に変え、外周ヒントの大きさ・位置・枠・数字の太さ・記号の位置は変えず、点滅やフェードも付けない。全ピースを置く前でも、その時点の光で判定する。一致しない外周ヒントは通常の見た目のままとし、誤りとして強調しない。正解の配置とマスごとに比べた結果や、ピースごとの正誤は示さない。

外周ヒントを押すと、その位置から入れた光が今の盤面でどう進むかを光路の線として盤面に描く。光が出た位置・通ったマスの数・結果を説明の文では示さない。代わりに、光路を表示している外周ヒントが一致していないときだけ、そのそばに今の光が通るマスの数だけを添える（数が外周ヒントと同じでも、出た先が違えば添える）。外周ヒントの数字と並んで1つの数に読まれない位置に置き、外周ヒントの記号の位置は動かさない。光路とその両端の印は盤面の外枠の内側で止め、外枠をまたいで外へ出さない。入口（押した外周ヒントの前の盤面の縁）には外枠の内側に沿う光路と直交する短い太線、光が出た位置には先が外枠の内側に接する外向きの矢印を置いて向きを示し、外周ヒントに枠や地を足さない。光路の線は、通るマスとピースの中心を通り、端は外周ヒントの中心の延長上に置く。光路は盤面の地・罫線・外枠より手前、ピースより奥に描く。光路は外周ヒントが一致しない理由を確かめるためのもので、今の配置の物理的な結果だけを示す。盤面が変わると光路を閉じ、確かめ直すには外周ヒントを押し直す。光路の表示を補助として扱い、遊び方で補助と説明し、使った回数を結果で事実として示すことは、実プレイで検証する仮決定とする。通常の操作として扱う場合は、遊び方の説明と結果での回数の扱いだけを変え、光路の表示そのものは変えない。

手持ちのピースをすべて置き、全外周ヒントが目標と一致した時点でクリアとする。問題は一意解を持つため、これは完成解との一致と同じ意味になる。全ピースを置いても一致しないときも、外周ヒントごとの一致の表示のままとし、一致していない外周ヒントの本数や揃っていないことを文では示さない。失敗して終わる条件は無い。

クリアした瞬間に入力を止め、全外周ヒントの光路を入口から伸ばしていく演出で揃ったことを返し、揃った全光路をしばらく見せてから結果へ進む。動きを減らす設定では光路を伸ばさずに全光路を示し、同じ時間見せてから結果へ進む。

一度盤面に置いたピースを、別のマスへ移す、入れ替える、ストックへ戻す、別の種類で置き換える回数を、置き直しとして記録する。入れ替えは動いた2個を1回と数える。盤面を戻して回収したピースは置き直しに数えない。解答との照合は置き直しの判定に使わない。

直前の盤面操作を取り消す「待った」は提供しない。置いたピースは直接選んで、別のマスへ移す、入れ替える、ストックへ戻すことができ、1手戻す役割がこの操作と重なるため。

プレイ中は経過時間だけを示す。経過時間はプレイ開始からクリアまでを計る。置き直し回数、盤面を戻した回数、光路を確かめた回数は評価に使わないため、プレイ中に示さない。

ヒント、確定できるマスや種類の提示、完成解との照合は通常UIで提供しない。

ルールと操作は、盤面と同じ見た目の小さな図と短い文で示す遊び方として、プレイ中と難易度の選択時に確認できるようにする。初めてリフレクションを遊ぶときは、盤面に触れる前に遊び方を示し、一度閉じた後は自動では示さない。初めての遊び方を読んでいた時間はプレイの経過時間に含めない。

プレイ中は、盤面を戻す操作、同じ問題のやり直し（画面の「リセット」）、新しい問題の開始を提供する。盤面を戻す操作は、同じプレイを続けたまま全ピースをストックへ戻し、経過時間とそれまでの置き直し回数を引き継ぎ、戻した回数を数える。同じ問題のやり直しと新しい問題の開始は新しいプレイとして始め、各回数と経過時間を数え直す。

## 難易度

難易度は `レベル 1`〜`レベル 5` の5段階とする。問題難易度は、ルール・6種類のピース・外周ヒントの意味を理解し、外周ヒントごとの一致を見ながら遊び、光路の表示は置いたピースの確認に使い、盤面を戻す操作を使わないプレイを基準にする。盤面の大きさとピース数だけによる作業量、光路を頭の中で追い続ける負担、解くまでの入力回数や時間そのものは問題難易度に含めない。

リフレクションの挑戦は、外周ヒントの結果から見えないピースの位置と種類を1つずつ確定させ、1本の光路で決まらないときは複数の光路、手持ちの残り数、仮に置いた先の矛盾まで読んで確定させることとする。外周ヒントごとの一致が見えるため、外周ヒント同士が同じピースを取り合わない問題は、1本ずつ試し置きで合わせていくだけでも解ける。複数の外周ヒントが同じピースを取り合い、1本を合わせると別の1本が崩れることも、読みを要する挑戦として扱う。各難易度で利用者が出会う挑戦は次のとおりとし、上の難易度ほど必要な推論が深くなる。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 1本の外周ヒントを見れば、置く場所と種類が決まる |
| 2 | 候補を他の外周ヒントと照らし合わせて絞る |
| 3 | 1つ決まると別の外周ヒントの候補が減り、連鎖して決まる |
| 4 | 手持ちの残り数も手がかりにして決める。1本ずつ合わせていくと別の外周ヒントが崩れる |
| 5 | 広い盤面で、仮に置いた先の矛盾まで読まないと決まらない。1本ずつの試し置きでは押し切れない |

難易度は推論の深さを主軸にし、盤面の大きさとピース数を各難易度で許す範囲として、外周ヒントを1本ずつ試し置きで合わせる進め方で押し切れる度合いを難易度4・5 の条件として組み合わせる。上の難易度ほど許す範囲と条件を下げず、隣り合う難易度は同じ規模を共有する。同じ規模の問題は推論の深さと試し置きで押し切れる度合いで難易度が分かれ、規模だけで難易度が上がる・下がることはない。この組み合わせによる分類は、実プレイで検証する仮決定とする。

難易度の選択肢には、その難易度で遊ぶ盤面の幅とピース数の範囲に収まる模式図として、盤面の一部の帯を1本の光が斜め鏡で折れながら横切る図を示す。光の折れる回数（たどる光路の長さ）は上の難易度ほど増え、推論の深さを表す。色は光路とピースの2色にとどめ、外周ヒントの数字や結果の形は描かない。上の難易度の図は、下の難易度の図の鏡をすべて同じ位置に含み、光路はその続きになる。

### 判定

難易度は、手持ちと外周ヒントだけから人間向けの推論で各マスの候補を絞る過程を分析して判定する。推論は浅い段階から順に、1本の外周ヒントからの直接の確定、候補を全外周ヒントに照らした除去、その除去の繰り返しによる連鎖、手持ちの残り数の利用、候補を仮に置いた先の矛盾による除去を区別し、全ピースの置き場所を決め切るまでに使った最も深い段階を観測する。光路は、同じマスを2回通るなら同じピースとみなし、手持ちの残り数を超えるピースを使う光路を考えない。

あわせて、推論をせずに、一致していない外周ヒントを1本ずつ狙い、その光路の上にピースを置いたり入れ替えたりして一致させていく決まった手順の試し置きで、解き切れるか、一致していた外周ヒントを崩したり置き方を変えたりした手が何回要るかを観測する。

分析結果は、次の状態を区別して扱う。

- 成立しない: 解が無い、2つ以上ある、または一意性を確かめられない。提供しない。
- 評価不能: 一意解だが、最も深い段階まで使っても決め切れない、または仮に置いて確かめる回数が上限に達する。高難易度と推定せず、提供しない。
- 提供範囲外: 分析できるが、推論の深さ・規模・試し置きの組がどの難易度の範囲にも当たらない。近い難易度へ寄せず、提供しない。
- 難易度1〜5: 推論の深さ・規模・試し置きの組がその難易度の範囲に入る。

正確な推論と試し置きの手順、探索と仮定の上限、各難易度の盤面の大きさ・ピース数・試し置きの条件はコードを正とする。

### 供給

各難易度の問題は、判定済みの問題を事前に生成した問題集から供給する。回転・反転で一致する問題は同じ問題として扱い、問題集に重複させない。各難易度の問題集は、その難易度で許す盤面の大きさとピース数の組からほぼ均等に採る。プレイ開始時に seed を定め、その seed で選んだ難易度の問題集から1問を選ぶ。同じ seed と同じ問題集からは同じ問題を選ぶ。プレイ時には問題の生成・解探索・難易度分析を行わない。

選んだ問題は、問題を再現するための情報とともに扱い、同じ問題のやり直しでは同じ問題を空の盤面から始める。新しい問題の開始と難易度の選び直しでは、新しい seed で問題を選ぶ。

## 成績評価

クリアしたプレイだけを評価し、1プレイを100点満点で評価する。推測なしで解ける問題だけを提供し、外周ヒントごとの一致を見ながら置いて確かめ、動かして直すことをこのゲームの中心の操作とするため、迷わず速く配置を復元することを称える。置き直し、盤面を戻すこと、光路の確認は減点しない。

- 速さ 100点: 問題ごとの基準時間を満点基準とし、超過に応じて線形に減点する。基準時間の3倍で0点とする。点は1点単位に四捨五入し、0点から100点の範囲とする。基準時間は、読んで解く時間（外周ヒント1本あたり0.5秒、ピース1個あたり3.5秒、照らし直す局面1つあたり1.25秒、仮に置いて確かめる回数1回あたり3.5秒（10回を上限とする）の合計）と、読んで解く時間と試し置きで解く時間（外周ヒント1本あたり0.5秒と、試し置きの1手あたり5秒の合計）の短い方との中間とする。試し置きで解き切れない問題は、読んで解く時間を基準時間とする。

100点を `perfect`、90点以上を `great`、80点以上を `good`、それ未満のクリアを `clear` とする。基準時間の1.2倍以内で `great`、1.4倍以内で `good` に残る。基準時間の係数は、難易度5 の問題を熟練者が読んで解いた実プレイ（1人）の水準に合わせた暫定値とし、0点になる倍率とともに、代表的な問題の実プレイを重ねて校正する仮決定とする。

置き直し回数、盤面を戻した回数、光路を確かめた回数、入力回数は評価に使わない。置き直しを減点すると、一致を見ながら置き直す遊び方や押し間違いの修正を罰することになるため。盤面を戻しても経過時間は続き、戻すまでに使った時間は速さに表れる。

照らし直す局面の数は、判定と同じ人間向けの推論でその問題を解き切るまでに、全外周ヒントへ照らし直して候補が変わった回数とする。仮に置いて確かめる回数は、そのうち候補を仮に置いて確かめた回数とする。試し置きの手数は、判定と同じ試し置きの手順で解き切るまでの手数とする。いずれも問題の性質として問題ごとに定まる。基準時間は問題の作業量だけから決め、難易度そのものを加点や基準時間の理由にしない。

記録するプレイ事実は、難易度、問題を再現するための情報、問題の作業量（ピース数、外周ヒントの本数、照らし直す局面の数、仮に置いて確かめる回数、試し置きの手数）、経過時間、置き直し回数、盤面を戻した回数、光路を確かめた回数、入力回数とする。評価点、評価段階、基準時間、基準時間との差は保存した事実から現在の評価規則で導出する。

生成器の版が変わるなどして記録の問題を問題集から引けなくなっても、その記録は履歴と自己ベストに残し、記録した問題の作業量から評価する。そうした記録からは同じ問題を再プレイできないものとして扱い、再プレイできないことを示す。

履歴と自己ベストの比較単位は難易度とする。自己ベストとして、評価点は高いほど、問題ごとの速さ満点基準時間に対するクリア時間の差は少ないほど良い値として比較する。置き直し回数と光路を確かめた回数は、評価に使わず、少ないほど良いとは言えないため比較に使わない。

結果では、評価点と評価段階に続けて、経過時間と基準時間との差、置き直し回数をリフレクションの主要成績として扱う。置き直し回数は評価に使わないプレイの事実として示す。盤面を戻した回数、光路を補助として扱うときの光路を確かめた回数、評価の内訳と基準時間の根拠は主結果と分けて確認できるようにする。履歴では、評価点と基準時間との差を難易度ごとに比較する主要指標として扱う。
