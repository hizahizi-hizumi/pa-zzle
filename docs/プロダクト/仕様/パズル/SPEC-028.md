# SPEC-028 箱入り娘

4×5 の箱の中で、大きさの違う駒をなぞって空きマスへすべらせ、娘（2×2 の駒）を下辺の出口まで運ぶパズル。娘を通す道を空けるために、ほかの駒をどこへどの順でよけるかを先に読む。

## ルールと問題

- 盤面は 4 列 × 5 行の箱で、出口は下辺の真ん中の2マスとする。駒は娘（2×2）・縦長（1×2）・横長（2×1）・小駒（1×1）で、娘はちょうど1つある。娘のほかの駒は箱の外へ出ない。
- 利用者は駒をなぞって動かす。駒は空きマスを1マスずつ伝って動き、なぞったまま角を曲がってもよい。塞がれた向きへは動かず、ほかの駒を飛び越えたり回り込んだりしない。
- 同じ駒の続けての移動を、何マス動いても何回曲がっても1手と数える。途中で指を離しても、次に同じ駒をなぞればその1手の続きとする。待った・盤面を戻すの後に同じ駒を動かすと、新しい1手とする。
- 同じ1手の中で駒を1手の前の位置へ戻したら、その1手は指さなかったことにする（手数から外し、待ったで戻す手にもしない）。最短手数は盤面が変わる手だけを数えるので、それと数え方をそろえる。
- 娘の左上が下から2段目・左から2列目（出口の前）に着けば、その時点でクリアとする。最短の手数でなくてよく、どの道順でもよい。失敗して終わる条件もミスとして数える操作も無い。

問題は次を満たすものに限る。

- 娘を出口の前へ運べる盤面だけを問題にし、どの問題も最短手数が分かっている（解いた後の表示と評価の基準に使うため）。最短解は1つでなくてよい。
- 最短手数が短すぎる問題（よける順を読む前に解ける）と、長すぎる問題（最上位の横刀立馬を大きく超える）は出さない。
- 左右を反転した盤面は同じ問題とし、片方の向きだけを出す。
- 同じ難易度の中で、少し動かせば行き来できる2問や、解き筋の大半が重なる2問を重ねて出さない（同じ問題を解き直させないため）。

## 状態の知らせ

- 動けない向きへなぞっても、駒が動かないことだけで知らせる。文章も音も出さない。

## 補助

補助は無い。正しい手・残りの手数・最短手数はプレイ中に出さない。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。待ったは直前の1手（同じ駒の続けての移動のまとまり）を戻す。待ったと盤面を戻すは、それまでの手数と時間を減らさない。

## 難易度

- 基準とするプレイは、正しい手と残りの手数が見えない盤面で、待ったと盤面を戻すを使えるプレイとする。手数と速さは難易度に含めない。
- 挑戦は、娘を出口へ通す道を空けるために、娘を出口へ進められないあいだに、ほかの駒をどこへどの順でよけるか（ときに娘をいったん出口から遠ざけるか）を先に読むこととする。
- 難易度は、準備の長さ、娘の遠回り、規模（空きマスの数）の組で決める。
  - 準備の長さは、娘が出口へ近づき、その後二度と戻らない距離へ出る手（前進）と前進のあいだの手の数の最長とする。1手の滑りの途中で娘が通る位置も、戻らないかどうかに含める。
  - 娘の遠回りは、娘を出口から遠ざける手の数とする。
  - どちらも最短解に限らず、どんな長さの解でもよいとして、値が最も小さくなる解で数える。回り道、娘の往復、一時的に娘を前へ出して戻す手、1手の中で遠回りして戻る滑りで値が下がらないようにするためである。
- 最短手数は難易度に使わず、短すぎる問題と長すぎる問題を提供範囲から外すためにだけ使う。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 空きが多く、娘はまっすぐ出口へ向かう。数手よけるだけで道が開く |
| 2 | 娘を進める前に十手ほどよけ方を読む。娘を一度わきへよけることもある |
| 3 | 空きが減り、娘を進められない手が続く。娘を1〜2回遠ざけながら、駒の入れ替えを先に読む |
| 4 | 空きは2〜3マス。娘を進める前に、二十手を超える長い入れ替えを組む |
| 5 | 空きは2マス。横刀立馬のように、娘を2回以上遠ざけ、三十手を超える入れ替えを読み切る |

- 上の難易度は、どの観点でも下の難易度より弱くならない。最上位は横刀立馬くらいまでとする。
- 規模は各難易度で許す範囲として組み合わせ、規模だけで難易度は決めない。
- 盤面が小さく全局面を数え切れるので、評価できない問題は無い。娘が出口に着けない問題は成立しない問題とする。

## 評価

よける駒と順を先に読み、最短の手数で娘を出口へ運ぶことを称え、その上で速さを称える。

- 効率 70点: 手数を最短手数と比べ、手数が最短手数のときだけ満点とする。最短手数と手数のそれぞれに同じゆとりの手数を足した比で減らし、短い問題でも試しに動かした1手の減点を小さく保つ。
- 速さ 30点: 経過時間を、最短手数と準備の長さから決める基準時間と比べる。難易度そのものを基準時間の理由にしない。

待ったと盤面を戻すは別に減点しない。取り消した手は手数として効率に、かかった時間は速さに表れる。問題集から引けなくなった記録も、記録した問題の作業量から評価し、自己ベストの比較に使う。

自己ベストでは、評価点は高いほど、基準時間との差と最短手数との差は少ないほど良い値として比べる。
