# SPEC-028 箱入り娘

4×5 の箱の中で、大きさの違う駒をなぞって空きマスへすべらせ、娘（2×2 の駒）を下辺の出口まで運ぶパズル。娘を通す道を空けるために、ほかの駒をどこへどの順でよけるかを先に読む。

## ルールと問題

- 盤面は 4 列 × 5 行の箱で、出口は下辺の真ん中の2マスとする。駒は娘（2×2）・縦長（1×2）・横長（2×1）・小駒（1×1）で、娘はちょうど1つある。娘のほかの駒は箱の外へ出ない。
- 利用者は駒をなぞって動かす。駒は空きマスを1マスずつ伝って動き、なぞったまま角を曲がってもよい。塞がれた向きへは動かず、ほかの駒を飛び越えたり回り込んだりしない。
- 駒をマスへ移さないまま速く弾いて離したときは、弾いた向きの隣が空いていれば1マス動かす（ほかのゲームの短いスワイプで動かすのに慣れた人が、動かないと受け取らないため）。
- 同じ駒の続けての移動を、何マス動いても何回曲がっても1手と数える。途中で指を離しても、次に同じ駒をなぞればその1手の続きとする。待った・盤面を戻すの後に同じ駒を動かすと、新しい1手とする。
- 同じ1手の中で駒を1手の前の位置へ戻したら、その1手は指さなかったことにする（手数から外し、待ったで戻す手にもしない）。最短手数は盤面が変わる手だけを数えるので、それと数え方をそろえる。
- 娘の左上が下から2段目・左から2列目（出口の前）に着けば、その時点でクリアとする。最短の手数でなくてよく、どの道順でもよい。失敗して終わる条件もミスとして数える操作も無い。

問題は次を満たすものに限る。

- 娘を出口の前へ運べる盤面だけを問題にし、どの問題も最短手数が分かっている（解いた後の表示と評価の基準に使うため）。最短解は1つでなくてよい。
- 最短手数が短すぎる問題（よける順を読む前に解ける）と、長すぎる問題（最上位の横刀立馬を大きく超える）は出さない。
- 左右を反転した盤面は同じ問題とし、片方の向きだけを出す。
- 同じ難易度の中で、少し動かせば行き来できる2問や、解き筋の大半が重なる2問を重ねて出さない（同じ問題を解き直させないため）。片方を左右反転した盤面で比べても同じにする。
- 違う難易度のあいだでも、上の難易度の問題から少し動かした盤面や、その最短の解の途中の盤面を、下の難易度の問題にしない（上の難易度を優先する）。
- 難易度4・5 では、娘が出口の前に着く1手前の盤面（左右反転は同じ）が同じになる問題を出しすぎない（終わり方が似た問題が続かないため）。
- 作られた初期配置に見える盤面を出す。小駒は6個以下とし、難易度4・5 では娘を上の2段から始める。下の難易度でも娘が上の段から始まる盤面と、左右対称や空きのまとまった盤面を先に出す。始めから娘が動ける盤面と、合法な初手が1つしかない盤面は後に回し、空きが下の段にある盤面を先に、上の段にある盤面を後に出す。図鑑の並びの始めの数十問は、その難易度の最短手数の中央値以下の問題にする（ランダムに遊ぶ問題の選び方は変えない）。
- 1つの難易度の中で、最短手数が大きくばらつかないようにする。難易度1 は 18 手まで、難易度3 は 40 手まで（難易度4 と手数が入れ替わらないため）、難易度4 は難易度5 の最短手数の中央値より短くする。難易度5 は長い問題を厚くする。
- 1手ずつ行き来できる盤面の集まり（連結成分）から、1つの難易度に採る問題の数に上限を置く（解き筋の似た問題が続かないため）。

## 状態の知らせ

- 押している駒は持ち上げて見せ、つかんだことを知らせる。動けない駒でも同じに持ち上げ、押し返しや音は付けない。
- なぞっている間、駒は置ける向きにだけ、指が隣のマスへ移ったとみなす所（0.65 マス）まで指へ寄せて見せ、指を離すと今のマスに収まる。寄せの上限を移る所とそろえ、駒が途中で止まって移るときに跳ばないようにする。寄せるのは横か縦の一方で、指が大きく離れた向きがふさがれていれば空いた向きへ寄せる。斜めになぞったときは今の向きを保ち、もう一方のずれがはっきり大きくなったときだけ向きを替え、前の向きの寄せは短く移して消す（ちらつきと跳びを出さない）。寄せて見せるのは見た目だけで、駒のマスと手数は変えない。
- 娘が出口の前に着いたら、その時点でクリアとし、指へ寄せていたずれを収めて持ち上げを下ろし、出口の前に少し止めてから下の縁の出口を抜けさせる。抜けていく音と落ちる音は、この動きと同じ時刻を始まりに合わせる。
- 動けない向きへなぞっても、駒が動かないことだけで知らせる。文章も音も出さない。

## 補助

補助は無い。正しい手・残りの手数・最短手数はプレイ中に出さない。

出口は箱の縁の切れ目として、外の明るさが差し込む淡い色で見せる。出口はルール（娘を運ぶ先）の一部で補助ではない。出口の前の2×2 のマスは塗らない（行き先の示しすぎになるため）。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。待ったは直前の1手（同じ駒の続けての移動のまとまり）を戻す。待ったと盤面を戻すは、それまでの手数と時間を減らさない。

## 難易度

- 基準とするプレイは、正しい手と残りの手数が見えない盤面で、待ったと盤面を戻すを使えるプレイとする。手数と速さは難易度に含めない。
- 挑戦は、娘を出口へ通す道を空けるために、娘を出口へ進められないあいだに、ほかの駒をどこへどの順でよけるか（ときに娘をいったん出口から遠ざけるか）を先に読むこととする。
- 難易度は、準備の長さ、娘の遠回り、規模（空きマスの数）の組で決める。
  - 準備の長さは、娘が出口へ近づき、直前の前進の距離を下回り、その後二度と戻らない距離へ出る手（前進）と前進のあいだの手の数の最長とする。1手の滑りの途中で娘が通る位置も、戻らないかどうかに含める。
  - 前進の基準を直前の前進の距離にするのは、娘を一時的に前へ出して戻しても、後の前進が前進でなくならないようにするためである。
  - 娘の遠回りは、娘を出口から遠ざける手の数とする。
  - どちらも、娘の続けての移動を1手として数える（同じ駒の続けての移動は1手のため）。娘の1手を2つに分けると、2つ目が前進になって準備の長さが下がることがあるので、解の上で娘の手を続けて2つに分けない。
  - 2つは同じ1つの解の上で数える。最短解に限らず、同じ盤面を2度通らない解であればどんな長さの解でもよいとして、準備の長さが最も小さくなる解を選び、その中で遠回りが最も少ない解を選ぶ。回り道、娘の往復、一時的に娘を前へ出して戻す手、1手の中で遠回りして戻る滑りで値が下がらないようにし、難易度が実在する1つの解き方の姿を指すようにするためである。同じ盤面へ戻る輪を含む解でしか出ない値（娘を一度上げて戻して前進の位置をずらす解）は数えず、輪の無い解でその値になることを確かめられない問題は出さない。その解に、娘の2つの手を、あいだのほかの駒の手と入れ替えて娘の1手にまとめられる並びがあれば、まとめた解で数え直し、値が変わる問題も出さない（娘の1手を分けて値を下げた解のため）。
- 難易度2 以上には、最短の解だけで数えた準備の長さが最短手数の 0.87 倍以下の問題だけを出す。最短で解いても娘を進められる区切りがほとんど無い問題では、準備の長さが手数そのものになり、難易度が作業の量で決まってしまうためである。最短の解で数えるのは、長い解で回り道をして区切りを作ることで、この上限をすり抜けられないようにするためである。
- 最短手数は難易度に使わず、短すぎる問題と長すぎる問題を提供範囲から外すためにだけ使う。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 空きが多く、数手よけるだけで道が開く。娘をわきへよけるのは多くて1回 |
| 2 | 娘を進める前に十手ほどよけ方を読む。娘を一度わきへよけることもある |
| 3 | 空きが減り、娘を進められない手が続く。娘を1〜2回遠ざけながら、駒の入れ替えを先に読む |
| 4 | 空きは2〜3マス。娘を進める前に、二十手を超える長い入れ替えを組む |
| 5 | 空きは2マス。横刀立馬のように、娘を2回以上遠ざけ、三十手を超える入れ替えを読み切る |

- 上の難易度は、どの観点でも下の難易度より弱くならない。最上位は横刀立馬くらいまでとする。
- 規模は各難易度で許す範囲として組み合わせ、規模だけで難易度は決めない。
- 盤面が小さく全局面を数え切れるので、評価できない問題は無い。娘が出口に着けない問題は成立しない問題とする。

## 評価

よける駒と順を先に読み、最短の手数で娘を出口へ運ぶことを称え、その上で速さを称える。

- 効率 70点: 手数を最短手数と比べ、手数が最短手数のときだけ満点とする。最短手数と手数のそれぞれに同じゆとりの手数を足した比で減らし、短い問題でも試しに動かした1手の減点を小さく保つ。
- 速さ 30点: 経過時間を、最短手数と準備の長さから決める基準時間（1秒単位に切り上げる）と比べ、基準時間の3倍で0点とする。よける順を先に読む時間は読みの当たり外れでぶれるので、先を読む遊びのほかのゲームと同じ倍率にする。難易度そのものを基準時間と倍率の理由にしない。

待ったと盤面を戻すは別に減点しない。取り消した手は手数として効率に、かかった時間は速さに表れる。問題集から引けなくなった記録も、記録した問題の作業量から評価し、自己ベストの比較に使う。

結果の内訳には、最短手数と並べて、完成した盤面までの手の数（待ったで取り消した手と盤面を戻す前の手を除く）を出す。記録は、手数が最短手数の50倍以下、経過時間が24時間以下で、今の問題集にある盤面ならその盤面を収めた難易度のものだけを読み、ほかは無いものとして扱う。

自己ベストでは、評価点は高いほど、基準時間との差と最短手数との差は少ないほど良い値として比べる。
