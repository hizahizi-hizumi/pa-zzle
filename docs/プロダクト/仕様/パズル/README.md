# パズル仕様

特定のパズルでのみ成立する現在のゲーム契約を置く。

新しいパズルを追加するときは、既存ゲームの構造をコピーするのではなく、そのパズルについて少なくとも次を判断し、採用した内容を仕様化する。

- 何を完成させればクリアかという基本ルール
- 問題として成立するために何を保証するか
- 利用者が何を見て、どう操作するか
- プレイを補助する操作を何として提供するか
- 人間にとっての難しさを何が生み、どう分類するか
- 一回のプレイで何を良いプレイと評価し、何を計測するか
- 履歴・自己ベストで何を同じ条件として比較するか

すべてを同じ章立てで書く必要はない。基本ルール、入力、問題生成上の保証、難易度、採点、ゲーム固有機能など、そのパズルの意味を将来の実装から独立して判断するために必要な契約を書く。

調査・検証の過程や候補は `docs/パズル/` 等へ残し、ここには採用された現在の契約だけを置く。

調査から実装・レビュー・正本化までの一連の工程は [`../../../開発/パズル追加手順.md`](../../../開発/パズル追加手順.md) を参照する。
