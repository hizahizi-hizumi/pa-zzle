# SPEC-025 氷の床迷路

氷の床の上で、ぶつかるまで止まらずに滑る駒を動かし、止まれる場所だけを足場にしてゴールのマスで止めるパズル。もろい岩・薄い氷・雪・滑る氷の塊は滑りによって変わったり動いたりし、解いている途中の盤面は初期盤面と違っていく。

## ルールと問題

- 盤面は氷・岩・床・もろい岩・薄い氷・雪・滑る氷の塊のマスで、駒が1つ、ゴールが1マスある。盤面は外壁が囲み、外壁は盤面として描くマスの形に沿う。盤面として描かないマス（盤面の外）は外壁と同じく駒を止め、盤面に囲まれた盤面の外は外壁として示す。
- 利用者は上下左右の向きを選ぶ。駒はその向きへ、岩・もろい岩・水面・雪山・滑る氷の塊・外壁のどれかにぶつかるか、床か雪に入るまで止まらずに滑り、利用者は止まる位置を選べない。
- 床は駒が入れるマスで、滑ってきた駒は床に入るとそこで止まる。床の上からは氷と同じく滑り出す。床は変化しない。床に入って止まった滑りでは、床の先のもろい岩は崩れない。
- もろい岩は、駒が滑ってきてその手前で止まったときだけ、その滑りの後で崩れて氷になる。すぐ隣にいる駒をもろい岩へ向けても崩れない。
- 薄い氷は上を滑れ、駒が離れると割れて水面になる。滑りの出発マスと途中で通ったマスの薄い氷は、その滑りの後で割れる。駒が止まっている間は割れない。
- 雪は、駒が滑り込むと進む向きへ1マス押し出されて雪山になり、駒は雪のあったマスで止まる。雪のあったマスは氷になる。押し出す先が氷か薄い氷でなければ（岩・もろい岩・水面・雪・雪山・滑る氷の塊・床・盤面の外・外壁）雪は動かず、駒は雪の手前で止まる。雪山は止め役で、動かず、積み重ならない。雪山は薄い氷の上に載っても薄い氷を割らない。雪はゴールの上へも押し出せ、雪山で埋まったゴールにはもう止まれない。
- 滑る氷の塊は止め役で、駒が1マス以上滑ってきてぶつかると、塊を押しながら一緒に滑る。塊は岩・もろい岩・水面・雪・雪山・ほかの塊・床・盤面の外・外壁の手前で止まり、駒はその塊の手前で止まる。塊が1マスも動けなければふつうの岩と同じく手前で止まる。すぐ隣にいる駒を塊へ向けても塊は動かない。塊は薄い氷を割らず（駒が通った薄い氷は割れる）、ゴールの上を通り、止まることもできる。塊がゴールの上にある間は駒はゴールに入れない。
- 1マスも動けない向きを選んだ操作は成立せず、盤面を変えず、手数にもミスにも数えない。
- 成立した滑り1回を1手と数え、滑った距離によらない。待ったで取り消した手と盤面を戻す前の手も、総手数に残す。最短手数も滑りの回数で求める。
- 滑りが止まった位置がゴールなら、その時点でクリアとする。滑りの途中でゴールを通過しても、止まった位置がゴールでなければクリアにしない。失敗して終わる条件もミスとして数える操作も無い。

問題は次を満たすものに限る。

- 開始位置からゴールで止まれることを生成で保証し、最短手数を事前に求めて持つ。最短解はただ1つとする。
- 開始位置とゴールは氷のマスとする（床・雪・滑る氷の塊にしない）。水面と雪山は初期盤面に置かない。
- 盤面として描くのは、到達できるいずれかの状態で駒が通るか止まるマス・雪山ができるマス・滑る氷の塊が通るか止まるマスと、それに接する岩・もろい岩・滑る氷の塊だけとする。どの状態でも動かない滑る氷の塊は岩として置く。
- 同じ向きへ続けて滑る手を生む配置を作らない。要素のある問題では、最短に近いどの道筋にも同じ向きへ続く2手が無く、どの状態にも、もろい岩を崩す・雪を押し出す・滑る氷の塊を動かした直後に、同じ向きでもう一度同じことができる配置が無い。床のある問題では、最短解に同じ向きへ続く2手が無く、止まれるどの位置からも、床に入って止まった後に同じ向きへ1マスだけ進むか別の床で止まる手（同じ向きの連打）が無い。
- 床は答えの目印にしない。床のある問題には、最短解で止まる床と、最短解では止まらないがもっともらしい手が止まるおとりの床を両方置き、氷にしても最短解・もっともらしい選択肢・選択肢ごとの詰みのどれも変わらない床は置かない。床で止まる位置ごとに道筋を区切っても、区切った区間の読みがその難易度の読みの深さを下回らない。
- どの選択にも関わらない要素（もろい岩・薄い氷・雪・滑る氷の塊）は置かない。要素のある問題には、最短解では変えないが、もっともらしい手で変えると詰むか大回りになる要素（おとり）を含める。
- 要素を変わらないもの（初期の姿のまま、または変わった後の姿のまま）として読んだ盤面の道筋が、このルールでもそのまま最短に近い手数で通る問題は出さない。
- 戻らない選択肢が1つしかない手（一本道）が多い問題は出さない。
- 最短解に、1マスだけの滑りや、選択肢の無いまま直交する2つの向きを交互に続ける手（階段）を多く含む問題は出さない。
- 要素のある問題では、止め役（水面・雪山・動かした塊）を作ってすぐそれで止まる手筋を繰り返す問題、前の手が作った地形をそれ以外の形で使う手の無い問題、要素も誘いも関わらない移動だけの手が長く続く問題を出さない。

ゴールへ二度と止まれない状態（詰み）へ入れる問題も出す。

## 状態の知らせ

- 直前の滑りで通ったマスを跡として示し、止まった後も残す。ゴールを通過したことは跡で読めるようにする。
- 崩れたもろい岩の跡は、止め役でないと分かる姿で盤面に残す。
- 雪・雪山・滑る氷の塊は、互いと岩・水面とを見分けられる姿で描く。雪を押し出す動きと、塊が駒と一緒に滑って止まる動きを見せる。

## 補助

- 詰みに入ったこと（この先の手詰まり）は補助とし、次の出し方で文章で知らせて遊び方で説明する。
  - 詰みに入っても、すぐには知らせない。詰みのまま、待った・盤面を戻すを使わずに決まった回数滑り続けたとき、気づいていないと見なして、もうゴールに止まれないことを知らせ、待ったと盤面を戻すへ導く。成立しない入力は滑りに数えない。
  - 待った・盤面を戻す・リセットを使ったら、気づいたと見なして数え直す。戻った先がまだ詰みなら、そこから数える。
  - 詰みの中で移れる状態（盤面と駒の位置の組）が数種類しかないときは、その詰みへ滑った時点で数えずに知らせる。行き来するだけで試行錯誤の余地が無いため。
  - 知らせた後は、滑っても、待った・盤面を戻すで戻っても、ゴールで止まれる状態に戻るまで知らせ続ける。

## 操作

方向ボタンを置かない。向きは盤面の領域と操作欄でのスワイプと、矢印キーで選ぶ。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。待ったは、直前の滑りで崩れたもろい岩・割れた薄い氷・押し出した雪・動かした滑る氷の塊も元に戻す。

## 難易度

- 基準とするプレイは、待ったと盤面を戻すを使える状態で、試し滑りに頼らずに、止まる位置と、要素が変わったり動いたりした後の盤面を読んで道筋を組み立てるプレイとする。最短手数と盤面の広さそのものは難易度に含めない。
- 挑戦は、止まれる場所を先まで繋いでゴールで止まる道筋を組み立てることとし、要素のある盤面では、初期盤面のとおりに読まず、要素を変える滑りで自分の手が作る地形（割れてできた水面・押し出してできた雪山・動かした塊、崩れて開いた通り道・雪をどけた跡・塊の元の場所）を読み、それに何手も後で頼る道筋を組み立てることとする。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 氷と岩（と床）だけ。ゴールの先の岩（止め石）を使って止まる道筋を組み立てる |
| 2 | 氷と岩（と床）だけ。止め石へ回り込む道筋や、ゴールを通り過ぎる誘いを避けて一度離れ、入り直す道筋を長く組み立てる |
| 3 | もろい岩・薄い氷・雪・滑る氷の塊のどれか1種類が少し加わる入門。変える要素は少なく、自分で作った地形に頼る読みは浅い。おとりは、変えるとすぐに、要素を変えない滑りでは同じところを回るだけの詰みになるものだけとする |
| 4 | 薄い氷、もろい岩と薄い氷、雪、雪と薄い氷、滑る氷の塊、滑る氷の塊と薄い氷のどれかが加わり、自分で作った地形に後の手でたびたび頼る |
| 5 | 4 と同じ組み合わせの要素が4 より多く加わり、何手も前に作った止め役で何度も止まり、ゴールの止め役も自分で作るなど、自分で作った地形に最も深く頼る。ただし頼る読みの多さには上限を置き、遊び切れないほど深くはしない |

- 氷と岩だけの難易度は、含む手筋と読みの深さで分ける。床は止まれる場所を変える要素として、氷と岩の難易度に床の無い問題と混ぜて出し、床の有無と数では難易度を分けない。要素のある難易度には床を置かない。要素のある難易度は、自分の手で作った地形に何手も後で頼る読みの多さで分け、要素の種類と数では分けない。隣り合う難易度で、この多さの範囲を重ねない。
- 隣り合う難易度が同じ組み合わせの要素を持つときは、要素の数の範囲を重ねない。
- 盤面の広さは各難易度で許す範囲とし、盤面の広さだけで難易度は決めない。

## 評価

試し滑りをせず、止まる位置と要素の変わり方を読んで最短の道筋でゴールに止めることを称え、その上で速さを称える。要素を試して盤面の変化を確かめることを重く罰しない。

- 効率 60点: 総手数を最短手数と比べ、総手数が最短手数のときだけ満点とする。最短手数と総手数のそれぞれに同じゆとりの手数を足した比で減らし、短い問題でも試し滑り1回の減点を小さく保つ。
- 速さ 40点: 経過時間を、盤面として描くマスの数、最短手数、初期盤面の要素（もろい岩・薄い氷・雪・滑る氷の塊）の数から決める基準時間と比べる。難易度そのものを基準時間の理由にしない。

待ったと盤面を戻すは別に減点しない。取り消した手は総手数として効率に表れる。問題集から引けなくなった記録も、記録した問題の盤面と最短手数から評価し、自己ベストの比較に使う。

自己ベストでは、評価点は高いほど、基準時間との差と最短手数との差は少ないほど良い値として比べる。
