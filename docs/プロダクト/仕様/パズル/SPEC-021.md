# SPEC-021 詰将棋

9×9 の将棋盤の局面と攻方の持駒から、攻方が王手だけを続けて、決められた手数のうちに玉方の玉を詰ませるパズル。利用者は攻方だけを指し、玉方は自動で指す。

## ルールと問題

- 駒の動き、成り、持駒の打ち方、指せない手（二歩、打歩詰、行き所のない駒になる手）は本将棋に従う。
- 攻方は毎手、王手をかける。玉方は、詰むまでの手数が最も長くなる応手を選ぶ（最長抵抗）。玉方は、盤上と攻方の持駒に無い玉以外のすべての駒（駒箱）を持駒として使える。
- 玉方の応手は、攻方が指してから間を置いて盤面に指す。玉方の手を攻方の手と分けて見せ、見落とさないようにするため。
- 手数は攻方と玉方の手を合わせた数とし、問題によって3手か5手に決まる。手数は問題と一緒に「n手詰」として示し、開始条件として選ばせない。1手詰は提供しない。
- 問題は、早詰・余詰・駒余りが無く、作意に玉方の合駒が現れず、無駄合と2手変長をどう解釈しても手数・作意・攻方の正解が変わらないものに限る。玉方の最長の応手が複数ある問題は採り、玉方が指す応手を1つに決める。
- 王手にならない手と、ルールで指せない手は着手させず、ミスに数えない。
- 作意の上の攻方の手番を判断地点とし、判断地点から指した合法な王手のうち、残りの手数のうちに詰まないものを誤王手とする。誤王手を指しても不正解として戻さず、玉方は残りの手数のうちに詰まなくなる応手（反証）を盤面に指す。誤王手の筋でも王手を続けられ、残りの手数が尽きるか王手が無くなると、それ以上は指せない。
- 誤王手は、判断地点から指すたびに1回と数え、誤王手の筋を続けた王手は数えない。同じ判断地点で同じ誤王手を、待った・盤面を戻すで戻して指し直したときは1回だけ数える。
- 誤王手をミスとして数える。ミスとして数える操作はほかに持たない。
- 作意ではないが残りの手数のうちに詰む王手は、詰みへ向かう手として受ける。
- 玉方の玉を詰ませた時点でクリアとする。

## 状態の知らせ

- 玉方の持駒は、枚数を並べずに「残り全部」とだけ示す。盤上と攻方の持駒に無い駒はすべて玉方が使えるため。
- 直前の攻方と玉方の1組の手だけを、棋譜で盤面の移動と並べて示す。同じ升へ動ける駒が2枚ある手にも「右」「上」などは付けない。どの駒が動いたかは盤面で分かるため。
- 玉方の反証の応手と、誤王手の筋でそれ以上指せなくなったことは状態の知らせとし、通常の操作として遊び方で説明する。指せなくなったことは「この手数では詰まない」とだけ示し、その筋が詰まないとは言い切らない。
- 着手させなかった手は、選んでいた駒を揺らして成立しなかった操作として返し、理由は文で示さない。動きを減らす設定では揺らさずに、選んでいた駒の地を短く変えて返す。読み上げでは指せなかったことだけを伝え、理由は言わない。指せない手の種類は遊び方で説明する。
- 選んだ駒の行き先と、王手になる手は示さない。
- 補助は提供しない。

## 操作

- 成と不成のどちらでも王手になる移動では、成るか成らないかを選ばせる。片方だけが王手になる移動では、選ばせずにその手を指す。
- 成・不成の選択肢は、移動先の升から決まる位置に出し、周りの駒は避けない。位置が場面で変わらないことを優先するため。

## チュートリアル

- ルールを1つずつ使って詰将棋を1問解くチュートリアルを持つ。操作と王手を伝え、詰まない王手と待ったで逃げ道を伝えてから、詰ませる手を自分で指させる。
- 逃げ道を伝える詰まない王手は、詰ませる手と同じ升への王手にする。同じ升への詰ませる手と見比べられるようにするため。
- 玉方の応手と反証、この手数では詰まないという知らせ、待ったの戻り方は本番と同じにする。詰ませる手を自分で指させる間は、着手させなかった手への反応も本番と同じにする。
- 着手させなかった手と、玉方に逃げられた王手のわけを一言で伝えるのは、チュートリアルの中だけにする。本番では理由を文で示さない（「状態の知らせ」）。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。誤王手の筋にいるときの待ったは、最初の誤王手を指す前の判断地点まで一度に戻る。

## 難易度

- 基準とするプレイは、駒の動き・成り・持駒・毎手王手・最長抵抗を理解し、誤王手を指す前に読んで正解を選ぶプレイとする。ルールを覚える負担、駒の見分けや升の押しにくさ、玉方の応手を待つ時間、手数そのもの、盤上と持駒の駒の数、詰みを探す探索の量は難易度に含めない。
- 挑戦は、王手の候補を挙げ、それぞれへの玉方の最善の応手を読み、正しそうに見える誤王手を反証して、正しい王手の手順を最後まで保つこととする。王手の候補が多いほど、効いていそうに見える誤王手があるほど、詰まないことが数手先まで見えない誤王手が多いほど、挑戦は強くなる。正しい手順の側で手筋を組み合わせることや、玉方の応手ごとに詰むことを確かめることも挑戦に加える。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 王手の候補は少なく、正解以外の王手はどれもその局面で崩れると分かる |
| 2 | 効いていそうな誤王手があるが、次の一手で詰まないと分かる |
| 3 | 数手先まで続く紛れが少しあり、候補を読み比べる |
| 4 | 数手先まで続く紛れが複数あり、正しい手順も手筋か玉方の応手を比べて確かめる |
| 5 | 数手先まで続く紛れが多く、遠い利きや複数の手筋を含めて比べる |

- 難易度は、初手の王手の数・効いていそうな誤王手の数・数手先まで続く紛れの数・変化の幅・作意の手筋の種類の組で決め、数手先まで続く紛れの数を主軸にする。上の難易度は下の難易度の挑戦を含む。
- 脅しがあるかと変化の幅は、玉方の応手のうち玉が逃げる手と王手した駒を取る手（自然な応手）だけを見て、合駒は読みの候補に数えない。出す問題は、合駒の数え方で答えが変わらないため（「ルールと問題」）。
- 自然な応手の少なくとも1つが残りの手数のうちに詰む王手を、脅しのある王手とする。
- 誤王手の後、玉方の反証（合駒を含む）のうち最も早く崩れを見せるものを選び、攻方が脅しのある王手で最も長く続けたときに、脅しのある王手が尽きるまでの手数（誤王手と玉方の手を含む）を紛れの長さとする。紛れの長さが4以上の誤王手を、数手先まで続く紛れとする。玉方がどう反証しても次に脅しのある王手が続き、詰まないことが4手目以降まで見えない誤王手である。
- 効いていそうな誤王手は、脅しのある誤王手と、数手先まで続く紛れとする。
  - 脅しが無く、数手先まで続く紛れでもない誤王手は、その局面を見ただけで崩れると分かるため数えない。
- 効いていそうな誤王手と数手先まで続く紛れは、作意のすべての判断地点で数えた数の和とする。初手の王手の数は、初手の合法な王手の数とする。
- 変化の幅は、作意の玉方の手番ごとの、作意以外の自然な応手の数の和とする。正解の後に、玉方がどう応じても詰むことを確かめる幅である。
- 作意の手筋は、作意の攻方の手に現れる、成る、成れるのに成らない、駒を取る、捨駒（次の玉方の手で取られる）、開き王手（動かした駒以外の駒の利きで王手になる。両王手を含む）、遠い利きの王手（2升以上離れた位置から、飛・角・香・龍・馬の利きで王手する）とし、作意の手筋の種類は、そのうち作意に1回以上現れた種類の数とする。駒打ちは詰将棋の基本の手なので、手筋に数えない。
- どの難易度の組にも当たらない問題は、近い難易度へ寄せず提供しない。手数を難易度の条件にしない。数手先まで続く紛れは残りの手数が5以上の判断地点でだけ起きるので、難易度 3 以上の問題は結果として5手詰になる。
- 左右反転を含めて、同じ局面の問題と、作意の各手の駒と初期局面の玉から見た位置が同じ問題（平行移動しただけの同じ詰み筋）は、問題集に重ねて出さない。1つの難易度の中では、攻方の各手の駒と、その手の直前の玉から見た行き先が左右反転を含めて同じ問題（遊ぶ人から見て、玉にどう迫って詰めるかが同じ問題）を出さない。
- 1つの難易度の中で、作意の各手の形（打つ・成る・取る・捨駒・玉方が玉で応じるか駒で応じるか）の並びが同じ問題、初手の捨駒を玉で取らせる問題、最終手が駒打ちの問題の割合に上限を置く。上限を置かないと、問題集がこれらの筋に偏るため。

## 評価

王手の候補を読み比べ、誤王手を指さずに正しい王手の手順を速く指し切ることを称える。反証を見ることと、待った・盤面を戻すで考え直すことは罰しない。

- 正確さ 20点: 誤王手で減点し、何回指しても減点は正確さの20点までにとどめる。誤王手は、玉方の反証を盤面で見て考え直す体験でもあるため。誤王手を1回でも指すと `perfect` には届かないが、速ければ `great` に残る。
- 速さ 80点: 経過時間を、手数・初手の王手の数・効いていそうな誤王手と数手先まで続く紛れの数から決める基準時間と比べる。難易度そのものを基準時間の理由にしない。
  - 基準時間に数える効いていそうな誤王手と数手先まで続く紛れの数には、上限を設ける。人間は正解を見つけた時点で残りの候補を読まないため。
- 反証を見た回数と、待った・盤面を戻すの回数は評価に使わない。どれも誤王手の後の考え直しか正しい筋の確かめ直しで、かかった時間は速さに表れるため。指せない手を押した回数も評価に使わない。
- 問題集から引けなくなった記録も、記録した問題の作業量から評価し、自己ベストの比較に使う。

自己ベストでは、評価点は高いほど、基準時間との差と誤王手の回数は少ないほど良い値として比べる。
