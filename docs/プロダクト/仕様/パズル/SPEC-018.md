# SPEC-018 パーキングジャム

駐車場に停まった車を1台ずつ道路へ出し、すべての車を駐車場から出すパズル。

## ルールと問題

- 駐車場は格子とし、2マスまたは3マスの長さで縦向きか横向きに停まる車と、車が通れない植え込みを置く。外周には道路へつながる開口がある。
- 利用者は、車とその向きに沿う前後どちらかの方向を選んで出庫を試みる。
- 進む先に車も植え込みもなく、進んだ先の外周がその車線で道路につながっていれば出庫は成立し、車は一度で盤面から消える。途中で止まる動きはない。
- 出庫が成立しなかったときは盤面を変えず、ミスとして数える。
- 成立した出庫で他の車が出にくくなることはなく、どの順で出庫を続けても行き詰まらない。問題は、すべての車を出せるものに限る。
- すべての車を出した時点でクリアとする。

## チュートリアル

- 手順の最後に、ほかの車を塞いでいる車を先に出させ、塞がれていた車は手順を終えてからプレイヤーが自分で出す。手順を終えた駐車場には、ほかの車に塞がれた車も残し、どれを先に出すかを読ませる。
- 出られない手への一言は、手順の一言がルールを言うのに対し、その手に当てはめて、動かした向きと当たったものを言う。
  - 動きを減らす設定で当たって揺れる動きが見えなくても、一言が替わることで操作が届いたことが分かるため。
  - 道路がないために出られないときは、その車の進む先の車線に道路がないと言う。同じ側でも、ほかの車線には道路があることがあるため。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。

## 難易度

- 基準とするプレイは、出庫を試さずに盤面を読んで出せる車と方向を選び、待ったと盤面を戻すを使わないプレイとする。手数は難易度に含めない。
- 挑戦は、塞がれた車の進路をたどってどの車を先に出せば道が開くかを読み、今出せる車とその方向を試さずに見つけ続けることとする。
- 難易度は、次の3つの観点の強さの組で決める。
  - 依存の深さ・広さ: 塞いでいる車をさかのぼって読む段数と、先に出す必要がある台数。先に出す台数は、車ごとに、その車を出せるようになるまでに最少で先に出す車の台数とし、全車の最大で見る。枝分かれは、その台数がさかのぼる段数を超える分とし、塞いでいる車が1本の連鎖でつながるだけなら無い。
  - 読み違いの誘いやすさ: 出られそうに見えて出られない操作を誘う車の割合。始めの盤面で、植え込みに塞がれた側を除いて見たときに、次のどれかに当たる車を数える。
    - 開口の無い側が、同じ辺の隣の車線の開口に接している。
    - 両側に開口があり、片側だけがほかの車に塞がれている。
    - 塞がれていて、最も塞がれ方の少ない進路で、最初に当たる車が離れている。
  - 規模: 盤面の広さと、車と植え込みの数の弱い方。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 何台かが1台に塞がれているが、塞いでいる車はすぐ出せる。開口と車線ははっきり合っていて、見たとおりに出せる |
| 2 | 塞がれ方は1と同じく浅いが、隣の車線に開口がある車や、両側に開口があって片側だけ塞がれた車が混ざる |
| 3 | 2台に塞がれた車や、塞いでいる車がさらに塞がれている車が現れ、何を先に出すかを2段さかのぼって読む |
| 4 | 塞がれ方は3と同じくらいだが、出られそうに見えて出られない車が半分以上になり、盤面も中程度以上に広がる |
| 5 | 3段以上さかのぼる待ちや、2段の待ちの枝分かれに、半分以上の車の読み違いやすさと広い盤面が重なる |

- 難易度を1つ上げるごとに、読み違い、依存の順に交互に、観点の強さを1つずつ強める。上の難易度は、どの観点でも下の難易度より弱くならず、下の難易度の挑戦を含む。
- 規模は各難易度で許す範囲として組み合わせ、その範囲を隣の難易度と重ねる。規模だけで難易度は決めない。
- 次の問題は出さない。
  - 観点の強さの組が、どの難易度にも当たらない問題。
  - すべての車がすぐ出せる問題と、塞がれた車が1台だけの問題。出す順序を読む挑戦がほとんど無いため。
  - 6段以上さかのぼる待ちがある問題。作れる問題の中にほとんど現れず、遊んで確かめていないため。

## 評価

盤面を読み、出せない方向を選ばずに判断し続けることを最も称え、その上で速さを称える。手数は評価に使わない。待ったと盤面を戻すは、すでに成立した判断を戻した事実として軽く扱う。

- 正確さ 40点: ミスで減点する。
- 速さ 40点: 経過時間を、車の台数と塞がれ方から決める基準時間と比べる。難易度そのものを基準時間の理由にしない。
- 安定性 20点: 待ったと盤面を戻すで減点する。

自己ベストでは、評価点は高いほど、経過時間とミス数は少ないほど良い値として比べる。
