# SPEC-018 パーキングジャム

パーキングジャムは、駐車場に停まった車を1台ずつ道路へ出し、すべての車を駐車場から出すゲームとして提供する。

駐車場は縦横の格子の盤面とし、最大 8×8 とする。車は2マスまたは3マスの長さで、縦向きか横向きに停まる。盤面には車のほかに、車が通れない植え込み（固定物）がある。駐車場の外周には、道路へつながる開口がある。

## 問題

問題は、合法な出庫だけですべての車を出せるものに限る。合法な出庫で車が盤面から消えても、他の車が出にくくなることはないため、どの順で合法な出庫を続けても行き詰まらない。問題の成立性の確認と、利用者向け難易度の判定は別の責務として扱う。

## プレイ

利用者は、車と、その車の向きに沿う前後どちらかの方向を選んで出庫を試みる。車の向きと直交する方向へは動かせない。

- 車の進む先に他の車も植え込みもなく、進んだ先の外周がその車線で道路につながっていれば、出庫は成立する。車は一度で盤面の外へ出て、盤面から消える。途中で止まる動きはない。
- 進む先に車か植え込みがあるとき、または進んだ先の外周に道路への開口がないときは、出庫は成立しない。盤面は変わらず、成立しなかった出庫をミスとして記録する。車がその方向へ短く動いて戻ることで、出られなかったことを返す。

操作は、車を出したい方向へのスワイプとする。車を押して選ぶと車の両端に方向の印が出て、印を押しても出せる。PC ではキーボードで車へ移動し、車の向きに沿う矢印キーで出せる。

出せる車や成立する方向を、操作の前に示したり、成立しない方向を押せなくしたりしない。どの車を先に出せば道が開くかを盤面から読むことをゲーム性として残す。出庫が成立しなかったことを操作の後に返すのは、今の盤面で進めないことを伝える状態の知らせ（SPEC-017）であり、補助ではない。

すべての車を出した時点でクリアとする。最後の車が盤面の外へ出ていく動きを見せてから結果へ進む。失敗して終わる条件は無い。

プレイ中は、ミス数、経過時間、待った回数を示す。

プレイ中は、待った、盤面を戻す、リセット、別の問題を提供する。

- 待った: 直前に出した車を1台ずつ盤面へ戻す。成立しなかった出庫は盤面を変えないため、待ったの対象にならない。待った回数を記録する。盤面を戻した後は、盤面を戻す前に出した車を待ったで戻せない。クリア後は戻せない。
- 盤面を戻す: 出したすべての車を初期配置へ戻す。経過時間とそれまでのミス数・待った回数を引き継ぎ、戻した回数を数える。車を1台も出していないときは押せない。

## 難易度

難易度は `レベル 1`〜`レベル 5` の5段階とする。問題難易度は、ルールと操作を理解し、出庫を試さずに盤面を読んで出せる車と方向を選び、待ったと盤面を戻すを使わないプレイを基準にする。クリアまでに出庫が成立する回数は車の台数で決まるため、手数や最短手数は難易度に含めない。

パーキングジャムの挑戦は、塞がれた車の進路をたどって、どの車を先に出せば道が開くかを読み、今出せる車とその方向を試さずに見つけ続けることとする。合法な出庫で後から行き詰まることはないため、挑戦は数手先の配置を作る計画ではなく、車同士・植え込みが進路を塞ぐ関係の読み取りにある。

難易度は、次の3つの観点で問題の挑戦を表し、その組で分類する。

- 依存の深さ・広さ: 塞いでいる車がさらに塞がれているときに、何段さかのぼって読むか、何台を先に出す必要がある車があるか。
- 読み違いの誘いやすさ: 隣の車線に開口がある、両側に開口があって片側だけ塞がれている、塞いでいる車が離れているなど、出られそうに見えて出られない車が、車全体のどれだけを占めるか。
- 規模: 盤面の広さと、読む対象（車と植え込み）の数。

各難易度で利用者が出会う挑戦は次のとおりとする。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 何台かが1台に塞がれているが、塞いでいる車はすぐ出せる。開口と車線ははっきり合っていて、見たとおりに出せる |
| 2 | 塞がれ方は1と同じく浅いが、隣の車線に開口がある車や、両側に開口があって片側だけ塞がれた車が混ざる |
| 3 | 2台に塞がれた車や、塞いでいる車がさらに塞がれている車が現れ、何を先に出すかを2段さかのぼって読む |
| 4 | 塞がれ方は3と同じくらいだが、出られそうに見えて出られない車が半分以上になり、盤面も中程度以上に広がる |
| 5 | 3段以上さかのぼる待ちや、2段の待ちの枝分かれに、半分以上の車の読み違いやすさと広い盤面が重なる |

依存の深さ・広さと読み違いの誘いやすさを1段ずつ交互に上げ、上の難易度はどの観点でも下の難易度より弱くならず、下の難易度の挑戦をすべて含む。

規模は、広さと読む対象の数の弱い方で表し、各難易度で許す範囲として組み合わせる。規模だけで難易度は決まらず、同じ規模の問題は依存と読み違いで難易度が分かれる。見渡して読む車と進路が増えることは考えどころを増やすため、難易度4・5 では最も小さい規模の問題を提供しない。上の難易度ほど許す規模の範囲を下げない。

難易度の選択肢には、実際の問題の縮小ではなく、本番の盤面と同じ駐車場・車・縁石・開口の見た目で描いた簡略図を添え、依存と読み違いの差だけを示す。全難易度で同じ大きさの駐車場を使い、上の難易度の図は下の難易度の図の車と開口をすべて同じ位置に残し、塞ぐ車か、どの車も使わない開口を足す。広いほど難しいという印象を与えないよう、規模の差は図で示さない。

### 判定

難易度は、問題の車同士・植え込みが進路を塞ぐ関係と、出庫を続けて到達するすべての状態を分析して判定する。その時点で出せる車を全部出すことを繰り返した段数、各車が出せるようになるまでに先に出す必要がある車の最少台数、読み違いを誘う車の数、初期盤面で出せない車の数、盤面の広さと車・植え込みの数を観測する。

分析結果は、次の状態を区別して扱う。

- 成立しない: すべての車を出せない。提供しない。
- 評価不能: 車が多すぎて分析で扱える範囲を超える。高難易度と推定せず、提供しない。
- 提供範囲外: 分析できるが、すべての車がすぐ出せる、または初期盤面で塞がれた車が1台以下で出す順序を読む挑戦がほとんどない、さかのぼる段数が多すぎる、または観点の組がどの難易度の組にも当たらない。近い難易度へ寄せず、提供しない。
- 難易度1〜5: 分析でき、観点の組がその難易度の組に当たる。

正確な特徴、観点の境界、難易度ごとの組と規模の範囲はコードを正とし、その根拠と検証は [パーキングジャム難易度](../../../パズル/パーキングジャム難易度.md) に置く。

### 供給

各難易度の問題は、判定済みの問題を事前に生成した問題集から供給する。問題は難易度によらない共通の生成条件の範囲から作って判定で分類し、難易度ごとに生成条件を絞らない。回転・反転で一致する問題は同じ問題として扱い、問題集に重複させない。プレイ時には問題の生成と難易度の分析を行わない。

## 成績評価

クリアしたプレイだけを評価し、1プレイを100点満点で評価する。クリアに必要な出庫の回数は車の台数で決まるため、手数は評価に使わない。盤面を読み、出せない方向を選ばずに判断し続けることを最も称え、その上で速さを称える。待ったと盤面を戻すは、すでに成立した判断を戻した事実として軽く扱う。

- 正確さ 40点: ミス1回につき5点を減点する。
- 速さ 40点: 盤面把握5秒、車1台あたり3秒、初期盤面で出せない車1台あたり3秒を合計した基準時間を満点基準とし、超過に応じて線形に減点する。基準時間の2倍で0点とする。
- 安定性 20点: 待った1回につき2点、盤面を戻す1回につき5点を減点する。

各項目は0点から満点の範囲とする。基準時間は問題の車の台数と塞がれ方だけから決め、難易度そのものを加点や基準時間の理由にしない。

記録するプレイ事実は、難易度、問題を再現するための情報（車の台数を含む）、初期盤面で出せない車の数、経過時間、出庫を試みた回数、成立した出庫の回数、ミス数、待った回数、盤面を戻した回数とする。成立した出庫の回数は、待ったと盤面を戻すで戻した車の出し直しを含む。

初期盤面で出せない車の数を持たない記録は、今の評価規則で評価できないため、今の規則で扱えない記録（SPEC-001）とする。

3段階（`かんたん / ふつう / むずかしい`）の難易度で記録したプレイは、廃止した難易度区分の記録として、`レベル 1`〜`レベル 5` へ読み替えず、レベルとは別の比較単位とする（SPEC-001）。

自己ベストとして、評価点は高いほど、経過時間とミス数は少ないほど良い値として比較する。

結果では、評価点と評価段階に続けて、経過時間、ミス数、待った回数をパーキングジャムの主要成績として扱う。評価の内訳、盤面を戻した回数、基準時間と減点の根拠は主結果と分けて確認できるようにする。履歴では、評価点、経過時間、ミス数を難易度ごとに比較する主要指標として扱う。
