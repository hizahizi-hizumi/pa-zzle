# SPEC-011 スライドパズル

正方形の盤面に並んだ番号付きのタイルを空白へ滑らせ、左上から順に 1 から番号が並び、右下が空白になる配置へ揃えるパズル。

## ルールと問題

- 問題は、完成配置から合法な手だけをたどって作った、必ず解ける初期配置とし、完成までの最短手数を事前に求めて持つ。
- 空白と同じ行または列にあるタイルを選ぶと、そのタイルから空白までのタイルがまとめて1マスずつ滑る。空白と同じ行・列にないタイルを選んだ操作は成立せず、ミスにもしない。
- 手数は動いたタイルの枚数で数える。最短手数も同じ単位で扱う。
- 盤面が完成配置と一致した時点でクリアとする。

## やり直し

盤面を戻す、リセット、別の問題を提供する。待ったは提供しない。

## 難易度

- 難易度は、盤面の大きさと、最短で解くためにタイルを一時的に完成位置から遠ざける手（遠回り手数）の多さの組で決める。最短手数そのものを難易度とはみなさない。

| レベル | 盤面 | 遠回り手数 |
| --- | --- | --- |
| 1 | 3×3 | 0〜3 |
| 2 | 4×4 | 2〜3 |
| 3 | 4×4 | 4 以上 |
| 4 | 5×5 | 5〜7 |
| 5 | 5×5 | 8 以上 |

- 盤面の大きさは、見渡して退避先を探すタイルと、揃えた部分を崩さずに読む手順を増やすため、難易度の要因とする。盤面が大きくなる境目では遠回り手数の帯を下げない。
- 同じ盤面の中では、レベルが上がるほどタイル同士が道をふさぎ合い、退避と送り込みの順序を先読みする負荷が強くなる。

## 評価

- 効率 60点: 盤面を戻す前も含めて動いたタイルの総手数を、最短手数と比べる。
- 速さ 40点: 経過時間を、盤面の大きさと最短手数から決める基準時間と比べる。

盤面を戻すことは別に減点しない。

自己ベストでは、評価点は高いほど、基準時間との差と最短手数との差は少ないほど良い値として比べる。
