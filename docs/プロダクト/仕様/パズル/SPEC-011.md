# SPEC-011 バイナリパズル

バイナリパズルは、8×8 の盤面の空きマスに2種類のタイルを置き、各行・各列で2種類を同数にし、同じタイルを縦・横に3つ以上続けず、同じ並びの行どうし・列どうしを作らない配置へ完成させるゲームとして提供する。盤面の大きさは 8×8 に固定し、難易度や開始条件として変えない。

画面に表示する名称は「バイナリパズル」とする。同じパズルの通称である「タクズ」（Takuzu）や Binairo は、画面に表示する名称に使わない。

## 問題と操作

問題は固定の初期配置と一意な完成解を持ち、推測（仮置きと後戻り）なしに、1本の行・列を読む推論だけで最後まで解けるものに限る。初期配置のタイルは利用者が変更する対象ではない。問題の成立性の確認と、利用者向け難易度の判定は別の責務として扱う。

2種類のタイルは数字ではなく、形・明度・色相がそれぞれ異なるタイルとして表し、色だけに頼らずに区別できるようにする。初期配置のタイルと利用者が置いたタイルは見分けられるようにする。

固定マス以外のマスを押すたびに、空き → 一方のタイル → もう一方のタイル → 空き の順に巡回する。入力モードの切り替えは持たない。PC では右クリックで逆順に巡回し、キーボードではマスを移動して各タイルと空きを直接置ける。固定マスを押しても盤面は変わらない。

盤面だけから分かるルール違反は、その場で関係するマスに示す。ルール違反は、同じタイルの3つ以上の連続、行・列で片方のタイルが半数を超えること、全マスが埋まった行どうし・列どうしの並びの一致とする。完成解との照合結果は表示も計数もしない。2値のパズルでは、照合結果を示すことが答えを示すことになるためである。

全マスが埋まり、ルール違反が無い時点でクリアとする。問題は一意解を持つため、これは完成解との一致と同じ意味になる。失敗して終わる条件は無い。

元に戻す、ヒント、確定できるマスの提示・自動入力、行・列ごとのタイル数の表示は通常UIで提供しない。プレイ中は、同じプレイを続けたまま盤面を初期配置へ戻す操作（盤面を戻す）、同じ問題のやり直し、新しい問題の開始を提供する。盤面を戻しても、経過時間とそれまでの置き直しは引き継ぐ。

## 難易度

難易度は `難易度 1`〜`難易度 5` の5段階とする。問題難易度は、ルールと巡回の操作を理解し、ヒントや個数表示を使わず、ルール違反の表示に頼らずに盤面を読んで確定したマスだけを置き、仮置きと後戻りをしないプレイを基準にする。空きマスの数、解くまでの入力回数や時間そのものは問題難易度に含めない。

バイナリパズルの挑戦は、盤面から次に確定できるマスを見つけ、局所の形で決まらないときは行・列全体を読んで確定させることとする。各難易度で利用者が出会う挑戦は次のとおりとし、上の難易度ほど必要な読みの種類が深くなる。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 並んだ2つの両隣・挟まれた1つを埋める形を見つければ、次々に決まっていく |
| 2 | 行・列のタイルを数え、半数そろった方の反対で残りを埋める場面がある |
| 3 | 行・列に残り1個のタイルを、どこに置けるか読む場面がある |
| 4 | 完成した行・列と同じ並びにならないよう読む場面が1度ある |
| 5 | 完成した行・列との見比べが何度も要る、または残りの多い行・列で並びを読み比べる場面がある |

### 判定

難易度は、問題を人間向けの推論で解き進める過程を分析して判定する。各局面で最も浅い推論から順に確定できるマスを探し、解き切るまでに使わざるを得なかった推論の段階と、その推論が要った局面の数を観測する。推論の段階は、隣接・挟みの形、行・列の個数の完成、残り1個の置き場所、完成済みの行・列との重複の回避、残りの多い行・列の並びの比較を区別する。どの推論も1本の行・列の中で読むもので、2本以上の行・列を組み合わせる推論は扱わない。

分析結果は、次の状態を区別して扱う。

- 成立しない: 解が無い、または2つ以上ある。提供しない。
- 評価不能: 一意解だが、1本の行・列を読む推論では解き切れない。高難易度と推定せず、提供しない。
- 提供範囲外: 分析できるが、局所の形を数巡埋めるだけで解き終わり、挑戦が軽すぎる。提供しない。
- 難易度1〜5: 分析でき、提供範囲に入る。

空きマスの数は難易度の根拠にしない。空きマスの多さで難易度を見分けられないよう、全難易度で同じ空きマスの範囲に入る問題だけを供給する。

正確な特徴量、閾値、空きマスの範囲はコードを正とする。

### 供給

各難易度の問題は、判定済みの問題を事前に生成した問題集から供給する。回転・反転と2種類のタイルの入れ替えで一致する問題は同じ問題として扱い、問題集に重複させない。プレイ開始時に seed を定め、その seed で選んだ難易度の問題集から1問を選ぶ。同じ seed と同じ問題集からは同じ問題を選ぶ。

選んだ問題は、問題を再現するための情報とともに扱い、同じ問題のやり直しでは同じ問題を初期配置から新しいプレイとして始める。新しい問題の開始と難易度の選び直しでは、新しい seed で問題を選ぶ。

## 成績評価

クリアしたプレイだけを評価し、1プレイを100点満点で評価する。推測なしで解ける問題だけを提供するため、盤面を読んで確定したマスだけを置き、置き直しをせずに解き切ることを最も称え、その上で速さを称える。

- 正確さ 60点: 置き直し1回につき5点、盤面を戻す1回につき15点を減点する。
- 速さ 40点: 盤面把握10秒、空きマス1つあたり2秒、局面1つあたり3秒、行・列全体を読む局面1つあたり10秒を合計した基準時間を満点基準とし、超過に応じて線形に減点する。基準時間の2倍で0点とする。

各項目は0点から満点の範囲とする。合計100点を `perfect`、90点以上を `great`、80点以上を `good`、それ未満のクリアを `clear` とする。

置き直しは、一度置いたタイルを後から別のタイルや空きへ変えた回数とする。同じマスを続けて押している間は1回の入力として扱い、別のマスを押した時点で、そのマスを押し始める前の中身と比べて置き直しかどうかを決める。空きマスを続けて押してタイルを選ぶ間と、盤面を戻して消えたマスは置き直しに数えない。入力回数とルール違反の発生は評価に使わない。

局面の数は、判定と同じ人間向けの推論でその問題を解き切るまでに、次に確定できるマスを探し直す回数とする。行・列全体を読む局面の数は、そのうち残り1個の置き場所、重複の回避、並びの比較のいずれかが要った局面の数とする。どちらも問題の性質として問題ごとに定まる。基準時間は問題の作業量だけから決め、難易度そのものを加点や基準時間の理由にしない。

置き直しも盤面を戻すこともなく基準時間内に解いたプレイだけが `perfect` に届く。押し間違いを直した程度の置き直しでは評価段階を大きく落とさない。盤面を戻して消えたマスは置き直しに数えないため、盤面を戻したプレイは速さによらず最高で `good` とする。

記録するプレイ事実は、難易度、問題を再現するための情報、問題の作業量（空きマスの数、局面の数、行・列全体を読む局面の数）、経過時間、置き直し回数、盤面を戻した回数、入力回数とする。評価点、評価段階、基準時間、基準時間との差は保存した事実から現在の評価規則で導出する。

履歴と自己ベストの比較単位は難易度とする。自己ベストとして、評価点は高いほど、問題ごとの速さ満点基準時間に対するクリア時間の差と置き直し回数は少ないほど良い値として比較する。

結果では、評価点と評価段階に続けて、経過時間と基準時間との差、置き直し回数、盤面を戻した回数をバイナリパズルの主要成績として扱う。評価の内訳と基準時間の根拠は主結果と分けて確認できるようにする。履歴では、評価点、基準時間との差、置き直し回数を難易度ごとに比較する主要指標として扱う。
