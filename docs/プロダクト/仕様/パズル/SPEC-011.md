# SPEC-011 スライドパズル

正方形の盤面に並んだ番号付きのタイルを空白にスライドさせ、左上から順に 1 から番号が並び、右下が空白になる配置へ揃えるパズル。

## ルールと問題

- 問題は、完成配置から合法な手だけをたどって作った、必ず解ける初期配置とし、完成までの最短手数を事前に求めて持つ。
- 空白と同じ行または列にあるタイルを選ぶと、そのタイルから空白までのタイルがまとめて1マスずつスライドする。空白と同じ行・列にないタイルを選んだ操作は成立せず、ミスにもしない。
- 手数は動いたタイルの枚数で数える。最短手数も同じ単位で扱う。
- 盤面が完成配置と一致した時点でクリアとする。

## 操作

- 矢印キーを押すと、押した方向へ、空白の隣のタイルを1枚スライドさせる。

## チュートリアル

- 3×3 の盤面を1枚解くチュートリアル（SPEC-029）を持つ。空白の隣のタイルをスライドさせる操作を教えた後、「空白と同じ行・列のタイルは、間のタイルとまとめて空白側へスライドする」と、「行や列の最後の2枚は、片方を奥の場所へずらし、もう片方をその隣に並べて組にしてから、空白を回して続けて入れる」を伝える。
  - 後者は、1枚ずつ入れると、揃えた所を崩さずには最後の1枚が入らないため。
- 盤面は、上の行の最後の2枚を組にして入れるところまで手を引き、上の行が揃って手を離した後に、左の列に同じ形が残るものにする。上の行を崩さずに完成させる最短の道は、左の列の2枚を組にして入れる1通りだけにする。
  - 手を離した後も、教えた読みを自分で当てはめて解かせるため。
- 同じ行・列のルールを伝える手順では、始めに空白と同じ行・列にないタイルに、指を添えずに印を付け、押して揺れたことから空白を先に動かさせる。
- 組にする読みは、印を付けずに自分で探させる。道から外れた手を押したときと、手が止まったとき（SPEC-029）に、次に押すタイルに印を付ける。探す間は、決め手のタイルに加えて、いまスライドできるタイルも覆いから抜き、押せないように見せない。
- 手を引く道の次の何手かを1回のタップでまとめて進められるときは、いちばん遠いタイルに印を付け、離れたタイルが間のタイルとまとめてスライドすることを体験させる。
- 空白と同じ行・列にないタイルを選んだ手は、同じ行・列のタイルがまとめてスライドするルールを示すまでは、ルールに合わない手としては返さず、印を濃くし直す。示した後は、印のタイルへ導いている手順の間も、本番と同じくルールに合わない手として返す。
- タイルが自分の場所に収まった合図は本番に無いので、手を引いている間の手にだけ返す。
- 手を離した後の手がかりは、揃えた上の行（と左の列）を崩さない最短の道から選ぶ。
- 進み具合は、手を引く手順を1つ終えるたびと完成したときに進め、手を離した後に途中の段を置かない。

## やり直し

盤面を戻す、リセット、別の問題を提供する。待ったは提供しない。

## 難易度

- 難易度は、盤面の大きさと、最短で解くためにタイルを一時的に完成位置から遠ざける手（遠回り手数）の多さの組で決める。最短手数そのものを難易度とはみなさない。
- 最短手数が盤面の大きさごとの下限に満たない問題は、どのレベルにも出さない。完成位置へ近づける手を無作為に選び続けるだけでも完成しやすい問題を外すため。

| レベル | 盤面 | 遠回り手数 |
| --- | --- | --- |
| 1 | 3×3 | 0〜3 |
| 2 | 4×4 | 2〜3 |
| 3 | 4×4 | 4 以上 |
| 4 | 5×5 | 5〜7 |
| 5 | 5×5 | 8 以上 |

- どのレベルの境目でも、盤面の大きさと遠回り手数の下限を下げない。
- 盤面の大きさは、見渡して退避先を探すタイルと、揃えた部分を崩さずに読む手順を増やし、大きい盤面を小さい盤面へ落とし込む過程の負荷も強めるため、難易度の要因とする。
- 同じ盤面の中では、レベルが上がるほど遠回り手数を上げる。タイル同士が道をふさぎ合い、退避と送り込みの順序を先読みする負荷が強くなるため。

## 評価

- 効率 60点: 盤面を戻す前も含めて動いたタイルの総手数を、最短手数との比で評価する。
  - 人の手数は最短の数倍になりやすく、最短手数を超えた分で線形に減らすと、最短の数倍で解く人どうしの上達差が0点に潰れるため。
- 速さ 40点: 経過時間を、盤面の大きさと最短手数から決める基準時間と比べる。

盤面を戻すことは別に減点しない。

自己ベストでは、評価点は高いほど、基準時間との差と最短手数との差は少ないほど良い値として比べる。
