# SPEC-024 ブリッジパズル

数字の付いた島の間に縦か横にまっすぐ橋を架け、どの島からも数字と同じ本数の橋が出て、全部の島が1つにつながるようにするパズル。

## ルールと問題

- 橋は、間に島の無い縦か横の2島だけをつなぎ、同じ2島の間は2本まで架けられる。橋どうしは交わらない。
- どの島も数字と同じ本数の橋が出ていて、全部の島が1つにつながった時点でクリアとする。失敗して終わる条件も、ミスとして数える操作も無い。

問題は次を満たすものに限る。

- 盤面は 10×10 までの正方形とする。
- 答えはただ1つとする。
- 推理だけで解ける。推理は次の読みとし、それより先まで試さないと決まらない問題は出さない。
  - 数字の読み: 島の数字と行き先の数から、ちょうど・少なくとも・多くとも何本かを決める。
  - つながりの読み: 架けると2島や3島以上の組が閉じて孤立しないか、この行き先が無いと全部の島がつながらない唯一の通り道か、1手だけ仮に決めて、その両端の島から本数が破れる・組が閉じる・孤立するのが見えて退ける読み（1手の先読み）。
  - 閉じる組は、つながりの読みでも1手の先読みの中でも、7島までの組か、組の外に残る島が5島までの所に限る。
  - 1手の先読みで進めるのは、仮に決めた手の両端の島が埋まる所（足りた島の他の行き先は0本、上限の合計が数字と同じなら全部上限）だけとする。孤立は、4島までのまとまりが架けられる橋だけでは残りとつながらなくなる所に限る。
  - 当てずっぽうではなく推理で解けるパズルにするため。1手の先読みは盤面の一部を見て矛盾が分かる読みで、矛盾を探して深く追う試し置きとは手応えが違う。1手の先読みも推理から外すと、つながりを何度も読む最上位の問題が減り、歯ごたえを残しにくい。
  - つながりの読みと1手の先読みを「盤面の一部を見て矛盾が分かる」読みに保つため。閉じる組は、組の島が全部足りたと島ごとの知らせで見えても、それが全島ではないと確かめるには組の島か外に残る島を数え切る。数え切れるのは、組か外のどちらかが数島の所で、組も外も広い所は盤面全体をたどる探索になる。孤立は知らせに出ないので、大きなまとまりが残りとつながらないことを確かめるのは、盤面全体をたどる探索になる。
- 島は上下左右に隣り合わない。
  - スマホで 10×10 の盤面を遊ぶと、隣り合う2島の間に見える線は指で押し分けられない幅になるため。
- 盤面の上下の端の行と左右の端の列のどれにも島がある。
  - 端に島の無い行・列があると、盤面の広さが見かけだけになるため。

## 状態の知らせ

- 島ごとに、出ている橋の本数が数字に足りない・ちょうど・多すぎのどれかを状態の知らせ（SPEC-017）として示す。
- 交わる橋に阻まれた操作には、阻んだ橋を縁取って短く揺らし、押した所に架かるはずだった橋の影を一瞬見せて返す。理由は文で示さない。
- 全部の島がつながったかは知らせない。
- 補助は提供しない。

## 操作

- 島の間を押すたびに、その間の橋を 1本 → 2本 → なし と回す。島を押して選んでから行き先の島を押す操作と、島から行き先の向きへなぞって離す操作も、同じ回し方をする。なぞりは縦横から 25° の内へ動いた向きの最初の島への辺に決め、指が行き先の島に届いてから離したとき（通り過ぎたときも含む）に、その辺の橋を回す。斜めのなぞりと、行き先の島に届く前の海の上で離したなぞりでは回さない。
  - 斜めのなぞりや途中で止めたなぞりで橋が架かると、狙っていない橋が増え、何も起きないより直しにくいため。届いたかどうかは、なぞっている間に架かる予定の橋の姿で先に見せる。
- 島の間の線とその近くを押したときだけ、その辺の橋を回す。線から離れた海を押しても橋を回さず、島を選んでいればその選びを解く。海から始めたなぞりでも橋を回さない。
  - 離れた海の押しで近くの橋が回ると、狙っていない橋が増え、何も起きないより直しにくいため。
- 交わる2本の線の近くを押しても、どちらか1つの辺として受ける。架かっている橋の板の上を押したら、その橋を回す。どちらにも橋の無い所では、押した位置が縦と横のどちらの線に近いかで決め、見分けにくい交点のそばでは、ほかの橋に阻まれずに架けられる方、2島の間の真ん中に近い方、直前に触った島から伸びる方の順で決める。
  - 見えている橋を押したのに、交わる別の組が対象になって阻まれると、押した橋を増やすことも外すこともできなくなるため。交点のそばで押しても何も起きないと、押し方が悪いのか規則に阻まれたのか分からない。
- 交わる橋がある所へ架けようとした操作は、盤面を変えない。
- 島の間を押す操作だけで、どの問題も最後まで解けるようにする。なぞる操作は押す操作の近道とし、なぞらないと架けられない辺を作らない。
  - 島の間ごとにボタンを置く形は、交わる所でボタンが重なり、盤面に操作の部品が増えるので取らない。
- 島を押している間・選んでいる間・マウスを乗せている間は、その島から盤面の形だけで分かる行き先（間に島の無い縦横の島）のうち、今架けられる行き先への線と、その島と同じ行と列を淡く示す。交わる橋に阻まれて今は架けられない行き先には線を引かない。正解の行き先は示さない。
  - 盤面を見れば分かる行き先を、なぞる先の狙いを定めるために見せる操作の案内で、次に取るべき手を先回りして示すものではない。線を引いた行き先を押して阻まれると、案内と結果が食い違うため、阻まれる行き先には引かない。
- なぞる指が行き先の島に届いている間と、マウスを島の間や選んだ島の相手に乗せている間は、離す・押すと回る辺に、回した後の橋の姿を薄く示す。

## チュートリアル

- ルールを1つずつ使って小さな盤面を1枚解くチュートリアルを持ち、ゲームのホームとプレイ中のメニューから開く。
- 島の状態の知らせと、交わる橋に阻まれた操作への反応は、本番と同じにする。
- ほかとつながらない島の組ができたことを一言で伝えるのは、チュートリアルの中だけにする。本番では、全部の島がつながったかを知らせない（「状態の知らせ」）。
  - つながりのルールを伝えたばかりのプレイヤーに、閉じた組を作った手がそのルールに当たると返すため。本番は盤面を読んで決めるパズルなので、つながりの判定を先回りして見せない。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。

## 難易度

- 基準とするプレイは、島ごとの本数の知らせを見ながら、読んで決めてから架けるプレイとする。架けて直す試行錯誤の量、試し置きで解いたときの手間、待った・盤面を戻すの回数は難易度に含めない。
- 挑戦は、数字の読みで必ず架かる橋・架からない橋を決め、数字だけでは決まらない所では、つながりの読みで決めることとする。読みの種類は「ルールと問題」の推理の読みとする。レベルは作業の量ではなく、要る読みの種類と深さで分ける。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 6×6・7×7 の盤面に島が10前後。見ただけで本数が決まる島（決め打ち）、「2本まで」、行き先が1つしかない島から次々に決まる。「少なくとも1本はここへ」の配分は要っても1か所で、組が閉じない読みは要らない |
| 2 | 決め打ちに加えて、「少なくとも1本はここへ」と2本と1本の配分を何か所かで読み、「1 と 1 をつながない」ように2島が閉じない読みを1回使う |
| 3 | 配分の読みに加えて、つなぐと組が閉じて孤立する所と、交差で行き先が消える所を見抜くつながりの読みを2回以上使う。5以上の数字の島がある |
| 4 | 1手だけ仮に決めて先を確かめる読み（1手の先読み）が盤面の1か所で要り、読みで止まる所が多い。5以上の数字の島が2つ以上ある |
| 5 | 1手の先読みが盤面の2か所以上で要る。島が多く、5以上の数字が3つ以上並び、6以上の数字もある |

- 上の難易度は下の難易度の読みを含み、数字の読みだけでは決まらない範囲が下の難易度より狭くならない。
- つながりの読みは一か所の気づき（1〜2組だけが決まる所）で数え、盤面を同じ規則で掃いてまとめて決まる所は数えない。1手の先読みの回数は、それより下の読みで決まる所を全部決め切った盤面で数え、どの順に解いてもこれより少なくはならない。同じ所を続けて読む先読み（直前の先読みの後に数組しか決まらないうちに、同じ行き先をもう一度狭める先読み）は1回と数え、間に別の読みを数組より多く挟んだ先読みは別の場所の先読みと数える。2島で閉じない読みと数字の読みで決まる所は、3島以上の組の読みとして数えない。
  - 掃くように決まる所は発見の瞬間にならず、解き順で回数が変わる数え方ではレベルが解き方で入れ替わるため。同じ辺を続けて狭める先読みは、人には1つの仮定を追う1回の読みで、回数で数えると難易度 4 と 5 が作業量の違わない問題で分かれるため。
- どのレベルも、数字の平均・最も多い数字の割合・数字2の割合・2本で架ける組の割合・外周に沿う橋の割合・行き先のうち橋を架ける割合に下限か上限を置き、1 と 2 ばかりの単調な盤面、盤面の枠をなぞる盤面、どの行き先にも架けるのでどこへ架けるかを選ぶ所の無い盤面は出さない。難易度 2 以上は解に輪があり、上の2つの難易度は輪が2つ以上ある。難易度 1 は外周に沿う橋をほかの難易度より少なくし、半分以上の問題の解に輪がある。
- どのレベルも、斜め隣に島がある島の割合と、間が1マスの短い橋の割合に上限を置き、盤面の一辺の半分以上の長い橋を1本以上求める。島が市松に固まり、隣の島をつなぐだけの盤面は、どの問題も同じ見た目と同じ手になるため。
- 難易度 4 と 5 は、最後のつながりの読みが、行き先の半分以上の本数が決まった後に来る問題に限る。
  - 読みの山場が解き始めに偏ると、後半は決め打ちの連鎖だけになり、上の難易度ほど終盤が作業になるため。
- 上の難易度ほど大きい盤面と多い島を求める。盤面の大きさは各難易度で許す範囲とし、島の数は盤面のマスに対する割合の下限を難易度ごとに置く（同じ難易度では、盤面が大きいほど島も多い）。盤面の大きさと島の数だけで難易度は決めない。隣り合う難易度は盤面の大きさを1つ共有し、共有する大きさでは盤面の大きさでは難易度が分かれない。難易度 4 と 5 は、同じ 10×10 でも島の数と、1手の先読みが要る場所の数で分け、難易度 5 の問題は、問題を解き切る作業の量（「評価」の基準時間）が難易度 4 のどの問題よりも多いものに限る。
- 島の配置が同じか、回転・反転してそろえて島の数の1割（1島以上）までしか違わない問題は、数字が違っても出さない。解く手順の流れが同じ問題は1つの難易度に少数までにし、読む数字の並びまで同じ問題は3問までにする。解き始めの3回の手詰まりの流れが同じ問題も、1つの難易度に少数までにし、読む数字の並びまで同じ始まりは2%までにする。
- 1つの難易度の中で、四隅の決め打ちから始まる問題の割合に上限を、唯一の通り道が要る問題・7 か 8 の島がある問題・8 の島がある問題・数島の孤立を見る先読みが要る問題の割合に下限を置き、同じ始まりと同じ手筋の問題が並ばないようにする。難易度 3 以上は、島の配置が盤面の中心について点対称な問題を1〜2割入れる。

## 評価

数字とつながりを読んで、迷わず速く全部の島をつなぐことを称える。架けて本数の知らせを見ながら直すことは罰しない。

- 速さ 100点: 経過時間を、問題の作業量（島の数・橋を架ける操作の回数・数字の読みとつながりの読みが要る量）から決める基準時間と比べる。難易度そのものを基準時間の理由にしない。0点になる時間は、基準時間のうち読みにかかる時間の割合が大きい問題ほど遠くする。
  - 読みにかかる時間は、架ける操作の時間より人によるぶれが大きく、読みの多い問題を手で解き切った人が0点にならないようにするため。
- 橋を回した入力、待った、盤面を戻す、交わる橋に阻まれた回数は評価に使わない。
  - 架けて知らせを見ながら直すことは、読んで解くプレイでも普通に起き、架け直しは押し間違いと読み直しを区別できないため。架け直しは時間に表れるので、回数でも減点すると同じ事実を二重に罰するため。
- 問題集から引けなくなった記録も、記録した問題の作業量から評価し、自己ベストの比較に使う。

自己ベストでは、評価点は高いほど、基準時間との差は小さいほど良い値として比べる。
