# SPEC-024 ブリッジパズル

数字の付いた島の間に縦か横にまっすぐ橋を架け、どの島からも数字と同じ本数の橋が出て、全部の島が1つにつながるようにするパズル。

## ルールと問題

- 盤面は 10×10 までの正方形とする。橋は、間に島の無い縦か横の2島だけをつなぎ、同じ2島の間は2本まで架けられる。橋どうしは交わらず、交わる橋がある所へ架けようとした操作は盤面を変えない。
- どの島も数字と同じ本数の橋が出ていて、全部の島が1つにつながった時点でクリアとする。失敗して終わる条件も、ミスとして数える操作も無い。

問題は次を満たすものに限る。

- 答えはただ1つとする。
- 試し置きをせずに、推理だけで解ける。推理は「難易度」の数字の読みとつながりの読みとし、1手だけ仮に決め、その両端の島から本数が破れる・組が閉じる・孤立するのが見えて退ける読み（1手の先読み）までを含める。それより先まで試さないと決まらない問題は出さない。
  - 当てずっぽうではなく推理で解けるパズルにするため。1手の先読みは盤面の一部を見て矛盾が分かる読みで、矛盾を探して深く追う試し置きとは手応えが違う。1手の先読みも推理から外すと、つながりを何度も読む最上位の問題が減り、歯ごたえを残しにくいため、推理に含める。
- 島は上下左右に隣り合わない。
  - スマホで 10×10 の盤面を遊ぶと、隣り合う2島の間に見える線は指で押し分けられない幅になるため。
- 盤面の上下の端の行と左右の端の列のどれにも島がある。
  - 端に島の無い行・列があると、盤面の広さが見かけだけになるため。

## 状態の知らせ

- 島ごとに、出ている橋の本数が数字に足りない・ちょうど・多すぎのどれかを状態の知らせ（SPEC-017）として示す。
- 全部の島がつながったかは知らせない。
- 島を押している間は、その島から盤面の形だけで分かる行き先（間に島の無い縦横の島）への線を示す。正解の行き先も、交わる橋に阻まれるかも示さない。
- 補助は提供しない。

## 操作

- 島の間を押すたびに、その間の橋を 1本 → 2本 → なし と回す。島から隣の島へなぞる操作も、同じ回し方をする。
- 島の間を押す操作だけで、どの問題も最後まで解けるようにする。
  - 島の間ごとにボタンを置く形は、交わる所でボタンが重なり、盤面に操作の部品が増えるので取らない。なぞる操作だけで架ける形も、押す操作で解けない問題ができるので取らない。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。

## 難易度

- 基準とするプレイは、島ごとの本数の知らせを見ながら、読んで決めてから架けるプレイとする。架けて直す試行錯誤の量、試し置きで解いたときの手間、待った・盤面を戻すの回数は難易度に含めない。
- 挑戦は、島の数字と行き先の数から必ず架かる橋・架からない橋を決め、数字だけでは決まらない所では、架けると島の組が閉じて孤立しないか、全部の島が1つにつながるかまで読んで決めることとする。数字の読みは、ちょうど・少なくともの読みとする。つながりの読みは、2島・3島以上の組が閉じない読み、唯一の通り道、1手の先読みとする。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 数字と行き先の数を見るだけで、次々に決まる |
| 2 | 見ただけでは決まらず、「少なくとも1本はここへ」と何か所かで読む |
| 3 | 「少なくとも1本」の読みに加えて、一か所、つながりの読みが要る |
| 4 | 数字だけでは半分も決まらず、つながりを二か所で読む |
| 5 | 何度もつながりを読む。ただしつながりの読みの多さには上限を置き、重すぎる問題は出さない |

- 上の難易度は下の難易度の読みを含み、数字の読みだけでは決まらない範囲が下の難易度より狭くならない。
- 盤面の大きさと島の数は各難易度で許す範囲とし、上の難易度ほど広く多くを許す。盤面の大きさと島の数だけで難易度は決めない。隣り合う難易度は盤面の大きさを1つ共有し、共有する大きさでは読みだけで難易度が分かれる。

## 評価

数字とつながりを読んで、迷わず速く全部の島をつなぐことを称える。架けて本数の知らせを見ながら直すことは罰しない。

- 速さ 100点: 経過時間を、問題の作業量（島の数・橋の本数・数字の読みとつながりの読みが要る量）から決める基準時間と比べる。難易度そのものを基準時間の理由にしない。
- 橋を回した入力、待った、盤面を戻す、交わる橋に阻まれた回数は評価に使わない。
  - 本数の知らせを見ながら架けて直すことがこのパズルの中心の遊び方で、架け直しは押し間違いと読み直しを区別できない。架け直しは時間にだけ表れるので、回数でも減点すると同じ事実を二重に罰するため。架け直しの少なさや正確さに配点する形は、知らせを見ながら直す遊び方そのものを罰するので取らない。読まずに試して直すプレイも、読むプレイと同じ時間で終われば同じ点になることは受け入れる。
- 問題集から引けなくなった記録も、記録した問題の作業量から評価し、自己ベストの比較に使う。

自己ベストでは、評価点は高いほど、基準時間との差は小さいほど良い値として比べる。
