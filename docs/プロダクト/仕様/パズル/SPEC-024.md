# SPEC-024 ブリッジパズル

数字の付いた島の間に縦か横にまっすぐ橋を架け、どの島からも数字と同じ本数の橋が出て、全部の島が1つにつながるようにするパズル。

## ルールと問題

- 橋は、間に島の無い縦か横の2島だけをつなぎ、同じ2島の間は2本まで架けられる。橋どうしは交わらない。
- どの島も数字と同じ本数の橋が出ていて、全部の島が1つにつながった時点でクリアとする。失敗して終わる条件も、ミスとして数える操作も無い。

問題は次を満たすものに限る。

- 盤面は 10×10 までの正方形とする。
- 答えはただ1つとする。
- 推理だけで解ける。推理は次の読みとし、それより先まで試さないと決まらない問題は出さない。
  - 数字の読み: 島の数字と行き先の数から、ちょうど・少なくとも・多くとも何本かを決める。
  - つながりの読み: 架けると2島や3島以上の組が閉じて孤立しないか、この行き先が無いと全部の島がつながらない唯一の通り道か、1手だけ仮に決めて、その両端の島から本数が破れる・組が閉じる・孤立するのが見えて退ける読み（1手の先読み）。
  - 1手の先読みで進めるのは、仮に決めた手の両端の島が埋まる所（足りた島の他の行き先は0本、上限の合計が数字と同じなら全部上限）だけとする。孤立は、4島までのまとまりが架けられる橋だけでは残りとつながらなくなる所に限る。閉じる組は大きさを問わない。
  - 当てずっぽうではなく推理で解けるパズルにするため。1手の先読みは盤面の一部を見て矛盾が分かる読みで、矛盾を探して深く追う試し置きとは手応えが違う。1手の先読みも推理から外すと、つながりを何度も読む最上位の問題が減り、歯ごたえを残しにくい。
  - 閉じる組は、組のどの島も本数が足りたと島ごとの知らせで見えるので、大きくても盤面の一部を見て分かる。孤立は知らせに出ず、大きなまとまりが残りとつながらないことを確かめるのは、盤面全体をたどる探索になるため。
- 島は上下左右に隣り合わない。
  - スマホで 10×10 の盤面を遊ぶと、隣り合う2島の間に見える線は指で押し分けられない幅になるため。
- 盤面の上下の端の行と左右の端の列のどれにも島がある。
  - 端に島の無い行・列があると、盤面の広さが見かけだけになるため。

## 状態の知らせ

- 島ごとに、出ている橋の本数が数字に足りない・ちょうど・多すぎのどれかを状態の知らせ（SPEC-017）として示す。
- 交わる橋に阻まれた操作には、阻んだ橋を短く光らせて返し、理由は文で示さない。
- 全部の島がつながったかは知らせない。
- 補助は提供しない。

## 操作

- 島の間を押すたびに、その間の橋を 1本 → 2本 → なし と回す。島を押して選んでから行き先の島を押す操作と、島から行き先の島の近くまでなぞって離す操作も、同じ回し方をする。行き先の島に届く前に離したなぞりは、橋を回さない。
- 交わる2本の線の近くを押しても、どちらか1つの辺として受け、何も起きない押しを作らない。どちらを狙ったか位置で分からない所では、架かっている橋を増やしも外しもしない方を選ぶ。
  - 押しても何も起きないと、押し方が悪いのか規則に阻まれたのか分からないため。狙いと違う橋が増える誤りは、何も起きないより直しにくい。
- 交わる橋がある所へ架けようとした操作は、盤面を変えない。
- 島の間を押す操作だけで、どの問題も最後まで解けるようにする。なぞる操作は押す操作の近道とし、なぞらないと架けられない辺を作らない。
  - 島の間ごとにボタンを置く形は、交わる所でボタンが重なり、盤面に操作の部品が増えるので取らない。
- 島を押している間と選んでいる間は、その島から盤面の形だけで分かる行き先（間に島の無い縦横の島）への線を示す。正解の行き先も、交わる橋に阻まれるかも示さない。
  - 盤面を見れば分かる行き先を、なぞる先の狙いを定めるために見せる操作の案内で、次に取るべき手を先回りして示すものではない。

## チュートリアル

- ルールを1つずつ使って小さな盤面を1枚解くチュートリアルを持ち、ゲームのホームとプレイ中のメニューから開く。
- 島の状態の知らせと、交わる橋に阻まれた操作への反応は、本番と同じにする。
- ほかとつながらない島の組ができたことを一言で伝えるのは、チュートリアルの中だけにする。本番では、全部の島がつながったかを知らせない（「状態の知らせ」）。
  - つながりのルールを伝えたばかりのプレイヤーに、閉じた組を作った手がそのルールに当たると返すため。本番は盤面を読んで決めるパズルなので、つながりの判定を先回りして見せない。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。

## 難易度

- 基準とするプレイは、島ごとの本数の知らせを見ながら、読んで決めてから架けるプレイとする。架けて直す試行錯誤の量、試し置きで解いたときの手間、待った・盤面を戻すの回数は難易度に含めない。
- 挑戦は、数字の読みで必ず架かる橋・架からない橋を決め、数字だけでは決まらない所では、つながりの読みで決めることとする。読みの種類は「ルールと問題」の推理の読みとする。レベルは作業の量ではなく、要る読みの種類と深さで分ける。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 見ただけで本数が決まる島（決め打ち）から次々に決まり、1か所だけ「少なくとも1本はここへ」の配分か「1 と 1 をつながない」読みが要る |
| 2 | 決め打ちに加えて、「少なくとも1本はここへ」と2本と1本の配分を何か所かで読む |
| 3 | 配分の読みに加えて、つなぐと組が閉じて孤立する所と、交差で行き先が消える所を見抜く読みを2回以上使う |
| 4 | 1手だけ仮に決めて先を確かめる読み（1手の先読み）が1〜2回要り、そのうち1回は組が閉じるか孤立するのを見る |
| 5 | 組が閉じるか孤立するのを見る1手の先読みが2回以上要り、先読みを3回以上重ねる問題や続けて重ねる問題も入る。島が多く、大きい数字が並ぶ |

- 上の難易度は下の難易度の読みを含み、数字の読みだけでは決まらない範囲が下の難易度より狭くならない。
- つながりの読みは一か所の気づき（1〜2組だけが決まる所）で数え、盤面を同じ規則で掃いてまとめて決まる所は数えない。1手の先読みの回数は、それより下の読みで決まる所を全部決め切った盤面で数え、どの順に解いてもこれより少なくはならない。2島で閉じない読みと数字の読みで決まる所は、3島以上の組の読みとして数えない。
  - 掃くように決まる所は発見の瞬間にならず、解き順で回数が変わる数え方ではレベルが解き方で入れ替わるため。
- どのレベルも、数字の平均・最も多い数字の割合・数字2の割合・2本で架ける組の割合・外周に沿う橋の割合に下限か上限を置き、1 と 2 ばかりの単調な盤面と盤面の枠をなぞる盤面は出さない。難易度 2 以上は解に輪があり、上の2つの難易度には5以上の数字の島を、難易度 5 には6以上の数字の島も求める。
- 上の難易度ほど大きい盤面と多い島を求める。盤面の大きさは各難易度で許す範囲とし、島の数は難易度ごとの下限を置く。盤面の大きさと島の数だけで難易度は決めない。隣り合う難易度は盤面の大きさを1つ共有し、共有する大きさでは盤面の大きさでは難易度が分かれない。難易度 4 と 5 は、同じ 10×10 でも島の数で分ける。
- 島の配置が同じで数字だけが違う問題は出さない。解く手順の流れが同じ問題は1つの難易度に少数までにし、読む数字の並びまで同じ問題は3問までにする。
- 1つの難易度の中で、四隅の決め打ちから始まる問題の割合に上限を、唯一の通り道が要る問題・7 か 8 の島がある問題・1手の先読みを3回以上か続けて重ねる問題の割合に下限を置き、同じ始まりと同じ手筋の問題が並ばないようにする。

## 評価

数字とつながりを読んで、迷わず速く全部の島をつなぐことを称える。架けて本数の知らせを見ながら直すことは罰しない。

- 速さ 100点: 経過時間を、問題の作業量（島の数・橋の本数・数字の読みとつながりの読みが要る量）から決める基準時間と比べる。難易度そのものを基準時間の理由にしない。
- 橋を回した入力、待った、盤面を戻す、交わる橋に阻まれた回数は評価に使わない。
  - 架けて知らせを見ながら直すことは、読んで解くプレイでも普通に起き、架け直しは押し間違いと読み直しを区別できないため。架け直しは時間に表れるので、回数でも減点すると同じ事実を二重に罰するため。
- 問題集から引けなくなった記録も、記録した問題の作業量から評価し、自己ベストの比較に使う。

自己ベストでは、評価点は高いほど、基準時間との差は小さいほど良い値として比べる。
