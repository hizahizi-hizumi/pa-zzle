# SPEC-024 ブリッジパズル

数字の付いた島の間に縦か横にまっすぐ橋を架け、どの島からも数字と同じ本数の橋が出て、全部の島が1つにつながるようにするパズル。

## ルールと問題

- 盤面は正方形で、島は上下左右に隣り合わない。
- 橋は、間に島の無い縦か横の2島だけをつなぐ。同じ2島の間は2本まで。橋どうしは交わらない。
- 交わる橋がある所には架けられず、架けようとした操作は盤面を変えない。
- どの島も数字と同じ本数の橋が出ていて、全部の島が1つにつながった時点でクリアとする。
- 問題は、答えがただ1つで、試し置きをせずに推理だけで解けるものに限る。盤面の外周のどの行・列にも島がある。
- 島の間を押すたびに、その間の橋を 1本 → 2本 → なし と回す。島から隣の島へなぞる操作も、同じ回し方をする。
- ミスとして数える操作は持たない。

## 状態の知らせ

- 島ごとに、出ている橋の本数が数字に足りない・ちょうど・多すぎのどれかを状態の知らせ（SPEC-017）として示す。
- 橋の正誤と、全部の島がつながったかは知らせない。
- 補助は提供しない。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。

## 難易度

- 基準とするプレイは、ルールと操作を理解し、島ごとの本数の知らせを見ながら、読んで決めてから架けるプレイとする。架けて直す試行錯誤の量、待った・盤面を戻すの回数は難易度に含めず、時間に表す。盤面の大きさや橋の本数だけによる作業量も難易度に含めない。
- 挑戦は、島の数字と行き先の数から必ず架かる橋・架からない橋を決め、数字だけでは決まらない所では、架けると島の組が閉じて孤立しないか、全部の島が1つにつながるかまで読んで決めることとする。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 数字と行き先の数を見るだけで、次々に決まる |
| 2 | 見ただけでは決まらず、「少なくとも1本はここへ」と何か所かで読む |
| 3 | 「少なくとも1本」の読みに加えて、一か所、つながりの読みが要る |
| 4 | 数字だけでは半分も決まらず、つながりを二か所で読む |
| 5 | 何度もつながりを読む |

- 推理は、数字の読み（ちょうど・少なくとも）と、つながりの読み（2島・3島以上の組が閉じない、唯一の通り道、1手の先読み）とする。1手だけ仮に決め、その両端の島から本数が破れる・閉じる・孤立するのが見えて退ける読みは、推理に含める。それより先まで試さないと決まらない問題は出さない。
- 難易度は、盤面の大きさの範囲、島の数の下限、解き始めに数字の読みで狭められる範囲の広さ、「ちょうど」で止まって「少なくとも1本」を読む回数、数字の読みで止まってつながりを読む回数、数字の読みだけでは決まらない範囲の広さを組み合わせて決める。規模だけで難易度が上がる・下がることはない。上の難易度ほど、盤面の大きさ・島の数・「少なくとも1本」とつながりの読みの回数・数字だけでは決まらない範囲の条件を下げず、解き始めに狭められる範囲の広さの上限を上げない。隣り合う難易度が共有する盤面の大きさでは、推論だけで難易度が分かれる。
- 回転・反転で重なる盤面は同じ難易度になる。試し置きで解いたときの手間は、難易度に使わない。

## 評価

数字とつながりを読んで、迷わず速く全部の島をつなぐことを称える。架けて本数の知らせを見ながら直すことは罰しない。

- 速さ 100点: 経過時間を、問題の作業量（島の数・橋の本数・数字の読みとつながりの読みが要る量）から決める基準時間と比べる。難易度そのものを基準時間の理由にしない。
- 橋を回した入力、待った、盤面を戻す、交わる橋に阻まれた回数は評価に使わない。
- 問題集から引けなくなった記録も、記録した問題の作業量から評価し、自己ベストの比較に使う。

自己ベストでは、評価点は高いほど、基準時間との差は小さいほど良い値として比べる。
