# SPEC-019 氷の床迷路

氷の床の上で、ぶつかるまで止まらずに滑る駒を動かし、止まれる場所だけを足場にしてゴールのマスで止めるパズル。もろい岩と薄い氷は滑りによって変わり、解いている途中の盤面は初期盤面と違っていく。

## ルールと問題

- 盤面は氷・岩・もろい岩・薄い氷のマスで、駒が1つ、ゴールが1マスある。盤面は外壁が囲み、外壁は盤面として描くマスの形に沿う。盤面として描かないマス（盤面の外）は外壁と同じく駒を止める。
- 利用者は上下左右の向きを選ぶ。駒はその向きへ、岩・もろい岩・水面・外壁のどれかにぶつかるまで止まらずに滑り、利用者は止まる位置を選べない。
- もろい岩は、駒が滑ってきてその手前で止まったときだけ、その滑りの後で崩れて氷になる。すぐ隣にいる駒をもろい岩へ向けても崩れない。
- 薄い氷は上を滑れ、駒が離れると割れて水面になる。滑りの出発マスと途中で通ったマスの薄い氷は、その滑りの後で割れる。駒が止まっている間は割れない。
- 1マスも動けない向きを選んだ操作は成立せず、盤面を変えず、手数にもミスにも数えない。
- 成立した滑り1回を1手と数え、滑った距離によらない。待ったで取り消した手と盤面を戻す前の手も、総手数に残す。最短手数も滑りの回数で求める。
- 滑りが止まった位置がゴールなら、その時点でクリアとする。滑りの途中でゴールを通過しても、止まった位置がゴールでなければクリアにしない。失敗して終わる条件もミスとして数える操作も無い。

問題は次を満たすものに限る。

- 開始位置からゴールで止まれることを生成で保証し、最短手数を事前に求めて持つ。最短解はただ1つとする。
- 開始位置とゴールは氷のマスとする。水面は初期盤面に置かない。
- 盤面として描くのは、到達できるいずれかの状態で駒が通るか止まるマスと、それに接する岩・もろい岩だけとする。
- 同じ向きへ続けて滑る手を生む配置を作らない。最短に近いどの道筋にも同じ向きへ続く2手が無く、どの状態にも、もろい岩を崩した直後に同じ向きでもう一度もろい岩を崩せる配置が無い。
- どの選択にも関わらない要素（もろい岩・薄い氷）は置かない。要素のある問題には、最短解では崩さず割らないが、もっともらしい手で崩す・割ると詰むか大回りになる要素（おとり）を含める。
- 要素を変わらないもの（初期の姿のまま、または変わった後の姿のまま）として読んだ盤面の道筋が、このルールでもそのまま最短に近い手数で通る問題は出さない。
- 戻らない選択肢が1つしかない手（一本道）が多い問題は出さない。

ゴールへ二度と止まれない状態（詰み）へ入れる問題も出す。

## 状態の知らせ

- 直前の滑りで通ったマスを跡として示し、止まった後も残す。ゴールを通過したことは跡で読めるようにする。
- 崩れたもろい岩の跡は、止め役でないと分かる姿で盤面に残す。
- 詰みで、かつもろい岩を崩さず薄い氷を割らない滑りだけでは、今の位置から行けるどの位置からも同じ滑りで今の位置へ戻れるとき（閉じ込め）は、もうゴールに止まれないことを知らせ、待ったと盤面を戻すへ導く。崩す・割る滑りが残っていても知らせる。詰みでも、崩さず割らない滑りでまだ戻れない先へ滑れる間は知らせない。
- 知らせた後は、崩す・割る滑りで進んでも、待った・盤面を戻すで戻っても、ゴールで止まれる状態に戻るまで知らせ続ける。

## 操作

方向ボタンを置かない。向きは盤面の領域でのスワイプと、矢印キーで選ぶ。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。待ったは、直前の滑りで崩れたもろい岩と割れた薄い氷も元に戻す。

## 難易度

- 基準とするプレイは、待ったと盤面を戻すを使える状態で、試し滑りに頼らずに、止まる位置と、もろい岩・薄い氷が変わった後の盤面を読んで道筋を組み立てるプレイとする。最短手数と盤面の広さそのものは難易度に含めない。
- 挑戦は、止まれる場所を先まで繋いでゴールで止まる道筋を組み立てることとし、要素のある盤面では、初期盤面のとおりに読まず、どの要素をどの順で崩す・割るか、どの要素に触れてはいけないかを読み分けることとする。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 氷と岩だけ。ゴールの先の岩（止め石）を使って止まる道筋を組み立てる |
| 2 | 氷と岩だけ。止め石へ回り込む道筋や、ゴールを通り過ぎる誘いを避けて一度離れ、入り直す道筋を長く組み立てる |
| 3 | もろい岩か薄い氷のどちらか1種類が加わり、崩れた・割れた後の盤面を読んで使う |
| 4 | 薄い氷が多く並ぶか、もろい岩と薄い氷の両方が加わり、使う順序を読む |
| 5 | もろい岩と薄い氷が多く、見た目どおりに読むと誤る盤面で、使う順序とおとりを読み分ける |

- 難易度は、要素の種類と数と、生成の条件で分ける。氷と岩だけの難易度は、含む手筋と読みの深さで分ける。要素のある難易度は、要素の種類と数で分け、難易度5 は生成で求める難しさに下限を置いて難易度4 と差をつける。
- 隣り合う難易度が同じ種類の要素を持つときは、要素の数の範囲を重ねない。
- 盤面の広さは各難易度で許す範囲とし、盤面の広さだけで難易度は決めない。

## 評価

試し滑りをせず、止まる位置と要素の変わり方を読んで最短の道筋でゴールに止めることを称え、その上で速さを称える。要素を試して盤面の変化を確かめることを重く罰しない。

- 効率 60点: 総手数を最短手数と比べ、総手数が最短手数のときだけ満点とする。最短手数と総手数のそれぞれに同じゆとりの手数を足した比で減らし、短い問題でも試し滑り1回の減点を小さく保つ。
- 速さ 40点: 経過時間を、盤面として描くマスの数、最短手数、初期盤面のもろい岩と薄い氷の数から決める基準時間と比べる。難易度そのものを基準時間の理由にしない。

待ったと盤面を戻すは別に減点しない。取り消した手は総手数として効率に表れる。問題集から引けなくなった記録も、記録した問題の盤面と最短手数から評価し、自己ベストの比較に使う。

自己ベストでは、評価点は高いほど、基準時間との差と最短手数との差は少ないほど良い値として比べる。
