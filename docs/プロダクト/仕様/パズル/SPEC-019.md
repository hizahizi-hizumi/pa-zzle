# SPEC-019 氷の床迷路

氷の床の上で、岩か外壁にぶつかるまで止まらずに滑る駒を動かし、止まれる場所だけを足場にしてゴールのマスで止めるパズル。

## ルールと問題

- 盤面は氷と岩のマスの格子で、外周は外壁とする。駒が1つ、ゴールが1マスある。
- 利用者は上下左右の向きを選ぶ。駒はその向きへ岩か外壁にぶつかるまで止まらずに滑り、利用者は止まる位置を選べない。
- 1マスも動けない向きを選んだ操作は成立せず、盤面を変えず、手数にもミスにも数えない。
- 成立した滑り1回を1手と数え、滑った距離によらない。待ったで取り消した手と盤面を戻す前の手も、総手数に残す。最短手数も滑りの回数で求める。
- 滑りが止まった位置がゴールなら、その時点でクリアとする。滑りの途中でゴールを通過しても、止まった位置がゴールでなければクリアにしない。失敗して終わる条件もミスとして数える操作も無い。
- 問題は、開始位置からゴールで止まれることを生成で保証し、最短手数を事前に求めて持つ。盤面の岩は、到達できる位置からの滑りを止めるか塞ぐものだけとする。
- ゴールへ二度と止まれない位置（詰み）へ入れる問題も出す。

## 状態の知らせ

- 直前の滑りで通ったマスを跡として示し、止まった後も残す。ゴールを通過したことは跡で読めるようにする。
- 今の位置から滑って行けるどの位置からも今の位置へ戻れ、その中にゴールが無いとき（閉じ込め）は、そのことを知らせ、待ったと盤面を戻すへ導く。ゴールへ二度と止まれない位置でも、まだ戻れない先へ滑れる間は知らせない。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。

## 難易度

- 基準とするプレイは、待ったと盤面を戻すを使える状態で、試し滑りに頼らずに止まる位置を読んで道筋を組み立てるプレイとする。最短手数、盤面の広さ、岩の数そのものは難易度に含めない。
- 挑戦は、止まれる場所を何手先まで頭の中で繋いで、ゴールで止まる道筋を組み立てるかとする。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | ゴールへ近づく手を選んでいけば、短い手数で止まれる |
| 2 | 近づく手を重ねれば着くが道のりが長い。または2手先の止まり方まで見れば道筋が決まる |
| 3 | 3手先の止まる場所まで読んで道筋を組み立てる |
| 4 | 目先の近づく手が4手先まで報われない |
| 5 | ゴールが見えていても、一度離れて別の方向から入り直す道筋を5手以上先まで組み立てる |

- 難易度は計画深さを主軸に判定する。計画深さは、止まれる位置を k 手先まで読み、その中にゴールがあればそこへ、無ければゴールへ近づく位置かゴールと同じ行・列に揃う位置へ向かう手を選び、待ったを使わず一度止まった位置へは戻らない素朴な先読みで解ける最小の k とする。最短手数は、計画深さ1の問題を難易度1と2に分けるときだけ使う。
- 盤面の形は各難易度で許す範囲とし、上の難易度ほど広い盤面まで許す。隣り合う難易度は同じ形を共有し、同じ形では計画深さで難易度が分かれる。難易度5 は最も広い形だけで出し、各手で比べる止まり先の多さでも難易度4 と差をつける。盤面の広さだけで難易度は決めない。

## 評価

試し滑りをせず、止まる位置を読んで最短の道筋でゴールに止めることを称え、その上で速さを称える。

- 効率 60点: 総手数を最短手数と比べる。
- 速さ 40点: 経過時間を、盤面のマス数と最短手数から決める基準時間と比べる。難易度そのものを基準時間の理由にしない。

待ったと盤面を戻すは別に減点しない。取り消した手は総手数として効率に表れる。問題集から引けなくなった記録も、記録した盤面の形と最短手数から評価し、自己ベストの比較に使う。

自己ベストでは、評価点は高いほど、基準時間との差と最短手数との差は少ないほど良い値として比べる。
