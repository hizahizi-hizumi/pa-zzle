# SPEC-015 詰将棋

詰将棋は、9×9 の将棋盤の局面と攻方の持駒から、攻方が王手だけを続けて、決められた手数のうちに玉方の玉を詰ませるゲームとして提供する。利用者は攻方だけを指し、玉方は自動で指す。手数は問題によって決まる3手か5手とし、難易度以外の開始条件として手数を選ばせない。

画面に表示する名称は「詰将棋」とする。

## ルール

駒の動き、成り、持駒の打ち方、指せない手は本将棋に従う。攻方の駒は、敵陣（上の3段）に入る・そこから出る・その中で動くときに成れる。二歩、打歩詰、行き所のない駒になる手は指せない。

詰将棋としての約束は次のとおりとする。

- 攻方は毎手、王手をかける。
- 玉方は、詰むまでの手数が最も長くなる応手を選ぶ（最長抵抗）。
- 玉方は、盤上と攻方の持駒に無い玉以外のすべての駒（駒箱）を持駒として使える。
- 手数は攻方と玉方の手を合わせた数とし、玉方の合駒も1手と数える。
- 詰め上がりで攻方の持駒を余らせない。

## 問題

問題は、次をすべて満たすものに限る。

- 3手詰か5手詰である。1手詰は通常の難易度で提供しない。
- 示した手数より短く詰まない（早詰が無い）。
- 攻方の正解が、最終手を含む各手番で1つだけである（余詰が無い）。
- 玉方が最長抵抗しても、詰め上がりで攻方の持駒が余らない（駒余りが無い）。
- 作意（正解の手順）に玉方の合駒が現れない。
- 無駄合の扱い、または2手長く逃れて駒が余る応手の扱い（2手変長）をどう解釈しても、手数・作意・正解の一意性が変わらない。

問題の品質は、不詰・早詰・余詰・駒余りを「成り立たない」、作意の合駒と無駄合・2手変長の解釈で答えが変わることを「対象外」として項目ごとに判定し、どちらにも当たらない問題だけを採る。玉方の最長の応手が複数ある問題（変化同手数）は採り、玉方が自動で指す応手を1つに決める。問題の成立性の確認と、利用者向け難易度の判定は別の責務として扱う。

問題の成立性は自前の詰み探索で確かめる。問題集を作るときには、独立した外部の詰将棋ソルバーとも開発環境で照合し、詰み手順の食い違いを説明できない局面と、玉方が2手長く逃れる変化の見方が違う局面は問題集に採らない。製品と継続的な検証には外部ソルバーを含めない。

## プレイ

盤は攻方から見た向きに、木の縁を持つ将棋盤として描き、縁の上に筋、右に段の表記を置き、星を打つ。駒は五角形に1文字の漢字を筆文字で描き、駒の格に応じて大きさを変え（玉が最も大きく歩が最も小さい）、玉方の駒は 180° 回した向きで攻方の駒と見分け、成った駒の文字は赤くする。玉方の持駒は盤の左上の駒台に「残り全部」とだけ示し、枚数を並べない。攻方の持駒は盤の下の駒台に駒の形で並べ、2枚以上は枚数を添える。盤の下には直前の攻方と玉方の手を棋譜で示し、最後に指した手の升の地を変える。棋譜では、成れたのに成らなかった手に「不成」を付ける。

攻方の駒を押して選び、行き先の升を押して指す。持駒は押してから打つ升を押す。選んでいる駒は升の地で示す。選んだ駒の行き先や、王手になる手は盤に示さない。どの手が王手になるかを読むことがこのゲームの考えどころで、行き先を示すと王手の候補が絞れてしまうため。成と不成のどちらもルール上指せる移動では、王手になるかどうかに関係なく、行き先の升のそばで成るか成らないかを選ばせる（選択肢が出たらそこへフォーカスを移す）。選択肢が出るかどうかで王手かどうかが分からないようにするため。片方しか指せない移動はその手を指す。ドラッグの操作は持たない。

攻方が指すと、短い間を置いて玉方が自動で応手を指す。その間は攻方の入力を受けないが、盤と持駒のフォーカスは残す。誤王手の筋でそれ以上指せなくなった後と詰んだ後は、持駒を薄くして押せないことを示す。指した駒は移動元から滑らせ、打った駒は浮かび上がらせて、どの駒が動いたかを目で追えるようにする。元に戻すなどで盤面に戻ってきた手は滑らせない。動きを減らす設定では滑らせない。

### 指せない手

王手にならない手（成・不成を選んだ結果が王手にならない手を含む）と、ルールで指せない手（二歩、打歩詰、行き所のない駒になる手、その駒が行けない升への手）は着手させない。押した升の地を誤王手の反証と取り違えない色に変え、盤の下にその理由を次の入力まで示し、駒の選択は残す。指せない手を押したことは読みの誤りとして扱わず、評価に使わない。

### 誤王手と反証

作意の上の攻方の手番を判断地点とし、判断地点から指した合法な王手のうち、残りの手数のうちに詰まないものを誤王手とする。誤王手を指しても、すぐに「不正解」として戻さない。玉方は、残りの手数のうちに詰まなくなる応手（反証）を盤面に指す。反証の升の地と棋譜を反証の色で示し、「で逃れる」と添える。反証には、玉が逃げる手と王手した駒を取る手を、合駒より先に選ぶ。反証は問題集に持たず、プレイ中に残りの手数以内の探索で求める。

誤王手の筋でも、攻方は王手を続けてその筋を確かめられ、玉方は毎回反証を指す。残りの手数が尽きるか王手が無くなったら、問題の手数を添えて「3手では詰みません」「5手では詰みません」と示し、それ以上は指せない。手数をかければ詰む筋もあるので、その筋が詰まないとは言い切らない。誤王手の筋にいる間に元に戻すと、最初の誤王手を指す前の判断地点まで一度に戻る。

誤王手の回数は、判断地点から誤王手を指すたびに数え、誤王手の筋を続けた王手は数えない。同じ判断地点で同じ誤王手を、元に戻す・盤面を戻すで戻して指し直したときは、1回だけ数える。反証を確かめ直すための指し直しを、新しい読みの誤りとして重ねて数えないため。反証を見た回数は指し直すたびに数える。

作意ではないが残りの手数のうちに詰む王手は、誤王手にせず詰みへ向かう手として受け、玉方は最も長く逃れる応手を指す。攻方の正解は1つなので、提供する問題ではこの手は現れない。

### クリア

玉方の玉を詰ませた時点でクリアとする。失敗して終わる条件は無い。詰んだ瞬間に入力を止め、詰んだ玉の升を染めて玉を小さく揺らし、詰め上がりの盤をしばらく見せてから結果へ進む。動きを減らす設定では揺らさず、同じ時間見せてから結果へ進む。

### 補助操作

`SPEC-007` の区別に従い、次の操作を分けて提供する。

- 元に戻す（盤の下の「待った」）: 攻方の1手と玉方の応手を取り消す。誤王手の筋にいるときは、最初の誤王手を指す前の判断地点まで一度に戻る。戻る操作はこの1つとし、判断地点へ戻るための別の操作は置かない。
- 盤面を戻す: 同じプレイを続けたまま初期局面へ戻す。経過時間とそれまでの回数を引き継ぎ、戻した回数を数える。
- 同じ問題のやり直し（画面の「リセット」）: 同じ問題を新しいプレイとして始め、経過時間と各回数を数え直す。
- 新しい問題の開始（画面の「別の問題」）: 同じ難易度の別の問題を新しいプレイとして始める。

元に戻すは玉方の応手を待つ間も使え、その応手は指さない。

ヒント、正解の初手や作意の手順の表示、王手になる手の候補の提示は通常UIで提供しない。誤王手への反証を盤面で見せることが、詰まったときに考え直す手がかりを担う。

プレイ中は手数（「N手詰」）と経過時間だけを示す。経過時間はプレイ開始から詰むまでを計り、玉方の応手を待つ間を含む。誤王手の回数は評価に使うが、数え上げて見せると王手を試すことをためらわせるため、プレイ中には示さない。

### 遊び方

ルールと操作は、盤と同じ見た目の駒で描いた小さな図と短い文で示す遊び方として、プレイ中と難易度の選択時に確認できるようにする。遊び方には、目的と手数の意味、毎手王手、玉方の自動の応手（最長抵抗）と持駒（残り全部）、10種の駒の動きの図、成り（成る前と後の駒の図）、持駒を打つこと、指せない手（二歩・打歩詰・行き所のない駒）、誤王手と元に戻すで判断地点へ戻ること、操作を載せる。

## 難易度

難易度は `レベル 1`〜`レベル 5` の5段階とする。問題難易度は、駒の動き・成り・持駒・二歩と打歩詰・毎手王手・玉方の最長抵抗を理解し、ヒントを使わず、誤王手を指す前に読んで正解を選ぶプレイを基準にする。ルールを覚える負担、駒の文字の見分けや升の押しにくさ、玉方の応手を待つ時間は問題難易度に含めない。誤王手を指して反証を見てから選び直すことは成績（誤王手の回数）で扱い、難易度の基準にしない。

詰将棋の挑戦は、王手になる候補を挙げ、それぞれに対する玉方の最善の応手を読み、一見正しそうな誤王手を反証して、正しい王手の手順を最後まで保つこととする。挑戦は、王手の候補が多いほど、自然な応手（玉が逃げる手と王手した駒を取る手）の一部が詰むために効いていそうに見える誤王手があるほど、玉方が逃れた後も攻方の脅しのある王手が続いて「この筋では詰まない」が数手先まで見えない誤王手（数手先まで続く紛れ）が多いほど強くなると考える。正しい手順の側で、複数の手筋を組み合わせることや、玉方の応手ごとに詰むことを確かめることも挑戦に加える。手数そのもの、盤上の駒数と持駒の枚数、ソルバーの探索量は問題難易度に含めない。各難易度で利用者が出会う挑戦は次のとおりとし、上の難易度は下の難易度の挑戦を含む。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 王手の候補は少なく、正解以外の王手はどれもその局面で崩れると分かる |
| 2 | 効いていそうな誤王手があるが、次の一手で詰まないと分かる |
| 3 | 数手先まで続く紛れが少しあり、候補を読み比べる |
| 4 | 数手先まで続く紛れが複数あり、正しい手順も手筋か玉方の応手を比べて確かめる |
| 5 | 数手先まで続く紛れが多く、遠い利きや複数の手筋を含めて比べる |

数手先まで続く紛れは5手詰の初手でしか起きないため、結果として難易度3以上は5手詰になり、3手詰は難易度1・2 にだけ現れる。手数を分類の条件にはしない。この分類は、代表・境界の問題の実プレイで検証する仮決定とする。

難易度の選択肢には、盤の右上隅を切り出し、隅の玉の守り駒を上の難易度ほど足して固い囲いに近づけた模式図を示し、上の難易度ほど難しそうに見せる。攻方の駒と持駒はどの難易度でも同じにし、上の難易度の図は下の難易度の駒をすべて同じ位置に含む。図はどれも初手に王手があり5手以内に詰まない答えの無い局面とし、問題集の問題や手数を示さない。

### 判定

難易度は、成立を確かめた問題について、作意の攻方の手番（判断地点）ごとに作意以外の王手を読む分析で判定する。観測する特徴は次のとおりとする。

- 初手の王手の数。
- もっともらしい誤王手の数: すべての判断地点で、自然な応手の一部が残りの手数のうちに詰む誤王手と、数手先まで続く紛れを合わせた数。どの自然な応手でも詰まず、逃れた後にも脅しが続かない誤王手は、その局面を見ただけで崩れると分かるので数えない。
- 数手先まで続く紛れ（深い紛れ）の数: 玉方が最も早く崩れを見せる逃れを選んでも、攻方の脅しのある王手が続き、反証が4手目以降まで見えない誤王手の数。
- 変化の幅: 作意の玉方の手番での、作意以外の自然な応手の数。
- 作意に現れる手筋の種類（成、不成、駒取り、捨駒、開き王手、遠い利き）。

合駒は、提供する問題では無駄合として読み飛ばせるため、読みの候補に数えない。

深い紛れの数を分類の主軸にする。深い紛れの無い問題は、もっともらしい誤王手の有無と初手の王手の数で難易度1・2 に分け、難易度4・5 には正しい手順の側の比べどころ（手筋の組み合わせか変化の幅）を求める。特徴の組が範囲に入る難易度のうち、難易度1から順に最初に当たったものに分類する。

分析結果は、次の状態を区別して扱う。

- 成立しない: 不詰・早詰・余詰・駒余りのいずれかがある、または作意が成立性の判定の作意と一致しない。提供しない。
- 評価不能: 作意に合駒が現れる、無駄合・2手変長の解釈で答えが変わる、または分析できる手数を超える。高難易度と推定せず、提供しない。
- 提供範囲外: 1手詰、または特徴の組がどの難易度の範囲にも当たらない。深い紛れが無いのに効いていそうな誤王手が多い問題や、深い紛れが多いのに正しい手順の比べどころが無い問題がこれに当たる。近い難易度へ寄せず、提供しない。
- 難易度1〜5: 特徴の組がその難易度の範囲に入る。

正確な特徴の定義と、各難易度の範囲はコードを正とする。

### 供給

各難易度の問題は、判定済みの問題を事前に生成した問題集から供給する。問題は詰め上がりから攻方の王手と玉方の応手をさかのぼって作り、1手さかのぼるごとに成立性を確かめる。詰め上がりの起点は駒打ちで詰む形に偏るので、難易度1 には盤上の駒を動かして詰める形から作った問題を足す。起点の玉は盤の上の端に置くものと盤の中ほどに置くものの両方から作る。生成するときに初手の王手の数の範囲を難易度ごとに寄せるが、生成の条件を分類には使わない。左右反転や平行移動で同じになる局面と詰み筋は問題集の中で重複させず、1つの難易度の中では、攻方の各手の駒と、その手の直前の玉から見た移動先の並び（左右反転は同じとみなす）が同じ問題を重複させない。同じ手筋の並び、初手の捨駒を玉で取らせる筋、最終手の駒打ちが1つの難易度に偏りすぎないよう上限を置く。

プレイ開始時に seed を定め、その seed で選んだ難易度の問題集から1問を選ぶ。同じ seed と同じ問題集からは同じ問題を選ぶ。プレイ時には問題の生成・成立性の確認・難易度分析を行わず、誤王手への反証を求める探索だけを行う。

選んだ問題は、問題を再現するための情報（生成器の版、seed、生成の条件（手数、初手の王手の数の範囲、詰め上がりの起点の種類））とともに扱い、同じ問題のやり直しでは同じ問題を初期局面から始める。新しい問題の開始と難易度の選び直しでは、新しい seed で問題を選ぶ。

## 成績評価

クリアしたプレイだけを評価し、1プレイを100点満点で評価する。王手の候補を読み比べ、誤王手を指さずに、正しい王手の手順を速く指し切ることを称える。

- 読みの確かさ 20点: 誤王手1回ごとに5点を減らし、0点を下回らない。
- 速さ 80点: 問題ごとの基準時間以内で満点とし、超過に応じて線形に減点する。基準時間の3倍で0点とする。点は1点単位に四捨五入する。基準時間は、盤面を見る8秒、攻方の1手あたり4秒、初手の王手1つあたり2秒、もっともらしい誤王手1つあたり4秒（20までを数える）、深い紛れ1つあたり6秒（10までを数える）の合計とする。

100点を `perfect`、90点以上を `great`、80点以上を `good`、それ未満のクリアを `clear` とする。誤王手を1回でも指したプレイは `perfect` にならない。基準時間以内なら、誤王手1〜2回で `great`、3回以上でも `good` に残る。誤王手は反証を見て考え直す学習でもあるため、減点の合計に上限を置く。一方で、反証が盤面で見えるため、読まずに王手を順に試すプレイが読み切ったプレイと同じ評価にならないよう、読みの確かさを観点に持つ。配点、減点の重さ、基準時間の係数と上限、0点になる倍率は人間の実プレイ前の暫定値とし、代表的な問題の実プレイで校正する仮決定とする。

反証を見た回数、元に戻した回数（誤王手の筋から判断地点へ戻った回数を含む）、盤面を戻した回数は減点しない。指せない手を押した回数は入力の摩擦で読みの誤りではないため、評価に使わない。盤面を戻しても経過時間は続き、戻すまでに使った時間は速さに表れる。

基準時間に使うもっともらしい誤王手と深い紛れの数は、判定と同じ分析で数えた、すべての判断地点の和とする。いずれも問題の性質として問題ごとに定まる。基準時間は問題の作業量だけから決め、難易度そのものを加点や基準時間の理由にしない。

記録するプレイ事実は、難易度、問題を再現するための情報、遊んだときの問題集の版と問題番号、問題の作業量（手数、初手の王手の数、もっともらしい誤王手の数、深い紛れの数）、経過時間、誤王手の回数、反証を見た回数、元に戻した回数、そのうち誤王手の筋から判断地点へ戻った回数、盤面を戻した回数、指せない手を押した回数、入力回数とする。評価点、評価段階、基準時間、基準時間との差は保存した事実から現在の評価規則で導出する。問題集の版と問題番号は、問題集を作り直すと別の問題を指すので遊び直しには使わず、記録がどの問題集から出たかを確かめるためだけに残す。

生成器の版が変わるなどして記録の問題を問題集から引けなくなっても、その記録は履歴と自己ベストに残し、記録した問題の作業量から評価する。そうした記録は、同じ問題を遊び直せない記録とする。

履歴と自己ベストの比較単位は難易度とする。自己ベストとして、評価点は高いほど、問題ごとの基準時間に対するクリア時間の差は少ないほど、誤王手の回数は少ないほど良い値として比較する。反証を見た回数、判断地点へ戻った回数、元に戻した回数、盤面を戻した回数、指せない手を押した回数は、評価に使わず、少ないほど良いとは言えないため比較に使わない。

結果では、評価点と評価段階に続けて、経過時間と基準時間との差、誤王手の回数を詰将棋の主要成績として扱う。反証を見た回数、元に戻した回数、盤面を戻した回数、評価の内訳（読みの確かさと速さ）、基準時間とその根拠（手数、初手の王手の数、もっともらしい誤王手の数、深い紛れの数）は主結果と分けて確認できるようにする。分析の用語は、利用者向けには「効いていそうな誤王手」「数手先まで続く紛れ」と言い換え、その問題で指す前に読んで捨てる候補の数だと添える。履歴では、評価点、基準時間との差、誤王手の回数を難易度ごとに比較する主要指標として扱う。
