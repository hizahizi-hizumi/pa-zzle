# SPEC-008 ナンプレ

ナンプレは 9×9 の盤面を、各行・各列・各 3×3 ブロックに 1〜9 が一度ずつ入るよう完成させるゲームとして提供する。

## 問題

問題は初期数字と一意な完成解を持ち、推測（仮置きと後戻り）なしに、人間向けの手筋だけで最後まで解けるものに限る。初期数字は利用者が変更する対象ではない。問題の成立性の確認と、利用者向け難易度の判定は別の責務として扱う。

## 難易度

難易度は `レベル 1`〜`レベル 5` の5段階とする。問題難易度は、ルールと入力・メモの操作を理解し、ヒントやミスの表示に頼らずに盤面を読んで数字を置き、候補を消す読みが要る場面ではメモで候補を管理し、仮置きと後戻りをしないプレイを基準にする。ヒント数、空きマスの数、解き終えるまでの長さ、入力回数や時間そのものは問題難易度に含めない。

ナンプレの挑戦は、盤面から次に数字を置けるマスを見つけ出し、置けるマスが見つからないときは、行・列・ブロックの重なりや、いくつかのマス・数字の組を読んで候補を絞り、置けるマスを作り出すこととする。各難易度で利用者が出会う挑戦は次のとおりとし、上の難易度ほど、新しい種類の読みが1つずつ加わる。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | ブロックの中で、数字の置き場所を探せば進められる |
| 2 | 行や列の中の置き場所や、1マスに入り得る数字まで読む場面がある |
| 3 | 置ける数字が見つからないとき、ブロックと行・列の重なりで候補を絞る場面がある |
| 4 | 1つの行・列・ブロックの中で、いくつかのマス・数字の組を見つけて候補を絞る場面がある |
| 5 | 複数の行・列や離れたマスにまたがる候補のつながりを読んで候補を絞る場面がある |

難易度の選択肢には、盤面の一部を切り出した小さな図を添え、レベルが上がるほど盤面の数字がまばらになる密度の違いで挑戦の強さを抽象的に示す。図の数字の量は、実際の問題のヒント数を表さない。

### 判定

難易度は、問題を人間向けの手筋で解き進める過程を分析して判定する。各局面で最も浅い手筋から順に数字を置ける・候補を消せる場所を探し、解き切るまでに使わざるを得なかった最も深い手筋で難易度を決める。手筋の段は、ブロックの中の置き場所、行・列の中の置き場所と1マスに入り得る数字、ブロックと行・列の重なり、1つの単位の中のマス・数字の組、複数の単位にまたがる形（2〜3本の行・列の組み合わせ、3マスの候補のつながり）を区別する。

分析結果は、次の状態を区別して扱う。

- 成立しない: 解が無い、または2つ以上ある。提供しない。
- 評価不能: 一意解だが、分析で扱う手筋では解き切れない。高難易度と推定せず、提供しない。
- 提供範囲外: 分析できるが、行・列・ブロックの最後の1マスを埋めるだけで解き終わり、数字の置き場所を探す挑戦が無い。提供しない。
- 難易度1〜5: 分析でき、提供範囲に入る。

ヒント数は難易度の根拠にしない。ヒントの多さで難易度を見分けられないよう、全難易度で同じヒント数の範囲に入る問題だけを供給する。

正確な手筋、分類表、ヒント数の範囲はコードを正とする。

### 供給

各難易度の問題は、判定済みの問題を事前に生成した問題集から供給する。プレイ開始時に seed を定め、その seed で選んだ難易度の問題集から1問を選ぶ。同じ seed と同じ問題集からは同じ問題を選ぶ。

選んだ問題は、問題を再現するための情報とともに扱い、同じ問題のやり直しでは同じ問題を初期数字から始める。新しい問題の開始と難易度の選び直しでは、新しい seed で問題を選ぶ。

## プレイ

利用者は空きマスへ数字を入力・変更・削除でき、候補数字をメモできる。メモは解答とは別の補助情報であり、正解判定には使わない。

入力した数字が完成解と異なる場合はミスとして記録する。盤面上の制約競合と、完成解に対する誤答は同じ意味として扱わない。

正しい数字が入力されたとき、その数字と両立しない同一行・列・ブロックのメモは除去する。

全マスが完成解と一致した時点でクリアとする。見かけ上各数字が揃っていても、誤答を含む盤面はクリアとしない。

プレイ中は元に戻す、同じ問題のやり直し、新しい問題の開始を提供する。

## 成績評価

1プレイを100点満点で評価する。

- 正確性 40点: ミス1回につき5点を減点する。
- 速さ 40点: 15分以内を満点とし、それ以降は1分ごとに1点を減点する。
- 安定性 20点: 元に戻す1回につき2点、やり直し1回につき5点を減点する。

各項目は0点を下回らない。合計100点を `perfect`、90点以上を `great`、80点以上を `good`、それ未満のクリアを `clear` とする。

記録するプレイ事実は、難易度、問題を再現するための情報、経過時間、ミス数、元に戻した回数、やり直した回数とする。評価点と評価段階は保存した事実から現在の評価規則で導出する。

3段階（`かんたん / ふつう / むずかしい`）の難易度で記録したプレイは、履歴と自己ベストに旧区分のまま残し、`レベル 1`〜`レベル 5` へ読み替えない。旧区分は5段階のどのレベルとも別の比較単位とし、レベルの自己ベストに混ぜない。旧区分の記録の問題は現在の問題集に無いため、同じ問題を再プレイできないものとして扱い、再プレイできないことを示す。現在の問題集から引けない記録も同様に扱う。

履歴と自己ベストの比較単位は難易度とする。自己ベストとして、評価点は高いほど、経過時間とミス数は少ないほど良い値として比較する。結果・履歴では、これらを含むナンプレでプレイを理解するために意味のある事実を扱う。
