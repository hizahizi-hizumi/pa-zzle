# SPEC-008 ナンプレ

9×9 の盤面を、各行・各列・各 3×3 ブロックに 1〜9 が一度ずつ入るよう完成させるパズル。

## ルールと問題

- 問題は初期数字と一意な完成解を持ち、推測（仮置きと後戻り）なしに人間向けの手筋だけで最後まで解けるものに限る。初期数字は利用者が変更できない。
- 行・列・ブロックの制約に反する数字や完成解と異なる数字も、入力を拒まず盤面に置く。
- 全マスが完成解と一致した時点でクリアとする。
- 完成解と異なる数字の入力をミスとし、入力した時点で1回と数える。誤りを直しても、待ったで取り消しても、ミスは減らない。メモの操作と数字の消去はミスに数えない。

## 補助

- 次の3つは完成解と照らして伝える補助とし、常に出して遊び方で説明する。
  - 完成解と異なる数字は、入力した直後からそのマスで誤りとして示す。
  - 正しい位置に9つそろった数字は、入力ボタンを押せなくする。
  - 正しい数字を入れたとき、その数字と両立しない同じ行・列・ブロックのメモを除く。完成解と異なる数字を入れたときは、ほかのマスのメモを変えない。

## チュートリアル

- 本物の 9×9 の盤面を1枚解くチュートリアルを持つ。数字の入れ方を教えた後、行・列・ブロックのルールを1つずつ示し、示した行・列・ブロックで最後に空いたマスを埋めさせる。
- 完成解と異なる数字を入れ、示した行・列・ブロックの数字と重なったときの一言は、重なった行・列・ブロックをすべて挙げる。盤面で赤く示すまとまりと食い違わせないため。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。

## 難易度

- 基準とするプレイは、誤りの表示に頼らず盤面を読んで数字を置き、必要な場面ではメモで候補を管理し、仮置きと後戻りをしないプレイとする。
- 挑戦は、次に数字を置けるマスを見つけ、見つからないときは候補を絞って置けるマスを作り出すこととする。上の難易度ほど、新しい種類の読みが1つずつ加わる。

| 難易度 | 挑戦 | 手筋 |
| --- | --- | --- |
| 1 | ブロックの中で、数字の置き場所を探せば進められる | 残り1マス、ブロックのシングル |
| 2 | 行や列の中の置き場所や、1マスに入り得る数字まで読む場面がある | 行・列のシングル、マスのシングル |
| 3 | ブロックと行・列の重なりで候補を絞る場面がある | ブロックと行・列の重なり |
| 4 | 1つの行・列・ブロックの中で、いくつかのマス・数字の組を見つけて候補を絞る場面がある | 数字の組、場所の組 |
| 5 | 複数の行・列や離れたマスにまたがる候補のつながりを読んで候補を絞る場面がある | 行・列の組み合わせ、3マスの候補のつながり |

- 手筋は次のものとし、「ルールと問題」の人間向けの手筋はこれらを指す。
  - 数字を置く手筋
    - 残り1マス: 行・列・ブロックに空きマスが1つだけ残り、入る数字が1つに決まる。
    - ブロックのシングル: ブロックの中で、ある数字を置けるマスが1つしかない。
    - 行・列のシングル: 行・列の中で、ある数字を置けるマスが1つしかない。
    - マスのシングル: あるマスに入り得る数字が1つしかない。
  - 候補を消す手筋
    - ブロックと行・列の重なり: ブロックの中である数字の候補が1本の行・列に並ぶとき、その行・列のほかのマスからその数字の候補を消す。行・列の中である数字の候補が1つのブロックに収まるときは、そのブロックのほかのマスから消す。
    - 数字の組: 1つの行・列・ブロックで、2つ（3つ）のマスの候補が合わせて2種類（3種類）なら、同じ行・列・ブロックのほかのマスからその数字の候補を消す。
    - 場所の組: 1つの行・列・ブロックで、2種類（3種類）の数字の置き場所が合わせて2つ（3つ）のマスなら、そのマスからほかの数字の候補を消す。
    - 行・列の組み合わせ: ある数字の候補が2本（3本）の行で同じ2本（3本）の列に収まるなら、その列のほかの行からその数字の候補を消す。行と列を入れ替えても同じ。
    - 3マスの候補のつながり: 候補が2つ（3つ）の軸のマスと、軸から見える候補が2つの2マスで、軸がどの数字に決まっても2マスに共通の数字が3マスのどれかに入るとき、その数字が入り得るマスのすべてから見えるマスから、その数字の候補を消す。
- 難易度は、解き切るまでに使わざるを得なかった最も深い手筋で判定する。手筋は表の上の行ほど浅いとし、局面ごとに使える最も浅い手筋で解き進めたときに使った最も深い手筋を、使わざるを得なかった手筋とする。
- 行・列・ブロックの最後の1マスを埋めるだけで解き終わる問題は、数字の置き場所を探す挑戦が無いので出さない。
- 初期数字の数は難易度の根拠にしない。初期数字の多さで難易度を見分けられないよう、全難易度で同じ範囲の初期数字の数の問題を出す。

## 評価

正確さ 40点（ミスで減点）、速さ 40点（経過時間で減点）、安定性 20点（待ったと盤面を戻すで減点）とする。速さの基準時間は、問題の作業量によらず全問で共通にする。

自己ベストでは、評価点は高いほど、経過時間とミス数は少ないほど良い値として比べる。
