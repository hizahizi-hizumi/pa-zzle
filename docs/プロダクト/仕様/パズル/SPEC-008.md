# SPEC-008 ナンプレ

ナンプレは、9×9 の盤面を、各行・各列・各 3×3 ブロックに 1〜9 が一度ずつ入るよう完成させるゲームとして提供する。盤面の大きさは難易度によって変えない。

## 問題

問題は初期数字と一意な完成解を持ち、推測（仮置きと後戻り）なしに、人間向けの手筋だけで最後まで解けるものに限る。初期数字は利用者が変更できない。

## プレイ

利用者は空きマスへ数字を入力・変更・削除でき、候補数字をメモできる。メモは解答とは別の利用者の書き込みで、正解の判定には使わない。メモの入力は切り替えで行い、数字の入ったマスにはメモを書かない。候補数字を自動で書き込む機能は持たない。

行・列・ブロックの制約に反する数字や完成解と異なる数字も、入力そのものは拒否せず盤面に置く。

全マスが完成解と一致した時点でクリアとする。見かけ上各数字が揃っていても、誤答を含む盤面はクリアとしない。

完成解と異なる数字の入力をミスとし、入力した時点で1回と数える。示された誤りを直しても、待ったで取り消しても、ミスは減らない。メモの書き込み・消去と、数字の消去はミスに数えない。

プレイ中はミス数、経過時間、待った回数を示す。

### 状態の知らせと補助

同じ行・列・ブロックで重なった数字は、初期数字も含めて、関係するマスすべてで示す。これは今の盤面のルール違反を伝える状態の知らせ（SPEC-017）である。選んだマスと同じ行・列・ブロックのマスや、同じ数字のマスの強調は、盤面を見やすくするためのもので、正誤を含まない。

次の表示は、完成解と照らして伝える補助とする。ナンプレではこの補助を常に出し、遊び方で説明する。

- 完成解と異なる数字は、入力した直後からそのマスで誤りとして示す。行・列・ブロックで重なっていなくても示す。
- 正しい位置に9つそろった数字は、入力ボタンを押せなくする。誤答を含めて9つ見えるだけの数字は、そろったとみなさない。
- 正しい数字を入れたとき、その数字と両立しない同じ行・列・ブロックのメモを除く。完成解と異なる数字を入れたときは、そのマスのメモだけを消し、ほかのマスのメモは変えない。

### やり直し

プレイ中は、待った、盤面を戻す、リセット、別の問題を提供する。

- 待った: 直前の盤面操作（数字の入力・消去、メモの書き込み・消去）を1つ取り消す。
- 盤面を戻す: 盤面を初期数字だけの状態へ戻し、メモも消す。

## 難易度

問題難易度は、ルールと入力・メモの操作を理解し、誤答の表示に頼らずに盤面を読んで数字を置き、候補を消す読みが要る場面ではメモで候補を管理し、仮置きと後戻りをしないプレイを基準にする。初期数字の数、空きマスの数、解き終えるまでの長さ、入力回数や時間そのものは問題難易度に含めない。

ナンプレの挑戦は、盤面から次に数字を置けるマスを見つけ出し、見つからないときは、行・列・ブロックの重なりや、いくつかのマス・数字の組を読んで候補を絞り、置けるマスを作り出すこととする。各難易度で利用者が出会う挑戦は次のとおりとし、上の難易度ほど、新しい種類の読みが1つずつ加わる。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | ブロックの中で、数字の置き場所を探せば進められる |
| 2 | 行や列の中の置き場所や、1マスに入り得る数字まで読む場面がある |
| 3 | 置ける数字が見つからないとき、ブロックと行・列の重なりで候補を絞る場面がある |
| 4 | 1つの行・列・ブロックの中で、いくつかのマス・数字の組を見つけて候補を絞る場面がある |
| 5 | 複数の行・列や離れたマスにまたがる候補のつながりを読んで候補を絞る場面がある |

難易度の選択肢には、盤面の一部を切り出した小さな図を添え、レベルが上がるほど数字がまばらになる密度の違いで挑戦の強さを抽象的に示す。図の数字の量は、実際の問題の初期数字の数を表さない。

### 判定

難易度は、問題を人間向けの手筋で解き進める過程を分析して判定する。各局面で最も浅い手筋から順に、数字を置ける場所や候補を消せる場所を探し、解き切るまでに使わざるを得なかった最も深い手筋で難易度を決める。手筋の段は、ブロックの中の置き場所、行・列の中の置き場所と1マスに入り得る数字、ブロックと行・列の重なり、1つの単位の中のマス・数字の組、複数の単位にまたがる形（2〜3本の行・列の組み合わせ、3マスの候補のつながり）を区別する。

分析結果は、次の状態を区別して扱う。

- 成立しない: 解が無い、または2つ以上ある。提供しない。
- 評価不能: 一意解だが、分析で扱う手筋では解き切れない。高難易度と推定せず、提供しない。
- 提供範囲外: 分析できるが、行・列・ブロックの最後の1マスを埋めるだけで解き終わり、数字の置き場所を探す挑戦が無い。提供しない。
- 難易度1〜5: 分析でき、提供範囲に入る。

初期数字の数は難易度の根拠にしない。初期数字の多さで難易度を見分けられないよう、全難易度で同じ初期数字の数の範囲に入る問題だけを供給する。

正確な手筋、分類表、初期数字の数の範囲はコードを正とする。

### 供給

各難易度の問題は、判定済みの問題を事前に生成した問題集から供給する。プレイ時には問題の生成と難易度の判定を行わない。

## 成績評価

- 正確さ 40点: ミス1回につき5点を減点する。
- 速さ 40点: 経過時間15分以内を満点とし、超えた時間を1分単位で切り上げ、1分につき1点を減点する。基準は全難易度で同じとする。
- 安定性 20点: 待った1回につき2点、盤面を戻す1回につき5点を減点する。

各項目は0点を下回らない。

### 記録と自己ベスト

記録するプレイ事実は、経過時間、ミス数、待った回数、盤面を戻した回数とする。

自己ベストでは、評価点は高いほど、経過時間とミス数は少ないほど良い値として比べる。

3段階（`かんたん / ふつう / むずかしい`）は廃止した難易度区分で、その記録の扱いは SPEC-001 による。

### 結果

結果では、評価点と評価段階に続けて、経過時間、ミス数、待った回数を主な成績として示す。評価の内訳、盤面を戻した回数、採点の基準は、主な成績と分けて確認できるようにする。
