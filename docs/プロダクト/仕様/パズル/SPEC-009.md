# SPEC-009 ウォーターソート

ウォーターソートは、容量4のボトルに入った色付きの液体を注ぎ分け、各色を一つの満杯のボトルへ揃えるゲームとして提供する。問題には空ボトルを2本含める。

## 問題と操作

一回の操作では、一つのボトルから別のボトルへ、注ぎ元の上端に連続する同色の液体を可能な量だけ移す。

注ぎ先が空であるか、注ぎ先の上端が注ぎ元と同色であり、かつ容量に空きがある場合に注げる。自分自身へは注げない。

すべての空でないボトルが容量4まで単色で満たされた時点でクリアとする。

プレイ中は元に戻す、同じ問題のやり直し、新しい問題の開始を提供する。合法な注ぎ元・注ぎ先を通常UIで先回りして示さず、盤面を読んで注ぎ方を判断することをゲーム性として残す。

## 難易度

難易度は `かんたん / ふつう / むずかしい` の3段階とする。色数や最短手数そのものを難易度とはみなさない。

問題を解く過程で必要になる準備操作、空ボトルの余裕、選択を誤ったときの行き止まり・遠回りなど、判断と先読みの負荷を表す特徴を用いて分類する。問題生成・可解性の保証と難易度分類は分離する。

## 成績評価

1プレイを100点満点で評価する。

- 効率 40点: クリアまでに必要だった手数を最短手数と比較する。
- 速さ 40点: 盤面把握5秒、1色あたり1.5秒、最短1手あたり5秒を合計した基準時間を満点基準とし、超過に応じて線形に減点する。
- 正確性 20点: クリアへ至る手数とは別に行った後戻り相当の操作量を、最短手数に対する割合で評価する。

各項目は0点から満点の範囲とする。合計100点を `perfect`、90点以上を `great`、80点以上を `good`、それ未満のクリアを `clear` とする。

履歴と自己ベストの比較単位は難易度とする。自己ベストとして、評価点は高いほど、経過時間と最短手数との差は少ないほど良い値として比較する。結果・履歴では、これらを含むウォーターソートでプレイを理解するために意味のある事実を扱う。
