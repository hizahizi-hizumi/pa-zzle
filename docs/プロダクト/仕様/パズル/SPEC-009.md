# SPEC-009 ウォーターソート

ウォーターソートは、容量4のボトルに入った色付きの液体を注ぎ分け、各色を一つの満杯のボトルへ揃えるゲームとして提供する。

## 問題

問題は、各色をちょうど4単位ずつ含み、色数と同じ本数の満杯のボトルと、1本または2本の空ボトルから始まる。初期状態で既に1色で満杯になっているボトルは含めない。

問題は、解けることを生成時に探索で確かめ、最短手数を求めたものに限る。色数や空ボトル数から解けると推測しない。探索の上限までに解けると確かめられなかった問題は提供しない。問題の成立性の確認と、利用者向け難易度の判定は別の責務として扱う。

## プレイ

一回の操作では、一つのボトルから別のボトルへ、注ぎ元の上端に連続する同色の液体を、注ぎ先に入るだけまとめて移す。移す量は利用者が指定しない。

注ぎ先が空であるか、注ぎ先の上端が注ぎ元と同色であり、かつ容量に空きがある場合に注げる。自分自身へは注げない。

利用者は注ぎ元のボトルを選び、続けて注ぎ先のボトルを選んで注ぐ。選んだ注ぎ元をもう一度選ぶと選択を解除する。成立した注ぎ1回を1手と数え、移した量によらない。選択、選択の解除、成立しなかった操作は手に数えない。最短手数も同じ1手の数え方で求める。

すべての空でないボトルが容量4まで単色で満たされた時点でクリアとする。空のボトルは残ってよい。

プレイ中は総手数、経過時間、待った回数を示す。最短手数と基準時間はプレイ中に示さない。

### 状態の知らせ

注げる注ぎ元・注ぎ先は前もって示さず、盤面を読んで注ぎ方を判断することをゲーム性として残す。次の知らせは、今の盤面とルールだけから分かることを伝える状態の知らせ（SPEC-017）であり、補助ではない。ウォーターソートは補助を提供しない。

- 注げる先が一つも無いボトルを注ぎ元に選ぶと、選択されず、成立しない操作として返す。1色で満杯になったボトルも注ぎ元に選べない。空ボトルへ移しても同じ状態にしかならないためである。ルール上注げない注ぎ先を選んだときも、盤面と手数を変えずに成立しない操作として返す。
- 今の盤面から注いで行ける盤面がどれも今の盤面へ戻れるものだけで、その中にクリアが無いとき（手詰まり）は、「手詰まり」と知らせ、待ったと盤面を戻すへ導く。この先いずれ手詰まりになる盤面でも、まだ先へ進める手がある間は知らせない。手詰まりかどうかを判定しきれないときも知らせない。知らせるのは注ぐ演出が終わってからとする。

### やり直し

プレイ中は、待った、盤面を戻す、リセット、別の問題を提供する。

- 待った: 直前の1手を取り消す。総手数は減らさず、待った回数を数える。盤面を戻した後は、盤面を戻す前の手を取り消せない。
- 盤面を戻す: 盤面を初期状態へ戻し、経過時間、総手数、待った回数を引き継ぎ、戻した回数を数える。

クリア後は待ったと盤面を戻すを使えない。

## 難易度

難易度は `レベル 1`〜`レベル 5` の5段階とする。問題難易度は、ルールと操作を理解し、待ったや盤面を戻すに頼らずに盤面を読んで注ぐ順序を選ぶプレイを基準にする。色数、最短手数、解き終えるまでの長さそのものは問題難易度に含めない。

ウォーターソートの挑戦は、限られた空きの中で、後で必要になる色を出す・よける・まとめることができる状態を保つよう、注ぐ順序を先読みすることとする。各難易度で利用者が出会う挑戦は次のとおりとし、上の難易度ほど、目先の自然な手を選び続けたときに詰みやすく、先読みが要る。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 同じ色をまとめていけば解ける |
| 2 | 何も考えずに進めると、ときどき詰む |
| 3 | 空きボトルの使い方を考えないと詰む |
| 4 | 何度か先を読む必要がある |
| 5 | 先を読まずに進めると、ほぼ確実に詰む |

各難易度は、問題の候補を作る色数と空ボトル数の範囲を持ち、隣り合う難易度で範囲が重なってよい。上の難易度ほど、色数の多い問題と空ボトル1本の問題を含める。色が増えると同時に追う色と注ぐ順序の依存が広がり、空ボトルが減ると使える空きが狭まって誤った順序で詰みやすくなるため、どちらも先読みの考えどころを増やす。色数や空ボトル数だけでは難易度を決めず、次の判定で決める。

### 判定

難易度は、目先の自然な手を選び続けるプレイを同じ問題で何度も試し、詰んだ割合（自然詰み率）で判定する。自然な手は、同じ色の上へ注げるならそこへ注ぎ、なければまだ通っていない盤面へ進む手から無作為に選ぶものとし、先読みも後戻りもしない。自然詰み率が高いほど、先読みしないと詰む問題として上の難易度とする。判定には、最短解を探す探索の経路や探索量を使わない。

難易度は、自然詰み率の帯と、その難易度の色数・空ボトル数の範囲の組で決める。分析結果は、次の状態を区別して扱う。

- 成立しない: 解けない、または探索の上限までに解けると確かめられない。提供しない。
- 提供範囲外: 解けるが、自然詰み率と色数・空ボトル数の組がどの難易度の範囲にも入らない。提供しない。
- 難易度1〜5: 自然詰み率と色数・空ボトル数の組がその難易度の範囲に入る。

正確な試行回数、自然詰み率の帯、色数・空ボトル数の範囲はコードを正とする。

### 供給

各難易度の問題は、判定済みの問題を事前に生成した問題集から供給する。各難易度の問題集は、その難易度で許す色数と空ボトル数の組からほぼ均等に採る。プレイ時には問題の生成、最短手数の探索、難易度の判定を行わない。

## 成績評価

クリアしたプレイだけを評価し、1プレイを100点満点で評価する。少ない手数で、手戻りなく、速く揃えることを称える。

- 効率 40点: クリア手数を最短手数と比べる。最短手数で満点、最短手数の2倍以上で0点とし、その間はクリア手数に応じて線形に減点する。
- 速さ 40点: 盤面把握5秒、1色あたり1.5秒、最短1手あたり5秒を合計した基準時間以内で満点、基準時間の2倍以上で0点とし、その間は経過時間に応じて線形に減点する。
- 正確性 20点: 手戻りが無ければ満点、手戻りが最短手数以上で0点とし、その間は手戻りに応じて線形に減点する。

クリア手数は、クリアした盤面へ至った手の数とし、待ったで取り消した手と、盤面を戻す前の手を含めない。手戻りは、総手数からクリア手数を引いた手数とする。待った回数と盤面を戻した回数そのものは減点せず、取り消した手や戻す前の手は手戻りとして評価に表れる。

各項目は1点単位に四捨五入し、0点から満点の範囲とする。基準時間は問題の色数と最短手数だけから決め、難易度そのものを基準時間の理由にしない。

記録するプレイ事実は、難易度、問題を再現するための情報、経過時間、総手数、クリア手数、待った回数、盤面を戻した回数、最短手数とする。基準時間、基準時間との差、最短手数との差、手戻りは記録せず、保存した事実から導く。評価に要る事実を記録から求められない記録は、評価点と最短手数との差を推測せず、示さない。

自己ベストとして、評価点は高いほど、基準時間との差と最短手数との差は少ないほど良い値として比較する。

結果では、評価点と評価段階に続けて、クリア手数と最短手数との差、経過時間と基準時間との差をウォーターソートの主要成績として扱う。評価の内訳、基準時間とその根拠、総手数、手戻り、待った回数、盤面を戻した回数は主結果と分けて確認できるようにする。履歴では、評価点、基準時間との差、最短手数との差を難易度ごとに比較する主要指標として扱う。

3段階（`かんたん / ふつう / むずかしい`）の難易度で記録したプレイは、履歴と自己ベストに旧区分の名前のまま残し、`レベル 1`〜`レベル 5` へ読み替えない。旧区分は5段階のどのレベルとも別の比較単位とし、レベルの自己ベストに混ぜない。旧区分の記録は、同じ問題を遊び直せない記録になる（SPEC-014）。
