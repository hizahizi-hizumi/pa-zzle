# SPEC-009 ウォーターソート

容量4のボトルに入った色付きの液体を注ぎ分け、各色を一つの満杯のボトルへ揃えるパズル。

## ルールと問題

- 問題は、各色をちょうど4単位ずつ含む、色数と同じ本数の満杯のボトルと、1本または2本の空ボトルから始まる。初めから1色で満杯のボトルは含めない。
- 問題は、生成時に探索で解けることを確かめ、最短手数を求めたものに限る。
- 1回の注ぎでは、注ぎ元の上端に連続する同色の液体を、注ぎ先に入るだけまとめて移す。移す量は利用者が指定しない。
- 注ぎ先が空であるか、注ぎ先の上端が注ぎ元と同色で空きがあるときに注げる。
- 成立した注ぎ1回を1手と数え、移した量によらない。選択や成立しなかった操作は手に数えない。最短手数も同じ数え方で求める。
- すべての空でないボトルが単色で満杯になった時点でクリアとする。

## 状態の知らせ

- 1色で満杯のボトルや注げる先が無いボトルは注ぎ元に選べない。
- 今の盤面から注いで行ける盤面がどれも今の盤面へ戻れるものだけで、その中にクリアが無いとき（手詰まり）は、そのことを知らせ、待ったと盤面を戻すへ導く。この先いずれ手詰まりになる盤面でも、まだ先へ進める手がある間は知らせない。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。

## 難易度

- 基準とするプレイは、待ったや盤面を戻すに頼らずに盤面を読んで注ぐ順序を選ぶプレイとする。色数、最短手数、解き終えるまでの長さそのものは難易度に含めない。
- 挑戦は、限られた空きの中で、後で必要になる色を出す・よける・まとめることができる状態を保つよう、注ぐ順序を先読みすることとする。上の難易度ほど、目先の自然な手を選び続けたときに詰みやすい。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 同じ色をまとめていけば解ける |
| 2 | 何も考えずに進めると、ときどき詰む |
| 3 | 空きボトルの使い方を考えないと詰む |
| 4 | 何度か先を読む必要がある |
| 5 | 先を読まずに進めると、ほぼ確実に詰む |

- 難易度は、目先の自然な手を選び続けるプレイを同じ問題で何度も試して詰んだ割合で判定する。最短解の探索の経路や探索量は判定に使わない。
- 色数と空ボトル数は難易度そのものではなく、各難易度で許す範囲とする。

## 評価

少ない手数で、手戻りなく、速く揃えることを称える。

- 効率 40点: クリアした盤面へ至った手数を最短手数と比べる。
- 速さ 40点: 経過時間を、問題の色数と最短手数から決める基準時間と比べる。
- 正確性 20点: 待ったで取り消した手と盤面を戻す前の手（手戻り）の多さで減点する。待った回数と盤面を戻した回数そのものは減点しない。

基準時間は問題の作業量だけから決め、難易度そのものを理由にしない。

自己ベストでは、評価点は高いほど、基準時間との差と最短手数との差は少ないほど良い値として比べる。
