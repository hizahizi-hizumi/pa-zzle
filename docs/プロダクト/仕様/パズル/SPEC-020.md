# SPEC-020 ハミルトン路

壁と仕切りのある正方形の盤面で、始点から上下左右に隣り合うマスへ道を延ばし、通れるすべてのマスをちょうど1回ずつ通る1本の道を引くパズル。

## ルールと問題

- マスは通れるマスと壁マスからなり、隣り合う通れるマスの間に仕切りを置ける。道は壁マスへ入れず、仕切りを越えられない。
- 始点だけを示し、終点は示さない。
- 問題は、始点から全マスを通る道がただ1つであり、どの仕切りも、外すとその道がただ1つでなくなるものに限る。
- 道は先端から隣り合うマスへ延ばし、道の途中のマスまで巻き戻して引き直す。離れたマスを指して道を自動で引く操作は持たない。
- 道が全マスを通った時点でクリアとする。
- 一度引いた道を戻し、同じ位置から前と別のマスへ道を引いたことを、引き直しとして数える。どの操作で戻したかによらない。戻して前と同じ道を引き直したことは数えない。待ったで前の道筋へ戻したことも、道筋を変えたこととして数える。
- 引き直しは、なぞり1回（押してから離すまで）・キー入力1回・待った1回・盤面を戻す1回の前後で道筋が変わったかで数え、なぞりの途中の行き来は数えない。
- 仕切りや壁に阻まれて道が延びなかったことは数えない。

## 状態の知らせ

- 道が全マスを通る前に、先端から延ばせるマスが無くなったこと（行き止まり）は状態の知らせ（SPEC-017）として示す。
- 道に切り離されて通れなくなったマスや、取り残されるマスは、この先の手詰まりを示す補助として扱い、示さない。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。待ったは、なぞり1回をまとめて取り消す。

## 難易度

- 基準とするプレイは、ルールと操作を理解し、盤面を読んで道筋を決めてから引くプレイとする。行き止まりの知らせは見えてよい。引いて行き詰まってから戻す試行錯誤の量は難易度に含めず、評価に表す。盤面の大きさや通るマスの数だけによる作業量、入力回数や時間そのものも難易度に含めない。
- 挑戦は、盤面の形（壁・仕切り・始点）から、角・通路・袋小路のように通り方の決まるマスを見つけて道を確定させ、決まらないときは数手先の破綻（取り残し・分断・輪）を読んで道筋を選ぶこととする。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 角・通路・袋小路を見つければ、道が次々に決まる |
| 2 | 1か所だけ、少し先まで読んで進む向きを選ぶ |
| 3 | 何か所かで、数手先の取り残しを読んで道筋を選ぶ |
| 4 | 開けた領域で、先読みを重ねて道筋を決める |
| 5 | 広い開けた盤面で、長い先読みを何度も重ねないと道筋が決まらない |

- 難易度は、局所の推論（通り方の決まるマスと、道を輪にしないこと）だけで道が決まるか、先読みを要した回数、盤面の大きさの範囲を組み合わせて決め、難易度5 には最も長い先読みの長さも条件に加える。規模だけで難易度が上がる・下がることはない。上の難易度ほど条件の範囲を下げず、隣り合う難易度が共有する盤面の大きさでは、推論だけで難易度が分かれる。
- 先読みの回数と長さは、盤面を回転・反転した向きのうち最も少ない先読みで道が決まる読み順で測る。回転・反転で重なる盤面は同じ難易度になる。
- 先読みは、1つの仮定から破綻までを読むものに限る。仮定を重ねないと決まらない問題は出さない。始点から引き進めて迷う分岐が1つも無い問題も出さない。

## 評価

先を読んで道筋を決め、引き直しを少なく、迷わず速く引き切ることを称える。速さを主にし、先読みを要する問題で引いて確かめることを強く罰しない。

- 速さ 60点: 経過時間を、問題の作業量（なぞるマスの数と、読みが要る量）から決める基準時間と比べる。難易度そのものを基準時間の理由にしない。
- 正確さ 40点: 引き直しで減点する。押し間違いを直した程度の引き直しでは評価段階を大きく落とさない。
- 待ったと盤面を戻すは減点しない。戻した後に別のマスへ引けば、引き直しとして減点される。
- 問題集から引けなくなった記録も、記録した問題の作業量から評価し、自己ベストの比較に使う。

自己ベストでは、評価点は高いほど、基準時間との差と引き直し回数は少ないほど良い値として比べる。
