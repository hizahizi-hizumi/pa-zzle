# SPEC-020 ノノグラム

行と列に並んだ数字（ヒント）を手がかりに盤面のマスを塗り、隠れた図柄を完成させるパズル。

## ルールと問題

- 盤面は幅10列までの正方形か縦長の長方形とし、白黒の2色だけを扱う。図柄は機械で作った模様とし、意味のある絵や題材の名前は持たない。
- 各行の左と各列の上に、その行・列の黒の塊の長さを並びの順に置いたヒントを示す。黒の無い行・列のヒントは `0` とする。
- マスは未確定・塗り・× のいずれかとする。× は塗らないと決めたマスの印で、クリアの判定に使わない。
- 問題は解がただ1つで、1本の行・列のヒントと今のマスから必ず決まるマスを確定させることの繰り返しだけで、仮置きなしに最後まで解けるものに限る。
- 塗ったマスの集合が解の黒マスと一致した時点でクリアとする。× や未確定のマスが残っていてもよい。
- 正誤とミスは数えない。塗ったマスを後から未確定か × に変えたマスの数を、塗り直しとして数える。待ったと盤面を戻すで消えた塗りも、塗り直しに数える。

## 状態の知らせ

- 塗ったマスの並びがヒントにちょうど一致した行・列は、そのヒントを薄くして示す。これは今の盤面だけから決まる状態の知らせ（SPEC-017）とし、未確定と × はどちらも塗っていないマスとして扱う。
- 解と照らした正誤、ヒントの数字ごとの消し込み、空きマスへの自動の ×、行・列の破綻（塗りすぎなど）は示さない。
- 補助は提供しない。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。

## 難易度

- 基準とするプレイは、1本の行・列について、ヒントと今のマスに合う塊の置き方をすべて考え、どの置き方でも同じになるマスを確定させ、試し塗りをせず、待ったと盤面を戻すを使わないプレイとする。図柄の黒マスが多いことによる塗る手数は難易度に含めない。
- 挑戦は、1本の行・列のヒントと決まったマスから確定できるマスを見つけ、その結果が交わる行・列を開く連鎖を、手を付けられる行・列が少ない局面でも見つけ続けて最後までたどることとする。
- 難易度は、連鎖の長さを主に、入口の狭さ（最初に進められる行・列の少なさ）と細い局面（進められる行・列が少ない局面）の多さを組み合わせ、1本の行・列を読む重さ（行・列あたりの塊の数）で分け、盤面の大きさを各難易度で許す範囲として重ねて決める。連鎖が長くても、塊が1つの行・列ばかりの問題は上の難易度に出さない。

| 難易度 | 盤面（幅×高さ） | 挑戦 |
| --- | --- | --- |
| 1 | 7×7、8×8 | 塊が1つの行・列が多く、手を付けられる行・列も多く、数回の読みで埋まる |
| 2 | 8×8、9×9 | 塊が2つの行・列が混ざり、決めたマスを使って次の行・列を開く読みを重ねる |
| 3 | 9×9、10×10 | 塊が1つだけの行・列は少なくなり、連鎖が長くなり、進められる行・列が少ない局面がある |
| 4 | 10×10、10×12 | ほとんどの行・列で2つ以上の塊の置き方を考え、入口が狭く、長い連鎖を、進められる行・列が少ない局面を何度か越えてたどる |
| 5 | 10×12、10×13、10×15 | 行・列あたりの塊が最も多く、入口がさらに狭く、1〜2本しか進めない局面を何度も越えて、最も長い連鎖をたどる |

- 上の難易度ほど連鎖を長くし、行・列あたりの塊の数を多い側へ動かし、入口の狭さと細い局面の多さの条件を緩めず、許す盤面を小さくしない。同じ大きさの盤面を許す隣り合う難易度は、連鎖の長さで分ける。
- 左右対称の図柄は最も易しい難易度だけに出す。それより上の難易度は、左右対称を仮定して読みを省ける図柄を出さない。
- 仮置きなしで解けるが、どの難易度の組み合わせにも当たらない問題は提供範囲外とし、出題しない。解がただ1つでも仮置きが要る問題は評価不能とし、出題しない。
- 各難易度の問題は、事前に作って難易度を判定した問題集から出す。

## 評価

ヒントから読んで確定させてから塗り、迷わず速く図柄を完成させることを称える。× は自由に使うメモとして扱う。

- 速さ 85点: 経過時間を、読む行・列の本数、ヒントの数字の数、塗るマスの数、連鎖の長さから決める基準時間と比べる。難易度そのものを基準時間の理由にしない。
- 正確さ 15点: 塗り直したマスの数で減点する。

× の付け外し、待った・盤面を戻すの回数、入力回数は評価に使わない。問題集から引けなくなった記録も、記録した問題の作業量から評価し、自己ベストの比較に使う。

自己ベストでは、評価点は高いほど、基準時間との差と塗り直したマスの数は少ないほど良い値として比べる。
