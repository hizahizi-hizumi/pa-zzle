# SPEC-020 一筆パズル

穴の開いた正方形の盤面で、始点から上下左右に隣り合うマスへ道を延ばし、穴でないすべてのマスをちょうど1回ずつ通る1本の道を引くパズル。

## ルールと問題

- 穴は盤面に無いマスとし、道は穴へ入れない。外周の穴は盤面の外形を欠く。穴のほかに道を阻むものは置かない。
- 始点だけを示し、終点は示さない。
  - 慣れた利用者が盤面から終点を読めても、読めないようにする手は入れない。
    - 盤面から終点が読めることは、このパズルと切り離せないため。
- 問題は、始点から全マスを通る道がただ1つであるものに限る。
- 問題の盤面は、穴が適度に散らばったものに限る。穴が少なすぎて長方形に近い盤面、大きな空白や穴の片寄りがある盤面、通路だらけの盤面は出さない。
- 道は先端から隣り合うマスへ延ばし、道の途中のマスまで巻き戻して引き直す。離れたマスを指して道を自動で引く操作は持たない。
- 道が全マスを通った時点でクリアとする。
- 一度引いた道を戻し、同じ位置から前と別のマスへ道を引いたことを、引き直しとして数える。どの操作で戻したかによらない。戻して前と同じ道を引き直したことは数えない。別の道筋へ引き直した後に、待ったで元の道筋へ戻したときも、引き直しとして数える。
- なぞりの途中の行き来は、引き直しに数えない。
- 穴に阻まれて道が延びなかったことは数えない。
- 引き直しは評価の正確さに数えるが、ミスとしては扱わない。ミスとして数える操作は持たない。

## 状態の知らせ

- 道が全マスを通る前に、先端から延ばせるマスが無くなったこと（行き止まり）は状態の知らせ（SPEC-017）として示す。
- 道を延ばせなかった操作は、指で隠れやすい先端だけでなく、押した・なぞった先のマスでも阻まれたと分かるように返す。

## 補助

- 難易度1〜3 では、道を延ばした結果、もう全マスを通れないと盤面から分かる状態に入った瞬間に、その原因のマス（入れる隣の無いマス、終点にしかなれないマスが2つ以上できたときのそれらのマス、先端から届かなくなったマス）を、控えめな点線の枠で示す。理由の文は出さない。行き止まりの間は、先端の知らせに任せて示さない。
  - 解けなくなった道を、気づかずに盤面の端まで引き続けて時間を失うことを防ぐため。
- 難易度4・5 では示さない。
  - 開けた盤面で、数手先の取り残しや分断を自分で読み当てることがその難易度の挑戦で、引いた直後に解けなくなったと知らせると、試しに引いて確かめる遊び方へ変わるため。
- 示すのは、進めた直後に見える取り残し・分断（「難易度」の迷う分岐の定義と同じ）だけとし、数手先で初めて破綻する道は示さない。

## チュートリアル

- ルールを伝えながら決まった道を引かせる間も、伝えたルールで阻まれる手（穴へ進む・通ったマスへ進む）は、本番と同じく阻まれたとして返す。
- 決まった道を引き終えて自分で解く間は、穴や通ったマスへ進もうとした手に加え、解から外れて全マスを通れなくなった道も、ルールに合わない手として返す。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。

- 待ったは1マスずつ戻し、押し続けると続けて戻す。延ばした道は先端から1マスずつ消え、巻き戻した道は巻き戻す前の道へ1マスずつ延び直す。
  - なぞり1回をまとめて取り消すと、長くなぞった後の1マスの間違いを直すのに道を大きく失い、引き直す手間が罰になるため。
- 待ったの回数は、なぞり1回などの盤面操作1回分を戻すのに何回押しても、その操作について1回と数える。

## 難易度

- 基準とするプレイは、ルールと操作を理解し、盤面を読んで道筋を決めてから引くプレイとする。行き止まりの知らせは見えてよい。引いて行き詰まってから戻す試行錯誤の量は難易度に含めず、評価に表す。盤面の大きさや通るマスの数だけによる作業量、入力回数や時間そのものも難易度に含めない。
- 挑戦は、盤面の形（穴・始点）から、角・通路・袋小路のように通り方の決まるマスを見つけて道を確定させ、決まらないときは数手先の破綻（取り残し・分断・輪）を読んで道筋を選ぶこととする。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 角・通路・袋小路を見つければ、道が次々に決まる |
| 2 | 局所の推論で止まる所を、出入口が2本の辺の領域を読むか、1か所だけ少し先まで読んで抜ける |
| 3 | 2か所で数手先の取り残しを読むか、1か所で長く先まで読んで道筋を選ぶ |
| 4 | 開けた領域で、先読みを重ねて道筋を決める |
| 5 | 広い開けた盤面で、長い先読みを何度も重ねないと道筋が決まらない |

- 局所の推論で止まった所で、盤面の分かれ方と市松模様の色の数から道を決めることは、先読みではなく盤面から見える推論として扱う。
  - 盤面の分かれ方は、使わないと残りのマスがつながらなくなる辺、1マスで盤面が分かれる所、出入口が2本の辺しかない領域から読む。1マスで分かれた領域のうち、道の端（始点・終点）を含まない側には入っても出られない。出入口が2本の辺しかない領域は、道の端が無ければ通り抜け、終点があればそこで終わる。
  - 市松模様の色の数からは、終点の色と、1マスで分かれた領域を通り切れるかを読む。
- 先読みは、1つの仮定から破綻までを読むものに限る。
- 先読みの重さは、先読みを要した局面の数と、短い先読みでは破綻が見えず長く読んだことから決める。どちらも最も上手な読み順で数え、上手に読めば要らない先読みは数えない。
- 難易度は、局所の推論（通り方の決まるマスと、道を輪にしないこと）だけで道が決まるか、先読みの重さ、盤面の大きさの範囲を組み合わせて決める。規模だけで難易度が上がる・下がることはない。上の難易度ほど条件の範囲を下げず、隣り合う難易度が共有する盤面の大きさでは、推論だけで難易度が分かれる。回転・反転で重なる盤面は同じ難易度になる。
- 仮定を重ねないと決まらない問題と、始点から引き進めて迷う分岐が1つも無い問題は出さない。
  - 迷う分岐は、解の道を始点から引き進める途中で、進めた直後に取り残しや分断（入れないマス、2つ以上の袋小路、先端から届かないマス）が見えない手が2つ以上あり、その中に全マスを通れなくなる手を含む地点とする。

## 評価

先を読んで道筋を決め、引き直しを少なく、迷わず速く引き切ることを称える。速さを主にし、先読みを要する問題で引いて確かめることを強く罰しない。上の難易度の問題は最も上手に読んでも先読みが要るので、引いて確かめること自体を強く罰すると、その遊び方を罰するため。

- 速さ 60点: 経過時間を、問題の作業量（なぞるマスの数と、読みが要る量）から決める基準時間と比べる。難易度そのものを基準時間の理由にしない。
- 正確さ 40点: 引き直しで減点する。押し間違いを直した程度の引き直しでは評価段階を大きく落とさない。
- 待った・盤面を戻すの回数と、戻したマスの数は減点しない。
  - 戻した後に別の向きへ引いたことは、どの操作で戻したかによらず引き直しとして減点するため（「ルールと問題」）。
- 問題集から引けなくなった記録も、記録した問題の作業量から評価し、自己ベストの比較に使う。

自己ベストでは、評価点は高いほど、基準時間との差と引き直し回数は少ないほど良い値として比べる。
