# SPEC-010 マインスイーパー

長方形の盤面に隠れた地雷を、開いたマスの数字と総地雷数から論理的に見極め、地雷ではないマスをすべて開くパズル。

## ルールと問題

- 問題は、推測（確率判断）なしに、見えている数字と総地雷数だけで最後まで解けるものに限る。
- 盤面は正方形か縦長（行数が列数以上）とし、横長にしない。
- 問題は初期開示状態を持ち、利用者は開示済みの盤面から考え始める。利用者の最初の操作で問題は変わらない。
- 総地雷数は、利用者が推論に使える問題の情報として示す。
- 旗は利用者のメモで、置いた時点で正誤を判定せず、クリア条件にも含めない。
- 地雷を踏んでも失敗として終わらず、プレイを続ける。踏んだ地雷以外の地雷配置は、クリアするまで示さない。
- 地雷ではないマスをすべて開いた時点でクリアとし、地雷を踏んでいてもクリアできる。
- 踏んだ地雷の数をミスとして数える。1回の操作で複数の地雷を踏んだときは、その数だけ数える。

## チュートリアル

- 小さな盤面を1枚解くチュートリアル（SPEC-029）を持つ。マスを開くと数字が出る操作を教えた後、難易度1の問題を解く、数字1つで決まる2つの読み（周りの閉じたマスが数字と同じ数なら全部地雷、地雷が全部見つかった数字の周りの残りのマスは地雷ではない）を1つずつ使わせる。手順を終えて任せる盤面にも、2つの読みがそれぞれもう一度要るようにする。
- 決め手のある手順では、初めは押す所に印を付けず、決め手の数字とその周りの閉じたマスだけを覆いから抜き、その中から押す所と操作をプレイヤーに選ばせる。周りのほかの数字は抜かず、どの数字の話かを迷わせない。選び違えたり地雷を踏んだりしたら、押す所に印を付ける。
- 旗を置かせる手順で地雷のマスを開いたときは、1回目だけ本番と同じく地雷を踏ませて、考えずに押すと何が起きるかを見せる。踏んだ地雷は地雷と分かったものとし、残りの地雷には旗を置かせる。
- 手を離した後は、本番と同じく、地雷を踏んでもプレイを続けられ、踏んだマスは踏んだ地雷の面だけで示す。踏んだマスにチュートリアルの合図を重ねない。
- 手を離した後の手がかりは、2つの読みで先に決まるマスを、その決め手の数字と一緒に示す。地雷でないマスに旗が置かれていれば、先にその旗を外させる。

## やり直し

リセットと別の問題を提供する。待ったと盤面を戻すは提供しない。

## 難易度

- 基準とするプレイは、総地雷数と自分の置いた旗の数を見ながら、確率判断を使わず確定したマスだけを開いて進めるプレイとする。旗を使うかどうかと解く速さは難易度に含めない。
- 挑戦は、確定できるマスがどこにあるかを見つけ、数字と総地雷数から安全なマスと地雷を論理的に確定させることとする。

| 難易度 | 挑戦 | 盤面 |
| --- | --- | --- |
| 1 | 数字1つを見れば分かる手だけで解ける | 小さい |
| 2 | 隣り合う2つの数字を見比べて、差から割り出す場面がある | 小さい〜やや広い |
| 3 | 2つの数字の範囲が部分的に重なり、重なりの地雷数から割り出す場面がある | 中程度 |
| 4 | 重なりからの割り出しを繰り返す、または盤面全体の地雷数を数え合わせて割り出す場面がある | 広い |
| 5 | 3つ以上の数字を同時に組み合わせないと割り出せない場面がある | 最も広い |

- 手は、マスを決めるのに同時に組み合わせる数字の数と組み方で、表の挑戦に当てはめる。数字の範囲は、その数字の周りのまだ決まっていないマスとする。総地雷数を使う手は、総地雷数を「まだ決まっていないマス全体に残りの地雷がある」という数字1つとみなしたときの組み方で当てはめる。
  - 数字1つで決まる手と、残りの地雷数だけで決まる手（残りが0、または残りのマスの数と同じ）は、難易度1の手とする。
  - 一方の範囲がもう一方に含まれる2つの数字の差で決まる手と、1つの数字を総地雷数と突き合わせて決まる手は、難易度2の「差から割り出す」手とする。
  - 範囲が部分的に重なる2つの数字で決まる手、範囲の重ならない2つの数字の和を総地雷数と突き合わせて決まる手、1つの数字の範囲の中に範囲の重ならない2つの数字が収まる組み方（「2の中に1が2つ」）で決まる手は、難易度3の「重なり」の手とする。
  - 範囲の重ならない3つ以上の数字や、数字のまとまりの地雷数の組み合わせを総地雷数と突き合わせて決まる手は、組み方によらず難易度4の「盤面全体の地雷数を数え合わせる」手とする。
  - それ以外の、3つ以上の数字を同時に組み合わせて決まる手（1つの数字の範囲に3つ以上の数字が収まる組み方を含む）は、難易度5の手とする。
- 盤面の広さと地雷密度は、確定できるマスを探す範囲と、どの数字の組み合わせが効くかを見抜く考えどころを増やすため、難易度の要因とする。上の難易度ほど盤面を大きく、地雷密度を高くする。盤面の広さや地雷数だけでは難易度を決めない。
- 隣り合う難易度は盤面の大きさが一部重なってよいが、離れた難易度どうしは盤面の大きさと地雷密度の組が重ならない。
- 難易度は、解き切るまでに使わざるを得なかった手のうち最も高い難易度とし、難易度3の手を繰り返し使う問題は難易度4とする。総地雷数を数字と突き合わせる手は、数字だけで決まるマスが無いときにだけ使うものとして数える。その難易度の盤面範囲に入らない問題は出さない。
- 推測なしに解けても、挑戦が薄すぎる問題と重すぎる問題は出さない。

## 評価

地雷を踏まずに確定したマスだけを開いて解き切ることを最も称え、その上で速さを称える。

- 正確性 60点: 踏んだ地雷の数で減点する。
- 速さ 40点: 経過時間を、問題の作業量から決める基準時間と比べる。難易度そのものを基準時間の理由にしない。

地雷を踏まずに解き切ったプレイだけが `perfect` と `great` に届く。地雷を踏んでも、最後まで解き切る価値を残す。

自己ベストでは、評価点は高いほど、基準時間との差とミス数は少ないほど良い値として比べる。
