# SPEC-010 マインスイーパー

マインスイーパーは、長方形の盤面に隠れた地雷を、開いたマスの数字と総地雷数から論理的に見極め、地雷ではないマスをすべて開くゲームとして提供する。

## 問題

問題は、推測（確率判断）なしに、見えている数字と総地雷数だけで最後まで安全なマスと地雷を確定させて解けるものに限る。問題の成立性の確認と、利用者向け難易度の判定は別の責務として扱う。

問題は初期開示状態を持つ。利用者は画面表示直後の初期開示済みの盤面から考え始め、利用者の最初の操作によって問題は変わらない。

盤面全体の総地雷数は、利用者が推論に使える問題情報とする。

## プレイ

利用者は未開示マスを開く操作と、未開示マスへ旗を置く・外す操作を行える。

- 開いたマスは周囲8マスの地雷数を示す。周囲に地雷がないマスを開いた場合は、周囲のマスも続けて開く。
- 地雷のマスを開いた場合は、失敗として終了せずにプレイを続ける。開いた地雷のマスは踏んだ地雷として盤面に残し、以後は開く操作も旗の操作もできない。踏んだ地雷以外の地雷配置は示さない。
- 旗は利用者のメモであり、置いた時点で正誤を判定せず、クリア条件にも含めない。旗を置いたマスは、旗を外すまで開かない。
- 開くモードで開いた数字のマスを押したとき、周囲の旗と踏んだ地雷の合計がその数字と一致していれば、周囲の旗のない未開示マスをまとめて開く。この操作は開く操作の短縮であり、新しい情報を与えない。旗が誤っていれば、まとめて開いたマスに含まれる地雷をすべて踏む。

盤面を押したときの操作は、ヘッダーのトグルで「開く」と「旗」を切り替える。長押しと右クリックは、選択中のモードによらず旗を置く・外す操作とする。

地雷ではないマスをすべて開いた時点でクリアとする。地雷を踏んでいてもクリアできる。

踏んだ地雷の数をミスとして記録する。1回の操作で複数の地雷を踏んだ場合は、踏んだ地雷の数だけ記録する。プレイ中は総地雷数、置いた旗の数、ミス数、経過時間を示す。経過時間はプレイ開始からクリアまでを計る。

ヒント、自動で旗を置く機能、確定できるマスの提示は通常UIで提供しない。

プレイ中は同じ問題のやり直しと新しい問題の開始を提供する。どちらも新しいプレイとして始め、ミス数と経過時間を数え直す。

スマートフォンでも盤面全体をパン・ズームなしに一つの視野で表示・操作できるよう、提供する盤面は最大 16行×12列 とする。

## 難易度

難易度は `レベル 1`〜`レベル 5` の5段階とする。問題難易度は、ルールと基本操作を理解し、総地雷数と自分の置いた旗の数を見ながら、ヒントや確率判断を使わず、確定したマスだけを開いて進めるプレイを基準にする。旗を使うかどうか、解く速さは問題難易度に含めない。

各難易度で利用者が出会う挑戦は次のとおりとする。

| 難易度 | 挑戦 | 盤面 |
| --- | --- | --- |
| 1 | 数字1つを見れば分かる手だけで解ける | 小さい |
| 2 | 隣り合う2つの数字を見比べて、差から割り出す場面がある | 小さい〜やや広い |
| 3 | 2つの数字の範囲が部分的に重なり、重なりの地雷数から割り出す場面がある | 中程度 |
| 4 | 重なりからの割り出しを繰り返す、または盤面全体の地雷数を数え合わせて割り出す場面がある | 広い |
| 5 | 3つ以上の数字を同時に組み合わせないと割り出せない場面がある | 最も広い |

難易度ごとに盤面サイズと地雷密度の範囲を持ち、上の難易度ほど盤面を大きく、地雷密度を高くする。盤面の広さや地雷数そのものを難易度とはみなさず、どの数字の組み合わせが効くかを見抜く負担が推論と一緒に上がるよう、推論の段階に合わせた盤面範囲を選ぶ。

### 判定

難易度は、問題を人間向けの推論で解き進める過程を分析して判定する。各局面で最も単純な推論から順に確定できるマスを探し、解き切るまでに使わざるを得なかった推論の段階と回数を観測する。推論の段階は、数字1つ、2つの数字の包含、2つの数字の重なり、3つ以上の数字の組み合わせ、総地雷数の利用を区別する。

難易度は、推論の段階から決まる難易度と、その難易度の盤面範囲に盤面サイズと地雷数が入ることの組で決める。推論の段階だけで決まる難易度の盤面範囲に入らない問題は、その難易度として提供しない。

分析結果は、次の状態を区別して扱う。

- 成立しない: 推測なしでは解き切れない。提供しない。
- 評価不能: 推測なしで解き切れるが、分析で扱える推論の範囲を超える、または計算を打ち切った。高難易度と推定せず、提供しない。
- 提供範囲外: 分析できるが、挑戦が軽すぎる、重すぎる、または盤面が推論で決まる難易度の盤面範囲に入らない。提供しない。
- 難易度1〜5: 分析でき、提供範囲に入る。

正確な特徴量、閾値、盤面サイズ・地雷密度の範囲はコードを正とする。

### 供給

各難易度の問題は、判定済みの問題を事前に生成した問題集から供給する。プレイ開始時に seed を定め、その seed で選んだ難易度の問題集から1問を選ぶ。同じ seed と同じ問題集からは同じ問題を選ぶ。

選んだ問題は、盤面を再現するための情報とともに扱い、同じ問題のやり直しでは同じ問題を初期開示から始める。新しい問題の開始と難易度の選び直しでは、新しい seed で問題を選ぶ。

## 成績評価

クリアしたプレイだけを評価し、1プレイを100点満点で評価する。推測なしで解ける問題だけを提供するため、地雷を踏まずに確定したマスだけを開いて解き切ることを最も称え、その上で速さを称える。

- 正確性 60点: 踏んだ地雷1つにつき15点を減点する。
- 速さ 40点: 盤面把握5秒、開く操作の最小回数1回あたり2秒、地雷1つあたり4秒を合計した基準時間を満点基準とし、超過に応じて線形に減点する。基準時間の2倍で0点とする。

各項目は0点から満点の範囲とする。合計100点を `perfect`、90点以上を `great`、80点以上を `good`、それ未満のクリアを `clear` とする。

開く操作の最小回数は、問題の初期開示状態から、旗もまとめて開く操作も使わずに地雷ではないマスをすべて開くのに要る開く操作の回数とし、未開示の0のマスは連鎖で開く範囲ごとに1回、どの連鎖にも含まれない数字のマスは1マスごとに1回と数える。基準時間は問題の作業量だけから決め、難易度そのものを加点や基準時間の理由にしない。

地雷を踏まずに解き切ったプレイだけが `perfect` と `great` に届く。地雷を1つ踏んだプレイは速さによらず最高で `good` とし、踏んだ地雷の数に応じて評価を下げる。1つのミスで評価段階を大きく落としすぎず、踏んだ後も最後まで解き切る価値を残す。

記録するプレイ事実は、難易度、問題を再現するための情報、経過時間、ミス数、開く操作の最小回数とする。評価点、評価段階、基準時間との差は保存した事実から現在の評価規則で導出する。

履歴と自己ベストの比較単位は難易度とする。自己ベストとして、評価点は高いほど、問題ごとの速さ満点基準時間に対するクリア時間の差とミス数は少ないほど良い値として比較する。

結果では、評価点と評価段階に続けて、経過時間と基準時間との差、ミス数をマインスイーパーの主要成績として扱う。評価の内訳と基準時間の根拠は主結果と分けて確認できるようにする。履歴では、評価点、基準時間との差、ミス数を難易度ごとに比較する主要指標として扱う。
