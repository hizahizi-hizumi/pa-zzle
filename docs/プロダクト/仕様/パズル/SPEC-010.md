# SPEC-010 マインスイーパー

マインスイーパーは、長方形の盤面に隠れた地雷を、開いたマスの数字と総地雷数から論理的に見極め、地雷ではないマスをすべて開くゲームとして提供する。スマートフォンでも盤面全体をパン・ズームなしに一つの視野で表示・操作できるよう、盤面は最大 16行×12列 とする。

## 問題

問題は、推測（確率判断）なしに、見えている数字と総地雷数だけで最後まで安全なマスと地雷を確定させて解けるものに限る。

問題は初期開示状態を持つ。初期開示は、周りに地雷の無い開始マスから続けて開く範囲とする。利用者は初期開示済みの盤面から考え始め、利用者の最初の操作によって問題は変わらない。

盤面全体の総地雷数は、利用者が推論に使える問題の情報とする。

## プレイ

利用者は、未開示マスを開く操作と、未開示マスへ旗を置く・外す操作を行える。

- 開いたマスは周囲8マスの地雷数を示す。周囲に地雷がないマスを開いたときは、周囲のマスも続けて開く。
- 地雷のマスを開いても、失敗として終了せずにプレイを続ける。開いた地雷のマスは踏んだ地雷として盤面に残し、以後は開く操作も旗の操作もできない。踏んだ地雷以外の地雷配置は、クリアするまで示さない。
- 旗は利用者のメモであり、置いた時点で正誤を判定せず、クリア条件にも含めない。旗を置いたマスは、旗を外すまで開かない。
- 開くモードで開いた数字のマスを押したとき、周囲の旗と踏んだ地雷の合計がその数字と一致していれば、周囲の旗のない未開示マスをまとめて開く。この操作は開く操作の短縮であり、新しい情報を与えない。旗が誤っていれば、まとめて開いたマスに含まれる地雷をすべて踏む。

盤面を押したときの操作は、「開く」と「旗」のモード切り替えで選ぶ。長押しと右クリックは、選んでいるモードによらず旗を置く・外す操作とする。

地雷ではないマスをすべて開いた時点でクリアとする。地雷を踏んでいてもクリアできる。クリアした後は、旗を置いていない地雷も含めて、すべての地雷の位置を盤面に示す。利用者が置いた旗はそのまま残す。

踏んだ地雷の数をミスとして数える。1回の操作で複数の地雷を踏んだときは、踏んだ地雷の数だけ数える。

プレイ中は総地雷数、置いた旗の数、ミス数、経過時間を示す。

### やり直し

プレイ中は、リセットと別の問題を提供する。待ったと盤面を戻すは提供しない。

## 難易度

問題難易度は、ルールと基本操作を理解し、総地雷数と自分の置いた旗の数を見ながら、確率判断を使わず、確定したマスだけを開いて進めるプレイを基準にする。旗を使うかどうか、解く速さは問題難易度に含めない。

マインスイーパーの挑戦は、盤面のどこに確定できるマスがあるかを見つけ出し、見えている数字と総地雷数から安全なマスと地雷を論理的に確定させることとする。各難易度で利用者が出会う挑戦は次のとおりとする。

| 難易度 | 挑戦 | 盤面 |
| --- | --- | --- |
| 1 | 数字1つを見れば分かる手だけで解ける | 小さい |
| 2 | 隣り合う2つの数字を見比べて、差から割り出す場面がある | 小さい〜やや広い |
| 3 | 2つの数字の範囲が部分的に重なり、重なりの地雷数から割り出す場面がある | 中程度 |
| 4 | 重なりからの割り出しを繰り返す、または盤面全体の地雷数を数え合わせて割り出す場面がある | 広い |
| 5 | 3つ以上の数字を同時に組み合わせないと割り出せない場面がある | 最も広い |

難易度ごとに盤面サイズと地雷密度の範囲を持ち、上の難易度ほど盤面を大きく、地雷密度を高くする。盤面が広く地雷が密になるほど、確定できるマスを探す範囲が広がり、どの数字の組み合わせが効くかを見抜く考えどころが増えるため、推論の段階に合わせて盤面の範囲を選ぶ。盤面の広さや地雷数だけでは難易度を決めない。

難易度の選択肢には、開いた数字のマスと地雷を描いた3行の小さな図を添え、上のレベルほど列と地雷を増やして数字を大きくする。図は実際の問題ではない。

### 判定

難易度は、問題を人間向けの推論で解き進める過程を分析して判定する。各局面で最も単純な推論から順に確定できるマスを探し、解き切るまでに使わざるを得なかった推論の段階と回数を観測する。推論の段階は、数字1つ、2つの数字の包含、2つの数字の重なり、3つ以上の数字の組み合わせ、総地雷数の利用を区別する。総地雷数を使う推論は、突き合わせる数字の数に応じて、同じ構造の数字どうしの推論と同じ段階として数える。

難易度は、推論の段階から決まる難易度と、その難易度の盤面範囲に盤面サイズと地雷数が入ることの組で決める。推論の段階だけで決まる難易度の盤面範囲に入らない問題は、その難易度として提供しない。盤面の回転・反転で判定は変わらない。

分析結果は、次の状態を区別して扱う。

- 成立しない: 推測なしでは解き切れない。提供しない。
- 評価不能: 推測なしで解き切れるが、分析で扱える推論の範囲を超える、または計算を打ち切った。高難易度と推定せず、提供しない。
- 提供範囲外: 分析できるが、挑戦が軽すぎる、重すぎる、または盤面が推論で決まる難易度の盤面範囲に入らない。提供しない。
- 難易度1〜5: 分析でき、提供範囲に入る。

正確な特徴量、閾値、盤面サイズ・地雷密度の範囲はコードを正とする。

### 供給

各難易度の問題は、判定済みの問題を事前に生成した問題集から供給する。プレイ時には問題の生成と難易度の判定を行わない。

## 成績評価

推測なしで解ける問題だけを提供するため、地雷を踏まずに確定したマスだけを開いて解き切ることを最も称え、その上で速さを称える。

- 正確性 60点: 踏んだ地雷1つにつき15点を減点する。
- 速さ 40点: 盤面把握5秒、開く操作の最小回数1回あたり2秒、地雷1つあたり4秒を合計した基準時間以内で満点、基準時間の2倍以上で0点とし、その間は経過時間に応じて線形に減点する。

各項目は1点単位とし、0点から満点の範囲とする。

開く操作の最小回数は、問題の初期開示状態から、旗もまとめて開く操作も使わずに地雷ではないマスをすべて開くのに要る開く操作の回数とする。未開示の0のマスは連鎖で開く範囲ごとに1回、どの連鎖にも含まれない数字のマスは1マスごとに1回と数える。基準時間は問題の作業量だけから決め、難易度そのものを加点や基準時間の理由にしない。

地雷を踏まずに解き切ったプレイだけが `perfect` と `great` に届く。地雷を1つ踏んだプレイは速さによらず最高で `good` とし、踏んだ地雷の数に応じて評価を下げる。1つのミスで評価段階を大きく落としすぎず、踏んだ後も最後まで解き切る価値を残す。

### 記録と自己ベスト

記録するプレイ事実は、経過時間、ミス数、開く操作の最小回数とする。

自己ベストでは、評価点は高いほど、基準時間との差とミス数は少ないほど良い値として比べる。

### 結果

結果では、評価点と評価段階に続けて、経過時間と基準時間との差、ミス数を主な成績として示す。評価の内訳と基準時間の根拠は、主な成績と分けて確認できるようにする。
