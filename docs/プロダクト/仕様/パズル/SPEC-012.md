# SPEC-012 バイナリパズル

8×8 の盤面の空きマスに2種類のタイルを置き、各行・各列で2種類を同数にし、同じタイルを縦・横に3つ以上続けず、同じ並びの行どうし・列どうしを作らない配置へ完成させるパズル。

## ルールと問題

- 問題は固定の初期配置と一意な完成解を持ち、推測（仮置きと後戻り）なしに、1本の行・列を読む推論だけで最後まで解けるものに限る。初期配置のマスは利用者が変更できない。
- 全マスが埋まり、ルール違反が無い時点でクリアとする。
- 一度置いたタイルを後から別のタイルや空きへ変えた回数を、置き直しとして数える。同じマスを続けて押している間は、別のマスを押すまでを1回の入力とみなし、押し始める前のタイルと比べて置き直しかを決める。なぞって置いたマスは、空きマスにだけ置くので置き直しに数えない。待ったで取り消した操作と、盤面を戻して消えたマスは置き直しに数えない。

## 状態の知らせ

- ルール違反は、状態の知らせ（SPEC-017）として印で示す。印は控えめにし、平常時の盤面を騒がしくしない。
  - 同じタイルが3つ以上続く違反は、そのマスごとに示す。個数超過と同じ並びの重複は、行・列全体の違反として、マスには印を付けず、行・列ごとに示す。
    - 直す必要のないタイルまで誤りに見せないためと、マスごとに示す3連続の違反と見分けるため。
  - 違反の印は、少し待ってから出し、消すときは待たない。出た瞬間に1回だけ脈打たせてから、控えめな姿に戻す。
    - 同じマスを続けて押してタイルを切り替える途中で一瞬だけ違反になっても、印がちらつかないようにするため。控えめな印だけでは、盤面の外の短い線に気づけないため。
- 行・列が違反なく埋まりきった瞬間、その行・列のマスを端から順に軽く光らせ、短い音を1つ鳴らす。行と列が同時に埋まっても音は1つにする。盤面が完成した手では、クリアの演出に任せる。
  - 1本ずつ埋めていく途中に、区切りの手応えを返すため。今の盤面のルールだけで決め、置いたタイルが解と合うかは明かさない。
- 固定マスを押して何も変わらなかったことは、そのマスだけの小さな横揺れで返す。

## 操作

- 指でなぞると、なぞり始めのマスを1回押したのと同じに切り替え、そのタイルを、なぞって通った空きマスに置く。タイルのあるマスと固定マスは変えない。なぞり始めのマスを空きにしたなぞりでは、通ったマスを変えない。なぞり1回は、待った1回で全体を戻す。
  - 丸を続けて置くのに毎回2回押す手間を減らすため。なぞりで置いたタイルを直す手間と待ったの回数が増えて採点で損をしないよう、空きマスにだけ置き、待った1回で戻せるようにする。

## チュートリアル

- ルールを1つずつ、まず行に、次に列に当てはめて、小さな盤面を1枚解くチュートリアルを持つ。
- 手を引く手順は、それぞれ新しい見方（どのルールを、行と列のどちらに当てはめるか）を1つだけ使わせ、印を付けるマスは、前の手順までに使わせた見方だけでは決まらないマスにする。丸を入れる手は途中で四角を置いた盤面を通るので、その途中の盤面も、まだ伝えていないルールに当たらないマスを選ぶ。
- 違反は本番と同じ印で示し、タイルを揺らさない。揺れは本番と同じく、固定マスを押したときだけにする。ただし、まだ伝えていない見方の違反は見せない。手順のマスを正しい手へ向かう途中にした直後は、責めないよう違反を見せず、途中の盤面のまま手が止まったら見せる。
- 違反を伝える一言は、直前に置いたマスが当たっている違反を先に言う。
  - 古い違反が残っていても、今の手の結果を返すため。
- 手を離した後は、手が止まったときに、今の盤面と手に入れたルールだけで決まるマスを示し、本番と同じく、置いたタイルが解と合うかは明かさない。違反がある間は、直すことに向かわせるため示さない。解と違うタイルのせいで、ルールだけで決まるマスが無くなったときに限り、手詰まりのままにしないよう、そのタイルのマスを示す。
  - 解と違うタイルは、ルールを当てはめていけば違反として盤面に現れるため。

## やり直し

待った、盤面を戻す、リセット、別の問題を提供する。

## 難易度

- 基準とするプレイは、ルール違反の表示に頼らずに盤面を読んで確定したマスだけを置き、仮置きと後戻りをしないプレイとする。入力回数や時間そのものは難易度に含めない。
- 挑戦は、次に確定できるマスを見つけ、局所の形で決まらないときは行・列全体を読んで確定させることとする。
- マスを確定させる推論は、浅い順に次の5段階とする。どれも1本の行・列の中だけで読む推論で、2本以上の行・列を組み合わせる推論は扱わない。
  - 問題をこの推論で解き切れるものに限る（ルールと問題）のは、それより先の推論が要る問題では挑戦の強さを評価できないため。

| 段階 | 確定のしかた |
| --- | --- |
| A 隣接・挟み | 3マスの並びに同じタイルが2つあれば、残る1マスは反対のタイルにする |
| B 個数の完成 | 行・列に片方のタイルが半分そろえば、残りの空きマスは反対のタイルにする |
| C 残り1個 | 片方のタイルが残り1個の行・列で、その1個を置ける位置を読む |
| D 重複の回避 | C と同じ行・列で、同じ向きの完成した行・列と同じ並びになる置き方も除いて読む |
| E 一般の行候補 | 両方のタイルが残り2個以上の行・列で、ルールを満たし、同じ向きの完成した行・列と同じにならない並びを読み比べる |

- 難易度は、解き切るまでに使わざるを得なかった最も深い推論の段階と、それが要った局面の数で判定する。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 並んだ2つの両隣・挟まれた1つを埋める形を見つければ、次々に決まっていく |
| 2 | 行・列のタイルを数え、半数そろった方の反対で残りを埋める場面がある |
| 3 | 行・列に残り1個のタイルを、どこに置けるか読む場面がある |
| 4 | 完成した行・列と同じ並びにならないよう読む場面が1度ある |
| 5 | 完成した行・列との見比べが何度も要る、または残りの多い行・列で並びを読み比べる場面がある |

- 盤面を数巡見るだけで解き終わる問題は、次の一手を探す挑戦がほとんど無いので出さない。
- 空きマスの数は難易度の根拠にしない。空きマスの多さで難易度を見分けられないよう、全難易度で同じ範囲の空きマスの数の問題を出す。

## 評価

盤面を読んで確定したマスだけを置き、置き直しをせずに解き切ることを最も称え、その上で速さを称える。

- 正確性 60点: 置き直し、盤面を戻す、待ったで減点する。推測なしに解ける問題だけを出すので、読みの正確さを速さより重くする。
  - 置き直しは、押し間違いを直した程度（2回まで）なら great に残り、試し置きを重ねて5回以上直したプレイは速さによらず good に届かない重さにする。
  - 盤面を戻すは、1回戻せばほかが完璧でも最高で good とする重さにする。戻して消えたマスは置き直しに数えないので、試し置きの跡を消せる分を含めて重くする。
  - 待ったは、取り消した操作を置き直しに数えないので、押し間違いをすぐ取り消したプレイを置き直したプレイより軽く扱い、試し置きを待ったで戻し続けたプレイにも回数に応じた減点を残す重さにする。
- 速さ 40点: 経過時間を、問題の作業量から決める基準時間と比べる。難易度そのものを基準時間の理由にしない。

入力回数とルール違反の発生は評価に使わない。問題集から引けなくなった記録も、記録した問題の作業量から評価し、自己ベストの比較に使う。

自己ベストでは、評価点は高いほど、基準時間との差と置き直し回数は少ないほど良い値として比べる。
