# SPEC-012 バイナリパズル

バイナリパズルは、8×8 の盤面の空きマスに2種類のタイルを置き、各行・各列で2種類を同数にし、同じタイルを縦・横に3つ以上続けず、同じ並びの行どうし・列どうしを作らない配置へ完成させるゲームとして提供する。盤面の大きさは難易度や開始条件によって変えない。

画面に表示する名称は「バイナリパズル」とする。同じパズルの通称である「タクズ」（Takuzu）や Binairo は、画面に表示する名称に使わない。

## 問題

問題は固定の初期配置と一意な完成解を持ち、推測（仮置きと後戻り）なしに、1本の行・列を読む推論だけで最後まで解けるものに限る。問題の成立性の確認と、利用者向け難易度の判定は別の責務として扱う。

初期配置のタイルを置いたマス（固定マス）は、利用者が変更する対象ではない。

## プレイ

盤面は、既存のゲームと同じく装飾の無い平らな格子として表す。2種類のタイルは数字ではなく、塗りの四角と輪郭の丸という形の違うタイルとして表し、色を見なくても形だけで区別できるようにする。2種類のタイルに別々の色は持たせない。固定マスのタイルと利用者が置いたタイルは同じ形・同じ大きさとし、色の濃淡だけで見分けられるようにする。

固定マス以外のマスを押すたびに、空き → 一方のタイル → もう一方のタイル → 空き の順に巡回する。入力モードの切り替えは持たない。PC では右クリックで逆順に巡回し、キーボードではマスを移動して各タイルと空きを直接置ける。固定マスを押しても盤面は変わらず、押せないことを小さな動きで返す。

盤面だけから分かるルール違反は、その場で盤面に示す。ルール違反は、同じタイルの3つ以上の連続、行・列で片方のタイルが半数を超えること、全マスが埋まった行どうし・列どうしの並びの一致とする。3連続は、続いているマスの地を控えめに染めて示す。個数超過と重複は行・列全体の違反として、マスには示さず、盤面の縁の外で行・列の両端に細い印で示す。直す必要のないタイルまで誤りに見せないためである。印は平常時の盤面を騒がしくしない強さにとどめ、アプリ共通のエラーとは別のゲーム固有の表現にする。巡回の途中で一瞬だけ生じる違反が点滅して見えないよう、印は違反が生じてから短く待って出す。完成解との照合結果は表示も計数もしない。2値のパズルでは、照合結果を示すことが答えを示すことになるためである。

ルールと操作は、盤面と同じ見た目の小さな図と短い文で示す遊び方として、プレイ中と難易度の選択時に確認できるようにする。

全マスが埋まり、ルール違反が無い時点でクリアとする。問題は一意解を持つため、これは完成解との一致と同じ意味になる。失敗して終わる条件は無い。

一度置いたタイルを後から別のタイルや空きへ変えた回数を、置き直しとして記録する。同じマスを続けて押している間は1回の入力として扱い、別のマスを押した時点で、そのマスを押し始める前の中身と比べて置き直しかどうかを決める。空きマスを続けて押してタイルを選ぶ間と、盤面を戻して消えたマスは置き直しに数えない。

プレイ中は「待った」で、直前の盤面操作を1つずつ取り消せる。待ったで取り消した操作は置き直しに数えず、置き直し回数も取り消す前の値へ戻す。待った回数は記録する。盤面を戻した後は、盤面を戻す前の操作を取り消せない。クリア後は取り消せない。待ったは、ウォーターソートと同じ見た目・位置のボタンとして画面下部の中央に置き、取り消せる操作が無いときは押せない状態で示す。

プレイ中は置き直し回数、経過時間、待った回数を示す。置き直し回数は、押している途中のマスを離れたときに数える分も含めて示し、結果の値と食い違わせない。経過時間はプレイ開始からクリアまでを計る。盤面を戻した回数はプレイ中に示さない。

ヒント、確定できるマスの提示・自動入力、行・列ごとのタイル数の表示は通常UIで提供しない。

プレイ中は、盤面を戻す操作、同じ問題のやり直し（画面の「リセット」）、新しい問題の開始を提供する。盤面を戻す操作は、同じプレイを続けたまま盤面を初期配置へ戻し、経過時間とそれまでの置き直し回数・待った回数を引き継ぎ、戻した回数を数える。同じ問題のやり直しと新しい問題の開始は新しいプレイとして始め、置き直し回数、盤面を戻した回数、待った回数、経過時間を数え直す。

## 難易度

難易度は `レベル 1`〜`レベル 5` の5段階とする。問題難易度は、ルールと巡回の操作を理解し、ヒントや個数表示を使わず、ルール違反の表示に頼らずに盤面を読んで確定したマスだけを置き、仮置きと後戻りをしないプレイを基準にする。空きマスの数、解くまでの入力回数や時間そのものは問題難易度に含めない。

バイナリパズルの挑戦は、盤面から次に確定できるマスを見つけ、局所の形で決まらないときは行・列全体を読んで確定させることとする。各難易度で利用者が出会う挑戦は次のとおりとし、上の難易度ほど必要な読みの種類が深くなる。

| 難易度 | 挑戦 |
| --- | --- |
| 1 | 並んだ2つの両隣・挟まれた1つを埋める形を見つければ、次々に決まっていく |
| 2 | 行・列のタイルを数え、半数そろった方の反対で残りを埋める場面がある |
| 3 | 行・列に残り1個のタイルを、どこに置けるか読む場面がある |
| 4 | 完成した行・列と同じ並びにならないよう読む場面が1度ある |
| 5 | 完成した行・列との見比べが何度も要る、または残りの多い行・列で並びを読み比べる場面がある |

難易度の選択肢には、その難易度で初めて要る読みの局面を、読みに関わる行だけの小さな図として読む前の状態で示す。その読みで決まるマスは空きマスのまま目立たせ、答えのタイルを置いた図にしない。全マスが埋まった行は、見比べる相手の完成した行だけとし、読む行より控えめに示す。

### 判定

難易度は、問題を人間向けの推論で解き進める過程を分析して判定する。各局面で最も浅い推論から順に確定できるマスを探し、解き切るまでに使わざるを得なかった推論の段階と、その推論が要った局面の数を観測する。推論の段階は、隣接・挟みの形、行・列の個数の完成、残り1個の置き場所、完成済みの行・列との重複の回避、残りの多い行・列の並びの比較を区別する。どの推論も1本の行・列の中で読むもので、2本以上の行・列を組み合わせる推論は扱わない。

分析結果は、次の状態を区別して扱う。

- 成立しない: 解が無い、または2つ以上ある。提供しない。
- 評価不能: 一意解だが、1本の行・列を読む推論では解き切れない。高難易度と推定せず、提供しない。
- 提供範囲外: 分析できるが、局所の形を数巡埋めるだけで解き終わり、挑戦が軽すぎる。提供しない。
- 難易度1〜5: 分析でき、提供範囲に入る。

空きマスの数は難易度の根拠にしない。空きマスの多さで難易度を見分けられないよう、全難易度で同じ空きマスの範囲に入る問題だけを供給する。

正確な特徴量、閾値、空きマスの範囲はコードを正とする。

### 供給

各難易度の問題は、判定済みの問題を事前に生成した問題集から供給する。回転・反転と2種類のタイルの入れ替えで一致する問題は同じ問題として扱い、問題集に重複させない。プレイ開始時に seed を定め、その seed で選んだ難易度の問題集から1問を選ぶ。同じ seed と同じ問題集からは同じ問題を選ぶ。

選んだ問題は、問題を再現するための情報とともに扱い、同じ問題のやり直しでは同じ問題を初期配置から始める。新しい問題の開始と難易度の選び直しでは、新しい seed で問題を選ぶ。

## 成績評価

クリアしたプレイだけを評価し、1プレイを100点満点で評価する。推測なしで解ける問題だけを提供するため、盤面を読んで確定したマスだけを置き、置き直しをせずに解き切ることを最も称え、その上で速さを称える。

- 正確性 60点: 置き直し1回につき5点、盤面を戻す1回につき15点、待った1回につき2点を減点する。
- 速さ 40点: 盤面把握10秒、空きマス1つあたり2秒、局面1つあたり3秒、行・列全体を読む局面1つあたり10秒を合計した基準時間を満点基準とし、超過に応じて線形に減点する。基準時間の2倍で0点とする。点は1点単位に四捨五入する。

各項目は0点から満点の範囲とする。合計100点を `perfect`、90点以上を `great`、80点以上を `good`、それ未満のクリアを `clear` とする。

入力回数とルール違反の発生は評価に使わない。

局面の数は、判定と同じ人間向けの推論でその問題を解き切るまでに、次に確定できるマスを探し直す回数とする。行・列全体を読む局面の数は、そのうち残り1個の置き場所、重複の回避、並びの比較のいずれかが要った局面の数とする。どちらも問題の性質として問題ごとに定まる。基準時間は問題の作業量だけから決め、難易度そのものを加点や基準時間の理由にしない。

置き直しも盤面を戻すことも待ったもなく、速さが満点になる時間で解いたプレイだけが `perfect` に届く。速さの点は四捨五入するため、基準時間をわずかに超えても満点になる範囲がある。押し間違いを直した程度の置き直しでは評価段階を大きく落とさない。待ったの減点はナンプレと同じ重さとし、押し間違いを待ったで取り消したプレイは置き直したプレイより軽く扱う。盤面を戻すと消えたマスは置き直しに数えないため、盤面を戻す1回の減点を重くし、盤面を戻したプレイは速さによらず最高で `good` とする。

記録するプレイ事実は、難易度、問題を再現するための情報、問題の作業量（空きマスの数、局面の数、行・列全体を読む局面の数）、経過時間、置き直し回数、盤面を戻した回数、待った回数、入力回数とする。待った回数を持たない記録は、待った0回として扱う。評価点、評価段階、基準時間、基準時間との差は保存した事実から現在の評価規則で導出する。

生成器の版が変わるなどして記録の問題を問題集から引けなくなっても、その記録は履歴と自己ベストに残し、記録した問題の作業量から評価する。そうした記録は、同じ問題を遊び直せない記録とする。

履歴と自己ベストの比較単位は難易度とする。自己ベストとして、評価点は高いほど、問題ごとの速さ満点基準時間に対するクリア時間の差と置き直し回数は少ないほど良い値として比較する。

結果では、評価点と評価段階に続けて、経過時間と基準時間との差、置き直し回数、待った回数をバイナリパズルの主要成績として扱う。盤面を戻した回数、評価の内訳と基準時間の根拠は主結果と分けて確認できるようにする。履歴では、評価点、基準時間との差、置き直し回数を難易度ごとに比較する主要指標として扱う。
