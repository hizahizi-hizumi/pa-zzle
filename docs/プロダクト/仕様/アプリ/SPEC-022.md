# SPEC-022 アプリの入口

アプリを開いてから最初の操作で効果音が鳴るように、遊び始める前に効果音を用意する決まり。

- ホームを開いて文書を読み込んだときだけ、ホームの上にタイトルを出す。アプリの中でホームへ移ったときと、ホーム以外の画面を開いたときは出さない。
- タイトルでは、アプリが鳴らしうる効果音すべての読み込みを待ち、待っている間は進みを示す。待ち終えるまでは入れない。
- 待つ時間には上限を設ける。上限を過ぎたときと読み込めない音があったときは、待ち終えたものとし、間に合わなかった音は鳴らさないまま進める。
- 効果音を鳴らさない設定（SPEC-019）では待たない。待っている間に鳴らさない設定へ変えたら、待ち終えたものとする。
- 待ち終えたら、画面のどこを押してもホームへ入れる。ゲームのピクトグラムを押したときは、そのゲームのホームへ直接入る。
- ホーム以外の画面を開いたときも、開いたときに効果音すべての読み込みを始める。
