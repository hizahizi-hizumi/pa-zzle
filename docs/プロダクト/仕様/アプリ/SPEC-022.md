# SPEC-022 アプリの入口

アプリを開いてから最初の操作で効果音が鳴るように、遊び始める前に効果音を用意する決まり。

- ホームを開いて文書を読み込んだときだけ、ホームの上にタイトルを出す。アプリの中でホームへ移ったときと、ホーム以外の画面を開いたときは出さない。
- タイトルでは、アプリが鳴らしうる効果音すべての読み込みを待ち、待っている間は進みを示す。待ち終えるまでは入れない。
- 待つ時間には上限を設ける。上限を過ぎたときと読み込めない音があったときは、待ち終えたものとし、間に合わなかった音は鳴らさないまま進める。
- 効果音の音量が 0（SPEC-019）のときは待たない。待っている間に音量を 0 にしたら、待ち終えたものとする。音量を 0 から上げても待ち直さない。
- BGM の曲は取得中も届いた分から流せるので、待つのは効果音だけとし、BGM の曲は待たない。タイトルの間は BGM を流さず、入った先の画面の曲から流し始める。
- タイトルでも、ホームと同じ設定で効果音と BGM の音量（SPEC-019）を選べる。設定を開く操作と、設定の中の操作では入らない。
- 待ち終えたら、画面のどこを押しても、決定のキーを押してもホームへ入れる。ゲームのピクトグラムを押したときは、そのゲームのホームへ直接入る。
- ホーム以外の画面を開いたときも、開いたときに効果音すべての読み込みを始める。
