# SPEC-001 プレイ履歴

プレイ履歴は、クリアしたプレイで実際に起きた事実を後から振り返るための記録とする。

## 記録するもの

クリアしたプレイだけを履歴として確定し、1回のプレイ（SPEC-007）を1件として記録する。同じプレイを二重に記録しない。各記録から、少なくともゲーム、難易度、遊んだ問題、開始日時と完了日時、そのゲームの評価・振り返りに必要なプレイ事実を識別できるようにする。記録するプレイ事実はゲームごとに決め、パズル仕様に書く。

評価点、評価段階、自己ベスト判定は記録へ保存せず、保存した事実から今の規則で導く（SPEC-006、SPEC-002）。

記録はこの端末のブラウザに保存する。保存に失敗したプレイは、そのことを結果で示し、その結果はその場でだけ示す。

## 記録の結果と振り返り

記録は一件ごとに識別でき、記録を保存できたプレイの結果は、後から同じ記録を指して開き直せる。結果は、保存した記録から今の規則で作り直して示す。

履歴画面には「過去にどう遊んだか」を理解するために意味のある情報を構成して見せる。問題を再現するための識別情報や保存形式上の情報は、通常は表示しない。

問題の再現や分析のために、履歴一件、または記録画面の一覧に出ている記録の、問題識別情報とプレイ事実を、明示的なコピー操作で書き出せる。この書き出しは記録の読み込みや移し替えには使わない。

## 今の規則で扱えない記録

記録形式、生成器、難易度区分、評価規則を変えたとき、古い記録を今の形式へ変換したり、当時の規則で計算し直したりする処理は設けない。

今の規則で扱えない記録（古い記録形式の記録、今と違う生成器の問題の記録など）も消さずに残す。そうした記録は、結果を開けず、評価と自己ベスト比較に使わない。同じ問題を遊び直せるかは SPEC-014 による。

廃止した難易度区分の記録は、今の難易度へ読み替えず、当時の区分のまま、今の難易度とは別の比較単位として扱う。

完了せずに離れたプレイの記録は履歴ではなく、SPEC-015 で扱う。
