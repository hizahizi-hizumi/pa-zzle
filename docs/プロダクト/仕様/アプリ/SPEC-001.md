# SPEC-001 プレイ履歴

プレイ履歴は、完了したプレイで実際に起きた事実を後から振り返り、現在の規則で再評価できる記録とする。

完了したプレイの記録が保存されたことをもってクリアを確定し、その記録を履歴とする。各記録から、少なくともゲーム、比較に必要な開始条件、完了日時、そのゲームの評価・振り返りに必要なプレイ事実を識別できるようにする。自己ベストや推移など履歴から導出するものは、完了したプレイの記録だけを対象とする。

評価点、評価段階、自己ベスト判定は保存事実から導出する。評価方式が変わったとき、過去記録を当時の導出値へ固定せず、保持した事実から現在の規則で評価できるようにする。

問題を再現するための識別情報や保存形式上の情報を保持しても、それ自体は通常表示する情報ではない。問題再現用識別情報は、履歴から同じ問題を再プレイするときに内部で利用できる。問題の再現や分析のために、履歴一件、または記録画面の一覧に出ている記録の問題識別情報とプレイ事実を、明示的なコピー操作で書き出せる。履歴画面には「過去にどう遊んだか」を理解するために意味のある情報を構成して見せ、コピー機能を使わなくても履歴を利用できるようにする。

## 完了しなかったプレイ

完了しなかったプレイも、将来の振り返り・分析・評価改善に使える事実として残す。

- プレイを開始した時点で、開始の事実を記録する。
- 利用者がアプリ内の操作で難易度選択やホームへ戻ったとき、プレイ中に別の問題へ切り替えたとき、ブラウザの戻る・進むで移動したときは、明示的にプレイを離れたものとして、その時点の進み具合を記録し離脱として確定する。
- 同じ問題のやり直しは同じプレイ内の出来事であり、離脱とはしない。
- タブを閉じる、再読み込みする、外部へ移動するときも、できる範囲で離脱として記録する。ブラウザの制約により記録できない場合があるため、確実さは保証しない。
- 回線切れ、強制終了、端末によるページ破棄などでは離脱を記録しない。その場合は開始の記録だけが残る。

離脱時の進み具合は、各ゲームが結果として扱う実測値から、クリアに関わる部分を除いたものとする。評価点などの導出値は、完了した記録と同じく離脱の記録にも保存しない。

一つのプレイの状態は、記録から次の順に解釈する。

- 完了した記録がある: クリア。離脱の記録があっても完了を優先する。
- 離脱の記録がある: 離脱。
- どちらもない: 未完了。

離脱・未完了の記録は履歴ではなく、自己ベスト、推移の対象にしない。離脱の記録は、履歴と区別できる形でなら、同じ比較文脈の履歴と並べて参照できる。
