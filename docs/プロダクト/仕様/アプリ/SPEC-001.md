# SPEC-001 プレイ履歴

プレイ履歴は、クリアしたプレイで実際に起きた事実を後から振り返るための記録とする。

## 記録するもの

クリアしたプレイだけを、1回のプレイ（SPEC-007）につき1件の履歴として記録する。同じプレイを二重に記録しない。

各記録には、少なくともゲーム、難易度、遊んだ問題を再現するための情報、開始日時と完了日時、そのゲームの評価と振り返りに必要なプレイ事実を持たせる。記録するプレイ事実はパズル仕様に書く。

評価点、評価段階、自己ベストの判定は記録へ保存しない（SPEC-006、SPEC-002）。

記録はこの端末のブラウザに保存する。保存に失敗したときは、そのことを結果で示す。そのプレイの結果は、その場でだけ示す。

## 結果と振り返り

記録は一件ごとに識別でき、保存できたプレイの結果は、後から同じ記録を指して開き直せる。開き直した結果は、保存した記録から作り直して示す。

履歴画面では、過去にどう遊んだかを理解するための情報を示す。問題を再現するための情報や保存形式上の情報は、通常は表示しない。履歴の一覧と推移は、自己ベストと同じ比較単位と指標（SPEC-002）で示す。

問題の再現用に、履歴一件、または記録画面の一覧に出ている履歴の、問題を再現するための情報とプレイ事実を、明示的なコピー操作で書き出せる。書き出しの対象は履歴だけとし、離脱の記録（SPEC-015）は含めない。

## 今の規則で扱えない記録

記録形式、生成器、難易度区分、評価規則を変えても、古い記録を今の形式へ変換したり、当時の規則で計算し直したりしない。古い記録も消さずに残し、今の規則で扱える範囲で使う。

- 結果を開けるのは、今の記録形式で、今の生成器の問題を記録したものだけとする。
- 評価と自己ベストの比較には、今の評価規則が使うプレイ事実を記録から得られるものだけを使う。
- 同じ問題を遊び直せるかは SPEC-014 による。

廃止した難易度区分の記録は、今の難易度へ読み替えない。当時の区分の名前のまま、今の難易度とは別の比較単位として扱う。
