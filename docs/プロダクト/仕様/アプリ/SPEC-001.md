# SPEC-001 プレイ履歴

プレイ履歴は、完了したプレイで実際に起きた事実を後から振り返り、現在の規則で再評価できる記録とする。

完了したプレイだけを履歴として確定する。各記録から、少なくともゲーム、比較に必要な開始条件、完了日時、そのゲームの評価・振り返りに必要なプレイ事実を識別できるようにする。

評価点、評価段階、自己ベスト判定は保存事実から導出する。評価方式が変わったとき、過去記録を当時の導出値へ固定せず、保持した事実から現在の規則で評価できるようにする。

記録は一件ごとに識別でき、完了したプレイの結果は、保存した記録から現在の規則で作り直して示す。そのため、記録を保存できたプレイの結果は、後から同じ記録を指して開き直せる。古い記録形式の記録や、今と違う生成器の問題の記録など、今の結果として作り直せない記録の結果は開けない。保存に失敗したプレイの結果は、その場でだけ示す。

問題を再現するための識別情報や保存形式上の情報を保持しても、それ自体は通常表示する情報ではない。問題再現用識別情報は、履歴から同じ問題を遊び直すときに、その問題の問題IDを求めるために内部で利用できる。問題の再現や分析のために、履歴一件、または記録画面の一覧に出ている記録の問題識別情報とプレイ事実を、明示的なコピー操作で書き出せる。履歴画面には「過去にどう遊んだか」を理解するために意味のある情報を構成して見せ、コピー機能を使わなくても履歴を利用できるようにする。

完了せずに離れたプレイの記録は履歴ではなく、SPEC-015 で扱う。
