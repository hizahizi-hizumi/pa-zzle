# SPEC-001 プレイ履歴

プレイ履歴は、完了したプレイで実際に起きた事実を後から振り返り、現在の規則で再評価できる記録とする。

完了したプレイだけを履歴として確定する。各記録から、少なくともゲーム、比較に必要な開始条件、完了日時、そのゲームの評価・振り返りに必要なプレイ事実を識別できるようにする。

評価点、評価段階、自己ベスト判定は保存事実から導出する。評価方式が変わったとき、過去記録を当時の導出値へ固定せず、保持した事実から現在の規則で評価できるようにする。

問題を再現するための識別情報や保存形式上の情報を保持しても、それ自体は通常表示する情報ではない。問題再現用識別情報は、履歴から同じ問題を再プレイするときに内部で利用できる。問題の再現や調査のために、履歴一件の問題識別情報とプレイ事実を明示的なコピー操作で書き出せる。履歴画面には「過去にどう遊んだか」を理解するために意味のある情報を構成して見せ、コピー機能を使わなくても履歴を利用できるようにする。
