# SPEC-001 プレイ履歴

クリアしたプレイを、後から振り返り同じ問題を遊び直すための記録として残す決まり。

- クリアしたプレイだけを、1回のプレイ（SPEC-007）につき1件の履歴として記録する。
- 履歴はこの端末のブラウザに保存する。
- 履歴にはプレイで起きた事実を保存し、評価点・評価段階・自己ベストの判定は保存しない（SPEC-006、SPEC-002）。
- 保存できたプレイの結果は、その履歴を指して後から開き直せる。開き直した結果は、保存した履歴から作り直して示す。結果を見たまま再読み込みしても同じ結果を示し、次の問題を始めない。
- 履歴が無い、または今の結果として示せない履歴の結果を開いたときは、理由を区別せず記録が見つからないことを示し、記録画面へ戻れるようにする。
- 保存に失敗したときは、そのことを結果で示す。
- 記録画面の履歴の一覧と推移は、自己ベストと同じ比較単位と指標（SPEC-002）で示す。推移は各プレイの実値をそのまま時系列に示し、平滑化や集計で別の値に置き換えず、件数が増えても間引かない。
- 問題を再現するための情報は、通常の画面には示さない。履歴の、問題を再現するための情報とプレイ事実は、明示的なコピー操作で書き出せる。

## 今の規則で扱えない履歴

- 記録形式・生成器・難易度区分・評価規則を変えても、古い履歴を今の形式へ変換したり、当時の規則で計算し直したりしない。古い履歴は消さずに残し、今の規則で扱える範囲で使う。
- 今の評価規則が使うプレイ事実を得られない履歴は、評価と自己ベストの比較に使わない。
- 廃止した難易度区分の履歴は今の難易度へ読み替えず、当時の区分の名前のまま、今の難易度とは別の比較単位として扱う。
