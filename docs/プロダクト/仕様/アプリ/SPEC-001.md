# SPEC-001 プレイ履歴

クリアしたプレイを、後から振り返り同じ問題を遊び直すための記録として残す決まり。

- クリアしたプレイだけを、1回のプレイ（SPEC-007）につき1件の履歴として記録する。
- 履歴はこの端末のブラウザに保存する。
- 保存できたプレイの結果は、その履歴を指して後から開き直せる。

## 記録画面

- 記録画面は、いつ・何を遊んだかを示す。全ゲームの履歴と離脱したプレイ（SPEC-015）を、ゲームや難易度で分けずに遊んだ時刻の順に並べる。成績の比較（自己ベストと推移）は記録画面に置かない（SPEC-002）。
- 日ごとに遊んだ量を示す。遊んだ量は、数・連続日数・称賛では示さない。
- 履歴からはそのプレイの結果を開く。結果を開き直せない履歴と離脱したプレイからは、その問題を選んだゲームのホーム（SPEC-004）を開く。

## 今の規則で扱えない履歴

- 記録形式・生成器・難易度区分・評価規則を変えても、古い履歴を今の形式へ変換したり、当時の規則で計算し直したりしない。古い履歴は消さずに残し、今の規則で扱える範囲で使う。
- 今の評価規則が使うプレイ事実を得られない履歴は、評価と自己ベストの比較に使わない。
- 廃止した難易度区分の履歴は今の難易度へ読み替えず、当時の区分の名前のまま、今の難易度とは別の比較単位として扱う。
