# SPEC-002 自己ベスト

今回のプレイを過去の自分のプレイと比べる決まり。

- 自己ベストは専用の保存値を持たず、保存済みの履歴（SPEC-001）から導く。
- 比較単位は、同じゲームの同じ難易度とする。
- 記録や図鑑（SPEC-026）から同じ問題を遊び直したプレイも、通常のプレイと同じく比較に含める。
- 同じ比較単位に過去の履歴がなければ初記録とする。
- 更新は指標ごとに判定し、過去の最良値を厳密に上回った指標を更新とする。同値は更新としない。1つでも更新した指標があれば自己ベスト更新とし、更新した指標をすべて示す。
- 初記録と自己ベスト更新は、クリアから結果へ進んだときだけ告げる。
- 比較単位ごとの自己ベストと推移は、ゲームのホームで開いている難易度について示す。推移は自己ベストと同じ指標で示す。
- 内部診断が有効なビルドでは、比較単位の履歴をゲームのホームから JSON でまとめてコピーできる。プロダクトオーナーが難易度の調整などの分析に使うため、利用者には出さない。
