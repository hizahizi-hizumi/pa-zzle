# SPEC-002 自己ベスト

自己ベストは専用の保存値ではなく、保存済みの履歴（SPEC-001）から導出する。

比較単位は難易度とする。同じゲームの同じ難易度の履歴どうしを比べる。比較する指標と、各指標で高いほど良いか低いほど良いかはゲームごとに決め、パズル仕様に書く。

記録から同じ問題を遊び直したプレイも、通常のプレイと同じく自己ベストの比較に含める。離脱したプレイ（SPEC-015）と、今の規則で評価できない記録は含めない。

同じ比較単位に過去の記録がなければ初記録とする。自己ベストの更新は指標ごとに判定し、過去の最良値を厳密に上回った指標を更新とする。同値は更新とは扱わない。1つでも更新した指標があればそのプレイを自己ベスト更新とし、更新した指標をすべて示す。

同値のプレイが現在のベスト値に該当すること自体は許容する。

自己ベストを更新しなかったプレイでも、結果では指標ごとに現在の自己ベストとの差を示す。
