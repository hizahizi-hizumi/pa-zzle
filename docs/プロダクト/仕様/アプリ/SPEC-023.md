# SPEC-023 ホームの続き

ゲームを選ぶホームで、選んでおくゲームと、選んでいるゲームの続きの決まり。

- ホームを開いたときは、図鑑（SPEC-021）に使える履歴のうち最後にクリアまたは離脱した（SPEC-015）プレイのゲームを選んでおき、そのようなプレイが無ければ並びの先頭のゲームを選んでおく。
- 選んでいるゲームの続きとして、問題を指定せずにそのゲームのホームを開いたときに開く難易度（SPEC-004）と、その難易度の挑戦中（SPEC-021）の問題の数を示す。挑戦中の問題が無ければ難易度だけを示し、図鑑に使える履歴が無いゲームでは続きを示さない。
