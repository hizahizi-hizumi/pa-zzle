# SPEC-015 完了しなかったプレイ

完了せずに離れたプレイで起きた事実を、完了したプレイの履歴と区別して残し、後から振り返り・分析・評価改善に使える記録とする。

## 開始と離脱

プレイを開始した時点で開始の記録を残す。開始の記録は、完了したプレイの記録と同じ意味で開始条件を持つ。

解き終える前に次のことが起きたら、明示的にプレイを離れたものとして、その時点の進み具合を記録し離脱として確定する。離れる前に利用者へ確認や警告はしない。

- アプリ内の操作で難易度選択やホームへ戻る。
- リセットや「別の問題」で、新しいプレイに置き換わる（SPEC-007）。
- ブラウザの戻る・進むで移動する。

待った・盤面を戻すなど同じプレイの続きとなる操作（SPEC-007）は、離脱としない。

タブを閉じる、再読み込みする、外部へ移動するときも、できる範囲で離脱として記録する。ブラウザの制約により記録できない場合があるため、確実さは保証しない。回線切れ、強制終了、端末によるページ破棄などでは離脱を記録せず、開始の記録だけが残る。

離脱時の進み具合は、各ゲームが結果として扱う実測値から、クリアに関わる部分を除いたものとする。評価点などの導出値は、完了したプレイの記録と同じく離脱の記録にも保存しない。

## プレイの状態

一つのプレイの状態は、記録から次の順に解釈する。

- 完了したプレイの記録がある: クリア。離脱の記録があっても完了を優先する。
- 離脱の記録がある: 離脱。
- どちらもない: 未完了。

クリアしたプレイの開始の記録は完了したプレイの記録から導出できるため保持せず、離脱・未完了の開始の記録だけを保持する。

## 履歴との関係

離脱・未完了のプレイはプレイ履歴ではなく、評価も自己ベストの比較もしない。離脱の記録は、履歴と区別できる形でなら、同じ難易度の履歴と並べて参照でき、履歴と同じく、記録した問題の問題IDで同じ問題を通常のプレイとして遊び直せる。遊び直せる条件は履歴の遊び直し（SPEC-014）と同じとする。問題の識別情報とプレイ事実の書き出しは履歴だけを対象とし、離脱の記録は対象にしない。
