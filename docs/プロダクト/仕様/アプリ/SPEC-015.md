# SPEC-015 完了しなかったプレイ

クリアせずに離れたプレイを、履歴（SPEC-001）と区別して残す決まり。

- クリアする前にプレイが終わったとき（SPEC-007 の、離れたときと新しいプレイに置き換わったとき）は、そのプレイを離脱として、その時点の進み具合を記録する。
- 盤面を一度も操作しないまま終わったプレイは、離脱として記録しない。盤面をのぞいて戻っただけで、挑戦中・離脱の記録や、次に開く難易度・ゲーム（SPEC-004・SPEC-023）が変わらないようにする。
- 同じプレイに離脱の記録と完了の記録が両方あるときは、完了を優先し、クリアしたプレイとして扱う。
- 離れる前に、利用者へ確認や警告はしない。
- 離脱したプレイは履歴ではなく、評価も自己ベストの比較もしない。
- 離脱の記録は、履歴と同じく記録した問題を通常のプレイとして遊び直せる（SPEC-014）。
