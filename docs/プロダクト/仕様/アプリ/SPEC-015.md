# SPEC-015 完了しなかったプレイ

クリアしていない挑戦の中断時点の進み具合を、完了記録（SPEC-001）と区別して残す決まり。

- クリア前に新しいプレイへ置き換えたときや、ページを離れて復帰していない間は、離れた時点の進み具合を離脱として記録する。中断・再読み込みそのものはプレイの終了条件ではない（SPEC-007）。
- 同じ挑戦に復帰したら、その試行の離脱記録を解除する。ブラウザの戻る・進むキャッシュへの退避だけでは離脱を記録しない。
- 同じ挑戦に離脱記録と完了記録の両方があるときは、完了を優先する。
- 離れる前に確認や警告はしない。離脱したプレイは評価も自己ベストの比較もしない。
- 離脱記録の問題は、通常の問題選択と同じ入口で遊び直せる（SPEC-014）。
