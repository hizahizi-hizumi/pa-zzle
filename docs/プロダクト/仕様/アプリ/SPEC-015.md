# SPEC-015 完了しなかったプレイ

完了せずに離れたプレイで起きた事実を、履歴（SPEC-001）と区別して残す。

## 開始と離脱

プレイを始めた時点で、開始の記録を残す。開始の記録は、履歴と同じ意味で難易度と問題を持つ。

クリアする前に次のことが起きたら、そのプレイを離脱として、その時点の進み具合を記録する。離れる前に、利用者へ確認や警告はしない。

- アプリ内の操作で、難易度選択やホームへ移る。
- リセットや「別の問題」で、新しいプレイに置き換わる（SPEC-007）。
- ブラウザの戻る・進むで移動する。

タブを閉じる、再読み込みする、外部へ移動するときも、できる範囲で離脱として記録する。ブラウザの制約で記録できないことがあるため、確実には記録しない。回線切れ、強制終了、端末によるページ破棄などでは離脱を記録せず、開始の記録だけが残る。

離脱の進み具合は、そのゲームが結果で示す実測値から、クリアに関わるものを除いたものとする。評価点などの導出値は保存しない。

## プレイの状態

一つのプレイの状態は、記録から次の順に決める。

- 履歴がある: クリア。離脱の記録があっても、クリアを優先する。
- 離脱の記録がある: 離脱。
- どちらもない: 未完了。

## 履歴との関係

離脱と未完了のプレイは履歴ではなく、評価も自己ベストの比較もしない。

離脱の記録は、記録画面で履歴と区別して、同じ難易度の履歴と並べて示せる。履歴と同じく、記録した問題を通常のプレイとして遊び直せる。遊び直せる条件は SPEC-014 による。
