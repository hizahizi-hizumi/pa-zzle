# SPEC-027 コレクション

記録画面で、ゲームをまたいでクリアしてきた問題の量と出来を振り返るための決まり。

- コレクションは専用の保存値を持たず、保存済みの完了したプレイ履歴（SPEC-001）から導く。離脱したプレイは含めない。
- 今の問題集から同じ難易度で引ける履歴だけを使う。対象と評価点は各ゲームの図鑑（SPEC-026）と同じ規則で求める。
- 同じゲーム・難易度・問題 ID の履歴は、何回クリアしても1問と数える。評価段階は、その時点までの最高評価点で決める。
- 全体の合計と評価段階別の数は、ゲーム別の数を合算する。ゲームの表示順はパズル選択画面と同じ設定に従う。
- ゲーム別の数は、最も多いゲームの数以上で最も小さい節目（SPEC-026 と同じ刻み）を上端とした高さで示し、上端の数を添える。最も多いゲームの数を上端にすると、1問しか解いていなくても満杯に見え、積み上がりが見えないため。
- 時間を戻したときの積み重ねは、その月末までにクリアした履歴から求める。今月は現在までの履歴を使う。
- 月ごとの初クリア数は、その月に初めてクリアした問題の数とする。評価別の内訳は、その月末の最高評価で分ける。
- 月ごとの評価更新数は、前月末までにクリア済みの問題のうち、当月末の最高評価段階が前月末より上がった問題の数とする。同じ月に繰り返し更新しても1問と数える。
- コレクションは全ゲームの量と出来を眺めるためのもので、ゲーム・難易度ごとの自己ベスト指標の比較（SPEC-002）は置かない。
