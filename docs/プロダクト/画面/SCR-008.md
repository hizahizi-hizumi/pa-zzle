# チュートリアル

## 目的

- 遊ぶ人が、1つの盤面を解きながら、パズルのルールを1つずつ身につけられる。

## 優先すること

- 盤面を主役にし、言葉はゲーム名、何をするパズルか、手に入れたルール、短い一言だけにする。
- ゲーム名と何をするパズルかを、盤面と一緒に見せる。チュートリアルはパズルの入口の1つである。
- ゴールの盤面と始めの盤面は、自動では先へ進めず、遊ぶ人の「次へ」でだけ進める。
  - 盤面を見る速さは人によって違うので、自分のペースで進められるようにする。2つの盤面を見ないまま、ルールを身につける手順に入らないようにする。
- ルールは、手に入れるまで中身を伏せる。
- 今の一言が示すルールがどれかは、手に入れたルールの並びの側でも分かるようにする。
- ルールの並びは、伏せたルールも含めて、押せる部品や問いかけに見えないようにする。
- BGM は、開いた画面によらず解く場面の曲を流す。チュートリアルは盤面を解く場面である。
- 終えて遊び始めるときは、ゲームのホームで開いていたレベルを始める。特定のレベルを勧めないようにする。
