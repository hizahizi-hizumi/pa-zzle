# チュートリアル

## 目的

- 遊ぶ人が、1つの盤面を解きながら、パズルのルールを1つずつ身につけられる（SPEC-029）。

## 優先すること

- プレイ画面と同じ地の上で、盤面の色と形を本番のまま見せる。
- 盤面を主役にし、言葉はゲーム名、何をするパズルか、短い一言、解き終えたときに振り返るルールだけにする。
- チュートリアルはパズルの入口の1つなので、導入（SPEC-029）では、ピクトグラムと名前を大きく見せる。
- 解いている間は、一言が替わっても盤面を動かさない。
- 印（輪郭と、押すしぐさをする指）は、次に押す所と、そこから押す所を選ばせる候補にだけ付ける。違反を直す所は次に押す所なので印を付け、目標・違反の範囲・その手を決める物（決め手）には印を付けない。
  - 指が決め手や一言を隠す所、すぐ下に読ませたい物がある所、どれを押すかを選ばせる候補には、指を出さず輪郭だけにする。
- 決め手を見せる間は、盤面の中だけを薄く覆い、押す所と、決め手・目標・違反の範囲を元の明るさで残す。印を付けない物は、印の代わりに覆いから抜いて示す。決め手の無い手順（操作を教える手順など）では覆わない。
  - 覆いは、盤面がプレイ画面と同じ物に見えるまま、抜いた所との差が分かる薄さにとどめる。
- 一言は、文節の切れ目で折り返し、語の途中で折り返さない。
- 盤面1枚では伝えきれないこと（駒の動きの一覧、この盤面に出ない仕掛けなど）は、その場で開ける遊び方の説明に任せる。
- BGM は、開いた場所によらず解く場面の曲を流す。チュートリアルは盤面を解く場面である。

## やらないこと

- 画面全体を暗く覆わない。覆うのは、決め手を見せる間の盤面の中だけにする。
- 次に押す所の印と、手が成立した瞬間の応えに、ゲームごとの点線・発光・矢印・バッジ・独自の色を足さない。覆いもゲームごとに描かない。全ゲームで同じ見せ方にする。
