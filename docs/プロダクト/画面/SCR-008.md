# チュートリアル

## 目的

- 遊ぶ人が、1つの盤面を解きながら、パズルのルールを1つずつ身につけられる（SPEC-029）。

## 優先すること

- 盤面と、自分で次の一手を考える体験を主役にする。言葉は理解に必要なものだけに絞る。
- チュートリアルを、そのゲームを解く体験への入口として扱う。
- ルールは、自分の手で発見し獲得するまで伏せておく。
- 今考えるべきルールと、すでに手に入れたルールのつながりを感じられるようにする。
- 手を引く場面でも、盤面の状況と次の一手の決め手を自分で読む余地を残す。決め手を示しすぎない。

## やらないこと

- まだ手に入れていないルールを、すでに操作できる選択肢のように見せない。
- 次の一手や手が成立した瞬間の案内を、ゲーム固有の装飾で競わせない。
