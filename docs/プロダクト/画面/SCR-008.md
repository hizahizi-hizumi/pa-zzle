# チュートリアル

## 目的

- 遊ぶ人が、1つの盤面を解きながら、パズルのルールを1つずつ身につけられる（SPEC-029）。

## 優先すること

- 盤面を主役にし、言葉はゲーム名、何をするパズルか、手に入れたルール、短い一言だけにする。
- ゲーム名と何をするパズルかを、盤面と一緒に見せる。チュートリアルはパズルの入口の1つである。
- ルールは、手に入れるまで中身を伏せる。
- 今の一言が示すルールがどれかは、手に入れたルールの並びの側でも分かるようにする。
- 手を引いている間は、画面全体を暗く覆い、次に押す所と、その手を決める物（決め手）と、一言だけを抜いて元の明るさで見せる。決め手には印を付けず、抜くことだけで示す。
  - 覆いは、盤面の状態がまだ読める濃さにとどめ、抜いた所だけが明らかに明るく見えるようにする。
- BGM は、開いた場所によらず解く場面の曲を流す。チュートリアルは盤面を解く場面である。

## やらないこと

- ルールの並びを、伏せたルールも含めて、押せる部品や問いかけに見せない。
- 次に押す所の印と、手が成立した瞬間の応えに、ゲームごとの点線・発光・矢印・バッジ・独自の色を足さない。覆いもゲームごとに描かない。全ゲームで同じ見せ方にする。
