# ホーム

## 目的

- 遊ぶ人が、並んだゲームの違いを見分けて、遊ぶゲームを決められる。

## 優先すること

- ゲーム名と、そのゲームで実際に見る・触るものを縮約した表現を主役にする。ここはゲームの説明書ではなく、異なる遊びを見分けて選ぶ場所である。
- ゲームが増えても、候補を順に見つけていけ、今見ているゲームと次の候補が分かるようにする。
- 選んでいるゲームは、色と動きで見せる。遊び方を図で説明するものにはしない。
  - 濃淡2色の静止画だけでは、FR-001・RQ-002 を満たしにくい。
- 額の中には、ゲームのホームと同じ並びと形のそのゲームの台紙を見せ、色と動きで見せるピクトグラムはその台紙の絵として馴染ませる。
  - 額に飾られているのはピクトグラムのジグソーパズルで、ジグソーの上にピクトグラムを載せただけには見せない。
- 台紙の全体を、額の中で見られるようにする。
- ゲーム名は、額の中に入れず、額に添える。
  - ゲーム名は額の題名で、額の中のものではない。

## やらないこと

- ルールの詳細と、始めてから分かればよい条件を持ち込まない。
  - 遊ぶゲームを見分けて選ぶのに要らない。
- 成績と履歴は、額の台紙の解いたピースに付く評価の色のほかは持ち込まない。選んでいるゲームの続き（SPEC-006）は、そのゲームに入らずに続きを確かめて選べるようにするもの（FR-026）で、ここで言う成績・履歴に当たらない。
- ホームの画面そのものをピースに見立てない。
  - やりすぎになる。
