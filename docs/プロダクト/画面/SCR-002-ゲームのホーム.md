# ゲームのホーム

## 目的

- 遊ぶ人が、遊ぶレベルを選んで始めることと、解いてきた問題を図鑑で見返して次の1問を自分で選ぶことを、同じ場所でできる。

## 優先すること

- ホームの額の中に入った画面として、額を無くさない。
  - 行き来の動きだけでは、額の中に入ったように見えない。
- 背景は、ホームの背景と合わせる。
- 図鑑の台紙を最も重視する。遊んできた問題を、全問の中の自分の跡として、全体の分布で眺められるようにする。
- 見方・問題の詳細・絞り込み・成績は、必要になったときに確かめられるようにし、台紙を眺める妨げにしない。
- 開いていないレベルも、解いてきた問題の位置と出来を比較できるようにする。
- 前回のプレイから、どこに何が増え、どの評価が上がったかを実感できるようにする。
  - 多くの問題の中で変わったものが今の姿で現れるだけでは、積み上がりと塗り替えの手応えにならない。
- 結果からこの画面へ来たときは、解いた問題のピースが台紙のどこに収まったかを分かるようにする。
- 問題を始めるときは、台紙のどのピースからプレイへ入るのかを分かるようにする。ゲームが選んだ問題でも同じにする。

## やらないこと

- 台紙を番号やスコアの文字で埋めない。問題が数千あるゲームでも、全問を見渡す体験を優先する。
- この画面の台紙には、ゲームの絵などの飾りを加えない。問題を集めた跡そのものを主役にする。
