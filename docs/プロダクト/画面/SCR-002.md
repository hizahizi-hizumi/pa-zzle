# ゲームのホーム

## 目的

- 遊ぶ人が、これから解く1問の盤面を前にして、そのままプレイへ入れる。
- 遊ぶ人が、遊ぶ難易度を決め、解いてきた問題を図鑑で見返して、次の1問を自分で決められる。

## 優先すること

- これから遊ぶ1問（SPEC-004）の盤面を主役にする。難易度の選択・図鑑・操作は、盤面と競わない強さに抑える。
  - 計数と操作を並べただけの画面には、画面単体での完成度も、そのゲームに入った没入感も無い。
  - 選ばなくても、目の前の盤面をそのまま始められるようにする。
- 始めるときと戻ってきたときは、ここの盤面とプレイの盤面が、同じ1枚の盤面に見えるようにする。
  - 画面が切り替わるだけでは、プレイへ入っていく楽しさが無い。
- 図鑑は、開いている難易度の全問を、スクロールさせずに一度に見せる。
  - 遊んできた問題を、全問の中の自分の跡として、全体の分布で眺められるようにする。
- 図鑑の1問は、ジグソーのピース1枚で示す。どのピースを選んでいるかは、ピースの大きさによらない目印と、主役の盤面で返す。
  - 全問を一度に見せると、ピースは指より小さくなる。
- 前回からの変化（SPEC-026）は、どこに何が増え、どの色が上がったかが分かるように返す。
  - 多くのピースの中で、変わったピースが今の姿で現れるだけでは、前と何が違うかが分からず、積み上がりと塗り替えの手応えにならない。
- 評価段階の色の見方・絞り込み・成績は、求めたときにだけ出す。それらを開く操作は、ゲーム名と競わない強さに抑える。絞り込みは、かけている間は、開かなくても選んでいる選択肢の数が分かるようにする。

## やらないこと

- ピースに番号やスコアなどの文字を載せない。問題の多い難易度でも、全問をスクロールさせずに見せる大きさにするため。
- ピースを大きくして図鑑を主役にしない。ピースには問題ごとの個性が無く、図鑑の楽しさは自分の跡と分布にある。
- ピースは、隣にピースがある辺を平らにしない。ピースの間に平らな辺のあるジグソーはありえないため。
- 図鑑で問題を選ぶたびに、その問題のための面を開かない。選んだ問題は、主役の盤面が替わって返す。
