# SCR-002 開始条件選択

## 役割

ゲームを選んだ利用者が、プレイ前に自分で決める必要のある条件を理解して選び、その条件で問題を始める画面。

開始前に選ぶ条件がないゲームでは存在しない。

## 情報構造

最初に何を選ぶのかを示し、各選択肢について「選ぶとプレイ体験の何が変わるか」を比較できるようにする。

難易度ならラベルだけでなく解く負荷の違いとして理解できることを優先する。ゲーム固有の視覚表現が比較に役立つ場合は使うが、実際の開始条件に存在しない違いを装飾で作らない。

条件を決めるために不要な生成情報、内部特徴量、成績情報は表示しない。

## 選択

選択肢全体を操作対象とし、現在選べるものと選択操作の結果が分かるようにする。選択後は追加の確認操作を要求する必然性がなければ、その条件で問題の開始へ進む。

## 共通とゲーム固有

「開始前に必要な条件を一つ選ぶ」という役割だけを共通化する。条件の種類、選択肢、比較情報、視覚表現はゲームが定義する。難易度は現在のゲームで使う開始条件だが、新しいゲームへ必須とはしない。

## 画面サイズ

スマートフォンでも候補同士を比較したまま選べることを優先する。PCでは余白を増やすのではなく、候補の比較へ利用可能な幅を使う。
