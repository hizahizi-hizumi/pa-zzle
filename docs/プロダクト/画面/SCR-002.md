# ゲームのホーム

## 目的

- 遊ぶ人が、解いた問題がピースとして埋まっていくそのゲームのジグソーを前にして、次の1問を始められる。

## 優先すること

- ジグソーを主役にし、ほかの要素はジグソーと競わない強さに抑える。
  - 計数と操作を並べた中にピースを置いただけでは、画面単体での完成度も、ゲームに入った没入感も無い。
- ピースは、指で1枚を選べ、1枚が埋まるところが画面の中の出来事として見える大きさにする。
- ジグソーは幅いっぱいに組む。ピースの大きさが狙いから少し離れても、最後の段が欠けにくい列の数を取る。
- 埋まったピースと空きは、ひと目で見分けられるようにする。
- ピースに載せる文字は、問題の番号だけにする。
  - 番号は、どの問題かをピースの上で見分けられるようにするため。スコアなどほかの文字は、ピースの形と色でジグソーとして見せるために載せない。
- ピースの並びは、問題を選んでも、プレイから戻っても変えない。並びが変わると、どこが埋まったかを追えない。
- 選んだ問題が空きなら、空きを囲むだけにして持ち上げない。持ち上げるのは、埋まったピースを選んだときだけにする。
- 問題の盤面は、ピースを選んだときにだけ見せる。主役のジグソーと盤面を競わせないため。
- 始めるときは、選んだ問題の盤面がそのままプレイへつながって見えるようにする。
  - 画面が切り替わるだけでは、プレイへ入っていく楽しさが無い。
- 前回からの変化は、どこに何が増え、どの色が上がったかが分かるように返す。
  - 多くのピースの中で、変わったピースが今の姿で現れるだけでは、前と何が違うかが分からず、積み上がりと塗り替えの手応えにならない。
- 前回からの変化を返している間は、変化したピースを、選んだ問題の表示で隠さない。
- 見方・絞り込み・成績は求めたときにだけ出す。ジグソーを最も広く見せるため。
- 求めたときにだけ出すものを開く見出しの操作は、ゲーム名と競わない強さに抑える。
- 絞り込みは、かけている間は、開かなくても選んでいる選択肢の数が分かるようにする。

## やらないこと

- 1つのレベルの全問を一度に見せるために、ピースを小さくしない。収まらない分はスクロールさせる。
  - ピースを小さくすると、台が集計表に見え、解いた1枚が埋まる瞬間が画面の中で小さすぎる。
- ピースは、隣にピースがある辺を平らにしない。ピースの間に平らな辺のあるジグソーはありえないため。
