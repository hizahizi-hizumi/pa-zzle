# SCR-002 開始条件選択

## 役割

ゲームを選んだ利用者が、難易度を含む開始条件を理解して選び、その条件で問題を始める画面。

## 情報構造

最初に何を選ぶのかを示し、各選択肢について「選ぶとプレイ体験の何が変わるか」を比較できるようにする。

難易度は `難易度 1`〜`難易度 5` を共通の選択肢とし、数値だけでなく、そのゲーム固有の挑戦がどのように変わるかを理解できることを優先する。ゲーム固有の視覚表現が比較に役立つ場合は使うが、実際の開始条件に存在しない違いを装飾で作らない。

条件を決めるために不要な生成情報、内部特徴量、成績情報は表示しない。

## 選択

選択肢全体を操作対象とし、現在選べるものと選択操作の結果が分かるようにする。選択後は追加の確認操作を要求する必然性がなければ、その条件で問題の開始へ進む。

## 共通とゲーム固有

すべてのゲームで `難易度 1`〜`難易度 5` から一つを選ぶことを共通化する。難易度以外の追加条件、難易度ごとのゲーム固有の体験説明、比較情報、視覚表現はゲームが定義する。

## 画面サイズ

スマートフォンでも候補同士を比較したまま選べることを優先する。PCでは余白を増やすのではなく、候補の比較へ利用可能な幅を使う。
