# ゲームのホーム

## 目的

- 遊ぶ人が、遊ぶレベルを選んで始めることと、解いてきた問題を図鑑で見返して次の1問を自分で選ぶことを、同じ場所でできる。

## 優先すること

- 画面全体に、プレイと同じゲームの地を敷き、ブランドの帯と見出しまでつなげる。没入感を作る。
- 見出しのピクトグラムは、ホームで選んでいたときと同じ、ゲーム固有色でそのゲームの遊びを見せる姿にする。
- 図鑑の台紙を最も広く見せる。見出し・レベルのカード・始める操作は台紙を狭めない大きさに抑え、見方・問題の詳細・絞り込み・成績は求めたときにだけ出す。
  - 遊んできた問題を、全問の中の自分の跡として、全体の分布で眺められるようにする。
  - 求めたときにだけ出すものを開く見出しの操作は、ゲーム名と競わない強さに抑える。
  - 絞り込みは、かけている間は、開かなくても選んでいる選択肢の数が分かるようにする。
- レベルのカードには、そのレベルの台紙を同じ並びのまま縮めた縮図を載せる。開いていないレベルも、どこをどの出来で解いてきたかを、台紙と同じ位置で眺められるようにする。
- レベルのカードには、そのレベルの中身（手数、色の数、盤の大きさなど）を一言で添える。レベルの番号だけでは、何が違うのかが分からない。
- 解いた数は、次の節目までの残りと細い進みで示す（SPEC-026）。遠い全問の数ではなく、目の前の目標を見せる。
- どの画面幅でも、全レベルのカードを横に送らずに一度に見せる。レベルを切り替えずに、全レベルの跡を比べられるようにする。
- 前回からの変化は、どこに何が増え、どの色が上がったかが分かるように返す。
  - 多くのマスの中で、変わったマスが今の姿で現れるだけでは、前と何が違うかが分からず、積み上がりと塗り替えの手応えにならない。
- 始めるときは、選んだ問題のピースが台紙から抜けてプレイへ入っていくところを見せる。プレイへ入っていく楽しさを作る。
  - この動きは、抜けて入っていくところが見える長さと大きさにし、共通UIの遷移時間と拡縮の決まりに合わせて縮めない。
  - 長さを縮めない代わりに、動きの途中で画面を押すかキーを押すと、すぐ盤面へ移る。待たせない。

## やらないこと

- マスに番号やスコアなどの文字を載せない。問題が数千あるゲームでも、全問を見渡せる大きさにするため。
- ジグソーのピースにしたマスは、隣にマスがある辺を平らにしない。マスの間に平らな辺のあるジグソーはありえないため。
- 台紙に、ゲームの絵などの飾りを載せない。余計な賑やかしになる。
