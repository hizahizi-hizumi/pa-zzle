# SCR-001 ゲーム一覧

## 役割

利用者が「どのパズルで遊ぶか」を見つけて決める、pa-zzle の入口。

一覧はゲームの説明書ではなく、異なる遊びを見分けて選ぶ場所とする。

## 情報構造

各ゲームでは、ゲーム名と、そのパズルで実際に見る・触るものを縮約したゲーム固有の視覚表現を主役にする。説明文を読まなければゲームを識別できない構成にしない。

ルール詳細、開始後に分かればよい条件、成績、履歴は一覧へ持ち込まない。

ゲーム数が増えても、利用者が候補を順に発見し、現在見ているゲームと次の候補を把握できる一覧性を保つ。スマートフォンでは縦にカードを積み上げるのではなく、横方向へゲームを探す体験を基本とする。

## 選択

ゲーム全体を一つの選択対象として扱う。選択すると、そのゲームに開始条件があれば開始条件選択へ、なければ問題の開始へ進む。

## 共通とゲーム固有

ゲームを並べて選ぶ構造と操作はアプリが担う。何をそのゲームの顔として見せるかはゲーム側が担う。

一覧へ追加するためだけの共通アイコンへゲーム固有表現を置き換えず、既存ゲームの盤面表現を新しいゲームへ流用することも要求しない。
