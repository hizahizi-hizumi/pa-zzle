# ホーム

## 目的

- 遊ぶ人が、並んだゲームの違いを見分けて、遊ぶゲームを決められる。

## 優先すること

- ゲーム名と、そのゲームで実際に見る・触るものを縮約した表現を主役にする。ここはゲームの説明書ではなく、異なる遊びを見分けて選ぶ場所である。
- ゲームが増えても、候補を順に見つけていけ、今見ているゲームと次の候補が分かるようにする。
- 選んでいるゲームは、ゲーム固有色と動きで、何を考え何をする遊びかと、解けた・揃った瞬間の気持ちよさを見せる。動きはそのゲームで実際に起きることに留め、遊び方の説明にはしない。
  - 濃淡2色の静止画だけでは、何をする遊びかも、遊びたくなる期待も伝えにくい（FR-001・RQ-002）。

## やらないこと

- ルールの詳細、始めてから分かればよい条件、成績、履歴を持ち込まない。選んでいるゲームの続き（SPEC-023）は、そのゲームに入らずに続きを確かめて選べるようにするもの（FR-026）で、ここで言う成績・履歴に当たらない。
  - 遊ぶゲームを見分けて選ぶのに要らない。
