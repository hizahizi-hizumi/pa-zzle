# 結果

## 目的

- 遊ぶ人が、解き切った達成を受け取り、今回どう遊べたかを納得して知り、その流れのまま次の1問へ移れる。

## 優先すること

- 今回の評価を最も強く返す。主要成績と自己ベストは、その評価を理解するために、評価と同じまとまりで添える。
- 次の行動は「次の問題」を主にする。結果を受け取った流れを切らずに、次の1問へ進めるようにする。

## やらないこと

- 評価点、評価段階、主要成績、自己ベストを、一つの数値群として平坦に並べない。それぞれ意味が違う。
- 取得した値を網羅しない。評価の理解に役立たない計測値、内部の特徴量、問題の識別情報は出さない。
- そのプレイの出来でないもの（図鑑に1問加わったこと、色が上がったことなど）を足さない。足すと、何を受け取る画面かがぼやける。
