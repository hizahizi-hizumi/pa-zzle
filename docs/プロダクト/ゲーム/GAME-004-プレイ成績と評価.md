# GAME-004 プレイ成績と評価

1回のプレイで起きた事実と、その事実にゲームが与える評価の決まり。難易度は問題側の性質で、評価とは区別する。

## 採点の考え方

ゲーム間で揃えるのは採点方法ではなく、何を良いプレイとするかの考え方と、その理由である。

- 採点項目や配点を決める前に、そのパズルでどんな解き方を称えたいかを考える。速く解く、間違えずに解く、頭の中で考えてから操作する、盤面上で試行錯誤する、少ない手で解く、などは考えるための観点であり、分類や必須項目ではない。
- 重視する観点は組み合わせたり、新しいものを設けたりしてよい。採点項目や配点は各ゲームの特徴に応じて決め、全ゲームで揃える必要はない。
- 待った、ミス、やり直しなどの扱いは、操作名ではなく、その操作がプレイ中に持つ意味から決める。同じゲームの待ったでも判断の撤回、自然な試行錯誤、メモの修正などがあり、一律に誤判断や減点対象とはみなさない。
- 採点は、そのパズルで称えたい解き方の良さが点数に表れるように設計する。各採点項目がどんな上手さを表すかを明確にし、項目や操作の扱いがゲームごとに違う場合も、パズルの特徴から理由を説明できるようにする。

## 成績の共通契約

- 各ゲームは、何を良いプレイとして称えるかから観点を決め、そのために要る事実をプレイの進行から計測する。取得できるというだけの値は評価に加えない。
- 評価の観点の項目は、同じ意味のものなら、ゲームが違っても同じ名前にする。
- 経過時間は、プレイの開始からクリアまでの時間とする。画面が見えていない間や遊び方を開いている間も含める。
- 評価はクリアしたプレイだけに与え、100点満点の評価点で表す。
- 評価段階は全ゲーム共通で、評価点が100点なら `perfect`、90点以上なら `great`、80点以上なら `good`、それ未満なら `clear` とする。
- 異なるゲームの同じ点数が同程度の成績であることは表さない。
- 評価点と評価段階は保存せず、記録したプレイ事実から今の評価規則で導く。
