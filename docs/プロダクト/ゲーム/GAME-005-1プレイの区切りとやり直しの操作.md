# GAME-005 1プレイの区切りとやり直しの操作

1回のプレイがどこで始まりどこで終わるかと、プレイ中のやり直しの操作の決まり。この区切りを、計測・評価・記録・自己ベストの比較のすべてで同じに扱う。

1回のプレイは、一つの問題を初期状態から始めた時点で始まり、クリアしたとき、リセット・別の問題の開始によって新しいプレイに置き換わったときに終わる。画面移動や再読み込みはプレイの終了条件ではない。

## やり直しの操作

プレイ中に盤面や問題をやり直す操作は次の4つとし、呼び名とプレイの区切りに対する意味を固定する。

| 操作 | すること | プレイ |
| --- | --- | --- |
| 待った | 直前の盤面操作を取り消す | 同じプレイの続き |
| 盤面を戻す | 盤面を初期状態へ戻す | 同じプレイの続き |
| リセット | 同じ問題を初期状態から始める | 新しいプレイ |
| 別の問題 | 同じ難易度で別の問題を始める | 新しいプレイ |

- 同じプレイの続きでは、経過時間とそれまでの計数を引き継ぐ。待った・盤面を戻すを使った回数は、そのプレイの事実として数える。
- 新しいプレイでは、経過時間と計数を数え直す。
- 「別の問題」はすべてのゲームが提供する。待った・盤面を戻す・リセットのどれを提供するかはパズル仕様で定める。

## そのほかの区切り

- クリア後の結果で同じ問題を始める操作はリセットと、次の問題を始める操作は「別の問題」と同じ意味を持つ。
- 再読み込みやブラウザの戻る・進むで同じ問題のプレイへ戻る場合、同じ挑戦の盤面・操作履歴・経過時間・計数を引き継ぐ。
- ゲームのホームやパズル選択への移動はプレイの中断であり、リセットではない。中断時点の試行記録は残し、復帰した場合は同じ挑戦として扱う。
- プレイの途中状態は同じタブ内で保存する。別タブ・別端末への同期は行わず、新しい問題を始めた場合は前の挑戦を引き継がない。
