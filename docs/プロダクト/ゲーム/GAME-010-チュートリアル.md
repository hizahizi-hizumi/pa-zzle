# GAME-010 チュートリアル

各ゲームが持つチュートリアルの決まり。

## 進め方

- 1つの盤面を、ルールを1つずつ示しながら、利用者と一緒に解く。
- 最初は手順ごとに一言と、操作する所かその手を決める物を示して手を引き、すべての手順を終えたら手を離して、残りを利用者に解かせる。
- すべての手順を終えたとき、本番のレベル1を進めるのに要るルールと読みを使い終えているようにする。最後の手順では、その読み（パズル仕様の段階設計にある難易度1の挑戦）を使わせる。
- 盤面1枚では伝えきれないこと（駒の動きの一覧、この盤面に出ない仕掛けなど）は、その場で開ける遊び方の説明に任せる。
- ルールは、それを示す手順を始めたときに手に入る。
- まだ示していないルールの違反は見せない。
- ルールに合わない所ができたときの一言は、どのルールに当たったかを、今の盤面から具体的に言う。
- ルールに合わない手や、手順から外れた手の後は、直す所や押す所に印を付けてよい。
- 手を引いている間に、手が止まったら次に押す所を示してよいのは、押す所を利用者に探させる手順（押す所に印を付けない手順や、印を付けた複数の所のどれをどう押すかを選ばせる手順）だけにする。
- 手を離した後は、次の手を示す手がかりを、利用者が「ヒント」で求めたときだけ見せる。手が止まっても、手がかりを出して割り込まない。

## 導入

- 開いたときは、操作より先に、ゲーム名と何をするパズルかを、解き終えた盤面と一緒に見せる。
  - 何を目指すかを、始めの盤面より先に見せるため。
- 解き終えた盤面は、自動では先へ進めず、利用者の「はじめる」でだけ始めの盤面へ替え、そのまま最初の手順に入る。
  - 盤面を見る速さは人によって違うので、自分のペースで進められるようにする。
- 解き終えた盤面を見せている間と、始めの盤面へ替える間は、盤面を押せない。

## 開いた場所と終え方

- チュートリアルは、ゲームのホームとプレイ中のメニューから開けるほか、URLから単独で開ける。
- 解き終えたら、覚えたルールを振り返ってから、本番へつなぐ操作を出す。
- 解き終えたときの一言は、本番へどうつながるかを言う。開いた場所で本番へのつながりが違うときは、開いた場所ごとに言い分ける。
- ゲームのホームから開いたときは、終えて遊び始める操作で、ゲームのホームで開いていた難易度を始める（GAME-002）。
- プレイ中のメニューから開いたときは、終えたらプレイに戻る。
- URLから単独で開いたときは、閉じればゲームのホームに戻り、終えて遊ぶ操作なら新しい問題を始める。
- チュートリアルを終えたかどうかは残さない。開くたびに、導入から始まる。
- 解き終えた後の「もう一度」では、導入を見せず、最初の手順から始める。
