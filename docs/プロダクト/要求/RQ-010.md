# RQ-010 遊んできた問題を自分の跡として集め、次の1問を自分で選びたい

同じパズルで遊んできた問題を、遊ぶたびに流れて消えるものではなく、1問ずつ自分の跡として残したい。

- 1問解いたあと、その1問が集めてきたもののどこに加わったかを確かめ、遊んだことが積み上がっていくのを感じたい。
- それぞれの問題をどこまでうまく解けたかを知り、同じ問題で前の自分を超えたい。
- まだ遊んでいない問題や途中でやめた問題を見つけ、次に遊ぶ問題を自分で選びたい。
- 自分がどれだけ、どんな出来で遊んできたかを、全体の姿として眺めたい。

集めることは、埋め切ることを課されるノルマではなく、もう1問遊びたくなる理由であってほしい。
