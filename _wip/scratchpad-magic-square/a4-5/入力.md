## 反例探し（A4）の5回目の入力

経緯を渡さない新しい確かめ役に、この節だけを渡す。範囲内の問題（レベルが付いた問題）について、人が使いうる読み方・数え方のうち、同じ問題のレベルを動かすものを探してもらう。

### ルール

n×n のマスに 1〜n² を1回ずつ置き、縦・横・斜め2本のどの列も同じ合計 n(n²+1)/2 にすればクリア。いくつかの数は最初から置いてある。答えは1つ。盤面には、置いた数、列の端の今の合計と合計の定数、候補のメモ（マスに小さく書く数。1マス4つまで。置いた数は全部のメモから消える）が見える。違反（埋まって合わない列、空きがあるのに合計に届いた・超えた列）は知らされ、行き詰まりは知らされない。盤面は 4×4・5×5・6×6。

### 特徴の定義

**読む単位**。どちらも「その単位の空きマスに、メモの候補の数を互いに違うように入れて、単位の列の合計を全部満たす入れ方」を全部考える。段は、その単位で仮に置く数の数（空きマスの数 − 式の数 + 1）で、入れ方の数に依らない（段は単位で付ける。下の「近道」）。

- 列: 空きが e マスの列。段 e。e = 1 なら、そのマスに残りの数が入る。空き2マスの列は、残っている数で組が1通りでも段2。
- 鎖: 空きが2マスの列が同じマスでつながったまとまり（2本以上、つながった全部）。段2。1つのマスの数を t と置くと、つながった列の相手が順に決まる。

**単位を読んだ結果**（どちらも読んだ巡の結果に入る）

- 台: 単位の各マスの候補を、どれかの入れ方で入る数に絞る。
- 組の数を他で使わない: どの入れ方でも単位の中で使う数を、その巡に読んだ単位のマスのうち単位の外のマスの候補から消す（段2以上）。

**巡**。段 t の1巡は、段 t 以下の単位を全部、巡の始めの候補（同じ写し）から読み、結果を全部重ねること。重ねた候補で、候補が1つになったマスと、入る所が1マスだけになった数（この数はここだけ）を、その巡で決まったマスとする。巡の数は読みの依存の段数の最小になる。

**段と所**。

- 段1 = 空き1マスの列・メモで候補が1つのマス・この数はここだけ。段1で置けない盤面が行き詰まり。
- 行き詰まりでは、段2・段3・段4の順に、どの段も行き詰まりの始めの候補から巡を重ね、決まったマスが出たら止める。出た最も低い段を使い、その段と巡の数をその「所」の値にする。段3の巡は段2の単位も一緒に読んで数える。
- 決まったマスは全部置いて段1に戻る。メモは残す（基準はメモの数に上限を置かない）。
- 深い所 = 段3の所か、段2で2巡以上の所。
- 近道: 組が少ない単位を、単位の段より低い段で読む読み方（下の部品 `short3_*`・`jointk2_s*`・`pair1`、測るだけの `jointk3_s*`・`jk2t2`）は、近道なしで置けない所でだけ近道を使うとみなし、近道で初めて置けた所は近道を使った段の1つ上（空き3の列を含む単位なら段3、空き2の列なら段2）と数える（`read_solve` の `try_tier`）。その所の巡は、近道を使った巡と、1つ上の段を近道なしで読んだときの巡の少ない方（近道は深くしない）。近道は所の段を変えない。基準の読むモデルは近道を持たない。

**特徴**

| 特徴 | 定義 | 分類での使い方 |
| --- | --- | --- |
| 入口 | 最初の盤面の段1の1巡で決まるマスがあるか | L2 はある、L3〜L5 は無い |
| 段の最大 | 所の段の最大 | L1 は1、L2・L3 は2、4 は範囲外 |
| 深い所 | 段3の所か段2で2巡以上の所があるか | L4・L5 はある |
| 最初の所 | 最初の所の段と巡（入口がある問題は段1・1巡） | L5 は最初の所が深い。作るときの帯（下） |
| 段3の所・段2の所の巡の最大 | 段3の所があるか、段2の所の巡の最大 | 作るときの帯（下） |
| 1か所の巡の最大 | 段2以上の所の巡の最大 | 基準の読み方で4を超えると範囲外（作り方の決まり。レベルの比べ合いには使わない） |
| 段1で極小 | 段1だけで解け、どの与える数を1つ外しても基準の段1だけでは解けない | L1 の作り方の決まり（基準で測る。読み方で比べない） |
| 組の突き合わせの回数・絞り直しの回数 | 段2以上の所の数・巡が2以上の所の数 | 使わない（記録だけ） |

**レベル**（上から当てる）

| レベル | 盤面 | 条件 | 作るときの帯（基準の読み方だけで測る） |
| ---: | --- | --- | --- |
| 1 | 4×4 | 段1だけで解ける | 与える数を基準の段1で極小にする |
| 2 | 4×4・5×5 | 入口がある。段2まで要り、深い所は無い | ― |
| 3 | 5×5・6×6 | 入口が無い。段2まで、深い所は無い | ― |
| 4 | 5×5・6×6 | 入口が無い。深い所があり、最初の所は深くない | 段3の所か、段2で3巡以上の所がある |
| 5 | 5×5・6×6 | 入口が無い。最初の所が深い | 最初の所が段3で2巡以上か、段2で3巡以上 |

範囲外: 段4が要る（`long-line`）、段4でも止まる（`requires-trial`）、基準の読み方で1か所の巡が4を超える（`too-deep`）、段1だけで解けるが基準の段1で極小でない（`not-minimal`）、入口があって深い所もある（`unlisted-combination`）、読みのレベルはあるがその盤面を許していない（`size-not-allowed`。5×5・6×6 の L1、6×6 の L2、4×4 の L3〜L5）、4×4 で仮想の列（四隅・中央 2×2・上下の辺の中央2マス・左右の辺の中央2マスも合計34）を足すとレベルが下がる（`virtual-shortcut`）、基準の読み方で L4・L5 だが作るときの帯に入らない（`near-boundary`）、次の一致の決まりに当たらない（`reading-dependent`）。

**一致の決まり**。上の定義（基準）のほかに、次の 32 の部品と、その2つ・3つの組み合わせ（461 通り・4,026 通り）でも同じ定義で特徴を測る。レベル（範囲外を含む。巡の上限と作るときの帯は当てない）が基準と1つでも違えば `reading-dependent` として出さない。組み合わせでは、「K 通りまで」「K 本まで」の設定は大きい方、「段 t から」は低い方を採り、ほかの設定に違う値が入る組と、前に出た組と設定が同じ組は除く。4×4 は、どの読み方でも、その読み方に仮想の列を足して読むとレベルが下がるなら `virtual-shortcut` として比べる。

| 部品 | 中身 |
| --- | --- |
| `carry` | 段を上げた所で、下の段を出し切った候補から続け、上げた段の巡だけ数える |
| `cum` | `carry` に、下の段で候補が動いた巡を足す |
| `lock_all` | 組の数を他で使わないで、単位の外の全マスの候補から消す |
| `lock_eph` | 組の数を他で使わないで消した数を候補に残さない（その巡に置けるマスを探すのにだけ使う） |
| `memoryless` | メモを使わず、置くたびに盤面から読み直す |
| `memo4` | メモに書けるのは候補が4つ以下のマスだけ。候補が5つ以上のマスは、巡の間で絞り込みを覚えず、残っている数全部に戻る |
| `one` | 1巡で決まったマスを1つずつ置く |
| `fewest` | 行き詰まりで、巡の最も少ない段を使う |
| `lock_next` | 組の数を他で使わないを次の巡から効かせる（`lock_eph` と重ねると、次の巡の置き場所探しにだけ使う） |
| `hidden_next` | この数はここだけを次の巡から効かせる |
| `range1`・`range2` | 列の上下限（空き e の列の各マスは、残り − 残っている数の大きい e−1 個の和以上、残り − 小さい e−1 個の和以下）を段1から・段2から使う |
| `viol1`・`viol2` | 違反の知らせで分かる上限（空きが2マス以上の列に、残り以上の数は置けない）を段1から・段2から使う |
| `mrange1`・`mrange2` | メモの最小・最大で、空き3以上の列の各マスの上下限を取る（ほかのマスのメモの最大の和・最小の和から）。段1から・段2から |
| `short3_1`〜`short3_4` | 組が1〜4通りまでの空き3の列を段2の読みに混ぜる（近道。それで初めて置けた所は段3） |
| `jointk2_s1`・`jointk2_s2` | 空き3の列と交わる1本の列の組を、入れ方が1通り・2通りまでなら段2の読みに混ぜる（近道。同） |
| `jointk2` | 空き3の列と、交わる空き2〜3の列を一緒に読む（段3） |
| `pair1` | 残っている数で組が1通りの空き2の列を段1の読みに混ぜる（近道。それで初めて置けた所は段2。その列から組の数を他で使わない） |
| `chain4t3` | 4本以上の列がつながった鎖を段3に数える |
| `diag_nochain` | 斜めの列を鎖（と `jointk2` の組）につながない |
| `chain_late` | 段2以上の各段の1巡目は列を1本ずつ読み、鎖は2巡目からつなぐ |
| `chain2` | 鎖をつながった2本ずつに分けて読む |
| `nohidden` | この数はここだけを使わない |
| `chain_nolock` | 鎖から組の数を他で使わないをしない |
| `strong` | `range1`・`short3_2`・`jointk2`・`carry`・`lock_all` を一緒に |
| `weak` | `cum`・`lock_next`・`chain2`・`nohidden`・`chain_nolock`・`memoryless` を一緒に |

### 測るコードの関数

`docs/パズル/導入調査/魔方陣/調査コード/magic_square_difficulty.py`（標準ライブラリだけ）。

- 読み: `enumerate_line`（1本の列の入れ方）、`enumerate_eqs`（鎖などの一般の単位）、`line_units`・`chain_units`・`jointk_units`・`build_units`（単位を作る）、`read_solve`（段・巡・置き方・メモの上限。設定は `DEFAULT_READ`、部品と測るだけの変種は `VARIANTS`）
- 特徴と分類: `read_features`（`FEATURE_KEYS` が主な特徴。`d2max` が段2の所の巡の最大、`d3max` が段3の所の巡の最大、`t3` が段3の所の数、`first_hard` が最初の所が深いか）、`is_tier1_minimal`、`level_v6_raw(f, cap)`（盤面に依らない1つの読み方でのレベル。`cap=None` で巡の上限を当てない）、`single_level_v6(f, n, sizes, cap)`（盤面の割り当てと 4×4 の仮想の列を当てる）、`band_reason(f, level)`（作るときの帯）、`classify_v6`（一致の決まりまで当てた最終のレベル）、`classify_givens(n, givens)`（与える数だけから同じ結果を出す）、`AGREE`（32 の部品）、`AGREE_COMBOS`（1〜3つの組み合わせの名前。`"a+b+c"` の形）、`variant_kw(name, merge=True)`（名前から `read_solve` の設定）、`combo_level(geo, givens, name, sizes)`（組み合わせでのレベル）、`SIZES_V6`（盤面の割り当て）
- 1問を全部の部品で測る: `measure_all(geo, givens)` が (基準の特徴, 変種ごとの特徴, 段1で極小か, 基準の `read_solve` の結果) を返す。`classify_v6` は、単独の部品で一致すれば組み合わせ（`agreement_combos`）も確かめ、結果を `d["agree"]` に入れる
- 候補を作る: `generate_candidate(n, T, k, i)`。下の「範囲内の問題を作る」で、全候補のレベルと特徴を JSONL に書ける
- 1問を測る:

```sh
python3 -B -c "import sys; sys.path.insert(0, '<調査コード>'); import magic_square_difficulty as m; n=5; g=[<与える数を行優先で25個。空きは0>]; geo=m.geo_of(n); b, v, mn, r = m.measure_all(geo, g); d={'n': n, 'givens': g, 'base': b, 'var': v, 'l1_minimal': mn}; print({k: b[k] for k in m.FEATURE_KEYS}); print(m.classify_v6(d, m.SIZES_V6), d.get('agree')); print({x: m.single_level_v6(v[x], n, m.SIZES_V6, cap=None)[0] for x in m.AGREE}); print([(s['tier'], s['sweeps'], s['cells']) for s in r['steps']])"
```

- 新しい読み方を当てる: `read_solve` の設定を足すか写しを作り、`f = m.read_features(geo, g, m.read_solve(geo, g, **設定))`、4×4 なら `f['_virtual'] = m.read_features(geo, g, m.read_solve(geo, g, extra_lines=m.VIRTUAL4, **設定))` として `m.single_level_v6(f, n, m.SIZES_V6, cap=None)` を、範囲内の問題の `level` と比べる。新しい近道（組が少ない単位を低い段で読む読み）を当てるときは、`run_tier` の `plain` と `try_tier` に合わせて、近道で初めて置けた所を1つ上の段と数え、巡は1つ上の段を近道なしで読んだときを超えないようにする（段を付け替えたまま、または近道の巡のまま数えると、版 6 の定義とは別の段の付け方を測ることになる。`MSD_UNIT_TIER=0`・`MSD_SWEEP_CAP=0` でそれぞれの別の数え方になる）。部品と重ねるには `{**m.variant_kw('carry+memo4', merge=True), **新しい設定}` のように設定を重ねる。

### 探す向き

1. 32 の部品の外の、人が使いうる読み方。とくに、作るときの帯を越えて隣へ移す読み: L5 の最初の所が段2・1巡で決まるようになる読み（3マスの列を含む単位を読まずに、作り直しもせずに最初の1マスが決まる）、L4 の3マスの組を読む所と段2の3巡以上の所が両方とも要らなくなる読み、L3 に深い所が要るようになる読み（列や鎖を読む時機を遅らせる、単位を小さく分けるなど）、L3 に入口ができる読み、L2 が段1だけで解ける読み。上下限やメモの和の見積もりのような、単位を読まずに候補を絞る読みの延長（版 6 の段の付け方は、これらを近道として扱わない）。
2. 段の付け方の妥当さ。版 6 は段を単位で付け、組が少ない単位を低い段で読む近道（組が少ない空き3の列・交わる2〜3本の組を段2で、組が1通りの空き2の列を段1で）は、近道なしで置けない所でだけ使い、その所を1つ上の段と数え、その所の巡は1つ上の段を近道なしで読んだときの巡を超えない（近道は深くしない）。これで近道の族ではレベルが動かなくなった（下の表）。近道の巡をそのまま数えると、近道に読みを弱める部品を重ねたときに、近道で段1の巡を重ねた所が深い所になった（下書き §4.4）。近道を使う人に、その所が「3マスの組を読んだ所」「2マスの組を読んだ所」と感じられないような盤面があるか、近道の扱いそのものに反例があるか（たとえば、近道を先に使う人で巡や置く順が変わり、別の所の段が変わる問題）を探してほしい。
3. 段の付け方のほかの別案のうち、人が自然に使いそうなもの（今の付け方は「仮に置く数の数」で、4本以上の鎖を段3に数える人は部品）。
4. メモの使い方の別案。ゲームのメモは1マス4つまで。4つの選び方（たとえば大きい方から4つ書く、列の組に出てくる数だけ書く）、メモを書くマスの選び方、メモの和や差の使い方など。
5. 部品の4つ以上の組み合わせで、特に動きやすい組（3つまでは一致を求めた。2つ・3つの組で外れる問題の多くは `range1+mrange1`・`chain_late`・`one+range1+mrange1`・`strong+mrange1+pair1`・`strong+mrange2+pair1`・`memo4+chain_late` を含む組。4つは無作為な 1,000 通りと 150 通りで0だった）。
6. 6×6 だけ、または 4×4 の L2 だけで揺れが大きくなる向き（4×4 の L2 は 26 問と少なく、段1の上下限で多くが外れた）。
7. 作るときの帯の抜け。帯の内側でも、隣のレベルとの差がほとんど無い問題（たとえば L4 で段3の所が1つだけで巡1、L5 で最初の所が段3・2巡）が、自然な読み方で隣に移らないか。

反例は「範囲内の問題のレベルが、自然な読み方・数え方で別のレベル（範囲外を含む）になる」もの。範囲外の問題が範囲内に入るのは反例ではない。巡の上限（4）・L1 の極小・作るときの帯は基準の読み方で測る作り方の決まりで、読み方でその値が変わることは反例に数えない（その読み方でレベルが変わるなら反例）。割合は範囲内 866 問に対して、盤面ごとにも出す。反例が出たら、その読み方を部品に入れるか、定義を値の動かない形に直して決め直す。読み方が自然かどうかの判断も添える。

## 問題供給と図鑑の観点への入口

- 関数（`magic_square_difficulty.py`）:
  - `generate_candidate(n, T, k, i)`: 1候補を作る。
    - n は盤面、T は極小化に使う読みの段の上限（1〜3）、k は 0〜2 なら空けたマスを k 個戻し、12 なら L5 向け、13 なら L4 向けに200回磨く（点に6つの読み方での一致を入れる）。i は候補番号。
    - seed は `candidate_seed(n, T, k, i) = ((n×10 + T)×100 + k)×10000 + i`。
    - 返り値に `givens`・`solution`・時間。
  - `analyze_candidate(cand)`: 完全な解法器・読むモデル・素朴な解き方を当てる。
  - 分類: `classify_givens(n, givens)` が (レベル, 範囲外の理由)（版 6。盤面の割り当ては `SIZES_V6`）。違う読み方を見つけた所で止める。`measure_all` → `classify_v6` と同じ結果（範囲外の理由は最初に見つかったもの。版 6 の候補 192 で全部一致）。1候補の分類は 4×4 0.01〜2.3秒、5×5 0.6〜31秒、6×6 4〜24秒（生成条件ごとの平均。範囲内の問題には部品の1〜3つの組み合わせ 4,519 通りを全部当てるので、範囲内が多い条件ほど重い）。
- コマンド: 上の「範囲内の問題を作る」と同じ。`classify` の出力 `classified.jsonl` は候補ごとに `id`・`seed`・`T`・`k`・`level` を持つ。範囲外なら `level` が null で、`reason` に `not-minimal`・`near-boundary`・`reading-dependent`・`too-deep`・`virtual-shortcut`・`size-not-allowed`・`unlisted-combination`・`long-line`・`requires-trial` が入る。ほかに特徴（`FEATURE_KEYS`）・慣れた試し置きの戻し・`givens`・`solution` を持つ。
- 何問作れるか（当たる割合、事実（実測）。下書き §6.2）:
  - L1 は 4×4 T1 k0 100%。L2 は 5×5 T2 k1 52%・T2 k2 35%・T3 k2 32%・T2 k0 25%、4×4 T2 k0 15%・T2 k1 12%・T3 k1 10%。
  - L3 は 5×5 T2 k13 82%、6×6 T2 k13 75%。L4 は 5×5 T3 k13 78%、6×6 T3 k13 70%。L5 は 5×5 T3 k12 73%、6×6 T3 k12 64%。
  - 1問あたりの時間（生成 + 一意性 + 分類）は L1 2.3秒、L2 0.2〜10秒、L3 5〜10秒、L4 23〜39秒、L5 33〜44秒。各レベル500問（2つの盤面は半分ずつ）は3プロセスで全部4時間ほどの見込み（推測）。足りなくなる盤面は無い見込み。
  - 5×5 の魔方陣は向き違いを除いて 275,305,224 通り（外部知見。測っていない）、6×6 はさらに多い（同）。与える数の置き方も掛かるので、500問は候補空間に対して小さい（推測）。
  - 4×4 は魔方陣 880 通りが上限で、L1 の 500 問と L2 の 4×4 の 250 問を魔方陣の重複なしで作るのは難しい（L2 の 4×4 は当たる割合が 15% まで。下書き §6.3）。同じ魔方陣を別の与える数で出すかは、この観点で決める。
- 供給の調査コード（`magic_square_supply.py`）は版 4 の分類（`classify_v4`・`SIZES_C2`）と `AGREE` を呼ぶ。版 6 で `AGREE` は 32 の部品になり（版 4 の 21 は `AGREE_V4`、版 5 の 24 は `AGREE_V5`）、近道の部品の段の数え方も変わった。版 6 に合わせるには、分類を `classify_givens`（か `measure_all` → `classify_v6`）、盤面の割り当てを `SIZES_V6`（版 5 と同じ）に替え、L4 を k = 13 から作る。分類は版 4 より重い（上の1候補の分類の時間）。
- 図鑑の特徴の材料: 始めたときの盤面で分かるのは、盤面・与える数・入口のマス。読みの量（巡・段3・突き合わせ）は解いて初めて分かり、分類にも使っている（難易度の写しになりやすい）。レベルごとの最小 / 10 / 50 / 90 / 最大は下書き §11。
