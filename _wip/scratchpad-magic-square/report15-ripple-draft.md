## 6. 波及（`ripple.md` の「`/add-puzzle` からの入口」）

| 段 | 通したか |
| --- | --- |
| 判定モデル（読むモデル・部品・梯子・帯） | 通した。`MAGIC_SQUARE_DIFFICULTY_MODEL_VERSION = "reading-v8"`（`difficulty.ts`） |
| 生成器 | 通した。候補の作り方（`candidate.ts`）と生成スクリプト。生成器の版（identity の `seed` の記法）は変えていないので `MAGIC_SQUARE_GENERATOR_VERSION` は "1" のまま |

| 難易度の資料 | 通していない（導入調査のディレクトリは読むだけの決まり）。更新したい所を「頼むこと」に書いた |
| 採点（score） | 通していない（自分の項目の外）。問題集の各問に作業の量を持たせた。基準時間に使う量と記録の形は score の項目 |
| 図鑑（zukan） | 通していない（自分の項目の外）。図鑑の枠と番号は問題集の件数と並びで決まり、今回はじめて 500 問ずつになった（公開前なので遊ぶ人の記録は変わらない） |
| パズル仕様（spec） | 通していない（自分の項目の外）。資料 §12 の案を使う |
| 記録（payloadVersion） | 該当なし。記録の形は変えていない |
