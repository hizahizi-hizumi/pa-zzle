## 結論

**条件つきで成り立つ（前の回の決定を保つ）。** 版 8 の問題でも、切り口は「盤面」「最初の数（2個ごとにまとめる）」「空きだけの列（まとめない）」の3つで、3つの物差しを前の回と同じ形で満たす。満たさなくなった特徴は無いので、案の比べ直しはしていない。前の回から変わったこと・新しく分かったことは2点。

- 空きだけの列は、難易度とも最初の数とも前の回より離れた（層の中の読みの量との相関の絶対値の最大 0.45 → 0.28、最初の数との相関の絶対値の最大 0.63 → 0.38）。6×6 で 0本が 79〜95% を占めて分かれにくいのは変わらない。
- 最初の数は、前の回と同じく L2 と L4 で値がちょうど8種で、まとめが効いていない。各レベル500問の問題集で8種を超えたときを今回測ると、幅 3 では L4 の 5×5 の 96% が1つの選択肢に入り、幅 2 なら 68% だった。幅 2 を採る理由が1つ増えた。

問いごとの答え:

- **問い1（3つの物差しの測り直し）**:
  - **レベルの中で値が分かれるか**: 3つとも成り立つ（盤面は L1 を除く）。
    - 盤面: L2〜L5 は2種、L1 は 4×4 だけ。
    - 最初の数: L1 は 569問すべて8個で、軸は出ない。L2〜L5 は 8〜11種。幅 2 で盤面を選んだ後は 3〜5種・最多 40〜84%。
    - 空きだけの列: L1 は 0本 63%・1本 33%・2本 4% で、L1 で分かれる唯一の推奨の軸のまま。L2〜L5 は盤面ごとに 2〜4種。5×5 は最多 44〜62%、6×6 は 0本が 79〜95%。
  - **ほかの特徴と重ならないか**: 条件つきで成り立つ。
    - 最初の数と盤面は、同じレベルの中で盤面をまたぐと +0.73〜+0.88。ただし幅 2 でも幅 3 でも、まとめた選択肢が盤面をまたぐことは無い（入れ子で、最初の数は盤面の中を分ける）。
    - 空きだけの列は、同じレベル・盤面の中で最初の数と −0.38〜+0.04、同じレベルの中で盤面と −0.29〜−0.45。
  - **難易度の写しにならないか**: 空きだけの列は成り立つ。最初の数は条件つきで成り立つ。盤面は難易度の盤面の割り当てそのもの。
    - 空きだけの列: レベルとの順位相関は +0.02（5×5 だけで +0.13・6×6 だけで +0.22）。同じレベル・盤面の中の読みの量との相関の絶対値は 0.28 以下（版 8 の梯子に使う量を含む）、慣れた試し置きの戻しとは 0.30 以下。
    - 最初の数: 同じ盤面ではレベルと −0.57（5×5）・−0.56（6×6）。隣のレベルと値が重なるので、レベルの写しにはならない（5×5 の 10 / 50 / 90 パーセンタイルは L2 11/12/13、L3 10/11/12、L4・L5 9/10/11 で、前の回と同じ）。同じレベル・盤面の中では、組の突き合わせの回数と −0.42〜−0.73、L4・L5 の段3の所の数と −0.29〜−0.45（前の回は −0.39〜−0.73）。版 8 の梯子と帯に使う量（3巡以上の所・段2の巡の最大・最初の所の巡）とは、絶対値 0.37 以下。読みの種類ではなく、読む所の数（作業量）の目安になる。
    - 盤面: レベルと +0.48。
- **問い2（値の書き方とまとめる幅）**: 合う。直す所は無い。
  - 最初の数は「個」、幅 2。
  - 空きだけの列は「本」で、まとめない（値は0〜3本）。問題の詳細には1本以上のときだけ出す。
- **採らない案**（前の回の判断を版 8 の値で確かめ直した）:
  - 1マスだけ空いた列・入口・いちばん埋まった列の空き: L3〜L5 で全問同じ値（0・0・2）。レベルとの相関は −0.78・−0.78・+0.78 で、L2 と L3 の境目そのもの。
  - 配置の対称: 767問中1問。埋まった列: 83〜100% が0本。
  - 大きい数の数・角の数: 列の構造を保つ並べ替え × 補数で、値が変わらない問題が 17%・23% だけ。
  - 2マス空いた列: L1 の中で段1の巡の数と +0.55、L3 の中で組の突き合わせと −0.41〜−0.42、1マス空いた列と −0.81。
  - 斜めの空き: L1 の中で段1の巡の数と +0.50、角の数と −0.59。
  - 1 と最大の数、大きい数と小さい数の差: 値は分かれ、読みの量との相関も 0.44 以下と小さい。ただし、次の1問を選ぶ手がかりとしての意味が薄い（推測）。

## 事実と推測

- 事実（計測）: L1（段1だけで解ける・極小）は、569問すべて最初の数が8個だった。盤面も 4×4 だけなので、今の実装（盤面と最初の数）では、L1 の図鑑に問題の特徴の軸が1つも出ない。根拠は、選択肢が1つの軸は出さない作り（`frontend/src/features/zukan/zukan-filter.ts`）。版 8 でも変わらない（`measure` の (1)）
- 事実: 今の実装は、まだ盤面（`square-board-size`）と最初の数（個、幅 3）の2つ: `frontend/src/games/magic-square/problem/problem-pool.ts` の `magicSquareProblemFeatureAxes`・`ui/problem-features.ts`
- 事実: 図鑑の数の選択肢は、レベルの値が8種以下ならそのまま、超えたら `Math.floor(値 / 幅)` でまとめる。幅を持たない軸はまとめない: `frontend/src/features/zukan/zukan-filter.ts` の `listCountOptions`
- 事実: 無い要素（0個）を問題の詳細に出さない前例は、氷の床迷路の要素の数: `frontend/src/games/ice-floor-maze/ui/problem-features.ts`。まとめ幅の前例は 3 が多く、2 はウォーターソートの空ボトルとパーキングジャムの植え込み: `frontend/src/games/*/ui/problem-features.ts`
- 事実（計測）: 入力の `classified.jsonl`（09:47 に作られたもの）の読むモデルの特徴は、今のコード（11:01）で測り直した値と、範囲内 767問の全部で同じだった。4×4 の 70候補では `classify_givens` の分類も同じだった（`measure` の先頭と一時の照合）
- 事実（計測）: L2 の 4×4 の当たる割合は T2 k0 17.5%・T3 k1 10.3%・T2 k1 6.5%（各 400候補）。難易度の資料 §6.2 の 15%・10%・8% と近い
- 事実（計測）: 盤面・最初の数・空きだけの列は、回転・裏返しでも、列の構造を保つ並べ替えと補数でも、全問で値が変わらない（`measure` の (4)）
- 導出: 最初の数を幅 2 でまとめたとき、5×5 の帯（…12〜13、14〜15）と 6×6 の帯（16〜17、…）は、5×5 が14個以下・6×6 が16個以上なら交わらない。4×4（L2 は 5〜7個）と 5×5（L2 は 10個以上）も交わらない。計測した範囲では 5×5 は14個以下、6×6 は16個以上だった
- 導出: 1マスだけ空いた列があれば、その空きは最初の1巡で決まる。よって L3〜L5（入口が無い）では、1マスだけ空いた列は必ず0本になる
- 推測: 各レベル500問の問題集では、L2 と L4 の最初の数は8種を超える見込み。L4 の 5×5 は 8〜11個、6×6 は 16〜19個で、隣の 12個・15個・20個が数問でも入れば9種になる（L3・L5 の同じ盤面にはその値がある）。そのとき幅 3 では、L4 の 5×5 の 96% が 9〜11個の1つに入る
- 推測: 空きだけの列は、盤面を見てすぐ分かる見た目の違い（縦・横・斜めのどれか1本が丸ごと空き）。難易度とほぼ相関しないので、選ぶとレベルの中の難しさではなく、盤面の見た目と始め方が違う問題に当たる。遊ぶ人がこれで次の1問を選ぶかは、試遊と最終レビューで確かめる
- 推測: 最初の数は、同じレベル・盤面の中で、読む所の数（作業量）と負に相関する。「今日は短めの問題を」という選び方の手がかりになる。前例のナンプレ（初期数字）・タクズ（初期配置）と同じ役
- 推測: 問題集の生成条件は問題供給の観点が決める。この観点の「問題集に近い形」は、難易度の資料 §6.2 の当たる割合の高い条件を仮に置いたもの。本文の候補で L3〜L5 の 83〜91%（L3 83%・L4 88%・L5 91%）はその条件から出ていて、絞る前と後で盤面を選んだ後の最多の割合は数ポイントしか変わらなかった（L3 5×5 75% → 80% など）。条件が変わっても割合は大きくは動かない見込み
