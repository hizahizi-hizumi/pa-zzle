## 反例探し（A4）の3回目の入力

経緯を渡さない新しい確かめ役に、この節だけを渡す。範囲内の問題（レベルが付いた問題）について、人が使いうる読み方・数え方のうち、同じ問題のレベルを動かすものを探してもらう。

### ルール

n×n のマスに 1〜n² を1回ずつ置き、縦・横・斜め2本のどの列も同じ合計 n(n²+1)/2 にすればクリア。いくつかの数は最初から置いてある。答えは1つ。盤面には、置いた数、列の端の今の合計と合計の定数、候補のメモ（マスに小さく書く数。置いた数は全部のメモから消える）が見える。違反（埋まって合わない列、空きがあるのに合計に届いた・超えた列）は知らされ、行き詰まりは知らされない。盤面は 4×4・5×5・6×6。

### 特徴の定義

**読む単位**。どちらも「その単位の空きマスに、メモの候補の数を互いに違うように入れて、単位の列の合計を全部満たす入れ方」を全部考える。

- 列: 空きが e マスの列。段 e。e = 1 なら、そのマスに残りの数が入る。
- 鎖: 空きが2マスの列が同じマスでつながったまとまり（2本以上、つながった全部）。段2。1つのマスの数を t と置くと、つながった列の相手が順に決まる。

**単位を読んだ結果**（どちらも読んだ巡の結果に入る）

- 台: 単位の各マスの候補を、どれかの入れ方で入る数に絞る。
- 組の数を他で使わない: どの入れ方でも単位の中で使う数を、その巡に読んだ単位のマスのうち単位の外のマスの候補から消す（段2以上）。

**巡**。段 t の1巡は、段 t 以下の単位を全部、巡の始めの候補（同じ写し）から読み、結果を全部重ねること。重ねた候補で、候補が1つになったマスと、入る所が1マスだけになった数（この数はここだけ）を、その巡で決まったマスとする。巡の数は読みの依存の段数の最小になる。

**段と所**。

- 段1 = 空き1マスの列・メモで候補が1つのマス・この数はここだけ。段1で置けない盤面が行き詰まり。
- 行き詰まりでは、段2・段3・段4の順に、どの段も行き詰まりの始めの候補から巡を重ね、決まったマスが出たら止める。出た最も低い段を使い、その段と巡の数をその「所」の値にする。段3の巡は段2の単位も一緒に読んで数える。
- 決まったマスは全部置いて段1に戻る。メモは残す。

**特徴**

| 特徴 | 定義 | 分類での使い方 |
| --- | --- | --- |
| 入口 | 最初の盤面の段1の1巡で決まるマスがあるか | L2 はある、L3〜L5 は無い |
| 段1で極小 | 段1だけで解け、どの与える数を1つ外しても段1だけでは解けない | L1 の条件（4×4 だけ） |
| 段の最大 | 所の段の最大 | L1 は1、L2・L3 は2、4 は範囲外 |
| 段3の所 | 段3の所があるか | 深い読みの1つ |
| 段2の所の巡の最大 | 段2の所の巡の最大 | 2以上が深い読み、3以上が L5 の条件の1つ、4を超えると範囲外 |
| 最初の所 | 最初の所の段と巡（入口がある問題は段1・1巡） | L5 は段3か、段2で2巡以上 |
| 段3の所の巡の最大 | 段3以上の所の巡の最大 | 4を超えると範囲外（レベルの条件には使わない） |
| 組の突き合わせの回数・絞り直しの回数 | 段2以上の所の数・巡が2以上の所の数 | 使わない（記録だけ） |

**レベル**（「深い読み」は段2で2巡以上の所か段3の所があること。上から当てる）

| レベル | 盤面 | 条件 |
| ---: | --- | --- |
| 1 | 4×4 | 段1だけで解け、与える数が段1で極小 |
| 2 | 4×4・5×5 | 入口がある。段2まで要り、段2の所はどれも1巡で決まる |
| 3 | 5×5・6×6 | 入口が無い。段2まで、段2の所はどれも1巡で決まる |
| 4 | 5×5・6×6 | 入口が無い。深い読みがある。L5 に当たらない |
| 5 | 5×5・6×6 | 入口が無い。最初の所が段3か、最初の所が段2で2巡以上かかり、どこかに段2の3巡以上の所か段3の所がある |

範囲外: 段4が要る（`long-line`）、段4でも止まる（`requires-trial`）、1か所の巡が4を超える（`too-deep`）、段1だけで解けるが段1で極小でない（`not-minimal`）、入口があって深い読みもある（`unlisted-combination`）、読みのレベルはあるがその盤面を許していない（`size-not-allowed`）、4×4 で仮想の列（四隅・中央 2×2・上下の辺の中央2マス・左右の辺の中央2マスも合計34）を足すとレベルが下がる（`virtual-shortcut`）、次の一致の決まりに当たらない（`reading-dependent`）。

**一致の決まり**。上の定義（基準）のほかに、次の 21 の読み方・数え方（変種）でも同じ定義で特徴を測り、レベル（範囲外を含む）が基準と1つでも違えば `reading-dependent` として出さない。4×4 は、どの変種でも、その読み方に仮想の列を足して読むとレベルが下がるなら `virtual-shortcut` として比べる。

| 変種 | 中身 |
| --- | --- |
| `carry` | 段を上げた所で、下の段を出し切った候補から続け、上げた段の巡だけ数える |
| `cum` | `carry` に、下の段で候補が動いた巡を足す |
| `lock_all` | 組の数を他で使わないで、単位の外の全マスの候補から消す |
| `lock_eph` | 組の数を他で使わないで消した数を候補に残さない（その巡に置けるマスを探すのにだけ使う） |
| `memoryless` | メモを使わず、置くたびに盤面から読み直す |
| `one` | 1巡で決まったマスを1つずつ置く |
| `fewest` | 行き詰まりで、巡の最も少ない段を使う |
| `lock_next` | 組の数を他で使わないを次の巡から効かせる |
| `hidden_next` | この数はここだけを次の巡から効かせる |
| `range1`・`range2` | 列の上下限（空き e の列の各マスは、残り − 残っている数の大きい e−1 個の和以上、残り − 小さい e−1 個の和以下）を段1から・段2から使う |
| `viol1`・`viol2` | 違反の知らせで分かる上限（空きが2マス以上の列に、残り以上の数は置けない）を段1から・段2から使う |
| `short3_1`・`short3_2` | 組が1通り・2通りまでの空き3の列を段2で読む |
| `jointk2` | 空き3の列と、交わる空き2〜3の列を一緒に読む（段3） |
| `chain2` | 鎖をつながった2本ずつに分けて読む |
| `nohidden` | この数はここだけを使わない |
| `chain_nolock` | 鎖から組の数を他で使わないをしない |
| `strong` | `range1`・`short3_2`・`jointk2`・`carry`・`lock_all` を一緒に |
| `weak` | `cum`・`lock_next`・`chain2`・`nohidden`・`chain_nolock`・`memoryless` を一緒に |

### 測るコードの関数

`docs/パズル/導入調査/魔方陣/調査コード/magic_square_difficulty.py`（標準ライブラリだけ）。

- 読み: `enumerate_line`（1本の列の入れ方）、`enumerate_eqs`（鎖などの一般の単位）、`line_units`・`chain_units`・`jointk_units`・`build_units`（単位を作る）、`read_solve`（段・巡・置き方。設定は `DEFAULT_READ`、変種は `VARIANTS`）
- 特徴と分類: `read_features`（`FEATURE_KEYS` が主な特徴。`d2max` が段2の所の巡の最大、`d3max` が段3の所の巡の最大、`t3` が段3の所の数）、`is_tier1_minimal`、`level_v4_raw`（盤面に依らない1つのモデルでのレベル）、`single_level_v4`（盤面の割り当てと 4×4 の仮想の列を当てる）、`classify_v4`（一致の決まりまで当てた最終のレベル）、`AGREE`（21 の変種の名前）、`SIZES_C2`（盤面の割り当て）
- 1問を全部の変種で測る: `measure_all(geo, givens)` が (基準の特徴, 変種ごとの特徴, 段1で極小か, 基準の `read_solve` の結果) を返す
- 候補を作る: `generate_candidate(n, T, k, i)`。下の「範囲内の問題を作る」で、全候補のレベルと特徴を JSONL に書ける
- 1問を測る:

```sh
python3 -B -c "import sys; sys.path.insert(0, '<調査コード>'); import magic_square_difficulty as m; n=5; g=[<与える数を行優先で25個。空きは0>]; geo=m.geo_of(n); b, v, mn, r = m.measure_all(geo, g); d={'n': n, 'base': b, 'var': v, 'l1_minimal': mn}; print({k: b[k] for k in m.FEATURE_KEYS}); print(m.classify_v4(d, m.SIZES_C2)); print({x: m.single_level_v4(v[x], n, m.SIZES_C2)[0] for x in m.AGREE}); print([(s['tier'], s['sweeps'], s['cells']) for s in r['steps']])"
```

- 新しい読み方を当てる: `read_solve` の設定を足すか写しを作り、`f = m.read_features(geo, g, m.read_solve(geo, g, **設定))`、4×4 なら `f['_virtual'] = m.read_features(geo, g, m.read_solve(geo, g, extra_lines=m.VIRTUAL4, **設定))` として `m.single_level_v4(f, n, m.SIZES_C2)` を、範囲内の問題の `level` と比べる。変種どうしを組み合わせるには `{**m.VARIANTS['carry'], **m.VARIANTS['range2']}` のように設定を重ねる。

### すでに測った向き（同じ向きを繰り返さなくてよい）

「今の扱い」の「一致」は 21 の変種に入れたもの（範囲内では定義により 0%）、「測るだけ」は分類に使わず割合だけ測ったもの。「範囲内で動く割合」は上の範囲内 669 問でレベルが変わる割合。

| 向き | 今の扱い | 範囲内で動く割合 |
| --- | --- | --- |
| 2本の列の差・和（空き3まで） | 測るだけ（`combo2`） | 0% |
| 交わる2本を一緒に読む（空き3・4・5マスまで） | 測るだけ（`joint3`・`joint4`、空き5マスは 5×5・6×6 だけ） | 0% |
| 3本の列の ±1 の式（空き3・4マスまで） | 測るだけ（`combo3`、空き4マスは 5×5・6×6 だけ） | 0% |
| 4本の列の ±1 の式 | 測るだけ | 2.8%（主に L5・L4 → L3） |
| 列の式の一次結合で決まるマスを段1で読む | 測るだけ（`lin`・`allx`） | 2.8%（主に L3 → L2 か範囲外） |
| 鎖を2本ずつ・3本ずつ・極大の道ごとに読む | 2本ずつは一致（`chain2`）、ほかは測るだけ | 0% |
| 鎖の中で同じ列の外のマスどうしを区別しない | 測るだけ | 0% |
| 鎖を読まない | 測るだけ（`nochain`） | 10.3%（主に L3 → L4） |
| 段を上げた所の巡（続きから・下の段の巡も足す） | 一致（`carry`・`cum`） | 0% |

### 探す向き

1. 21 の変種の組み合わせ。`strong`・`weak` 以外の2〜3個の組み合わせ（たとえば `carry` と `range2`、`lock_eph` と `cum`、`viol1` と `short3_1`）で、範囲内の問題のレベルが動くか。
2. 磨いた候補（k = 12）に偏って効く読み方。磨く処理は5つの変種（`cum`・`lock_next`・`weak`・`strong`・`lock_eph`）で一致するように与える数を動かしたので、ほかの自然な読み方で L4・L5 の磨いた問題が動きやすくないか。
3. 上の表に無い、人が使いうる読み方。とくに、L5 の最初の所が段2以下で決まるようになる読み（3マスの組を読まずに最初の1マスが決まる）、L3 に入口ができる読み、L4 の深い読みが要らなくなる読み、L2・L3 で深い読みが要るようになる読み。
4. 段の付け方の別案。どの読みを段2・段3に数えるか（たとえば空き3の列と交わる空き2の列を一緒に読むのを段2と数える）を自然な別案に変えると、レベルが動くか。
5. L1 の条件。段1で極小な 4×4 を、人が「すぐ埋まる」と感じる別の量で割れるか。段1で極小でない（`not-minimal`）問題と L1 の問題の差が、人の手応えで消えないか。
6. 6×6 だけ、または 4×4 の L2 だけで揺れが大きくなる向き。
7. 一致の決まりの抜け。21 の変種で一致しても、隣のレベルとの差がほとんど無い問題（たとえば L4 で段2の巡がちょうど2、L5 で最初の所が段2・2巡）が、自然な読み方で隣に移らないか。

反例は「範囲内の問題のレベルが、自然な読み方・数え方で別のレベル（範囲外を含む）になる」もの。範囲外の問題が範囲内に入るのは反例ではない。割合は範囲内 669 問に対して、盤面ごとにも出す。反例が出たら、その読み方を一致を求める変種に入れるか、定義を値の動かない形に直して決め直す。

## 問題供給と図鑑の観点への入口

- 関数（`magic_square_difficulty.py`）:
  - `generate_candidate(n, T, k, i)`: 1候補を作る。
    - n は盤面、T は極小化に使う読みの段の上限（1〜3）、k は 0〜2 なら空けたマスを k 個戻し、12 なら200回磨く（点に一致を入れる）。i は候補番号。
    - seed は `candidate_seed(n, T, k, i) = ((n×10 + T)×100 + k)×10000 + i`。
    - 返り値に `givens`・`solution`・時間。
  - `analyze_candidate(cand)`: 完全な解法器・読むモデル・素朴な解き方を当てる。
  - 分類: `measure_all(geo_of(n), givens)` → `classify_v4({"n": n, "base": 基準の特徴, "var": 変種ごとの特徴, "l1_minimal": 段1で極小か}, SIZES_C2)` が (レベル, 範囲外の理由)。`level_v4_raw(f)` は盤面に依らない1つのモデルでのレベル。
- コマンド: 上の「範囲内の問題を作る」と同じ。`classify` の出力 `classified.jsonl` は候補ごとに `id`・`seed`・`T`・`k`・`level` を持つ。範囲外なら `level` が null で、`reason` に `not-minimal`・`reading-dependent`・`too-deep`・`virtual-shortcut`・`size-not-allowed`・`unlisted-combination`・`long-line`・`requires-trial` が入る。ほかに特徴（`FEATURE_KEYS`）・慣れた試し置きの戻し・`givens`・`solution` を持つ。`corpus` は4プロセスで動く。1候補の p50 は 4×4 0.00秒・5×5 0.16秒・6×6 0.54秒。
- 何問作れるか（当たる割合、事実（実測）。下書き §6.2）:
  - L1 は 4×4 T1 k0 100%。L2 は 5×5 T2 k1 65%・T2 k2 47%、4×4 T2 k0・k1 17%。
  - L3 は 5×5 T2 k12・6×6 T2 k12 78%。L4 は 6×6 T3 k12 26%、6×6 T2 k12 16%、5×5 T2 k12 13%。
  - L5 は 5×5 T3 k12 78%、6×6 T3 k12 60%。
  - 5×5 の魔方陣は向き違いを除いて 275,305,224 通り（外部知見。測っていない）、6×6 はさらに多い（同）。与える数の置き方も掛かるので、500問は候補空間に対して小さい（推測）。
  - 4×4 は魔方陣 880 通りが上限で、L1 と L2 の 4×4 を合わせて 880 を超えると、同じ魔方陣が別の与える数で出る。調査コードは魔方陣を重複を避けずに選ぶ（L1 68問で 66種）。
