# 魔方陣の難易度の特徴: 反例探し（A4）の結果（2回目、版 3 に対して）

経緯を渡さない新しい確かめ役が、`a4-2/入力.md` と `magic_square_difficulty.py` だけを使って探した結果。再現のスクリプトと全変種の出力は同じ `a4-2/` にある（`results.txt`・`rs2.py`・`run_variants.py`・`compare.py`・`entry_scan.py`・`minjoint.py`・`repro.py`・`var_*.jsonl`）。

測った範囲: 入力のコマンドで候補を作り直した 1860 候補（base 1620・polish 240）。範囲内は 851 問（4×4 L1 124・L2 150、5×5 L2 175・L3 65・L4 59・L5 82、6×6 L3 61・L4 61・L5 74）。入力の 789 問とは数が合わない。`rs2.py` は `read_solve` の写しに切り替えを足したもので、既定の設定で 1860 候補すべてで元と特徴が一致した。carry は元の `VARIANTS['oldtier']` と全件で一致した。

## 1. 特徴ごとの反例

| 特徴 | 反例 | 主な向き |
|---|---|---|
| 入口 | あり | L1 の上限が、見回しながら置く数え方で大きく割れる。2マス空きの列の上下限で入口0の問題に入口ができる |
| 段の最大・段3の有無 | あり | 長い列の上下限、組が1通りの空き3の列。組の数を他で使わないをメモに残さないと段が上がる |
| 最大の巡 | あり | 段を上げる時の巡の数え方、長い列の上下限 |
| 最初の1マスの巡 | あり | 段を上げる時の数え方、2〜3本の列を一緒に読む、読みを足すと増える場合 |

## 2. 反例の中身

- A. 入口（L1 の上限）: `ms4-T1-k0-2`（与える数 `[0,15,6,9,1,14,0,0,13,0,11,0,0,3,0,0]`）。定義（最初から空き1マスの列のマスだけを数える）では入口2で L1。行→列→斜めの順に1回見回し、埋まったらすぐ書いて次を見ると1回で5マス置け、空き8の半分を超えて too-light。自然な順で L1 の 87/124（70%）、22通りの順のどれかで 123/124 が割れる。L1 のうち 42問が「入口がちょうど空きの半分」。空き1マスの列を本数で数えても L1 の 11% が too-light。自然さ: 見回しながら置くのはいちばん自然な数え方。`entry_scan.py`
- B. 長い列の上下限を段2で使う（range2）: `ms5-T3-k1-8`。1列目は空き3で残り22、ほかの2マスは少なくとも 3+5 なので各マスは14以下。この上下限だけで段2の1巡で (3,1)=12・(4,0)=25 が決まり、段3 1→0、L4→L3。範囲内の 3.3%（5×5 3.4%、6×6 7.7%）、L4 の 25/120 が L3、L5 の3問が L4 か L3。自然さ: 足し算のパズルでよく使う読み。定義は段を空きの数だけで決めるので、安い上下限の読みまで段3に入る。
- C. 2マス空きの列の上下限を段1の扱いにする（range1）: `ms5-T2-k12-22`（L4）。3列目は残り8で (1,3)≤7、反対の斜めは残り31で (1,3)≥31−24=7、よって (1,3)=7。入口 0→1 で unlisted-combination。入口0の問題（L3〜L5 の 402問）の 17問（4.2%）に入口ができる。4×4 は 55% が動く。自然さ: 定義の上では段2の読みだが、人には段1並みに軽い。
- D. 段を上げる時の巡の数え方（carry・cum）: `ms5-T3-k12-4`（L5、最初の巡3）。定義は段2で動かなくなった後、段3を行き詰まりの始めの候補から数え直す（最初の巡3）。人はメモを消さないので、段2を出し切った候補から段3を読む: 段3で数えて1巡（carry、L4）、段2の3巡も足すと4巡（cum）。carry 4.0%（L5 の 34/156 が L4）。cum 5.4%（L5 の 29問が too-deep、L4 の 13問が L5）。自然さ: どちらも「メモは残す」と食い違わない。
- E. 組の数を他で使わないをメモに残さない（lock_eph）: 消した数をその巡で置けるマスを探すのにだけ使い、ほかの単位を読む時には使わない。`ms5-T2-k12-26` が L4→L5。16.7%（5×5 18%、6×6 37%）、L5 の 96/156・L4 の 42/120 が動き、ほとんどが requires-trial・long-line へ。消したのを読んだ列のマスのメモにだけ書く（lock_units）なら 0.8%。自然さ: 単位の外の全マスのメモを手で消すのは手間で、消さない人はかなりいる。
- F. 読みを足すとレベルが上がる（short3）: 組が1通りになった空き3の列を段2で読む。`ms5-T3-k0-10` で最初の所が (3,1)（段3・1巡）から (2,2)（段2・2巡）に変わり、最初の巡 1→2、L4→L5。原因は「置ける最も低い段を使う」決まり。short3_1 3.4%（L4 の4問が L5、L4→L3 は19問）、組2通りまで 5.6%（6×6 13.8%）。
- G. 2〜3本の列を一緒に読む（jointk）: `ms5-T3-k0-27`。1行目（空き3）と1列目（空き2）を一緒に読むと（4マス・自由度2）、(0,2)=15 が最初の1巡で決まり L5→L4。L5 156問のうち最初の1マスが1巡で決まるようになるのは、4マスの組で17問、自由度2以下で4本まで39問（25%）、4本まで何でも91問（58%）。全体で自由度2以下・3本まで 4.3%（5×5 6.0%、6×6 7.1%）、何でも3本まで 7.2%、4本まで 12.1%、空き2〜3の列のつながり全部を1単位にすると 14.2%。自然さ: 3本を一緒に読むのは重く、上級者向け。
- H. ほか: 鎖から組の数を他で使わないをしない 4.8%、この数はここだけを使わない 2.1%、4本の列の ±1 の式 4.7%（4×4 の L1 10問が too-light）、組の数を他で使わないを全く使わない 24.6%。

## 3. 割合のまとめ（範囲内 851問、レベルが変わる割合）

| 読み方・数え方 | 全体 | 5×5 | 6×6 | 自然さ |
|---|---|---|---|---|
| 見回しながら置く入口（L1 の上限） | 4×4 L1 の 70% | − | − | 高い |
| 組の数をメモに残さない | 16.7% | 18% | 37% | 中〜高 |
| 段を上げる時に巡を足す（cum） | 5.4% | 6.8% | 10.2% | 高い |
| 段を上げる時に続きから数える（carry） | 4.0% | 4.2% | 9.2% | 高い |
| 組2通りまでの空き3を段2で | 5.6% | 5.5% | 13.8% | 高い |
| 組1通りの空き3を段2で | 3.4% | 3.4% | 8.2% | 高い |
| 長い列の上下限を段2で | 3.3% | 3.4% | 7.7% | 高い |
| 2〜3本を一緒に読む（自由度2以下） | 4.3% | 6.0% | 7.1% | 中 |

6×6 はどの向きでも 5×5 の 1.5〜2.5倍動く（空き3マスの列が多いため）。

## 4. 試したが崩れなかった向き

- 鎖を極大の単純な道ごとに読む: 0%。
- 数 v の入る所が全部ある列の中なら、その列は v を使う（pointing）: 0%。
- この数はここだけを段2から使う: 0%。
- 鎖の中で同じ列の外のマスどうしを区別しない: 0.8%。
- 組の数を他で使わないを、読んだ列のマスのメモにだけ書く: 0.8%。
- 違反の表示（その数を置くと合計に届く）を段2で使う: 0.5%（段1で使うと 5.4%、ほとんどが 4×4）。
- 空き3の列と、交わる鎖の全部を一緒に読む: 1.3%。
- 5×5・6×6 の仮想の列: 6マスまで探して0。

## 5. 直し方の案（確かめ役から）

1. L1 の上限: 置き方や読む順に依らない「段1の巡の数」で決める。今の L1 は 2〜5巡、too-light は 1〜2巡。境目は決め直しが要る。
2. 段: 列の上下限と組が1通りの列は、空きの数に関係なく段2の読みに入れる。「段3」は、上下限で足りず組が2通り以上ある空き3の列を読む所に限る。
3. 段を上げた所の巡: 「メモは残す」に合わせ、下の段を出し切った候補から数える（carry）。下の段を出し切った結果は1つに決まるので読む順に依らない。または、L5 の条件を最初の1マスの巡に頼らない形にする。
4. 組の数を他で使わない: 消すのは読んだ列のマスのメモにだけ、と決める（0.8% しか動かない）。メモを手で直さない人はモデルの外と書く。
5. 置ける最も低い段を使う決まり: 読みを足すとレベルが上がらないよう、段と巡を合わせた量の最小で所を決める形にする。
