## 反例探し（A4）の2回目の入力

経緯を渡さない新しい確かめ役に、この節だけを渡す。同じ問題のまま特徴の値（とレベル）を動かせる、人の読み方・数え方を探してもらう。

### ルール

n×n のマスに 1〜n² を1回ずつ置き、縦・横・斜め2本のどの列も同じ合計 n(n²+1)/2 にすればクリア。いくつかの数は最初から置いてある。答えは1つ。盤面には、置いた数、列の端の今の合計と合計の定数、候補のメモ（マスに小さく書く数。置いた数は全部のメモから消える）が見える。違反（埋まって合わない列、空きがあるのに合計に届いた・超えた列）は知らされ、行き詰まりは知らされない。盤面は 4×4・5×5・6×6。

### 特徴の定義

**読む単位**。どちらも「その単位の空きマスに、メモの候補の数を互いに違うように入れて、単位の列の合計を全部満たす入れ方」を全部考える。

- 列: 空きが e マスの列。段 e。e = 1 なら、そのマスに残りの数が入る。
- 鎖: 空きが2マスの列が同じマスでつながったまとまり（2本以上、つながった全部）。段2。1つのマスの数を t と置くと、つながった列の相手が順に決まる。

**単位を読んだ結果**（どちらも読んだ巡の結果に入る）

- 台: 単位の各マスの候補を、どれかの入れ方で入る数に絞る。
- 組の数を他で使わない: どの入れ方でも単位の中で使う数を、単位の外のマスの候補から消す（段2以上）。

**巡**。段 t の1巡は、段 t 以下の単位を全部、巡の始めの候補（同じ写し）から読み、結果を全部重ねること。重ねた候補で、候補が1つになったマスと、入る所が1マスだけになった数（この数はここだけ）を、その巡で決まったマスとする。k 巡目は k−1 巡目の結果だけを使うので、巡の数は読みの依存の段数の最小になる。単位を順に読んですぐ使う走査の回数は、別の量として扱う。

**段と所**。

- 段1 = 空き1マスの列・メモで候補が1つのマス・この数はここだけ。段1で置けない盤面が行き詰まり。
- 行き詰まりでは、段2・段3・段4の順に、どの段も行き詰まりの始めの候補から巡を重ね、決まったマスが出たら止める。出た最も低い段を使い、その段と巡の数をその「所」の値にする。段3の巡は段2の単位も一緒に読んで数える。
- 決まったマスは全部置いて段1に戻る。メモは残す。

**特徴**

| 特徴 | 定義 | 分類での使い方 |
| --- | --- | --- |
| 入口 | 最初の盤面で、段1の1巡で決まるマスの数（何マス置くかに依らない） | L2 は1以上、L3〜L5 は0。L1 は空きの半分まで |
| 段の最大 | 所の段の最大 | L1 は1、L2・L3 は2、4 は範囲外 |
| 段3の有無 | 段3の所があるか | 深い読みの1つ |
| 最大の巡 | 所の巡の最大 | 2以上が深い読み、3以上が L5 の条件の1つ、4を超えると範囲外 |
| 最初の1マスの巡 | 最初の所の巡（入口がある問題は1） | L5 は2以上 |
| 組の突き合わせの回数・絞り直しの回数 | 段2以上の所の数・巡が2以上の所の数 | 使わない（記録だけ。置き方で揺れるため） |

**レベル**（「深い読み」は2巡以上の所か段3があること。上から当てる）

| レベル | 盤面 | 条件 |
| ---: | --- | --- |
| 1 | 4×4 | 段1だけで解ける（入口は空きの半分まで） |
| 2 | 4×4・5×5 | 入口がある。段2まで要り、どの所も1巡で決まる |
| 3 | 5×5・6×6 | 入口が無い。段2まで、どの所も1巡で決まる |
| 4 | 5×5・6×6 | 入口が無い。深い読みがある。L5 に当たらない |
| 5 | 5×5・6×6 | 入口が無い。最初の1マスに2巡以上要り、3巡以上の所か段3がある |

範囲外: 段4が要る（`long-line`）、段4でも止まる（`requires-trial`）、1か所の巡が4を超える（`too-deep`）、段1だけで解けて入口が空きの半分を超える（`too-light`）、入口があって深い読みもある（`unlisted-combination`）、読みのレベルはあるがその盤面を許していない（`size-not-allowed`）、4×4 で仮想の列（四隅・中央 2×2・上下の辺の中央2マス・左右の辺の中央2マスも合計34）を足すとレベルが下がる（`virtual-shortcut`）。

### 探す向き

1. 鎖より広い、人が使いうる列をまたぐ読み。たとえば、空き3マスの列と鎖を一緒に読む、交わる2本を空き6マス以上で一緒に読む、4本以上の列の式。L5 の最初の1マスが1巡で決まる、L4 の深い読みが要らなくなる、入口0の問題に入口ができる、の3つを探す。
2. 鎖の読み方。人が鎖の全部を1つの数で表して読まないとき（途中で切る、分かれ道のある鎖を一部だけ読む）に、レベルが変わる問題。
3. 段の選び方。段2で何巡もかかる所を段3で1巡で読む、のように段を上げ下げして巡が変わる問題。読みを足すとかえって段が上がる問題。
4. メモの使い方。メモを一部のマスにしか書かない、組の数を他で使わないで消した数をメモに反映しない、など。
5. 1巡に入る読み。台・組の数を他で使わない・この数はここだけのほかに、同じ巡に入れるのが自然な読み、または次の巡に回すのが自然な読み。
6. 入口と L1。最初の盤面で、1マス空きの列が2本重なるマス、仮想の列（4×4）、列の式で入口の数が変わる問題。L1 の上限（空きの半分）の数え方で割れる問題。
7. 6×6。6×6 だけで定義の揺れが大きくなる向き。

すでに測ったもの（同じ向きを繰り返さなくてよい。数は範囲内 789 問でレベルが変わる割合）:

- 置き方・向き・メモ: 1マスずつ置く 0%、回転・裏返し 0%、メモを使わない 2%。
- 列をまたぐ読み: 交わる2本（空き3マスまで 0%・4マスまで 2%・5マスまで 5×5・6×6 で 4%）、2本の差・和 1%、3本の ±1 の式（空き3マスまで 1%・4マスまで 1%）、組3通りまでの長い列 2%、列の式の一次結合 20%（4×4 の L1 が入口の広すぎる側に出るのがほとんど。5×5・6×6 は 5%）。
- 鎖と段: 鎖を2本ずつ 3%、3本ずつ 0%、巡の最も少ない段を使う 0%。
- 数え方: 走査の回数（読む順5通り）9〜12%、組の数を他で使わないを次の巡から 10%、この数はここだけを次の巡から 2%。

反例が出たら、その定義を、どの読み方・数え方でも値が動かない形に直して決め直す。

## 問題供給と図鑑の観点への入口

- 関数（`magic_square_difficulty.py`）:
  - `generate_candidate(n, T, k, i)`: 1候補を作る。
    - n は盤面、T は極小化に使う読みの段の上限（1〜3）、k は 0〜2 なら空けたマスを k 個戻し、12 なら200回磨く。i は候補番号。
    - seed は `candidate_seed(n, T, k, i) = ((n×10 + T)×100 + k)×10000 + i`。
    - 返り値に `givens`・`solution`・時間。
  - `analyze_candidate(cand)`: 完全な解法器・読むモデル・素朴な解き方を当てる。
  - 分類: `read_solve(geo_of(n), givens)` → `read_features(...)` → `level_and_reason(PROPOSALS["C2"], f, d)`。`reading_level(f)` は盤面に依らない読みのレベル。`d` には盤面 `n`・`givens`、4×4 なら仮想の列の特徴 `d["var"]["virtual"]` を入れる。
- コマンド:

```sh
D=docs/パズル/導入調査/魔方陣/調査コード
python3 $D/magic_square_difficulty.py corpus --sizes 4 5 6 --tiers 1 2 3 --addback 0 1 2 --per 60 --out base.jsonl
python3 $D/magic_square_difficulty.py corpus --sizes 5 6 --tiers 2 3 --addback 12 --per 60 --out polish.jsonl
python3 $D/magic_square_difficulty.py classify base.jsonl polish.jsonl --proposal C2 --out classified.jsonl
```

  - `classified.jsonl` は候補ごとに `id`・`seed`・`level` を持つ。範囲外なら `level` が null で、`reason` に `too-light`・`too-deep`・`virtual-shortcut`・`size-not-allowed`・`unlisted-combination` などが入る。
  - ほかに、特徴（`FEATURE_KEYS`）・慣れた試し置きの戻し・`givens`・`solution` を持つ。
  - `corpus` は4プロセスで動く。1候補の p50 は 4×4 0.00秒・5×5 0.08秒・6×6 0.34秒。
- 何問作れるか（当たる割合、事実（実測）。下書き §6.2）:
  - L1 は 4×4 T1 k0 92%。L2 は 5×5 T2 k1・k2 78%、4×4 T2 k1 68%。
  - L3 は 5×5 T2 k12 37%、6×6 T2 k0 35%。L4 は 6×6 T2 k12 57%、5×5 T2 k12 47%。
  - L5 は 5×5 T3 k12 92%、6×6 T3 k12 90%。
  - 5×5 の魔方陣は向き違いを除いて 275,305,224 通り（外部知見。測っていない）、6×6 はさらに多い（同）。与える数の置き方も掛かるので、500問は候補空間に対して小さい（推測）。
  - 4×4 は魔方陣 880 通りが上限で、L1 と L2 の 4×4 を合わせて 880 を超えると、同じ魔方陣が別の与える数で出る。
