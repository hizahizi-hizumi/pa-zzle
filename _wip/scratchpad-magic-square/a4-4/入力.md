## 反例探し（A4）の4回目の入力

経緯を渡さない新しい確かめ役に、この節だけを渡す。範囲内の問題（レベルが付いた問題）について、人が使いうる読み方・数え方のうち、同じ問題のレベルを動かすものを探してもらう。

### ルール

n×n のマスに 1〜n² を1回ずつ置き、縦・横・斜め2本のどの列も同じ合計 n(n²+1)/2 にすればクリア。いくつかの数は最初から置いてある。答えは1つ。盤面には、置いた数、列の端の今の合計と合計の定数、候補のメモ（マスに小さく書く数。1マス4つまで。置いた数は全部のメモから消える）が見える。違反（埋まって合わない列、空きがあるのに合計に届いた・超えた列）は知らされ、行き詰まりは知らされない。盤面は 4×4・5×5・6×6。

### 特徴の定義

**読む単位**。どちらも「その単位の空きマスに、メモの候補の数を互いに違うように入れて、単位の列の合計を全部満たす入れ方」を全部考える。段は、その単位で仮に置く数の数（空きマスの数 − 式の数 + 1）。

- 列: 空きが e マスの列。段 e。e = 1 なら、そのマスに残りの数が入る。
- 鎖: 空きが2マスの列が同じマスでつながったまとまり（2本以上、つながった全部）。段2。1つのマスの数を t と置くと、つながった列の相手が順に決まる。

**単位を読んだ結果**（どちらも読んだ巡の結果に入る）

- 台: 単位の各マスの候補を、どれかの入れ方で入る数に絞る。
- 組の数を他で使わない: どの入れ方でも単位の中で使う数を、その巡に読んだ単位のマスのうち単位の外のマスの候補から消す（段2以上）。

**巡**。段 t の1巡は、段 t 以下の単位を全部、巡の始めの候補（同じ写し）から読み、結果を全部重ねること。重ねた候補で、候補が1つになったマスと、入る所が1マスだけになった数（この数はここだけ）を、その巡で決まったマスとする。巡の数は読みの依存の段数の最小になる。

**段と所**。

- 段1 = 空き1マスの列・メモで候補が1つのマス・この数はここだけ。段1で置けない盤面が行き詰まり。
- 行き詰まりでは、段2・段3・段4の順に、どの段も行き詰まりの始めの候補から巡を重ね、決まったマスが出たら止める。出た最も低い段を使い、その段と巡の数をその「所」の値にする。段3の巡は段2の単位も一緒に読んで数える。
- 決まったマスは全部置いて段1に戻る。メモは残す（基準はメモの数に上限を置かない）。

**特徴**

| 特徴 | 定義 | 分類での使い方 |
| --- | --- | --- |
| 入口 | 最初の盤面の段1の1巡で決まるマスがあるか | L2 はある、L3〜L5 は無い |
| 段の最大 | 所の段の最大 | L1 は1、L2・L3 は2、4 は範囲外 |
| 段3の所 | 段3の所があるか | 深い読みの1つ |
| 段2の所の巡の最大 | 段2の所の巡の最大 | 2以上が深い読み、3以上が L5 の条件の1つ |
| 最初の所 | 最初の所の段と巡（入口がある問題は段1・1巡） | L5 は段3か、段2で2巡以上 |
| 1か所の巡の最大 | 段2以上の所の巡の最大 | 基準の読み方で4を超えると範囲外（作り方の決まり。レベルの比べ合いには使わない） |
| 段1で極小 | 段1だけで解け、どの与える数を1つ外しても基準の段1だけでは解けない | L1 の作り方の決まり（基準で測る。読み方で比べない） |
| 組の突き合わせの回数・絞り直しの回数 | 段2以上の所の数・巡が2以上の所の数 | 使わない（記録だけ） |

**レベル**（「深い読み」は段2で2巡以上の所か段3の所があること。上から当てる）

| レベル | 盤面 | 条件 |
| ---: | --- | --- |
| 1 | 4×4 | 段1だけで解ける（与える数は基準の段1で極小に作る） |
| 2 | 4×4・5×5 | 入口がある。段2まで要り、段2の所はどれも1巡で決まる |
| 3 | 5×5・6×6 | 入口が無い。段2まで、段2の所はどれも1巡で決まる |
| 4 | 5×5・6×6 | 入口が無い。深い読みがある。L5 に当たらない |
| 5 | 5×5・6×6 | 入口が無い。最初の所が段3か、最初の所が段2で2巡以上かかり、どこかに段2の3巡以上の所か段3の所がある |

範囲外: 段4が要る（`long-line`）、段4でも止まる（`requires-trial`）、基準の読み方で1か所の巡が4を超える（`too-deep`）、段1だけで解けるが基準の段1で極小でない（`not-minimal`）、入口があって深い読みもある（`unlisted-combination`）、読みのレベルはあるがその盤面を許していない（`size-not-allowed`）、4×4 で仮想の列（四隅・中央 2×2・上下の辺の中央2マス・左右の辺の中央2マスも合計34）を足すとレベルが下がる（`virtual-shortcut`）、次の一致の決まりに当たらない（`reading-dependent`）。

**一致の決まり**。上の定義（基準）のほかに、次の 24 の部品と、その2つ・3つの組み合わせ（同じ切り替えに違う値を入れる組と、`strong`・`weak` に含まれていて設定が変わらない組を除いた 1,952 通り）でも同じ定義で特徴を測る。レベル（範囲外を含む。巡の上限は当てない）が基準と1つでも違えば `reading-dependent` として出さない。4×4 は、どの読み方でも、その読み方に仮想の列を足して読むとレベルが下がるなら `virtual-shortcut` として比べる。

| 部品 | 中身 |
| --- | --- |
| `carry` | 段を上げた所で、下の段を出し切った候補から続け、上げた段の巡だけ数える |
| `cum` | `carry` に、下の段で候補が動いた巡を足す |
| `lock_all` | 組の数を他で使わないで、単位の外の全マスの候補から消す |
| `lock_eph` | 組の数を他で使わないで消した数を候補に残さない（その巡に置けるマスを探すのにだけ使う） |
| `memoryless` | メモを使わず、置くたびに盤面から読み直す |
| `memo4` | メモに書けるのは候補が4つ以下のマスだけ。候補が5つ以上のマスは、巡の間で絞り込みを覚えず、残っている数全部に戻る |
| `one` | 1巡で決まったマスを1つずつ置く |
| `fewest` | 行き詰まりで、巡の最も少ない段を使う |
| `lock_next` | 組の数を他で使わないを次の巡から効かせる（`lock_eph` と重ねると、次の巡の置き場所探しにだけ使う） |
| `hidden_next` | この数はここだけを次の巡から効かせる |
| `range1`・`range2` | 列の上下限（空き e の列の各マスは、残り − 残っている数の大きい e−1 個の和以上、残り − 小さい e−1 個の和以下）を段1から・段2から使う |
| `viol1`・`viol2` | 違反の知らせで分かる上限（空きが2マス以上の列に、残り以上の数は置けない）を段1から・段2から使う |
| `short3_1`・`short3_2` | 組が1通り・2通りまでの空き3の列を段2で読む |
| `jointk2` | 空き3の列と、交わる空き2〜3の列を一緒に読む（段3） |
| `chain4t3` | 4本以上の列がつながった鎖を段3に数える |
| `diag_nochain` | 斜めの列を鎖（と `jointk2` の組）につながない |
| `chain2` | 鎖をつながった2本ずつに分けて読む |
| `nohidden` | この数はここだけを使わない |
| `chain_nolock` | 鎖から組の数を他で使わないをしない |
| `strong` | `range1`・`short3_2`・`jointk2`・`carry`・`lock_all` を一緒に |
| `weak` | `cum`・`lock_next`・`chain2`・`nohidden`・`chain_nolock`・`memoryless` を一緒に |

### 測るコードの関数

`docs/パズル/導入調査/魔方陣/調査コード/magic_square_difficulty.py`（標準ライブラリだけ）。

- 読み: `enumerate_line`（1本の列の入れ方）、`enumerate_eqs`（鎖などの一般の単位）、`line_units`・`chain_units`・`jointk_units`・`build_units`（単位を作る）、`read_solve`（段・巡・置き方・メモの上限。設定は `DEFAULT_READ`、部品と測るだけの変種は `VARIANTS`）
- 特徴と分類: `read_features`（`FEATURE_KEYS` が主な特徴。`d2max` が段2の所の巡の最大、`d3max` が段3の所の巡の最大、`t3` が段3の所の数）、`is_tier1_minimal`、`level_v4_raw(f, cap)`（盤面に依らない1つの読み方でのレベル。`cap=None` で巡の上限を当てない）、`single_level_v4(f, n, sizes, cap)`（盤面の割り当てと 4×4 の仮想の列を当てる）、`classify_v5`（一致の決まりまで当てた最終のレベル）、`AGREE`（24 の部品）、`AGREE_COMBOS`（1〜3つの組み合わせの名前。`"a+b"` の形）、`variant_kw(name)`（名前から `read_solve` の設定）、`combo_level(geo, givens, name, sizes)`（組み合わせでのレベル）、`SIZES_C2`（盤面の割り当て）
- 1問を全部の部品で測る: `measure_all(geo, givens)` が (基準の特徴, 変種ごとの特徴, 段1で極小か, 基準の `read_solve` の結果) を返す。`classify_v5` は、単独の部品で一致すれば組み合わせ（`agreement_combos`）も確かめ、結果を `d["agree"]` に入れる（範囲内の問題で 5×5 は5秒ほど、6×6 は10秒ほど）
- 候補を作る: `generate_candidate(n, T, k, i)`。下の「範囲内の問題を作る」で、全候補のレベルと特徴を JSONL に書ける
- 1問を測る:

```sh
python3 -B -c "import sys; sys.path.insert(0, '<調査コード>'); import magic_square_difficulty as m; n=5; g=[<与える数を行優先で25個。空きは0>]; geo=m.geo_of(n); b, v, mn, r = m.measure_all(geo, g); d={'n': n, 'givens': g, 'base': b, 'var': v, 'l1_minimal': mn}; print({k: b[k] for k in m.FEATURE_KEYS}); print(m.classify_v5(d, m.SIZES_C2), d.get('agree')); print({x: m.single_level_v4(v[x], n, m.SIZES_C2, cap=None)[0] for x in m.AGREE}); print([(s['tier'], s['sweeps'], s['cells']) for s in r['steps']])"
```

- 新しい読み方を当てる: `read_solve` の設定を足すか写しを作り、`f = m.read_features(geo, g, m.read_solve(geo, g, **設定))`、4×4 なら `f['_virtual'] = m.read_features(geo, g, m.read_solve(geo, g, extra_lines=m.VIRTUAL4, **設定))` として `m.single_level_v4(f, n, m.SIZES_C2, cap=None)` を、範囲内の問題の `level` と比べる。部品と重ねるには `{**m.variant_kw('carry+memo4'), **新しい設定}` のように設定を重ねる。


### 探す向き

1. 24 の部品の外の、人が使いうる読み方。とくに、L5 の最初の所が段2以下で決まるようになる読み（3マスの組を読まずに最初の1マスが決まる）、L3 に入口ができる読み、L4 の深い読みが要らなくなる読み、L2・L3 で深い読みが要るようになる読み。
2. メモの使い方の別案。ゲームのメモは1マス4つまで。4つの選び方（たとえば大きい方から4つ書く、列の組に出てくる数だけ書く）、メモを書くマスの選び方、消した数を戻す・戻さないなど。
3. 部品の4つ以上の組み合わせで、特に動きやすい組（`memo4`・`weak`・`lock_eph`・`diag_nochain`・`chain4t3` を含む組）。
4. 段の付け方・単位の区切り方の別案のうち、人が自然に使いそうなもの（今の付け方は「仮に置く数の数」）。
5. L1 の条件。段1だけで解ける 4×4 を、人が「すぐ埋まる」と感じる別の量で割れるか。L1 と、与える数が1〜2個多い問題の差が、人の手応えで出ないか。
6. 6×6 だけ、または 4×4 の L2 だけで揺れが大きくなる向き。
7. 一致の決まりの抜け。組み合わせまで一致しても、隣のレベルとの差がほとんど無い問題（たとえば L4 で段2の巡がちょうど2、L5 で最初の所が段2・2巡）が、自然な読み方で隣に移らないか。

反例は「範囲内の問題のレベルが、自然な読み方・数え方で別のレベル（範囲外を含む）になる」もの。範囲外の問題が範囲内に入るのは反例ではない。巡の上限（4）と L1 の極小は基準の読み方で測る作り方の決まりで、読み方でその値が変わることは反例に数えない（その読み方でレベルが変わるなら反例）。割合は範囲内 638 問に対して、盤面ごとにも出す。反例が出たら、その読み方を部品に入れるか、定義を値の動かない形に直して決め直す。

## 問題供給と図鑑の観点への入口

- 関数（`magic_square_difficulty.py`）:
  - `generate_candidate(n, T, k, i)`: 1候補を作る。
    - n は盤面、T は極小化に使う読みの段の上限（1〜3）、k は 0〜2 なら空けたマスを k 個戻し、12 なら200回磨く（点に9つの読み方での一致を入れる）。i は候補番号。
    - seed は `candidate_seed(n, T, k, i) = ((n×10 + T)×100 + k)×10000 + i`。

  - `analyze_candidate(cand)`: 完全な解法器・読むモデル・素朴な解き方を当てる。
