# 魔方陣の難易度の特徴: 反例探し（A4）の結果（1回目）

経緯を渡さない確かめ役が、入力（`a4/入力.md`）と `magic_square_difficulty.py` だけを使って探した結果。再現のスクリプトは同じ `a4/` ディレクトリにある。

## 1. 特徴ごとの結論

| 特徴 | 反例 | 主な原因 |
|---|---|---|
| 最大の巡・最初の1マスの巡 | あり（強い） | (a) 2本の列の差、交わる2本を一緒に読む、空き2マスの列の鎖を1つの数で表す、の3つの読み。(b) 段3の所では、前の段2の巡を数えていない。(c) 1巡の区切り方 |
| 組の突き合わせの回数 | あり | 1巡で決まったマスをまとめて置く前提 |
| 最初の1マス空きの列 | ほぼなし | 4本以上の列を使う式でだけ入口が生まれる。L1 の上限4は、列の本数で数えるかマスの数で数えるかで変わる |
| 段の最大・段3の有無 | 単独ではなし | ほかの読みを足したときに、ついでに動くだけ |

## 2. 反例ごとの中身

表の値は（入口, 最初の巡, 最大の巡, 突き合わせ, 段3の回数）。

### A. 2本の列の差・交わる2本を一緒に読む・空き2マスの列の鎖を1つの数で表す（どれも巡が下がる）

- `ms5-T2-k12-48`（L5、基準 (0,3,3,3,0)）
  - 空き2マスの列 d・c0・r4 は、(0,0)+(2,2)=31、(0,0)+(4,0)=37、(4,0)+(4,3)=36 でつながる。
  - (0,0)=t と置くと、残りのマスは 31−t、37−t、t−1。4つとも残っている数で、互いに違う数になるのは t=21 だけ。
  - これで4マスが1巡で決まり、値は (0,1,1,3,0) になって L5→L3 に下がる。
  - 交わる2本を一緒に読むだけでも (0,2,2,3,0) になり、L4 に下がる。
- `ms5-T2-k12-49`（L5 で最も弱い問題、最初の巡4）
  - 鎖 r4–c1 から (4,3)∈{18,19} が出る。鎖 r3–c2–d はどの入れ方でも 3 と 18 を使うので、18 はほかのマスに入らない。
  - よって (4,3)=19 が1巡で決まり、最初の巡は4→1、最大の巡も4→1になって L5→L3 に下がる。
- `ms6-T2-k0-29`（L4 の代表）
  - c5 は (1,5)+(5,5)=20、d は (4,4)+(5,5)=25。差を取ると (4,4)−(1,5)=5 で、ほかの列と重ねると (4,4)=9 が1巡で決まる。
  - 最大の巡は2→1になり、L4→L3 に下がる。3つの読みのどれでも起きる。
- `ms5-T2-k0-57`（L3 の代表）
  - 交わる2本を一緒に読むと、突き合わせが3→2回に減り、L3→L2 に下がる。

### B. 段3の巡の数え方が、定義の説明と合っていない

- 定義は「巡の数は、1マスを置くのに要る読みの依存の連なりの長さの最小」と説明している。
- コードは、段3を段2の動かなくなった候補から読み、巡を段3の分だけ数える。段2で候補を絞り直した巡は数に入らない。
- 盤面から段3まで一緒に読み、巡を最初から数える（`fresh3`）と、次のように動く。
  - `ms6-T3-k12-4`: 最初の巡が4→5で上限4を超え、L5→範囲外。段2で1巡絞った後に、段3で4巡かかっていた。
  - `ms6-T3-k12-34`: 最初の巡が2→3、最大の巡が3→4（L5 のまま）。
  - `ms5-T3-k1-15`: 段2で3巡絞った後に段3が1巡。数え直すと最大の巡は1→2（入口1なので L4 のまま）。

### C. 組の突き合わせの回数は、まとめて置く前提に乗っている

- 段2以上で決まったマスを1つずつ置き、置く順を全部試した。基準より回数が減る例は無かった。
  - `ms5-T2-k1-7`（L2）: どの順でも2→3回になり、L2→L3。
  - `ms4-T2-k0-31`（4×4 の L2）: どの順でも2→3回になり、範囲外（4×4 に L3 は無い）。
- 5×5 の境界の対（L2 `ms5-T2-k1-7` と L3 `ms5-T2-k0-57`）の差が、数え方で消えたり逆になったりする。1マスずつ置くとどちらも3回、交わる2本を一緒に読むとどちらも2回。

### D. 1巡の区切り方

- 列の順に読み、絞った候補をすぐ使う（`sync=False`）と、巡が下がる。`ms6-T3-k12-34` は (0,1,2,5,3) になり、L5→L4。読む順を5通り試すと、L5 の 73/161（45%）と L4 の 153/452（34%）が順だけで割れた。
- 「組の数を他で使わない」で除いた数を次の巡から効かせると、全体の 6.6% の段が変わる。「この数はここだけ」を次の巡から効かせると 1.3%。

## 3. レベルが変わる問題の割合

候補は `generate_candidate` で作った。4×4 は T1・T2 と k0・1・2、5×5 と 6×6 は T2・T3 と k0・1・2・12、条件ごとに60問、合わせて1320問（全問一意解）。比べたのは C2 で範囲内の 1119問（L1 145、L2 203、L3 158、L4 452、L5 161）。

| 読み・数え方 | L2 | L3 | L4 | L5 | 全体 |
|---|---|---|---|---|---|
| 1マスずつ置く（番号の小さいマスから） | 36 (18%) | 0 | 0 | 0 | 3.2% |
| 1マスずつ置く（置く順を全部試す） | どの順でも 30 (15%)、ある順で 48 (24%) | | | | |
| 2本の列の差（空き2マスの式） | 0 | 8 (5%) | 117 (26%) | 24 (15%) | 13.3% |
| 交わる2本を一緒に読む | 0 | 15 (9%) | 131 (29%) | 41 (25%) | 16.7% |
| 空き2マスの列の鎖を1つの数で表す | 0 | 16 (10%) | 139 (31%) | 45 (28%、うち5問は L3 へ) | 17.9% |
| 3本の ±1 の式（未知のマス3以下） | 0 | 10 | 124 (27%) | 31 (19%) | 14.7% |
| 段3の巡を盤面から数える | 0 | 0 | 36 (8%: 19問が L5 へ、17問が範囲外へ) | 48 (30%、巡が4を超えて範囲外) | 7.5% |
| 列の順に読む（5通りの順） | 0 | 4〜10% | 22〜25% | 30〜37% | 14〜16% |
| 置いた後も候補を覚えておく | 0 | 7 | 23 (5%) | 5 (3%) | 3.1% |

- L1 と 4×4 の L2 は、列をまたぐ読みでは1問も変わらなかった。
- 列をまたぐ読みの影響は 6×6 の方が少し大きめ（5×5 は14〜21%、6×6 は20〜24%）。

## 4. 試したが崩れなかった向き

- 偶奇・大小の偏り・同じ候補の2マス・同じ所にしか入らない2つの数: 段が変わったのは 8/1119（0.7%）だけ。
- 残りが極端な長い列（4マス以上で組が1〜3通りの列も読む）: 変化0。
- 入口0の問題に、列をまたぐ式で入口ができるか: 3本以下の列の式では L3〜L5 の入口0の401問で0問。4本の式なら L5 の 3/161 に入口ができる（例 `ms5-T2-k12-49`: c0+c2−r3−d で (2,0)=16）。
- 回転・裏返し: 8通りすべてで特徴は動かなかった。
- 段の選び方: 段3の方が巡が少ないときに段3を先に使っても、L5→L4 は2問だけ。
- 4×4 の仮想の列4本: 漏れなし。列の一次結合を全部使うと L2 88問のうち5問が L1 に下がるが、最初の盤面ではどれも4本以上の列の式が要る。
- 小さな点:
  - 読みを足すと段が上がることがある。`ms5-T3-k2-47` は、同じ候補の2マスの読みを足すと L4→L5 になった。段2が4巡で置けてしまい、1巡で済む段3の読みが使われなくなるため。
  - L1 の上限4は1マス空きの「列」の本数で数えている。マスの数で数え直すと、範囲外だった 4×4 の25問が L1 に入る。

## 5. 直し方の案（確かめ役から）

1. 巡を盤面から数え直す。段3の所も、段2の絞り直しの巡を含めて盤面から数える（`fresh3`）。L5 の30%が上限4を超えるので、上限と L5 の境目を決め直す。
2. 読む単位を、空き2マスの列の鎖にする。鎖を1つの数で表す読みを基準にしてから、2本の差・交わる2本・3本の式を足しても、段が変わったのは 5/1152（0.4%）。段の分布は L2 270、L3 265、L4 355、L5 117 に動くので、境目を決め直す。
3. 組の突き合わせの回数の数え方を決める。1マスずつ置いたときの最小の行き詰まり回数にするか、「まとめて置く」前提を定義に書くか。L2/L3 の境目はこの選び方で変わる。
4. 1巡に入る読みを定義に書く。「組の数を他で使わない」と「この数はここだけ」は、列を読んだのと同じ巡で効くと明記する。L1 の入口は、列の本数かマスの数か、どちらで数えるかを決める。

## 再現

`a4/` ディレクトリで実行する（スクリプトは `pool.jsonl` を相対パスで読む）。

- 入力の例だけを数秒で再現: `python3 -I <a4>/repro.py <a4>`
- 候補を作る: `python3 -I <a4>/pool.py <a4> 60 pool.jsonl`
- 割合の表: `python3 -I <a4>/variants.py <a4> out.jsonl one,diff2u2,joint2,chain2,fresh3,seq_nat,seq_rev,seq_r1,memory,tri3c1,lin` の後に `python3 -I <a4>/summarize2.py out.jsonl`。偶奇・大小などは `pairs,parity,hall,allglob`、1巡の区切り方は `hidden_lag,lock_lag`。
- そのほか: `one_choice.py`（置く順を全部試す）、`robust_chain.py`（鎖を基準にしたときの安定性）、`misc1.py`、`misc2.py`、`explain_step.py`・`explain_lin.py`・`diff_example.py`。
- 写したモデル `gread.py` は、1320問すべてで `read_solve` と置く順・段・巡が一致することを `verify_gread.py` で確かめた。足した読みはどれも、解き終えた盤面が答えと一致する（`soundness.py`）。
