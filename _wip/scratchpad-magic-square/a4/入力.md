# 魔方陣 難易度の特徴の定義と問題の例（反例探しの入力）

ルール: n×n のマスに 1〜n² を1回ずつ置き、縦・横・斜め2本のどの列も同じ合計 n(n²+1)/2 にすればクリア。いくつかの数は最初から置いてある。答えは1つ。

### 2.2 分析が表現できる解法過程

読むモデル（`read_solve`）は、置いた数と列の残りだけから空きマスの候補を絞る。

| 読み | 内容 |
| --- | --- |
| 段1 1マス空きの列 | 空きが1マスの列は、そのマスに残りの数が入る |
| 段2 組の突き合わせ | 空きが2マスの列で、残っている数のうち足して残りになる組を全部考え、各マスに入りうる数を絞る。交わる列の候補と重ね、1つになったマスに置く |
| 組の数を他で使わない | どの組でも使う数（組が1通りならその2つ）は、その列の外のマスには入らない |
| この数はここだけ | 残っている数のうち、入る所が1マスだけになった数はそこに置く |
| 段3 3マス空きの列の組 | 空きが3マスの列を、段2と同じように読む |
| 絞り直し | 同じ段で、絞った候補を使ってもう一度全部の列を読む。全部の列を1回読むのを1巡と数え、1マスを置けるまでに2巡以上要る所を絞り直しとする |

- 段は低い方から使い、置けたら段1に戻る。同じ段では、全部の列を同じ候補の写しから同時に読み、その巡で決まったマスを全部置く。読む列の順に依らない（導出）。k 巡目には、k−1 巡目までの絞り込みを使う読みが全部入るので、巡の数は、1マスを置くのに要る読みの依存の連なりの長さの最小になる（導出）。
- 置くたびに、候補を盤面から作り直す（メモが無い前提）。前の絞り込みを覚えておく数え方は A3 の変種として測った（§5.3）。
- 範囲外にするもの: 空きが4マス以上の列を読まないと進めない問題（段4）、段4でも止まる問題（試し置きが要る）、1か所の巡が4を超える問題。
- 表現できないもの:
  - 4×4 の仮想の列。どの 4×4 魔方陣でも、四隅・中央の 2×2・上下の辺の中央2マスずつ・左右の辺の中央2マスずつの合計が 34 になる（事実（実測）、`enum4` で全 7,040 通りに成り立つ）。知っている人には1マス空きの列が増える。4×4 は、仮想の列を足して読むとレベルが下がる問題を除く（§4.1）。5×5 には6マス以下、6×6 には5マス以下の仮想の列は無い（事実（実測）、`identities`）。
  - 2本の列の差など、列をまたぐ式から推す読み。反例探し（A4）で探してもらう。

## 3. 特徴

| 特徴 | 意味（人の挑戦がなぜ変わるか） | 使い方 |
| --- | --- | --- |
| 盤面の一辺 | 数と列が増え、1つの列で考える組が増える | 分類（規模の範囲） |
| 段の最大 | 2マスの組で足りるか、3マスの組まで読むか。3マスの組は考える組がずっと多い（§5.2 の B3） | 分類（L1 は1、L2・L3 は2、L4・L5 は2〜3） |
| 最初の1マス空きの列 | 最初に段1で手を付けられる列の数（入口の広さ） | 分類（L1 は1〜4、L2 は1以上、L5 は0） |
| 組の突き合わせの回数 | 段2以上が要った所の数。行き詰まって組を読む回数 | 分類（L2 は1〜2、L3 は3以上か入口0）。L4・L5 には下限を置かない（§13） |
| 最大の巡 | 1か所で読み直す深さ（絞った候補で組を作り直した回数＋1） | 分類（L2・L3 は1、L4 は2〜4か段3、L5 は3以上か段3。どのレベルも4まで） |
| 最初の1マスの巡 | 最初の1マスを決めるのに要る巡。入口の深さ。置く前なので、覚えておく数え方でも変わらない | 分類（L5 は2以上） |
| 絞り直しの回数 | 巡が2以上の所の数 | 記録（数え方で揺れる。§5.3） |
| 3マス空きの列を読む回数 | 段3が要った所の数 | 分類は「あるか」だけ（L4・L5） |
| 組の数を他で使わない・この数はここだけ | 段の中で使った読みの種類 | 記録（推論の種類の表、§5.2 の B5） |
| いちばん重い列の組の数 | 組の突き合わせの1巡目に読んだ列のうち、組がいちばん多い列の組の数。1か所を読む重さ | 記録（B3） |
| 慣れた試し置きの戻し | §8 | 記録 |
| 空き・与える数 | 規模・作業量 | 記録（下流の作業量） |

### 4.2 レベルごとの基準表（案 C2。比較実験の条件で、調査時点の値。正はコード）

上から当て、最初に当たったレベルにする。太字はそのレベルで新しく要るもの。

| レベル | 盤面 | 条件 |
| ---: | --- | --- |
| 1 | 4×4 | 段1だけで解ける。最初の1マス空きの列が1〜4 |
| 2 | 4×4・5×5 | 段2まで、どこも1巡で決まる。最初の1マス空きの列が1以上で、**組の突き合わせ**が1〜2回 |
| 3 | 5×5・6×6 | 段2まで、どこも1巡で決まる。**最初の1マス空きの列が0**か、**組の突き合わせが3回以上** |
| 4 | 5×5・6×6 | **2巡以上の所（絞り直し）**があるか、**段3（3マス空きの列の組）**が要る。L5 に当たらないもの |
| 5 | 5×5・6×6 | 最初の1マス空きの列が0で、**最初の1マスに2巡以上**要り、**3巡以上の所**か段3がある |

どのレベルも、巡は4まで、段4・試し置きは要らない。4×4 は、仮想の列（§2.2）を足して読んでもレベルが下がらない問題だけにする（L1 は、仮想の列で入口が広すぎる側に出るだけなら L1 のまま）。

## 反例探し（A4）の頼み

経緯を渡さない役に、次だけを渡して、同じ問題のまま特徴の値（とレベル）を動かせる解き方・数え方を探してもらう。

- 特徴の定義: 上の「決めた案のレベル」の表と用語、下書き §2.2（読み）・§3（特徴）・§4.2（基準表）
- 測るコード: `docs/パズル/導入調査/魔方陣/調査コード/magic_square_difficulty.py` の `enumerate_line`（1つの列の読み）、`read_solve`（段・巡・置き方）、`read_features`（特徴）、`reading_level`・`prop_C2`（分類）、`_virtual_ok`（4×4 の仮想の列）。1問を測るには `python3 -B -c "import sys; sys.path.insert(0, '<調査コード>'); import magic_square_difficulty as m; g=m.geo_of(5); f=m.read_features(g, <与える数のリスト>, m.read_solve(g, <与える数のリスト>)); print(f, m.reading_level(f))"`
- 探す向きの例: 読むモデルに無い人の読み（2本の列の差、偶奇、残りが極端な長い列、5×5・6×6 の列をまたぐ式）で、L5 の最初の1マスが1巡で決まる、L4 の絞り直しが要らなくなる問題。同じ列の読みの区切り方（1巡の中身）で巡が変わる問題。向き・置く順で変わる問題
- 問題の例（与える数 → 解。行ごと、`.` は空き）。ほかの代表・境界は下書き §7
