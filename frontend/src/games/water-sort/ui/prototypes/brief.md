# brush-up-puzzle: water-sort（ウォーターソート）

## 変えないもの

- 盤面は、容量4のボトルの並び。問題は、各色ちょうど4単位ずつを含む、色数と同じ本数の満杯のボトルと、1本または2本の空ボトルから始まる（色数は4〜12、ボトルは6〜14本）。
- 操作は、注ぎ元のボトルをタップして選び、注ぎ先のボトルをタップして注ぐ。選んだボトルをもう一度タップすると選びを外す。
- 1回の注ぎでは、注ぎ元の上端に連続する同色の液体を、注ぎ先に入るだけまとめて移す。移す量は遊ぶ人が指定しない。
- 注ぎ先が空か、注ぎ先の上端が注ぎ元と同色で空きがあるときだけ注げる。注げないときは盤面が変わらず、注ぎ元は選んだまま。
- 1色で満杯のボトルや、注げる先が無いボトルは注ぎ元に選べない（選ぼうとすると通らない）。
- 成立した注ぎ1回を1手と数える。
- すべての空でないボトルが単色で満杯になったらクリア。
- 手詰まり（どこへ注いでも戻れる盤面にしか行けず、その中にクリアが無い）になったら、そのことを知らせ、待ったと盤面を戻すへ導く。
- 待った（1手戻す）、盤面を戻す、リセット、別の問題がある。
- 合法手・注げる先・正解の手を先回りして示さない。

## 気持ちよい瞬間

1. 注いだ色が、注ぎ先の上端の同じ色に重なり、境目が消えて一つのかたまりにつながる瞬間
2. 1本のボトルが1色の4単位で満ちる瞬間
3. 混ざったボトルから上の色を出していくと、下に埋もれていた色が顔を出す瞬間
4. ボトルが空になり、使える空きが戻ってくる瞬間
5. 最後の1本が満ち、すべてのボトルが1色ずつに揃って並ぶ瞬間

## 場面

1. 眺める: 始まりや手の合間に、盤面全体の色の重なりを見渡して読む
2. 選ぶ: 注ぎ元のボトルを選ぶ（選びを外すことも含む）
3. 注ぐ: 選んだボトルから注ぎ先へ液体が移る
4. 注げない: 色が違う・満杯のボトルへ注ごうとした、選べないボトルを選ぼうとした
5. 空になる: 注ぎ元のボトルが空になる
6. 一部が済む: 1本が1色で満ちる
7. 手詰まり: もう先へ進めない盤面になったことを知る
8. 完成する: 最後の1本が満ち、全部が揃う

## 深掘りの案（手順 10）

出所: E = 1つ目のサブエージェント、F = 2つ目。各4案、5つの勝負所（素材の描き方・光・置かれる場所・動き・済んだ姿）から互いに違う所を選ばせた。
まとめ方: 勝負する所と作り方が同じものを1つにした。採ったのは、出したサブエージェントの番号の若いほう（E）の書き方。並びは数の多い順、同じ数ではE→F・返答の中の番号の順。
