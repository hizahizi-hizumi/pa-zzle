■ 加工

録音の取り出し方と加工は scripts/assets/hakoiri_musume_sounds.ts にある。乱数は使わない。発振器や雑音で音を足さず、
どの音も録音の切り出し・重ね・フィルタ・速さの変更だけで作る。録音は ffmpeg で 48kHz のモノラルにし、ピークから -30dB を
超える最初の点の 0.6ms 前から始め、ピークを 1 にそろえる。重ねと加工は Chromium の OfflineAudioContext で描く
（フィルタは BiquadFilterNode、速さは AudioBufferSourceNode の playbackRate、端は直線で閉じる）。

1. 駒がすべる音（piece-slid・piece-slid-2・piece-slid-3）
   ウッドブロックの打音を頭に置く。弱く打った録音は打ってから山まで約 10ms かかるので、山の直前（9ms から）の 26ms を、
   テイクごとに違う速さで鳴らし、180Hz〜1.8kHz に絞る。その 1ms 後から、ギロのこすりの 29ms を 0.72 倍の速さで -6dB で重ね、
   260Hz の高域通過・2.4kHz の低域通過・700Hz の谷（-2dB・Q 1.1）を掛ける。

   打音の速さは、3本の高さ（周波数の重心）が半音ほどずつ上がるように選ぶ。

   piece-slid    wood_click_pp_rr1（0.531 倍）＋ guiro_short5（30ms から）
   piece-slid-2  wood_click_pp_rr2（0.562 倍）＋ guiro_short3（130ms から）
   piece-slid-3  wood_click_pp_rr3（0.589 倍）＋ guiro_short（40ms から）

2. cleared-slide（娘が出口の縁をこすって抜けていく）
   頭に wood_click_pp_rr1 の 9ms からの 26ms を 0.45 倍の速さで -4dB、180Hz〜1.8kHz に絞って置く。
   その 4ms 後から Guiro_Med_rr1_Mid の 120ms からの 400ms を 0.62 倍の速さで 0dB、立ち上がり 30ms・終わり 220ms で鳴らし、
   出だしから 400ms 後に、同じ録音の 200ms からの 220ms を 0.8 倍の速さで +2dB、立ち上がり 200ms・終わり 25ms で重ねる。
   ギロはどちらも 200Hz〜1.8kHz に絞り、600Hz の山（+3dB・Q 1.0）を掛ける。後半ほど大きく高くなり、娘が抜け切るまで鳴る。

3. cleared-thud（抜けた娘が箱の外へ落ちる）
   Cajon_hit1_mp_rr1 の 420ms を 0.8 倍の速さで、70Hz〜1.1kHz に絞り 220Hz の低域の棚 +3dB を掛けたものに、
   wood_click_mp の 60ms を 0.5 倍の速さで 200Hz〜2kHz に絞って -2dB、
   wood_click_f_rr1 の 75ms を 0.3 倍の速さ（約 360Hz の低い音程の打音）で 180〜600Hz に絞り、-3dB・終わり 200ms で、
   Cajon_hit2_mp_rr1 の 320ms を 0.66 倍の速さで 200Hz〜1.6kHz に絞って -3dB を重ねる。
   スマホのスピーカーで鳴りにくい胴鳴りの低い音に、木の打音と胴の倍音を足して重さを伝える。

4. 仕上げ（すべての音）
   末尾に 30ms の無音を足し、400ms 窓の最大ラウドネス（ITU-R BS.1770 の K 特性、前後に 400ms の無音を足して測る）を目標に合わせる。
   2ms の RMS の包絡がピークから指定の大きさだけ下がった点に、閉じる長さを足したところで切り、cos² で閉じる。
   ピークから -50dB を超える最初の点の 0.5ms 前から始め、もう一度ラウドネスを目標に合わせる。
   ffmpeg で 16bit・48kHz・モノラルの FLAC にし、メタデータの PADDING のブロックを外す。

                   目標        切る点   閉じる長さ
   piece-slid（1〜3） -46.75 LUFS -50dB   12ms
   cleared-slide    -42.5 LUFS -50dB    20ms
   cleared-thud     -34.5 LUFS -54dB    120ms
