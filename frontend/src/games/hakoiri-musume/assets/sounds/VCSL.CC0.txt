■ 加工

録音の取り出し方と加工は scripts/assets/hakoiri_musume_sounds.ts にある。乱数は使わない。発振器や雑音で音を足さず、
どの音も録音の切り出し・重ね・フィルタ・速さの変更だけで作る。録音は ffmpeg で 48kHz のモノラルにし、ピークから -30dB を
超える最初の点の 0.6ms 前から始め、ピークを 1 にそろえる。重ねと加工は Chromium の OfflineAudioContext で描く
（フィルタは BiquadFilterNode、速さは AudioBufferSourceNode の playbackRate、端は直線で閉じる）。

1. 駒がすべる音（piece-slid・piece-slid-2・piece-slid-3）
   ギロのこすりの 46ms を 0.72 倍の速さで鳴らし、260Hz の高域通過・2.4kHz の低域通過・700Hz の山（+3dB・Q 1.1）を掛ける。
   その鳴り始めから 40ms に、ウッドブロックの 26ms を 0.55 倍の速さで、180Hz〜1.6kHz に絞って -5dB で重ねる。

   piece-slid    guiro_short5（30ms から）＋ wood_click_pp_rr1
   piece-slid-2  guiro_short3（60ms から）＋ wood_click_pp_rr2
   piece-slid-3  guiro_short（40ms から）＋ wood_click_pp_rr3

2. cleared-slide（娘が出口の縁をこすって抜けていく）
   Guiro_Med_rr1_Mid の 300ms を 0.62 倍の速さで鳴らし、200Hz〜1.8kHz に絞り、600Hz の山（+3dB・Q 1.0）を掛ける。
   立ち上がりを 120ms、終わりを 160ms で閉じる。

3. cleared-thud（抜けた娘が箱の外へ落ちる）
   Cajon_hit1_mp_rr1 の 420ms を 0.8 倍の速さで、70Hz〜1.1kHz に絞り 220Hz の低域の棚 +3dB を掛けたものに、
   wood_click_mp の 60ms を 0.5 倍の速さで 120Hz〜1.4kHz に絞って -8dB、
   Cajon_hit2_mp_rr1 の 320ms を 0.66 倍の速さで 150Hz〜800Hz に絞って -9dB を重ねる。

4. 仕上げ（すべての音）
   末尾に 30ms の無音を足し、400ms 窓の最大ラウドネス（ITU-R BS.1770 の K 特性、前後に 400ms の無音を足して測る）を目標に合わせる。
   2ms の RMS の包絡がピークから指定の大きさだけ下がった点に、閉じる長さを足したところで切り、cos² で閉じる。
   ピークから -50dB を超える最初の点の 0.5ms 前から始め、もう一度ラウドネスを目標に合わせる。
   ffmpeg で 16bit・48kHz・モノラルの FLAC にし、メタデータの PADDING のブロックを外す。

                   目標        切る点   閉じる長さ
   piece-slid（1〜3） -48 LUFS   -56dB    15ms
   cleared-slide    -47 LUFS   -50dB    60ms
   cleared-thud     -38 LUFS   -54dB    120ms
