# エージェントの書き方

## フロントマター

- `name` は動作主名詞にする
- `description` は「〜を受け取り、〜を返す。〜のときに使う。」の形で書く
- 検査の観点や手順は `description` ではなく本文に書く
- `tools` を書き、本文の手順で使うツールだけを挙げる

## 本文

- 本文には受け取るものと返すものを書く
- 構造化した出力を返すときは雛形をコードブロックで示す
- 手順は呼び出し側の会話が見えなくても、プロンプトで渡すものとリポジトリのファイルだけで進められるように書く
- ルールの決まりのようにエージェントの外で定まるものは中身を写さず、置き場所のパスと読むタイミングを書く
- 決まりからは分からない検査の手順は、その決まりを名指しして書く

  ```
  OK:
  - レビューの前に `.claude/rules/rules.md` を読み、その各項目で検査する
  - 「同じ対象への1つの決まりは1つのルールファイルにだけ書く」は、ほかのルールを Grep して検査する
  NG:
  - フロントマターに `paths` 以外のフィールドが無いかを検査する
  ```
