# AGENTS.md・CLAUDE.md の書き方

- `CLAUDE.md` とそこから `@` で取り込むファイルを合わせて 200 行を目安にする
- 同じ対象の指示は1つの見出しの下にまとめる
- 指示は箇条書きで書く
- 守れたかを確かめられる指示にする
- 大事な指示もほかと同じ書式と語調で書く

  ```
  OK:
  - 作業中に `main` を取り込まない
  NG:
  - **絶対に**作業中に `main` を取り込まない
  - IMPORTANT: 作業中に `main` を取り込まない
  ```

- 意図（「〜ため」）は書いていない場面にも同じ考えで判断を広げてほしい指示にだけ添える

  ```
  OK:
  - 決まりを変える・新しく決める前に `docs/adr/` の関係する ADR を確かめる。将来の意思決定に一貫性を持たせるため
  NG:
  - ADR を足したら `docs/adr/index.csv` に行を足す。将来の意思決定に一貫性を持たせるため
  ```

- 添える意図は `docs/adr/` の ADR とプロダクトオーナーがマージした PR の本文に書かれたものだけにする
- ChatGPT など Claude Code 以外のエージェントも従う指示は `AGENTS.md` に書く
- `CLAUDE.md` には `@AGENTS.md` の取り込みと、サブエージェントのモデル指定のように Claude Code だけに要る指示だけを書く
