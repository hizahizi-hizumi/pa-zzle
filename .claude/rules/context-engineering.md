# 開発情報の配置

## 置き場所

- 全作業で読む指示は `AGENTS.md` に置く。Claude Code 固有の指示だけ `CLAUDE.md` に置く。
- 対象パスで決まる規約は `.claude/rules/` に置き、`paths` で適用範囲を限定する。
- 特定の作業の実行手順、補助資料、検査スクリプトは `.claude/skills/<name>/` に置く。
- 独立した文脈で作業させる役割は `.claude/agents/<name>.md` に置く。
- いずれにも属さない開発知識は `docs/` に置き、必要な手順から読む先を示す。

## 判断の順序

1. 決定的な検査・処理として実装できる内容は、既存の検証機構やスクリプトに置く。
2. 毎セッション必要な共通指示なら `AGENTS.md` に置き、特定パスだけの指示なら `paths` 付きルールに置く。
3. 特定の作業を開始して使う手順なら Skill に置く。
4. 独立した文脈で判断する作業なら Agent に置く。
5. 残る知識は `docs/` に置く。

## 配置の制約

- サブディレクトリ固有の規約は `paths` 付きルールに置き、サブディレクトリの `CLAUDE.md` は作らない。
- `CLAUDE.md` と `paths` のないルールを分割する前に、毎セッション必要な指示だけが残っているか確かめる。
- `CLAUDE.md`・ルール・Skill・Agent の定義は人がレビューして確定する。生成物をそのまま採用しない。
