# TypeScript のコーディング規約

## 関数定義

- 名前付き関数はアロー関数で定義せず、関数宣言を使う。

## テスト専用公開

- モジュール内部でのみ使う関数や定数を、テストから参照する目的だけで通常の公開APIとして個別に `export` しない。
- テストから直接参照する必要がある内部要素は、`export const _private = { ... }` にまとめて公開する。
- `_private` に含める内部要素自体には `export` を付けず、モジュール内部からは直接参照する。
- `_private` はテスト専用とし、本番コードから参照しない。
