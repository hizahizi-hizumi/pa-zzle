# デザイントークンの編集

- `@theme` のトークンを追加・削除・改名する前と、値の変更でトークンの意味や使い分けが変わる前に、`DESIGN.md` を読む
- `DESIGN.md` でトークンを探すときは、`.claude/rules/design-md.md` の「値とトークン」に書いたトークン名の書き方で探す
- 追加するトークンは、意味と使い分けを `DESIGN.md` に定義する。定義できないものは足さない
- トークンを追加・削除・改名したら、同じ変更の中で `DESIGN.md` の定義も揃える
- 意味や使い分けを変えない値の調整では `DESIGN.md` を変えない
