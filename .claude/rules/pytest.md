# pytest のコーディング規約

## テスト配置

- テストは対象モジュールと同じディレクトリへコロケーションし、`test_<対象モジュール>.py` とする。
- 複数モジュールに共有する fixture が必要になるまで `conftest.py` は作らない。共有範囲は必要最小限にする。

## テストケース命名規則

- テストケース名は `test_` に続けて日本語の散文で具体的な期待動作を記述し、`こと` で終える。
- テストケース名と `@pytest.mark.parametrize` のケースIDは、人間が条件・期待動作を理解するための散文として扱う。
- テストケース名に `場合` `時` は含めない。
  - 条件を明示する必要がある場合は、`Test<条件>の場合` クラスでまとめる。`<条件>` は日本語の散文で記述し、その中のテストケースは期待動作だけを記述する。
  - 条件が対象コード内部の識別子や状態名でしか表現できない場合は、条件として独立させず、対象コードのグルーピング・fixture・parametrize の入力として表すべきでないかを見直す。
- 同じ関数・メソッドを複数ケースで検証する場合は、対象名を表す `Test...` クラスでまとめる。
  - 対象を表す `Test...` クラスは、対象コードの関数・メソッド・クラス名に対応するコード表記を使う。
- テストファイル自体が対象モジュールを表すため、モジュール名だけを繰り返すためのクラスは作らない。
- fixture・helper・変数など、テストコード内部で参照する識別子はコード表記を使う。
- CLIオプション・列挙値・ID・パス・コード識別子など機械識別子やリテラルそのものを検証する場合は、散文へ言い換えず実際の表記を保持する。

## テスト構造

### 基本原則

- 事前準備 / 実行 / 検証の3相を厳密に分離する。
- 事前準備はpytest fixtureまたは `@pytest.mark.parametrize` へ分離し、テスト関数は実行と検証に集中させる。
- 実行ではテスト対象を明示的に実行し、戻り値や観測結果を変数へ受ける。テスト対象の呼び出しをアサーション式へ埋め込まない。
- 実行と検証の間は空行で分離する。
- 例外送出自体が期待動作なら、`pytest.raises` で囲んだテスト対象の呼び出しを実行とみなす。
- テスト対象の公開契約を検証し、実装手順や内部構造を固定するだけのアサーションは置かない。

### 事前準備の分離方法

- テストデータ、入力値、外部状態、再利用するサブプロセスのコマンドなどはfixtureで用意する。
- 共通の事前準備は同じテストモジュール内のfixtureから始め、複数モジュールで本当に共有するときだけ `conftest.py` へ移す。
- fixtureの適用範囲は必要最小限とし、理由なく `session` / `module` や `autouse=True` を使わない。

```python
import pytest


@pytest.fixture
def user_id():
    return 1


def test_ユーザーを取得できること(user_id):
    result = get_user(user_id)

    assert result.id == user_id
```

テスト関数内でテストデータ生成やモック構築を始めない。

```python
# 避ける
def test_ユーザーを取得できること():
    user_id = 1
    repository = FakeRepository({1: User(id=1)})

    result = repository.get(user_id)

    assert result.id == user_id
```

テスト対象の実行をアサーションへ埋め込まない。

```python
# 避ける
def test_ユーザーが存在すること(user_id):
    assert user_exists(user_id)
```

### 特定のテストだけ異なるデータが必要な場合

- 同じ期待動作を入力違いで検証する場合は `@pytest.mark.parametrize` を使う。
- ケース名が必要なら `ids` を条件やケース内容を説明する日本語の散文で付け、失敗時に条件を判別できるようにする。機械識別子やリテラルそのものを区別する必要がある場合は実際の表記を保持してよい。
- 既存fixtureを使う一部のケースだけ値を変える必要がある場合は、fixtureを受け取った後にテスト固有の差分だけを変更してよい。
