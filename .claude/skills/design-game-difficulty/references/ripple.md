# 波及の連鎖

難易度に関わるものを1つ変えると、下流が古くなる。変えた所から下へ一気に通し、どこまで通したかを報告に表で書く。上流（ルール・補助）の変更を受けて起動されたときも、この連鎖の該当する所から入る。

## 下向きの連鎖

上から順に通す。各段で「直すもの」「測り直すもの」「版」を確かめる。

| 段 | 何が変わったら | 直すもの・測り直すもの | 版・テスト |
|---|---|---|---|
| 1. ルール・補助・状態の知らせ | ルール、一致・違反・正誤の表示、待った・盤面を戻すの有無 | 基準とするプレイ条件を資料と SPEC で書き直す。素朴な解き方の合法手と進み具合を新しい補助に合わせ、検査 D1 を測り直す | 素朴な解き方のテスト |
| 2. 解法器・特徴・分類 | 手筋、特徴の定義、組み合わせ定義、提供範囲 | 検査 A〜D を測り直す。レベルごとの一言が今の組み合わせと合うかを確かめる | 判定モデル版があれば上げる。分類のテスト（境界・状態・隣のレベルで弱まらないこと） |
| 3. 生成器 | 候補空間、生成条件、作り方、成立条件 | 検査 E を測り直す。identity から同じ問題が作れるか | 生成器の版（identity の再現が変わるとき）。記録の identity を読めるか（`game-structure.md`「記録」） |
| 4. 問題集 | 2・3 のどれか | 全問を作り直し、`--verify` を通す。代表・境界・異常の問題 ID を抜き直す。サイズと選択時間を測る | 問題集の版。問題集が持つ判定モデル版と今の版の一致をテストで確かめる |
| 5. 基準時間・採点 | 4 で問題の作業量の分布が変わったとき、つまみを足したとき | 基準時間の項に、足したつまみが作業量として効くなら入っているか。レベルごとに同じ腕前の点が平らか（基準時間に対する比の分布）。1つの項が基準の過半を占めていないか | 採点版。記録の採点版で旧式と新式を区別して再計算できるか |
| 6. 難易度プレビュー | 2 のつまみ・一言、4 の分布 | プレビューが写す量が、今の問題集でレベル間に差のある量か。作り方は `/design-game-difficulty-preview` に任せ、測った値を渡す | プレビューのテスト（組み合わせとの一致、隣で弱まらないこと） |
| 7. SPEC | 1・2 の契約、一言 | SPEC の難易度の節（基準とするプレイ、挑戦、つまみの組、レベルごとの一言、規模の扱い）。書く範囲は `難易度判定.md`「各パズルが持つべき具体化」に従う | 文書の数値とコードの値が食い違っていないか（SPEC・資料・テストを照合） |
| 8. 記録の互換 | 2〜5 のどれか | 旧版の記録を読み続けられるか。記録の難易度・判定モデル版・採点版で比較単位を分けるか。旧版の問題を遊び直せるか | payloadVersion（記録の項目の追加・削除・意味の変更のとき）。旧版の記録を読むテスト |
| 9. 難易度の資料 | どれか | 前提・特徴・組み合わせ・分布・供給・代表問題・素朴な解き方・ゲート表を今の版に合わせる。古い版の結果は「作り直す前の定義」として節を分けて残す | — |

## 上向きの戻り

下流で分かったことが上流を変えることがある。見つけたら、戻った段から下向きの連鎖を通し直す。

| 気づく所 | 戻る先 | 例 |
|---|---|---|
| 試遊・記録で「補助を見れば試して進める」 | 1（補助）か 2（試し置きの下限） | 一致表示を足したら試し置きで解けるようになった（リフレクション） |
| プレビューで、写せる量がレベル間で差を持たない | 2（一言とつまみ）か 6 の写し方 | プレビューの列数に合わせて難易度の割り当てを変えた（スライドパズル） |
| 採点で、あるレベルだけ点が系統的に低い | 2（つまみの作業量）か 5（基準時間の項） | 規模をつまみにしたのに基準時間の項が一定だった |
| 供給で、あるレベルの候補が出ない | 2（提供範囲）か 3（候補空間） | 密な盤面が成立条件で落ちる（リフレクションの 11×11） |

## 通し方

- 1回の変更で連鎖を最後まで通す。途中で止めると、問題集・基準時間・プレビュー・SPEC の版が食い違う。
- 段 4 の全生成は重いので、段 2・3 の案を仮の問題集で固めてから1回だけ流す。途中から再開できる形（候補番号順、キャッシュ）で流す。
- 新規では、段 5〜8 のうちまだ作っていない項目（スコア・プレビュー・記録が後の項目のとき）は、作る項目に渡すもの（測った分布・一言）を報告に書き、通したことにしない。
- 報告には段ごとに「通した／該当なし／通していない（理由）」を書く。
