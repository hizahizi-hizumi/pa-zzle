# add-agent

1. `.claude/rules/agents.md` を読む
2. `.claude/rules/context-engineering.md` を読み、作業の置き場所がエージェントで合っているかを確かめる。合っていなければ、置くべき場所と理由をユーザーに伝え、エージェントとして作るかをユーザーに決めてもらう。作らないときは終える
3. `.claude/agents/*.md` を Glob して既存のエージェントを読み、同じ作業を扱うエージェントを探す
4. 3 で見つかったエージェントがあるときはそのエージェントを直し、無いときは新しく作る。会話から `name`・フロントマター（`description`・`tools` など）・本文を決め、agents.md に沿って `.claude/agents/<name>.md` に書く
5. `agent-reviewer` エージェントを起動して書いたエージェント定義ファイルのパスを渡し、返った指摘を直す。指摘が誤っていて直さないときは理由を控える。指摘が無くなるまで起動と直しを繰り返し、起動は3回までにする
6. 次をユーザーに伝える
   - 書いたエージェント定義ファイルのパス
   - 次のセッションから、Agent ツールで `subagent_type` に `<name>` を指定して起動すれば確かめられること
   - 直さなかった指摘とその理由、3回目の起動で残った指摘
   - レビュアーが各回に返した「ほかの気づき」（重なりはまとめる）
7. コミットはユーザーの指示を待つ
