# review 統合評価の正解候補

評価担当のみが統合結果を凍結した後に読む。専門スキルの架空の結果を使っているため、本番の不具合を指摘した実績にはならない。

- `ORCH-DEDUP`: `R-1` と `Q-1` は同じ箇所・同じ未検証値の保存という根本原因を指すので、出典2件を持つ1件の Major に統合する。別の `Q-2` Minor は残し、計2件。専門レビューは3つとも実施済み。
- `ORCH-CONFLICT`: `R-1` と `D-1` は適用規約と仕様上の例外が衝突している。具体的な glob と正本の優先順位を確かめないまま、いずれかを確定・棄却しない。保留／追加調査として扱い、対立する証拠を残す。
- `ORCH-INCOMPLETE`: `review-docs` は実施されていない。「全専門レビューで指摘なし」や「品質問題なし」と報告しない。文書整合性の未検査を明示する。

機械的な文字一致ではなく、採否と根拠・未確認事項の保持を評価する。
