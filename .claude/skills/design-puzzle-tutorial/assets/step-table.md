# 盤面とステップの表

画面に出る文字は、この表にすべて書き出す。

- 始まりとゴールの盤面は、文字で書き、盤面の記号の意味を添える。
- 行は、入口から完成まで、一言が出る場面を出る順に並べる。違反を伝える一言はルールごとに、完成の一言は開いた場所（ゲームのホーム・プレイ中）ごとに1行にする。上部に並ぶルールの名前は、表の最初の1行にまとめる。
- 一言の改行は `/`、画面に出すときに埋める語は `＜…＞` で書く。一言に見出しと補う一文があるときは、`見出し｜補う一文` と書く。PO が決めた言い回しには `【PO】` を付ける。
- 「その手を決めるもの」には、ルールを伝えるステップと手がかりでは、伝えたルールと、そのルールで手を決める盤面の物（決め手）を書く。操作を教えるステップでは、その手がゴールの盤面と一致することを書く。手を離す行では、動作フロー2-3の「手を離した後」の条件のうち、どれで残りが解けるかを書く。

```text
始まり:        ゴール:
<盤面>          <盤面>
```

| 場面 | 印を付ける所 | 一言 | その手を決めるもの |
|---|---|---|---|
| ルールの名前 | なし | <ルールごとの名前> | |
| 入口 | なし | <何をするパズルかの一文> → <ゴールの盤面の一言> → <始まりの盤面の一言> | |
| ステップ1 | <打つ所> | <操作を教える一言> | 操作（ゴールの盤面と一致する） |
| ステップ2 | <打つ所> | <ルールを伝える一言> | <伝えたルール>（<決め手>） |
| 手を離す | なし | <残りを解かせる一言> | <伝えたルールで残りが決まる / どう進めても詰まない / 詰まっても教えた操作で戻せる> |
| 違反（<ルール>） | なし | <違反を伝える一言> | |
| 手がかり | <打てる所> | <手がかりの一言> | <伝えたルール>（<決め手>） |
| 完成（ゲームのホームから） | なし | <完成の一言> | |
| 完成（プレイ中から） | なし | <完成の一言> | |
