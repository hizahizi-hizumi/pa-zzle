# 盤面とステップの表

画面に出る一言を書き出す文書は、この表だけにする。

- 始まりとゴールの盤面を、マスの記号を添えて文字で書く。
- 入口から完成まで、画面に一言が出る場面を出る順に1行ずつ並べる。違反を伝える一言は、ルールごとに1行にする。
- 一言の改行は `/` で書く。画面に出すときに埋める語は `＜…＞` で書く。PO が決めた言い回しには `【PO】` を付ける。
- 「その手を決めるもの」には、伝えたルールと、そのルールで手を決める盤面の物（決め手）を書く。

```text
始まり:        ゴール:
<盤面>          <盤面>
```

| 場面 | 印を付ける所 | 一言 | その手を決めるもの |
|---|---|---|---|
| 入口 | なし | <何をするパズルかの一文> → <ゴールの盤面の一言> → <始まりの盤面の一言> | |
| ステップ1 | <打つ所> | <操作を教える一言> | 操作（ゴールの盤面と一致する） |
| ステップ2 | <打つ所> | <ルールを伝える一言> | <伝えたルール>（<決め手>） |
| 手を離す | なし | <残りを解かせる一言> | <伝えたルールで残りが決まる / どう進めても詰まない> |
| 違反（<ルール>） | なし | <違反を伝える一言> | |
| 手がかり | <打てる所> | <手がかりの一言> | <伝えたルール>（<決め手>） |
| 完成 | なし | <完成の一言> | |
