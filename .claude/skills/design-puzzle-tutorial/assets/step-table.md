# 盤面とステップの表

画面に出る一言を書き出す文書は、この表だけにする。

- 始まりとゴールの盤面を、マスの記号を添えて文字で書く。
- 入口から完成まで、画面に一言が出る場面を出る順に1行ずつ並べる。違反を伝える一言は、ルールごとに1行にする。
- 一言の改行は `/` で書く。画面に出すときに埋める語は `＜…＞` で書く。PO が決めた言い回しには `【PO】` を付ける。
- 「印を付ける所」には、次に操作する所だけを書く。目標や決め手は「その手を決めるもの」に書く。
- 「その手を決めるもの」には、伝えたルールか読みと、それで手を決める盤面の物（決め手）を書く。

```text
始まり:        ゴール:
<盤面>          <盤面>
```

| 場面 | 印を付ける所 | 一言 | その手を決めるもの |
|---|---|---|---|
| 入口 | なし | <何をするパズルかの一文>（補足: <ゴールの盤面に添える一言>） | |
| ステップ1 | <打つ所> | <操作を教える一言> | 操作（ゴールの盤面と一致する） |
| ステップ2 | <打つ所。向きや道筋を選ばせるなら行き先、打つ所を探させるなら「なし」> | <ルールを伝える一言> | <伝えたルール>（<決め手>） |
| 最後のステップ | <打つ所。自分で選ばせるなら「なし」> | <読みを伝える一言> | <レベル1に要る読み>（<決め手>） |
| 手を離す | なし | <残りを解かせる一言> | <伝えたルールと読みで残りが決まる / どう進めても詰まない / 詰んだら教えた操作で戻れる> |
| 手順に無い手（<ステップ>） | <そのステップの印。無ければ「なし」> | <今のステップで何をするかの一言> | |
| 違反（<ルール>） | <直す所。違反が盤面に残らないなら「なし」> | <何に当たったか>（補足: <直し方>） | |
| 「ヒント」を押したとき | <打てる所> | <手がかりの一言> | <伝えたルールか読み>（<決め手>） |
| 完成 | なし | <完成の一言>（補足: <本番へつなぐ一言>） | |
| 完成の振り返り | なし | <覚えたルールを1行ずつ> | |
