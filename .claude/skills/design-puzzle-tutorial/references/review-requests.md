# サブエージェントへの依頼

各役に、下の依頼文の `<…>` を埋めて渡す。依頼文に無いことは足さない。

「ゲームのホームの URL」には `<起点>/puzzles/<game>` を入れる。`<起点>` は、PR のプレビュー URL か、`AGENTS.md` の実行コマンドで起動した開発サーバーの URL にする。

## 編集者役

`<盤面とステップの表>` には PR 本文の表を入れる。

```text
あなたは日本語に厳しい母語話者の編集者です。次は、パズルのチュートリアルで画面に出る文字を、出る場面の順に並べた表です。「/」は改行の位置、「｜」は見出しと補う一文の境です。

<盤面とステップの表>

次に当たる所を、強い順に挙げてください。【PO】が付いた言い回しは挙げないでください。
- 声に出して不自然な所
- 人が横で教える言い方から外れる所
- 呼び名や動詞の揺れ
- 一度で意味が取れない所
- 削れる言葉
```

## 作る側

PR が無いときは、PR の行を `- コード: frontend/src/games/<game>/tutorial/ と frontend/src/games/<game>/ui/` に替える。

```text
<game> のチュートリアルを、作る側の目で見直してください。

- 決まり: .claude/skills/design-puzzle-tutorial/SKILL.md
- PR: <PR の URL>
- ゲームのホームの URL: <URL>

通常の設定に加えて、大原則 P6 の条件（動きを減らす設定は Playwright の page.emulateMedia({ reducedMotion: "reduce" })）でも、入口から完成まで自分で操作し、次を確かめてください。
- 大原則に反していないか。
- ルールの扱いが本番の実装と一致しているか。
- 動作フローの2-3の条件がテストで確かめられているか。
- コードの置き場所と依存、印や合図の描き方が、.claude/rules/game-*.md（game-md.md を除く）の「チュートリアル」節と「依存方向」節に沿っているか。

報告してほしいもの:
- 大原則の違反: 原則番号と、どこがどう反するかを1文で。
- 不具合: テストに無い条件、置き場所や共通の部品から外れた所も含める。
好みの指摘は要りません。コードは変更しないでください。
```

## 遊ぶ側

```text
次のゲームのホームから、パズルのチュートリアルを初めてのプレイヤーとして入口から完成まで遊び、感想を自由に書いてください。

- ゲームのホームの URL: <URL>
```
