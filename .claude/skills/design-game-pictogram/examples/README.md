# 完成見本

`/design-game-pictogram` で到達すべき品質水準を示す、レビュー済みの完成見本。

- `water-sort.svg`: 容器 + 水量差を最小構成で表現する例
- `sudoku.svg`: 3×3格子 + 数字を、外枠 / 格子 / 記号の視覚階層を付けて表現する例
- `parking-jam.svg`: 車両 + 出口 + 詰まりを、一定の余白と車幅で単純化して表現する例

これらはゲーム固有形状をそのまま流用するためのテンプレートではなく、次の観点の品質基準として参照する。

- 実表示サイズで識別要素が潰れない
- 外枠・内部要素・記号の視覚階層がある
- 要素間の余白に意図があり、線同士が不用意に接しない
- 必要な特徴だけを残し、盤面の縮小コピーにしない
- 同じ一覧内で光学的重量が極端に突出しない

PoCの途中案・比較・不採用案は `docs/立ち上げ/ゲーム選択ピクトグラムPoC.md` と同名ディレクトリを参照する。
