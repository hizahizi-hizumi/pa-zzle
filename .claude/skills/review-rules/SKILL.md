# review-rules

`/review-rules` で規約への適合だけをレビューする。一般的なコード品質や要求達成の判定は担当しない。

## 手順

1. `AGENTS.md` を読み、渡された固定 ref と対象パスを確認する。PR なら差分を特定し、関連ファイルも調査する。対象 ref の内容で判断し、別の時点の規約を混ぜない。
2. `.claude/rules/*.md` の frontmatter をすべて確認し、`paths` のない規約と、対象パスに glob が一致する規約だけを読む。除外条件と本文中の明示的な適用除外も確認する。`AGENTS.md` と `CLAUDE.md` の共通規約も確認する。
3. 適用する各規約について、該当するコード・文書と必要な周辺箇所を照合する。違反を指摘する前に、規約の原文・適用パス・例外条件と、実際に問題となる箇所を示す。
4. 静的解析やテストで決定的に分かる内容は、取得できる検査結果を根拠に使う。ツールが検出する事項を、独立の問題として重複報告しない。自動検査に載っていない違反を見落とさない。
5. 根拠を反証し、適用対象外・許された例外・既存問題を取り違えていないか確認する。規約の曖昧さや未整備は「基準側の課題」に分け、違反と断定しない。
6. `${CLAUDE_PROJECT_DIR}/.claude/skills/share/review-result.md` を読み、規約のファイル・見出し、対象の `path:line`、確認状態を含めて結果を返す。外部状態を変更しない。

## 評価

このスキルの評価・改訂時は `evals/cases.json` の入力だけでレビューを実行し、出力を確定した後に `evals/ground-truth.md` と比較する。適用除外の見落としによる誤検出を必ず測る。
