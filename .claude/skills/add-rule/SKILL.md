# add-rule

1. `.claude/rules/rules.md` を読む
2. `.claude/rules/context-engineering.md` を読み、決まりの置き場所がルールで合っているかを確かめる。合っていなければ、置くべき場所と理由をユーザーに伝え、ルールとして作るかをユーザーに決めてもらう。作らないときは終える
3. `.claude/rules/*.md` を Glob して既存のルールを読み、rules.md の「同じ対象への1つの決まりは1つのルールファイルにだけ書く」に当たるルールを探す
4. 3 で見つかったルールがあるときはそのルールを直し、無いときは新しく作る。会話からファイル名・`paths`・決まりを決め、rules.md に沿って `.claude/rules/<ファイル名>.md` に書く
5. `rule-reviewer` エージェントを起動して書いたルールファイルのパスを渡し、返った指摘を直す。指摘が誤っていて直さないときは理由を控える。指摘が無くなるまで起動と直しを繰り返し、起動は3回までにする
6. 次をユーザーに伝える
   - 書いたルールファイルのパス
   - `paths` があるときは一致するファイルの例と、そのファイルを Read すると読み込まれること。無いときは次のセッションの開始時から読み込まれること
   - 直さなかった指摘とその理由、3回目の起動で残った指摘
   - レビュアーが各回に返した「ほかの気づき」（重なりはまとめる）
7. コミットはユーザーの指示を待つ
