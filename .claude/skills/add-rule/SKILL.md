# add-rule

1. `.claude/rules/rules.md` を読む
2. `.claude/rules/context-engineering.md` を読み、決まりの置き場所がルールで合っているかを確かめる。合っていなければ、置くべき場所と理由をユーザーに伝え、ルールとして作るかをユーザーに決めてもらう。作らないときは終える
3. `.claude/rules/*.md` を Glob して既存のルールを読み、同じ対象の決まりを持つルールを探す
4. 会話からファイル名・`paths`・決まりの案を作る。同じ対象の決まりを持つルールがあるときは、そのルールを直す案にする
5. 案をユーザーに見せ、了承を得てから次に進む
6. rules.md に沿ってルールを書く
7. `rule-reviewer` エージェントを起動し、書いたルールのパスを渡す
8. 返った指摘をユーザーに伝え、直すかどうかをユーザーに決めてもらう
9. 書いたルールのパスをユーザーに伝える。`paths` があるときは、一致するファイルの例と、そのファイルを Read すると読み込まれることを伝える。`paths` が無いときは、次のセッションの開始時から読み込まれることを伝える。コミットはユーザーの指示を待つ
