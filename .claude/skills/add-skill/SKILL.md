# add-skill

1. `.claude/rules/skills.md` を読む
2. `.claude/rules/context-engineering.md` を読み、手順の置き場所がスキルで合っているかを確かめる。合っていなければ、置くべき場所と理由をユーザーに伝え、スキルとして作るかをユーザーに決めてもらう。作らないときは終える
3. `.claude/skills/*/SKILL.md` を Glob して既存のスキルを読み、同じ作業を扱うスキルを探す
4. 3 で見つかったスキルがあるときはそのスキルを直し、無いときは新しく作る。会話からスキル名・フロントマター（`description`・`allowed-tools`・`disable-model-invocation` など）・手順・補助ファイルを決め、skills.md に沿って `.claude/skills/<スキル名>/` に書く
5. `skill-reviewer` エージェントを起動して書いた SKILL.md のパスを渡し、返った指摘を直す。指摘が誤っていて直さないときは理由を控える。指摘が無くなるまで起動と直しを繰り返し、起動は3回までにする
6. 次をユーザーに伝える
   - 書いたファイルのパス
   - `/<スキル名>` で起動して確かめられること
   - 直さなかった指摘とその理由、3回目の起動で残った指摘
   - レビュアーが各回に返した「ほかの気づき」（重なりはまとめる）
7. コミットはユーザーの指示を待つ
