# チュートリアルのチェックリスト

作った本人の確認（SKILL.md「3. 作り方」の7）と、見直し役の確認（「4. 見直し」）で使う。375px 幅で入口から完成まで自分で操作し、動きを減らす設定でも通して見てから答える。P1〜P6 の項目に反するものは重大（P番号）、「細部」の項目に反するものは細部として報告する。

## P1. 目的・ゴール・始まりが分かり、迷わない

- [ ] 操作を求める前に、名前・何をするパズルかの一文・ゴールの盤面・始まりの盤面が見える。
- [ ] 最初の手順が、ルールより先に、何をどう操作するかを示している。
- [ ] 入口が自動で進んでも、自分で先へ進められる。

## P2. 言い切って、すぐそのルールで決まる手を使わせる

- [ ] 盤面が最初から最後まで本物の1枚で、始まりから解が1つに決まり、そのことがテストで確かめられている（P2・P5）。
- [ ] 手を引いている間、どこを見てどこを操作すればよいかが印で分かり、印は出た瞬間からはっきり見える。
- [ ] 操作を教える手を除き、各手順のマスが、その時点までに言い切ったルールで決まり、新しいルールを出す手順ではそのルールが決め手になる。
- [ ] 各手順の決め手（どのマス・どのルールから決まるか）が、一言か盤面から読み取れる。
- [ ] 手を引いている間は印の操作だけが進み、他の操作への反応が教えたルールと食い違わない（P2・P4）。
- [ ] 手を離した後の残りが、手に入れたルールだけで解ける。新しいルールが後から出てこない。

## P3. 盤面で伝わらないことだけを、短く自然な言葉で

- [ ] 盤面・印・反応で伝わることを言葉にしていない。補足は、決め手か操作の指示があるときだけ出す。
- [ ] 声に出して読んで自然で、人が横で教える口調になっている。
- [ ] 評価・クイズ・命令の口調や、体言止めだけの無機質な文が無い。
- [ ] 中身のないつなぎの文が無い。
- [ ] タイルやマスを人のように言わない（「自分の場所」「一緒に」など）。改行や短い文で切れ目が分かるところに読点を打たない。
- [ ] 同じもの・同じ操作を、最初から最後まで同じ呼び名と動詞で言い、遊び方や本番の画面ともそろっている。

## P4. 反応が教えたことと食い違わない

- [ ] まだ教えていないルールの違反に反応しない。
- [ ] 違反の一言が、今の盤面のどこがどのルールに当たるかを正しく言い、前後の手順と矛盾しない。
- [ ] 操作の途中の一瞬の状態に反応して、画面がちらつかない。
- [ ] 受け付けなかった操作や正しい操作のあとに、前の違反の一言が残らない。
- [ ] 一言で言った動き（どこが動く・どう変わる）と、実際の盤面の動きが一致する。
- [ ] 手順どおりに正しく操作したとき、盤面がその場で応える。
- [ ] 押しても何も起きないものが、押せる見た目をしていない。

## P5. 渡しきり、手応えを味わわせ、正直につなぐ

- [ ] ルールと、ルールを当てはめるだけで決まる読みが全部出てくる。仮定を重ねる読みは求めない。
- [ ] 手順が操作の練習で終わらず、手を離した後に自分で手を決める手応えがある。
- [ ] 迷って止まったときだけ、少し待つと手がかりが出る。止まっていないのに先回りしない。
- [ ] 完成が本番と同じ手触りの演出で見え、完成時の盤面が、完成したご褒美として明るく見える。
- [ ] 完成時の一言が、本番の難しさや内容を約束しすぎず、本番へつなぐ。

## P6. 誰でも同じ体験にたどり着け、乱れない

- [ ] 動きを減らす設定でも、入口・手順・完成で伝わる中身が欠けず、どの時点の静止画面でも意味が分かる。
- [ ] 375px 幅で盤面・一言・操作がはみ出さず、隠れない。
- [ ] 難易度選択からでもプレイ中からでも、同じ所から始まり同じ所で終わる。
- [ ] 一言や演出が、操作中の盤面を覆ったり操作を止めたりしない。

## 細部

- [ ] 余白・色・文字・動きの値が `DESIGN.md` と `@theme` に沿い、画面の端に要素が詰まっていない。
- [ ] 一言が変わっても、一言の欄の高さや盤面の位置が動かない。
