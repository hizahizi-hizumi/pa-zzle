# チュートリアル見直しチェックリスト

人間に見せる前に、上から順にすべて確かめる。確かめていない項目は「確かめていない」と報告に書く。

## 目的と範囲

- [ ] 知らない人が最後まで進めると、ルールと操作が分かり、レベル1〜2を自分で始められる
- [ ] 基本ルール（ルールとその直接の帰結）までに収まっており、テクニック集の内容を持ち込んでいない
- [ ] 遊び方ダイアログと役割が重なっていない（読む説明を増やしていない）

## 入口

- [ ] 開いた時点で、名前の下の一文から「何をするパズルか」が分かる（知らない人の目で確かめた）
- [ ] 完成した盤面に「この形がゴールです」、始まりの盤面に「最初はこのように〜」と添えている
- [ ] 目的・ゴール・始まりの一言が読める長さで表示され、何も動かない間がない
- [ ] どこを押しても演出を飛ばせ、飛ばした後に半端な状態が残らない
- [ ] 飛ばすためのタップで盤面が変わらない
- [ ] `prefers-reduced-motion` では動きを省き、目的・ゴール・始まりの一言を静止表示で読めてから本編に入る
- [ ] 「もう一度」では名前・目的・ゴールを省き、盤面を戻す動きと始まりの一言だけにしている

## 流れと盤面

- [ ] 手順1は目的を言い直さず、最初のルールと操作だけを言い、すぐ1手目を操作させている
- [ ] ルールは1つずつ言い切り、そのルールで決まる1マスをすぐ置かせている
- [ ] 最初の配置だけで解が1つに決まる（総当たりで確かめた）
- [ ] 各手順の印のマスが、その時点で示したルールだけで決まる（テストで確かめた）
- [ ] ルールを示す手順の印のマスが、それまでのルールでは決まらない
- [ ] 操作の練習で置いたマスが、後の手順の決め手に使われている
- [ ] 知っているルールだけで推理する手順がある
- [ ] 間違えると違反になる手順になっている（違う方を置いても何も起きない手順がない）
- [ ] 見比べる相手（行・列など）が近く、一言で示している
- [ ] 自由に埋める残りが、ルールで1マスずつ解き切れる
- [ ] 本番と同じ完成演出で締め、レベル1（またはプレイに戻る）へつながる

## 文言

- [ ] 評価・褒め言葉・クイズ口調・促し・中身のない一文がない
- [ ] 無機質な体言止めだけになっていない
- [ ] 操作のお願いだけ「〜してください」になっている
- [ ] 見出しが375px幅で1行に収まっている
- [ ] 声に出して読んで、自然な日本語になっている（直訳調・意味の曖昧な言い方がない）
- [ ] 動詞と呼び名が1つにそろい、チュートリアル・チップ・違反の一言・遊び方ダイアログで混ざっていない
- [ ] 2行になる文が意味の切れ目で折り返り、ほかの要素と重なっていない
- [ ] 文が増えて行数が変わっても、ピクトグラムや見出しが画面の端に詰まっていない（入口の各段で上下の余白を見た）
- [ ] プレイ中から開いた場合も、完成時の補足や操作が場違いになっていない（「レベル1」への言及など）
- [ ] 完成時の一言が、本番の難しさを約束しすぎていない（チュートリアルより本番が難しいなら、そう伝える）
- [ ] 違反の補足が、後の手順で教えることと矛盾しない（「〜だけ」と言い切って後で覆さない）
- [ ] `prefers-reduced-motion` でも、開いた直後に後ろの画面と文字が重なるコマがない
- [ ] 違反の一言が、何が起きたかと当たったルールを言っている
- [ ] 知らない人の目、上から目線・無機質に敏感な人の目で全文を読み直した

## 操作と反応

- [ ] 誘導中は印のマスだけ受け付け、他を押すと印を付け直す
- [ ] 受け付けなかった操作のあとに、前の違反の一言が残っていない（ルールの説明と矛盾して見えない）
- [ ] 印を後から出す手順で、違反の操作をしても印が消えたままにならない
- [ ] 違反への反応が遅れて出て、切り替え途中で画面が揺れない
- [ ] 一言欄の高さが固定され、文言の長さで盤面が動かない
- [ ] 手が止まると、今のルールで決まるマスに印が出る
- [ ] プレイ中から開いて閉じても、経過時間が進み続けている（画面で確かめた）
- [ ] チュートリアルのプレイが記録・採点されない
- [ ] 完成した盤面と完成後の画面が、押せない盤面のように見えない

## 実画面での確認

- [ ] 幅375pxで最初から完成まで1手ずつ進め、全手順のスクリーンショットを自分で見た
- [ ] わざと違反した、止まってヒントを出した、演出を飛ばした
- [ ] 入口・完成・「もう一度」の演出を約150msごとのコマで並べ、重なり・跳び・レイアウトのずれ・文字の切れがない
- [ ] ブラウザのエラーが0件
- [ ] `bun run --cwd frontend check`、`typecheck`、`test` が通る
