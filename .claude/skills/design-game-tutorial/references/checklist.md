# チュートリアルのチェックリスト

作った本人の確認（SKILL.md「3. 作り方」の7）と、見直し役の確認（「4. 見直し」）で使う。375px 幅で入口から完成まで自分で操作し、動きを減らす設定でも通して見てから答える。P1〜P6 の項目に反するものは重大（P番号）、「細部」の項目に反するものは細部として報告する。

## P1. 目的・ゴール・始まりが分かる

- [ ] 操作を求める前に、名前・何をするパズルかの一文・ゴールの盤面・始まりの盤面が見える。
- [ ] 最初の手順が、ルールより先に、何をどう操作するかを示している。
- [ ] 手を引いている間、どこを見てどこを操作すればよいかが印で分かる。

## P2. 言い切って、すぐ使わせる

- [ ] 盤面が最初から最後まで本物の1枚で、始まりから解が1つに決まる。
- [ ] 操作を教える手を除き、各手順のマスが、その手順で言い切ったルールで決まる。
- [ ] 比べる相手がいるルールでは、何と見比べるかが一言か盤面で分かる。
- [ ] 手を離した後の残りが、手に入れたルールだけで解ける。新しいルールが後から出てこない。
- [ ] ルールと、ルールを当てはめるだけで決まる読みが全部出てくる。仮定を重ねる読みは求めない。

## P3. 自然でそろった言葉

- [ ] 声に出して読んで自然で、人が横で教える口調になっている。
- [ ] 評価・クイズ・命令の口調や、体言止めだけの無機質な文が無い。
- [ ] 中身のないつなぎの文が無い。
- [ ] 同じもの・同じ操作を、最初から最後まで同じ呼び名と動詞で言い、遊び方や本番の画面ともそろっている。

## P4. 反応が教えたことと食い違わない

- [ ] まだ教えていないルールの違反に反応しない。
- [ ] 違反の一言が、今の盤面のどこがどのルールに当たるかを正しく言い、後の手順と矛盾する言い方（「〜だけ」など）をしない。
- [ ] 操作の途中の一瞬の状態に反応して、画面がちらつかない。
- [ ] 受け付けなかった操作や正しい操作のあとに、前の違反の一言が残らない。
- [ ] 手順で言った動き（どこが動く・どう変わる）と、実際の盤面の動きが一致する。

## P5. 遊びたくなる形で、正直につなぐ

- [ ] 完成が、本番と同じ手触りの演出でご褒美として見える。
- [ ] 完成時の一言が、本番の難しさや内容を約束しすぎず、本番のどこから始めればよいかへつなぐ。
- [ ] 手順が操作の練習で終わらず、自分で決めて置く手応えがある。

## P6. 誰でも同じ体験にたどり着け、邪魔しない

- [ ] 動きを減らす設定でも、入口・手順・完成で伝わる中身が欠けず、最初のコマから意味の分かる画面になっている。
- [ ] 375px 幅で盤面・一言・操作がはみ出さず、隠れない。
- [ ] どこから開いても、同じ所から始まり同じ所で終わる。
- [ ] 一言や演出が、操作中の盤面を覆ったり操作を止めたりしない。

## 細部

- [ ] 余白・色・文字・動きの値が `DESIGN.md` と `@theme` に沿っている。
- [ ] 画面の端に要素が詰まっていない。
- [ ] 一言が変わっても、一言の欄の高さや盤面の位置が動かない。
- [ ] 完成した盤面が、押せない盤面に見える沈んだ見た目になっていない。
- [ ] 盤面の確かめ（解の一意性・各手順の決め手）がテストに残っている。
