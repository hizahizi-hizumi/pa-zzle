# 作る順番

実装役はこの順で作る。順は依存で決まる。後の項目は、前の項目が作ったものの上でだけ完成を確かめられる。どの項目も、手本のゲームが同じ責務に持つ種類のテスト（Glob で手本と並べて比べる）をそろえるまでを完成条件に含める。いくつかの項目を続けて1つの作業カードにしてよい。片方を直すともう片方を必ず作り直す項目（difficulty と problem-pool など）は1つのカードにする。失敗パターン集の「いつ」はこの項目名で書く。

表は新しく作るときの順。main への追従の直しでは、各項目の完成条件を満たし直すことにだけ使い、「一時的に置くもの」の列は当てない（SKILL.md の作業カード）。

作業ブランチでは、playable の時点でゲームを一覧に載せ、最初から全部の画面を通す。結果画面とゲームのホームはカタログからゲームを引くので、載せないとクリアした後の画面が開けない。後の項目は、playable が置いた最初の版を中身ごと作り込む。
