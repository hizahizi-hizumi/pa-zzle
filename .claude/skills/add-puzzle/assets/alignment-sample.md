# ノノグラムの認識合わせ

ノノグラムを、下の前提で作ろうと思っています。違うところがあれば番号で教えてください。触れなかったところは、このまま進めます。

1. **完成図は絵ではなく、自動で作る模様にします。** 絵を数百問そろえる手段がないためです。模様でも約4割が一意に解ける問題になると測って確かめました。後から絵に変えると、生成と問題集を作り直します。
2. **ズームなしで、盤面の幅は10列までにします。** 幅320のスマホでも1マス24pxあり、押せる大きさです（計算）。ここを変えると、ほぼ全部やり直しになります。
3. **どのレベルも、仮置きなしで解ける問題だけにします。** 試しに塗って当てる遊びにしないためです。最上位のレベルでも500問を1分で作れました。代わりに、上級者には物足りないかもしれません。
4. **正誤は出さず、ヒントに合った行・列のヒントを薄くするだけにします。** 正誤を出すと、当てずっぽうに塗っても解けてしまうためです。
5. **スコアは速さを主にし、塗り直しを少しだけ減点します。** ×はメモとして自由に使えるよう、減点しません。
6. **名前は「ノノグラム」、ID は `nonogram` にします。** 「ピクロス」などは商標なので避けます（商標の確認はまだです）。

あわせて、作業のために次のことをしてよいか教えてください。

- `ng/` で始まるブランチの作成・push・force-push・削除
- 導入調査の Issue と PR の作成・更新

### 参考

- ルール: 各行・各列のヒント（黒の塊の長さ）どおりにマスを塗り、全部合えばクリアです。
- 面白さ: 1行で確定したマスが交わる列の手がかりになり、連鎖して解けていくところです。
- 近いゲーム: タクズ（ヒントが盤面の中にある）。
- こちらで決めて進めること: 操作はタップとなぞりで、塗りと×は切り替えます。難易度は、盤面の大きさと連鎖の長さなどの組み合わせで5段階にします。問題は各レベル数百問を前もって作ります。
- まだ確かめていないこと: 模様で達成感が出るか、縦15行が小さいスマホに収まるか、iPhone でのなぞる操作。
